10.8 栈：处理最近一个尚未完成的任务 必读

当输入中有嵌套结构（如括号、k[...]），或者当前元素需要与最近一个尚未处理的元素配对、计算时，就用栈。典型题有 20 题有效的括号、155 题最小栈、394 题字符串解码、150 题逆波兰表达式求值、32 题最长有效括号、71 题简化路径。

栈的特点是后进先出，正好对应嵌套结构中"最近打开的最先关闭"：

栈中保存所有已经开始、尚未结束的任务，栈顶是其中最近开始的一个。

例题 20 有效的括号（简述）

给一个只含 (、)、[、]、{、} 的字符串 s，判断其中的括号是否"有效"：每个左括号都有同类型的右括号与它配对，配对的右括号在它后面，而且括号之间正确嵌套，即后打开的括号要先关闭。有效返回 true，否则返回 false；空串算有效。

样例 1：s = "([]{})"，返回 true。中间的 []、{} 各自配好，外面的 ( 和最后的 ) 配对，后开的先关。

样例 2：s = "([)]"，返回 false。每种括号的个数都对，但 [ 在 ( 之后打开，却在 ) 之后才关闭，交叉了。

样例 3：s = "("，返回 false。左括号没有配对的右括号。

1.9 已经用逐步演示讲过这道题，这里给出一种更短的写法：遇到左括号时，把与之匹配的右括号压入栈中；遇到右括号时，只需判断它是否等于栈顶。[1]

// 有效的括号（LeetCode 20）：参数 s 只含 ()[]{} 六种字符。返回括号是否正确配对、嵌套；空串返回 true。
bool isValid(const string& s) {
    stack<char> st;                          // 存"接下来期待看到的右括号"
    for (char c : s) {                       // c = 当前字符；逐个看每个字符
        if (c == '(') st.push(')');          // 左括号：压入它期待的右括号
        else if (c == '[') st.push(']');     // 同上
        else if (c == '{') st.push('}');     // 同上
        else if (st.empty() || st.top() != c) return false;   // 来了右括号，但不是期待的那个
        else st.pop();                       // 正是期待的那个：配对成功，弹掉
    }
    return st.empty();                       // 还有没闭合的左括号也不合法
}
# 有效的括号（LeetCode 20）：参数 s 只含 ()[]{} 六种字符。返回括号是否正确配对、嵌套；空串返回 True。
def is_valid(s):
    st = []                           # 存"接下来期待看到的右括号"；list 当栈：append 压栈，pop 弹栈
    for c in s:                       # c = 当前字符；逐个看每个字符
        if c == '(':                  # 左括号
            st.append(')')            # 压入它期待的右括号
        elif c == '[':
            st.append(']')
        elif c == '{':
            st.append('}')
        elif not st or st[-1] != c:   # 来了右括号，但不是期待的那个；st[-1] 是栈顶
            return False
        else:
            st.pop()                  # 正是期待的那个：配对成功，弹掉
    return not st                     # 还有没闭合的左括号也不合法

栈中保存的是尚未闭合的各个左括号所期待的右括号。遇到右括号时，若栈为空或栈顶与它不同，立即返回 false；扫描结束后栈必须为空，否则有左括号没有闭合。时间 O(n)，空间 O(n)。

例题 155 最小栈

设计一个栈 MinStack，支持四个操作：push(x) 把 x 放到栈顶，pop() 拿掉栈顶元素，top() 返回栈顶元素，getMin() 返回栈里所有元素的最小值。四个操作都要在 O(1) 时间内完成。[2]

样例 1：依次执行 push(-2)、push(0)、push(-3)、getMin()、pop()、top()、getMin()，三次查询依次返回 -3、0、-2。压入三个数后栈里是 −2、0、−3，最小的是 −3；拿掉栈顶的 −3 后，栈顶是 0，剩下的 −2、0 中最小的是 −2。

样例 2：依次执行 push(1)、push(1)、pop()、getMin()，返回 1。有两个 1，拿掉一个以后栈里还剩一个 1，最小值仍是 1。

题目保证调用 pop、top、getMin 时栈不为空。若只在栈外用一个变量记录最小值，弹出最小值后就无法知道新的最小值。因此让栈的每一层存一对数：值本身，以及从栈底到这一层为止的最小值。这样每一层记录的最小值都等于它及以下所有值的最小值。压入 x 时，新一层的最小值是 x 与下面一层的最小值中较小的那个；弹出时只删除最上面一层，下面各层的记录不受影响。每个操作都是常数步。

// 最小栈（LeetCode 155）：一个对象是一个整数栈，push、pop、top、getMin 都是 O(1)。
// 成员 st 的每一格存 (值, 从栈底到这一格的最小值)。调用 pop、top、getMin 时栈保证非空。
class MinStack {
    stack<pair<int, int>> st;                // (值, 压入它之后整个栈的最小值)
public:                                      // 下面四个操作都是 O(1)
    // 压入 x：新的最小值 = min(x, 压入前的最小值)；空栈时就是 x
    void push(int x) { st.push({x, st.empty() ? x : min(x, st.top().second)}); }
    void pop() { st.pop(); }                 // 弹掉栈顶，下面那一格记的最小值自动恢复
    int top() { return st.top().first; }     // 栈顶的值
    int getMin() { return st.top().second; }  // 栈顶那一格记的就是当前整个栈的最小值
};
# 最小栈（LeetCode 155）：一个对象是一个整数栈，push、pop、top、get_min 都是 O(1)。
# 成员 st 的每一格存 (值, 从栈底到这一格的最小值)。调用 pop、top、get_min 时栈保证非空。
class MinStack:
    def __init__(self):               # 建一个空栈
        self.st = []                  # (值, 压入它之后整个栈的最小值)

    # 压入 x：新的最小值 = min(x, 压入前的最小值)；空栈时就是 x
    def push(self, x):
        self.st.append((x, x if not self.st else min(x, self.st[-1][1])))  # 新的最小值 = min(x, 压入前的最小值)；空栈时就是 x

    def pop(self):                    # 弹出栈顶，无返回值
        self.st.pop()                 # 弹掉栈顶，下面那一格记的最小值自动恢复

    def top(self):                    # 返回栈顶的值
        return self.st[-1][0]         # 栈顶的值

    def get_min(self):                # 返回当前整个栈的最小值
        return self.st[-1][1]         # 栈顶那一格记的就是当前整个栈的最小值

重复的最小值不需要特殊处理：每一层各自记录，弹出一个 2 之后，下面那个 2 所在层的记录仍然是 2。

例题 394 字符串解码

给一个编码后的字符串 s，规则是：k[encoded] 表示方括号里的内容 encoded 重复 k 次（k 是正整数，可以是多位数），方括号里还可以再套方括号；方括号外面的字母原样保留。返回解码后的字符串。题目保证输入格式正确。[3]

样例 1：s = "3[a]2[bc]"，返回 "aaabcbc"。"a" 重复 3 次得到 "aaa"，"bc" 重复 2 次得到 "bcbc"，前后拼起来。

样例 2：s = "3[a2[c]]"，返回 "accaccacc"。先看里层，"2[c]" 是 "cc"，于是方括号里是 "acc"，再重复 3 次。

样例 3：s = "10[a]"，返回 10 个 a 组成的串 "aaaaaaaaaa"。重复次数是两位数 10。

代码用到的变量：

  • cur：当前这一层括号内已经拼好的字符串。
  • num：正在读入的重复次数。
  • 栈 st：每一层保存一对数据，即进入这一层括号之前外层已拼好的字符串，以及这一层的重复次数。栈的深度等于当前所在的括号层数，cur 只包含当前层的内容。

逐个读字符：

  1. 读到数字，累加到 num：num = num * 10 + 这一位。
  2. 读到 [，把 (cur, num) 压入栈中，然后清空 cur、把 num 置 0，开始拼接内层。
  3. 读到 ]，弹出 (outer, k)，令 cur = outer + cur 重复 k 次，回到外层。
  4. 读到字母，追加到 cur。

扫描结束后栈为空，cur 就是答案。例如 "3[a2[c]]"：读到第一个 [ 时压入 ("", 3)；读完 a 后 cur = "a"，读到第二个 [ 时压入 ("a", 2)，cur 清空；读完 c 后 cur = "c"；第一个 ] 弹出 ("a", 2)，cur = "a" + "cc" = "acc"；第二个 ] 弹出 ("", 3)，cur 变成 "acc" 重复 3 次，即 "accaccacc"。

// 字符串解码（LeetCode 394）：参数 s 是编码串，k[encoded] 表示 encoded 重复 k 次，可嵌套，k 可以是多位数。
// 返回解码后的字符串；s 为空返回空串。
string decodeString(const string& s) {
    stack<pair<string, int>> st;     // 遇到 '[' 时保存：（括号外已拼好的串，这个括号的倍数）
    string cur;                      // cur = 当前这一层已经拼出的串
    int num = 0;                     // num = 正在读的倍数，可能有多位
    for (char c : s) {               // c = 当前字符；逐个看每个字符
        if (c >= '0' && c <= '9') num = num * 10 + (c - '0');  // 数字：拼到倍数后面（处理多位数）
        else if (c == '[') { st.push({cur, num}); cur = ""; num = 0; }   // 进入新的一层
        else if (c == ']') {                                             // 回到外层
            auto [outer, k] = st.top(); st.pop();  // outer = 外层已拼好的串，k = 这一层的倍数
            string rep;              // rep = 本层串重复 k 次的结果
            for (int i = 0; i < k; ++i) rep += cur;  // 拼 k 遍
            cur = outer + rep;       // 接回外层后面，成为外层的当前串
        } else cur += c;             // 普通字母：接到当前层
    }
    return cur;                      // 最外层拼好的就是答案
}
# 字符串解码（LeetCode 394）：参数 s 是编码串，k[encoded] 表示 encoded 重复 k 次，可嵌套，k 可以是多位数。
# 返回解码后的字符串；s 为空返回空串。
def decode_string(s):
    st, cur, num = [], "", 0          # st 存 (括号外已拼好的串, 这个括号的倍数)；cur 是当前层拼出的串；num 是正在读的倍数
    for c in s:                       # c = 当前字符；逐个看每个字符
        if c.isdigit():               # 数字
            num = num * 10 + int(c)   # 拼到倍数后面（处理多位数）
        elif c == '[':                # 左括号
            st.append((cur, num))     # 进入新的一层
            cur, num = "", 0          # 新的一层从空串、倍数 0 开始
        elif c == ']':                # 右括号：回到外层
            outer, k = st.pop()       # list.pop() 直接返回栈顶，不用先 top 再 pop；outer = 外层的串，k = 倍数
            cur = outer + cur * k     # 字符串乘整数 = 重复 k 次，代替 C++ 的 for 循环拼接；接回外层后面
        else:                         # 普通字母
            cur += c                  # 接到当前层
    return cur                        # 最外层拼好的就是答案

// 返回表达式的值（除法向零截断）；保证表达式合法。
int evalRPN(const vector<string>& tokens) {
    stack<long long> st;                         // 存还没用掉的操作数
    for (const string& t : tokens) {             // t = 当前记号；逐个看每个记号
        if (t == "+" || t == "-" || t == "*" || t == "/") {  // 运算符：弹出两个数计算，结果压回
            long long b = st.top(); st.pop();    // b = 右操作数：先弹出的是右操作数
            long long a = st.top(); st.pop();    // a = 左操作数：再弹出左操作数
            if (t == "+") st.push(a + b);
            else if (t == "-") st.push(a - b);
            else if (t == "*") st.push(a * b);
            else st.push(a / b);                 // C++ 整数除法向零截断，正好符合题意
        } else {                                 // 不是运算符：是一个整数
            st.push(stoll(t));                   // 数字（可能带负号）直接入栈
        }
    }
    return (int)st.top();                        // 最后栈里只剩一个数，就是结果
}

def eval_rpn(tokens):
    st = []                             # 存还没用掉的操作数
    for t in tokens:                    # t = 当前记号；逐个看每个记号
        if t in ('+', '-', '*', '/'):   # 运算符：弹出两个数计算，结果压回
            b, a = st.pop(), st.pop()   # 从左到右求值：先弹出的是右操作数 b，再弹出左操作数 a
            if t == '+':
                st.append(a + b)
            elif t == '-':
                st.append(a - b)
            elif t == '*':
                st.append(a * b)
            else:
                st.append(int(a / b))   # 向零截断；a // b 是向下取整，负数时会错
        else:                           # 数字
            st.append(int(t))           # 数字（可能带负号）直接入栈
    return st[-1]                       # 最后栈里只剩一个数，就是结果

例题 32 最长有效括号

给一个只由 ( 和 ) 组成的字符串 s，找出其中最长的有效括号子串，返回它的长度。子串 是 s 中位置相邻的一段字符。有效括号串 的意思和例题 20 相同：每个 ( 都和它后面的一个 ) 配成一对，每个字符恰好属于一对，并且后打开的先关闭。只有圆括号一种时，有一个等价、更容易检查的说法：从左往右数，任何时候已经读到的 ) 都不比 ( 多，读完时两者一样多。例如 "(())"、"()()" 有效，")("、"(()" 无效。s 的长度在 0 到 3×10⁴ 之间；没有有效子串时（包括 s 为空）返回 0。[5]

样例 1：s = ")()())"，答案 4。下标 1～4 的 "()()" 有效，长 4。长度为奇数的串不可能两两配对；长 6 的只有整串，它第一个字符就是 )，不有效。

样例 2：s = "(()"，答案 2。整串有两个 (、一个 )，不一样多；下标 1～2 的 "()" 有效。

样例 3：s = ""，答案 0。

样例 4：s = "()(()"，答案 2。下标 0～1 和下标 3～4 各是一个 "()"，但中间下标 2 的 ( 后面没有多余的 ) 能和它配对，包含它的子串都无效，两个 "()" 连不成一段。

思路。 最直接的做法是检查每个子串：枚举起点 l，从 l 往右逐个读字符，用一个计数器记"已读到的 ( 个数减 ) 个数"。计数变成负数就停，再往右也不会有效；计数回到 0 时，从 l 到当前位置是一个有效子串，用它的长度更新答案。这样是 O(n²)，n = 3×10⁴ 时要做约 4.5×10⁸ 步，太慢。

先标出哪些字符能配上。 用例题 20 的栈把整串匹配一遍：读到 ( 把它的下标压栈；读到 ) 时，栈不空就弹出栈顶，这一对配上了；栈空就说明这个 ) 配不上。样例 1 的结果是：

配不上的字符把串切成几段，这里只剩下标 1～4 一段。每一段里的字符都在段内两两配好，所以是有效括号串；反过来，有效子串里不会含有配不上的字符。于是答案就是"被配不上的字符隔开的最长一段"，这里是 4。样例 4 "()(()" 里配不上的是下标 2 的 (，读完整串它还留在栈里；它把串切成两个 "()"，答案 2。

边走边算长度。 不必先标完再找最长段。当下标 i 的 ) 配上时，以 i 结尾的这一段，从"到 i 为止还没配上的、最靠右的那个字符"的下一格开始。这个字符要么是栈里还在等的 (，栈顶就是最靠右的一个；要么是最近一个配不上的 )。所以在栈底多放一个 分界：最近一个配不上的 ) 的下标。开始时还没有这样的 )，就放 −1，相当于在第一个字符左边假想一个分界。这样，配上并弹出之后，栈顶总是这一段左边紧挨着的那个字符，这一段的长度就是 i − 栈顶。

代码用到的变量：

  • st：栈，存下标。栈底是分界，即最近一个配不上的 ) 的下标，开始时是 −1；分界上面是还没配上的 ( 的下标，越靠栈顶越靠右。
  • best：目前找到的最长有效子串长度。
  • i：当前字符的下标。

步骤：

  1. 栈里先放 −1，best = 0。
  2. 读到 (：把 i 压栈。
  3. 读到 )：先弹出栈顶。
    • 弹完栈空了：弹掉的是分界，说明前面没有 ( 能和这个 ) 配对。这个 ) 成为新的分界，把 i 压栈。
    • 栈不空：弹掉的是一个 (，配上了。从栈顶下标的下一格到 i 是一段有效子串，用 i − 栈顶 更新 best。
  4. 读完返回 best。

// 最长有效括号（LeetCode 32）：参数 s 只含 '(' 和 ')'。
// 返回最长有效括号子串的长度；没有有效子串（包括 s 为空）时返回 0。时间 O(n)，空间 O(n)。
int longestValidParentheses(const string& s) {
    stack<int> st;                       // 栈底 = 分界：最后一个没配上的 ')' 的下标；上面 = 还没配上的 '(' 的下标
    st.push(-1);                         // 开始时还没有没配上的 ')'，用 -1（第一个字符的前一格）当分界
    int best = 0;                        // best = 目前找到的最长有效子串长度
    for (int i = 0; i < (int)s.size(); ++i) {   // i = 当前字符的下标
        if (s[i] == '(') { st.push(i); continue; }   // '(' 先等着配对，记下它的下标
        st.pop();                        // ')'：弹出栈顶。栈顶是 '(' 就配上了；是分界说明没有 '(' 可配
        if (st.empty()) st.push(i);      // 没配上：这个 ')' 成为新的分界
        else best = max(best, i - st.top());   // 配上了：从栈顶下标的后一格到 i 是有效子串，长 i - st.top()
    }
    return best;                         // 最长有效子串长度
}
# 最长有效括号（LeetCode 32）：参数 s 只含 '(' 和 ')'。
# 返回最长有效括号子串的长度；没有有效子串（包括 s 为空）时返回 0。时间 O(n)，空间 O(n)。
def longest_valid_parentheses(s):
    st = [-1]                         # 栈底 = 分界：最后一个没配上的 ')' 的下标，开始时用 -1；上面 = 还没配上的 '(' 的下标
    best = 0                          # best = 目前找到的最长有效子串长度
    for i, c in enumerate(s):         # i = 当前字符的下标，c = 这个字符
        if c == '(':                  # '(' 先等着配对，记下它的下标
            st.append(i)
            continue
        st.pop()                      # ')'：弹出栈顶。栈顶是 '(' 就配上了；是分界说明没有 '(' 可配
        if not st:                    # 没配上：这个 ')' 成为新的分界
            st.append(i)
        else:                         # 配上了：从栈顶下标的后一格到 i 是有效子串
            best = max(best, i - st[-1])
    return best                       # 最长有效子串长度

每个下标最多压栈、弹栈各一次，时间 O(n)，栈最多存 n + 1 个下标，空间 O(n)。

易错点。

  • 栈里要存下标，不能只存字符：长度靠下标相减算出来。
  • 开始时必须放 −1。不放的话，"()" 在 i = 1 配上后栈就空了，没有东西可减；有了 −1，从下标 0 开始的一段长度是 i − (−1)，正好对。
  • 配上之后长度要用 i 减去弹出后的栈顶，不能用 i 减去弹出的那个 ( 的下标再加 1。后者只算了最里面这一对，样例 1 在 i = 4 时会得到 2，漏掉前面相邻的 "()"。

参考答案
// 简化路径（LeetCode 71）：参数 path 是以 '/' 开头的 Unix 绝对路径（可有连续 '/'、"."、".."）。
// 返回规范路径：'/' 开头、目录间只有一个 '/'、末尾无 '/'、不含 "." 和 ".."；最终在根目录时返回 "/"。
string simplifyPath(const string& path) {
    vector<string> st;                       // 当栈用：已经进入、还没退出的目录名
    int n = path.size(), i = 0;                          // n = 路径长度；i：当前扫描位置
    while (i < n) {                                      // 还没扫完就继续切下一段名字
        while (i < n && path[i] == '/') ++i;             // 跳过连续的 '/'
        int j = i;                                       // j = 这一段名字的末尾（不含），从 i 往后找
        while (j < n && path[j] != '/') ++j;             // [i, j) 是一段名字
        string name = path.substr(i, j - i);             // 这一段名字（可能为空）
        if (name == "..") { if (!st.empty()) st.pop_back(); }   // 上一级；根目录的 .. 还是根
        else if (!name.empty() && name != ".") st.push_back(name);  // 普通名字才进入；空串和 "." 跳过
        i = j;                                           // 从这段末尾继续
    }
    string ans;                                          // 化简后的路径
    for (const string& d : st) ans += "/" + d;           // d = 一层目录名；栈底到栈顶就是从根往下的顺序
    return ans.empty() ? "/" : ans;                      // 栈空：就是根目录 "/"
}

    for name in path.split('/'):      # name = 一段名字；split 把连续的 '/' 切出空串，和 '.' 一起跳过

        elif name and name != '.':    # 普通名字才进入；空串和 "." 跳过

题面：给一个普通写法的算式字符串 expr，只含非负整数、四种运算符 + - * / 和空格，没有括号。按数学规则求它的值：先乘除、后加减，同级从左到右。整数除法向零截断，即直接去掉小数部分。保证算式合法、不会除以 0，结果和中间值都在 int 范围内。n ≤ 3×10⁵。（相近题型：LeetCode 227）

样例 1：expr = "3+2*2"，答案 7。先算 2 × 2 = 4，再算 3 + 4 = 7。

样例 2：expr = " 14 - 3/2 "，答案 13。空格不影响计算；3 / 2 = 1.5，去掉小数得 1，14 − 1 = 13。

样例 3：expr = "2*3*4-10/3"，答案 21。2 × 3 × 4 = 24，10 / 3 去掉小数得 3，24 − 3 = 21。

样例 4：expr = "42"，答案 42。只有一个数，没有运算符。

提示

栈里存"等着最后相加的项"。每读完一个数 num，看它前面的运算符 op：'+' 压入 num；'-' 压入 −num；'*' '/' 立即和栈顶算掉再放回——乘除优先级高，只和最近的那一项结合，这就是"最近一个还没完成的事"。最后把栈里的项全部相加。易错三处：最后一个数后面没有运算符，要在 i == n−1 时也结算；空格要跳过，不能触发结算；栈顶可能是负数，C++ 的 / 向零截断正好对，Python 要写 int(a / b)。

// 基本计算器 II（LeetCode 227）：参数 expr 只含非负整数、+ - * / 和空格，没有括号，保证合法、不除以 0。
// 返回表达式的值（整数除法向零截断）。
int evalNoParen(const string& expr) {
    vector<long long> st;                    // 等着最后相加的项（减号已经折进符号里）
    long long num = 0;                                   // num = 正在读的数，可能有多位
    char op = '+';                           // op = num 前面的运算符；第一个数前面当作 '+'
    int n = expr.size();                                 // 表达式长度
    for (int i = 0; i < n; ++i) {                        // i = 当前下标；逐个看每个字符
        char c = expr[i];                                // c = 当前字符
        bool digit = c >= '0' && c <= '9';               // 是不是数字
        if (digit) num = num * 10 + (c - '0');           // 数字：拼到 num 后面
        if ((!digit && c != ' ') || i == n - 1) {        // 遇到运算符或到了末尾：结算 num
            if (op == '+') st.push_back(num);            // 加号：num 作为新的一项
            else if (op == '-') st.push_back(-num);      // 减号：-num 作为新的一项
            else if (op == '*') st.back() *= num;        // 乘除只和最近一项结合
            else st.back() /= num;                       // 向零截断
            op = c;                                      // 记下新的运算符，留给下一个数
            num = 0;                                     // 开始读下一个数
        }
    }
    long long total = 0;                                 // 所有项之和
    for (long long t : st) total += t;                   // t = 一项；把栈里的项全部加起来
    return (int)total;                                   // 表达式的值
}

10.9 单调栈：寻找左右两侧第一个更大或更小的元素 选读

单调栈用于求每个元素右侧（或左侧）第一个比它大或比它小的元素的位置，以及以每个元素为最矮或最高时能向两侧延伸多远。暴力做法是对每个元素向一侧逐个扫描，时间 O(n²)。典型题有 739 题每日温度、496 题下一个更大元素、84 题柱状图中最大的矩形、42 题接雨水（单调栈解法）、85 题最大矩形。

以"右侧第一个更大的元素"为例。从左到右扫描，用栈保存还没有找到答案的元素的下标。新元素 a[i] 到来时，栈中所有比它小的元素都以 i 为右侧第一个更大的元素：它们在 i 之前一直没找到答案，说明它们与 i 之间的元素都不比它们大。于是把这些下标依次从栈顶弹出并记录答案，然后把 i 压入栈中，等待它自己的答案。

栈中下标从底到顶递增，对应的值从底到顶单调不增；每个下标恰好进栈一次、最多出栈一次。

这种单调性是自动保持的：每个元素压入之前，栈中所有比它小的元素都已经被弹出。由于每个下标最多进出栈各一次，总时间为 O(n)。

// 下一个更大元素的下标（单调栈模板）：参数 a 是整数数组。
// 返回 ans，ans[j] = j 右侧第一个严格大于 a[j] 的元素的下标；不存在时为 -1。
vector<int> nextGreaterIndex(const vector<int>& a) {
    int n = a.size();                       // n = 元素个数
    vector<int> ans(n, -1);                 // ans[j] = 右边第一个更大元素的下标，没有就是 -1
    stack<int> st;                          // 还没找到答案的下标；对应值从栈底到栈顶不增

    }

}

最大的矩形一定以某根柱子为其中最矮的一根。以柱子 j 为最矮时，矩形向左延伸到左侧第一根比它矮的柱子之后，向右延伸到右侧第一根比它矮的柱子之前，宽度等于右边界减左边界再减 1。因此问题转化为求每根柱子左右两侧第一根更矮的柱子。用栈中高度从底到顶递增的单调栈，在柱子 j 被弹出的时刻，两个边界同时确定：右边界是当前的 i，左边界是弹出 j 之后的新栈顶。

代码先复制一份高度数组 h，在末尾补一根高度为 0 的柱子作为哨兵。用到的变量：

  • height：刚弹出的柱子 j 的高度。
  • left：弹出 j 之后的新栈顶，即 j 左侧第一根更矮的柱子；栈为空时取 −1。
  • best：目前的最大面积。

扫描到 i 时，只要栈顶柱子不比 h[i] 矮，就弹出栈顶 j 并结算：j 右侧第一根更矮或等高的柱子是 i，左侧第一根更矮的柱子是 left，以 h[j] 为高的矩形宽 i − left − 1，面积为 h[j] × (i − left − 1)。弹完以后把 i 压入栈。

            int height = h[st.top()];        // height = 矩形的高：以栈顶柱子为高
            st.pop();                        // 出栈后的新栈顶就是它左边第一根更矮的
            int left = st.empty() ? -1 : st.top();       // left = 左边第一根更矮的柱子；没有时为 -1
            best = max(best, height * (i - left - 1));   // 右边第一根更矮的是 i；宽 = i - left - 1
        }
        st.push(i);                          // i 入栈，保持严格递增
    }
    return best;                             // 最大矩形面积
}
# 柱状图中最大的矩形（LeetCode 84）：参数 heights 是每根柱子的高度（宽度都是 1），不修改。
# 返回能勾勒出的最大矩形面积；没有柱子时返回 0。
def largest_rectangle_area(heights):
    h = heights + [0]                 # 哨兵；+ 生成新列表，调用者的 heights 不变（对应 C++ 先拷贝再 push_back）
    st = []                           # 下标，对应高度从栈底到栈顶严格递增
    best = 0                                             # best = 目前最大面积
    for i in range(len(h)):                              # i = 当前柱子；扫描每根柱子，包括末尾哨兵
        while st and h[st[-1]] >= h[i]:                  # 栈顶不比 h[i] 矮：以它为高的矩形向右到不了 i，结算它
            height = h[st.pop()]                         # height = 矩形的高；pop() 同时取出并删除栈顶；以它为高
            left = st[-1] if st else -1                  # left = 左边第一根更矮的柱子；没有时为 -1
            best = max(best, height * (i - left - 1))    # 右边第一根更矮的是 i；宽 = i - left - 1
        st.append(i)                                     # i 入栈，保持严格递增
    return best                                          # 最大矩形面积

每根柱子进出栈各一次，时间 O(n)，空间 O(n)。

练习 10.9-1【基础】股价连续不高于今天的天数 选做

题面：数组 price 是 n 天的股价，price[i] 是第 i 天的股价（n ≤ 10⁵）。对每一天 i，从这一天开始往前一天一天地数，只要那天的股价不高于今天就继续数，遇到比今天高的一天就停下；数到的天数（包括今天）就是第 i 天的答案。返回所有天的答案。（相近题型：LeetCode 901）

样例 1：price = [100, 80, 60, 70, 60, 75, 85]，返回 [1, 1, 1, 2, 1, 4, 6]。例如第 5 天是 75：往前看 60、70、60 都不高于 75，再往前的 80 比 75 高，停下，连今天共 4 天；第 6 天是 85，往前 6 天都不高于 85，第 0 天的 100 更高，答案 6。

样例 2：price = [5, 5, 5]，返回 [1, 2, 3]。一样高也算"不高于今天"，所以第 i 天能一直数到第 0 天，答案是 i + 1。

提示

换个说法：找"左边第一个严格更高的那一天" prev，答案 = i − prev（没有时 prev = −1）。这是表格里"左边第一个更大"的一行：先弹出所有 ≤ 今天的（今天比它们高而且更近，它们再也挡不住以后的任何一天），弹完后压栈前读栈顶，就是左边第一个更高的；然后今天入栈。

// 股票价格跨度（LeetCode 901）：参数 price 是每天的股价。
// 返回 span，span[i] = 从第 i 天往前数、股价都 <= 今天的连续天数（含今天）。
vector<int> stockSpan(const vector<int>& price) {
    int n = price.size();                    // n = 天数
    vector<int> span(n);                     // span[i]：截至第 i 天、价格连续不高于今天的天数
    stack<int> st;                           // 下标；价格从栈底到栈顶严格递减

练习 10.9-2【变形】环形跑道上下一个更快的人 选做

题面：n 名跑者围成一圈站好（n ≤ 10⁵），v[i] 是第 i 人的速度。从每个人出发，按下标增大的方向依次往后看，看到最后一人后接着从第 0 人看起，直到回到自己为止。找到的第一个速度严格大于自己的人，他的速度就是答案；转一圈都没找到就填 −1。返回所有人的答案。（相近题型：LeetCode 503）

样例 1：v = [1, 2, 1]，返回 [2, -1, 2]。第 0 人往后第一个就是速度 2 的人；第 1 人速度 2 最快，填 −1；第 2 人往后绕回第 0 人（速度 1，不比他快），再看第 1 人，速度 2。

样例 2：v = [5, 4, 3, 2, 1]，返回 [-1, 5, 5, 5, 5]。速度 5 的人最快，填 −1；其余每人往后看都比自己慢，要绕回开头才遇到速度 5 的人。

样例 3：v = [3, 3]，返回 [-1, -1]。两人一样快，"严格大于"的人不存在。

提示

环形就是"把数组复制一份接在后面"：i 从 0 走到 2n−1，用 v[i % n] 取值，不必真的复制。只有第一圈的下标入栈，第二圈只负责替第一圈剩下的人结算，这样每人仍只进栈一次，总 O(n)。和模板相比改了两处：循环跑两圈；答案存速度而不是下标。

参考答案
// 下一个更大元素 II（LeetCode 503，环形）：参数 v 是围成一圈的跑者速度。
// 返回 ans，ans[i] = 沿下标增大方向（末尾接回开头）第一个速度严格更大的人的速度；找不到为 -1。
vector<int> nextFasterCircular(const vector<int>& v) {
    int n = v.size();                        // n = 人数
    vector<int> ans(n, -1);                  // 答案是速度；默认 -1 表示没有更快的
    stack<int> st;                           // 还没找到更快者的下标，速度从栈底到栈顶不增
    for (int i = 0; i < 2 * n; ++i) {        // i = 第几步（0..2n-1）；跑两圈：第二圈替第一圈剩下的人结算
        int x = v[i % n];                    // 第 i 步对应的人的速度，下标取模回到第一圈
        while (!st.empty() && v[st.top()] < x) { ans[st.top()] = x; st.pop(); }  // 比栈顶快：栈顶的答案就是 x，出栈
        if (i < n) st.push(i);               // 每个人只入栈一次
    }
    return ans;                              // 每人下一个更快者的速度
}

    st = []                           # 还没找到更快者的下标，速度从栈底到栈顶不增

        x = v[i % n]                  # 第 i 步对应的人的速度，下标取模回到第一圈

            ans[st.pop()] = x         # 栈顶的答案就是 x，同时出栈
        if i < n:                     # 只在第一圈
            st.append(i)              # 每个人只入栈一次

练习 10.9-3【变形】删掉 k 位让数最小 选做

题面：字符串 num 表示一个非负整数（|num| ≤ 10⁵，没有前导零，前导零就是写在最高位前面的 0，比如 "0123" 中的 0；num 本身也可以就是 "0"）。从中删掉恰好 k 位数字（0 ≤ k ≤ |num|），剩下的数字保持原来的先后顺序拼成一个数。问能得到的最小的数是多少，以字符串返回：结果要去掉前导零；数字全被删光，或者剩下的全是 0 时，返回 "0"。（相近题型：LeetCode 402）

样例 1：num = "1432219"，k = 3，返回 "1219"。删掉 4、3 和后面的一个 2，剩下 1、2、1、9；所有删 3 位的方法中，这样得到的数最小。

样例 2：num = "10200"，k = 1，返回 "200"。删掉开头的 1 得到 "0200"，去掉前导零是 200；删掉别的任何一位，结果都至少是四位数（例如删 2 得到 1000）。

样例 3：num = "10"，k = 2，返回 "0"。两位全删掉，什么都不剩，按规定返回 "0"。

样例 4：num = "112"，k = 1，返回 "11"。删掉最后的 2 得 11；删掉一个 1 得 12，更大。

提示

高位越小越好。从左往右扫，栈里是目前保留的数位，希望它尽量不降：当前数字 d 比栈顶小，并且还能删（k > 0），就删掉栈顶——把一个更大的高位换成更小的 d，数一定变小。这里单调栈的"弹出"是一次贪心决策，而不是"替栈顶结算答案"。扫完若 k 还有剩，栈已经不降，从末尾删掉 k 位。最后去前导零，空串返回 "0"。

参考答案
// 移掉 K 位数字（LeetCode 402）：参数 num 是非负整数的数字串（无前导零，或就是 "0"），k 是要删的位数（0..|num|）。
// 返回删掉 k 位、保持原顺序后能得到的最小数（去掉前导零；删光或全是零时返回 "0"）。
string removeKDigits(const string& num, int k) {
    string st;                               // 当栈用：保留下来的数位，尽量保持不降
    for (char d : num) {                     // d = 当前数位；从高位到低位逐位看
        while (k > 0 && !st.empty() && st.back() > d) { st.pop_back(); --k; }   // 更小的 d 顶替更大的高位
        st.push_back(d);                     // d 入栈
    }
    while (k > 0 && !st.empty()) { st.pop_back(); --k; }    // 剩下的不降：删末尾的几位
    // start = 第一个非 '0' 字符的下标；全是 '0' 或为空时是 string::npos（表示"没找到"的特殊值）
    size_t start = st.find_first_not_of('0');                // 去掉前导零
    return start == string::npos ? "0" : st.substr(start);  // 全删光了返回 "0"，否则返回去掉前导零的结果
}
# 移掉 K 位数字（LeetCode 402）：参数 num 是非负整数的数字串（无前导零，或就是 "0"），k 是要删的位数（0..|num|）。
# 返回删掉 k 位、保持原顺序后能得到的最小数（去掉前导零；删光或全是零时返回 "0"）。
def remove_k_digits(num, k):
    st = []                           # 当栈用：保留下来的数位，尽量保持不降
    for d in num:                     # d = 当前数位；从高位到低位逐位看
        while k > 0 and st and st[-1] > d:   # 更小的 d 顶替更大的高位
            st.pop()                  # 删掉栈顶
            k -= 1                    # 用掉一次删除
        st.append(d)                  # d 入栈
    while k > 0 and st:               # 剩下的不降：删末尾的几位
        st.pop()                      # 删末尾一位
        k -= 1                        # 用掉一次删除
    s = ''.join(st).lstrip('0')       # s = 去掉前导零后的结果
    return s if s else "0"            # 全删光了返回 "0"

练习 10.9-4【综合】所有连续时段最低气温之和 选做

题面：数组 t 是 n 天的气温（1 ≤ t[i] ≤ 3×10⁴，可以重复，n ≤ 3×10⁴）。"连续时段"是连着的若干天（至少一天）。每个连续时段都有一个最低气温；把所有连续时段的最低气温加起来，返回这个和。起止天不同的时段分别计算。结果用 long long，不取模。（相近题型：LeetCode 907）

样例 1：t = [3, 1, 2, 4]，答案 17。单独一天的 4 个时段最低气温是 3、1、2、4；两天的 [3, 1]、[1, 2]、[2, 4] 是 1、1、2；三天的 [3, 1, 2]、[1, 2, 4] 是 1、1；四天全部是 1。加起来 10 + 4 + 2 + 1 = 17。

样例 2：t = [2, 2]，答案 6。时段 [2]、[2]、[2, 2] 的最低气温都是 2，共 6。

样例 3：t = [5]，答案 5。只有一个时段。

提示

贡献法：把答案拆成每一天的贡献。对第 j 天，设 L 是它左边第一个气温比它低的位置（没有时取 −1），R 是右边第一个比它低的位置（没有时取 n）。以 t[j] 为最低气温的时段，起点可以是 L + 1 到 j 中的任意一天，终点可以是 j 到 R − 1 中的任意一天，共 (j − L) × (R − j) 个，贡献 t[j] × (j − L) × (R − j)。例如样例 1 中第 1 天的 1，左右都没有更低的，L = −1、R = 4，以它为最低的时段有 2 × 3 = 6 个，贡献 6。L 和 R 正是 84 题"以 j 为最矮能延伸多远"的两个边界。照抄 84 的单调栈（末尾补哨兵 0），弹出 j 时 R = i，L = 新栈顶。重复值是坑：[2,2] 里时段 [2,2] 不能让两个 2 各算一次。84 的写法里弹栈条件是 >=，于是 R 是"右边第一个 ≤"、L 是"左边第一个 <"：一边严格、一边不严格，有多个相同最小值的时段只算给最右边那一个。两边都严格会重复，两边都不严格会漏。

// 子数组的最小值之和（LeetCode 907，不取模）：参数 t 是每天气温（1..3×10^4，可重复），不修改。
// 返回所有连续时段的最低气温之和；t 为空返回 0。
long long sumOfRangeMins(const vector<int>& t) {
    vector<int> h(t);                                     // h = t 的副本，不改调用者的数组
    h.push_back(0);                          // 哨兵：比所有气温都低，最后把栈清空
    stack<int> st;                           // 下标，气温从栈底到栈顶严格递增
    long long total = 0;                                  // total = 所有时段最低气温之和
    for (int i = 0; i < (int)h.size(); ++i) {             // i = 当前位置；扫描每个位置，包括末尾哨兵
        while (!st.empty() && h[st.top()] >= h[i]) {      // i 是 j 右边第一个 <= 它的位置
            int j = st.top();                             // j = 要结算的位置；结算 j
            st.pop();                                     // 出栈后的新栈顶就是 L
            int L = st.empty() ? -1 : st.top();           // L = j 左边第一个 < 它的位置；没有时为 -1
            total += (long long)h[j] * (j - L) * (i - j); // 以 j 为最低气温的时段数 × 气温
        }
        st.push(i);                                       // i 入栈，保持严格递增
    }
    return total;                                         // 所有连续时段的最低气温之和
}

# 返回所有连续时段的最低气温之和；t 为空返回 0。
def sum_of_range_mins(t):
    h = t + [0]                       # 哨兵：比所有气温都低，最后把栈清空
    st = []                           # 下标，气温从栈底到栈顶严格递增

        while st and h[st[-1]] >= h[i]:      # i 是 j 右边第一个 <= 它的位置
            j = st.pop()              # j = 要结算的位置；结算 j，出栈后的新栈顶就是 L
            L = st[-1] if st else -1         # L = j 左边第一个 < 它的位置；没有时为 -1
            total += h[j] * (j - L) * (i - j)   # 以 j 为最低气温的时段数 × 气温

易错点和变式。

  • 栈里存下标：既能取到值 a[st.top()]，又能算距离和宽度。
  • 739 中等温不算"更暖"，弹栈条件是严格 <；写成 <= 会把等温的一天当答案。
  • 84 的宽度是 i − left − 1（左右两个边界都不包含）；没有哨兵时，扫描结束要再单独清空栈。

小结： 单调栈保存还没有找到答案的下标；新元素到来时，先为比它弱的栈顶元素确定答案并弹出，再把自己入栈；84 题中元素被弹出时，它的左右边界同时确定。

10.10 单调队列：求滑动窗口中的最大值 选读

长度为 k 的窗口在数组上滑动，要求出每个位置上窗口内的最大值（或最小值）。暴力做法每个窗口需要 O(k)，总时间 O(nk)；用堆可以做到 O(n log n)；用单调队列可以做到 O(n)。典型题有 239 题滑动窗口最大值、1438 题绝对差不超过限制的最长连续子数组。

用双端队列 deque 保存下标，使下标对应的值从队头到队尾严格递减。新元素 x 从队尾加入时，队尾所有不大于 x 的元素都可以直接删除：x 比它们大，又比它们晚离开窗口，所以在它们留在窗口的整个期间，最大值都不会是它们。

队列中的下标都在当前窗口内，对应的值从队头到队尾递减，队头就是窗口中的最大值。

单调队列与单调栈的区别在于多了一个出口：当队头的元素滑出窗口时，要从队头把它弹出。

例题 239 滑动窗口最大值

给一个整数数组 nums 和窗口长度 k（1 ≤ k ≤ n）。"窗口"是数组中连着的 k 个元素：第一个窗口是下标 0～k−1，然后整体右移一格是下标 1～k，依此类推，最后一个窗口以下标 n−1 结尾，共 n − k + 1 个窗口。按从左到右的顺序，返回每个窗口里的最大值。[8]

样例 1：nums = [1, 3, -1, -3, 5, 3, 6, 7]，k = 3，返回 [3, 3, 5, 5, 6, 7]。六个窗口依次是 [1, 3, −1]、[3, −1, −3]、[−1, −3, 5]、[−3, 5, 3]、[5, 3, 6]、[3, 6, 7]，最大值分别是 3、3、5、5、6、7。

样例 2：nums = [4, 4, 4, 1]，k = 2，返回 [4, 4, 4]。三个窗口 [4, 4]、[4, 4]、[4, 1] 的最大值都是 4。

样例 3：nums = [1]，k = 1，返回 [1]。只有一个窗口。

要求时间 O(n)，结果共 n − k + 1 个。dq 保存下标，对应的值从队头到队尾严格递减。处理完下标 i 后，dq 中保存的是窗口 [i−k+1, i] 内仍有可能成为某个窗口最大值的下标。处理下标 i 时依次做四件事：

  1. 从队尾弹出所有值不大于 nums[i] 的下标。
  2. 把 i 压入队尾。
  3. 检查队头：若它的下标不大于 i − k，说明它已经滑出窗口，将其弹出。
  4. 当 i ≥ k − 1，即窗口中已有 k 个元素时，把 nums[dq.front()] 记为当前窗口的最大值。

例如样例 1 中 k = 3，处理 i = 4（值 5）之前，队列里是下标 1、2、3（值 3、−1、−3）。三个值都不大于 5，全部从队尾弹出，压入 4 后队列只剩下标 4，窗口 [2, 4] 的最大值是 5。

// 滑动窗口最大值（LeetCode 239）：参数 nums 是整数数组，k 是窗口长度（1 <= k <= n）。
// 返回每个长度为 k 的窗口的最大值，共 n-k+1 个，按窗口起点顺序。
vector<int> maxSlidingWindow(const vector<int>& nums, int k) {
    deque<int> dq;                  // 下标；对应值从队头到队尾严格递减，且都在窗口内
    vector<int> ans;                                                      // 每个窗口的最大值
    for (int i = 0; i < (int)nums.size(); ++i) {                          // i 是新进窗口的下标；窗口是 [i-k+1, i]
        while (!dq.empty() && nums[dq.back()] <= nums[i]) dq.pop_back();   // 队尾：踢掉不可能再当最大的
        dq.push_back(i);                                                  // i 入队尾
        if (dq.front() <= i - k) dq.pop_front();                          // 队头：踢掉滑出窗口的
        if (i >= k - 1) ans.push_back(nums[dq.front()]);                  // 窗口成形后，队头就是最大值
    }
    return ans;                                                           // 每个窗口的最大值，共 n-k+1 个
}

# 返回每个长度为 k 的窗口的最大值，共 n-k+1 个，按窗口起点顺序。
def max_sliding_window(nums, k):
    dq = deque()                      # 下标；对应值从队头到队尾严格递减，且都在窗口内
    ans = []                          # 每个窗口的最大值
    for i in range(len(nums)):        # i 是新进窗口的下标；窗口是 [i-k+1, i]
        while dq and nums[dq[-1]] <= nums[i]:  # 队尾不比 nums[i] 大
            dq.pop()                  # 队尾：踢掉不可能再当最大的
        dq.append(i)                  # i 入队尾
        if dq[0] <= i - k:            # 队头下标已不在窗口 [i-k+1, i] 内
            dq.popleft()              # 队头：踢掉滑出窗口的；list.pop(0) 是 O(n)，所以用 deque
        if i >= k - 1:                # 窗口已满 k 个
            ans.append(nums[dq[0]])   # 窗口成形后，队头就是最大值
    return ans                        # 每个窗口的最大值，共 n-k+1 个

练习 10.10-2【变形】波动不超过 limit 的最长时段 选做

题面：数组 a 是传感器按时间顺序记下的 n 个读数（n ≤ 10⁵）。取连着的一段读数，如果段里最大的读数减最小的读数不超过 limit（limit ≥ 0），就说这一段是"平稳的"。求最长的平稳段有几个读数；没有读数时返回 0。（相近题型：LeetCode 1438）

样例 1：a = [8, 2, 4, 7]，limit = 4，答案 2。[2, 4] 相差 2、[4, 7] 相差 3，都平稳；任何三个连着的读数都不平稳，例如 [2, 4, 7] 相差 5。

样例 2：a = [10, 1, 2, 4, 7, 2]，limit = 5，答案 4。[2, 4, 7, 2] 最大 7、最小 2，相差 5，平稳；再往左加上 1 就相差 6。

样例 3：a = [4, 2, 2, 2, 4, 4, 2, 2]，limit = 0，答案 3。limit 为 0 要求段里读数全相等，最长的是中间连着的三个 2。

提示

外层是 10.6 的可变窗口（求最长：扩右，不满足就缩左），内层要随时知道窗口的最大值和最小值，于是用两个单调队列：maxq 值递减（队头最大），minq 值递增（队头最小）。缩左时 left 前进一格，队头下标 < left 的就过期弹出。和 239 相比，窗口长度不固定，过期条件从 "<= i − k" 变成 "< left"。

参考答案
// 绝对差不超过限制的最长连续子数组（LeetCode 1438）：参数 a 是传感器读数，limit 是允许的波动（>= 0）。
// 返回段内最大值 - 最小值 <= limit 的最长连续时段的长度；a 为空返回 0。
int longestCalmPeriod(const vector<int>& a, int limit) {
    deque<int> maxq, minq;                   // maxq：值递减，队头是窗口最大；minq：值递增，队头是窗口最小
    int left = 0, best = 0;                  // left = 窗口左端；窗口是 [left, right]；best 是最长合法长度
    for (int right = 0; right < (int)a.size(); ++right) {  // right 是本轮新加入窗口的下标
        while (!maxq.empty() && a[maxq.back()] <= a[right]) maxq.pop_back();  // 维护 maxq：队尾不比新值大的踢掉
        maxq.push_back(right);               // right 入 maxq
        while (!minq.empty() && a[minq.back()] >= a[right]) minq.pop_back();  // 维护 minq：队尾不比新值小的踢掉
        minq.push_back(right);               // right 入 minq
        while ((long long)a[maxq.front()] - a[minq.front()] > limit) {   // 波动太大：缩左
            ++left;                          // 左端右移一格
            if (maxq.front() < left) maxq.pop_front();   // 队头下标已不在窗口内
            if (minq.front() < left) minq.pop_front();  // 同理检查 minq
        }
        best = max(best, right - left + 1);  // 窗口合法，更新答案
    }
    return best;                             // 波动不超过 limit 的最长时段
}

练习 10.10-3【综合】跳格子拿最高分 选做

题面：一排 n 个格子，编号 0 到 n−1，格子 i 上写着分数 a[i]（可以为负）。从格子 0 出发，每次向右跳 1 到 k 格（跳几格自己选），最后必须正好停在格子 n−1。得分是所有停过的格子（包括起点和终点）上的分数之和。求最高能得多少分。1 ≤ k, n ≤ 10⁵。（相近题型：LeetCode 1696）

样例 1：a = [1, -1, -2, 4, -7, 3]，k = 2，答案 7。依次停在格子 0、1、3、5，得分 1 − 1 + 4 + 3 = 7；每次最多跳 2 格，格子 1、2 至少要停一个，停 1 比停 2 少扣分，格子 4 的 −7 可以跳过。

样例 2：a = [10, -5, -2, 4, 0, 3]，k = 3，答案 17。从格子 0 直接跳 3 格到格子 3，再跳 2 格到格子 5，得分 10 + 4 + 3 = 17，两个负分格子都跳过了。

样例 3：a = [5]，k = 1，答案 5。起点就是终点，不用跳。

提示

先写出 DP：dp[i] = a[i] + max(dp[i−k..i−1])，暴力 O(nk)。"在长 k 的滑动窗口里取最大值"正是 239：单调队列存 dp 值递减的下标。算 dp[i] 前先弹出过期的（下标 < i−k），队头就是窗口最大；算完 dp[i] 再按 239 的规则从队尾入队。易错：分数可负，不能把"不跳"当成 0 分；必须先取队头再把 i 入队，否则 dp[i] 会由自己转移。

参考答案
// 跳跃游戏 VI（LeetCode 1696）：参数 a 是格子分数（可为负，n >= 1），k 是一次最多向右跳几格（>= 1）。
// 从格子 0 跳到格子 n-1，返回停过的格子分数之和的最大值。
long long maxJumpScore(const vector<int>& a, int k) {
    int n = a.size();                        // n = 格子数
    vector<long long> dp(n);                 // dp[i]：停在格子 i 时的最高得分
    deque<int> dq;                           // 下标，dp 值从队头到队尾严格递减，都在 [i-k, i-1] 内
    dp[0] = a[0];                            // 起点只能是格子 0，得分就是 a[0]
    dq.push_back(0);                         // 格子 0 入队，供后面转移
    for (int i = 1; i < n; ++i) {            // i = 当前要算的格子；依次算每个格子的 dp
        while (dq.front() < i - k) dq.pop_front();       // 过期：跳不到 i 了（i-1 总在队里，队列不会空）
        dp[i] = a[i] + dp[dq.front()];                   // 用窗口最大值转移
        while (!dq.empty() && dp[dq.back()] <= dp[i]) dq.pop_back();  // 队尾 dp 不比 dp[i] 大：以后再也当不了最大，踢掉
        dq.push_back(i);                     // 算完 dp[i] 才入队，不会由自己转移
    }
    return dp[n - 1];                        // 停在最后一格的最高得分
}

# 跳跃游戏 VI（LeetCode 1696）：参数 a 是格子分数（可为负，n >= 1），k 是一次最多向右跳几格（>= 1）。
# 从格子 0 跳到格子 n-1，返回停过的格子分数之和的最大值。
def max_jump_score(a, k):
    n = len(a)                        # n = 格子数
    dp = [0] * n                      # dp[i]：停在格子 i 时的最高得分
    dq = deque([0])                   # 下标，dp 值从队头到队尾严格递减，都在 [i-k, i-1] 内；格子 0 先入队
    dp[0] = a[0]                      # 起点只能是格子 0，得分就是 a[0]
    for i in range(1, n):             # i = 当前要算的格子；依次算每个格子的 dp
        while dq[0] < i - k:          # 过期：跳不到 i 了（i-1 总在队里，队列不会空）
            dq.popleft()
        dp[i] = a[i] + dp[dq[0]]      # 用窗口最大值转移
        while dq and dp[dq[-1]] <= dp[i]:  # 队尾 dp 不比 dp[i] 大：以后再也当不了最大
            dq.pop()                  # 踢掉
        dq.append(i)                  # 算完 dp[i] 才入队，不会由自己转移
    return dp[n - 1]                  # 停在最后一格的最高得分

易错点和变式。

  • 存下标而不是值：只存值就无法判断队头是否已滑出窗口。
  • 判断过期用 dq.front() <= i − k，比较的是下标；先处理队尾再处理队头，或者反过来，结果都对，但要保证记录答案前两步都做完。
  • 窗口最小值：把队尾弹出条件改为 nums[dq.back()] >= nums[i]，队列变成递增。

小结： 单调队列用 deque 保存下标，从队尾删去比新元素小的元素，从队头删去过期的元素，队头就是窗口的最大值。
