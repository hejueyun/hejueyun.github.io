12.12 贪心算法：每一步做当前最好的选择 选读

贪心算法的代码通常很短，时间多是 O(n) 或 O(n log n)。常见的贪心题有区间调度（选出最多的不重叠区间、用最少的箭）、跳跃和加油这类求能到多远的问题，以及排序后扫描一遍就能做出决定的问题。[1] 先用一个熟悉的例子说清贪心是什么、怎样写、为什么对，再看例题。

贪心是什么：只走一个分支的递归

先用递归的三句话写一遍（5.3）。 用面额 1、5、10、20、50、100 元的纸币凑出 37 元，最少要几张？

  • 含义：minNotes(a) 返回凑出 a 元最少要几张。
  • 最小情况：a = 0 时不用纸币，返回 0。
  • 相信函数：第一张拿哪种面额？不知道哪种对，就每种都试一遍。拿面额 c，剩下的 a − c 元交给 minNotes(a − c)，相信它返回的是最少张数；在所有能拿的 c 里，取 1 + minNotes(a − c) 最小的那个。

这样每一层都要试所有面额，同样的金额会被反复计算，这就是暴力递归。把算过的金额记下来，每个金额只算一次，就是动态规划，12.8 的零钱兑换就是这样做的。

贪心的做法。 人找零钱不会这样试。凑 37 元，人会直接拿一张 20，剩 17；再拿一张 10，剩 7；拿一张 5，剩 2；再拿两张 1。共 5 张。每一步只拿"不超过剩余金额的最大面额"，不试别的面额，拿了也不回头改。

对照递归的写法，贪心只改了第 3 句：不再"每种面额都试一遍取最好的"，而是"只试规则指定的那一种"，也就是 minNotes(a) = 1 + minNotes(a − 不超过 a 的最大面额)。每一层只剩一个分支，递归就成了一条直线，可以直接写成循环。

这就是贪心的定义：每一步按一条固定的规则只做一个选择，不试其他选择，做了也不再修改。

三种做法放在一起比较：

做法每一步试几种选择同样的子问题算几次用面额 1、3、4 凑 6
暴力递归全部反复算很多次得 2 枚（3+3），但很慢
动态规划全部只算一次，记下来得 2 枚（3+3）
贪心只试规则选的那一种只算一次得 3 枚（4+1+1），错了

最后一列就是贪心的风险：只走一个分支，就可能正好错过最好的答案。人民币的面额下，"先拿最大的"总是对的；面额换成 1、3、4，先拿 4 就错过了 3+3（本节后面"贪心失败的例子"会完整算一遍）。所以贪心比动态规划多一个必须回答的问题：规则选的那一个，为什么一定不会错？

写贪心之前，先写下三句话。 和递归的三句话对应：

  1. 每一步决定什么：把问题看成一连串的选择。找零是"下一张拿哪种面额"，选区间是"下一个留下哪个区间"。
  2. 规则：每一步按什么标准选。例如"拿不超过剩余金额的最大面额"，"留下结束最早的区间"。
  3. 为什么不会错：任取一个最好的方案。如果它第一步选的和规则不一样，就把它的第一步换成规则选的那一个，然后说明换完以后方案仍然合法，结果也没有变差。这就证明了：第一步照规则做，最好的结果仍然拿得到。这种证明方法叫 交换论证。

第 3 句只证明了第一步。第一步做完，剩下的是同一个问题的更小版本，对它用同样的理由，第一步照规则做也不会错，一直到什么都不剩。这和递归里"最小情况正确，每一层又正确，所以整体正确"是同一个道理。教材里把这两点分别叫作 贪心选择性质（第一步照规则选不会错，就是第 3 句）和 最优子结构（第一步做完，剩下的部分还是同一类问题，它的最优解接上第一步，就是整个问题的最优解）。下面每道例题都按这三句话写。

例：分饼干。 每个孩子有一个胃口值，饼干的尺寸不小于胃口，他才满意；一块饼干只能给一个孩子。孩子的胃口是 [1, 2]，饼干的尺寸是 [1, 2, 3]，最多能让几个孩子满意？

  1. 每一步决定什么：把孩子按胃口从小到大排好，依次决定给当前这个孩子哪块饼干。
  2. 规则：给他"够大的饼干里最小的那块"。胃口 1 的孩子拿尺寸 1，胃口 2 的孩子拿尺寸 2，两个都满意。
  3. 为什么不会错：假设某个最好的方案给胃口 1 的孩子的是尺寸 3。把他手里的 3 和规则选的 1 对调：他拿 1 仍然够；原来拿 1 的人（如果有）改拿 3，只会更够。满意的人数不变。如果那个方案根本没满足胃口 1 的孩子，就把尺寸 1 的饼干从原来的主人那里拿来给他，满意的人数也不会减少。

三句话写完，代码就是两边各排一次序，再用两个指针从小到大往前走，完整的题目和代码见本节的练习 12.12-1。

规则从哪里来。 规则一般不是一下子就能想到的。先列出几条看起来都合理的规则，用两三个元素的小例子去试，找到反例的就扔掉，剩下的再用第 3 句证明。本节最后的"怎样判断能不能贪心"一小节给出了具体做法和更多例子；下面的 435 题会完整地做一次交换论证。

55 跳跃游戏

一排格子，非负整数数组 nums 中 nums[i] 是站在格子 i 时一次最多能向右跳的格数（可以跳得更少，也可以是 0 表示跳不动）。从格子 0 出发，判断能否到达最后一个格子。能就返回 true。

样例 1：nums = [2, 3, 1, 1, 4]，返回 true。从格子 0 跳 1 格到格子 1，再从格子 1 跳 3 格到最后的格子 4。

样例 2：nums = [3, 2, 1, 0, 4]，返回 false。从格子 0、1、2 无论怎么跳，最远都只能到格子 3，而格子 3 的值是 0，跳不动，到不了格子 4。

样例 3：nums = [0]，返回 true。起点就是最后一个格子。

三句话。

  1. 每一步决定什么：从左到右走到每一格，更新"目前最远能到哪里"。
  2. 规则：只记一个数 farthest，即目前能到达的最远下标。走到格子 i 时，如果 i ≤ farthest，i 能到，就用 i + nums[i] 把 farthest 往远推；如果 i > farthest，i 到不了，后面的格子也都到不了，返回 false。扫描完都没有到不了的格子，返回 true。
  3. 为什么不会错：每次可以跳得比最大步数少，从格子 i 能落到 i+1 到 i+nums[i] 中的每一格，所以能到达的格子总是从 0 开始连成一片，"[0, farthest] 都能到"这句话在扫描中一直成立。只记最远的下标，不会漏掉任何一种跳法。

canJump：farthest = 目前能到的最远下标

1 / 4

第1步 · [2,3,1,1,4]，i=0：farthest=0+2=2

2 / 4

第2步 · i=1：farthest=max(2, 1+3)=4，已经覆盖最后一个下标

返回 true
3 / 4

第3步 · [3,2,1,0,4]：i=0..3 时 farthest 一直是 3

4 / 4

第4步 · i=4 > farthest=3：走不到，返回 false

下标 3 的 0 是一堵墙
// 55 跳跃游戏：nums[i] 是在下标 i 处最多能跳几格（非负）。从下标 0 出发，返回能否到达最后一个下标。
bool canJump(const vector<int>& nums) {
    int farthest = 0;                                  // 目前能到达的最远下标
    for (int i = 0; i < (int)nums.size(); ++i) {       // i = 当前位置，从左往右走每个位置
        if (i > farthest) return false;                // 走不到 i
        farthest = max(farthest, i + nums[i]);         // 从 i 起跳能把边界推到 i + nums[i]
    }
    return true;                                       // 每个位置都能到，包括最后一个
}
# 55 跳跃游戏：nums[i] 是在下标 i 处最多能跳几格（非负）。从下标 0 出发，返回能否到达最后一个下标。
def can_jump(nums):
    farthest = 0                                              # 目前能到达的最远下标
    for i in range(len(nums)):                                # i = 当前位置，从左往右走每个位置
        if i > farthest: return False                         # 走不到 i
        farthest = max(farthest, i + nums[i])                 # 从 i 起跳能把边界推到 i + nums[i]
    return True                                               # 每个位置都能到，包括最后一个

这一做法正确，是因为能到达 i 就能到达 i 之前的所有位置：从 0 一路跳到 i 的过程中，每一跳的步数都可以少于最大值。所以可达的位置总是一个前缀 [0, farthest]，只需记录它的右端点。时间 O(n)，空间 O(1)。

45 跳跃游戏 II

输入与 55 题相同，并且保证能到达最后一个格子。求最少跳几次能到达。

样例 1：nums = [2, 3, 1, 1, 4]，答案 2。从格子 0 跳到格子 1，再跳 3 格到格子 4；一次跳不到，因为格子 0 最多跳 2 格。

样例 2：nums = [1, 1, 1, 1]，答案 3。每次只能跳 1 格，要跳 3 次。

样例 3：nums = [0]，答案 0。起点就是终点。

三句话。

  1. 每一步决定什么：每跳一次，下一次能落到哪些格子。
  2. 规则：按跳的次数把格子分组。跳 0 次只在格子 0；从跳 k 次能到的那一组里任意一格起跳，能落到的格子就是跳 k+1 次的那一组。以样例 1 [2, 3, 1, 1, 4] 为例：跳 0 次在格子 0；从格子 0 最多跳 2 格，跳 1 次能落在格子 1、2；从格子 1 能跳到 4，所以跳 2 次就到终点。下一组的右端点，取当前这一组里"跳得最远"的那一格能到的位置。
  3. 为什么不会错：和 55 题同理，每一组都是从 0 开始连成一片的一段，所以只要记住右端点。用当前组里跳得最远的位置作为下一组的右端点，得到的正好是跳 k+1 次能到的全部格子，一格也不漏。终点第一次落进某一组时，那一组对应的次数就是最少次数。

代码中的三个变量：

  • steps：已经跳的次数。
  • end：跳 steps 次能到达的最远下标，即当前这一组的右端点。[0, end] 中的位置都能在 steps 次之内到达。
  • farthest：跳 steps+1 次能到达的最远下标，即下一组的右端点。

三者开始时都是 0。从 i = 0 开始逐格扫描，对每个 i：

  1. 用 i + nums[i] 更新 farthest；
  2. 如果 i == end，当前这一组已经扫描完，要走得更远必须再跳一次：steps 加 1，end = farthest。

循环只到下标 n−2（n 是格子数），因为站在终点时不需要再跳。最后返回 steps。

// 45 跳跃游戏 II：nums[i] 是在下标 i 处最多能跳几格，保证能到终点。返回到达最后一个下标的最少跳跃次数。
int jump(const vector<int>& nums) {
    // steps = 已跳次数；farthest = 再多跳一步最远能到的下标
    int steps = 0, end = 0, farthest = 0;              // end：当前步数能到的边界
    for (int i = 0; i + 1 < (int)nums.size(); ++i) {   // 站在终点不用再跳，所以不看最后一个
        farthest = max(farthest, i + nums[i]);         // 多跳一步最远能到哪
        if (i == end) { ++steps; end = farthest; }     // 走到边界，必须再跳一次
    }
    return steps;                                      // 最少跳跃次数
}
# 45 跳跃游戏 II：nums[i] 是在下标 i 处最多能跳几格，保证能到终点。返回到达最后一个下标的最少跳跃次数。
def jump(nums):
    # steps = 已跳次数；farthest = 再多跳一步最远能到的下标
    steps = end = farthest = 0                                # end：当前步数能到的边界
    for i in range(len(nums) - 1):                            # 即 i + 1 < n：站在终点不用再跳
        farthest = max(farthest, i + nums[i])                 # 多跳一步最远能到哪
        if i == end: steps += 1; end = farthest               # 走到边界，必须再跳一次
    return steps                                              # 最少跳跃次数

这一做法其实就是 BFS 按层扩展：第 k 层是恰好 k 跳能到达的位置，每一层都是一个连续的区间。贪心写法不需要队列，只需记录区间的右端点。时间 O(n)，空间 O(1)。

435 无重叠区间

给一组区间，每个写成 [l, r]。求最少删除几个区间，才能使剩下的区间两两不重叠；两个区间只在端点处相接（如 [1, 2] 和 [2, 3]）不算重叠。

样例 1：intervals = [[1, 2], [2, 3], [3, 4], [1, 3]]，答案 1。删掉 [1, 3]，剩下的三个首尾相接，不重叠；不删的话 [1, 3] 和 [1, 2] 重叠。

样例 2：intervals = [[1, 2], [1, 2], [1, 2]]，答案 2。三个区间完全相同，只能留一个。

样例 3：intervals = [[1, 2], [2, 3]]，答案 0。两个区间只在 2 相接，不算重叠。

删得最少，就是留得最多。下面按"留下尽量多的互不重叠区间"来想。

三句话。

  1. 每一步决定什么：下一个留下哪个区间。
  2. 规则：在和已留下的区间不重叠的区间里，留下结束最早的那个。实现时把区间按右端点升序排列，从左往右扫，用 end 记录已留下的最后一个区间的右端点，kept 记录留下的个数：当前区间的左端点 ≥ end，就留下它并更新 end；否则删掉它。最后返回区间总数减去 kept。
  3. 为什么不会错（交换论证）：设某个最好的方案留下的第一个区间是 X，规则留下的是结束最早的 G，于是 G 的右端点 ≤ X 的右端点。把方案中的 X 换成 G：G 结束得不比 X 晚，和方案里后面的区间仍然不重叠，留下的个数不变。所以存在一个以 G 开头的最好方案。G 定下以后，剩下的是"在 G 结束之后的区间里留下尽量多个"，还是同一个问题，同样的理由一直用下去，规则得到的就是最优解。直观地说，结束得越早，留给后面区间的空间就越多。改成"开始最早的先留"或"最短的先留"都有反例，见本节最后的表。

end = −∞
2 / 5

第2步 · [1,2] 结束最早，选它；end=2

3 / 5

第3步 · [2,3] 的左端 2 ≥ end，选；end=3

4 / 5

第4步 · [1,3] 的左端 1 < end=3，重叠，删掉

5 / 5

第5步 · [3,4] 左端 3 ≥ end，选；end=4

保留 3 个，删掉 4−3=1 个
// 435 无重叠区间：intervals 的每个元素是 [左端, 右端]（会被原地排序）。返回最少删掉几个区间，剩下的互不重叠。
int eraseOverlapIntervals(vector<vector<int>>& intervals) {
    sort(intervals.begin(), intervals.end(),
         [](const vector<int>& a, const vector<int>& b) { return a[1] < b[1]; });   // 按右端点
    // INT_MIN 是 int 的最小值（<climits>）：保证第一个区间一定留下
    int kept = 0, end = INT_MIN;                       // kept：留下的区间数；end：最后留下那个的右端点
    for (const auto& it : intervals)                   // it = 当前区间；贪心：结束越早，给后面留的空间越多
        if (it[0] >= end) { ++kept; end = it[1]; }     // 与已选的不重叠就留下
    return (int)intervals.size() - kept;               // 其余的都要删掉
}
# 435 无重叠区间：intervals 的每个元素是 [左端, 右端]（会被原地排序）。返回最少删掉几个区间，剩下的互不重叠。
def erase_overlap_intervals(intervals):
    intervals.sort(key=lambda it: it[1])                      # 按右端点；用 key 函数代替 C++ 的比较 lambda
    kept, end = 0, float('-inf')                              # kept：留下的区间数；end：最后留下那个的右端点
    for it in intervals:                                      # it = 当前区间；贪心：结束越早，给后面留的空间越多
        if it[0] >= end: kept += 1; end = it[1]               # 与已选的不重叠就留下
    return len(intervals) - kept                              # 其余的都要删掉

排序需要 O(n log n)，扫描需要 O(n)。

763 划分字母区间

给一个只含小写字母的字符串 s，把它从左到右切成若干段，要求同一个字母只能出现在其中一段里（不能分散在两段）。在满足要求的前提下切出尽可能多的段，按从左到右的顺序返回每段的长度。

样例 1：s = "ababcbacadefegdehijhklij"，返回 [9, 7, 8]。切成 "ababcbaca"、"defegde"、"hijhklij"；a 最后出现在下标 8，所以第一段至少到下标 8，而 b、c 也都在这段之内，可以在这里切。

样例 2：s = "abc"，返回 [1, 1, 1]。每个字母只出现一次，每个字母单独一段。

样例 3：s = "eccbbbbdec"，返回 [10]。e 出现在开头和下标 8，c 出现在下标 1 和末尾，整串只能作为一段。

三句话。

  1. 每一步决定什么：从左往右扫，决定当前这一段在哪里结束。
  2. 规则：一段只要包含了某个字母，就必须延伸到这个字母最后一次出现的位置；满足这个要求的最早位置一到，就立刻切。实现时先求出 last[c]，即字母 c 最后一次出现的下标。用 start 表示当前段的起点，end 表示当前段至少要延伸到的位置；扫描到 i 时，用 last[s[i]] 更新 end；如果 i == end，说明 [start, end] 中的字母后面都不会再出现，在这里切一刀，记录长度，并令 start = i+1。
  3. 为什么不会错：在 end 之前切，必然有字母被分进两段，不合法。假设某个方案的第一段比 end 更长，把它在 end 处切开：前半段的字母最后一次出现都不超过 end，后半段里不会有它们；后半段的字母也不在前半段出现，所以两半都合法，段数还多了 1。因此段数最多的方案，第一刀一定在 end。切完后剩下的字符串是同一个问题，接着用同样的规则。

partitionLabels：先记每个字母最后出现的位置，再扫描

1 / 4

第1步 · i=0 'a'：a 最后在 8，end=8；之后 b(5)、c(7) 都没超过 8

2 / 4

第2步 · i=8 到达 end：切出第 1 段，长度 9；start=9

3 / 4

第3步 · i=9 'd'：d 最后在 14；i=10 'e'：e 最后在 15 → end=15；i=15 时切出第 2 段，长度 7

4 / 4

第4步 · 剩下 "hijhklij" 中 j 最后在 23，切出第 3 段，长度 8

答案 [9,7,8]

扫描时 end = 已见字母最后出现位置的最大值；i 走到 end 时，这一段的字母都不会再出现，切一刀

// 763 划分字母区间：s 由小写字母组成。把它切成尽量多的片段，使每个字母只出现在一个片段里，返回各片段长度。
vector<int> partitionLabels(const string& s) {
    vector<int> last(26, 0);                           // last[c]：字母 c 最后一次出现的下标（c = 0 表示 'a'）
    for (int i = 0; i < (int)s.size(); ++i) last[s[i] - 'a'] = i;   // 后出现的覆盖前面的
    vector<int> ans;                                   // 各片段的长度，从左到右
    int start = 0, end = 0;                            // 当前片段的起点、目前必须到达的终点
    for (int i = 0; i < (int)s.size(); ++i) {          // i = 当前扫描到的下标
        end = max(end, last[s[i] - 'a']);              // 当前片段至少要延伸到这里
        if (i == end) { ans.push_back(end - start + 1); start = i + 1; }   // 片段里的字母都不再出现：切一刀
    }
    return ans;                                        // 各片段的长度
}

def partition_labels(s):

    ans = []                                                  # 各片段的长度，从左到右
    start = end = 0                                           # 当前片段的起点、目前必须到达的终点
    for i in range(len(s)):                                   # i = 当前扫描到的下标
        end = max(end, last[ord(s[i]) - ord('a')])            # 当前片段至少要延伸到这里

每一刀都切在最早可以切的位置，切得越早，后面能切出的片段就越多。时间 O(n)，空间 O(1)（只需 26 个字母的数组）。

134 加油站

环形公路上有 n 个加油站，编号 0 到 n−1，第 n−1 站之后又回到第 0 站。在第 i 站能加 gas[i] 升油，从第 i 站开到下一站要耗 cost[i] 升油。汽车油箱容量不限，出发时是空的。选一个加油站出发，按编号增大的方向开，要求一路上油都够用，最后回到出发站。返回能做到的出发站编号，做不到时返回 −1；题目保证答案唯一。

样例 1：gas = [1, 2, 3, 4, 5]，cost = [3, 4, 5, 1, 2]，答案 3。从第 3 站出发：加 4 耗 1 剩 3；到第 4 站加 5 耗 2 剩 6；到第 0 站加 1 耗 3 剩 4；到第 1 站加 2 耗 4 剩 2；到第 2 站加 3 耗 5 剩 0，正好回到第 3 站。

样例 2：gas = [2, 3, 4]，cost = [3, 4, 3]，答案 -1。一圈总共只能加 9 升油，却要耗 10 升，从哪一站出发都不够。

在第 i 站加油再开到下一站，油量净变化 gas[i] − cost[i]。样例 1 中这五个数是 −2、−2、−2、3、3。

三句话。

  1. 每一步决定什么：从第 0 站往后扫，决定出发站是否还用当前这个候选。
  2. 规则：从候选出发站 start 一路开过来，油箱一旦变成负数（开不到 i+1），就放弃 start，把 i+1 作为新的候选，油箱清零。扫完一遍，绕一圈的总净变化小于 0 时返回 −1，否则返回 start。
  3. 为什么不会错：有两点。第一，从 start 到 i 之间的任何一站出发也到不了 i+1：从 start 出发途经这些站时油量都不是负数，改从其中某一站出发，到那里时油量是 0，不比原来多，所以同样到不了 i+1，这些站可以一起跳过。第二，总净变化不小于 0 时，一定有一站能绕完一圈（从"从第 0 站累计的油量"最低的那一站的下一站出发即可）；被跳过的站都不行，而后面任何一站 k 如果能绕一圈，从 start 出发也能：先以不为负的油量开到 k，再沿 k 的路线走，油只多不少。题目保证答案唯一，所以答案就是 start。

代码中的三个变量：

  • total：所有站的 gas[i] − cost[i] 之和，即绕一整圈油量的净变化。
  • start：当前候选的出发站，初值 0。
  • tank：从 start 出发、开到当前位置时油箱里的油量，初值 0。

从 i = 0 扫描到 n−1，对每个 i：

  1. total 和 tank 都加上 gas[i] − cost[i]；
  2. 如果 tank < 0，说明从 start 出发到不了 i+1，就把 start 设为 i+1，tank 清零。

扫描结束后，若 total < 0，说明总油量不够，返回 −1；否则返回 start。样例 1 中，从第 0、1、2 站出发都是一开始就变成 −2，start 依次挪到 1、2、3；从第 3 站出发，tank 是 3、6，一直非负，total = 0，答案是 3。

canCompleteCircuit：diff[i] = gas[i] − cost[i] = [−2,−2,−2,3,3]

1 / 3

第1步 · 从 0 出发：tank=−2 < 0，0 当不了起点，start=1，tank 清零

total=−2
2 / 3

第2步 · 从 1、2 出发同样立刻为负，start 依次挪到 2、3

total=−6
3 / 3

第3步 · 从 3 出发：tank=3，再加 3 得 6，一直非负

// 134 加油站：gas[i] 是第 i 站能加的油，cost[i] 是从第 i 站开到下一站的耗油，站点围成一圈。
// 返回能绕一圈的出发站下标；做不到返回 -1。
int canCompleteCircuit(const vector<int>& gas, const vector<int>& cost) {
    int total = 0, tank = 0, start = 0;                // total：全程净油量；tank：从 start 出发的当前油量；start：候选起点
    for (int i = 0; i < (int)gas.size(); ++i) {        // i = 当前加油站
        total += gas[i] - cost[i];                     // 累计全程净油量
        tank += gas[i] - cost[i];                      // 加油再开到下一站后的剩余
        if (tank < 0) { start = i + 1; tank = 0; }     // 从 start 到 i 都不能当起点
    }
    return total < 0 ? -1 : start;                     // 总油量不够一定不行；够的话 start 就是答案
}
# 134 加油站：gas[i] 是第 i 站能加的油，cost[i] 是从第 i 站开到下一站的耗油，站点围成一圈。
# 返回能绕一圈的出发站下标；做不到返回 -1。
def can_complete_circuit(gas, cost):
    total = tank = start = 0                                  # total：全程净油量；tank：从 start 出发的当前油量
    for i in range(len(gas)):                                 # i = 当前加油站
        total += gas[i] - cost[i]                             # 累计全程净油量
        tank += gas[i] - cost[i]                              # 加油再开到下一站后的剩余
        if tank < 0: start = i + 1; tank = 0                  # 从 start 到 i 都不能当起点
    return -1 if total < 0 else start                         # 总油量不够一定不行；够的话 start 就是答案

时间 O(n)，空间 O(1)。

贪心失败的例子：用面额 1、3、4 的硬币凑出 6

找零时每次拿面额最大的硬币，对人民币的面额（1、2、5、10 等）是正确的，但换一套面额就可能出错。18.24 已经给出过这个例子，这里把贪心和动态规划的结果放在一起比较：

面额 {1,3,4} 凑 6：贪心先拿最大的 4，剩 2 只能用两个 1，共 3 枚（左）；DP 找到 3+3，共 2 枚（右）

// 贪心凑硬币（反例用）：coins 是面额（按值传入），amount 是金额。每次拿能拿的最大面额，
// 返回用的枚数；凑不满返回 -1。结果不一定是最少枚数。
int greedyCoinCount(vector<int> coins, int amount) {
    sort(coins.rbegin(), coins.rend());                // 面额从大到小
    int cnt = 0;                                       // 用了几枚
    for (int c : coins)                                // c = 当前面额，从大到小
        while (amount >= c) { amount -= c; ++cnt; }    // 贪心：当前最大面额能拿就一直拿
    return amount == 0 ? cnt : -1;                     // 没凑满就算失败（这个贪心不一定最优）
}
// greedyCoinCount({1,3,4}, 6) == 3，而 coinChange({1,3,4}, 6) == 2
# 贪心凑硬币（反例用）：coins 是面额（不修改调用者的列表），amount 是金额。每次拿能拿的最大面额，
# 返回用的枚数；凑不满返回 -1。结果不一定是最少枚数。
def greedy_coin_count(coins, amount):
    # 面额从大到小；C++ 按值传参拿到副本，这里 sorted 返回新列表，不改调用者的
    coins = sorted(coins, reverse=True)
    cnt = 0                                                   # 用了几枚
    for c in coins:                                           # c = 当前面额，从大到小
        while amount >= c: amount -= c; cnt += 1              # 贪心：当前最大面额能拿就一直拿
    return cnt if amount == 0 else -1                         # 没凑满就算失败（这个贪心不一定最优）
# greedy_coin_count([1, 3, 4], 6) == 3，而 coin_change([1, 3, 4], 6) == 2

用 12.8 的 coinChange 计算，dp = [0,1,2,1,1,2,2]，dp[6] = min(dp[5]+1, dp[3]+1, dp[2]+1) = min(3,2,3) = 2，即 3+3。贪心先拿 4，剩下的 2 只能用 1+1，共 3 枚；而 3+3 这个组合在先拿最大面额的规则下永远不会被考虑。用交换论证检查：把最优解 {3,3} 中的一个 3 换成 4，剩下的 2 需要两枚硬币，个数变多，交换论证不成立。交换论证不成立时，就要改用动态规划。

怎样判断能不能贪心，以及怎样找到贪心的依据

贪心与动态规划的根本区别在于：贪心每一步只保留一个选择，选了就不再改变；动态规划保留每个子问题的最优值，到最后才比较。所以判断能不能贪心，先问一个问题：现在选择看起来最好的那一个，会不会让以后的选择变少或变差？ 如果会，而且无法证明这种损失总能弥补，就应当用动态规划；只有能说明“任何一个最优解都可以改成以贪心的选择开头而不变差”时，贪心才是正确的。下面几条经验可以帮助做出判断。

第一，列出几种候选的贪心规则，用很小的反例逐个筛选。 以 435 题为例，要从一组区间中选出尽量多个互不重叠的区间，可能想到三种规则：

规则反例结果
优先选开始最早的[1,10]、[2,3]、[4,5]选了 [1,10] 后只能选 1 个，最优是 2 个
优先选长度最短的[1,5]、[4,7]、[6,10]最短的 [4,7] 与另外两个都重叠，只能选 1 个，最优是 2 个
优先选结束最早的找不到反例再用交换论证证明它正确（见上文 435 题）

反例一般只需要两三个元素，并且取比较极端的值：一个很长的区间、一个夹在中间的短区间、一个很大的面额。找到一个反例，就可以放弃这条规则；硬币问题中“先拿面额最大的”就是被 {1, 3, 4} 凑 6 这个反例否定的。

第二，排序类的贪心，用相邻交换推出排序的依据。 很多贪心题的做法是“按某个规则排序后依次处理”，难点在于按什么排序。办法是只看相邻的两个元素 a、b：分别计算 a 在前和 b 在前时目标函数的值，比较两者，就得到 a 应当排在 b 前面的条件。如果排列中存在不满足这个条件的相邻两项，交换它们会使结果更好（至少不变差），所以最优的排列一定满足这个条件。

例：加权完成时间之和最小。 一台机器依次处理 n 个任务，任务 i 需要时长 tᵢ，重要程度为权重 wᵢ；任务的完成时间 Cᵢ 是它结束的时刻。要求安排顺序，使 Σwᵢ·Cᵢ 最小。只看相邻的两个任务 a、b，设它们开始前已经过去了时间 T：a 在前时，两者的贡献是 w_a(T+t_a) + w_b(T+t_a+t_b)；b 在前时是 w_b(T+t_b) + w_a(T+t_b+t_a)。两式相减，T 的部分完全抵消，a 在前更好当且仅当 w_b·t_a < w_a·t_b，即 t_a/w_a < t_b/w_b。所以按 tᵢ/wᵢ 从小到大排序就是最优顺序。所有权重都相同时，它退化为“时长短的先做”，这也是 SJF 调度使平均等待时间最短的原因（「计算机系统导论」5.7）。[2]

// 单机带权完成时间最小化：jobs 的每个元素是 (时长 t, 权重 w)，按值传入（排序不影响调用者）。
// 按最优顺序依次做完，返回 Σ w_i · C_i 的最小值，C_i 是任务 i 的完成时刻。
long long minWeightedCompletion(vector<pair<int, int>> jobs) {   // 每个任务是 (时长 t, 权重 w)
    // 相邻交换推出的排序依据；交叉相乘避免除法，转 long long 防溢出
    // a、b 是两个任务，.first = 时长，.second = 权重；返回 true 表示 a 排在 b 前面
    sort(jobs.begin(), jobs.end(), [](const pair<int, int>& a, const pair<int, int>& b) {
        return (long long)a.first * b.second < (long long)b.first * a.second;  // t_a/w_a < t_b/w_b
    });
    long long now = 0, total = 0;     // now：当前时刻；total：Σ w·C
    for (auto [t, w] : jobs) {        // 按排好的顺序依次处理；t = 时长，w = 权重
        now += t;                     // 这个任务的完成时间
        total += (long long)w * now;  // 累加 w_i · C_i
    }
    return total;                     // 最小的带权完成时间之和
}
// minWeightedCompletion({{3, 1}, {1, 2}, {2, 2}}) == 14
from functools import cmp_to_key

# 单机带权完成时间最小化：jobs 的每个元素是 (时长 t, 权重 w)（不修改调用者的列表）。
# 按最优顺序依次做完，返回 Σ w_i · C_i 的最小值，C_i 是任务 i 的完成时刻。
def min_weighted_completion(jobs):     # 每个任务是 (时长 t, 权重 w)
    # t_a/w_a < t_b/w_b 时 a 排在前面；交叉相乘避免除法。比较函数返回负数表示 a 排在 b 前面
    order = sorted(jobs, key=cmp_to_key(lambda a, b: a[0] * b[1] - b[0] * a[1]))
    now = total = 0                    # now：当前时刻；total：Σ w·C
    for t, w in order:                 # 按排好的顺序依次处理；t = 时长，w = 权重
        now += t                       # 这个任务的完成时间
        total += w * now               # 累加 w_i · C_i
    return total                       # 最小的带权完成时间之和

比较器用交叉相乘 t_a·w_b < t_b·w_a，而不是直接比较两个除法的结果，既避免了浮点误差，也不会在权重为 0 时除以 0。以 (3,1)、(1,2)、(2,2) 为例，比值分别是 3、0.5、1，顺序为 (1,2)、(2,2)、(3,1)，完成时间依次是 1、3、6，总和为 2×1 + 2×3 + 1×6 = 14；把 6 种顺序全部枚举一遍，14 确实最小。

第三，用暴力解检验贪心。 贪心的正确性很难仅凭感觉判断。写一个枚举所有排列或所有子集的暴力解，用随机的小数据与贪心的结果比较几百轮（对拍，见 8.6）：只要有一次不同，贪心就是错的，而且得到了一个反例；全部相同，再去写正式的证明。

第四，熟悉几种常见的贪心形式。 区间调度按右端点排序，每次选结束最早的（435、452）；“能走多远”类问题维护当前能到达的最远位置（55、45）；两组对象配对时，排序后用双指针，让最小的需求配最小的够用的资源（455 分饼干）；每次都要取当前最好的元素时用堆，例如哈夫曼编码、Dijkstra、前 K 大（11.16）；排序的依据不明显时，用相邻交换推导比较器。遇到的题不属于这几种形式，并且选择会影响以后的可选范围时，就应当优先考虑动态规划。

小结： 贪心算法在每一步做出当前看来最好的选择，并且不回头修改；它的正确性需要证明问题具有贪心选择性质和最优子结构，常用的方法是交换论证。区间调度类问题按右端点排序，每次选结束最早的区间。动态规划保留所有子问题的最优值再进行比较，而贪心每一步只保留一个选择；能用贪心解决的题，一般也能用动态规划解决，只是更慢。

练习 12.12-1【基础】饼干分给孩子 选做

题面：有一些孩子和一些饼干。数组 g 是孩子的胃口，g[i] 是第 i 个孩子的胃口；数组 s 是饼干的大小。当饼干大小不小于孩子的胃口时，这块饼干能让这个孩子满足。每个孩子最多分一块饼干，每块饼干最多给一个孩子。求最多能让几个孩子满足。0 ≤ |g|, |s| ≤ 3×10^4。

样例 1：g = [1, 2, 3]，s = [1, 1]，答案 1。两块饼干都是 1，只能满足胃口为 1 的那个孩子。

样例 2：g = [1, 2]，s = [1, 2, 3]，答案 2。饼干 1 给胃口 1 的孩子，饼干 2 给胃口 2 的孩子，两人都满足。

样例 3：g = []，s = [5]，答案 0。没有孩子。

提示

贪心：两边都排序，用"能满足他的最小那块饼干"去满足胃口最小的孩子。双指针：饼干从小到大扫，当前饼干能满足当前孩子就配对、孩子指针后移；否则这块饼干连胃口最小的孩子都满足不了，直接跳过。交换论证：若某个最优方案给最小胃口孩子的不是最小可用饼干，把两块饼干对调，没有人会因此不满足。相近题型：LeetCode 455。

参考答案
// g[i]：第 i 个孩子的胃口；s[j]：第 j 块饼干的大小（都按值传入，排序不影响调用者）。
// s[j] >= g[i] 时能满足，每人最多一块，返回最多满足几个孩子。
int feedKids_12_1(vector<int> g, vector<int> s) {
    sort(g.begin(), g.end()); sort(s.begin(), s.end());   // 胃口、饼干都从小到大
    int kid = 0;                                       // 下一个等饼干的孩子（胃口从小到大），也是已满足的人数
    // j = 当前试的饼干，从小到大试；孩子都满足了就停
    for (int j = 0; j < (int)s.size() && kid < (int)g.size(); ++j)
        if (s[j] >= g[kid]) ++kid;                     // 够大就给他；不够大这块谁也满足不了
    return kid;                                        // 满足了前 kid 个孩子
}

def feed_kids_12_1(g, s):
    g, s = sorted(g), sorted(s)                               # 胃口、饼干都从小到大

    for j in range(len(s)):                                   # j = 当前试的饼干，从小到大试

练习 12.12-2【变形】按评分发糖果 选做

题面：n 个孩子站成一排，数组 r 是每个孩子的评分。给孩子们发糖，要求：每人至少 1 颗；如果一个孩子的评分比他旁边（左边或右边）的孩子高，他的糖就必须比那个孩子多。评分相同的相邻孩子之间没有要求。求最少一共要发几颗糖。1 ≤ n ≤ 2×10^4。

样例 1：r = [1, 0, 2]，答案 5。中间的孩子评分最低，给 1 颗；两边的都比他高，各给 2 颗；共 2 + 1 + 2 = 5。

样例 2：r = [1, 2, 2]，答案 4。分别给 1、2、1 颗：第二个比第一个高，要多；第三个和第二个评分相同，没有要求，给 1 颗就行。

样例 3：r = [1, 3, 4, 5, 2]，答案 11。分别给 1、2、3、4、1 颗：前四个评分一路上升，糖也要一路增加；最后一个比左边低，给 1 颗。

提示

一次扫描顾不了两边的邻居，就拆成两次贪心：第一遍从左往右，只满足"比左邻高就比左邻多一颗"；第二遍从右往左，满足"比右邻高就比右邻多一颗"，这时要和第一遍的结果取较大值，第一遍的约束才不会被破坏。评分相等的两人之间没有约束。和本节其他题相比：贪心不一定是"排序后扫一遍"，也可以是"两个方向各扫一遍再合并"。相近题型：LeetCode 135。

参考答案
// r[i]：第 i 个孩子的评分（非空）。每人至少 1 颗，评分比相邻的高就要比那个邻居多，返回最少总糖数。
int snackCount_12_2(const vector<int>& r) {
    int n = r.size();                                  // n = 孩子数
    vector<int> c(n, 1);                               // c[i] = 第 i 个孩子分到的糖数；每人先发 1 颗
    for (int i = 1; i < n; ++i)                        // 从左往右：满足"比左邻高就比左邻多"
        if (r[i] > r[i - 1]) c[i] = c[i - 1] + 1;      // 只管左邻
    for (int i = n - 2; i >= 0; --i)                   // 从右往左：满足"比右邻高就比右邻多"
        if (r[i] > r[i + 1]) c[i] = max(c[i], c[i + 1] + 1);   // 再管右邻，保留左邻的约束
    int sum = 0;                                       // sum = 总糖数
    for (int x : c) sum += x;                          // 总糖数
    return sum;
}

        if r[i] > r[i + 1]: c[i] = max(c[i], c[i + 1] + 1)    # 再管右邻，保留左邻的约束
    return sum(c)                                             # 总糖数

练习 12.12-3【变形】K 次取反后的最大和 选做

题面：给整数数组 a，恰好做 k 次操作，每次选一个元素，把它变成相反数（正变负、负变正，0 不变）；同一个位置可以被选多次。k 次操作做完后，求数组所有元素之和最大是多少。1 ≤ n ≤ 10^4，−100 ≤ a[i] ≤ 100，1 ≤ k ≤ 10^4。

样例 1：a = [4, 2, 3]，k = 1，答案 5。必须翻一次，翻最小的 2 损失最少：4 − 2 + 3 = 5。

样例 2：a = [3, -1, 0, 2]，k = 3，答案 6。翻一次 −1 变成 1，剩下两次都翻 0，0 不变，和为 3 + 1 + 0 + 2 = 6。

样例 3：a = [2, -3, -1, 5, -4]，k = 2，答案 13。翻最负的 −3 和 −4，和为 2 + 3 − 1 + 5 + 4 = 13。

样例 4：a = [-5]，k = 2，答案 -5。只有一个数，翻两次又变回 −5。

提示

贪心分两步：① 排序后从最小（最负）的数开始翻，翻一个负数的收益是 2×|x|，越负收益越大；② 负数翻完 k 还有剩余时，剩下的次数都打在当前绝对值最小的那个数上——偶数次等于没翻，奇数次相当于翻一次，扣掉 2×最小值。易错：数组里有 0 时，剩余次数全打在 0 上，不扣分（最小值为 0，公式自动成立）；[−5], k=2 这种"翻正以后又被迫翻回去"的情况。相近题型：LeetCode 1005。

参考答案
// a：整数数组（按值传入）；k：恰好要做几次取反。每次把某个元素取相反数，返回最终数组和的最大值。
int flipMax_12_3(vector<int> a, int k) {
    sort(a.begin(), a.end());                          // 负数排在前面，越负越靠前
    // i = 当前要翻的下标；每翻一个 k 减 1，遇到非负数或 k 用完就停
    for (int i = 0; i < (int)a.size() && k > 0 && a[i] < 0; ++i, --k) a[i] = -a[i];   // 先把最负的翻正
    int sum = 0, mn = INT_MAX;                         // sum = 数组和；mn = 最小值（INT_MAX 是 int 的最大值，作初值）
    for (int x : a) { sum += x; mn = min(mn, x); }     // k 还有剩余时，a 里已经没有负数
    if (k % 2 == 1) sum -= 2 * mn;                     // 剩奇数次：等于把最小的那个翻一次
    return sum;                                        // 剩偶数次：同一个数翻两次抵消
}
# a：整数数组（不修改调用者的列表）；k：恰好要做几次取反。每次把某个元素取相反数，返回最终数组和的最大值。
def flip_max_12_3(a, k):
    a = sorted(a)                                             # 负数排在前面，越负越靠前
    i = 0                                                     # i = 当前要翻的下标
    while i < len(a) and k > 0 and a[i] < 0:                  # 先把最负的翻正
        a[i] = -a[i]; i += 1; k -= 1                          # 翻正，下标后移，次数减 1
    total, mn = sum(a), min(a)                                # total = 数组和；mn = 最小值；k 还有剩余时，a 里已经没有负数
    if k % 2 == 1: total -= 2 * mn                            # 剩奇数次：等于把最小的那个翻一次
    return total                                              # 剩偶数次：同一个数翻两次抵消

练习 12.12-4【综合】截止日期前做任务赚最多 选做

题面：有 n 个任务，每个用 (d, p) 表示：做这个任务要用一整天，必须在第 d 天结束前（含第 d 天）做完，才能拿到收益 p，过期做就没有收益。从第 1 天开始，每天只能做一个任务，任务可以不做。求最大总收益。1 ≤ n ≤ 10^5，1 ≤ d ≤ 10^5，1 ≤ p ≤ 10^4。

样例 1：[(2, 100), (1, 19), (2, 27), (1, 25), (3, 15)]，答案 142。第 1、2 天做截止日为 2 的两个任务（100 和 27），第 3 天做截止日为 3 的任务（15），共 142；截止日为 1 的任务只能在第 1 天做，收益 25 不如 100 和 27。

样例 2：[(1, 5), (1, 7), (1, 3)]，答案 7。三个任务都只能在第 1 天做，只能选一个，选收益最大的 7。

样例 3：[(1, 5)]，答案 5。

提示

贪心 + 小顶堆：按截止日升序处理任务，每个任务先放进"已选"堆。如果已选个数超过了当前截止日 d（前 d 天放不下这么多），就退掉已选里收益最小的那个。交换论证：放不下时，任何可行方案都必须在这 d+1 个任务里至少放弃一个，放弃最便宜的不会更差。和 435 的区间贪心相比：这里多了"后悔"一步，堆负责随时找出最该放弃的那个。对拍：n ≤ 10 时枚举所有子集，把子集按截止日排序，检查第 k 个（从 1 数）任务的截止日 ≥ k。相近题型：LeetCode 630、1353。

参考答案
// jobs：任务列表，每个是 (截止日 d, 收益 p)，按值传入。每个任务做 1 天，第 d 天结束前做完才有收益，
// 每天只能做一个，返回最大总收益。
long long maxJobProfit_12_4(vector<pair<int, int>> jobs) {
    sort(jobs.begin(), jobs.end());                    // 按截止日升序
    // greater<int> 让堆顶是最小值，即小顶堆
    priority_queue<int, vector<int>, greater<int>> picked;   // 已选任务的收益，小顶堆
    long long sum = 0;                                 // 已选任务的总收益
    for (const auto& [d, p] : jobs) {                  // d = 截止日，p = 收益
        picked.push(p); sum += p;                      // 先把这个任务选上
        // 已选个数超过 d：截止日不晚于 d 的任务塞不进前 d 天
        if ((int)picked.size() > d) { sum -= picked.top(); picked.pop(); }   // 前 d 天放不下：退掉最便宜的
    }
    return sum;                                        // 最大总收益
}
# jobs：任务列表，每个是 (截止日 d, 收益 p)（不修改调用者的列表）。每个任务做 1 天，第 d 天结束前做完才有收益，
# 每天只能做一个，返回最大总收益。
def max_job_profit_12_4(jobs):
    jobs = sorted(jobs)                                       # 按截止日升序
    picked = []                                               # 已选任务的收益，heapq 默认就是小顶堆
    total = 0                                                 # 已选任务的总收益
    for d, p in jobs:                                         # d = 截止日，p = 收益
        heappush(picked, p); total += p                       # 先选上；需要 from heapq import heappush, heappop
        if len(picked) > d: total -= heappop(picked)          # 前 d 天放不下：退掉最便宜的
    return total                                              # 最大总收益

  • 先写贪心再找理由：先试着做交换论证或找反例，找到反例就改 DP。
  • 435 用 > 判断不重叠会把端点相接的区间当成重叠；题目规定相接不算重叠，用 >=。
  • 45 循环到最后一个下标还会多跳一次，循环条件是 i + 1 < n。

12.13 位运算：x&(x−1)、lowbit、异或与位掩码 选读

整数在计算机中以二进制位的形式存储。很多题目可以直接对二进制位进行操作，代码只有一两行，额外空间为 O(1)，例如在成对出现的数中找出落单的数、统计 1 的个数、用一个整数表示一个子集。题目中出现“只出现一次”“成对出现”“二进制中 1 的个数”“2 的幂”，或者 n ≤ 20 需要枚举所有子集、要求 O(1) 额外空间时，可以考虑位运算。笔试中也常有“写出 x&(x−1) 的结果”这类读代码题。[3]

常用的写法如下，以 x = 12 = 1100₂ 为例：

写法作用x=12 的结果
x & (x-1)去掉最低位的 18（1000₂）
x & -x只保留最低位的 1（lowbit）4（0100₂）
(x >> i) & 1取第 i 位（从 0 数）i=2 时为 1
x | (1 << i)把第 i 位置 1i=0 时为 13
x & ~(1 << i)把第 i 位清 0i=3 时为 4
x ^ (1 << i)翻转第 i 位i=0 时为 13
n > 0 && (n & (n-1)) == 0判断 2 的幂12 不是，16 是

减 1 会把最低位的 1 变 0、它右边的 0 全变 1；与原数相与，正好抹掉最低位的 1。x&−x 只留下这个 1，叫 lowbit

异或满足以下性质：a^a = 0，即相同的数异或后抵消；a^0 = a；异或满足交换律和结合律，所以一串数的异或结果与运算顺序无关。在补码表示下，-x 等于 ~x + 1：取反使最低位的 1 以下的 0 都变成 1、这个 1 变成 0，再加 1 使进位恰好停在原来最低位的 1 处，所以 x & -x 恰好只留下最低位的 1。

int lowbit(int x) { return x & -x; }                   // 只保留最低位的 1
bool isPowerOfTwo(int n) { return n > 0 && (n & (n - 1)) == 0; }   // 2 的幂只有一个 1，去掉它就成 0
# Python int 是无限精度：没有 32 位溢出，1 << 31、1 << 100 都是正数；~x 就是 -x-1，不是 32 位按位取反。
# 负数按"左边有无限个 1 的补码"参与位运算，-x == ~x + 1 仍成立，所以 x & -x 照样取最低位的 1；
# 负数右移是算术右移、向下取整（-5 >> 1 == -3），C++20 之前对负数右移是实现定义。
def lowbit(x): return x & -x                           # 只保留最低位的 1
def is_power_of_two(n): return n > 0 and (n & (n - 1)) == 0   # 2 的幂只有一个 1，去掉它就成 0

136 只出现一次的数字

给一个非空整数数组 nums，其中只有一个元素只出现一次，其余每个元素都恰好出现两次。找出那个只出现一次的元素，要求额外空间 O(1)。

样例 1：nums = [4, 1, 2, 1, 2]，答案 4。1 和 2 各出现两次，只有 4 出现一次。

样例 2：nums = [-3]，答案 -3。只有一个元素，它就是答案。

把所有元素依次异或到变量 x 中：处理完前 k 个数时，x 等于它们的异或。由于异或与顺序无关，出现两次的数两两抵消为 0，扫描完毕时 x 就是只出现一次的那个数。

singleNumber([4,1,2,1,2])：x 依次异或每个数

1 / 3

第1步 · x=0^4=4

x = 100₂ = 4
2 / 3

第2步 · x=4^1=5，再 ^2=7

x = 111₂ = 7
3 / 3

第3步 · x=7^1=6，再 ^2=4

x = 4：两个 1、两个 2 互相抵消，剩下只出现一次的 4
// 136 只出现一次的数字：nums 中只有一个数出现一次，其余都出现两次。返回那个数。
int singleNumber(const vector<int>& nums) {
    int x = 0;                                         // 0 异或任何数都等于那个数
    for (int v : nums) x ^= v;                         // 成对的数异或后抵消为 0
    return x;                                          // 剩下的就是只出现一次的数
}

191 位 1 的个数

给一个 32 位无符号整数 n，求把它写成二进制后有几个 1。

样例 1：n = 11，答案 3。11 的二进制是 1011，有 3 个 1。

样例 2：n = 128，答案 1。128 = 2⁷，二进制是 1 后面跟 7 个 0。

样例 3：n = 0，答案 0。

每次执行 n &= n−1 去掉最低位的 1，并令 cnt 加 1。每轮开始时，cnt 加上 n 中剩余的 1 的个数，等于原来 1 的个数；n 变成 0 时，cnt 就是答案。

hammingWeight(11)：n &= n−1 每次去掉一个 1

1 / 4

第1步 · n=1011₂=11

cnt=0
2 / 4

第2步 · n&(n−1)=1011&1010=1010₂=10

cnt=1
3 / 4

第3步 · 1010&1001=1000₂=8

cnt=2
4 / 4

第4步 · 1000&0111=0，循环结束

cnt=3：循环次数 = 1 的个数
// 191 位 1 的个数：n 是 32 位无符号整数（uint32_t）。返回它二进制表示中 1 的个数。
int hammingWeight(uint32_t n) {
    int cnt = 0;                                       // 1 的个数
    while (n) { n &= n - 1; ++cnt; }                   // 每次去掉最低位的 1
    return cnt;
}
# 191 位 1 的个数：n 当作 32 位无符号整数。返回它二进制表示中 1 的个数。
def hamming_weight(n):
    # 没有 uint32_t：负数在 Python 里有"无限多个 1"，while n 永不结束，先截成 32 位无符号
    n &= 0xFFFFFFFF
    cnt = 0                                                   # 1 的个数
    while n: n &= n - 1; cnt += 1                             # 每次去掉最低位的 1
    return cnt

循环次数等于 1 的个数，最多 32 次。

338 比特位计数

给一个整数 n ≥ 0，返回长度为 n + 1 的数组 ans，其中 ans[i] 是 i 的二进制表示中 1 的个数（0 ≤ i ≤ n）。

样例 1：n = 5，返回 [0, 1, 1, 2, 1, 2]。0 到 5 的二进制依次是 0、1、10、11、100、101，1 的个数分别是 0、1、1、2、1、2。

样例 2：n = 0，返回 [0]。

i&(i−1) 比 i 少一个 1，而且比 i 小，所以 ans[i] = ans[i&(i−1)] + 1。i 从 1 递增计算，算 ans[i] 时所需的更小的值都已算好。这是一道用位运算写出转移方程的动态规划。

四行依次是 i、二进制、i&(i−1)、ans[i]。ans[7]=ans[6]+1=3：7&6=6 是 7 去掉最低位 1 之后的数，它已经算过

countBits(8)：ans[i] = ans[i & (i−1)] + 1

1 / 4

第1步 · ans[0]=0；i=1：1&0=0 → ans[0]+1=1

2 / 4

第2步 · i=2：2&1=0 → 1；i=3：3&2=2 → ans[2]+1=2

3 / 4

第3步 · i=4..6：4&3=0→1，5&4=4→2，6&5=4→2

4 / 4

第4步 · i=7：7&6=6 → ans[6]+1=3；i=8：8&7=0 → 1

每个 ans[i] 只依赖一个更小的下标，从小到大填即可
// 338 比特位计数：返回长度 n+1 的数组，第 i 个元素是 i 的二进制里 1 的个数（0 ≤ i ≤ n）。
vector<int> countBits(int n) {
    vector<int> ans(n + 1, 0);                         // ans[i]：i 的二进制里 1 的个数；ans[0] = 0
    // i & (i-1) 去掉 i 最低位的 1，比 i 小、已经算好，再加回这一个 1
    for (int i = 1; i <= n; ++i) ans[i] = ans[i & (i - 1)] + 1;
    return ans;
}
# 338 比特位计数：返回长度 n+1 的列表，第 i 个元素是 i 的二进制里 1 的个数（0 ≤ i ≤ n）。
def count_bits(n):
    ans = [0] * (n + 1)                                       # ans[i]：i 的二进制里 1 的个数；ans[0] = 0
    # i & (i-1) 去掉 i 最低位的 1，比 i 小、已经算好，再加回这一个 1
    for i in range(1, n + 1): ans[i] = ans[i & (i - 1)] + 1
    return ans

时间 O(n)，空间 O(n)（即输出本身）。

子集的位掩码枚举

题目是：给一个数组 nums（元素互不相同），列出它的所有子集，即从中任意挑出若干个元素（可以一个都不挑）组成的集合。例如 nums = [1, 2, 3] 时返回 [[], [1], [2], [1, 2], [3], [1, 3], [2, 3], [1, 2, 3]]：每个元素都有选和不选两种可能，共 2³ = 8 个子集（这里按下面代码的输出顺序列出）；nums = [] 时返回 [[]]，只有空集一个子集。

n 个元素的每个子集都对应一个 n 位的二进制数 mask：第 i 位是 1 表示选中 nums[i]。让 mask 从 0 枚举到 2ⁿ−1，就枚举了全部 2ⁿ 个子集。结果与 9.6 用回溯求子集相同，写法更短，适用于 n ≤ 20 的情况。

nums=[1,2,3]：第 i 位（从右数，从 0 起）为 1 表示选 nums[i]。mask=5=101₂ 选 nums[0]=1 与 nums[2]=3

// 用位掩码枚举 nums 的全部子集：返回 2^n 个子集（n 不能太大，2^n 个结果要放得下）。
vector<vector<int>> subsetsByMask(const vector<int>& nums) {
    int n = nums.size();                               // n = 元素个数
    vector<vector<int>> ans;                           // 所有子集
    for (int mask = 0; mask < (1 << n); ++mask) {      // 每个 n 位二进制数对应一个子集；mask 第 i 位为 1 表示选 nums[i]
        vector<int> sub;                               // mask 对应的子集
        for (int i = 0; i < n; ++i)                    // 逐位检查
            if (mask >> i & 1) sub.push_back(nums[i]);   // 第 i 位是 1：选 nums[i]
        ans.push_back(sub);                            // 收集这个子集
    }
    return ans;                                        // 共 2^n 个子集
}
# 用位掩码枚举 nums 的全部子集：返回 2^n 个子集（n 不能太大，2^n 个结果要放得下）。
def subsets_by_mask(nums):
    n = len(nums)                                             # n = 元素个数
    ans = []                                                  # 所有子集
    # mask 取 0 .. 2^n-1，第 i 位为 1 表示选 nums[i]；1 << n 不会溢出，但 n 大了照样枚举不完
    for mask in range(1 << n):
        sub = []                                              # mask 对应的子集
        for i in range(n):                                    # 逐位检查
            # 第 i 位是 1：选 nums[i]；>> 优先级高于 &，与 C++ 相同
            if mask >> i & 1: sub.append(nums[i])
        ans.append(sub)                                       # 收集这个子集
    return ans                                                # 共 2^n 个子集

时间 O(n·2ⁿ)，不计输出时空间 O(n)。

小结： x&(x-1) 去掉最低位的 1，x&-x 只保留最低位的 1，n>0 && (n&(n-1))==0 判断 2 的幂；异或使成对出现的数相互抵消；枚举子集时让 mask 从 0 取到 (1<<n)−1，用第 i 位决定是否选第 i 个元素。

练习 12.13-1【基础】两个编码有几位不同 选做

题面：给两个非负整数 x、y（都小于 2^31），把它们都写成二进制，逐位对齐比较（位数不够的在前面补 0），数一数有多少位不同。这个数叫 x 和 y 的"汉明距离"。

样例 1：x = 1，y = 4，答案 2。1 是 001，4 是 100，最低位和最高位不同，共 2 位。

样例 2：x = 3，y = 1，答案 1。3 是 11，1 是 01，只有高位不同。

样例 3：x = 0，y = 0，答案 0。两数相同。

样例 4：x = 0，y = 2147483647，答案 31。2147483647 = 2³¹ − 1，二进制是 31 个 1，和 0 每一位都不同。

提示

x ^ y 把不同的位变成 1、相同的位变成 0，问题就变成 191 题"数 1 的个数"。用 z &= z − 1 每次去掉最低位的 1，循环了几次就是答案。相近题型：LeetCode 461。

参考答案
// x、y：两个非负整数（小于 2^31）。返回它们二进制表示中不同的位数（汉明距离）。
int bitDiff_13_1(unsigned x, unsigned y) {
    unsigned z = x ^ y;                                // 不同的位变成 1
    int cnt = 0;                                       // 数 z 里有几个 1
    while (z) { z &= z - 1; ++cnt; }                   // 每次去掉最低位的 1
    return cnt;                                        // 不同的位数
}

    while z:                                                  # z 里还有 1
        z &= z - 1; cnt += 1                                  # 每次去掉最低位的 1
    return cnt                                                # 不同的位数

练习 12.13-2【变形】找出两个落单的数 选做

题面：数组 a 中恰好有两个数只出现一次，其余每个数都恰好出现两次。找出这两个数，按从小到大返回。2 ≤ n ≤ 3×10^4，元素在 int 范围内（可能是 int 的最小值 INT_MIN，即 −2³¹）。要求 O(n) 时间、O(1) 额外空间。

样例 1：a = [1, 2, 1, 3, 2, 5]，返回 [3, 5]。1 和 2 各出现两次，3 和 5 各出现一次。

样例 2：a = [-1, 0]，返回 [-1, 0]。两个数各出现一次，按从小到大排。

样例 3：a = [INT_MIN, 7, 7, 1]，返回 [INT_MIN, 1]。7 出现两次；INT_MIN 是最小的 int，排在 1 前面。

提示

全部异或起来，成对的数抵消，得到 xr = p ^ q。p ≠ q，所以 xr 至少有一位是 1；取它的 lowbit：p、q 在这一位上一个是 0、一个是 1。按这一位把所有数分成两组，相同的数一定进同一组，于是每组各自异或，就各剩下一个落单的数。和 136 相比：一个数变成两个数，多了"按 lowbit 分组"这一步。易错：xr 可能是 INT_MIN，对 int 取负会溢出，用 unsigned 计算 lowbit。相近题型：LeetCode 260。

参考答案
// a：恰好两个数只出现一次、其余都出现两次的数组（元素可能是 INT_MIN）。按升序返回那两个数。
vector<int> twoSingles_13_2(const vector<int>& a) {
    unsigned xr = 0;                                   // 用 unsigned 做位运算，INT_MIN 也不会出问题
    for (int x : a) xr ^= (unsigned)x;                 // 结果 = 两个落单数的异或
    unsigned low = xr & (~xr + 1);                     // lowbit；unsigned 下 ~xr+1 就是 -xr，不会溢出
    int p = 0, q = 0;                                  // 两组各自的异或结果，就是两个落单数
    for (int x : a) {                                  // 再扫一遍，按 low 这一位分组
        // 两个落单数在 low 这一位不同，分到两组；成对的数一定进同一组并抵消
        if ((unsigned)x & low) p ^= x; else q ^= x;    // 按这一位分两组，各自异或
    }
    return {min(p, q), max(p, q)};                     // 题目要求升序
}

    low = xr & -xr                                            # lowbit；Python int 不溢出，负数按无限位补码处理
    p = q = 0                                                 # 两组各自的异或结果，就是两个落单数
    for x in a:                                               # 再扫一遍，按 low 这一位分组
        # 两个落单数在 low 这一位不同，分到两组；成对的数一定进同一组并抵消
        if x & low: p ^= x
        else: q ^= x                                          # 按这一位分两组，各自异或
    return [min(p, q), max(p, q)]                             # 题目要求升序

练习 12.13-3【综合】不共享字母的两个词 选做

题面：给一组小写单词 words，从中挑两个单词，要求它们没有任何相同的字母，计算两个单词长度的乘积。求这个乘积的最大值；找不到这样的两个单词时返回 0。2 ≤ n ≤ 1000，1 ≤ 单词长度 ≤ 1000。

样例 1：words = ["abcw", "baz", "foo", "bar", "xtfn", "abcdef"]，答案 16。"abcw" 和 "xtfn" 没有相同字母，4 × 4 = 16；最长的 "abcdef" 和其他每个单词都有相同字母（例如和 "foo" 都有 f，和 "xtfn" 也都有 f），用不上。

样例 2：words = ["a", "ab", "abc", "d", "cd", "bcd", "abcd"]，答案 4。"ab" 和 "cd" 没有相同字母，2 × 2 = 4；"abcd" 和每个单词都有相同字母。

样例 3：words = ["a", "aa", "aaa", "aaaa"]，答案 0。每个单词都含 a，任意两个都有相同字母。

提示

位掩码：把每个单词压成一个 26 位整数 mask，第 c 位为 1 表示含字母 'a'+c。两个单词没有公共字母，当且仅当两个 mask 按位与为 0，判断只要 O(1)。再双重循环枚举所有单词对。易错：字母重复出现时用 |= 置位（用 += 会进位出错）；mask[i] & mask[j] == 0 要加括号（见下面的易错点）；没有合法的一对时返回 0。对拍：逐字符比较两个单词有没有公共字母的暴力。相近题型：LeetCode 318。

参考答案
// words：小写单词列表。返回两个没有公共字母的单词长度乘积的最大值；不存在这样的一对时返回 0。
int maxWordProduct_13_3(const vector<string>& words) {
    int n = words.size(), best = 0;                    // n = 单词数；best：目前最大的长度乘积
    vector<int> mask(n, 0);                            // mask[i] 第 c 位为 1：单词 i 含字母 'a'+c
    for (int i = 0; i < n; ++i)                        // 逐个单词建掩码
        for (char ch : words[i]) mask[i] |= 1 << (ch - 'a');   // 把出现的字母对应位置 1
    for (int i = 0; i < n; ++i)                        // 枚举所有单词对
        for (int j = i + 1; j < n; ++j)                // j > i：每对只看一次
            if ((mask[i] & mask[j]) == 0)              // 没有公共字母
                best = max(best, (int)(words[i].size() * words[j].size()));   // 更新最大乘积
    return best;                                       // 没有合法的一对时仍是 0
}
# words：小写单词列表。返回两个没有公共字母的单词长度乘积的最大值；不存在这样的一对时返回 0。
def max_word_product_13_3(words):
    n, best = len(words), 0                                   # n = 单词数；best：目前最大的长度乘积
    mask = [0] * n                                            # mask[i] 第 c 位为 1：单词 i 含字母 'a'+c
    for i in range(n):                                        # 逐个单词建掩码
        for ch in words[i]: mask[i] |= 1 << (ord(ch) - ord('a'))   # 把出现的字母对应位置 1
    for i in range(n):                                        # 枚举所有单词对
        for j in range(i + 1, n):                             # j > i：每对只看一次
            if mask[i] & mask[j] == 0:                        # Python 的 & 优先级高于 ==，不加括号也对；C++ 必须加
                best = max(best, len(words[i]) * len(words[j]))   # 更新最大乘积
    return best                                               # 没有合法的一对时仍是 0

易错点：

  • 运算符优先级：x & 1 == 0 等价于 x & (1 == 0)，判断位要加括号写成 (x & 1) == 0。
  • 对负数右移的结果依赖实现（C++20 之前），数 1 的个数时用无符号类型。
  • 1 << 31 超出 int 范围，需要 31 位以上时写 1LL << i 或 1u << i。
