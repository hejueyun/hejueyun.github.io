2.1 语法糖：auto、范围 for、结构化绑定、lambda 必读

语法糖是指不增加新的功能、只使代码更短更易读的写法。做题时它们几乎出现在每一行：for (auto& [k, v] : m) 一行里就有范围 for、引用、结构化绑定三样。写错一个符号（例如少一个 &），程序照样能够编译，结果却不对，所以本节逐一说明每个符号的含义。[6] [7] [8] [9]

void demoSugar() {
    using ll = long long;
    vector<int> v{3, 1, 4};
    for (auto& x : v) x *= 10;                            // 改原元素：v = {30, 10, 40}
    map<string, int> age{{"bob", 20}, {"amy", 18}};
    int limit = 19;
    auto older = [limit](int a) { return a > limit; };    // 只拷贝 limit
    ll total = 0;
    auto add = [&](ll x) { total += x; };                 // 按引用捕获，能改 total
    for (const auto& [name, a] : age) {                   // map 按键有序：amy 在前
        if (older(a)) add(a);
        cout << name << (older(a) ? "+" : "-") << " ";
    }
    cout << v[0] << " " << total << "\n";
}
def demo_sugar():
    v = [3, 1, 4]
    for i in range(len(v)):
        v[i] *= 10                         # Python 的 for x in v 拿到的是值，改原列表要用下标
    age = {"bob": 20, "amy": 18}
    limit = 19
    older = lambda a: a > limit

            total += a                     # 同一层作用域里直接改，不需要捕获
        parts.append(name + ("+" if older(a) else "-"))
    print(" ".join(parts), v[0], total)

练习 2.1-5【函数】用 lambda 一边遍历一边统计

题面：给一个整数数组 v 和阈值 t，返回 {大于 t 的元素个数, 这些元素的和}。要求用 for_each 加一个按引用捕获的 lambda 完成。

样例：v = {5, 1, 8, 3}, t = 3 → {2, 13}。

提示

for_each(b, e, f) 对每个元素调用一次 f。lambda 要修改外面的 cnt 和 sum，所以捕获写 [&]。

参考答案
pair<int, long long> countAndSumAbove(const vector<int>& v, int t) {
    int cnt = 0;
    long long sum = 0;
    for_each(v.begin(), v.end(), [&](int x) {
        if (x > t) { ++cnt; sum += x; }
    });
    return {cnt, sum};
}
def count_and_sum_above(v, t):
    cnt, total = 0, 0
    def visit(x):
        nonlocal cnt, total          # 内层函数要改外层变量必须声明 nonlocal，作用相当于 C++ 的 [&]
        if x > t:
            cnt += 1
            total += x
    for x in v:
        visit(x)
    return (cnt, total)

练习 2.1-7【函数】用 using 和 auto 让代码变短

题面：给一组点 vector<pair<int,int>>，返回离原点最近的点（距离平方最小；距离相同取先出现的）。要求在函数里用 using pii = pair<int, int>;，并用 min_element 加 lambda。

样例：{{3, 4}, {1, -1}, {-1, 1}} → {1, -1}。

提示

min_element(b, e, cmp) 返回第一个最小元素的迭代器，解引用得到点。比较器比较 x*x + y*y。

参考答案
pair<int, int> closestToOrigin(const vector<pair<int, int>>& pts) {
    using pii = pair<int, int>;
    auto d2 = [](const pii& p) { return 1LL * p.first * p.first + 1LL * p.second * p.second; };
    return *min_element(pts.begin(), pts.end(), [&](const pii& a, const pii& b) { return d2(a) < d2(b); });
}
def closest_to_origin(pts):
    d2 = lambda p: p[0] * p[0] + p[1] * p[1]
    return min(pts, key=d2)              # min 遇到相等时保留先出现的，与 min_element 一致

多选 · 理解检查 1　int cnt = 0; 下面哪些 lambda 调用一次之后，外面的 cnt 会变成 1？

A. [&]() { ++cnt; }

B. [&cnt]() { ++cnt; }

C. [=]() { ++cnt; }

D. [cnt]() mutable { ++cnt; }

查看答案与每个选项的解析

A · 正确：[&] 按引用捕获用到的外部变量，改的就是外面的 cnt。

B · 正确：只按引用捕获 cnt，同样改到外面的变量。

C · 错误：[=] 拷贝一份 cnt，而且拷进来的变量默认只读，这一行直接编译报错。

D · 错误：mutable 允许修改，但改的是 lambda 内部那份副本，外面的 cnt 仍是 0。

易错点

  • 范围 for 想改元素却写成 auto x：能编译、不报错、结果不变。改元素用 auto&，只读大对象用 const auto&。
  • lambda 比较器里写 <= 或 >=：违反"严格弱序"（2.4 详讲），sort 可能越界崩溃。
  • 三目运算符放进 cout << a > b ? x : y 会先算 cout << a，必须写成 cout << (a > b ? x : y)。

小结： auto 得到副本，auto& 引用原对象，const auto& 只读地引用原对象；lambda 的 [&] 可以修改外部变量，[x] 只拷贝 x；比较器必须是严格的 <。

按条件删除：remove_if 加 erase

"删掉所有偶数"这种按条件删除的需求很常见。在下标循环里逐个 erase 有两个问题：每删一个，后面的元素都要整体前移一次，最坏 O(n²)；而且删除后下标对不上，容易漏删（练习 2.2-3）。标准写法是两个函数配合，叫 erase–remove 惯用法：

v.erase(remove_if(v.begin(), v.end(), [](int x) { return x % 2 == 0; }), v.end());

remove_if(b, e, pred) 的第三个参数 pred 是一个返回 true 或 false 的函数（这里是 lambda），叫谓词，返回 true 表示"这个元素要删"。remove_if 从左到右扫一遍，把要保留的元素依次挪到数组前部，然后返回"保留部分的结尾"这个位置。它只挪动元素，不改变 vector 的长度，所以还要用 erase 把从这个位置到末尾的部分真正删掉。以 v = {2, 4, 5, 6, 7} 为例：

v.erase(remove_if(..., 偶数), v.end())

多选 · 理解检查 2　下面四个 vector 构造之后，哪些的 size() 等于 3？

A. vector<int> a(3);

B. vector<int> b{3};

C. vector<int> c(3, 5);

查看答案与每个选项的解析

A · 正确：圆括号里的 3 是个数，得到 3 个 0。

B · 错误：花括号是初始化列表，得到只有一个元素 3 的 vector，size() 是 1。

C · 正确：3 个 5。

D · 错误：reserve 只预留容量，size() 仍是 0。

易错点

  • insert/erase 的参数是迭代器 v.begin() + i，直接写下标 i 会编译报错；它们是 O(n)，放在循环里会变成 O(n²)。
  • reserve(n) 之后 v[0] = 1 是越界写；想按下标写就用 resize(n) 或构造时给出长度。
  • 在空 vector 上调用 back()、front()、pop_back() 是未定义行为，调用前先判断 !v.empty()。

小结： vector 的构造函数个数在前、值在后，二维 vector 要写全 g(m, vector<int>(n))；insert 和 erase 使用迭代器，时间 O(n)；resize 改变元素个数，reserve 只改变容量。

判断字符的种类：isdigit、isalpha、isalnum 与 unsigned char

速查表里"字符分类"和"大小写"两行的函数来自头文件 <cctype>，每个函数接收一个字符，回答它属于哪一类：

函数判断什么例子

isalnum(c)是不是字母或数字。名字来自 alphanumeric，即 alphabetic（字母）+ numeric（数字）'a'、'7' 是，'_'、' ' 不是
isspace(c)是不是空白：空格、制表符 '\t'、换行 '\n' 等' ' 是

使用时有三个细节。

第一，判断函数返回的是 int：0 表示"不是"，其他任何值都表示"是"，但不一定是 1。在 GCC 上 isalpha('a') 返回 1024，isspace('\n') 返回 8192。所以写 if (isalpha(c)) 是对的，写 if (isalpha(c) == true) 是错的：true 转成整数是 1，1024 不等于 1，条件不成立。

第二，toupper、tolower 返回的也是 int。直接 cout << tolower('A') 会打印 97，存回字符要写 (char)tolower(c)。

第三，参数最好先转成 unsigned char，写成 isalnum((unsigned char)c)。原因是：char 在 GCC 等常见编译器上是有符号的，能表示 −128～127。英文字母、数字、标点的编码都在 0～127 之间，没有问题；但 string 里的中文按 UTF-8 存储，每个汉字占 3 个字节，每个字节的值都大于 127，存进 char 就变成了负数，例如"中"的三个字节读出来是 −28、−72、−83。而这些函数只接受 0～255（以及表示文件结束的 EOF，即 −1），传入其他负数是未定义行为，可能返回错误结果，也可能直接崩溃。转成 unsigned char 后，−28 变回 228，落在合法范围内。只处理英文的题目里不转也不会出错，但转一下是更安全的习惯；写 lambda 时也可以直接把参数声明成 unsigned char，例如 [](unsigned char c) { return isdigit(c) != 0; }。

多选 · 理解检查 3　v = {2, 2, 1, 2}; 执行 auto it = unique(v.begin(), v.end()); 之后，哪些正确？

A. it - v.begin() 等于 3

B. v.size() 变成 3

C. v 的前三个元素是 2 1 2

D. 想得到 {1, 2}，应该先 sort 再 unique + erase

查看答案与每个选项的解析

A · 正确：相邻重复段是 [2,2]、[1]、[2]，保留 2 1 2 三个元素。

B · 错误：unique 只移动元素、返回新的逻辑结尾，size 仍是 4，要再 erase 才会变。

C · 正确：每段相同值的第一个被依次挪到前面。

D · 正确：排序后相同值相邻，unique 才能全局去重。

易错点

  • 比较器写 <=、>=：违反严格弱序，结果错误甚至崩溃。降序写 >，或者用 greater<int>()。
  • 只写 unique(b, e) 不 erase：size 没变，尾部是无意义的值；没先 sort 只能去掉相邻重复。
  • *max_element(...) 在空数组上解引用 end()，是未定义行为；调用前确认非空。

小结： 返回位置的算法函数给出迭代器，减去 begin() 得到下标，等于 end() 表示没找到；去重用 sort、unique、erase 三步；比较器只用 < 或 >。

def count_in_range(a, lo, hi):

练习 2.5-5【改错】在 set 上用了 std::lower_bound

题面：对每个询问 q，输出 set 中第一个 ≥ q 的元素，没有就输出 −1。数据有 10⁵ 个元素、10⁵ 个询问，下面的代码结果正确但超时。

vector<int> ceilingQueries(const set<int>& st, const vector<int>& qs) {
    vector<int> out;
    for (int q : qs) {
        auto it = lower_bound(st.begin(), st.end(), q);
        out.push_back(it == st.end() ? -1 : *it);
    }
    return out;
}
提示

std::lower_bound 需要"随机访问"才能 O(1) 跳到中点；set 的迭代器只能一步一步走，于是每次查询退化成 O(n)。改用成员函数 st.lower_bound(q)，它沿红黑树往下走，O(log n)。

参考答案
vector<int> ceilingQueries(const set<int>& st, const vector<int>& qs) {
    vector<int> out;
    for (int q : qs) {
        auto it = st.lower_bound(q);
        out.push_back(it == st.end() ? -1 : *it);
    }
    return out;
}
def ceiling_queries(sorted_vals, qs):
    # Python 标准库没有平衡树 set：用升序列表 + bisect 查询（插入删除才会变成 O(n)）
    out = []
    for q in qs:
        i = bisect.bisect_left(sorted_vals, q)
        out.append(-1 if i == len(sorted_vals) else sorted_vals[i])
    return out

练习 2.5-6【函数】列出所有不重复的排列

题面：s 中可能有重复字符，按字典序返回它的所有不同排列。

样例："aab" → {"aab", "aba", "baa"}。

提示

先 sort 得到最小排列，再用 do-while 配 next_permutation。它按字典序严格递增地走，相同字符交换不会产生"新"排列，所以天然去重。

参考答案
vector<string> allPerms(string s) {
    sort(s.begin(), s.end());
    vector<string> out;
    do { out.push_back(s); } while (next_permutation(s.begin(), s.end()));
    return out;
}
def next_perm(a):
    # 与 std::next_permutation 相同：把 a 改成下一个字典序排列；已是最大时改成最小并返回 False
    i = len(a) - 2
    while i >= 0 and a[i] >= a[i + 1]:
        i -= 1
    if i < 0:
        a.reverse()
        return False
    j = len(a) - 1
    while a[j] <= a[i]:
        j -= 1
    a[i], a[j] = a[j], a[i]
    a[i + 1:] = reversed(a[i + 1:])
    return True

def all_perms(s):
    a = sorted(s)
    out = []
    while True:                          # Python 没有 do-while：先处理，再判断
        out.append("".join(a))
        if not next_perm(a):
            break
    return out

练习 2.5-9【一行】循环右移 k 位

题面：把 v 循环右移 k 位（k ≥ 0，可能大于 n），v 为空时不变。

样例：{1, 2, 3, 4, 5}，k = 2 → {4, 5, 1, 2, 3}；k = 7 也是这个结果。

提示

右移 k 位等于左移 n − k 位；k 先对 n 取模。rotate 的中间参数是"移动后排第一个的元素"，右移 k 位后排第一的是原来的 v[n - k]。k % n 为 0 时 n − 0 = n，再对 n 取模避免越界。

参考答案
void rotateRight(vector<int>& v, int k) {
    if (v.empty()) return;
    int n = v.size();
    rotate(v.begin(), v.begin() + (n - k % n) % n, v.end());
}
def rotate_right(v, k):
    if not v:
        return
    n = len(v)
    s = (n - k % n) % n
    v[:] = v[s:] + v[:s]

多选 · 理解检查 4　a = {10, 20, 20, 30}（升序）。下面哪些表达式的值是 3？

A. upper_bound(a.begin(), a.end(), 20) - a.begin()

B. lower_bound(a.begin(), a.end(), 25) - a.begin()

C. lower_bound(a.begin(), a.end(), 20) - a.begin()

D. upper_bound(a.begin(), a.end(), 30) - a.begin()

查看答案与每个选项的解析

A · 正确：第一个 > 20 的是 30，下标 3。

B · 正确：第一个 ≥ 25 的也是 30，下标 3。

C · 错误：第一个 ≥ 20 是下标 1 的 20。

D · 错误：没有 > 30 的元素，返回 end()，下标是 4。

易错点

  • 二分族要求区间按同一个比较规则有序；对无序数组调用不会报错，只会给出错误位置。
  • set/map 上二分一定用成员函数 st.lower_bound(x)；std::lower_bound(st.begin(), ...) 能编译，但每次 O(n)。
  • next_permutation 想枚举全部排列，开始前必须 sort，循环写成 do-while，先处理当前排列。

小结： lower_bound 返回第一个 ≥ x 的位置，upper_bound 返回第一个 > x 的位置，两者相减是 x 的个数，前者减 1 是前驱；set 要用成员函数版本；枚举排列先 sort 再用 do-while；求第 k 小用 nth_element。
