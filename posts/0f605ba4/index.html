2.1 语法糖：auto、范围 for、结构化绑定、lambda 必读

语法糖是指不增加新的功能、只使代码更短更易读的写法。做题时它们几乎出现在每一行：for (auto& [k, v] : m) 一行里就有范围 for、引用、结构化绑定三样。写错一个符号（例如少一个 &），程序照样能够编译，结果却不对，所以本节逐一说明每个符号的含义。[6] [7] [8] [9]

// 示例：把本节的语法糖用在一个函数里。没有参数、没有返回值；
// 打印每个人的名字和是否"older"（+ 或 -），再打印 v[0] 和 older 的人的年龄和。
void demoSugar() {
    using ll = long long;                                 // 给 long long 起短名 ll，只在函数内有效
    vector<int> v{3, 1, 4};                               // 初始化列表：3 个元素
    for (auto& x : v) x *= 10;                            // 改原元素：v = {30, 10, 40}
    map<string, int> age{{"bob", 20}, {"amy", 18}};       // age[名字] = 年龄；每个 {键, 值} 是一个 pair
    int limit = 19;                                       // 年龄超过它算"older"
    auto older = [limit](int a) { return a > limit; };    // older(a)：年龄 a 超过 limit 时为 true；只拷贝 limit
    ll total = 0;                                         // older 的人的年龄和
    auto add = [&](ll x) { total += x; };                 // add(x)：把 x 加进 total；按引用捕获，能改 total
    for (const auto& [name, a] : age) {                   // name = 名字（键），a = 年龄（值）；map 按键有序：amy 在前
        if (older(a)) add(a);                             // 超过 limit 的才累加
        cout << name << (older(a) ? "+" : "-") << " ";    // 三目运算符要加括号才能放进 << 链
    }
    cout << v[0] << " " << total << "\n";                 // 最后打印 v[0] 和年龄和
}

# 打印每个人的名字和是否"older"（+ 或 -），再打印 v[0] 和 older 的人的年龄和。
def demo_sugar():

    for i in range(len(v)):                # i = 当前要改的下标
        v[i] *= 10                         # Python 的 for x in v 拿到的是值，改原列表要用下标

    # name = 名字（键），a = 年龄（值）；dict 按插入顺序遍历，C++ map 按键有序，所以这里 sorted
    for name, a in sorted(age.items()):
        if older(a):
            total += a                     # 同一层作用域里直接改，不需要捕获
        parts.append(name + ("+" if older(a) else "-"))   # 条件表达式，对应 C++ 的三目运算符
    print(" ".join(parts), v[0], total)    # 片段用空格连起来，再打印 v[0] 和年龄和

// 练习：没有参数、没有返回值，打印两个 lambda 在 k 被修改之后各自的返回值。
void showCapture() {
    int k = 1;                                   // k = 被两个 lambda 捕获的变量
    auto byValue = [k]() { return k * 10; };     // [k]：按值捕获 k
    auto byRef = [&k]() { return k * 10; };      // [&k]：按引用捕获 k
    k = 5;                                       // 两个 lambda 创建之后，外面改 k
    cout << byValue() << " " << byRef() << "\n"; // 现在才调用两个 lambda
}

// 练习：没有参数、没有返回值，按 map 的遍历顺序打印每个人的名字和是否及格（P 或 F）。
void showBinding() {
    map<string, int> score{{"tom", 59}, {"ann", 88}, {"joe", 60}};   // 名字 -> 分数
    for (const auto& [name, s] : score)          // 结构化绑定：name 是键，s 是值；按 map 的顺序遍历
        // >= 60 打 P 否则打 F；名字是 tom 时后面换行，否则跟空格
        cout << name << ":" << (s >= 60 ? "P" : "F") << (name == "tom" ? "\n" : " ");
}
提示

map 按键（字符串字典序）从小到大遍历，和初始化时写的顺序无关。

参考答案
// 输出：ann:P joe:P tom:F
// 遍历顺序是 ann、joe、tom；60 满足 >= 60，所以 joe 是 P；tom 是最后一个，后面跟换行。

// 目标：把 words 里每个单词的字母都改成大写。words 由调用者传入（按引用），无返回值。
void toUpperAll(vector<string>& words) {

练习 2.1-4【函数】用 lambda 一边遍历一边统计 选做

题面：给一个整数数组 v 和一个整数 t（t 叫"阈值"，是拿来比较的那条线）。找出 v 中所有严格大于 t 的元素（等于 t 的不算），返回一对数 {个数, 和}：第一个数是这样的元素有几个，第二个数是它们加起来的和；一个都没有时返回 {0, 0}。要求用 for_each 加一个按引用捕获的 lambda 完成。

样例 1：v = {5, 1, 8, 3}，t = 3，答案 {2, 13}。大于 3 的只有 5 和 8（3 等于 t，不算），共 2 个，和是 13。

样例 2：v = {1, 2}，t = 5，答案 {0, 0}。没有元素大于 5。

提示

for_each(b, e, f) 对每个元素调用一次 f。lambda 要修改外面的 cnt 和 sum，所以捕获写 [&]。

参考答案
// v = 整数数组（只读），t = 阈值。返回 {大于 t 的元素个数, 这些元素的和}；没有这样的元素时返回 {0, 0}。
pair<int, long long> countAndSumAbove(const vector<int>& v, int t) {
    int cnt = 0;                                 // 大于 t 的元素个数
    long long sum = 0;                           // 这些元素的和，用 long long 防溢出
    // 对每个元素调用一次 lambda，参数 x 就是当前元素；[&] 才能改外面的 cnt、sum
    for_each(v.begin(), v.end(), [&](int x) {
        if (x > t) { ++cnt; sum += x; }          // 只统计大于 t 的
    });
    return {cnt, sum};                           // {个数, 和}
}
# v = 整数列表，t = 阈值。返回 (大于 t 的元素个数, 这些元素的和)；没有这样的元素时返回 (0, 0)。
def count_and_sum_above(v, t):
    cnt, total = 0, 0                # 大于 t 的元素个数、它们的和
    # 处理一个元素 x：大于 t 时计入 cnt 和 total，无返回值
    def visit(x):                    # 相当于 C++ 里传给 for_each 的 lambda
        nonlocal cnt, total          # 内层函数要改外层变量必须声明 nonlocal，作用相当于 C++ 的 [&]
        if x > t:                    # 只统计大于 t 的
            cnt += 1
            total += x
    for x in v:                      # x = 当前元素；对每个元素调用一次
        visit(x)
    return (cnt, total)              # (个数, 和)

练习 2.1-5【函数】用 using 和 auto 让代码变短 选做

题面：给平面上的一组点（至少一个），类型是 vector<pair<int,int>>，每个点的 first 是横坐标 x，second 是纵坐标 y。返回离原点 (0, 0) 最近的点。比较远近时用距离的平方 x² + y²，不必开根号，大小关系不变；有几个点一样近时，返回在数组中最先出现的那个。要求在函数里用 using pii = pair<int, int>;，并用 min_element 加 lambda。

样例 1：{{3, 4}, {1, -1}, {-1, 1}}，答案 {1, -1}。三个点的距离平方分别是 25、2、2；后两个一样近，取先出现的 (1, −1)。

样例 2：{{-2, 7}}，答案 {-2, 7}。只有一个点，它就是最近的。

提示

min_element(b, e, cmp) 返回第一个最小元素的迭代器，解引用得到点。比较器比较 x*x + y*y。

参考答案
// pts = 平面上的点（非空，只读），每个点是 (x, y)。返回离原点最近的点；距离相同时返回先出现的那个。
pair<int, int> closestToOrigin(const vector<pair<int, int>>& pts) {
    using pii = pair<int, int>;                  // 点的类型起短名
    // d2(p)：到原点距离的平方；1LL 让乘法按 long long 算，防溢出
    auto d2 = [](const pii& p) { return 1LL * p.first * p.first + 1LL * p.second * p.second; };
    // min_element 返回第一个最小元素的迭代器（距离相同取先出现的），* 取出这个点；
    // 比较器的 a、b 是两个点，a 离原点更近时返回 true
    return *min_element(pts.begin(), pts.end(), [&](const pii& a, const pii& b) { return d2(a) < d2(b); });
}
# pts = 非空的点列表，每个点是 (x, y)。返回离原点最近的点；距离相同时返回先出现的那个。
def closest_to_origin(pts):
    d2 = lambda p: p[0] * p[0] + p[1] * p[1]   # d2(p) = 点 p 到原点距离的平方
    return min(pts, key=d2)              # min 遇到相等时保留先出现的，与 min_element 一致

多选 · 理解检查 1　int cnt = 0; 下面哪些 lambda 调用一次之后，外面的 cnt 会变成 1？

A. [&]() { ++cnt; }

B. [&cnt]() { ++cnt; }

C. [=]() { ++cnt; }

查看答案与每个选项的解析

A · 正确：[&] 按引用捕获用到的外部变量，改的就是外面的 cnt。

B · 正确：只按引用捕获 cnt，同样改到外面的变量。

C · 错误：[=] 拷贝一份 cnt，而且拷进来的变量默认只读，这一行直接编译报错。

D · 错误：mutable 允许修改，但改的是 lambda 内部那份副本，外面的 cnt 仍是 0。

易错点

  • 范围 for 想改元素却写成 auto x：能编译、不报错、结果不变。改元素用 auto&，只读大对象用 const auto&。
  • lambda 比较器里写 <= 或 >=：违反"严格弱序"（2.4 详讲），sort 可能越界崩溃。
  • 三目运算符放进 cout << a > b ? x : y 会先算 cout << a，必须写成 cout << (a > b ? x : y)。

小结： auto 得到副本，auto& 引用原对象，const auto& 只读地引用原对象；lambda 的 [&] 可以修改外部变量，[x] 只拷贝 x；比较器必须是严格的 <。

按条件删除：remove_if 加 erase

"删掉所有偶数"这种按条件删除的需求很常见。在下标循环里逐个 erase 有两个问题：每删一个，后面的元素都要整体前移一次，最坏 O(n²)；而且删除后下标对不上，容易漏删（练习 2.2-3）。标准写法是两个函数配合，叫 erase–remove 惯用法：

// remove_if 把要保留的元素挪到前面并返回保留部分的结尾；erase 删掉从那里到末尾的部分
v.erase(remove_if(v.begin(), v.end(), [](int x) { return x % 2 == 0; }), v.end());

remove_if(b, e, pred) 的第三个参数 pred 是一个返回 true 或 false 的函数（这里是 lambda），叫 谓词。pred 返回 true 表示"这个元素要删"。

这一行分两步完成：

  1. remove_if 从左到右扫一遍，把要保留的元素（pred 返回 false 的）依次挪到数组前部，然后返回"保留部分的结尾"这个位置。它只挪动元素，不改变 vector 的长度。
  2. erase(这个位置, v.end()) 把从这个位置到末尾的部分真正删掉。

以 v = {2, 4, 5, 6, 7} 为例：

v.erase(remove_if(..., 偶数), v.end())

1 / 3

第1步 · 原数组：要删的是 2、4、6

2 / 3

第2步 · remove_if 之后：保留的 5、7 挪到最前面，返回的位置 it 指向下标 2；size 仍是 5，后三格的值没有意义

3 / 3

第3步 · erase(it, v.end())：删掉 [it, end)，v = {5, 7}，size 为 2

整个过程每个元素只被看一次，是 O(n)。它和第 9 章的读写指针是同一个思路：一个位置负责"读"，一个位置负责"写下一个保留的元素"。2.4 节的 unique（去掉相邻重复）也是这样工作的，同样要配 erase。

定长数组：std::array 和 C 数组

长度在写代码时就确定、之后不再改变的数组，除了 vector，还有两种写法：C 语言留下来的 int a[5]，和 C++ 标准库的 std::array<int, 5>（头文件 <array>，using namespace std; 之后写成 array<int, 5>）。题解里 std::array 最常见的是三种用法：array<int, 26> cnt{} 统计 26 个字母出现的次数；vector<array<int, 3>> 存很多组"三个数"，比如图的边 {w, u, v}；priority_queue<array<int, 3>> 把三个数一起放进堆。

array<int, 5> a{};                 // 5 个 0；不写 {} 时，函数里的局部变量是随机值
array<int, 5> b = {3, 1, 2};       // 3 1 2 0 0：没写到的位置补 0
sort(b.begin(), b.end());          // 0 0 1 2 3：和 vector 一样用迭代器
b.fill(7);                         // 全部改成 7
int c[5] = {3, 1, 2};              // C 数组：3 1 2 0 0
sort(c, c + 5);                    // C 数组没有 begin()，用指针 c 和 c + 5 表示区间
sort(begin(c), end(c));            // 也可以用全局函数 begin(c)、end(c)

array 和 vector 的接口大部分相同：size()、[]、at()、front()、back()、begin()、end()、范围 for 都能用，algorithm 里的函数（sort、accumulate、count、find 等）也照常配合。区别有三点：

  • 长度是类型的一部分，必须是编译时就知道的常量。array<int, 5> 和 array<int, 6> 是两个不同的类型；int n; cin >> n; array<int, n> a; 编译不过，这时用 vector。
  • 没有 push_back、insert、erase、resize，长度永远不变。
  • 函数里的 array 放在栈上。栈是函数调用时临时分配的一块内存，通常只有几 MB，在函数里写 array<int, 10000000> 可能栈溢出；大数组用 vector，或者定义成全局变量。

和 C 数组相比，array 是一个完整的值：可以整体赋值 a = b，可以用 == 和 < 比较（< 按字典序，先比第 0 个，相等再比第 1 个），可以按值传给函数、从函数返回。C 数组做不到：a = b 编译不过；传给函数时会变成指向第一个元素的指针，函数里 sizeof(a) 得到的是指针的大小。题解写 vector<array<int, 3>> 而不写 vector<int[3]>，原因就在这里：vector 要求元素能拷贝和赋值，C 数组不行。

array 支持 <，所以 priority_queue<array<int, 3>, vector<array<int, 3>>, greater<array<int, 3>>> 能按第 0 个数从小到大出堆（相等时比第 1 个），array 也能当 map、set 的键；但标准库没有给 array 提供哈希函数，它不能直接当 unordered_map 的键，见 2.9。

哪些容器能用下标访问

[] 在不同容器里意思不同。在 vector、array、string、deque 和 C 数组里，[i] 表示"第 i 个位置"；在 map 和 unordered_map 里，m[k] 表示"键为 k 的那一项"，和位置无关，而且 k 不存在时会先插入一项默认值。其余容器没有 []。

容器能否用 [][] 的含义越界或不存在时安全的写法
vector、array、string、deque能第 i 个位置，O(1)不检查，是未定义行为at(i)，越界抛异常
C 数组 int a[n]能第 i 个位置，O(1)不检查，是未定义行为没有 at，自己先判断
map能键为 k 的值，O(log n)插入 k，值为默认值只查不插用 find、count；at(k) 不存在时抛异常
unordered_map能键为 k 的值，平均 O(1)插入 k，值为默认值同上
set、multiset、unordered_set不能——有序的 set 取第 k 小用 *next(s.begin(), k)，O(k)
list不能——只能用迭代器一个个走
stack、queue、priority_queue不能——只能看 top()，或 front()、back()

因为 m[k] 可能插入，const 的 map（例如参数写成 const map<int, int>& m）不能用 []，只能用 at 或 find。

拷贝：什么时候整份复制，怎样避免

STL 容器按值复制：vector<int> b = a; 会把 a 的元素全部复制一份，b 和 a 从此是两个独立的数组，改 b 不影响 a，复制本身是 O(n)。string、map、set 等所有容器都一样。这一点和 Python 正好相反：Python 的 b = a 只是让 b 指向同一个列表，要复制得写 a[:] 或 copy.deepcopy(a)。

嵌套的容器也整个复制：auto g2 = g; 复制一个 vector<vector<int>> 时，每一行都复制。但元素如果是指针（vector<Node*>、vector<TreeNode*>），复制的只是指针里的地址，两份 vector 指向的还是同一批节点，通过任何一份去改节点，另一份都看得到（见 9.3）。

需要复制时，几种写法的区别在于复制多少、放到哪里：

  • B b(a.begin(), a.end()) 和 b.assign(first, last) 复制一段区间（2.12）。
  • copy(first, last, dst.begin()) 写进 dst 已有的位置，dst 必须事先有足够的长度，否则越界。
  • copy(first, last, back_inserter(dst)) 逐个追加到 dst 末尾，不用事先开好大小。

不需要复制时：

  • a.swap(b) 交换两个容器的内容，只交换内部指针，O(1)。
  • b = std::move(a) 把 a 的内容"搬"给 b，不逐个复制元素；之后不要再读 a，它的内容不确定，只能重新赋值或销毁。
  • 函数返回局部的 vector 时直接 return v;，编译器会搬走而不是复制，不必为了省复制改成传引用的输出参数。

void removeEvens(vector<int>& v) {
    for (int i = 0; i < (int)v.size(); ++i)      // i = 当前检查的下标；按下标从左到右扫
        if (v[i] % 2 == 0) v.erase(v.begin() + i);   // 偶数就删掉下标 i 处的元素
}
提示

练习 2.2-4【改错】二维 DP 表只建了行 选做

题面：countPaths(m, n) 要算的是：网格有 m 行 n 列（m、n ≥ 1），从左上角的格子出发，每步只能向右或向下走一格，走到右下角的格子，一共有多少条不同的路线。countPaths(3, 3) 应为 6。下面的代码运行时崩溃。

样例 1：m = 3，n = 3，答案 6。一共要向右走 2 步、向下走 2 步，6 条路线是：右右下下、右下右下、右下下右、下右右下、下右下右、下下右右。

样例 2：m = 1，n = 5，答案 1。只有一行，只能一直向右走。

// 目标：m 行 n 列的网格（m、n >= 1），从左上角 (0, 0) 每步向右或向下走到右下角 (m-1, n-1)，
// 返回不同路径的条数。
int countPaths(int m, int n) {
    vector<vector<int>> dp(m);                   // dp[i][j]：走到 (i, j) 的路径数
    for (int i = 0; i < m; ++i)                  // i = 行号；逐行
        for (int j = 0; j < n; ++j)              // j = 列号；逐列
            // 第 0 行、第 0 列只有一条路；其余格子从上方或左方走来
            dp[i][j] = (i == 0 || j == 0) ? 1 : dp[i - 1][j] + dp[i][j - 1];
    return dp[m - 1][n - 1];                     // 右下角的路径数
}
提示

// 把 v 的第一个元素移到末尾，其余顺序不变；v 由调用者传入（会被修改），为空时什么也不做。无返回值。
void moveFirstToBack(vector<int>& v) {
    if (v.empty()) return;               // 空数组不能调用 front()，直接返回
    int first = v.front();               // 先记下第一个元素
    v.erase(v.begin());                  // 删掉它，后面的元素整体前移，O(n)
    v.push_back(first);                  // 放到末尾
}
# 把列表 v 的第一个元素移到末尾（原地修改），其余顺序不变；v 为空时什么也不做。无返回值。
def move_first_to_back(v):
    if not v:                            # 空列表什么也不做
        return
    v.append(v.pop(0))                   # pop(0) 和 erase(begin()) 一样是 O(n)

查看答案与每个选项的解析

A · 正确：圆括号里的 3 是个数，得到 3 个 0。

B · 错误：花括号是初始化列表，得到只有一个元素 3 的 vector，size() 是 1。

C · 正确：3 个 5。

D · 错误：reserve 只预留容量，size() 仍是 0。

易错点

  • insert/erase 的参数是迭代器 v.begin() + i，直接写下标 i 会编译报错；它们是 O(n)，放在循环里会变成 O(n²)。

  • 在空 vector 上调用 back()、front()、pop_back() 是未定义行为，调用前先判断 !v.empty()。

速查表里"字符分类"和"大小写"两行的函数来自头文件 <cctype>，每个函数接收一个字符，回答它属于哪一类：

使用时有三个细节。

第一，判断函数返回的是 int：0 表示"不是"，其他任何值都表示"是"，但不一定是 1。在 GCC 上 isalpha('a') 返回 1024，isspace('\n') 返回 8192。所以写 if (isalpha(c)) 是对的，写 if (isalpha(c) == true) 是错的：true 转成整数是 1，1024 不等于 1，条件不成立。

第二，toupper、tolower 返回的也是 int。直接 cout << tolower('A') 会打印 97，存回字符要写 (char)tolower(c)。

第三，参数最好先转成 unsigned char，写成 isalnum((unsigned char)c)。原因是：char 在 GCC 等常见编译器上是 有符号 的，能表示 −128～127。英文字母、数字、标点的编码都在 0～127 之间，没有问题；但 string 里的中文按 UTF-8 存储，每个汉字占 3 个字节，每个字节的值都大于 127，存进 char 就变成了负数，例如"中"的三个字节读出来是 −28、−72、−83。

这些函数只接受 0～255（以及表示文件结束的 EOF，即 −1），传入其他负数是未定义行为，可能返回错误结果，也可能直接崩溃。转成 unsigned char 后，−28 变回 228，落在合法范围内。只处理英文的题目里不转也不会出错，但转一下是更安全的习惯；写 lambda 时也可以直接把参数声明成 unsigned char，例如 [](unsigned char c) { return isdigit(c) != 0; }。

全部替换（replaceAll）。 用 find 找到一处 from，用 replace(pos, from.size(), to) 换掉，再接着找下一处。关键在"接着从哪里找"：要从换进去的 to 后面 找，也就是 pos + to.size()。如果还从 pos 找，当 to 里面本身含有 from 时（例如把 "a" 换成 "aa"），会一直找到刚换进去的 a，永远停不下来。from 为空串时 find 每次都返回原位置，同样会死循环，所以先排除。

// 去掉 s 两端的空白（空格、制表符、换行），返回新串；全是空白时返回空串，中间的空白保留。
string trim(const string& s) {
    const string ws = " \t\n\r";                       // ws = 算作空白的字符集合
    size_t l = s.find_first_not_of(ws);                // l = 第一个非空白字符的下标
    if (l == string::npos) return "";                  // 一个非空白字符都没有
    size_t r = s.find_last_not_of(ws);                 // r = 最后一个非空白字符的下标
    return s.substr(l, r - l + 1);                     // 取 [l, r]，长度是 r - l + 1
}

// 按分隔串 sep（可以多于一个字符，不能为空）把 s 切开，返回各段。
// 两个相邻的 sep 之间、以及最后一个 sep 之后，都会得到一段（可能是空串）；空串 s 返回一个空段。
vector<string> splitStr(const string& s, const string& sep) {
    vector<string> parts;                              // parts = 切出来的各段
    size_t start = 0;                                  // start = 当前这一段的起点
    size_t pos = s.find(sep);                          // pos = 下一个 sep 的位置
    while (pos != string::npos) {                      // 每找到一个 sep，就切下它前面的一段
        parts.push_back(s.substr(start, pos - start)); // [start, pos) 这一段
        start = pos + sep.size();                      // 下一段从 sep 后面开始
        pos = s.find(sep, start);                      // 从 start 往后找下一个 sep
    }
    parts.push_back(s.substr(start));                  // 最后一个 sep 之后剩下的部分
    return parts;
}

// 把 s 里所有（互不重叠的）from 换成 to，原地修改；from 为空时什么也不做。
void replaceAll(string& s, const string& from, const string& to) {
    if (from.empty()) return;                          // 空串到处都能"找到"，会死循环
    size_t pos = s.find(from);                         // pos = 下一处 from 的位置
    while (pos != string::npos) {
        s.replace(pos, from.size(), to);               // 从 pos 起的 from.size() 个字符换成 to
        pos = s.find(from, pos + to.size());           // 从换进去的 to 后面接着找
    }
}
# Python 的 str 自带这三个操作，行为和上面的 C++ 版本一致。
def trim_ws(s):
    return s.strip(" \t\n\r")                        # 去掉两端的这些字符；不传参数时去掉所有空白
def split_str(s, sep):
    return s.split(sep)                               # 按 sep 切开，空段都保留
def replace_all(s, a, b):
    return s.replace(a, b)                            # 字符串不可变，返回替换后的新串

例子：trim(" a,b ") 得 "a,b"；splitStr("a, b, , c", ", ") 得 ["a", "b", "", "c"]；把 "banana" 里的 "a" 全换成 "o" 得 "bonono"；把 "aaa" 里的 "a" 全换成 "aa" 得 "aaaaaa"。

练习 2.3-4【函数】按指定字符分割 必做

题面：给字符串 s 和一个分隔字符 sep，在每个 sep 处把 s 切开，返回切出来的各段（不含 sep 本身）。两个 sep 紧挨着时，它们之间切出一个空串 ""，要保留；但 s 最后一个 sep 后面如果什么也没有，不算一段。s 为空串时返回空数组。

样例 1：splitBy("a,,b", ',')，答案 {"a", "", "b"}。第一个逗号前是 "a"；两个逗号之间什么也没有，是空串 ""；第二个逗号后是 "b"。

样例 2：splitBy("x,y,", ',')，答案 {"x", "y"}。最后一个逗号后面已经到了末尾，不再算一段。

样例 3：splitBy("", ',')，答案 {}（空数组）。s 里没有任何字符。

提示

getline(ss, part, sep) 每次读到下一个 sep 为止（不含 sep）。它在流结束时读不到任何字符就返回 false，所以末尾的空段不会出现；Python 的 split 会保留末尾空段，写 Python 版时要手动去掉。

参考答案
// 把 s 按字符 sep 分割成若干段（s 只读）。返回各段组成的数组，中间的空段保留，末尾的空段不出现；
// s 为空时返回空数组。
vector<string> splitBy(const string& s, char sep) {
    vector<string> parts;                // 分割出的每一段
    stringstream ss(s);                  // 把 s 当作输入流
    string part;                         // part = 每次读出的一段
    while (getline(ss, part, sep)) parts.push_back(part);   // 每次读到下一个 sep 为止（不含 sep）；读不到就停
    return parts;                        // 按顺序排列的各段
}
# 把 s 按字符 sep 分割成若干段。返回各段组成的列表，中间的空段保留，末尾的空段去掉；s 为空时返回 []。
def split_by(s, sep):
    parts = s.split(sep)                 # 按 sep 切开，空段都保留
    if parts and parts[-1] == "":        # C++ 的 getline 不会产生最后那个空段；空串也得到空列表
        parts.pop()                      # 去掉末尾的空段
    return parts                         # 按顺序排列的各段

练习 2.3-5【函数】宽松回文 选做

题面：回文是正着读和倒着读完全一样的字符串，例如 "abba"。这里的"宽松回文"只看字母和数字，空格、标点等其他字符全部忽略，并且不区分大小写。s 是宽松回文就返回 true，否则返回 false。

样例 1："A man, a plan, a canal: Panama"，答案 true。去掉空格和标点、全部转成小写后是 "amanaplanacanalpanama"，倒着读也一样。

样例 2："race a car"，答案 false。处理后是 "raceacar"，倒着读是 "racaecar"，不一样。

样例 3：".,"，答案 true。没有字母和数字，处理后是空串，空串正着读和倒着读一样。

提示

先过滤：isalnum 判断字母数字，tolower 转小写，拼成新串 t；再比较 t 和它的反转 string(t.rbegin(), t.rend())。字符传给 isalnum 前转成 unsigned char，避免负值字符出问题。

参考答案
// 宽松回文：s 是任意字符串（只读）。只看字母和数字、忽略大小写时是回文就返回 true，否则返回 false。
bool isLoosePalindrome(const string& s) {
    string t;                            // 只留字母数字、并转成小写后的串
    for (char c : s)                     // c = s 的每个字符
        if (isalnum((unsigned char)c)) t += (char)tolower((unsigned char)c);   // 先转 unsigned char 再判断、转小写
    return t == string(t.rbegin(), t.rend());   // 用反向迭代器构造 t 的反转，与 t 相同就是回文
}
# 宽松回文：s 是任意字符串。只看字母和数字、忽略大小写时是回文就返回 True，否则返回 False。
def is_loose_palindrome(s):
    t = "".join(c.lower() for c in s if c.isalnum())   # 只留字母数字，并转成小写
    return t == t[::-1]                  # 与反转相同就是回文

练习 2.3-6【改错】stoi 读大数抛异常 选做

题面：一行字符串里有若干个用空格隔开的整数（可以是负数），每个最多 18 位，求它们的和。输入 "12345678901 1" 时程序因异常 std::out_of_range 退出。

样例 1："12345678901 1"，改对后答案 12345678902。两个数是 12345678901 和 1。

样例 2：" -5 7 "，答案 2。多余的空格不影响，两个数是 −5 和 7。

// line = 一行用空格分隔的整数（每个最多 18 位，只读）。返回这些整数的和；line 里没有数时返回 0。
long long sumBigTokens(const string& line) {
    stringstream ss(line);               // 把这一行当输入流
    string tok;                          // 每次读到的一个数字串
    long long sum = 0;                   // 总和
    while (ss >> tok) sum += stoi(tok);  // 按空白逐个读出，转成整数加进总和
    return sum;                          // 所有整数之和
}
提示

stoi 返回 int，数值超过 2147483647 就抛 out_of_range。用 stoll 读成 long long。

参考答案
// line = 一行用空格分隔的整数（每个最多 18 位，只读）。返回这些整数的和；line 里没有数时返回 0。
long long sumBigTokens(const string& line) {

    string tok;                          // 每次读到的一个数字串
    long long sum = 0;                   // 总和
    while (ss >> tok) sum += stoll(tok); // 修正：stoll 返回 long long，18 位数字也装得下
    return sum;                          // 所有整数之和
}

def sum_big_tokens(line):

易错点

  • substr(pos, len) 的第二个参数是长度；pos 大于 size() 时抛 out_of_range，等于 size() 时返回空串。
  • find 的返回值存进 int 再和 −1 比较能工作，但写 if (s.find(t)) 是错的：找到在下标 0 时结果为 0，被当成"假"。
  • 循环里 res = res + c 每次都复制整串，n = 10⁵ 时就会超时；用 res += c 或 push_back。

小结： substr 的参数是起点和长度；查找失败返回 npos；大整数用 stoll 转换；按空白切分单词用 stringstream >>，按逗号切分用 getline(ss, part, ',')；拼接用 +=。
