3.1 机器学习三要素：模型、策略、算法

面试官问"讲讲逻辑回归"或"讲讲 SVM"，最稳的回答框架是三句话：它假设数据长什么样（模型），用什么标准判断一组参数好不好（策略），怎样把最好的参数找出来（算法）。这三件事合称机器学习的三要素，国内教材（李航《统计学习方法》）就是这样组织的。掌握这个框架，后面每个模型都能放进同一张表里比较。[2]

  • 模型：一族候选函数，也叫假设空间。线性回归的模型是"所有形如 ŷ = w·x + b 的直线"，决策树的模型是"所有可能的 if-else 树"。
  • 策略：挑选标准，写成要最小化的目标。常见写法是经验风险（训练集上的平均损失，如平方误差、交叉熵）加上正则项，两者之和叫结构风险：结构风险 = 平均损失 + λ·模型复杂度。
  • 算法：求解目标的具体计算方法，例如直接解方程（闭式解）、梯度下降、贪心地逐层分裂、坐标上升。

三要素：模型给出候选范围，策略定义好坏，算法负责求解；超参数在训练开始前由人设定

参数与超参数是最常考的一对概念。** 参数**由训练算法从数据里学出来，例如线性回归的 w 和 b；超参数在训练开始前由人设定，训练过程本身不改它，例如正则强度 λ、KNN 的 K、学习率、树的最大深度。超参数的取值靠验证集或交叉验证挑选（3.17）。

要点：

  • 统计学习三要素是模型、策略、算法。
  • 结构风险最小化 = 经验风险 + 正则项，正则项用来惩罚复杂模型、防止过拟合。
  • 参数从数据中学习得到，超参数在训练前人为设定，通过验证集或交叉验证选择。

小结： 机器学习方法由模型、策略、算法三要素组成；参数从数据中学习，超参数由人设定，并通过验证集选择。

3.2 线性回归：最小二乘、闭式解与梯度下降

银行想估计"多投 1 万元广告，理财销售额能多多少"。手上有 4 个月的数据，我们想找一条直线最贴近这些点，用它做预测。这就是线性回归：模型 ŷ = w·x + b，w 是斜率（权重），b 是截距（偏置）。

策略：最小二乘。 每个点的预测误差（残差）是 y − ŷ。把所有残差平方后相加，叫残差平方和（SSE）；让 SSE 最小的 w、b 就是最小二乘解。平方的作用有两个：正负误差不会互相抵消；目标函数是一个光滑的"碗"，求导就能找到碗底。

一元情形的闭式解（直接套公式算出，不用迭代）：

  • w = Σ(x − x̄)(y − ȳ) / Σ(x − x̄)²
  • b = ȳ − w·x̄

其中 x̄、ȳ 是平均值。多元情形把每个样本写成一行、在最前面补一列 1，得到矩阵 X，闭式解是正规方程 w = (XᵀX)⁻¹Xᵀy，要求 XᵀX 可逆。[4]

逐步执行过程

数据：广告投入 x = [1, 2, 3, 4]（万元），销售额 y = [3, 5, 6, 8]（万元）。

  1. 均值：x̄ = 2.5，ȳ = 5.5。
  2. 分子 Σ(x − x̄)(y − ȳ) = (−1.5)(−2.5) + (−0.5)(−0.5) + (0.5)(0.5) + (1.5)(2.5) = 8；分母 Σ(x − x̄)² = 2.25 + 0.25 + 0.25 + 2.25 = 5。
  3. w = 8 / 5 = 1.6，b = 5.5 − 1.6×2.5 = 1.5。模型 ŷ = 1.6x + 1.5：每多投 1 万元，销售额平均多 1.6 万元。
  4. 预测值 [3.1, 4.7, 6.3, 7.9]，残差 [−0.1, 0.3, −0.3, 0.1]，SSE = 0.2，MSE（均方误差，SSE 除以 n）= 0.05。

用正规方程核对：XᵀX = [[4, 10], [10, 30]]（4 = 样本数，10 = Σx，30 = Σx²），Xᵀy = [22, 63]。行列式 4×30 − 10×10 = 20，解得 b = (30×22 − 10×63)/20 = 1.5，w = (4×63 − 10×22)/20 = 1.6，与上面一致。

最小二乘直线穿过点群中间，四个残差 −0.1、0.3、−0.3、0.1 的平方和为 0.2

梯度下降：不解方程，一步步走到碗底

特征上万维时，求 (XᵀX)⁻¹ 的代价约为 d³ 次运算，内存也放不下；数据源源不断时也没法一次性解方程。这时改用梯度下降：从任意起点出发，每步沿损失下降最快的方向（负梯度）走一小段。对 MSE = (1/n)Σ(w·x + b − y)²：

  • ∂MSE/∂w = (2/n)Σ(w·x + b − y)·x
  • ∂MSE/∂b = (2/n)Σ(w·x + b − y)
  • 更新：w ← w − η·∂MSE/∂w，b ← b − η·∂MSE/∂b，η 是学习率（超参数）。

变量表：w, b 当前参数；xs, ys 训练数据；lr 学习率 η；gw, gb 两个偏导数。

def gd_step(w, b, xs, ys, lr):
    """对 MSE = (1/n)Σ(w·x+b−y)² 做一步梯度下降，返回 (新 w, 新 b)。"""
    n = len(xs)
    gw = sum(2 * (w * x + b - y) * x for x, y in zip(xs, ys)) / n
    gb = sum(2 * (w * x + b - y) for x, y in zip(xs, ys)) / n
    return w - lr * gw, b - lr * gb

手工模拟第一步：w = b = 0 时预测全是 0，误差 w·x + b − y 就是 −y。∂w = (2/4)×(−3×1 − 5×2 − 6×3 − 8×4) = 0.5×(−63) = −31.5，∂b = 0.5×(−22) = −11。取 η = 0.05：w = 0 + 0.05×31.5 = 1.575，b = 0 + 0.05×11 = 0.55，MSE 从 33.5 降到 1.076。继续迭代，w、b 最终收敛到闭式解 1.6 和 1.5。

第一步就把 MSE 从 33.5 降到 1.08，之后沿着碗底缓慢逼近最小值 0.05

学习率太大会发散：这份数据上 η 超过约 0.12，每一步都冲过碗底、越冲越远；取 η = 0.13 时 MSE 依次变成 45.9、62.8、86.1……。特征量纲差别很大时，碗会变成狭长的山谷，梯度下降来回震荡，所以训练前常做标准化（第 4 章）。

要点：

  • 最小二乘 = 最小化残差平方和；一元闭式解 w = Σ(x − x̄)(y − ȳ)/Σ(x − x̄)²，b = ȳ − w·x̄。
  • 正规方程 w = (XᵀX)⁻¹Xᵀy，计算量约 O(d³)，适合特征不多的情形；特征多、数据量大时用梯度下降。
  • 线性回归的"线性"指对参数线性；把 x²、log x 当作新特征，模型仍是线性回归。

单选 · 理解检查 2　数据 x = [1, 2, 3, 4]、y = [3, 5, 6, 8]，从 w = b = 0 出发、学习率 0.05 对 MSE 做一步梯度下降，结果是？

A. w = 1.575，b = 0.55

B. w = 1.6，b = 1.5

C. w = 3.15，b = 1.1

D. w = −1.575，b = −0.55

查看答案与每个选项的解析

A · 正确：∂w = (2/4)×(−63) = −31.5，∂b = (2/4)×(−22) = −11，各乘 0.05 后取反加到 0 上。

B · 错误：这是闭式解（碗底），一步梯度下降只走了一小段。

C · 错误：忘了 MSE 里除以 n：(2/n) 中的 n = 4。

D · 错误：更新是减去学习率乘梯度，梯度为负时参数增大。

易错点：

  • XᵀX 不可逆（特征之间完全共线，或特征数多于样本数）时正规方程无解，加 L2 正则后 XᵀX + λI 一定可逆，见 3.3。
  • 平方误差对离群点敏感：一个离谱的点会把直线拉过去，需要先处理异常值或改用对离群点更稳健的损失。

小结： 线性回归采用最小二乘策略；数据量小时用闭式解，数据量大时用梯度下降；学习率太大会导致发散。

3.3 正则化：Ridge、Lasso 与 L1 为什么能产生稀疏解

风控模型常有上百个候选特征，其中很多只是噪声。我们希望模型既拟合得好，又能自动"关掉"没用的特征，让剩下的少数特征好解释。办法是在目标函数里加一项惩罚权重大小的正则项：

  • Ridge（岭回归，L2 正则）：J(w) = ½Σ(y − ŷ)² + (λ/2)·Σw²
  • Lasso（L1 正则）：J(w) = ½Σ(y − ŷ)² + λ·Σ|w|

λ ≥ 0 是正则强度。λ = 0 退化为普通最小二乘；λ 越大，权重被压得越小。两者把权重往 0 拉的方式不同，效果也不同：L2 让所有权重按比例缩小；L1 能把一部分权重精确地压到 0，相当于自动做特征选择，这种"很多分量恰好是 0"的解叫稀疏解。[5] [4]

逐步执行：同一份数据，两条正则化路径

沿用 3.2 的数据，先把 x、y 各减去均值（中心化，这样不用管 b），记 Sxx = Σ(x − x̄)² = 5，Sxy = Σ(x − x̄)(y − ȳ) = 8。一元情形下两个目标都能直接求出最优 w：

  • Ridge：对 J 求导令其为 0，−Sxy + Sxx·w + λw = 0，得 w = Sxy / (Sxx + λ) = 8 / (5 + λ)。
  • Lasso：w = max(Sxy − λ, 0) / Sxx = max(8 − λ, 0) / 5（Sxy > 0 时）。分子这一步叫软阈值：先减去 λ，减过头就停在 0。

为什么 L1 会精确到 0：次梯度直观

看 w = 0 这一点。数据项 ½Σ(y − wx)² 在 w = 0 处的导数是 −Sxy = −8，意思是"往正方向走能让误差下降，下降速度是 8"。

  • L2 罚项 (λ/2)w² 在 w = 0 处导数为 0，越靠近 0 惩罚的"阻力"越小。数据项那股 8 的推力没有东西抵消，最优点一定离开 0，所以 Ridge 的权重只会变小、到不了 0。
  • L1 罚项 λ|w| 在 w = 0 处有一个尖角，左导数 −λ、右导数 +λ；尖角处的"导数"可以取 [−λ, λ] 之间任何值，这个区间叫次梯度。只要 λ ≥ 8，就能在区间里找到 +8 正好抵消数据项的 −8，总的次梯度包含 0，w = 0 就是最优点。

一句话：L1 在 0 点有一股大小为 λ 的固定阻力，推力小于阻力的特征就停在 0；L2 在 0 点的阻力是 0，所有特征都会被推离 0。

几何直观：菱形的角落在坐标轴上

把正则写成约束形式：Lasso 等价于在 |w1| + |w2| ≤ t 的范围内最小化误差，这个范围在平面上是一个菱形；Ridge 对应 w1² + w2² ≤ t²，是一个圆。误差的等高线从无约束最优点 ŵ 向外扩张，第一次碰到约束区域的点就是解。菱形的四个角都在坐标轴上，等高线最容易先碰到角，于是某个坐标恰好为 0；圆没有角，碰到的位置通常两个坐标都不为 0。

用一个具体例子核对：设无约束最优点 ŵ = (2, 0.5)，误差等高线是以 ŵ 为圆心的圆，预算 t = 1。在菱形上离 ŵ 最近的点是角 A = (1, 0)，w2 被压成 0；在圆上离 ŵ 最近的点是 B = ŵ / |ŵ| = (0.970, 0.243)，两个分量都还在。

实线菱形是 |w1|+|w2| ≤ 1，圆点组成的圆是 w1²+w2² ≤ 1。L1 解是菱形的角 A = (1, 0)，w2 = 0；L2 解是圆上的点 B = (0.97, 0.24)，两个分量都不为 0

要点：

  • L1 正则（Lasso）产生稀疏解，可用于特征选择；L2 正则（Ridge）让权重整体变小、更平滑，并缓解特征共线性。
  • L1 稀疏的原因：几何上菱形约束的角在坐标轴上；代数上 |w| 在 0 点不可导，次梯度区间 [−λ, λ] 能抵消数据项的推力。
  • 两者结合叫弹性网（Elastic Net）：既稀疏，又能在一组高度相关的特征里保留多个。
  • 从概率角度看，L2 相当于给权重加高斯先验，L1 相当于加拉普拉斯先验。

单选 · 理解检查 3　沿用本节一元例子（Sxx = 5，Sxy = 8）。λ = 6 时 Ridge 和 Lasso 的最优 w 分别约是？

A. Ridge ≈ 0.727，Lasso = 0.4

B. Ridge = 0.4，Lasso ≈ 0.727

C. 两者都等于 0

D. Ridge = 0，Lasso = 0.4

查看答案与每个选项的解析

A · 正确：Ridge：8/(5+6) = 0.727；Lasso：(8−6)/5 = 0.4。

B · 错误：两个公式对调了：减 λ 再除以 Sxx 的是 Lasso（软阈值）。

C · 错误：Lasso 要到 λ ≥ Sxy = 8 才变成 0；Ridge 对任何有限 λ 都大于 0。

D · 错误：Ridge 的 8/(5+λ) 永远是正数，L2 不会把权重精确压到 0。

易错点：

  • 正则项一般不惩罚偏置 b，惩罚 b 会让模型整体平移，没有防过拟合的作用。
  • 加正则之前要先把特征标准化，否则量纲大的特征权重天然小，受到的惩罚不公平。

小结： L2 正则化按比例缩小权重，但不会缩到 0；L1 正则化相当于软阈值，绝对值小于 λ 的权重直接归零，几何上是因为菱形的约束区域有角，而圆形没有角。

3.4 逻辑回归：sigmoid、交叉熵与多分类

反欺诈要回答的是"这笔交易是欺诈吗"，输出应是 0 到 1 之间的概率，再按阈值决定拦不拦。线性回归的输出可以是任意实数，不适合直接当概率。逻辑回归在线性打分外面套一个 sigmoid 函数，把任意实数压进 (0, 1)：

  • 打分：z = w·x + b
  • 概率：p = σ(z) = 1 / (1 + e^(−z))，表示"属于正类（欺诈）的概率"
  • 判别：p ≥ 0.5 等价于 z ≥ 0，所以决策边界 w·x + b = 0 是一条直线（高维时是超平面）

几个值要记住：σ(0) = 0.5；σ(2) ≈ 0.881，σ(−2) ≈ 0.119；z = ln 9 ≈ 2.197 时 p = 0.9。[4]

sigmoid 把任意实数压到 (0,1)：z 越大越接近 1，越小越接近 0

策略：交叉熵损失

单个样本的交叉熵损失（也叫对数损失）：L = −[y·ln p + (1 − y)·ln(1 − p)]，y 是真实标签 0 或 1。直观意思是"给真实答案分配的概率越低，罚得越重"：

真实 y预测 p损失
10.9−ln 0.9 ≈ 0.105
10.5−ln 0.5 ≈ 0.693
10.1−ln 0.1 ≈ 2.303
00.9−ln 0.1 ≈ 2.303

为什么用交叉熵而不用 MSE：交叉熵正是"标签服从伯努利分布"时的负对数似然，最小化它就是做极大似然估计；而且它对 w 是凸函数，梯度形式非常简单。sigmoid 配 MSE 得到的目标是非凸的，p 接近 0 或 1 时梯度几乎消失，学得很慢。

算法：梯度下降，梯度只有一行

链式法则算下来，∂L/∂z = p − y，所以 ∂L/∂w = (p − y)·x，∂L/∂b = p − y。"预测减真实，再乘输入"，和线性回归的形式一样。

完整走一遍：一个样本 x = (1, 2)，y = 1，从 w = (0, 0)、b = 0 出发，学习率 0.1。

  1. z = 0，p = 0.5，损失 0.693。
  2. p − y = −0.5，梯度 ∂w = (−0.5, −1.0)，∂b = −0.5。
  3. 更新：w = (0.05, 0.1)，b = 0.05。
  4. 新的 z = 0.05×1 + 0.1×2 + 0.05 = 0.3，p = σ(0.3) ≈ 0.574，损失降到 0.554。

多分类：softmax 与 OvR

K 个类别时有两种做法：

  • softmax 回归：每一类有一个打分 zₖ，概率 pₖ = e^(zₖ) / Σⱼ e^(zⱼ)，K 个概率之和为 1，损失是 −ln p_真实类。例如打分 [2, 1, 0] 对应的概率为 [0.665, 0.245, 0.090]；真实类是第一类时，损失为 −ln 0.665 ≈ 0.408。

OvR：3 个类别训练 3 个二分类器，各自给出"是这一类"的得分，取最高者（得分为示意）

要点：

  • 逻辑回归是分类模型：线性打分 + sigmoid，输出正类概率；决策边界 w·x + b = 0 是线性的。
  • 损失用交叉熵（负对数似然），等价于极大似然估计；梯度 ∂L/∂w = (p − y)x。
  • 多分类用 softmax 或 OvR / OvO。逻辑回归可解释性强（每个权重对应一个特征的影响方向），银行评分卡的核心就是它（第 4 章）。

3.5 KNN：用最近的邻居投票

来了一笔新交易，想判断是否可疑。最朴素的想法是：翻出历史上和它最像的几笔交易，看它们大多是什么标签。这就是 K 近邻（KNN）：预测时找出训练集中离新样本最近的 K 个样本，分类取多数票，回归取平均值。[6]

KNN 没有显式的训练过程，"训练"就是把数据存起来，计算全部推迟到预测时，所以叫惰性学习。三个要素决定它的结果：K 的大小、距离怎么算（常用欧氏距离）、投票规则（等权或按距离加权）。

  • K 小：只看最近的一两个邻居，容易被噪声点带偏（方差大、过拟合）。
  • K 大：看的邻居多，边界被抹平（偏差大、欠拟合）；K 等于样本总数时永远预测多数类。
  • 预测一个样本要和全部 n 个训练样本算距离，朴素实现每次 O(n·d)。kd 树、球树能在低维时加速。

逐步执行：量纲会改变邻居

两个特征：近一小时交易笔数、单笔金额（元）。训练集 4 笔：A(2, 5150) 正常，B(5, 4850) 正常，C(20, 5300) 可疑，D(21, 4700) 可疑。新交易 Q(19, 5000)，K = 3。

  1. 直接计算欧氏距离：Q 到 A 的距离是 √(17² + 150²) ≈ 151.0，到 B 约为 150.7，到 C、D 都约为 300.0。金额的差距有几百，笔数的差距只有十几，距离几乎完全由金额决定。最近的 3 个邻居是 B、A、C，其中 2 票为正常，所以判为正常。

一小时 19 笔交易显然很反常，缩放后的结论更合理。KNN 的距离直接受特征量纲影响，用之前要把特征缩放到可比的范围（标准化或 min-max，第 4 章）。

缩放后的特征空间（横轴笔数、纵轴金额，都在 [0, 1] 内，按真实坐标画）：Q 的 3 个最近邻是 C、D、B，2 票可疑；边上数字是距离

KNN 与 K-means：名字像，任务完全不同

对比项KNNK-means

  • K 越小模型越复杂、越容易过拟合；K 越大越平滑、越容易欠拟合。K 通常取奇数，避免二分类平票。
  • KNN 的距离受特征量纲影响，使用前要标准化；维度很高时距离区分度下降（维度灾难，3.15）。

3.6 决策树：ID3、C4.5、CART 在同一份数据上

信用卡审批员的判断过程常常是一串问题："收入低吗？征信好吗？有房吗？"决策树把这个过程从数据中学出来：每个内部节点问一个特征，每条分支对应一个答案，叶子给出预测。训练要解决的核心问题只有一个——每个节点该问哪个特征。答案是：选能让分支后的样本"最纯"的那个。三种经典算法的区别就在"纯"怎么度量。[7] [8]

三种度量（熵的定义见第 2 章，这里以 2 为底）：

  • 信息熵 H(D) = −Σ pₖ·log₂ pₖ，pₖ 是第 k 类的比例。全是一类时 H = 0；两类各半时 H = 1。
  • 信息增益（ID3 用）= H(D) − Σ (|Dᵥ|/|D|)·H(Dᵥ)：父节点的熵减去按特征取值分组后的加权熵，越大越好。
  • 增益率（C4.5 用）= 信息增益 / 分裂信息，分裂信息 = 特征自身取值分布的熵 −Σ (|Dᵥ|/|D|)·log₂(|Dᵥ|/|D|)。取值越多，分裂信息越大，用来惩罚 ID3 对多取值特征的偏爱。
  • 基尼指数（CART 用）Gini(D) = 1 − Σ pₖ²，表示随机抽两个样本类别不同的概率。CART 只做二叉划分，选加权基尼最小的"特征 = 某值 vs 其余"。

def entropy(labels):
    """以 2 为底的信息熵 H = −Σ p·log2 p。"""
    n = len(labels)
    return -sum(labels.count(c) / n * math.log2(labels.count(c) / n) for c in set(labels))

def split_by(rows, j):
    groups = {}
    for r in rows:
        groups.setdefault(r[j], []).append(r)
    return groups

def info_gain(rows, j):
    """信息增益 = 父节点熵 − 按特征 j 划分后的加权熵。"""
    labels = [r[-1] for r in rows]
    cond = sum(len(g) / len(rows) * entropy([r[-1] for r in g]) for g in split_by(rows, j).values())
    return entropy(labels) - cond

def gain_ratio(rows, j):
    """C4.5 增益率 = 信息增益 / 分裂信息（特征 j 自身取值分布的熵）。"""
    split_info = entropy([r[j] for r in rows])
    return info_gain(rows, j) / split_info

3.7 剪枝与回归树

3.6 的 ID3 树把训练集分得很干净，每片叶子都纯。可是中收入分支只有 3 个人，凭"有没有房"再分一次，很可能是在记噪声。树越深，越能记住训练集的偶然细节，在新数据上越差，这就是过拟合。剪枝用来控制树的复杂度。

  • 预剪枝：生长时提前停下。常用条件有最大深度、叶子最少样本数、划分带来的增益低于阈值。优点是快；缺点是可能停得太早（当前划分增益小，下一层却很有用）。
  • 后剪枝：先长成完整的树，再自底向上考察每个内部节点：把它的子树换成一个叶子（取多数类），若验证集上的准确率不降，就剪掉。比预剪枝更不容易欠拟合，代价是训练更慢。

3.8 Bagging 与随机森林

单棵决策树很不稳定：训练集里换掉两三个样本，根节点就可能从"收入"变成"征信"，整棵树面目全非。这种"对训练数据很敏感"的毛病叫方差大。降低方差最直接的办法是多训练几个模型取平均：每个模型的偶然误差方向不同，平均后互相抵消。问题是只有一份训练集，怎样得到"多个不同的训练集"？

Bagging（Bootstrap Aggregating）的做法：从 n 个样本中有放回地抽 n 次，得到一个和原数据一样大的"自助样本集"；重复 B 次得到 B 个训练集，各训练一个模型；分类时投票，回归时取平均。B 个模型互不依赖，可以并行训练。[9] [10]

Bagging：每棵树看到一份有放回抽样得到的数据，彼此独立训练，最后投票（分类）或平均（回归）

逐步执行：一次自助抽样和袋外样本

10 个样本编号 1–10，有放回抽 10 次，得到 [2, 5, 5, 1, 9, 3, 3, 7, 10, 2]。

绿色 7 个编号被抽中（2、3、5 各抽中两次）；橙色 4、6、8 一次也没抽到，是这棵树的袋外样本

  1. 抽中的不同编号有 7 个：{1, 2, 3, 5, 7, 9, 10}；2、3、5 各出现两次。
  2. 没被抽到的 {4, 6, 8} 叫这棵树的袋外样本（OOB，out-of-bag）。
  3. 一个样本一次都没被抽中的概率是 (1 − 1/n)ⁿ：n = 10 时为 0.349，n = 100 时为 0.366，n 趋于无穷时趋于 1/e ≈ 0.368。所以每棵树大约有 36.8% 的样本没见过，约 63.2% 的样本被用于训练。
  4. OOB 估计：对每个样本，只让"没见过它"的那些树投票，统计这种预测的准确率。它相当于免费的验证集，不必另外留出数据。

随机森林：再加一层特征随机

取平均能把方差降多少，取决于模型之间有多相关。B 个方差为 σ²、两两相关系数为 ρ 的模型取平均，方差是 ρσ² + (1 − ρ)σ²/B。σ² = 1、B = 100 时：ρ = 0 降到 0.01；ρ = 0.3 只能降到 0.307，再多加树也低不过 ρσ² = 0.3。

自助样本之间重合度很高，长出来的树都爱选同一个强特征当根节点，彼此高度相关。随机森林在 Bagging 之外加了一步：每个节点分裂时，只从随机抽取的 m 个特征里挑最好的划分。分类常取 m = √d（d = 16 时 m = 4），回归常取 d/3。强特征有时不在候选里，其他特征就有机会上场，树与树之间的相关性 ρ 降下来，平均后的方差随之下降。

要点：

  • Bagging：有放回抽样 + 并行训练 + 投票/平均，主要降低方差，适合方差大的基模型（深度不限的决策树）。
  • 随机森林 = Bagging + 节点分裂时的随机特征子集，进一步降低树之间的相关性。
  • 每棵树约有 36.8% 的袋外样本，可用 OOB 误差代替交叉验证评估模型。
  • 随机森林能给出特征重要性；不需要特征缩放；对缺失值和异常值相对稳健。

3.9 AdaBoost：每轮加重分错样本的权重

Bagging 的每个模型平起平坐。换一个思路：先训练一个很弱的模型，看它在哪些样本上犯错，下一个模型专门去补这些错，一轮接一轮，这就是 Boosting。AdaBoost 是最早的 Boosting 算法，它让下一个模型"关注错题"的手段是调整样本权重。[11] [9]

每一轮 m 做四件事：

  1. 用当前样本权重 wᵢ 训练一个弱分类器 Gₘ（常用只切一刀的决策树桩），使加权错误率 eₘ = Σ(分错样本的 wᵢ) 最小。
  2. 算这个分类器的话语权 αₘ = ½·ln((1 − eₘ)/eₘ)。错误率越低，α 越大；eₘ = 0.5（相当于瞎猜）时 α = 0。
  3. 更新权重：wᵢ ← wᵢ·exp(−αₘ·yᵢ·Gₘ(xᵢ))，再除以总和 Z 归一化。分对的样本 yᵢGₘ(xᵢ) = +1，权重乘 e^(−α) 变小；分错的乘 e^(α) 变大。
  4. 最终模型 f(x) = Σ αₘGₘ(x)，取 sign(f(x)) 作为预测类别。

  • Boosting 主要降低偏差，基模型用简单的弱学习器（树桩、浅树）。

3.10 GBDT：一棵接一棵拟合残差

AdaBoost 用"改权重"告诉下一个模型哪里错了。还有一种更直接的说法：第一个模型预测完，还差多少就让第二个模型去预测这个差值，第二个模型还差多少再交给第三个……把所有模型的输出相加就是最终预测。这个"差值"在平方损失下就是残差 y − f(x)。用回归树做这件事的方法叫 GBDT（梯度提升决策树）。[12] [9]

为什么叫"梯度"提升：对平方损失 L = ½(y − f)²，损失对当前预测 f 的负梯度 −∂L/∂f = y − f，正好是残差。换成其他损失（例如分类用的对数损失）时，每一轮拟合的是负梯度，叫伪残差。所以 GBDT 的一般描述是：每一轮用一棵回归树拟合当前损失的负梯度。

def sse(vals):
    if not vals:
        return 0.0
    m = sum(vals) / len(vals)
    return sum((v - m) ** 2 for v in vals)

def best_stump(xs, rs):
    """在相邻 x 的中点处切一刀，左右各取均值，返回 (SSE, 阈值, 左值, 右值) 中 SSE 最小者。"""
    best = None
    for i in range(1, len(xs)):
        L, R = rs[:i], rs[i:]
        cand = (sse(L) + sse(R), (xs[i - 1] + xs[i]) / 2, sum(L) / len(L), sum(R) / len(R))
        if best is None or cand[0] < best[0]:
            best = cand
    return best

def gbdt_fit(xs, ys, rounds, lr=1.0):
    """返回 (初始值, [(阈值, 左值, 右值)], 每轮之后的残差列表)。"""
    f0 = sum(ys) / len(ys)
    pred = [f0] * len(ys)
    trees, history = [], []
    for _ in range(rounds):
        res = [y - p for y, p in zip(ys, pred)]          # 平方损失的负梯度 = 残差
        _, t, left, right = best_stump(xs, res)
        trees.append((t, left, right))
        pred = [p + lr * (left if x < t else right) for x, p in zip(xs, pred)]
        history.append([y - p for y, p in zip(ys, pred)])
    return f0, trees, history

gbdt_fit(GX, GY, 2) 返回 f0 = 11，两棵树 (3.5, −5, 5) 和 (5.5, −1, 5)，与上面的手算一致。

学习率（shrinkage）：实际使用时每棵树的输出要乘一个小于 1 的学习率 ν。取 ν = 0.5，第一轮后预测是 11 ± 0.5×5，即 [8.5, 8.5, 8.5, 13.5, 13.5, 13.5]，每步只走一半。步子小需要更多棵树，但每棵树的作用更温和，泛化通常更好。

要点：

  • GBDT 是加法模型：f(x) = f0 + Σ ν·树ₘ(x)，每一轮用回归树拟合当前损失的负梯度；平方损失下负梯度就是残差。
  • 即使做分类，GBDT 里的树也是回归树（拟合的是连续的梯度值）。
  • 串行训练、主要降低偏差；常用超参数：树的棵数、学习率、树深、叶子最少样本数、子采样比例。
  • 学习率越小，需要的树越多；两者要一起调。

3.11 XGBoost、LightGBM 与 Stacking

GBDT 在表格数据上效果很好，但原始实现有两个问题：容易过拟合；数据量大时，每次分裂都要扫描所有特征的所有取值，太慢。XGBoost 和 LightGBM 分别从"目标函数"和"工程效率"两个方向做了改进，是竞赛和银行风控里最常用的两个库。

XGBoost：二阶展开 + 正则

XGBoost 的目标是 Σ 损失 + Σ Ω(树)，正则项 Ω = γ·T + ½λ·Σw²，T 是叶子数，w 是叶子输出值。它对损失做二阶泰勒展开，每个样本算出一阶导 gᵢ 和二阶导 hᵢ，于是每片叶子的最优输出和每次分裂的收益都有闭式解：[13]

  • 叶子最优值 w* = −G / (H + λ)，G、H 是落在该叶子的样本的 gᵢ、hᵢ 之和。
  • 分裂增益 Gain = ½·[G_L²/(H_L + λ) + G_R²/(H_R + λ) − (G_L + G_R)²/(H_L + H_R + λ)] − γ，增益小于 0 就不分，这是自带的预剪枝。

算例：3.10 第一棵树的左叶有 3 个样本，残差 [−6, −5, −4]。平方损失 ½(f − y)² 的 g = f − y = −残差 = [6, 5, 4]，h = 1。G = 15，H = 3，取 λ = 1：w* = −15/(3 + 1) = −3.75。λ = 0 时 w* = −15/3 = −5，正是 GBDT 的叶子均值。λ 把叶子输出往 0 收缩，起正则作用。这一刀的分裂增益：G_L = 15，G_R = −15，H_L = H_R = 3，Gain = ½×(225/4 + 225/4 − 0/7) − γ = 56.25 − γ。

其他改进：支持行采样和列采样（借鉴随机森林）；学习率收缩；遇到缺失值时自动学习默认走向左还是右；特征预先排序存成块，在特征维度上并行寻找分裂点（树与树之间仍是串行）。

LightGBM：更快

LightGBM 的目标是在大数据上训练得更快、更省内存：[14]

  • 直方图算法：把连续特征离散成若干个桶（默认最多 255 个），只在桶边界上找分裂点，计算量和内存都大幅下降。
  • 按叶子生长（leaf-wise）：每次在所有叶子中挑增益最大的那片分裂；XGBoost 默认按层生长（level-wise），同一层的叶子一起分裂。同样的叶子数下，按叶子生长的损失下降更多，但容易长出很深的分支，要用 max_depth、num_leaves 限制。
  • GOSS（单边梯度采样）：保留梯度大的样本，梯度小的样本随机抽一部分；EFB（互斥特征捆绑）：把很少同时非零的稀疏特征合并成一个。
  • 原生支持类别特征，不必先做独热编码。

左：每层所有节点都分裂，树是均衡的；右：每次只分裂增益最大的叶子（绿色），两边都是 4 片叶子，右边长得更深

Stacking：让另一个模型学怎样组合

Bagging 和 Boosting 组合的都是同一种模型。Stacking 把不同种类的模型（例如逻辑回归、随机森林、GBDT、KNN）作为第一层，用它们的预测结果作为新特征，训练第二层的元模型（常用简单的逻辑回归）来学"该信谁多一点"。[15]

关键细节是第一层的预测必须来自没见过该样本的模型。做法是 K 折：把训练集分 5 份，每次用 4 份训练第一层模型、预测剩下 1 份，5 轮后每个样本都有一个"折外预测"（out-of-fold），再用它训练元模型。若直接用在全部训练集上拟合的模型去预测训练集，第一层模型早已记住了答案，元模型学到的是虚高的信心，这是一种数据泄漏。

Stacking：第一层模型各自给出折外预测，拼成新特征，第二层元模型学习组合权重

要点：

  • XGBoost 相对 GBDT：损失做二阶泰勒展开；目标中加入叶子数和叶子权重的正则项；支持列采样、缺失值自动处理、特征级并行。
  • LightGBM 相对 XGBoost：直方图分桶、按叶子生长、GOSS、EFB、原生类别特征，速度更快、内存更省。
  • Stacking 用第一层模型的折外预测训练元模型，防止泄漏。
  • Bagging 降方差、Boosting 降偏差；随机森林可并行，Boosting 的树之间串行。

3.12 SVM：最大间隔、软间隔与核函数

两类点能被一条直线分开时，这样的直线往往有无数条。哪条最好？直觉是：离两边的点都尽量远的那条最稳，新样本稍有偏差也不容易被分错。支持向量机（SVM）把这个直觉变成优化问题：在所有能分开两类的超平面里，选间隔最大的那个。[16] [17]

  • 超平面 w·x + b = 0，打分 f(x) = w·x + b，预测类别 sign(f(x))，标签 y 取 +1 或 −1。
  • 点到超平面的距离 = |w·x + b| / ‖w‖。把 w、b 同时缩放不改变超平面，于是约定离超平面最近的点满足 |w·x + b| = 1。
  • 约束：所有样本 yᵢ(w·xᵢ + b) ≥ 1。两条边界线 w·x + b = ±1 之间的宽度就是间隔 = 2/‖w‖。
  • 最大化 2/‖w‖ 等价于最小化 ½‖w‖²，这是一个凸二次规划，有唯一最优解。
  • 恰好落在边界线上的样本（yᵢ(w·xᵢ + b) = 1）叫支持向量。最优超平面只由它们决定，删掉其他样本，结果不变。

逐步执行：6 个点的最大间隔

正类 (2, 2)、(2, 3)、(3, 2)，负类 (0, 0)、(1, 0)、(0, 1)。

  1. 两类关于直线 x1 = x2 对称，最优超平面也应对称，设 w = (a, a)。正类中 x1 + x2 最小的是 (2, 2)，和为 4；负类中最大的是 (1, 0) 和 (0, 1)，和为 1。
  2. 让这三个点落在边界上：4a + b = 1，1·a + b = −1，解得 a = 2/3，b = −5/3。超平面是 (2/3)(x1 + x2) − 5/3 = 0，即 x1 + x2 = 2.5。
  3. 检查约束：(2, 3)、(3, 2) 的 f = 5/3 ≥ 1；(0, 0) 的 f = −5/3 ≤ −1。全部满足，且 (2, 2)、(1, 0)、(0, 1) 取等号，它们就是支持向量。
  4. ‖w‖ = (2/3)·√2 ≈ 0.943，间隔 = 2/0.943 ≈ 2.121，正好是直线 x1 + x2 = 1 与 x1 + x2 = 4 之间的距离 3/√2。
  5. 对偶形式核对：w = Σ αᵢyᵢxᵢ，取 α(2,2) = 4/9，α(1,0) = α(0,1) = 2/9，得 w = (4/9)(2, 2) − (2/9)(1, 0) − (2/9)(0, 1) = (2/3, 2/3)，并满足 Σ αᵢyᵢ = 4/9 − 2/9 − 2/9 = 0。非支持向量的 α 都是 0。

横轴 x1、纵轴 x2（向上为正）。实线 x1+x2 = 2.5 是决策边界，两条虚线 f = ±1 之间宽 2.121；绿色的三个点落在虚线上，是支持向量

软间隔：允许少数点越界

真实数据常有噪声点，硬要全部分对可能找不到超平面，或者间隔被挤得很窄。软间隔给每个样本一个松弛变量 ξᵢ ≥ 0，约束放宽为 yᵢ(w·xᵢ + b) ≥ 1 − ξᵢ，目标变成：

最小化 ½‖w‖² + C·Σξᵢ

最优时 ξᵢ = max(0, 1 − yᵢf(xᵢ))，这个函数叫 hinge 损失（合页损失）。所以软间隔 SVM 就是"hinge 损失 + L2 正则"。沿用上面的 w、b：

样本标签f(x)y·f(x)hinge 损失 ξ含义
(3, 3)+12.3332.3330在间隔外，分对
(2, 1)+10.3330.3330.667分对但落在间隔内
(2, 1.5)−10.667−0.6671.667分错

C 的作用：C 越大，对越界的惩罚越重，模型尽量把每个训练点都分对，间隔变窄，容易过拟合；C 越小，容忍的越界越多，间隔更宽，可能欠拟合。C 趋于无穷大时，软间隔退化为硬间隔。

核函数：在高维空间里画直线

一维数据 x = −2, −1, 0, 1, 2，标签 +, −, −, −, +：正类在两端、负类在中间，一个阈值分不开。把每个点映射成 φ(x) = (x, x²)，在二维平面上一条水平线 x² = 2.5 就分开了。

映射 φ(x) = (x, x²) 后（横轴 x，纵轴 x²，向上为正；圆内是符号和坐标），两端的正类被抬高，一条水平直线就能把两类分开

SVM 的对偶问题和预测公式里，样本只以内积 xᵢ·xⱼ 的形式出现。核技巧用核函数 K(x, z) 直接算出映射后的内积 φ(x)·φ(z)，不必真的把数据搬到高维空间。

  • 多项式核 K(x, z) = (x·z)²：x = (1, 2)，z = (3, 1) 时 (3 + 2)² = 25；对应映射 φ(v) = (v1², √2·v1v2, v2²)，φ(x)·φ(z) = 9 + 12 + 4 = 25，一致。
  • 高斯核（RBF） K(x, z) = exp(−γ‖x − z‖²)：取值在 (0, 1]，两点越近越接近 1。γ = 0.5、距离平方为 2 时 K = e^(−1) ≈ 0.368；距离平方为 8 时只有 0.018。γ 越大，每个样本的影响范围越小，边界越弯曲，越容易过拟合。
  • 线性核 K(x, z) = x·z：特征很多（如文本）时常用，速度快。

SVM 的分数要校准才能当概率

SVM 输出的 f(x) 是到超平面的有符号"距离分数"，取值范围是全体实数。上例中 (3, 3) 的分数是 2.333，原点 (0, 0) 是 −1.667，边界上的点 (1.5, 1) 是 0。分数的符号决定类别，绝对值越大离边界越远，但 2.333 本身没有概率含义。需要概率时（例如按预期损失定阈值），要在验证集上做概率校准：[18]

  • Platt 缩放：拟合 P(y = 1 | f) = 1 / (1 + exp(A·f + B))，A、B 从验证集学。假设学得 A = −2、B = 0，分数 2.333 对应概率 0.991，分数 0 对应 0.5。
  • 保序回归：拟合一条单调递增的阶梯函数，数据多时更灵活。

scikit-learn 的 SVC(probability=True) 就是在内部用交叉验证做 Platt 缩放。逻辑回归的输出本身按对数损失训练，通常已比较接近校准；树模型、SVM、朴素贝叶斯的分数一般都要先检查校准曲线。

要点：

  • SVM 求最大间隔超平面，间隔 = 2/‖w‖，等价于最小化 ½‖w‖²，约束 yᵢ(w·xᵢ + b) ≥ 1；决定超平面的只有支持向量。
  • 软间隔 = hinge 损失 + L2 正则；C 大 → 间隔窄、易过拟合；C 小 → 间隔宽、易欠拟合。
  • 核函数把内积换成 K(x, z)，隐式映射到高维；RBF 核的 γ 越大越容易过拟合。
  • SVM 输出的是分数，需要 Platt 缩放或保序回归校准后才能当概率；特征要先标准化。

3.13 朴素贝叶斯：公式与条件独立假设

垃圾短信过滤要回答"出现了'中奖''点击链接'这两个词，是垃圾短信的概率多大"。直接统计"同时含这两个词的短信"样本太少；朴素贝叶斯的办法是假设各个词在给定类别下互相独立，把联合概率拆成单个词的概率连乘，每个都容易估计。[19]

公式（贝叶斯定理见第 2 章）：

  • 后验 P(y | x) = P(y)·P(x | y) / P(x)。比较不同类别时分母 P(x) 相同，可以省略。
  • 条件独立假设：P(x | y) = P(x₁ | y)·P(x₂ | y)·…·P(x_d | y)。
  • 预测：ŷ = argmax_y P(y)·Π P(xⱼ | y)。实际计算取对数，把连乘变成连加，避免很多小概率相乘后下溢成 0。
  • 拉普拉斯平滑：P(xⱼ = v | y) = (类别 y 中 xⱼ = v 的个数 + 1) / (类别 y 的样本数 + Sⱼ)，Sⱼ 是特征 j 的取值个数。没有平滑时，某个取值在训练集里没出现过，概率是 0，整个连乘就被"一票否决"。

朴素贝叶斯的结构：类别决定每个特征的分布，特征之间没有连线，表示给定类别后彼此独立

条件独立把要估计的参数数量大大减少：10 个二值特征、2 个类别时，朴素贝叶斯只需估 1 个先验 + 2×10 个条件概率 = 21 个数；不做假设、直接估计完整的联合分布要 2×(2¹⁰ − 1) + 1 = 2047 个。

变体特征类型P(xⱼ | y) 的形式典型场景
高斯朴素贝叶斯连续值正态分布，每类估均值和方差数值型表格数据
多项式朴素贝叶斯计数词频比例文本分类
伯努利朴素贝叶斯0/1出现 / 不出现短文本、二值特征

完整的手算例子（一张贷款表，含拉普拉斯平滑）放在第 4 章。

要点：

  • 朴素贝叶斯 = 贝叶斯定理 + 特征条件独立假设；属于生成式模型（建模 P(x | y) 和 P(y)），逻辑回归属于判别式模型（直接建模 P(y | x)）。
  • 用拉普拉斯平滑避免零概率；用对数避免下溢。
  • 训练只需计数，速度快、小样本也能用；独立假设不成立时概率值偏极端，但排序和分类效果常常仍然不错。

3.14 K-means：分配与更新交替两轮

银行想把客户按消费行为分成几群，分别设计营销方案，但手里没有任何"这个客户属于哪群"的标签。K-means 是最常用的聚类算法：给定簇数 K，找 K 个中心，让每个点到所属中心的距离平方和（簇内平方和，SSE）尽量小。[20]

算法只有两步，交替进行，直到分组不再变化：

  2. 更新：每个中心移到本组所有点的平均位置（这就是"means"的由来）。

points 是从名字到坐标的字典；centers 是当前的 K 个中心；groups[k] 是第 k 个簇的成员名；new 是更新后的中心。

def kmeans_round(points, centers):
    """一轮 = 分配（每点归最近中心）+ 更新（中心移到组内均值）。返回 (分组, 新中心)。"""
    groups = [[] for _ in centers]
    for name, p in points.items():
        k = min(range(len(centers)), key=lambda i: math.dist(p, centers[i]))
        groups[k].append(name)
    new = [tuple(sum(points[n][d] for n in g) / len(g) for d in range(2)) for g in groups]
    return groups, new

从 [(1, 1), (1, 2)] 出发调用两次，分组依次是 [['A','C'], ['B','D','E','F']] 和 [['A','B','C'], ['D','E','F']]，第三次调用结果不变。

要点：

  • K-means 交替执行"分配到最近中心"和"中心更新为均值"，目标是最小化簇内平方和；一定收敛，但只保证局部最优。
  • 需要预先指定 K；对初始中心敏感（用 K-means++ 选初值、多次运行取最好），簇数用肘部法等选择（第 4 章）。
  • 适合大小相近的球形簇；对量纲和离群点敏感（均值会被离群点拉偏），非凸形状的簇用 DBSCAN（第 4 章）。
  • 每轮计算量 O(n·K·d)。

3.15 降维：为什么要减少特征

一张风控宽表可能有上千列：交易笔数、金额、时间段、地区编码……特征越多，模型越慢、越难解释，更麻烦的是数据会变得"稀疏"。降维把 d 个特征压缩成 k 个（k 远小于 d），保留主要信息、丢掉噪声和冗余。[21]

维度灾难：数据在 [0, 1] 的 d 维立方体里均匀分布，要圈住 10% 的数据，小立方体的边长需要 0.1^(1/d)。

10 维时边长要 0.79，100 维时要 0.98：所谓"邻域"几乎覆盖整个空间，近邻也不再近

一维时边长 0.1 就够；10 维时要 0.79，100 维时要 0.98。"最近的邻居"其实已经很远，KNN、K-means 这类依赖距离的方法效果变差；同样多的样本，高维时也更容易过拟合。

降维的作用可以归为四条：

  1. 缓解维度灾难，降低过拟合风险；
  2. 减少计算量和存储；
  3. 去掉噪声和高度相关（共线）的特征；
  4. 降到 2 维或 3 维做可视化。

两条路线：

路线做法典型方法结果是否可解释
特征选择从原特征里挑一个子集过滤法（方差、相关系数、卡方、IV）、包裹法（递归特征消除）、嵌入法（L1 正则、树的特征重要性）保留原始含义，好解释
特征提取把原特征组合成新特征PCA（无监督，保留最大方差）、LDA（有监督，让类间分得最开）、t-SNE（只用于可视化）、自编码器（第 5 章）新特征是组合，较难解释

PCA 的一个算例（推导见第 2 章）：两个特征标准化后的协方差矩阵是 [[2.5, 2], [2, 2.5]]，特征值为 4.5 和 0.5。第一主成分方向 (1, 1)/√2 保留了 4.5/(4.5 + 0.5) = 90% 的方差，只用这一个新特征就能代替原来的两个。PCA 的步骤是：标准化，求协方差矩阵，做特征分解，取前 k 个最大特征值对应的特征向量，再把数据投影到这些方向上。

要点：

  • 降维的作用：缓解维度灾难、降低计算量、去噪去冗余、可视化。
  • 特征选择保留原特征子集（可解释）；特征提取生成新特征（PCA、LDA）。
  • PCA 无监督、按方差最大投影，主成分彼此正交；LDA 有监督，按类别可分性投影，最多降到"类别数 − 1"维。
  • PCA 的均值和投影矩阵只能在训练集上拟合，再应用到验证集和测试集。

3.16 偏差与方差：靶心图与学习曲线

模型在验证集上表现不好时，第一件事是判断病因：是模型太简单、根本没学到规律（欠拟合），还是模型太复杂、把训练集的噪声也记住了（过拟合）？两种病的药方相反，判断错了越治越糟。偏差和方差就是用来诊断这件事的两个量。第 1 章已经介绍过欠拟合与过拟合，这里把它们画成靶心图，再用学习曲线诊断。[3] [22]

设想同一个模型，用不同的训练集各训练一次，每次对同一个测试点做一次预测，就像对靶子射了很多箭：

  • 偏差：这些预测的平均值离真实值有多远——箭群的中心偏不偏。
  • 方差：这些预测彼此之间有多分散——箭群散不散。
  • 期望误差 = 偏差² + 方差 + 噪声。噪声来自数据本身（同样的特征、不同的结果），任何模型都消除不了。

靶心是真实值，每个 × 是用一份不同训练集训练出的模型的预测。从左到右：理想状态；中心准但很散（过拟合）；很集中但整体偏了（欠拟合）；又偏又散

模型复杂度决定两者的此消彼长：线性模型、浅树、大 K 的 KNN、强正则，偏差大、方差小；深树、1-NN、高次多项式、弱正则，偏差小、方差大。随着复杂度增加，偏差下降、方差上升，验证误差先降后升，最低点就是合适的复杂度。集成方法分别从两头下手：Bagging 平均多个高方差模型降方差，Boosting 叠加多个高偏差模型降偏差（3.11）。

学习曲线：把训练集逐步加大

学习曲线横轴是训练样本数，纵轴是训练误差和验证误差。下面两张图来自同一份模拟数据：真实关系 y = x²，x 在 [−2, 2] 内均匀取值，噪声在 ±0.5 内均匀分布（噪声方差约 0.083）。训练集分别取 5、10、20、40、80 个点，每个规模重复 20 次取平均，验证集固定 200 个点。

高偏差：用直线拟合抛物线。两条曲线很快靠拢，停在约 1.5，远高于噪声水平 0.083；加数据也降不下去

高方差：1-NN 回归。训练误差恒为 0，样本少时与验证误差差距很大；样本增加后差距缩小，加数据有效

现象诊断有效的办法
训练误差高，验证误差也高，两者接近高偏差（欠拟合）加特征、换更复杂的模型、减弱正则、Boosting
训练误差很低，验证误差高很多高方差（过拟合）加数据、加强正则、剪枝、减少特征、Bagging、早停

要点：

  • 偏差衡量预测的平均值离真值多远，方差衡量不同训练集下预测的波动；期望误差 = 偏差² + 方差 + 噪声。
  • 简单模型高偏差低方差，复杂模型低偏差高方差；最优复杂度在验证误差最低处。
  • 学习曲线两线都高且靠拢 → 高偏差，加数据无用；两线间距大 → 高方差，加数据、加正则有用。
  • Bagging 降方差，Boosting 降偏差。

3.17 交叉验证、网格搜索与数据泄漏

KNN 的 K 取 3 还是 5、要不要标准化，这些超参数怎么定？用测试集挑，测试集就被"偷看"了，最后报告的成绩会偏高。第 1 章讲过训练集、验证集、测试集三分法；数据量不大时，只留一份验证集太浪费，结果也受划分的运气影响。交叉验证让每个样本都轮流当一次验证数据，结果更稳定。[23] [24]

K 折交叉验证：把训练数据分成 K 份（折），每次用其中 1 份做验证、其余 K − 1 份训练，轮 K 次，取 K 个验证分数的平均。常用 K = 5 或 10；K = 样本数时叫留一法。

5 折交叉验证：数据分成 5 块（第 1–5 列），每轮换一块做验证（绿色），最后把 5 个验证分数取平均

几种变体：类别不平衡时用分层 K 折，让每折的正负比例与总体一致；时间序列只能用"过去训练、未来验证"的滚动划分，随机打乱会让模型看到未来；同一客户的多条记录要整组放进同一折，否则模型靠"认人"得分。

网格搜索：把超参数组合全部试一遍

网格搜索列出每个超参数的候选值，对所有组合分别做 K 折交叉验证，选平均分最高的组合，再用它在全部训练数据上重新训练，最后在测试集上评估一次。候选组合多时改用随机搜索（随机抽若干组合），同样的预算下往往更高效。

完整走一遍：20 个样本，两个特征是交易笔数（1–30）和金额（3000–7000 元），标签由笔数决定（有 2 个噪声样本）。网格是 K ∈ {1, 3, 5, 7} × {不缩放, 标准化}，共 8 组；每组做 5 折交叉验证（样本下标从 0 起，第 f 折取下标除以 5 余 f 的样本，f = 0…4），标准化的均值和标准差只用当轮的训练折计算。8 组 × 5 折 = 训练 40 次。

5 折交叉验证准确率。不缩放时金额主导距离，准确率不到一半；标准化后 K = 5 最好（0.80），选它

结果说明两件事：预处理也是超参数，应放进网格一起比较；最复杂的 K = 1 并不最好，同一套交叉验证下 K = 5 胜出。

用一致的验证协议比较模型

"新模型比旧模型好"这句话要成立，两者必须在同一份划分、同样的折、同一个指标上比较，且测试集只在最后用一次。更复杂的模型能拟合更多规律，也能拟合更多噪声，在小数据、噪声大的场景里常常输给简单模型，上例的 K = 1 就是这样。没有统一协议时，模型 A 在随机划分上得 0.85、模型 B 在另一种划分上得 0.82，这两个数不能说明谁更好。

数据泄漏：验证时偷看了答案

数据泄漏指训练过程用到了预测时拿不到的信息，验证分数虚高，上线后效果断崖式下降。常见四类：[25]

  1. 预处理泄漏：先用全部数据做标准化、PCA、特征选择或过采样，再划分。例如训练集金额 [10, 20, 30] 的均值是 20，若把测试集的 100 也算进去，均值变成 40，训练过程已经"知道"了测试集的分布。
  2. 目标泄漏：特征里含有结果发生后才有的信息。预测是否违约时用了"是否进入催收"这一列，准确率会接近 100%，但放款时这一列根本不存在。
  3. 时间泄漏：时间序列随机打乱划分，用未来的数据预测过去。
  4. 重复样本：同一客户或同一笔交易的副本同时出现在训练集和测试集。

无泄漏的流程：先划分，所有"需要拟合"的步骤只在训练折上拟合，再把学到的参数套用到验证折。scikit-learn 的 Pipeline 能在交叉验证中自动做到这一点

要点：

  • K 折交叉验证：分 K 份，轮流 1 份验证、K − 1 份训练，取平均；不平衡数据用分层 K 折，时间序列用滚动划分。
  • 网格搜索 = 所有超参数组合 × 交叉验证，代价是"组合数 × K"次训练；组合多时用随机搜索。
  • 测试集只在最终评估时用一次，不参与任何选择。
  • 防泄漏：先划分再预处理；标准化、编码、特征选择、过采样都只在训练折上拟合；剔除结果发生后才有的特征；时间数据按时间切分。
  • 比较模型要用一致的验证协议；更复杂的模型不一定更好。

多选 · 理解检查 18　综合本章，关于模型选型哪些说法正确？

A. 随机森林是集成树模型，与深度神经网络的机制不同，不需要反向传播

B. KNN 的距离受特征量纲影响，使用前要做缩放

C. SVM 的分数天然是已校准的概率，可直接乘以损失金额算预期损失

D. 同一套交叉验证下，复杂模型的分数一定高于简单模型

查看答案与每个选项的解析

A · 正确：随机森林靠自助抽样和随机特征训练多棵独立的树再投票（3.8）。

B · 正确：3.5 的例子中，缩放前金额主导距离、判为正常，缩放后改判可疑。

C · 错误：SVM 分数是间隔距离，需要 Platt 缩放等额外校准（3.12）。

D · 错误：复杂模型可能过拟合，3.17 中 K = 1 的 KNN 就输给了 K = 5；结论要靠一致的验证协议得出。

易错点： 选型表是起点，最终以同一套验证协议下的结果为准；银行场景还要同时满足可解释、稳定性和监管要求，精度最高的模型未必能上线。

小结： 选择模型前先问：有没有标签，输出是什么类型，是否需要可解释性；评分卡用逻辑回归，追求表格数据的精度用 GBDT 一类模型；先建立基线，并在同一套验证方案下比较。
