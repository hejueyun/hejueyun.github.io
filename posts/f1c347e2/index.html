29.1 数据挖掘做什么：KDD 过程与 CRISP-DM

一家银行每天产生几千万条交易流水。业务部门想知道三件事：哪些客户下个月可能逾期，哪些产品常被一起购买，哪些交易像是盗刷。这些答案都藏在数据里，但要先清洗、整合、挑选，再用算法找出模式，最后判断模式是否可信。这一整套过程叫知识发现（KDD，Knowledge Discovery in Databases），其中"用算法找模式"那一步叫数据挖掘。

韩家炜教材把 KDD 分成 7 步：数据清理（去噪声、补缺失）、数据集成（多源合并）、数据选择（取出与任务相关的数据）、数据变换（规范化、汇总、编码）、数据挖掘、模式评估（用兴趣度度量筛掉无用模式）、知识表示（可视化、报告）。前四步合称数据预处理，实际项目里花时间最多的往往是这四步。[1]

KDD 的 7 步：前四步是预处理，第 5 步才是狭义的数据挖掘

挖掘任务分成两大类。描述性任务刻画数据本身的规律，包括关联分析、聚类、异常检测；预测性任务用已知数据推断未知标签，包括分类和回归。

CRISP-DM（跨行业数据挖掘标准流程） 是工业界最常用的项目方法论，把项目分成 6 个阶段：业务理解、数据理解、数据准备、建模、评估、部署。它从业务目标出发，到模型上线结束，阶段之间可以来回跳。[2]

CRISP-DM 六阶段：双向箭头表示两阶段之间常来回迭代

要点：

  1. 狭义的数据挖掘是 KDD 中的一个步骤；广义上人们也用"数据挖掘"指整个 KDD 过程。
  2. KDD 顺序：清理 → 集成 → 选择 → 变换 → 挖掘 → 评估 → 表示。
  3. CRISP-DM 六阶段：业务理解 → 数据理解 → 数据准备 → 建模 → 评估 → 部署，强调迭代和业务目标。
  4. 关联、聚类、异常检测属于描述性任务；分类、回归属于预测性任务。

29.2 缺失值与异常值：先补洞，再找离群点

拿到一张客户表，第一件事是数一数有多少空格子、有没有离谱的数字。月收入一栏有人没填，交易金额一栏有一笔 180 万的大单，这两种情况都会把均值、方差和模型带偏。

缺失值的处理方法

方法做法适用场合
删除元组整行丢掉缺失很少、样本很多
全局常量填"未知"或 −1类别变量；让模型自己学"未知"
均值 / 中位数用该列的均值或中位数填数值变量；有偏态时用中位数

我们用 6 位客户的月收入（千元）走一遍：[5, 6, 7, 8, 缺, 30]。已知的 5 个数均值是 (5+6+7+8+30)/5 = 11.2，被 30 这个大值拉高了；中位数是 7，更能代表"普通客户"。用中位数填补得到 [5, 6, 7, 8, 7, 30]，同时加一列缺失标记 [0, 0, 0, 0, 1, 0]。在风控里，不愿填收入的人风险可能更高，这一列标记往往就是有用的特征；评分卡也常把"缺失"单独作为一箱（29.17）。[3]

异常值：3σ 原则与 IQR 箱线图

3σ 原则：如果数据近似服从正态分布，落在 μ±3σ 之外的概率只有约 0.27%（第 18 章 18.5），于是把 |x−μ| > 3σ 的点视为异常。

IQR 方法（箱线图）：先求下四分位数 Q1、上四分位数 Q3，四分位距 IQR = Q3 − Q1；落在 [Q1 − 1.5·IQR, Q3 + 1.5·IQR] 之外的点视为异常。四分位数只看排序位置，极端值改变不了它。

本章求四分位数用"中位数分两半"的办法：先求整体中位数，再分别求下半部分和上半部分的中位数（个数为奇数时，整体中位数两边都不含它）。

3σ 失手的原因是 180 自己把 σ 撑大了：去掉 180 后，其余 9 个数的 μ = 62.56、σ = 6.47，180 远在 μ + 3σ ≈ 82 之外。异常值会"掩护"自己，这叫掩蔽效应。

要点：

  1. 有偏态或有极端值时，用中位数填补比均值稳健。
  2. 3σ 原则依赖正态假设，均值和标准差会被异常值本身拉偏；样本小时更明显。
  3. IQR 基于分位数，对极端值稳健，箱线图的"须"就是 Q1−1.5·IQR 和 Q3+1.5·IQR。
  4. 风控里"异常"可能正是要找的目标（大额盗刷），先查明原因再决定删、改还是保留。

29.3 分箱平滑、相关分析与规范化

数据里的噪声是随机误差，比如价格录入时多了几块钱。分箱平滑把相邻的值放进同一个"箱子"，再用箱内的代表值替换，抹掉小波动。数据集成时还要判断两列是否冗余，这要用相关分析；最后把不同量纲的列变到同一尺度，这叫规范化。

分箱平滑

等频分箱让每箱样本数相同；等宽分箱让每箱的取值区间宽度相同。平滑方式有三种：用箱均值、箱中位数或箱边界（离哪个边界近就变成哪个边界）替换。

相关分析：皮尔逊系数与卡方检验

两个数值属性用皮尔逊相关系数：r = Σ(x−x̄)(y−ȳ) / √(Σ(x−x̄)²·Σ(y−ȳ)²)，取值在 [−1, 1]，|r| 越接近 1 线性相关越强。

5 位客户的月收入 x = (3, 5, 6, 8, 8) 千元，月刷卡消费 y = (2, 3, 5, 6, 9) 千元。x̄ = 6，ȳ = 5；离差积之和 Σ(x−x̄)(y−ȳ) = 9+2+0+2+8 = 21，Σ(x−x̄)² = 18，Σ(y−ȳ)² = 30，所以 r = 21/√540 ≈ 0.904，强正相关。集成时若两列 r 接近 1，可以只留一列。

两个类别属性用卡方检验（第 18 章 18.10）。200 位客户：有房贷的 100 人中 60 人办了信用卡，无房贷的 100 人中 30 人办了。期望频数 = 行合计 × 列合计 / 总数，四格分别是 45、55、45、55；χ² = Σ(观测−期望)²/期望 = 225/45 + 225/55 + 225/45 + 225/55 ≈ 18.18，大于自由度 1、显著性 0.05 的临界值 3.841，判定"有房贷"和"办信用卡"相关。

方法公式账户余额 200, 300, 400, 600, 1000 的结果
最小-最大(x − min)/(max − min)0, 0.125, 0.25, 0.5, 1

最小-最大规范化把训练集压到 [0, 1]。上线后来了一个余额 1200 的新客户，(1200−200)/800 = 1.25，跑出了区间。z-score 没有固定上下界，对这种情况更从容。规范化的参数（min、max、μ、σ）只能在训练集上算，再原样用到测试集和线上。[4]

要点：

  1. 等频分箱每箱个数相同，等宽分箱每箱区间宽度相同；等宽对极端值敏感。
  2. 数值属性看皮尔逊 r，类别属性看卡方 χ²；r 只刻画线性关系，相关也说明不了因果。
  3. 小数定标的 j 是让最大绝对值小于 1 的最小整数。
  4. 距离类算法（KNN、K-means、SVM）对尺度敏感，必须先规范化；树模型对单调变换不敏感。

查看答案与每个选项的解析

A · 正确：最大绝对值 986，除以 10³ 后为 0.986 < 1，除以 10² 还大于 1。

B · 错误：120 正是最大值，规范化后为 1。

C · 正确：(45 + 986)/(120 + 986) = 1031/1106 ≈ 0.932。

  • 用全量数据算 min、max 再切训练集和测试集，会把测试集的信息泄漏给训练过程。

小结： 等频分箱使每箱的样本个数相同，等宽分箱使每箱的区间宽度相同；数值变量之间看皮尔逊相关系数 r，类别变量之间看卡方检验；min-max 规范化把数据落在 [0,1]，z-score 看偏离均值几个标准差，小数定标规范化除以 10 的 j 次方。

29.4 类别编码与不平衡样本：独热编码与 SMOTE

大部分算法只吃数字，"职业 = 学生"这种类别值要先变成数字。另一个常见麻烦是样本极不平衡：1 万个贷款客户里只有 200 个违约，模型把所有人都判成"不违约"也有 98% 的准确率，却一个坏人都抓不到。

类别编码

独热编码：一个类别变量拆成 k 列，每行只有一个 1

编码方式做法适用
独热编码（One-Hot）k 个类别拆成 k 列 0/1无序类别，类别数不多
序号编码按顺序编 1, 2, 3有序类别：学历 高中 < 本科 < 硕士
频数 / 目标编码用类别出现次数或该类的平均违约率代替高基数类别，如几百个城市
WOE 编码用该类的 WOE 值代替（29.18）评分卡

无序类别用序号编码，会让模型以为"职员(3) > 学生(2) > 个体(1)"，凭空造出大小关系。目标编码要在训练集内部用交叉折算，否则会把标签泄漏进特征。

不平衡样本的三层处理

  • 数据层：随机欠采样（丢掉部分多数类）、随机过采样（复制少数类）、SMOTE（合成新的少数类样本）。
  • 算法层：给少数类更大的权重（class_weight），或调低判为"坏"的阈值。
  • 评估层：用召回率、AUC、KS 代替准确率（29.10、29.20）。

SMOTE（合成少数类过采样） 的做法：对少数类样本 x，在它的 k 个少数类近邻里随机挑一个 x_nn，在两点连线上随机取一点：x_new = x + λ·(x_nn − x)，λ 是 [0, 1] 上的随机数。[5]

两个少数类样本连线上合成新点：λ=0.5 得 (3,5)，λ=0.25 得 (2.5,4)；灰色是多数类

算一个：x = (2, 3)，x_nn = (4, 7)，差向量 (2, 4)。λ = 0.5 时 x_new = (2+1, 3+2) = (3, 5)；λ = 0.25 时 x_new = (2.5, 4)。新点落在两个真实少数类样本之间，比简单复制更不容易过拟合。

要点：

  1. 无序类别用独热编码，有序类别用序号编码，评分卡用 WOE 编码。
  2. 不平衡问题可以在数据层、算法层、评估层分别处理；评估时看召回、AUC、KS，少看准确率。
  3. SMOTE 公式：x_new = x + λ(x_nn − x)，λ ∈ [0, 1]，x_nn 是少数类近邻。
  4. 采样只对训练集做，先划分数据集再采样。

A. (3.5, 6)

B. (3, 5)

C. (1.5, 3)

查看答案与每个选项的解析

A · 正确：x + 0.75×(2, 4) = (2 + 1.5, 3 + 3)。

B · 错误：这是 λ = 0.5 的结果。

C · 错误：把差向量直接乘了 0.75，忘了加上 x。

易错点

  • 先对全量数据做 SMOTE 再切分，合成样本和它的"父母"可能分别落进训练集和测试集，测试成绩虚高。
  • 过采样改变了训练集的坏样本比例，模型输出的概率要校准回真实违约率后才能当概率用。

小结： 无序的类别变量用独热编码，有序的用序号编码，评分卡中用 WOE 编码；类别不平衡可以从数据、算法、评估三个层面处理，SMOTE 在少数类样本与其近邻的连线上取点合成新样本，只能对训练集使用。

29.5 数据仓库与 OLAP：星型模型和数据立方体

核心业务系统（OLTP，联机事务处理）为"一笔一笔快速记账"设计：表高度规范化，只保留当前状态。管理层要看的是"过去三年各地区每季度的贷款增长"，需要把多个系统的数据合并、保留历史、按维度汇总。这类分析在数据仓库上做，分析操作叫 OLAP（联机分析处理）。

29.6 关联规则与 Apriori：逐层连接与剪枝

手机银行想做交叉营销：已经买了理财的客户，推荐什么产品成功率最高？把每位客户买过的产品看成一个"购物篮"，从大量购物篮里找出"买了 X 的人往往也买 Y"，就是关联规则挖掘。

三个度量

设 X、Y 是两个不相交的项集（项的集合），N 是交易总数。

  • 支持度 support(X→Y) = P(X∪Y) = 同时含 X 和 Y 的交易数 / N。它衡量规则覆盖面，"同时含"的交易数叫支持度计数。
  • 置信度 confidence(X→Y) = P(Y|X) = 支持度计数(X∪Y) / 支持度计数(X)。它衡量规则的可靠程度。
  • 提升度 lift(X→Y) = confidence(X→Y) / P(Y)。大于 1 表示 X 出现会让 Y 更常出现（正相关），等于 1 表示独立，小于 1 表示负相关。

再看一个简单的例子：100 个购物篮中 A 出现 40 次、B 出现 50 次、两者同时出现 30 次，则规则 A→B 的支持度为 30%，置信度为 30/40 = 75%，提升度为 0.75/0.5 = 1.5。同时满足最小支持度和最小置信度的规则叫作强规则。

Apriori 性质与算法

找强规则分两步：先找出所有频繁项集（支持度计数 ≥ 最小支持度计数），再从频繁项集生成规则。第一步最费时，Apriori 用一条性质大幅减少要数的项集：

Apriori 性质：频繁项集的所有非空子集也是频繁的。 等价地，只要某个项集不频繁，它的所有超集都不频繁。[7]

于是算法逐层进行：由频繁 (k−1) 项集 L(k−1) 生成候选 k 项集 C(k)，分两个动作——

  1. 连接：L(k−1) 中两个项集按字典序排好后，前 k−2 项相同、只有最后一项不同，就合并成一个 k 项集。
  2. 剪枝：检查候选的每个 (k−1) 子集，只要有一个不在 L(k−1) 中，就删掉这个候选。剪枝只查 L(k−1)，不扫描数据库。

剩下的候选再扫描一遍数据库计数，计数达标的组成 L(k)。

代码

变量表：transactions 是交易列表（每条是一个集合）；min_count 是最小支持度计数；C 是本层候选；L 是本层频繁项集；counts 是候选的计数；pruned 记录被剪掉的候选；trace 保存每一层的快照。

def apriori(transactions, min_count):
    """返回 (frequent, trace)。frequent: {项集元组: 支持度计数}；trace 记录每层 C_k、剪掉的候选、L_k。"""
    items = sorted({i for t in transactions for i in t})
    C = [(i,) for i in items]
    frequent, trace, k = {}, [], 1
    while C:
        counts = {c: support_count(c, transactions) for c in C}
        L = [c for c in C if counts[c] >= min_count]
        frequent.update({c: counts[c] for c in L})
        nextC, pruned = [], []
        Lset = set(L)
        for a, b in itertools.combinations(L, 2):          # 连接：前 k-1 项相同
            if a[:-1] == b[:-1]:
                cand = tuple(sorted(set(a) | set(b)))
                if all(s in Lset for s in itertools.combinations(cand, k)):   # 剪枝：所有 k 子集都频繁
                    nextC.append(cand)
                else:
                    pruned.append(cand)
        trace.append({'k': k, 'C': counts, 'L': L, 'pruned_next': pruned})
        C, k = nextC, k + 1
    return frequent, trace

代码里 k 是本层项集的大小，所以"前 k−1 项相同"对应正文"由 L(k−1) 生成 C(k) 时前 k−2 项相同"，只是下标从本层算起。用上面的 9 条交易运行 apriori(TX, 3)，第 2 层的 pruned_next 正好是 ABC、ABD、ACD。

要点：

  1. 支持度 = P(X∪Y)，置信度 = P(Y|X)，提升度 = P(Y|X)/P(Y)。
  2. Apriori 性质：频繁项集的子集都频繁；非频繁项集的超集都不频繁。
  3. 每层两步：连接（前 k−2 项相同才合并）、剪枝（有一个 (k−1) 子集不频繁就删），然后扫库计数。
  4. 置信度高的规则也可能提升度 < 1；后件本身很常见时尤其如此。
  5. 提升度描述共现强弱，说明不了因果。

29.7 FP-growth：一棵树压缩全部交易

Apriori 每生成一层候选就要扫一遍数据库，候选数也可能爆炸：如果有 10⁴ 个频繁 1 项集，就要产生超过 10⁷ 个候选 2 项集。FP-growth 只扫描数据库两遍，把所有交易压进一棵 FP 树（频繁模式树），然后在树上递归挖掘，整个过程不产生候选项集。[8]

建树：两遍扫描

第一遍扫描数出每个项的计数，删掉不频繁的项，按计数从大到小排成项头表：E:8、A:7、B:5、C:4、D:3（计数相同时按字母序）。

第二遍扫描把每条交易里的项按项头表顺序重排，再从根开始插入：路径已有的节点计数加 1，没有的就新建一个计数为 1 的子节点。9 条交易重排后依次是 EAD、EAC、EB、EAD、EAC、EABC、EABD、EB、ABC。项头表中每个项还用一条节点链串起树中所有同名节点，挖掘时顺着链找。

29.8 朴素贝叶斯：一张小表手算违约概率

信贷员面前有一位新申请人：学生、已婚、征信有过逾期。历史上和他三项完全相同的人可能一个都没有，没法直接数"这类人里多少违约"。朴素贝叶斯假设在类别确定的条件下，各特征相互独立，把联合概率拆成每个特征单独的条件概率连乘，每一项都能从数据里数出来。[9]

由贝叶斯公式（第 18 章 18.2），对每个类别 c：

P(c | x) ∝ P(c) × P(x₁|c) × P(x₂|c) × … × P(xₙ|c)

分母 P(x) 对所有类别相同，比较大小时可以省略，最后归一化即可。

某个特征取值在某类里一次都没出现时，条件概率为 0，整个连乘被"一票否决"。拉普拉斯平滑给每个计数加 1：

  • 先验：P(c) = (|D_c| + 1) / (|D| + N)，N 是类别数；
  • 条件概率：P(xᵢ|c) = (|D_c,xᵢ| + 1) / (|D_c| + Nᵢ)，Nᵢ 是第 i 个特征可能的取值个数。

代码

变量表：rows 是训练数据，每行最后一列是类别；x 是待预测样本的特征元组；alpha 是平滑参数（1 即拉普拉斯平滑，0 即不平滑）；VALUES[f] 是第 f 个特征的全部可能取值；scores 存每个类别未归一化的后验。

def naive_bayes_predict(rows, x, alpha=1):
    """返回 {类别: 未归一化后验}。alpha=1 即拉普拉斯平滑。"""
    classes = sorted({r[-1] for r in rows})
    scores = {}
    for c in classes:
        rc = [r for r in rows if r[-1] == c]
        p = (len(rc) + alpha) / (len(rows) + alpha * len(classes))      # 先验也平滑
        for f, v in enumerate(x):
            k = len(VALUES[f])
            p *= (sum(1 for r in rc if r[f] == v) + alpha) / (len(rc) + alpha * k)
        scores[c] = p
    return scores

要点：

  1. 朴素贝叶斯的"朴素"指：给定类别后，特征之间条件独立。
  2. 拉普拉斯平滑：分子加 1，分母加该特征的取值个数；先验的分母加类别数。
  3. 比较类别时可省略分母 P(x)；要输出概率时再归一化。
  4. 优点：训练只需计数，速度快，小样本可用；缺点：独立假设常不成立，概率值偏极端。

29.10 ROC 曲线与 AUC：手工画一条

违约模型输出的是一个分数，分数高于阈值才判为"坏"。阈值调低，抓到的坏人多了，误伤的好人也多了。ROC 曲线把所有阈值下的表现画在一张图上，AUC（曲线下面积）把它压成一个数，便于比较模型。[11]

  • TPR（真正例率，召回率） = TP / P：所有真坏人里被抓到的比例；
  • FPR（假正例率） = FP / N：所有好人里被误判的比例。

ROC 曲线横轴 FPR、纵轴 TPR。阈值从 +∞ 往下降：起点 (0, 0)，每越过一个正样本向上走 1/P，每越过一个负样本向右走 1/N，终点 (1, 1)。

面积法：阶梯下方由三个矩形组成，FPR 在 [0, 0.25) 时高 0.5，在 [0.25, 0.5) 时高 0.75，在 [0.5, 1] 时高 1：AUC = 0.25×0.5 + 0.25×0.75 + 0.5×1 = 0.8125 = 13/16。

配对法：AUC 等于"随机挑一个坏样本和一个好样本，坏样本分数更高"的概率。4 × 4 = 16 对中，0.95 和 0.85 各胜 4 对，0.70 胜 3 对（0.60、0.40、0.30），0.52 胜 2 对，合计 13 对，AUC = 13/16。分数相同的一对记 0.5。

def roc_points(scored):
    """按分数从高到低逐个降低阈值，返回 [(FPR, TPR)]，起点 (0,0)。"""
    P = sum(y for _, y in scored)
    N = len(scored) - P
    tp = fp = 0
    pts = [(0.0, 0.0)]
    for _, y in sorted(scored, reverse=True):
        if y:
            tp += 1
        else:
            fp += 1
        pts.append((fp / N, tp / P))
    return pts

def auc_pairs(scored):
    pos = [s for s, y in scored if y]
    neg = [s for s, y in scored if not y]
    win = sum(1 if p > n else 0.5 if p == n else 0 for p in pos for n in neg)
    return win / (len(pos) * len(neg))

要点：

  1. ROC 横轴 FPR、纵轴 TPR；对角线是随机猜测（AUC = 0.5），左上角 (0, 1) 是完美分类。
  2. AUC 的含义：随机取一正一负，正样本得分高于负样本的概率。
  3. AUC 只看排序，与阈值无关，对类别比例不敏感，适合不平衡数据。
  4. 风控常用 Gini = 2·AUC − 1，本例 Gini = 0.625（29.20）。

K-means++：让初始中心彼此分散

普通 K-means 随机挑 k 个初始中心，运气不好时两个中心落在同一群里，结果很差。K-means++ 的做法：

  1. 随机选第一个中心；
  2. 对每个点算它到"已选中心中最近那个"的距离 D(x)；
  3. 以正比于 D(x)² 的概率选下一个中心，重复到选满 k 个。

离已有中心越远的点越容易被选中。用 6 个一维点 1, 2, 3, 10, 11, 25 走一遍，第一个中心选 1：

第1轮已选中心 {1}，第二个中心大概率选 25；第2轮已选 {1, 25}，第三个中心几乎必在 10 和 11 之间产生

D² 之和为 0+1+4+81+100+576 = 762，25 被选中的概率 576/762 ≈ 0.756，10 或 11 被选中的概率合计 181/762 ≈ 0.2375。若选中 25，新的 D² 之和为 186，11 的概率 100/186 ≈ 0.538。

肘部法：SSE 下降变缓的拐点

SSE（簇内误差平方和）随 k 增大一定下降，k 等于样本数时降到 0，所以不能直接选 SSE 最小的 k。肘部法画出 SSE–k 曲线，找"再加一个簇也降不了多少"的拐点。12 个一维点分成明显的三群（1–4、10–13、25–28）：

k 从 2 到 3 时 SSE 从 177 降到 15，之后每加一簇只降 4

要点：

  1. 欧氏距离对尺度敏感，使用前要规范化；余弦只看方向，常用于文本和评分。
  2. K-means++ 按 D(x)² 成比例抽样选初始中心，使中心分散，结果更稳定。
  3. 肘部法选 SSE 曲线拐点处的 k；也可以用轮廓系数（29.13）辅助判断。
  4. K-means 适合球形、大小相近的簇；任意形状和含噪声的数据用 DBSCAN。

29.12 层次聚类：单链、全链、平均链

K-means 要先给定 k，得到的是"一刀切"的划分。层次聚类生成一棵完整的合并树（树状图，dendrogram），想要几个簇就在相应高度横切一刀。最常用的是凝聚法（AGNES）：开始每个点自成一簇，每一步合并距离最近的两个簇，直到只剩一簇。与之相反的分裂法（DIANA）从一簇开始逐步拆分。

两个簇之间的距离有三种常见定义：

  • 单链（最近邻）：两簇中最近的一对点的距离；
  • 全链（最远邻）：两簇中最远的一对点的距离；
  • 平均链：两簇所有点对距离的平均值。

def agglomerative(points, link):
    clusters = [(k,) for k in points]
    merges = []
    while len(clusters) > 1:
        best = None
        for a, b in itertools.combinations(clusters, 2):
            ds = [abs(points[x] - points[y]) for x in a for y in b]
            d = {'single': min(ds), 'complete': max(ds), 'average': sum(ds) / len(ds)}[link]
            if best is None or d < best[0]:
                best = (d, a, b)
        d, a, b = best
        clusters = [c for c in clusters if c not in (a, b)] + [tuple(sorted(a + b))]
        merges.append((''.join(sorted(a + b)), d))
    return merges

变量表：points 是点名到坐标的映射；link 选择链接方式；clusters 是当前所有簇；ds 是两簇之间所有点对的距离；merges 记录每次合并的簇和高度。

要点：

  1. 凝聚法自底向上合并，分裂法自顶向下拆分；合并一旦发生就不再撤销。
  2. 单链取最近点对，容易产生链式效应，能发现细长形状的簇；全链取最远点对，倾向于紧凑、直径相近的簇；平均链折中。
  3. 树状图横切的高度决定簇数，不必预先给 k。
  4. 朴素实现要存 n×n 距离矩阵，空间 O(n²)，时间 O(n³)，适合中小数据。

29.13 DBSCAN 与轮廓系数

信用卡交易的地理位置散点图里，客户常去的商圈形状各异，还夹着零星的异地交易。K-means 只会切出球形的簇，还会把每个离群点都硬塞进某个簇。DBSCAN 按"密度"聚类：密集区域连成一簇，稀疏处的点标为噪声。[13]

三种点

两个参数：半径 ε 和最少点数 MinPts。点 p 的 ε-邻域是到 p 距离不超过 ε 的所有点（包括 p 自己）。

  • 核心点：ε-邻域内至少有 MinPts 个点；
  • 边界点：自己不是核心点，但落在某个核心点的 ε-邻域里；
  • 噪声点：既不是核心点也不是边界点。

从一个核心点出发，把它邻域里的点都拉进来；新拉进来的点如果也是核心点，就继续向外扩展；边界点进簇但不再扩展。所有能这样"连起来"的点组成一个簇。

def dbscan(points, eps, min_pts):
    """返回 (labels, kinds, order)。labels: 点→簇号（-1 为噪声）；kinds: core/border/noise；order: 扩展顺序。"""
    labels, order = {}, []
    core = {p for p in points if len(region_query(points, p, eps)) >= min_pts}
    cid = 0
    for p in points:
        if p in labels or p not in core:
            continue
        cid += 1
        labels[p] = cid
        queue = [p]
        while queue:
            q = queue.pop(0)
            order.append(q)
            if q not in core:
                continue                          # 边界点：进簇，但不再向外扩展
            for r in region_query(points, q, eps):
                if r not in labels:
                    labels[r] = cid
                    queue.append(r)
    for p in points:
        labels.setdefault(p, -1)
    kinds = {p: 'core' if p in core else ('border' if labels[p] != -1 else 'noise') for p in points}
    return labels, kinds, order

变量表：region_query(points, p, eps) 返回 p 的 ε-邻域（含 p）；core 是核心点集合；labels 记录每个点的簇号；queue 是待扩展的点；order 记录点被处理的顺序，正好是上面 steps 的顺序。

轮廓系数：聚得好不好

聚类没有标签，怎么评价？轮廓系数对每个点 i 计算：

  • a(i)：i 到同簇其他点的平均距离（越小越紧凑）；
  • b(i)：i 到其他每个簇的平均距离中最小的那个（越大分得越开）；
  • s(i) = (b − a) / max(a, b)，取值在 [−1, 1]。

接近 1 说明 i 分得很好，接近 0 说明它在两簇边界上，为负说明它更像隔壁簇的成员。所有点的 s(i) 取平均就是整体轮廓系数。

一维点 x1…x5 = 1, 2, 4, 8, 9；下标即点的编号

算 x3 = 4：a = (|4−1| + |4−2|)/2 = 2.5；b = (|4−8| + |4−9|)/2 = 4.5；s = (4.5 − 2.5)/4.5 ≈ 0.444。五个点依次为 0.733、0.769、0.444、0.824、0.850，平均 0.724。x3 最靠近边界，得分最低。如果把 x3 错分到簇 2，它的 a 变成 4.5、b 变成 2.5，s = −0.444，负值立刻暴露了分错。

要点：

  1. DBSCAN 的点分三类：核心点、边界点、噪声点；只有核心点能扩展簇。
  2. 优点：不用预设簇数，能发现任意形状的簇，能识别噪声；缺点：对 ε、MinPts 敏感，各簇密度差异大时难以兼顾，高维时距离失效。
  3. 选 ε 的常用办法：画每个点到第 k 个近邻的距离（k-距离图），取拐点。
  4. 轮廓系数 s = (b − a)/max(a, b)，越接近 1 越好，为负说明分错。

29.14 异常检测与反欺诈

盗刷、套现、洗钱在全部交易里占比极小，形态还在不断变化，带标签的样本又少又滞后。异常检测的思路是先刻画"正常"长什么样，再把偏离正常的样本挑出来交给规则和人工核查。[14]

四类方法

方法思想特点
z-score|x − μ|/σ > 3 视为异常简单；要求近似正态，易被异常值本身拉偏（29.2）
IQR超出 Q1 − 1.5·IQR 或 Q3 + 1.5·IQR稳健；适合单变量

LOF：和邻居比密度

只看"离最近的点有多远"会出问题：一个稀疏的正常群里，每个点离邻居都很远。LOF 比较的是自己的密度和邻居的密度。[15]

  1. k-距离 k-dist(p)：p 到第 k 近邻的距离；p 的 k 近邻集合 N_k(p)。
  2. 可达距离 reach(p, o) = max(k-dist(o), d(p, o))：o 附近的点到 o 的距离至少按 o 的 k-距离算，起平滑作用。
  3. 局部可达密度 lrd(p) = |N_k(p)| / Σ reach(p, o)，即平均可达距离的倒数。
  4. LOF(p) = 邻居 lrd 的平均值 / lrd(p)。约等于 1 表示和邻居一样密，明显大于 1 表示比邻居稀疏得多。

9 个一维点：密集群 a=1、b=2、c=3、d=4，稀疏群 e=20、f=26、h=32、i=38，以及 g=9。取 k = 2：

  • g 的 2 近邻是 d（距离 5）和 c（距离 6），k-dist(g) = 6；
  • c、d 的 k-距离分别是 1、2，所以 reach(g,c) = max(1, 6) = 6，reach(g,d) = max(2, 5) = 5；
  • lrd(g) = 2/(6+5) ≈ 0.182，而 lrd(c) = lrd(d) ≈ 0.667；
  • LOF(g) = 0.667 / 0.182 ≈ 3.67。

g 的 k-距离只有 6，比稀疏群里 e 的 11 还小，但它挨着一个很密的群，LOF 最高

孤立森林：越容易被切出来越可疑

孤立森林反复随机挑一个特征、在其取值范围内随机挑一个切点，把数据一分为二，直到每个点被单独隔开。异常点"少而不同"，往往几刀就被切出来；正常点挤在一起，要切很多刀。[16]

把一个点在多棵树中的平均路径长度记为 E(h)，异常分数为 s = 2^(−E(h)/c(n))，其中 c(n) = 2H(n−1) − 2(n−1)/n 是 n 个样本时的平均路径长度，H(i) ≈ ln i + 0.5772。每棵树默认抽 n = 256 个样本，c(256) ≈ 10.24：

反欺诈系统怎样组合这些方法

实时链路：规则拦已知手法，模型打分发现新手法，复核结果回流成为训练标签

  • 规则与名单：处理已知手法，例如"同一设备 10 分钟内登录 5 个账户"，可解释、上线快。
  • 有监督模型（GBDT、逻辑回归）：在有欺诈标签的历史数据上训练，准确率高，但只认识见过的手法。
  • 无监督方法（孤立森林、LOF）：没有标签也能发现"和大家不一样"的交易，用来捕捉新手法。
  • 关联图分析：把账户、设备、手机号连成图，共用设备的一群账户可能是一个团伙（第 4 章的连通分量）。

要点：

  1. z-score、IQR 适合单变量快速筛查；LOF 适合密度不均的数据；孤立森林适合高维大数据。
  2. LOF ≈ 1 为正常，明显大于 1 为局部离群；它比较的是相对密度。
  3. 孤立森林的分数接近 1 为异常，明显小于 0.5 为正常；路径越短越异常。
  4. 反欺诈的特点：极度不平衡、标签滞后、对手会变；实践中规则、有监督、无监督、图分析组合使用。

矩阵分解：用隐因子解释评分

评分表大部分格子是空的。矩阵分解把评分矩阵 R（用户 × 物品）近似为两个小矩阵的乘积 R ≈ P·Qᵀ：每个用户一个 f 维向量 p_u，每个物品一个 f 维向量 q_i，预测评分 r̂ = p_u · q_i。f 个维度叫隐因子，可以理解成"偏好稳健""偏好高收益"这类说不出名字的口味。[18]

例如 f = 2，用户向量 p = (0.9, 0.2)，某基金的向量 q = (4, 1)，预测评分 = 0.9×4 + 0.2×1 = 3.8。P、Q 通过最小化"已知评分的平方误差 + 正则项"学出来，常用随机梯度下降或交替最小二乘（ALS）。

冷启动

新用户没有评分、新产品没人评过，协同过滤无从下手，这叫冷启动。常见办法：新用户先推热门产品或用注册问卷、年龄职业等属性做推荐；新产品用产品内容特征（风险等级、期限）找相似产品（基于内容的推荐）；实际系统多把协同过滤和基于内容的方法混合使用。

要点：

  1. 基于用户：找相似用户，用他们的评分加权；基于物品：找相似物品，用该用户自己的评分加权。
  2. 相似度常用余弦或皮尔逊相关；只在共同评分的项上计算。
  3. 矩阵分解 R ≈ P·Qᵀ，预测评分 = 用户向量与物品向量的内积。
  4. 冷启动分新用户、新物品、新系统三种，靠热门推荐、属性和内容特征缓解。

29.16 文本挖掘简述

客服每天收到几千条投诉和留言："转账失败一直没退款""到账很快很满意"。人工逐条看不过来，文本挖掘把这些文字变成数字，再做分类（自动派单）、聚类（发现新的投诉热点）、情感分析（满意度监控）。

文本挖掘流水线：中文先分词，再把每篇文档变成一个向量

  • 分词：中文没有空格，要先切分成词，例如“转账失败”切分为“转账”和“失败”。

TF-IDF = TF × IDF。TF = 词在本文档中的次数 / 本文档总词数；IDF = ln(文档总数 / 含该词的文档数)。4 条留言分词后：

文档词
d1转账 失败 退款
d2转账 成功
d3转账 到账 很快 满意
d4退款 太慢 投诉

d1 中三个词的 TF 都是 1/3。"转账"出现在 3 篇里，TF-IDF = 1/3 × ln(4/3) ≈ 0.096；"退款"出现在 2 篇里，1/3 × ln2 ≈ 0.231；"失败"只出现在 d1，1/3 × ln4 ≈ 0.462。最能代表 d1 的词是"失败"。[19]

情感分析最简单的做法是查情感词典：正面词 +1、负面词 −1。d3 有"很快""满意"，得 +2；d4 有"太慢""投诉"，得 −2。词典法的盲点是否定和反讽："不 满意"只查到"满意"，得 +1，方向反了。实际系统用规则处理否定词，或直接训练分类模型。

要点：

  1. 文本挖掘的流程依次是分词、去除停用词、向量化，再进行分类、聚类或情感分析。

B · 错误：把 TF 算成 1/2 了；TF 的分母是本文档总词数 4。

29.17 评分卡（一）：建模流程与卡方分箱

信贷审批要回答"这个人借钱会不会还"，监管和业务还要求回答"为什么拒绝他"。评分卡把逻辑回归模型改写成一张加分减分表：每个变量分成几个箱，每个箱对应一个分数，申请人的各项分数加起来就是总分，分数越高风险越低。审批员能逐项看懂，模型也便于验证和监控。[20]

按用途分，常见的有 A 卡（申请评分，贷前审批）、B 卡（行为评分，贷中调额和预警）、C 卡（催收评分，贷后）。下面以 A 卡为例。

建模流程

评分卡九步：29.17 讲 ①–④，29.18 讲 ⑤，29.19 讲 ⑥ 和 ⑧，29.20 讲 ⑦ 和 ⑨

  1. 定义好坏：在观察点之前的一段时间（观察期）取特征，之后一段时间（表现期，如 12 个月）看表现。例如表现期内逾期 90 天以上记为坏，从未逾期记为好，介于两者之间的"不确定"样本通常剔除。
  2. 样本划分：除了随机切出的测试集，还要留一段更晚时间的样本做跨时间验证（OOT），检验模型在未来客群上是否依然有效。[21]
  3. 分箱：把连续变量切成若干区间、把取值很多的类别变量合并成几组。

为什么要分箱

  • 风险和变量的关系常常是非线性的（年龄太小、太大风险都高），分箱后每箱单独给分，就能刻画这种关系；
  • 极端值自动落进首尾箱，模型更稳健；
  • 缺失值可以单独成箱；
  • 分数表按箱给分，业务人员一看就懂。

好的分箱要满足：每箱样本占比不太小（常要求 ≥ 5%），各箱坏样本率呈单调或符合业务逻辑，箱数一般 3–7 个。

卡方分箱（ChiMerge）

卡方分箱是有监督、自底向上的方法：先把变量切成很多细箱，每次计算所有相邻两箱的 χ²（2×2 列联表：两箱 × 好坏），合并 χ² 最小的一对——χ² 越小，两箱的好坏分布越接近，越没必要分开。重复直到箱数达到上限，或所有相邻 χ² 都超过阈值（如自由度 1、显著性 0.05 的 3.841）。[22]

def chimerge(bins, max_bins):
    """bins: [[标签, 好, 坏], ...] 按变量取值排序。每轮合并卡方最小的相邻两箱。返回每轮快照。"""
    cur = [list(b) for b in bins]
    history = []
    while len(cur) > max_bins:
        chis = [chi2_2x2(cur[i][1:], cur[i + 1][1:]) for i in range(len(cur) - 1)]
        i = min(range(len(chis)), key=chis.__getitem__)
        history.append(([tuple(b) for b in cur], [round(c, 3) for c in chis], i))
        lo, hi = cur[i][0].split('-')[0], cur[i + 1][0].split('-')[1]
        cur[i:i + 2] = [[lo + '-' + hi, cur[i][1] + cur[i + 1][1], cur[i][2] + cur[i + 1][2]]]
    return cur, history

变量表：cur 是当前各箱 [标签, 好, 坏]；chis 是相邻两箱的 χ² 列表；i 是 χ² 最小的位置；history 保存每轮快照，就是上面 steps 的内容；chi2_2x2 计算两箱的 2×2 卡方值。

要点：

  1. 评分卡的开发流程依次是：定义好坏样本、准备样本、数据清洗、分箱、计算 WOE 和 IV、建立逻辑回归模型、评估、刻度转换、上线和监控。

29.18 评分卡（二）：WOE 与 IV

分好箱后，每个箱要变成一个数字喂给逻辑回归。直接用箱号 1、2、3 没有意义；WOE（证据权重） 用"这一箱的坏人比全体更集中多少"来编码，而 IV（信息值） 把各箱的差异汇总成一个数，衡量这个变量有多大的区分能力。

定义

设全体好人数 G、坏人数 B，第 i 箱有 Gᵢ 个好人、Bᵢ 个坏人。

  • WOEᵢ = ln( (Bᵢ/B) / (Gᵢ/G) )，即 ln(坏人占比 / 好人占比)；
  • IV = Σ (Bᵢ/B − Gᵢ/G) × WOEᵢ。

每一项的两个因子同号，所以 IV 的每个分量都 ≥ 0。WOE 还有一个等价写法：WOEᵢ = ln(Bᵢ/Gᵢ) − ln(B/G)，即"本箱的坏好比"相对"总体坏好比"的对数差，它和逻辑回归的对数几率天然对齐。

def woe_iv(bins):
    """bins: [(标签, 好, 坏)]。WOE = ln(坏占比 / 好占比)（坏样本越集中，WOE 越大）。"""
    G = sum(b[1] for b in bins)
    B = sum(b[2] for b in bins)
    rows, iv = [], 0.0
    for name, g, b in bins:
        pg, pb = g / G, b / B
        woe = math.log(pb / pg)
        part = (pb - pg) * woe
        iv += part
        rows.append((name, pg, pb, woe, part))
    return rows, iv

要点：

  1. WOE = ln(坏占比/好占比)：大于 0 表示该箱坏人更集中，小于 0 表示好人更集中。
  2. IV = Σ(坏占比 − 好占比)×WOE，每项非负；IV 用来筛选变量，常保留 IV ≥ 0.02（或 ≥ 0.1）的变量。
  3. WOE 编码让每个变量与对数几率近似线性，逻辑回归拟合得好、系数可解释。
  4. IV 过高（> 0.5）先怀疑泄漏。

易错点

  • 有的教材定义 WOE = ln(好占比/坏占比)，符号整体相反，IV 不变；逻辑回归系数的符号也随之相反。本章统一用 ln(坏/好)，所以系数应为正。

小结： WOE = ln(坏样本占比/好样本占比)，IV = Σ(坏样本占比−好样本占比)·WOE；IV 以 0.02、0.1、0.3、0.5 为界，依次表示无预测力、弱、中、强和可疑。

29.19 评分卡（三）：逻辑回归与 PDO 刻度

逻辑回归输出的是违约概率或对数几率，例如 ln(odds) = −0.7257。业务需要的是"600 分"这种好记、加减直观的分数。刻度换算用一个线性变换把对数几率变成分数，再把总分拆到每个变量的每个箱上，就得到评分表。

逻辑回归（第 19 章）

令 p = P(坏)，odds = p/(1−p) 为坏好比，用 WOE 编码后的变量建模：

ln(odds) = β₀ + β₁·WOE₁ + β₂·WOE₂ + …

因为 WOE 越大越坏，系数 β 应为正。若某个系数为负，往往是变量之间高度相关（共线性），要先查相关系数或方差膨胀因子（VIF），删掉冗余变量。

刻度：基准分与 PDO

设 Score = A − B·ln(odds)（odds 越大越坏，分数越低）。业务给两个条件：

  1. 基准点：odds = 1:50（坏:好）时，分数为 600；
  2. PDO（Points to Double the Odds） = 20：odds 每翻一倍，分数降 20 分。

由第 2 条：(A − B·ln(2·odds)) − (A − B·ln odds) = −B·ln2 = −20，所以 B = 20/ln2 ≈ 28.854。 由第 1 条：600 = A − B·ln(1/50)，所以 A = 600 + B·ln(1/50) = 600 − 28.854 × 3.912 ≈ 487.12。

odds 每翻一倍分数降一个 PDO（20 分）；基准点 1:50 对应 600 分

审批时，系统查表把申请人各变量的得分加上基础分即可，不再需要算指数。很多机构把基础分平均摊到各变量上，让表里只出现"变量得分"。

def scale_params(base_score, base_odds, pdo):
    """odds 指 坏:好。score = A - B * ln(odds)。odds 翻倍，分数下降 PDO。"""
    B = pdo / math.log(2)
    A = base_score + B * math.log(base_odds)
    return A, B

要点：

  1. 刻度公式 Score = A − B·ln(odds)，B = PDO/ln2，A = 基准分 + B·ln(基准 odds)（odds 为坏:好）。
  2. odds 每翻一倍，分数降 PDO；odds 每减半，分数升 PDO。
  3. 每个箱的得分 = −B·β·WOE；总分 = 基础分（A − B·β₀）+ 各变量得分。
  4. 用 WOE = ln(坏/好) 编码时，逻辑回归系数应为正，出现负号先查共线性。

多选 · 理解检查 21　基准点 odds = 1:50 时 600 分，PDO = 20（odds 为坏:好）。哪些计算正确？

A. odds = 4:50 时分数为 560

B. odds = 1:100 时分数为 620

C. B = 20/ln2 ≈ 28.85

D. odds = 2:50 时分数为 620

查看答案与每个选项的解析

A · 正确：odds 翻了两倍（×4），分数降 2 × 20 = 40。

B · 正确：odds 减半，分数升 20。

C · 正确：由 B·ln2 = PDO 得到。

D · 错误：odds 变大是风险变高，分数应降到 580。

易错点

  • 如果 odds 定义为好:坏，公式变成 Score = A + B·ln(odds)，A 的算法也跟着变；先看清题目的 odds 方向。
  • 刻度换算是单调线性变换，它不改变模型的排序能力，KS、AUC 换算前后完全一样。

小结： 刻度公式中 B = PDO/ln2，A = 基准分 + B·ln(基准坏好比)；odds 每翻一倍，分数下降 PDO；每箱的得分为 −B·β·WOE，总分等于基础分加上各项得分。

29.20 评分卡（四）：KS、AUC/Gini、PSI、拒绝推断与监控

模型建好了，要回答三个问题：它把好人坏人分得开吗（KS、AUC、Gini）？上线后客群变了没有（PSI）？训练样本只包含被批准的人，这个偏差怎么处理（拒绝推断）？

KS：好坏累计分布的最大差距

把样本按分数从低到高排序（或分成若干箱），分别算坏人和好人的累计占比，KS = max |累计坏% − 累计好%|。KS 越大，说明在某个切分点上，模型把坏人往低分段集中得越多。

def ks_table(bad, good):
    """bad、good：按分数从低到高各箱的坏、好人数。返回 [(累计坏%, 累计好%, 差)] 与 KS。"""
    TB, TG = sum(bad), sum(good)
    cb = cg = 0
    rows = []
    for b, g in zip(bad, good):
        cb += b
        cg += g
        rows.append((cb / TB, cg / TG, cb / TB - cg / TG))
    return rows, max(r[2] for r in rows)

AUC 与 Gini

同一张表也能画 ROC：横轴是累计好%（被误拒的好人比例），纵轴是累计坏%（被拒掉的坏人比例），用梯形法求面积得 AUC ≈ 0.7628，Gini = 2·AUC − 1 ≈ 0.5256。Gini 系数又叫准确率比（AR），把"随机"映射为 0、"完美"映射为 1。KS 只看一个最优切点，AUC 和 Gini 综合了所有切点。

PSI：分数分布稳定吗

PSI（群体稳定性指标） 比较建模时（预期）和上线后（实际）的分数分布：PSI = Σ (实际% − 预期%) × ln(实际% / 预期%)。形式和 IV 一样，只是比较对象从"坏 vs 好"换成了"现在 vs 当初"。

常用阈值：PSI < 0.1 稳定；0.1–0.25 有变化，需关注原因；> 0.25 显著变化，要排查客群、渠道、数据口径，必要时重建模型。第 6 个月的 0.295 已经越线。对单个变量做同样的计算叫 CSI（特征稳定性指标），用来定位是哪个变量的分布变了。

def psi(expected, actual):
    return sum((a - e) * math.log(a / e) for e, a in zip(expected, actual))

拒绝推断：被拒的人没有表现

训练评分卡时只有被批准的申请人才有还款表现，被拒绝的人好坏未知。只用通过样本建模，模型从没见过低分客群，会低估他们的风险，这叫样本选择偏差。拒绝推断用各种办法给被拒样本补上推断的标签，再与通过样本一起建模。[20]

拒绝推断：给拒绝样本补上推断的好坏，让模型也能看到低分客群

  • 硬截断法：用通过样本建的模型给拒绝样本打分，低于某分数线的记为坏，其余记为好。
  • 打包法（分组法）：把拒绝样本按分数分组，按各组在通过样本中的坏样本率随机分配好坏。
  • 模糊扩充：每个拒绝样本拆成一个"好"、一个"坏"，权重分别是预测的好、坏概率。
  • 其他：用外部征信数据看被拒者在别家的表现；或在风险可控范围内随机放行一小部分低分申请人，直接收集表现。

上线后的监控

监控类型看什么典型指标
前端（不等表现）分数和变量的分布是否漂移PSI、CSI、通过率
后端（等表现期成熟）模型区分能力是否下降KS、AUC、各分数段坏账率（按放款月份看，即账龄分析）
决策规则和人工是否频繁推翻模型人工否决率、分数段通过率

模型的开发、验证、上线、监控、退役都要留文档，由独立团队验证，这是模型风险管理的基本要求。[23]

要点：

  1. KS = max|累计坏% − 累计好%|，衡量最优切点处的区分度；本例 0.417。
  2. Gini = 2·AUC − 1；KS、AUC、Gini 都只看排序，刻度换算不改变它们。
  3. PSI = Σ(实际% − 预期%)·ln(实际%/预期%)；< 0.1 稳定，0.1–0.25 关注，> 0.25 显著变化。
  4. 拒绝推断解决"只有通过样本才有表现"的样本偏差；常用硬截断、打包、模糊扩充。
  5. 监控分前端（PSI、CSI）和后端（KS、坏账率），前端可以在表现期之前就报警。

多选 · 理解检查 23　某分数箱建模时占 20%，上线后占 30%。下列哪些正确？

A. 该箱的 PSI 分量 = 0.1 × ln1.5 ≈ 0.0405

B. 如果该箱占比降为 10%，PSI 分量 ≈ 0.0693

C. PSI 分量可能为负，各箱会互相抵消

D. PSI = 0.0405 已超过 0.25，必须重建模型

查看答案与每个选项的解析

A · 正确：(0.3 − 0.2) × ln(0.3/0.2)。

B · 正确：(0.1 − 0.2) × ln(0.5) = (−0.1)(−0.693)；每个分量总是非负。

C · 错误：两个因子同号，每个分量 ≥ 0，变化只会累加。

D · 错误：0.0405 只是一个箱的分量，且远低于 0.25。

易错点

  • KS 的累计方向（从低分累计还是从高分累计）不影响最大差值的大小，但要两条曲线用同一方向。
  • PSI 中某箱占比为 0 会出现 ln0，实际计算时给 0 占比加一个很小的数，或合并相邻箱。

小结： KS 是两条累计分布曲线之间的最大差距，Gini = 2AUC − 1；PSI 与 IV 的公式相同，以 0.1 和 0.25 为界；拒绝推断为被拒绝的样本补充标签；前端监控看 PSI，后端监控看 KS 和坏账率。
