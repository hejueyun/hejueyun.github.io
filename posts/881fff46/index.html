5.1 从线性模型到神经元：激活函数与多层感知机

第 3 章的线性回归把输入加权求和得到一个数，逻辑回归再套一个 Sigmoid 变成概率。它们只能画出一条直线（或一个平面）把数据分开。现实里"收入高且负债低才放贷"这种规则，边界是弯的，单个线性模型画不出来。深度学习的办法是：把很多个"加权求和再弯一下"的小单元一层层叠起来。这个小单元就叫神经元。

一个神经元做两件事：先算加权和 z = w·x + b（w 是权重向量，b 是偏置），再用激活函数 φ 把 z 变成输出 a = φ(z)。权重和偏置是训练要学的参数；激活函数是事先选定的固定函数。

一个神经元：z = 2×1 + (−1)×2 + 1 = 1，ReLU(1) = 1

完整走一遍：输入 x = [1, 2]，权重 w = [2, −1]，偏置 b = 1。

  1. 加权和：z = 2×1 + (−1)×2 + 1 = 1。
  2. 若激活函数是 ReLU（取 max(0, z)），输出 a = 1；若是 Sigmoid，输出 1/(1+e⁻¹) ≈ 0.7311。
  3. 把权重换成 w = [−1, −1]，z = −1 − 2 + 1 = −2，ReLU 输出 0：这个神经元"没被激活"。

四个常用激活函数

激活函数的作用是引入非线性。如果没有它，两层线性变换 W2(W1x) 可以合并成一个矩阵 (W2W1)x，叠多少层都等价于一层（practice 里用 W1=[[1,2],[0,1]]、W2=[[3,0],[1,1]] 验证过两种算法都得到 [−3, −2]）。

Sigmoid 压到 (0,1)，Tanh 压到 (−1,1)，ReLU 负半轴为 0，GELU 在负半轴有一个小凹（最低约 −0.17）

多层感知机

把许多神经元并排组成一层，层与层首尾相接，就是多层感知机（MLP，也叫全连接网络）。每层的计算是 a = φ(Wx + b)，其中 W 的形状是"输出个数 × 输入个数"。

2-3-1 的多层感知机：参数 = (2×3+3) + (3×1+1) = 13 个

参数量怎么数：一个全连接层有 d 个输入、h 个输出，就有 d×h 个权重和 h 个偏置，共 dh + h 个参数。3 输入 4 输出的层有 3×4+4 = 16 个参数。参数被所有样本共享，batch 里放 100 个样本，参数仍是 16 个。

要点：

  • 神经元 = 加权和 + 激活函数；激活函数提供非线性，让多层网络能拟合弯曲的边界。
  • 标准答案句："若没有非线性激活，多层线性层的复合仍是一个线性变换。"
  • Sigmoid/Tanh 两端饱和，导数接近 0，深层网络里容易造成梯度消失；ReLU 正半轴导数为 1，缓解了这个问题。
  • 全连接层参数量 = 输入数 × 输出数 + 输出数（每个输出一个偏置）。
  • 万能逼近定理：只要隐藏层足够宽，单隐藏层 MLP 就能以任意精度逼近闭区间上的连续函数；实践中"更深"比"更宽"往往用更少参数达到同样效果。

单选 · 理解检查 1　输入 x=[3,−1]，权重 w=[1,2]，偏置 b=−2，激活函数为 ReLU。这个神经元的输出是多少？

A. 0

B. −1

C. 1

D. 0.2689

查看答案与每个选项的解析

A · 正确：z = 1×3 + 2×(−1) + (−2) = −1，ReLU(−1) = max(0, −1) = 0。

B · 错误：−1 是加权和 z；ReLU 会把负数截成 0。

C · 错误：漏加了偏置：3 − 2 = 1，再加 b = −2 才是 −1。

D · 错误：这是 Sigmoid(−1) 的值，题目用的是 ReLU。

易错点

  • ReLU 的输出可以大于 1，它没有上界；把输出压到 (0,1) 的是 Sigmoid。
  • 参数量与 batch 大小无关；与 batch 大小成正比的是激活值占用的显存。
  • GELU 在负半轴会输出小的负数，所以它的最小值约是 −0.17，而非 0。

小结： 神经元先计算 w·x + b，再经过激活函数；激活函数带来非线性；全连接层的参数量等于输入维度乘以输出维度再加上输出维度。

5.2 前向与反向传播：用计算图手算梯度

训练网络就是调整参数让损失变小。第 1 章讲过梯度下降：参数沿负梯度方向走一小步。难点在于网络有成千上万个参数，每个参数的梯度怎样高效求出？答案是反向传播：先从输入到输出算一遍（前向），再从损失往回，按链式法则把每一步的局部导数乘起来（反向）。链式法则的基础见第 2 章 2.14。[1]

计算图把一次计算拆成节点：每个节点是一步运算，边表示数据流向。前向时数值沿箭头流动；反向时梯度逆着箭头流动，每经过一个节点就乘上该节点的局部导数。

手算一个两层小网络

网络结构：隐藏层只有一个神经元 h = ReLU(w1·x + b1)，输出层 ŷ = w2·h + b2，损失 L = ½(ŷ − y)²。取 x = 2、标签 y = 1，初始参数 w1 = 0.5、b1 = 0.5、w2 = 1、b2 = 0。

计算图：方框是参数或中间值，箭头是前向数据流；反向时梯度逆着箭头走

反向传播：从损失一路乘回每个参数

1 / 6

第1步 · 前向：从左到右算出每个节点的值

z1 = 0.5×2 + 0.5 = 1.5
h = ReLU(1.5) = 1.5
ŷ = 1×1.5 + 0 = 1.5
L = ½(1.5 − 1)² = 0.125
2 / 6

第2步 · 从损失出发：∂L/∂ŷ

L = ½(ŷ − y)²，对 ŷ 求导得 ŷ − y = 1.5 − 1 = 0.5
3 / 6

第3步 · 输出层参数：乘上 ŷ 对 w2、b2 的局部导数

∂ŷ/∂w2 = h = 1.5  → ∂L/∂w2 = 0.5×1.5 = 0.75
∂ŷ/∂b2 = 1      → ∂L/∂b2 = 0.5
∂ŷ/∂h  = w2 = 1 → ∂L/∂h  = 0.5×1 = 0.5
4 / 6

第4步 · 穿过 ReLU：z1 > 0，局部导数是 1

ReLU 在 z1 = 1.5 > 0 处导数为 1，所以 ∂L/∂z1 = 0.5×1 = 0.5
若 z1 ≤ 0，导数为 0，梯度在这里被切断
5 / 6

第5步 · 隐藏层参数：乘上 z1 对 w1、b1 的局部导数

∂z1/∂w1 = x = 2 → ∂L/∂w1 = 0.5×2 = 1.0
∂z1/∂b1 = 1     → ∂L/∂b1 = 0.5
6 / 6

第6步 · 更新：学习率 0.1，每个参数减去 0.1×梯度

w1: 0.5 − 0.1×1.0 = 0.4     b1: 0.5 − 0.1×0.5 = 0.45
w2: 1 − 0.1×0.75 = 0.925    b2: 0 − 0.1×0.5 = −0.05
再前向一次：ŷ = 1.10625，L = 0.005645，损失从 0.125 降到约 0.0056

深度学习框架里的自动微分（PyTorch 的 autograd）做的正是这件事：前向时记录计算图，调用 backward() 时按拓扑逆序把局部导数乘回去。

变量表：x, y 是一个样本的输入和标签；w1, b1, w2, b2 是四个参数；dL_dyhat 等是损失对各节点的梯度。

def two_layer_backward(x, y, w1, b1, w2, b2):
    """手写链式法则，返回四个参数的梯度。"""
    z1, h, yhat, loss = two_layer_forward(x, y, w1, b1, w2, b2)
    dL_dyhat = yhat - y
    dL_dw2 = dL_dyhat * h
    dL_db2 = dL_dyhat
    dL_dh = dL_dyhat * w2
    dL_dz1 = dL_dh * (1.0 if z1 > 0 else 0.0)
    dL_dw1 = dL_dz1 * x
    dL_db1 = dL_dz1
    return {"w1": dL_dw1, "b1": dL_db1, "w2": dL_dw2, "b2": dL_db2}

梯度消失与梯度爆炸

反向传播要把每层的局部导数连乘。若每层乘的数小于 1，乘多了趋向 0，前面的层几乎学不动，这叫梯度消失；若大于 1，乘多了数值溢出，这叫梯度爆炸。Sigmoid 的导数 σ(z)(1−σ(z)) 最大只有 0.25（在 z = 0 处），10 层连乘后最多剩 0.25¹⁰ ≈ 9.5×10⁻⁷；而每层乘 1.5，10 层后变成约 57.7 倍。

纵轴取对数：−6 表示缩小到百万分之一，1.76 表示放大约 57.7 倍

问题原因常用对策
梯度消失饱和激活函数、层数深、权重太小改用 ReLU/GELU；残差连接（5.3）；合适的初始化；归一化层；RNN 改用 LSTM/GRU
梯度爆炸权重太大、RNN 长序列连乘梯度裁剪（把梯度范数截到上限）；合适的初始化；降低学习率

初始化

权重初始值决定了一开始信号和梯度的大小。全部初始化为 0 会让同一层所有神经元算出相同的值、收到相同的梯度，永远学成一样，这叫对称性问题，所以权重要随机初始化。随机的方差也要合适：

  • Xavier（Glorot）初始化：方差取 2/(fan_in + fan_out)，适合 Tanh、Sigmoid。fan_in 是这一层的输入个数，fan_out 是输出个数。
  • He（Kaiming）初始化：方差取 2/fan_in，专为 ReLU 设计（ReLU 把一半输入置 0，所以方差要乘 2 补回来）。fan_in = 512 时标准差 = √(2/512) = 0.0625。[5]

要点：

  • 标准答案句："反向传播利用链式法则，从输出层向输入层逐层计算损失对各参数的梯度，并复用中间结果，避免重复计算。"
  • 某参数的梯度 = 上游传来的梯度 × 本节点的局部导数；分叉的节点把各分支梯度相加。
  • 梯度消失主因：Sigmoid/Tanh 饱和 + 层数深；对策：ReLU、残差、归一化、He 初始化、LSTM。梯度爆炸对策：梯度裁剪。
  • 偏置可以初始化为 0；权重要随机，否则对称性无法打破。

A. 0

B. −1.0

C. 1.0

D. −0.5

查看答案与每个选项的解析

A · 正确：z1 = 0.5×(−2) + 0.5 = −0.5 < 0，ReLU 导数为 0，梯度在 ReLU 处被切断，w1 的梯度为 0。

B · 错误：这是忽略了 ReLU 导数直接按 (ŷ−y)×w2×x 算的结果；z1 为负时要乘 0。

C · 错误：这是 x = 2 时的梯度。

D · 错误：此时 h = 0，ŷ = 0，∂L/∂ŷ = −1，但穿过 ReLU 后仍要乘 0。

易错点

  • 反向传播算的是梯度，更新参数的是优化器（SGD、Adam 等），两者是训练的两个步骤。
  • ReLU 在 z ≤ 0 时导数为 0：大量神经元长期落在负半轴就成了"死神经元"，可改用 Leaky ReLU 或 GELU。
  • 梯度裁剪治的是爆炸；消失要靠结构和初始化来解决。

小结： 前向传播计算各层的值，反向传播把局部导数逐层相乘；连乘的因子小于 1 时梯度消失，大于 1 时梯度爆炸；ReLU 配合 He 初始化，Tanh 配合 Xavier 初始化。

5.3 训练技巧：损失、优化器、归一化与正则

有了梯度，还要解决一串实际问题：用什么损失？步子迈多大？网络很深时怎样稳定训练？怎样防止把训练集背下来？这一节把常用技巧按"训练一步要经过的环节"排开讲。

训练一步经过的环节，本节每个技巧都挂在其中一个环节上

损失函数：回归用 MSE，分类用交叉熵

均方误差 MSE = 平均的 (预测 − 真实)²，用于回归。预测 [2.5, 0, 2]、真实 [3, −0.5, 2]，MSE = (0.25 + 0.25 + 0)/3 ≈ 0.1667。

交叉熵用于分类。网络先输出每类一个分数（logits），用 softmax 变成概率：pᵢ = e^{zᵢ} / Σⱼ e^{zⱼ}；损失是正确类别概率的负对数 −log p_正确。

完整走一遍：三分类 logits = [2, 1, 0]。

  1. 取指数：e² ≈ 7.389，e¹ ≈ 2.718，e⁰ = 1，和为 11.107。
  2. 归一化：p ≈ [0.6652, 0.2447, 0.0900]，三者之和为 1。
  3. 若正确类别是第 0 类，损失 = −ln 0.6652 ≈ 0.4076；若正确类别是第 2 类，损失 = −ln 0.09 ≈ 2.4076。预测越偏离正确答案，损失越大。

为什么分类不用 MSE？ 对 Sigmoid 输出，假设模型错得离谱：输出 0.01，标签是 1。交叉熵对 z 的梯度是 a − y = −0.99，很大，纠错快；MSE 的梯度是 (a−y)·a(1−a) ≈ −0.0098，被 Sigmoid 的饱和导数压小了 100 倍，几乎学不动。

优化器：SGD、Momentum、Adam

优化器更新规则（直观）特点
SGDθ ← θ − η·g最简单；在狭长山谷里来回震荡
Momentumv ← βv + g；θ ← θ − η·v像滚下坡的球，有惯性；方向一致时越滚越快：梯度恒为 1、β = 0.9 时速度趋近 1/(1−0.9) = 10
Adam同时维护梯度的一阶矩 m（均值）和二阶矩 v（平方的均值），步长 ∝ m/√v每个参数自适应步长；第一步的步长约等于学习率 η，与梯度绝对大小无关（梯度 100 和 0.01 第一步都走约 0.001）[6]

η 是学习率。训练大模型常用 AdamW：把权重衰减（L2 的一种实现）从梯度里分离出来单独做。[7]

学习率与调度

学习率太大，损失震荡甚至发散；太小，收敛慢。大模型训练通常先预热（warmup：从小学习率线性升到峰值），再余弦退火（按余弦曲线降到接近 0）。下图是共 10 步、预热 2 步、峰值 10×10⁻⁴ 的调度：

正则化：L2、Dropout 与早停

  • L2 正则：损失里加 λ·Σw²，让权重倾向于小，模型更平滑。
  • Dropout：训练时每个神经元以概率 p 被临时置 0，迫使网络不依赖少数神经元。常用"倒置 Dropout"：训练时把保留下来的值乘 1/(1−p)（p = 0.5 时乘 2），推理时什么都不做，直接用全部神经元。[8]
  • 早停：每个 epoch 看验证集损失，验证损失连续若干轮不再下降就停止，并取验证损失最低时的参数。

示意数据：训练损失一直下降，验证损失先降后升，两线分开处就是过拟合开始

BatchNorm 与 LayerNorm：在哪个方向上归一化

两者都把一组数减去均值、除以标准差，再乘可学习的缩放 γ、加偏移 β。区别在于"一组数"怎么取。用一个 2 个样本 × 3 个特征的小矩阵看：[9] [10]

LayerNorm：每一行（一个样本）自己算均值方差。第 0 行均值 2，归一化后为 [−1.22, 0, 1.22]；第 1 行同样

BatchNorm：每一列（一个特征）跨样本算均值方差。第 0 列 [1,3] 均值 2，归一化后为 [−1, 1]；每列都变成 [−1, 1]

归一化方向同一特征、跨 batch 内样本同一样本、跨所有特征
依赖 batch 大小依赖；batch 很小时统计量不稳不依赖
训练与推理训练用当前 batch 统计量；推理用训练时累计的滑动平均两阶段计算方式相同
典型使用CNNTransformer、RNN（序列长度可变）

Transformer 用 LayerNorm，因为一个 batch 里句子长度不同、生成时 batch 可能只有 1，跨样本统计不可靠。许多大模型用 RMSNorm：只除以均方根、省去减均值，计算更省。[11]

残差连接

残差连接把一层的输入直接加到输出上：y = x + F(x)。网络只需学习"在 x 基础上的修正量" F(x)；反向时 ∂y/∂x = 1 + ∂F/∂x，那个"1"给梯度开了一条直通的高速路，几十上百层也能训练。ResNet 用它训练了 152 层的网络。[12]

残差块：下路学修正量 F(x)，上路把 x 原样送到加法处，梯度也沿上路直通

要点：

  • 回归用 MSE，分类用 softmax + 交叉熵；交叉熵配 Sigmoid/softmax 时梯度是 (预测 − 标签)，不会被饱和压小。
  • Adam = Momentum（一阶矩）+ 自适应步长（二阶矩）+ 偏差修正；大模型常用 AdamW + 预热 + 余弦退火。
  • 标准答案句："BatchNorm 在 batch 维度上对每个特征归一化，LayerNorm 在特征维度上对每个样本归一化；Transformer 使用 LayerNorm。"
  • 残差连接缓解深层网络的退化和梯度消失；Dropout、L2、早停、数据增强都是防过拟合手段。

5.4 卷积神经网络：尺寸、参数量、池化与感受野

一张 32×32 的彩色图片有 32×32×3 = 3072 个数。用全连接层接 8 个神经元，就要 3072×8 + 8 = 24,584 个参数，而且"左上角的猫"和"右下角的猫"要分别学。卷积神经网络（CNN）抓住图像的两个特点来省参数：有用的模式是局部的（边缘、角点只占几个像素），同一种模式可以出现在任何位置。[13]

卷积层用一个小窗口（卷积核，例如 3×3）在图上滑动；每到一个位置，把窗口内的像素与核的权重逐个相乘再求和，得到输出图上的一个数。整张图共用同一个核，这叫权重共享。一个核只能检测一种模式，所以一层通常有多个核，每个核产生一张输出图，叫一个输出通道。

逐步执行：3×3 输入、2×2 核

输入 [[1,2,3],[4,5,6],[7,8,9]]，核 [[1,0],[0,1]]（左上和右下为 1），步长 1、不填充。

卷积核在 3×3 输入上滑动

1 / 4

第1步 · 窗口在左上：1×1 + 2×0 + 4×0 + 5×1 = 6

输出[0][0] = 6
2 / 4

第2步 · 右移一格：2×1 + 3×0 + 5×0 + 6×1 = 8

输出[0][1] = 8；再右移会越界，换到下一行
3 / 4

第3步 · 下移一行：4×1 + 5×0 + 7×0 + 8×1 = 12

输出[1][0] = 12
4 / 4

第4步 · 最后一个位置：5×1 + 6×0 + 8×0 + 9×1 = 14

输出是 2×2：[[6, 8], [12, 14]]。输出边长 = (3 − 2)/1 + 1 = 2

输出尺寸公式

一条边上，输入长 n、核大小 k、每侧填充 p、步长 s，输出长度是

out = ⌊(n + 2p − k) / s⌋ + 1

例子代入输出
32×32 输入，3×3 核，s=1，p=1(32+2−3)//1+1=3232×32（"same" 填充，尺寸不变）
224×224 输入，7×7 核，s=2，p=3(224+6−7)//2+1 = 111+1112×112
28×28 输入，5×5 核，s=1，p=0(28−5)//1+124×24
5×5 输入，3×3 核，s=2，p=0(5−3)//2+12×2

参数量公式

每个输出通道的核要覆盖全部输入通道，所以一个核有 k×k×C_in 个权重，再加 1 个偏置；共有 C_out 个核：

参数量 = (k·k·C_in + 1)·C_out

输入 32×32×3，8 个 3×3 卷积核：(3·3·3+1)·8=224。对比开头全连接的 24,584 个参数，少了一百多倍，而且这个数与图片的长宽无关。224×224×3 输入接 64 个 7×7 核时，参数是 (7·7·3+1)·64 = 9472。

每个核同时看全部 3 个输入通道，产生 1 个输出通道；8 个核就有 8 个输出通道

池化

池化层把一个小窗口里的数合成一个数，用来缩小特征图、让模型对小幅平移不敏感。最大池化取窗口最大值，平均池化取平均值。池化没有可学习的参数，只有窗口大小和步长两个超参数。

2×2 最大池化、步长 2：四个窗口的最大值分别是 4、5、6、3，输出 [[4,5],[6,3]]

感受野

感受野是输出图上一个点"看得到"的输入区域大小。一层 3×3 卷积的感受野是 3；两层叠起来，第二层的一个点看到第一层的 3×3，而第一层每个点又看到输入的 3×3，合起来是 5×5；三层是 7×7。递推规则：r 从 1 开始，每过一层加上 (k − 1) × 前面所有层步长的乘积。中间插一个步长 2 的层，后面的层每加一圈就跨 2 个像素，感受野长得更快：3×3（s=1）→ 2×2（s=2）→ 3×3（s=1）的感受野是 1 + 2 + 1 + 2×2 = 8。

两层 3×3 和一层 5×5 的感受野相同，但输入输出都是 64 通道时，前者参数为 2×3×3×64×64 = 73,728，后者为 5×5×64×64 = 102,400，而且前者中间多一次激活、非线性更强。VGG 等网络因此偏爱堆叠小卷积核。

要点：

  • 输出边长 = ⌊(n + 2p − k)/s⌋ + 1；3×3 核配 p=1、s=1 时尺寸不变。
  • 参数量 = (k·k·C_in + 1)·C_out，与输入图的长宽无关；标准答案句："卷积通过局部连接和权重共享大幅减少参数。"
  • 池化无参数，作用是下采样和平移不变性。
  • 堆叠小卷积核可以用更少的参数获得同样的感受野。

5.5 循环神经网络：RNN、LSTM、GRU 与 Seq2Seq

一句话"我把钱存进了银行"，读到"银行"时要记得前面说的是"存钱"，才知道这是金融机构而非河岸。图像可以一次全部输入，文本却是有先后的序列，长度也不固定。循环神经网络（RNN）的做法是：从左到右一个词一个词地读，用一个隐藏状态 h 记住"到目前为止读到了什么"。[14]

每一步的更新公式是 hₜ = tanh(Wₓ·xₜ + W_h·hₜ₋₁ + b)：新状态由"当前输入"和"上一步状态"共同决定。所有时间步共用同一组参数 Wₓ、W_h、b，所以句子再长参数也不变。

按时间展开的 RNN：三个方框是同一个单元、同一组参数，在三个时刻重复使用

完整走一遍：用一维的玩具 RNN，hₜ = tanh(0.5·hₜ₋₁ + 1.0·xₜ)，输入序列 x = [1, 0, 0]。

  1. t=1：h1 = tanh(0 + 1) = 0.7616，第一个输入被记下。
  2. t=2：h2 = tanh(0.5×0.7616 + 0) = tanh(0.3808) = 0.3634。
  3. t=3：h3 = tanh(0.5×0.3634) = 0.1797。

第一个词的信号每步大约减半，几步之后就所剩无几。反向传播时也一样：梯度要沿时间逐步连乘 W_h 和 tanh 的导数，序列一长就出现 5.2 讲过的梯度消失（或爆炸）。所以朴素 RNN 记不住长距离信息。

参数量：输入维度 d、隐藏维度 h 时，一个 RNN 层有 h·d + h·h + h 个参数。d=3、h=4 时为 12 + 16 + 4 = 32。

LSTM 与 GRU：用门控制记什么、忘什么

LSTM（长短期记忆网络）在隐藏状态之外加了一条细胞状态 c，像一条传送带贯穿所有时间步，并用三个门控制它。每个门都是一个 Sigmoid 输出的 0～1 之间的向量，逐元素相乘，起"阀门"作用。[15]

LSTM 的细胞状态沿上方横线流动：先被遗忘门缩放，再加上新信息；输出门决定露出多少给 h(t)

门公式（σ 为 Sigmoid，⊙ 为逐元素乘）作用
遗忘门 ff = σ(W_f·[hₜ₋₁, xₜ] + b_f)决定旧记忆保留多少，f≈1 表示全留
输入门 i 与候选 c̃i = σ(…)，c̃ = tanh(…)决定写入多少新信息
更新细胞cₜ = f ⊙ cₜ₋₁ + i ⊙ c̃加法更新，梯度可沿 c 直接回传
输出门 oo = σ(…)，hₜ = o ⊙ tanh(cₜ)决定对外输出多少

关键在第三行的加法：只要遗忘门接近 1，cₜ 对 cₜ₋₁ 的导数就接近 1，梯度沿传送带回传时不会被连乘压小，这和残差连接的思路相同。

GRU（门控循环单元）是 LSTM 的简化版：把遗忘门和输入门合并成一个更新门 z，再加一个重置门 r，并取消单独的细胞状态。[16] 三类单元的参数量正好是"门数 × 一个 RNN 层"：d=3、h=4 时，RNN 32 个，GRU 3×32 = 96 个，LSTM 4×32 = 128 个（PyTorch 的 LSTM 每个门有两组偏置，实际是 4×(12+16+4+4) = 144 个）。

Seq2Seq：编码器—解码器

机器翻译的输入和输出长度不同。Seq2Seq 用两个 RNN：** 编码器**读完整个源句，把最后的隐藏状态当作"上下文向量"；解码器以它为初始状态，一个词一个词地生成译文，每一步把上一步生成的词作为输入。[17]

整句压进一个定长向量是瓶颈；注意力机制让解码器每一步都能直接查看编码器的所有位置

源句很长时，一个定长向量装不下全部信息，翻译质量明显下降。2014 年提出的注意力机制让解码器在每一步按相关程度对编码器的全部隐藏状态加权求和，不再只依赖最后一个状态。[18] 后来的 Transformer 干脆去掉了循环结构，只保留注意力（5.8、5.9）。

要点：

  • RNN 按时间共享参数，用隐藏状态传递历史；长序列上梯度连乘，容易消失或爆炸。
  • 标准答案句："LSTM 通过遗忘门、输入门、输出门和加法更新的细胞状态缓解梯度消失，从而捕捉长期依赖。"
  • GRU 用更新门和重置门两个门，参数约为 LSTM 的 3/4，效果常常接近。
  • RNN 必须按时间顺序逐步计算，难以并行；这是 Transformer 取代它的主要原因之一。

查看答案与每个选项的解析

小结： RNN 在各时间步共享参数并逐步传递状态；LSTM 有三个门，细胞状态用加法更新；GRU 有两个门；Seq2Seq 由编码器压缩输入、解码器生成输出，这一结构的信息瓶颈促成了注意力机制的出现。

5.6 Embedding：把 token 变成向量

神经网络只能处理数字。把"存款""储蓄""天气"直接编号成 1、2、3，模型会误以为"天气"比"存款"大，编号之间也看不出"存款和储蓄意思相近"。我们需要一种表示，让意思相近的词在数值上也相近。

Embedding（嵌入）给词表里的每个 token 分配一个 d 维的实数向量，这些向量组成一个 V×d 的矩阵 E（V 是词表大小），作为模型参数一起训练。查一个 token 的向量，就是取 E 的第 id 行。

最朴素的表示是 one-hot：长度为 V 的向量，只有自己那一位是 1。它有两个问题：维度等于词表大小，太长；任意两个词的向量都正交，余弦相似度都是 0，表达不了相近关系。one-hot 向量乘以 E 恰好取出 E 的对应行，所以 Embedding 层可以看作"one-hot 输入的全连接层"，只是实现上直接查表，省去乘法。

二维玩具 Embedding：存款与储蓄方向接近（夹角小），天气与它们方向差得远

完整走一遍：用余弦相似度 cos = a·b / (|a||b|) 衡量方向是否接近。

  1. 存款 (3,1) 与储蓄 (2,1)：点积 3×2 + 1×1 = 7，模长 √10 × √5 = √50 ≈ 7.071，cos ≈ 0.9899，非常接近。
  2. 存款 (3,1) 与天气 (−1,2)：点积 −3 + 2 = −1，cos = −1/√50 ≈ −0.1414，几乎无关。
  3. 任意两个不同的 one-hot 向量：点积为 0，cos = 0。

向量从哪里来：word2vec 用"一个词的意思由它的上下文决定"这一分布假设训练，让出现在相似上下文里的词向量靠近。[19] 在 Transformer 里，输入 Embedding 只是第一层；经过多层注意力后，每个位置的输出向量融合了整句上下文，称为上下文相关的表示："苹果很甜"和"苹果发布新手机"里的"苹果"，输入 Embedding 相同，输出向量不同。

参数量：V = 50,000、d = 768 时，Embedding 矩阵有 50,000×768 = 38,400,000 个参数。很多语言模型的输出层（把隐藏向量映射回词表的 d×V 矩阵）与它共享权重。

把整段文字编码成一个向量（句向量 / 文本 Embedding）用于语义检索，是 RAG 的基础，见第 6 章。

要点：

  • Embedding = 可训练的 V×d 查找表；one-hot × E = 取 E 的一行。
  • 标准答案句："Embedding 把离散符号映射为稠密低维向量，语义相近的词在向量空间中距离相近。"
  • 相似度常用余弦相似度（只看方向）或点积；向量归一化后两者相等。
  • 静态词向量（word2vec）一词一个向量；Transformer 输出的是上下文相关的向量，能区分多义词。

单选 · 理解检查 6　向量 a=(1, 2)、b=(2, 4)、c=(2, −1)。下列哪项正确？

A. cos(a,b)=1，cos(a,c)=0

B. cos(a,b)=2，因为 b 是 a 的 2 倍

C. cos(a,c)=−1

D. a 与 b 的欧氏距离为 0

查看答案与每个选项的解析

A · 正确：b = 2a，方向相同，余弦为 1；a·c = 2 − 2 = 0，正交，余弦为 0。

B · 错误：余弦相似度只看方向，取值在 [−1, 1]，与长度无关。

C · 错误：−1 要求方向完全相反（如 (−1,−2)）；a 与 c 的点积为 0。

D · 错误：|b − a| = |(1,2)| = √5 ≈ 2.236；方向相同而距离不为 0，这正是余弦与欧氏距离的区别。

易错点

  • Embedding 维度 d 是人为选的超参数，与词表大小 V 和上下文长度是三个独立的量。
  • 余弦相似度高说明两段文字"话题或用法相近"，答案是否正确还要另外验证（第 6 章的检索评估）。
  • 词向量的单个维度通常没有可解释的含义，有意义的是向量之间的相对位置。

小结： Embedding 是一张 V×d 的查找表；one-hot 向量两两正交，稠密向量能够表达相近的含义；余弦相似度衡量方向；Transformer 输出的是与上下文相关的向量。

5.7 分词：BPE、WordPiece 与 SentencePiece

token 应该取多大？按整词切，词表会大到几十万，还会遇到没见过的词（"未登录词"）；按单个字符切，词表很小，但序列变得很长，每个 token 携带的信息也少。子词分词取折中：常见词保留为一个 token，罕见词拆成几个常见片段，例如 "banks" 拆成 "bank" + "s"。[20]

BPE：反复合并最常见的相邻对

BPE（字节对编码）的训练过程只有一个循环：[21]

  1. 把语料里每个词拆成单个字符，初始词表就是所有字符。
  2. 统计所有相邻符号对的出现次数（按词频加权）。
  3. 把次数最多的一对合并成一个新符号，加入词表，并记下这条合并规则。
  4. 重复 2–3，直到词表达到预定大小（或做满预定的合并次数）。

5.8 注意力机制：Q、K、V 与缩放点积

5.5 末尾说过，解码器需要"按相关程度回看所有位置"。注意力把这件事做成了一个通用操作：句子里每个位置都向其他所有位置"提问"，按相关程度把它们的信息加权汇总。读到"它"时，模型可以把大部分权重放到前文的"银行"上。[2]

三个角色：每个 token 的向量 x 乘三个可学习矩阵，得到三个向量。

  • Q（Query，查询）：我在找什么信息。
  • K（Key，键）：我能提供什么信息，供别人匹配。
  • V（Value，值）：被选中后真正交出去的内容。

Q 与每个 K 做点积得到相关分数，softmax 变成权重，再对 V 加权求和。把所有位置写成矩阵，就是缩放点积注意力：

Attention(Q, K, V) = softmax(QKᵀ / √d_k) · V

其中 d_k 是 Q、K 的维度，softmax 沿每一行（每个查询）做。

自注意力的数据流：Q、K 决定权重，V 提供内容；n 个位置两两打分得到 n×n 的分数表

逐步执行：3 个 token、2 维

设三个 token（"银行""存款""利率"）投影后的向量已经算好（Q 与 K 取相同的数，便于手算）：

Q = K = [[1,0], [0,1], [1,1]]，V = [[1,0], [0,2], [1,1]]，d_k = 2，√2 ≈ 1.4142。

缩放点积注意力：3 个 token 逐步算到输出

1 / 4

第1步 · QKᵀ，每对 token 一个点积

例：利率·利率 = 1×1 + 1×1 = 2；银行·存款 = 1×0 + 0×1 = 0
2 / 4

第2步 · 除以 √d_k = √2

1/√2 ≈ 0.7071，2/√2 ≈ 1.4142
3 / 4

第 1 行：e^0.7071 ≈ 2.028，e^0 = 1，和 = 5.056 → [0.4011, 0.1978, 0.4011]
每行加起来都是 1
4 / 4

第4步 · 权重乘 V，得到每个位置的新向量

银行 = 0.4011×[1,0] + 0.1978×[0,2] + 0.4011×[1,1] = [0.8022, 0.7967]
每个输出都是 V 各行的加权平均，融合了其他位置的信息

变量表：Q, K, V 是 n 行的矩阵（列表的列表）；dk 是每个向量的维度；S 是缩放后的分数表；W 是 softmax 后的权重；causal 为真时屏蔽未来位置。

def scaled_dot_attention(Q, K, V, causal=False):
    """返回 (scores, weights, output)。scores = QK^T/√d_k，按行 softmax，再乘 V。"""
    dk = len(Q[0])
    S = matmul(Q, transpose(K))
    S = [[v / math.sqrt(dk) for v in row] for row in S]
    if causal:
        S = [[v if j <= i else -math.inf for j, v in enumerate(row)] for i, row in enumerate(S)]
    W = []
    for row in S:
        finite = [v for v in row if v != -math.inf]
        m = max(finite)
        e = [math.exp(v - m) if v != -math.inf else 0.0 for v in row]
        s = sum(e)
        W.append([v / s for v in e])
    return S, W, matmul(W, V)

softmax 前先减去每行最大值 m，防止 exp 溢出，结果不变。用上面的 Q、K、V 调用，W[0] 就是 [0.4011, 0.1978, 0.4011]。

为什么除以 √d_k

假设 q、k 的每个分量独立、均值 0、方差 1，那么点积 q·k 是 d_k 项之和，方差为 d_k，标准差为 √d_k。d_k = 64 时，点积的典型大小在 ±8 左右。softmax 对大数非常敏感：softmax([8, 0]) = [0.9997, 0.0003]，几乎变成 one-hot，此时 softmax 的梯度接近 0，训练学不动。除以 √d_k = 8 后变成 softmax([1, 0]) = [0.7311, 0.2689]，分布保持平滑。

本例中若不缩放，第 3 行是 softmax([1, 1, 2]) = [0.2119, 0.2119, 0.5761]，比缩放后的 0.5035 更尖；维度越大，这个差距越大。

因果掩码

生成文本时，第 t 个位置只能看到前 t 个 token，否则训练时就等于"偷看答案"。因果掩码把分数表右上三角（j > i 的位置）设为 −∞，softmax 后这些权重变成 0：

加因果掩码后的权重：灰格被置 0。第 1 行只能看自己，权重为 1；第 2 行在前两个位置上重新做 softmax

第 2 行原分数为 [0, 0.7071]，softmax 得 [0.3302, 0.6698]，输出 = 0.3302×[1,0] + 0.6698×[0,2] = [0.3302, 1.3395]。第 3 行能看到全部，结果与不加掩码时相同。训练时整段序列一次输入，靠掩码让每个位置各自只看前文，所有位置的损失可以并行计算。

多头注意力

一组 Q、K、V 只能学到一种"关注方式"。多头注意力把 d_model 维切成 h 份，每份 d_k = d_model/h 维，各自独立做注意力（有的头关注语法搭配，有的关注指代），再把 h 个结果拼接，乘一个输出矩阵 W_O。

量公式d_model=512、h=8、n=1024 时
每个头的维度d_k = d_model / h64
投影参数（不计偏置）W_Q、W_K、W_V、W_O 各 d_model²，共 4·d_model²1,048,576
一层的分数表元素数h·n²8,388,608

分数表大小随 n² 增长，这是长上下文昂贵的根源（5.15 的 FlashAttention 就是为此设计的）。Q、K、V 都来自同一序列时叫自注意力；Q 来自解码器、K 和 V 来自编码器时叫交叉注意力。

要点：

  • 公式：Attention = softmax(QKᵀ/√d_k)·V，softmax 按行；输出是 V 的加权平均。
  • 标准答案句："除以 √d_k 是为了防止点积随维度增大而过大，导致 softmax 进入饱和区、梯度过小。"
  • 因果掩码把未来位置的分数置为 −∞，保证自回归生成时只看前文。
  • 多头：d_k = d_model/h；多个子空间学习不同的关注模式，总计算量与单头相当。
  • 自注意力的时间和显存随序列长度 n 呈 O(n²)。

5.9 Transformer 结构：编码器、解码器与 BERT、GPT、T5

2017 年的 Transformer 去掉了循环，只用注意力、前馈网络、残差和 LayerNorm 搭成一个"块"，再堆叠 N 次。没有逐步依赖，整段序列可以并行计算，训练速度远超 RNN。[2]

一个 Transformer 块里有什么

每个块有两个子层，每个子层外面都包着"残差 + LayerNorm"：

  1. 多头自注意力：让每个位置从其他位置汇总信息（5.8）。
  2. 前馈网络（FFN）：对每个位置单独做两层全连接，维度 d → 4d → d，中间用 GELU 等激活。注意力负责"位置之间交流"，FFN 负责"每个位置自己加工"。

原论文把 LayerNorm 放在残差相加之后（Post-LN）；现在的大模型多数放在子层之前（Pre-LN：x + Attention(LN(x))），深层训练更稳定。

原始 Transformer（编码器—解码器）：左列读源句，右列逐个生成目标；交叉注意力把两边连起来

数一数参数：设隐藏维度为 d。注意力有 W_Q、W_K、W_V、W_O 四个 d×d 矩阵，共 4d²；FFN 有 d×4d 和 4d×d 两个矩阵，共 8d²。所以一层约 12d² 个参数（忽略偏置和 LayerNorm）。

配置每层 12d²层数主体参数
d = 768（BERT-base 的宽度）7,077,8881284,934,656 ≈ 0.85 亿
d = 4096（一个假设的 7B 级配置）201,326,592326,442,450,944 ≈ 64 亿

BERT 论文报告 BERT-base 约 1.1 亿参数 [24]，主体之外的大头是词表 Embedding：30,522×768 = 23,440,896。d = 4096 的配置再加 32,000×4096 = 131,072,000 的 Embedding，总数接近 66 亿，这就是"7B 级"模型的量级。参数量主要由宽度 d 的平方决定。

要点：

  • Transformer 块 = 多头注意力 + FFN，各带残差和 LayerNorm；可并行训练，这是它取代 RNN 的关键。
  • 标准答案句："BERT 是双向编码器，用掩码语言模型预训练，适合理解类任务；GPT 是单向解码器，用自回归语言模型预训练，适合生成类任务。"
  • T5 把所有任务都写成"输入文本 → 输出文本"。
  • 一层参数约 12d²：注意力 4d² + FFN 8d²。

5.10 位置编码：正弦编码、RoPE 与长度外推

注意力只看"内容是否相关"。把"账户 冻结"换成"冻结 账户"，两个 token 的 Q、K、V 完全不变，每个位置得到的输出也只是跟着交换了顺序。没有额外信息，模型分不清谁在前、谁在后。位置编码就是把"第几个位置"的信息注入模型。

正弦位置编码

原始 Transformer 给第 pos 个位置构造一个 d 维向量，偶数维用 sin、奇数维用 cos，不同维度对使用不同频率：

PE(pos, 2i) = sin(pos / 10000^(2i/d))，PE(pos, 2i+1) = cos(pos / 10000^(2i/d))

然后把它加到该位置的 token Embedding 上。

完整走一遍（d = 4，两对维度的频率分别为 1 和 1/100）：

  1. pos = 0：[sin 0, cos 0, sin 0, cos 0] = [0, 1, 0, 1]。
  2. pos = 1：[sin 1, cos 1, sin 0.01, cos 0.01] = [0.8415, 0.5403, 0.0100, 1.0000]。
  3. pos = 2：[sin 2, cos 2, sin 0.02, cos 0.02] = [0.9093, −0.4161, 0.0200, 0.9998]。

低维对变化快（像秒针），高维对变化慢（像时针），组合起来每个位置都有独一无二的"指纹"。

d = 8 时前两对维度的频率为 1 和 0.1：一条快速振荡，一条缓慢上升

BERT、GPT-2 等模型改用可学习的绝对位置向量：每个位置一行参数，和 Embedding 一样训练。它的缺点是只学过训练时的最大长度，超出部分没有对应的向量。

RoPE：用旋转表示相对位置

句子含义更多取决于"两个词相距多远"，而非"各自在第几位"。RoPE（旋转位置编码）不再把位置向量加到输入上，而是在算注意力分数之前，把 q 和 k 按位置旋转：位置 m 的 q 旋转 mθ，位置 n 的 k 旋转 nθ。两个向量各转一个角度后，它们的点积只取决于角度差 (n − m)θ，也就是相对距离。[27]

完整走一遍（二维，θ = 30°，q = (1, 2)，k = (3, 1)，原始点积 q·k = 3 + 2 = 5）：

相距 2 的两组位置，旋转后的坐标完全不同，点积却都是 6.830；同一位置时转角相同，点积回到原始的 5

  1. m = 1：q 转 30°，(1·cos30° − 2·sin30°, 1·sin30° + 2·cos30°) = (−0.134, 2.232)。
  2. n = 3：k 转 90°，(3·0 − 1·1, 3·1 + 1·0) = (−1, 3)。
  3. 点积 = (−0.134)(−1) + 2.232×3 = 6.830。把位置整体平移到 (5, 7)，结果不变。

真实模型的维度是几十到上百，RoPE 把维度两两配对，每对用不同的转速 θᵢ = 10000^(−2i/d)。d = 128 时，第 0 对的 θ = 1（转得最快），第 63 对的 θ ≈ 1.155×10⁻⁴（几乎不转）。

长度外推

模型在 4096 长度上训练，推理时输入 16,384 个 token，会发生什么？RoPE 的低频维度会转到训练中从未见过的角度，注意力分数的分布偏离训练时的样子，效果明显下降。这叫外推问题。常见对策：

方法做法来源
位置插值把位置按比例压缩回训练范围：16,384 → 4096，位置乘 1/4，再少量微调[28]
调整旋转频率按频率分段缩放 θᵢ（NTK 感知插值、YaRN 等），高频少动、低频多压—
ALiBi不旋转，直接在注意力分数上减去"与距离成正比"的惩罚[29]

要点：

  • 自注意力本身对位置不敏感，需要位置编码提供顺序信息。
  • 正弦编码：不同维度用不同频率的 sin/cos，加到输入上；可学习绝对位置：每个位置一个向量。
  • 标准答案句："RoPE 将 q、k 按位置旋转，使注意力分数只依赖于相对位置 (n − m)，兼具绝对位置的实现方式和相对位置的效果。"
  • 超过训练长度时效果会下降；位置插值、调整频率、ALiBi 是常见的扩展手段，扩展后仍需在长文本任务上评测。

A. 0

B. 1

C. −1

D. 0.5

查看答案与每个选项的解析

易错点

  • RoPE 作用在每一层注意力的 q、k 上，v 不旋转，输入 Embedding 上也不加位置向量。
  • 正弦编码"理论上可算任意位置"，但模型没在长位置上训练过，外推效果同样有限。
  • 上下文窗口变长后，KV cache 显存也按长度线性增长（5.14），这和位置编码是两个独立的约束。

小结： 注意力本身不知道顺序；正弦位置编码把多种频率的 sin、cos 加到输入上；RoPE 旋转 q 和 k，使点积只与相对距离有关；长度外推依靠插值、调整频率或 ALiBi。

5.11 预训练与缩放定律

参数随机的 Transformer 什么也不会。预训练让它在海量无标注文本上做"预测下一个 token"的练习：给定前文，输出词表上的概率分布，用交叉熵损失（5.3）衡量猜得准不准。标签就是文本本身的下一个词，不需要人工标注，所以叫自监督学习。为了把下一个词猜准，模型被迫学会语法、常识、事实和一定的推理模式。

从语料到对话模型的三阶段：预训练消耗绝大部分算力，后两阶段让模型学会按指令回答

训练算力怎么估

一个常用近似：训练 N 个参数的模型、喂 D 个 token，总计算量约为

C ≈ 6·N·D（单位：浮点运算次数 FLOPs）

其中前向每个 token 每个参数约 2 次运算（一次乘、一次加），反向约是前向的 2 倍，合计 6。

完整走一遍：

  1. 10 亿参数、200 亿 token：6 × 10⁹ × 2×10¹⁰ = 1.2×10²⁰ FLOPs。
  2. Chinchilla 论文的 700 亿参数模型训练了 1.4 万亿 token，每参数 20 个 token：6 × 7×10¹⁰ × 1.4×10¹² ≈ 5.88×10²³ FLOPs。[30]

缩放定律

Kaplan 等人 2020 年发现：在很宽的范围内，语言模型的测试损失随参数量 N、数据量 D、算力 C 的增加按幂律平滑下降，在双对数坐标上近似一条直线。[31] 这让人们可以先用小模型做实验，再外推大模型的效果，决定"钱该花在更大的模型还是更多的数据上"。

2022 年的 Chinchilla 研究修正了分配比例：在固定算力下，参数量和训练 token 数应同比例增长，最优点大约是每个参数 20 个 token。[30] 工程上还要算推理成本：小模型多喂数据，部署更便宜，所以很多模型训练的 token 数远超 20 倍参数。

"涌现"：现象与争议

Wei 等人 2022 年把涌现能力定义为"在小模型上没有、在大模型上出现"的能力：多位数加法、多步推理等任务的准确率在模型规模达到某个量级前接近随机，之后突然上升。[32]

Schaeffer 等人 2023 年提出了不同看法：许多"突变"来自评测指标本身。如果用"整个答案完全正确才得分"的指标，模型每个 token 的准确率平滑上升，整体得分也会看起来像突然跳变；换成逐 token 准确率这类连续指标，曲线就平滑了。[33] 下图用一个 10 个 token 的答案演示这个效应：

p 从 0.5 匀速升到 0.99，p¹⁰ 却在前四档几乎贴着 0，之后陡升：同一组能力，换个指标就像出现了突变

截至本书写作时，学界对于涌现究竟是能力真实的跃迁，还是度量方式造成的表象，仍有争议；也有研究认为两种因素在不同的任务上都存在。面试中客观地讲清现象和两种解释即可。

要点：

  • 预训练 = 在无标注文本上做下一个 token 预测，属于自监督学习。
  • 训练算力 C ≈ 6ND；Chinchilla 结论：算力固定时参数与数据同比例扩大，约 20 token/参数。
  • 标准答案句："缩放定律指模型损失随参数量、数据量和计算量的增加呈幂律下降。"
  • "涌现"指能力随规模突然出现的现象；是否是度量方式造成的表象存在争议。

5.12 微调：全参数、LoRA 与效果评估

预训练模型懂通用语言，但不懂某家银行的信用卡条款，也未必按你想要的格式回答。微调是在预训练权重的基础上，用较小的任务数据集继续训练。问题在于成本：全参数微调要为每个参数存权重、梯度和优化器状态。以混合精度加 Adam 为例，每个参数约需 16 字节（FP16 权重 2、FP16 梯度 2、FP32 主权重 4、Adam 的两个矩各 4），70 亿参数就是 7×10⁹ × 16 = 112 GB，一张常见的 80 GB 显卡装不下。

LoRA：只训练一个低秩增量

LoRA 的出发点是：微调时权重的变化量 ΔW 往往是"低秩"的，可以用两个瘦长矩阵的乘积来近似。[34]

做法：冻结原权重 W（形状 d×k），旁边加一条支路 ΔW = B·A，其中 A 是 r×k、B 是 d×r，秩 r 远小于 d 和 k（常取 4～64）。前向时输出 h = W·x + B·A·x。B 初始化为 0，所以训练开始时模型与原模型完全一样。

LoRA：上路是冻结的原权重，下路是可训练的低秩增量 B·A，两路结果相加

完整走一遍：d = k = 4096，r = 8。

  1. 原矩阵参数：4096 × 4096 = 16,777,216。
  2. LoRA 参数：r × (d + k) = 8 × 8192 = 65,536，只占原矩阵的 0.39%。
  3. 在 32 层的 Q、V 两个投影上都加（共 64 个矩阵）：64 × 65,536 = 4,194,304 个可训练参数，约 420 万。
  4. r 翻倍到 16，参数也翻倍：131,072 个/矩阵。

部署时可以把 B·A 直接加回 W（W' = W + BA），推理没有额外延迟；也可以保留多个 LoRA 支路，按任务切换。QLoRA 进一步把冻结的 W 量化成 4 bit 存储，只让 LoRA 支路用高精度训练，显存再降一大截。[35] Adapter 则在层间插入"降维—升维"小模块（d = 4096、瓶颈 64 时 2×4096×64 = 524,288 个参数），推理时多一次计算。

5.13 解码：温度、top-k、top-p 与幻觉

模型每一步输出的是词表上的一个概率分布，而用户要的是一段文字。从分布里怎么选出下一个 token，就是解码策略。同一个模型，解码方式不同，输出可能从"死板重复"变成"天马行空"。[36]

自回归生成：把提示送进模型，得到下一个 token 的分布，选一个 token 接到末尾，再把整段送进去预测下一个，直到生成结束符或达到长度上限。

贪心、束搜索与采样

  • 贪心：每步选概率最大的 token。简单、可复现，但容易重复，也可能错过整体更好的句子。
  • 束搜索：每步保留概率乘积最高的 b 条候选序列。例：第一步 A、B、C 的概率为 0.5、0.4、0.1；A 之后最好的是 x（0.4），B 之后 x 的概率是 0.9。贪心选 A→x，整句概率 0.5×0.4 = 0.20；束宽 2 时保留 A、B，发现 B→x = 0.4×0.9 = 0.36 更高。束搜索适合翻译、摘要这类有标准答案的任务。
  • 采样：按概率随机抽取，配合下面三个旋钮控制随机程度，是对话和创作的常用方式。

温度：把分布拉尖或压平

在 softmax 之前把 logits 除以温度 T：pᵢ = e^(zᵢ/T) / Σ e^(zⱼ/T)。T < 1 时放大差距，分布更尖；T > 1 时缩小差距，分布更平；T 趋于 0 时等价于贪心解码。

完整走一遍：前文"我想去银行"，五个候选 token 的 logits 为 存钱 2、开户 1、取钱 0.5、咨询 0、跳舞 −1。

温度越低，第一名越集中（0.829）；温度越高，长尾 token（跳舞）的概率从 0.002 升到 0.084

top-k 与 top-p：先截断再采样

  • top-k：只保留概率最高的 k 个 token，重新归一化后再采样。T = 1、k = 2 时只剩下“存钱”和“开户”，概率分别为 0.563/0.770 = 0.731 和 0.207/0.770 = 0.269。

top-k 固定保留个数；top-p 按累计概率决定个数：分布尖时留得少，分布平时留得多

top-p 的好处是自适应：模型很确定时（第一名 0.95），只留 1 个；模型不确定时，多留几个。实际系统常把三者串起来：先除以温度，再做 top-k、top-p 截断，最后采样。另有重复惩罚：对已出现过的 token，正 logit 除以惩罚系数、负 logit 乘以系数。系数 1.2 时，logits [2, 1, 0.5, 0, −1] 中已出现的第 1、5 个变为 1.6667 和 −1.2。

从原理看幻觉

幻觉指模型生成流畅、自信，但与事实或给定资料不符的内容。从本章学过的原理可以找到几个根源：[37] [38]

四个来源：目标是流畅而非核实，罕见事实学不牢，采样有随机性，训练和评测鼓励猜答案

  1. 训练目标：预训练最小化"下一个 token 的交叉熵"，奖励的是"像语料里的文字"，没有一步在核对事实。一个看起来合理的错误答案和正确答案在语言上可能同样通顺。
  2. 知识的长尾与截止：某个人的生日在语料里只出现一次，模型很难记准；语料截止日之后的事它根本没见过，却仍会按"这类问题通常这样回答"的模式补全。
  3. 解码随机性：温度高、top-p 大时，低概率的错误 token 也有机会被抽中，而一旦写下，后面的内容会顺着它继续编（自回归没有"撤回"）。
  4. 评测与对齐的激励：Kalai 等人 2025 年指出，多数评测按"答对得分、答错和不答都是 0 分"计分，模型猜一个答案的期望分高于说"我不知道"，训练出的模型因此倾向于自信地猜。[38]

对应的缓解思路：用 RAG 提供可核查的资料并要求引用出处（第 6 章）、降低温度、让模型在证据不足时明确拒答、在评测中奖励"表达不确定"、对齐训练（第 7 章）。这些措施能降低幻觉率，但无法从原理上消除它。

要点：

  • 温度 T < 1 分布变尖、更保守；T > 1 分布变平、更多样；T → 0 等价于贪心。
  • top-k 固定保留 k 个；top-p 保留累计概率达到 p 的最小集合，个数随分布自适应。
  • 标准答案句："大模型以预测下一个 token 为训练目标，追求生成文本的似然而非事实正确，加上知识缺失和采样随机性，导致幻觉。"
  • 有标准答案的任务（翻译、抽取）用低温或束搜索；创作类任务用较高温度加 top-p。

5.14 推理加速一：KV cache、显存估算与 PagedAttention

按 5.13 的自回归流程，生成第 t 个 token 时要把前面所有 token 再送进模型一次，前文越长每一步越慢。而前文 token 的 K、V 每一步都完全一样（因果掩码保证前面的位置看不到后面），重复计算纯属浪费。[39]

KV cache 就是把每一层、每个已处理 token 的 K、V 向量存起来。之后每生成一步，只为新 token 计算 Q、K、V，把新的 K、V 追加进缓存，再用新 token 的 Q 与缓存中全部 K、V 做注意力。

  • 预填充（prefill）：把整个提示一次性并行送入，算出全部位置的 K、V 写入缓存，并得到第一个输出 token。
  • 解码（decode）：每步只处理 1 个新 token，读取整个缓存。

KV cache 显存公式

每层、每个 token 要存 K 和 V 两个向量，每个向量有 kv_heads × head_dim 个数：

KV cache 字节数 = 2 × 层数 × kv_heads × head_dim × 序列长度 × batch × 每个数的字节数

完整走一遍：一个 32 层、32 个 KV 头、head_dim = 128 的假设模型，FP16（2 字节）。

  1. 每个 token：2 × 32 × 32 × 128 × 2 = 524,288 字节 = 0.5 MiB。
  2. 序列长 4096：0.5 MiB × 4096 = 2 GiB。
  3. batch = 8 个请求同时服务：16 GiB，已经超过 7B 模型 FP16 权重本身（7×10⁹ × 2 = 14 GB）。
  4. 改用 GQA（分组查询注意力，32 个查询头共享 8 组 K、V）：kv_heads = 8，单条 4096 长度降到 512 MiB。[40]
  5. KV cache 用 1 字节的 INT8/FP8 存：单条降到 1 GiB（见 5.15）。

KV cache 随序列长度线性增长；GQA 把 KV 头从 32 减到 8，显存降为 1/4

PagedAttention：像操作系统分页一样管理缓存

早期的推理框架为每个请求按"最大长度"预留一整块连续显存。一个请求最大长度 2048，实际只生成到 100 个 token，就浪费了 1948 个位置。PagedAttention（vLLM）借用操作系统的分页思想：把 KV cache 切成固定大小的块（例如每块 16 个 token），按需分配，用一张块表记录"逻辑第几块在物理显存哪里"，物理块无需连续。[41]

100 个 token 需要 ⌈100/16⌉ = 7 块，只有最后一块浪费 12 个位置；对比预留 2048 时浪费 1948 个

浪费只发生在每个请求的最后一块，同一张卡能同时服务更多请求；多个请求共享同一段系统提示时还能共享这些块。

要点：

  • 标准答案句："KV cache 缓存已生成 token 每层的 Key 和 Value，生成新 token 时只需计算新 token 的 Q、K、V，避免对历史 token 的重复计算，从而降低每步延迟。"
  • 显存 = 2 × 层数 × kv_heads × head_dim × 长度 × batch × 字节数，随长度和 batch 线性增长。
  • GQA/MQA 让多个查询头共享 K、V，直接减少 KV cache。
  • PagedAttention 把缓存分块按需分配，减少碎片和预留浪费。

5.15 推理加速二：量化、FlashAttention、推测解码与延迟指标

大模型推理还有三个瓶颈：权重和缓存太大、注意力的 n×n 中间矩阵太大、每步只能出一个 token。本节的三种技术各治一个，最后讲衡量快慢的两个指标。

量化：用更少的位数存数

量化把 FP16（2 字节）的数映射到 INT8（1 字节）或 INT4（半字节）。7B 模型的权重从 14 GB 降到 7 GB 或 3.5 GB。最简单的对称量化：

  1. 缩放因子 scale = max|x| / q_max，INT8 的 q_max = 127，INT4 的 q_max = 7。
  2. 量化：q = round(x / scale)，截断到 [−q_max, q_max]。
  3. 反量化：x̂ = q × scale。误差最多是 scale/2。

完整走一遍：一组权重 x = [0.5, −1.2, 0.031, 2.54, −0.7]，max|x| = 2.54。

INT8 的 scale = 0.02，最大误差 0.009；INT4 的 scale ≈ 0.3629，只有 15 个格子可用，最大误差 0.137（0.5 被量化成 0.363）

离群值问题：把 2.54 换成 25.4，INT8 的 scale 变成 0.2，0.5 被量化成 2×0.2 = 0.4、−0.7 变成 −0.8，误差都变成 0.1，小数值的精度被一个大数"拖累"了。大模型激活中确实存在少量极大的离群值，LLM.int8() 的做法是把这些离群维度单独用 FP16 计算，其余用 INT8。[42] 实践中还会按通道、按组（如每 128 个数一组）各算一个 scale，缩小离群值的影响范围。

FP8 是 8 位浮点，仍有指数位，表示范围比 INT8 宽。两种常用格式：E4M3（4 位指数、3 位尾数，最大 448，精度较高，常用于前向）和 E5M2（5 位指数、2 位尾数，最大 57,344，范围更大，常用于梯度）。[43]

KV cache 量化：长上下文、大 batch 时 KV cache 比权重还大（5.14 的 16 GiB 例子），把它从 FP16 存成 INT8 或 FP8 直接减半，INT4 再减半。K 的分布常有明显的通道级离群值，V 相对平稳，所以有方法对 K 按通道、对 V 按 token 分别量化，KIVI 甚至做到 2 bit。[44] [45]

FlashAttention：少搬数据

标准注意力要把 n×n 的分数矩阵完整写进显存（HBM），再读出来做 softmax、再写、再读。n = 4096 时，一个头的分数矩阵用 FP16 存是 4096×4096×2 = 32 MiB，32 个头就是 1 GiB，而且每层都要来回搬。GPU 的计算速度远快于显存读写，这时瓶颈在"搬数据"。

FlashAttention 把 Q、K、V 切成小块，每次把一块搬进 GPU 片上高速缓存（SRAM），在片上算完分数、softmax 和加权求和，用"在线 softmax"技巧边算边合并各块结果，从不把完整的 n×n 矩阵写回显存。结果与标准注意力完全相同（精确计算），但显存占用从 O(n²) 降到 O(n)，速度也明显提升。[48]

推测解码：小模型猜，大模型验

解码阶段每步只处理 1 个 token，大模型的算力大量闲置。推测解码让一个小的草稿模型先快速连续猜 k 个 token，大模型再用一次前向并行验证这 k 个位置：从左到右逐个接受，遇到第一个不接受的位置就换成大模型自己的结果，后面的作废。[49]

一次大模型前向产出多个 token；按论文的接受规则，输出分布与大模型单独生成完全一致

若每个草稿 token 被接受的概率为 α（假设彼此独立），一次验证平均产出 (1 − α^(k+1)) / (1 − α) 个 token。α = 0.8、k = 4 时约 3.36 个；α = 0.5 时只有约 1.94 个。草稿模型猜得越准，加速越明显。

  • 量化：scale = max|x|/q_max，误差 ≤ scale/2；离群值会放大误差，要分组或单独处理。
  • FlashAttention 分块在片上计算，避免写出 n×n 矩阵，结果精确、显存 O(n)。
  • 推测解码：小模型起草、大模型并行验证，输出分布与大模型一致。
  • 标准答案句："首 token 延迟由预填充决定，衡量响应快慢；吞吐是单位时间生成的总 token 数，衡量服务容量；增大 batch 提高吞吐但可能增加延迟。"

5.16 多模态：ViT、CLIP 与扩散模型

用户拍一张票据问"这张能报销吗"，模型既要看懂图又要读懂字。多模态模型处理文本、图像、音频等多种输入或输出，核心思路是把各种模态都变成"一串向量"交给 Transformer。本节讲三个基础：ViT、CLIP 和扩散模型。

ViT：把图片切成 patch 当 token

扩散模型：学会一步步去噪

扩散模型生成图片的思路是"先学会去噪，再从纯噪声开始一步步去噪"。[52]

  • 前向加噪（训练时构造数据）：往原图 x₀ 里逐步加高斯噪声，第 t 步可以一步写出：xₜ = √ᾱₜ · x₀ + √(1 − ᾱₜ) · ε，ᾱₜ 从接近 1 逐渐减小到接近 0。
  • 反向去噪（网络学的事）：给定 xₜ 和 t，让网络预测加进去的噪声 ε。
  • 生成：从纯噪声 x_T 出发，反复用网络预测噪声并去掉一部分，几十到上千步后得到一张清晰的图。

上面的实线：加噪，有固定公式，无需学习；下面的虚线：生成时由去噪网络从纯噪声出发，一步步还原出图片

完整走一遍（一维玩具）：x₀ = 1，噪声 ε = 0.5。

  1. ᾱ = 0.9：x = √0.9×1 + √0.1×0.5 = 0.9487 + 0.1581 = 1.1068，原图占主导。
  2. ᾱ = 0.5：x = 0.7071 + 0.3536 = 1.0607。
  3. ᾱ = 0.1：x = 0.3162 + 0.4743 = 0.7906，噪声占主导。
  4. 去噪：若网络在 ᾱ = 0.5 时准确预测出 ε = 0.5，就能反推 x₀ = (1.0607 − 0.7071×0.5)/0.7071 = 1。

文生图与图生文

  • 文生图：文本编码器（常用 CLIP 的文本塔）把提示词变成向量序列，通过交叉注意力注入去噪网络，引导每一步往"符合描述"的方向去噪。为了省算力，主流做法在压缩后的潜空间里扩散，最后再解码成像素，这就是潜在扩散模型。[53]
  • 图生文（看图说话、视觉问答）：视觉编码器（如 ViT）把图片变成一串向量，经过一个投影层映射到语言模型的 Embedding 空间，当作"图片 token"放在文本前面，再由语言模型自回归生成文字。

多模态 Embedding 怎么选

考虑因素要问的问题
模态组合只要图文互搜，CLIP 类双塔模型就够；还要音频、视频，选支持更多模态的模型
语言查询以中文为主时，优先选在中文图文数据上训练或评测过的版本
领域票据、医学影像等专业图片，通用模型效果可能不足，需要在自有数据上微调或换领域模型
成本与部署向量维度影响存储和检索速度；数据敏感时要求可私有化部署
评测用自己的业务数据构造查询集，比较 Recall@k 等检索指标，再做决定

要点：

  • ViT：图片切 patch → 线性投影 → 加 [CLS] 和位置编码 → Transformer；224/16 得 196 个 patch。
  • 标准答案句："CLIP 用图像编码器和文本编码器把图文映射到同一向量空间，通过对比学习使匹配的图文对相似度最高、不匹配的最低，从而实现零样本分类和跨模态检索。"
  • 扩散模型：前向按公式加噪，网络学习预测噪声，生成时从纯噪声逐步去噪；文生图用交叉注意力注入文本条件。
  • 多模态 Embedding 选型看模态、语言、领域、成本，最终以自有数据上的检索指标为准。

单选 · 理解检查 16　ViT 输入 384×384 的图片，patch 大小 16×16，加一个 [CLS] token。送进 Transformer 的序列长度是多少？

A. 577

B. 576

C. 197

D. 25

查看答案与每个选项的解析

A · 正确：(384/16)² = 24² = 576 个 patch，加 [CLS] 共 577。

B · 错误：漏了 [CLS] token。

C · 错误：这是 224×224 输入的结果。

D · 错误：24 是每边的 patch 数，序列长度要取平方再加 1。

易错点

  • CLIP 是双塔检索模型，擅长"判断图文是否匹配"，自己并不生成文字；看图说话要接语言模型。
  • 扩散模型的前向加噪有固定公式，无需学习；网络只学反向的去噪。
  • 对比学习的温度 τ 越小，分布越尖，对难分的负样本惩罚越重。

小结： ViT 把图像切成 patch 当作 token；CLIP 采用双塔结构和对比学习，使图像和文本处于同一向量空间；扩散模型的加噪过程有公式，网络学习去噪；文生图依靠交叉注意力注入文本信息；选择 Embedding 模型时，用自己的数据测试召回率。

多选 · 理解检查 17　下列关于大模型原理的说法，哪些正确？

A. KV cache 用显存换计算，显存随序列长度线性增长

B. RoPE 让注意力分数只依赖 q、k 的相对位置

C. 温度调到 0 就能消除幻觉

D. LoRA 推理时必须额外多算一条支路，延迟一定增加

查看答案与每个选项的解析

A · 正确：每个 token 在每层存一份 K、V，长度翻倍显存翻倍。

B · 正确：两者各旋转 mθ、nθ 后，点积只取决于 (n − m)θ。

C · 错误：温度 0 只是总选概率最高的 token；模型认为最可能的答案本身可能是错的。

D · 错误：可以把 B·A 合并回 W，推理与原模型结构相同。
