7.7 调试方法：打印、断言和边界输入 选读

答案错了却不知道错在哪里时，盯着代码反复看最浪费时间。更快的方法是让程序自己提供信息：打印中间状态、在关键位置加断言、用一份固定的边界清单逐个测试。三种方法结合起来，通常几分钟内就能把问题缩小到某一行。

工具一：打印中间状态

在循环中把关键变量打印到 cerr，与手工模拟的表格（7.5）逐行对照，第一处不一致的位置就是错误所在。下面这个常用的宏可以省去很多输入：

#define DBG(x) cerr << #x << " = " << (x) << "\n"
// 用法：DBG(l); DBG(cnt);   输出：l = 2   cnt = 3
# Python 没有宏；f-string 里写 {表达式 = }（3.8 起）会自动带上表达式原文
print(f"{l = }", file=sys.stderr)   # 输出：l = 2

#x 把括号中的表达式原样变成字符串，所以输出中自带变量名。

工具二：assert 断言

assert(条件) 在条件为假时立即终止程序，并报告文件名、行号和条件的原文。[1] 它最适合用来检查自认为一定成立的前提。例如双指针要求数组有序，就在开头写：

assert(is_sorted(a.begin(), a.end()));   // 前提：已排序；不成立时程序立刻停下并报出这一行
assert all(a[i] <= a[i + 1] for i in range(len(a) - 1))   # 前提：已排序；不成立时抛 AssertionError 并报出这一行
# 用 python -O 运行时 assert 会被整体跳过，相当于 C++ 编译时加 -DNDEBUG

如果在 7.6 中那个忘记排序的版本开头加上这一行，第一次传入 [9,7,8,…] 时程序就会停下，报出类似 Assertion `is_sorted(a.begin(), a.end())' failed. 的信息，比对拍更早发现问题。编译时加上 -DNDEBUG 会关闭所有断言，所以断言是自测工具，提交时可以保留，也可以删去。

工具三：边界清单

大多数“样例通过、提交出错”的情况，都出在下面几类输入上。每写完一道题，都把这份清单检查一遍：

边界例子它在测什么
空输入[]有没有访问 a[0]、size()-1 变成巨大正数（1.5）
只有一个元素[7]循环一次都不进时答案对不对
全部相同[4,4,4,4]比较里的 < 和 <= 写对没有
有负数[-3,-1,2]最大值初值写成 0、奇偶判断 x%2==1 这类问题
最大值10⁵ 个 10⁹int 溢出，要不要 long long
重复元素[5,1,5,1]哈希表覆盖、去重逻辑
已排序 / 逆序[9,8,7,6]双指针、单调栈的极端情况

把清单写成代码，与暴力解逐个比较：

int runEdgeCases() {
    vector<pair<vector<int>, int>> cases = {
        {{}, 0},                       // 空输入
        {{7}, 0},                      // n = 1
        {{4, 4, 4, 4}, 0},             // 全相同
        {{-3, -1, 2, -2}, 1},          // 负数
        {{1000000000, -1000000000}, 2000000000},   // 差值达到 2e9
        {{5, 1, 5, 1, 5}, 0},          // 重复元素
        {{9, 8, 7, 6}, 1},             // 降序
    };
    int bad = 0;
    for (auto& [a, d] : cases)
        if (countClosePairs(a, d) != countClosePairsBrute(a, d)) ++bad;
    return bad;
}

        ([], 0),                       # 空输入
        ([7], 0),                      # n = 1
        ([4, 4, 4, 4], 0),             # 全相同
        ([-3, -1, 2, -2], 1),          # 负数
        ([1000000000, -1000000000], 2000000000),   # 差值达到 2e9（Python 整数不溢出，这组在 C++ 里才是考验）
        ([5, 1, 5, 1, 5], 0),          # 重复元素
        ([9, 8, 7, 6], 1),             # 降序
    ]
    bad = 0
    for a, d in cases:

    return bad

逐行说明： 每个 {数组, d} 是一组边界输入，注释说明它测试什么；循环把每组输入同时交给快慢两个版本，统计不一致的组数，返回 0 表示全部通过。第五组的差值是 2×10⁹，仍在 int 的范围内（上限约 2.147×10⁹），这一组用来确认 a[r] - a[l] 不会溢出。

溢出：小数据测试不出的错误

对拍使用小数据，所以测试不出溢出。看下面这个求和函数：

long long sumAll(const vector<int>& a) {
    long long s = 0;                              // 累加器用 long long
    for (int x : a) s += x;
    return s;
}
def sum_all(a):
    s = 0                                         # Python 的 int 是任意精度，10^5 个 10^9 相加也不会溢出
    for x in a: s += x                            # 等价于内置的 sum(a)
    return s

10⁵ 个 10⁹ 相加，正确结果是 10¹⁴。如果把 s 写成 int，结果会溢出。有符号整数溢出在 C++ 中是未定义行为，在常见平台上往往得到 276447232 这样没有意义的数。所以边界清单中一定要有一组全部取最大值的数据，单独测试。

要点

  • 调试的三种方法：用 cerr 打印中间状态，用 assert 检查前提，用边界清单逐个测试。
  • 边界清单固定为七类：空、只有一个元素、全部相同、有负数、最大值、有重复、已排序或逆序。
  • 对拍发现逻辑错误，清单发现边界错误和溢出，两者互补。
  • 计数、求和、相乘、相减（大正数减大负数）时，都要先考虑结果是否会超过 2.1×10⁹。

练一练：最大值与最小值之差

题面：给出一个 int 数组（元素在 −2×10⁹～2×10⁹ 之间，可能为空），返回最大值减最小值；空数组返回 0。

提示

按边界清单逐项检查：空、只有一个元素、有负数、最大值。

参考答案
long long maxMinGap(const vector<int>& a) {
    if (a.empty()) return 0;                      // 边界：空输入
    int mx = a[0], mn = a[0];
    for (int x : a) { mx = max(mx, x); mn = min(mn, x); }
    return (long long)mx - mn;                    // 先转 long long 再相减
}
def max_min_gap(a):
    if not a: return 0                            # 边界：空输入
    mx = mn = a[0]
    for x in a: mx = max(mx, x); mn = min(mn, x)
    return mx - mn                                # Python 整数不溢出，不需要先转 long long

与例题的区别： 与上面的初版相比，增加了空输入的判断，返回类型和减法都改为 long long。注意必须写成 (long long)mx - mn：先把 mx 转型，减法就按 long long 计算；如果写成 (long long)(mx - mn)，减法已经在 int 中溢出，再转型就太晚了。

多选 · 理解检查 1　int mx = 2000000000, mn = -2000000000; 下列哪些写法能得到正确的 4000000000？

A. long long g = (long long)mx - mn;

B. long long g = (long long)(mx - mn);

C. long long g = mx - mn;

D. long long g = 1LL * mx - mn;

查看答案与每个选项的解析

A · 正确：mx 先转成 long long，减法按 long long 计算，不会溢出。

B · 错误：括号里的 mx - mn 先按 int 计算，已经溢出，之后再转型来不及。

C · 错误：右边两个 int 相减，结果按 int 计算后才赋给 long long。

D · 正确：1LL * mx 已经是 long long，后面的减法也按 long long 做。

练习 7.7-1【基础】平均分向下取整

题面：n 个整数 a[i]（可以为负），返回平均值向下取整的结果，即不超过 (a[0]+…+a[n−1]) / n 的最大整数。1 ≤ n ≤ 10⁵，|a[i]| ≤ 10⁹。

样例 1：a=[1,2,2]，输出 1。样例 2：a=[−1,−2,−2]，输出 −2（平均约 −1.67）。样例 3：a=[10⁹,10⁹,10⁹]，输出 10⁹。

提示

按边界清单过两项。最大值：总和可达 10¹⁴，累加器用 long long。负数：C++ 的整数除法向 0 截断，−5/3 得 −1，向下取整应是 −2，所以总和为负且除不尽时要再减 1；Python 的 // 本身向下取整，同一个式子在两种语言里结果不同。暴力换一种不用除法的算法：答案 q 是满足 q·n ≤ 总和的最大整数，一定落在 [min(a), max(a)] 里，从 min(a) 开始逐个往上试。暴力只用乘法和比较，不受取整方向影响，适合用来检查优化版。

参考答案
long long floorAvgBrute(const vector<long long>& a) {
    long long n = (long long)a.size(), s = 0, q = a[0];
    for (long long x : a) { s += x; q = min(q, x); }   // q 从最小值开始
    while ((q + 1) * n <= s) ++q;                  // 最大的 q 满足 q*n <= s
    return q;
}
long long floorAvg(const vector<long long>& a) {
    long long n = (long long)a.size(), s = 0;
    for (long long x : a) s += x;                  // 和可达 1e14：long long
    long long q = s / n;                           // C++ 向 0 截断
    if (s % n != 0 && s < 0) --q;                  // 负数且除不尽：再往下取一格
    return q;
}
def floor_avg_brute(a):
    n, s, q = len(a), 0, a[0]
    for x in a: s += x; q = min(q, x)              # q 从最小值开始
    while (q + 1) * n <= s: q += 1                 # 最大的 q 满足 q*n <= s
    return q
def floor_avg(a):
    n, s = len(a), 0
    for x in a: s += x                             # Python 整数不溢出
    q = s // n                                     # Python 的 // 本来就向下取整
    return q                                       # C++ 版"负数再减 1"那一行在这里多余，加上反而错

练习 7.7-2【变形】两数最大乘积

题面：n 个整数 a[i]，选两个不同下标的数相乘，求最大乘积。2 ≤ n ≤ 10⁵，|a[i]| ≤ 10⁹。

提示

新题一：长度不超过 k 的最大和区间

题面：给出 n 笔交易金额 a[i]（收入为正，支出为负），选一段连续的交易，笔数在 1 到 k 之间，使金额总和最大，输出这个最大和。1 ≤ k ≤ n ≤ 10⁵，|a[i]| ≤ 10⁹。样例：a=[2,−3,4,−1,5,−6,3]，k=3，输出 8（选 4,−1,5）。

第 1 步：读题。 输入是 a 和 k；输出一个整数；规模 n ≤ 10⁵；限制：有负数，区间非空，长度上限为 k；和最大可达 10⁵×10⁹ = 10¹⁴，要用 long long。手算样例：长度不超过 3 的区间中，[4,−1,5] 的和 8 最大；[4,−1,5,−6,3] 虽然更长，但长度 5 超过了 k。

第 2 步：估算复杂度。 n ≤ 10⁵，查表可知需要 O(n log n) 或 O(n)。

第 3 步：暴力解。 列出所有长度不超过 k 的区间，一边扩展一边累加，O(n·k)，k=n 时为 O(n²)。

long long maxSumAtMostKBrute(const vector<int>& a, int k) {
    int n = (int)a.size();
    long long best = LLONG_MIN;
    for (int l = 0; l < n; ++l) {
        long long sum = 0;
        for (int r = l; r < n && r - l + 1 <= k; ++r) {   // 长度不超过 k
            sum += a[r];
            best = max(best, sum);
        }
    }
    return best;
}
def max_sum_at_most_k_brute(a, k):
    n = len(a)
    best = float('-inf')                          # 相当于 LLONG_MIN：比任何整数都小
    for l in range(n):
        s = 0
        for r in range(l, min(n, l + k)):         # 长度不超过 k：r 最多到 l+k-1
            s += a[r]
            best = max(best, s)
    return best

best 的初值是 LLONG_MIN（long long 的最小值），因为全是负数时答案也是负数，用 0 作初值会出错。

第 4 步：优化。 先问区间和能不能预处理：设前缀和 P[i] = a[0]+…+a[i−1]，区间 a[j..r−1] 的和是 P[r] − P[j]，长度是 r − j。固定右端 r，要使 P[r] − P[j] 最大，就要在 j ∈ [r−k, r−1] 中找最小的 P[j]，这是一个滑动窗口最小值问题。

再问能不能只保留有用的候选：对于两个候选 j1 < j2，如果 P[j1] ≥ P[j2]，那么 j1 既更早过期，值又不更小，永远不会被选中，可以丢弃。留下的候选下标递增，P 值也严格递增，最小的在最前面。两端都需要操作（在队尾加入新候选并删去无用的，在队头删去过期的），所以使用 deque，这种结构叫作单调队列。[2] [3]

long long maxSumAtMostK(const vector<int>& a, int k) {
    int n = (int)a.size();
    vector<long long> P(n + 1, 0);                 // P[i] = a[0..i-1] 之和
    for (int i = 0; i < n; ++i) P[i + 1] = P[i] + a[i];
    long long best = LLONG_MIN;
    deque<int> dq;                                 // 存下标 j，P[j] 从队头到队尾严格递增
    for (int r = 1; r <= n; ++r) {                 // 区间是 (j, r]，和为 P[r] - P[j]
        while (!dq.empty() && P[dq.back()] >= P[r - 1]) dq.pop_back();   // 新候选 r-1 入队前，踢掉不如它的
        dq.push_back(r - 1);
        while (dq.front() < r - k) dq.pop_front();  // 长度 r-j 超过 k 的左端过期
        best = max(best, P[r] - P[dq.front()]);     // 队头是窗口里最小的前缀
    }
    return best;
}
from collections import deque
def max_sum_at_most_k(a, k):
    n = len(a)
    P = [0] * (n + 1)                              # P[i] = a[0..i-1] 之和
    for i in range(n): P[i + 1] = P[i] + a[i]
    best = float('-inf')
    dq = deque()                                   # 存下标 j，P[j] 从队头到队尾严格递增；deque 两头增删都是 O(1)
    for r in range(1, n + 1):                      # 区间是 (j, r]，和为 P[r] - P[j]
        while dq and P[dq[-1]] >= P[r - 1]: dq.pop()   # 新候选 r-1 入队前，踢掉不如它的；dq[-1] 是队尾
        dq.append(r - 1)
        while dq[0] < r - k: dq.popleft()          # 长度 r-j 超过 k 的左端过期；dq[0] 是队头
        best = max(best, P[r] - P[dq[0]])          # 队头是窗口里最小的前缀
    return best

新题二：两人分配任务，使耗时之差最小

题面：有 n 个任务，第 i 个耗时 t[i]。每个任务整个交给 A 或 B 中的一人。求两人总耗时之差的绝对值的最小值。1 ≤ n ≤ 8，1 ≤ t[i] ≤ 1000。样例：t=[3,1,4,2,2]，输出 0（A 做 3,1,2，B 做 4,2，各 6）。

第 1 步：读题。 输入是 t；输出一个整数；规模 n ≤ 8，非常小；限制：任务不能拆分，一个人可以一个任务都不做；手算样例：总和为 12，能凑出 6 就是 0。

第 2 步：估算复杂度。 n ≤ 8 时只有 2⁸ = 256 种分法，可以直接枚举所有子集。在这个数据范围下，暴力解就是正解。

第 3 步：暴力解。 每个任务给 A 或给 B，恰好对应一个子集：mask 的第 i 位为 1 表示任务 i 给 A（第 5 章讲过 mask）。A 的总耗时为 a，B 的就是 total − a，两者之差为 |total − 2a|。

int splitTasks(const vector<int>& t) {             // 子集枚举：mask 的第 i 位为 1 表示任务 i 给 A
    int n = (int)t.size(), total = 0;
    for (int x : t) total += x;
    int best = INT_MAX;
    for (int mask = 0; mask < (1 << n); ++mask) {
        int a = 0;
        for (int i = 0; i < n; ++i) if (mask >> i & 1) a += t[i];
        best = min(best, abs(total - 2 * a));       // |A - B| = |A - (total - A)|
    }
    return best;
}

新题三：先拿钥匙才能通过门的迷宫

题面：R×C 的网格迷宫中，S 是起点，E 是出口，# 是墙，. 是空地，K 是钥匙，D 是门。每步走到上下左右相邻的格子。没有钥匙时不能进入门；走到 K 上就自动拿到钥匙，之后所有门都能进入。求从 S 到 E 的最少步数，无法到达时输出 −1。R, C ≤ 100。

样例：

S 在 (0,0)，门 D 在 (0,2)，钥匙 K 在 (2,0)。最短路线先下去拿钥匙，再原路返回过门，共 10 步

第 1 步：读题。 输入是字符网格；输出最少步数或 −1；规模为 100×100 = 10⁴ 个格子；限制：进门需要钥匙，拿到的钥匙不会丢失，迷宫中可能没有钥匙；手算样例：直接向右走到 (0,1) 会被门挡住，只能先向下去拿钥匙，4 步到达 K，再走 6 步到达 E，共 10 步。

第 2 步：估算复杂度。 网格上的最少步数问题应当用 BFS（第 6 章）：BFS 按距离逐层向外扩展，第一次到达某个状态时的步数就是最少步数。[4]

第 3 步：确定状态。 手算时注意到，同一个格子 (1,1) 被走过两次：第 2 步时没有钥匙，第 6 步时有钥匙。这两次能做的事不同（后者可以过门），所以它们是两个不同的状态。状态是（行，列，是否有钥匙），共有 R×C×2 个。

先看只按位置记录 visited 的错误写法会怎样（keyDoorBFSWrong）：

int keyDoorBFS(const vector<string>& g) {
    int R = (int)g.size(), C = (int)g[0].size();
    int sr = 0, sc = 0;
    for (int r = 0; r < R; ++r)
        for (int c = 0; c < C; ++c)
            if (g[r][c] == 'S') { sr = r; sc = c; }
    // dist[r][c][k]：走到 (r,c) 且钥匙状态为 k（0 没有，1 有）的最少步数，-1 表示还没到过
    vector<vector<vector<int>>> dist(R, vector<vector<int>>(C, vector<int>(2, -1)));
    queue<tuple<int, int, int>> q;
    dist[sr][sc][0] = 0;
    q.push({sr, sc, 0});
    int dr[4] = {-1, 1, 0, 0}, dc[4] = {0, 0, -1, 1};
    while (!q.empty()) {
        auto [r, c, k] = q.front(); q.pop();
        if (g[r][c] == 'E') return dist[r][c][k];   // BFS 第一次到出口就是最少步数
        for (int t = 0; t < 4; ++t) {
            int nr = r + dr[t], nc = c + dc[t];
            if (nr < 0 || nr >= R || nc < 0 || nc >= C) continue;   // 出界
            char ch = g[nr][nc];
            if (ch == '#') continue;                                // 墙
            if (ch == 'D' && k == 0) continue;                      // 没钥匙进不了门
            int nk = (ch == 'K') ? 1 : k;                           // 踩到钥匙就拿上
            if (dist[nr][nc][nk] != -1) continue;                   // 这个状态来过
            dist[nr][nc][nk] = dist[r][c][k] + 1;
            q.push({nr, nc, nk});
        }
    }
    return -1;
}

逐行说明：

  • dist 是三维的：前两维是位置，第三维是钥匙状态。-1 同时表示没有到过，省去了单独的 visited 数组。
  • queue<tuple<int,int,int>>：队列中存放完整的状态（行、列、钥匙），取出时用结构化绑定 auto [r, c, k] 拆开。
  • dr、dc 两个数组写出四个方向，循环 4 次就是上下左右。
  • 判断的顺序是：出界、墙、门、算出新的钥匙状态、查询这个新状态是否到过。nk 必须在查询 dist 之前算好，因为是否到过要按新状态查询。
  • 入队时就写入 dist，保证每个状态只入队一次，总复杂度为 O(R×C×2)。

练习 7.8-1【基础】预算内最长的连续行程

题面：一条路线依次有 n 段路，第 i 段的过路费 a[i] ≥ 0。选一段连续的路段，过路费总和不超过预算 S，求最多能走几段。0 ≤ n ≤ 10⁵，0 ≤ a[i] ≤ 10⁹，0 ≤ S ≤ 10¹⁴。

提示

五问：输入 a、S；输出段数；n ≤ 10⁵，要 O(n) 或 O(n log n)；限制里最关键的是过路费非负；总和最大 10¹⁴，用 long long。暴力固定左端 l 往右加，超过 S 就停，因为费用非负，再往右只会更大，最坏 O(n²)。优化看重复计算：l 右移一格后，暴力又从 l 重新加起，而上一轮已经算过这一段的和。费用非负保证 l 右移时，满足条件的最远右端不会左移，所以 l、r 都只往右走，O(n)。手工模拟样例 1，每加入一段后的窗口依次是 [2]、[2,1]、[1,3]、[1,3,0]、[0,4]、[1]。对拍时值域要包含 0，样例 3 这类 S=0、全零段的情况才会出现。

int longestTripBrute(const vector<int>& a, long long S) {
    int n = (int)a.size(), best = 0;
    for (int l = 0; l < n; ++l) {
        long long sum = 0;
        for (int r = l; r < n; ++r) {
            sum += a[r];
            if (sum > S) break;                    // 非负：再往右只会更大
            best = max(best, r - l + 1);
        }
    }
    return best;
}
int longestTrip(const vector<int>& a, long long S) {

        sum += a[r];

    }

练习 7.8-2【变形】排队时有些人不能挨着

题面：n 个人（编号 0..n−1）排成一列，给出若干对 (u, v)，表示 u 和 v 不能相邻。求合法排列的个数。1 ≤ n ≤ 15。先写全排列暴力 countLineupsBrute（只对 n ≤ 10 可行），再写 O(2ⁿ·n²) 的 countLineups。

提示

范围：15! ≈ 1.3×10¹²，全排列只能做 n ≤ 10 的部分；2¹⁵·15² ≈ 7.4×10⁶ 可以做满。暴力用 next_permutation 列出所有排列，逐对检查相邻两人。找重复计算：前缀 [0,2,3] 和 [2,0,3] 用到的人相同、最后一人相同，后面怎么接完全一样，暴力却把后半段各算了一遍。所以状态取（已排好的人的集合 mask，最后一人 last），dp[mask][last] 是这样的前缀个数，mask 的写法见第 5 章。转移：选一个不在 mask 里、且和 last 不冲突的 nx，把 dp[mask][last] 加到 dp[mask | (1 << nx)][nx]。答案是 mask 为全集时各个 last 的和。结果最大 15! ≈ 1.3×10¹²，用 long long。

long long countLineupsBrute(int n, const vector<pair<int, int>>& bad) {
    vector<vector<bool>> ban(n, vector<bool>(n, false));
    for (auto [u, v] : bad) { ban[u][v] = true; ban[v][u] = true; }
    vector<int> p(n);
    for (int i = 0; i < n; ++i) p[i] = i;          // 从升序开始，next_permutation 才能列出全部 n! 种
    long long cnt = 0;
    do {
        bool ok = true;
        for (int i = 0; i + 1 < n; ++i) if (ban[p[i]][p[i + 1]]) { ok = false; break; }
        if (ok) ++cnt;
    } while (next_permutation(p.begin(), p.end()));
    return cnt;
}
long long countLineups(int n, const vector<pair<int, int>>& bad) {
    vector<vector<bool>> ban(n, vector<bool>(n, false));
    for (auto [u, v] : bad) { ban[u][v] = true; ban[v][u] = true; }
    // dp[mask][last]：已排好的人是 mask、最后一人是 last 的前缀个数
    vector<vector<long long>> dp(1 << n, vector<long long>(n, 0));
    for (int i = 0; i < n; ++i) dp[1 << i][i] = 1;
    for (int mask = 1; mask < (1 << n); ++mask)
        for (int last = 0; last < n; ++last) {
            if (dp[mask][last] == 0) continue;
            for (int nx = 0; nx < n; ++nx)
                if (!(mask >> nx & 1) && !ban[last][nx])
                    dp[mask | (1 << nx)][nx] += dp[mask][last];
        }
    long long total = 0;
    for (int last = 0; last < n; ++last) total += dp[(1 << n) - 1][last];
    return total;
}

def count_lineups_brute(n, bad):

练习 7.8-3【综合】最多拆 k 堵墙的最短路

题面：R×C 网格，'S' 是起点，'E' 是出口，'#' 是墙，'.' 是空地。每步走到上下左右相邻的格子；走进墙格时要把它拆掉，整个过程最多拆 k 堵墙。求从 S 到 E 的最少步数，到不了返回 −1。1 ≤ R, C ≤ 40，0 ≤ k ≤ R·C。先写枚举"拆哪些墙"的暴力 breakWallsBrute（配一个普通 BFS wallBfsPlain），再写状态 BFS breakWallsBFS。

样例：网格 {"S##.E", ".#...", "....."}，k=0 输出 8（绕到最下面一行），k=1 输出 6（拆 (1,1)），k=2 输出 4（拆第 0 行的两堵，直走）。网格 {"S#E"}，k=0 输出 −1，k=1 输出 2。

提示

找状态：钥匙迷宫里"有没有钥匙"决定后面能走哪里；这里"已经拆了几堵"决定后面还能拆几堵，所以状态是（行, 列, 已拆数 u），共 R·C·(k+1) 个，最多约 2.6×10⁶。转移：走进墙格时 u 加 1，超过 k 就不能走。同一格子 u 不同就是不同状态，只按位置记 dist 会犯 keyDoorBFSWrong 的错误：少拆墙到达的路线被多拆墙但先到达的路线挡掉。暴力用独立的思路：枚举墙的子集，大小不超过 k 的子集把这些墙改成空地，再跑普通 BFS，取最小值。最短路线不会重复经过同一格，所以两种做法的答案相同。有 w 堵墙时暴力要跑 2ʷ 次 BFS，只能用于墙很少的小网格，正好用来对拍。边界：k=0 时就是普通 BFS；S、E 被墙隔开且 k=0 时返回 −1。

int wallBfsPlain(const vector<string>& g) {       // 普通 BFS：'#' 不能走
    int R = (int)g.size(), C = (int)g[0].size(), sr = 0, sc = 0;
    for (int r = 0; r < R; ++r)
        for (int c = 0; c < C; ++c)
            if (g[r][c] == 'S') { sr = r; sc = c; }
    vector<vector<int>> dist(R, vector<int>(C, -1));
    queue<pair<int, int>> q;
    dist[sr][sc] = 0;
    q.push({sr, sc});
    int dr[4] = {-1, 1, 0, 0}, dc[4] = {0, 0, -1, 1};
    while (!q.empty()) {
        auto [r, c] = q.front(); q.pop();
        if (g[r][c] == 'E') return dist[r][c];
        for (int t = 0; t < 4; ++t) {
            int nr = r + dr[t], nc = c + dc[t];
            if (nr < 0 || nr >= R || nc < 0 || nc >= C) continue;
            if (g[nr][nc] == '#' || dist[nr][nc] != -1) continue;
            dist[nr][nc] = dist[r][c] + 1;
            q.push({nr, nc});
        }
    }
    return -1;
}
int breakWallsBrute(const vector<string>& g, int k) {   // 枚举拆哪些墙，每种跑一次普通 BFS
    vector<pair<int, int>> walls;
    for (int r = 0; r < (int)g.size(); ++r)
        for (int c = 0; c < (int)g[0].size(); ++c)
            if (g[r][c] == '#') walls.push_back({r, c});
    int w = (int)walls.size(), best = -1;
    for (int mask = 0; mask < (1 << w); ++mask) {
        vector<string> h = g;
        int used = 0;
        for (int i = 0; i < w; ++i)
            if (mask >> i & 1) { h[walls[i].first][walls[i].second] = '.'; ++used; }
        if (used > k) continue;                    // 最多拆 k 堵
        int d = wallBfsPlain(h);
        if (d != -1 && (best == -1 || d < best)) best = d;

    int R = (int)g.size(), C = (int)g[0].size(), sr = 0, sc = 0;

def break_walls_bfs(g, k):
    R, C, sr, sc = len(g), len(g[0]), 0, 0
    for r in range(R):
        for c in range(C):
            if g[r][c] == 'S': sr, sc = r, c
    # dist[(r, c, u)]：走到 (r,c) 且已拆 u 堵墙的最少步数，不在字典里就是还没到过

    while q:
        r, c, u = q.popleft()
        if g[r][c] == 'E': return dist[(r, c, u)]  # BFS 第一次到出口就是最少步数

            nr, nc = r + dr[t], c + dc[t]
            if nr < 0 or nr >= R or nc < 0 or nc >= C: continue

            dist[(nr, nc, nu)] = dist[(r, c, u)] + 1
            q.append((nr, nc, nu))

易错点：

  • 状态少了一维，BFS 会把"带着钥匙回头走"当成重复状态跳过；手算时同一格子走两次，就是要加维度的信号。
  • 最大和类问题的初值用 LLONG_MIN；全负数时用 0 当初值会输出 0。
  • n 很小时暴力就是正解，省下的时间用来写对拍和测边界。

练习 7.9-1【基础】ACM 模式：最长上升连续段

题面：输入第一行是 n，第二行是 n 个整数；输出最长的严格递增连续段的长度，n=0 时输出 0。写暴力 longestRiseBrute、O(n) 的 longestRise，以及把整段输入当字符串处理的 solveRiseText。0 ≤ n ≤ 10⁵。

提示

暴力从每个 l 往右走到不再严格递增为止，O(n²)。优化的状态是"以当前元素结尾的递增段长度 cur"：a[i] > a[i−1] 时 cur 加 1，否则重置为 1，和练习 7.1-2 的连击数是同一种转移，O(n)。solveRiseText 按本节的写法用 istringstream 读，n=0 时第二行为空，读数循环一次都不执行。三组自测分别覆盖题目样例、全相同（要求严格递增，相等时也要重置）、空输入。

int longestRiseBrute(const vector<int>& a) {
    int n = (int)a.size(), best = 0;
    for (int l = 0; l < n; ++l) {
        int r = l;
        while (r + 1 < n && a[r + 1] > a[r]) ++r;  // 走到不再严格递增
        best = max(best, r - l + 1);
    }
    return best;
}
int longestRise(const vector<int>& a) {
    int best = 0, cur = 0;                         // cur：以 a[i] 结尾的递增段长度
    for (int i = 0; i < (int)a.size(); ++i) {
        if (i > 0 && a[i] > a[i - 1]) ++cur;
        else cur = 1;
        best = max(best, cur);
    }
    return best;
}
string solveRiseText(const string& input) {
    istringstream in(input);
    int n;
    in >> n;
    vector<int> a(n);
    for (int& x : a) in >> x;
    return to_string(longestRise(a)) + "\n";
}
def longest_rise_brute(a):
    n, best = len(a), 0
    for l in range(n):
        r = l
        while r + 1 < n and a[r + 1] > a[r]: r += 1   # 走到不再严格递增
        best = max(best, r - l + 1)
    return best
def longest_rise(a):
    best, cur = 0, 0                               # cur：以 a[i] 结尾的递增段长度
    for i in range(len(a)):
        if i > 0 and a[i] > a[i - 1]: cur += 1
        else: cur = 1
        best = max(best, cur)
    return best
def solve_rise_text(text):
    data = text.split()
    n = int(data[0])
    a = [int(x) for x in data[1:1 + n]]
    return str(longest_rise(a)) + "\n"

练习 7.9-2【变形】只会一半时按情况分段

题面：给 n 个整数 a[i] 和 target（target ≥ 1），求和不小于 target 的最短连续区间长度，不存在返回 −1。n ≤ 10⁵，|a[i]| ≤ 10⁴。题目说明：50% 的数据所有 a[i] ≥ 0；另有 20% 的数据含负数但 n ≤ 3000。假设你只会非负情况的滑动窗口。写暴力 shortestReachBrute、只对非负数据正确的 shortestReachWindow，以及分段调用的 shortestReachSafe：全部非负走窗口，否则走暴力。

样例 1：a=[2,3,1,2,4,3]，target=7，输出 2（4+3）。样例 2：a=[−3,1]，target=1，输出 1。样例 3：a=[1,1]，target=5，输出 −1。

提示

滑动窗口的依据是"右端加入一个数，和不会变小；左端移出一个数，和不会变大"，这只在所有数非负时成立。样例 2 说明了失败的过程：窗口先放入 −3，和为 −3，再放入 1，和为 −2，始终达不到 1，左端从不移动，单独的 [1] 被漏掉，返回 −1。所以分段函数先扫一遍判断有没有负数：全部非负用窗口拿 50% 的分，含负数时用 O(n²) 暴力拿 n ≤ 3000 的 20%，合计 70%。剩下 30% 需要前缀和加单调队列，可以参考 7.8 第一道新题。暴力内层找到第一个达标的 r 就停，因为同一个 l 再往右只会更长。

参考答案
int shortestReachBrute(const vector<int>& a, long long target) {
    int n = (int)a.size(), best = -1;
    for (int l = 0; l < n; ++l) {
        long long sum = 0;
        for (int r = l; r < n; ++r) {
            sum += a[r];
            if (sum >= target) {
                if (best == -1 || r - l + 1 < best) best = r - l + 1;
                break;                             // 同一个 l 再往右只会更长
            }
        }
    }
    return best;
}
int shortestReachWindow(const vector<int>& a, long long target) {   // 前提：a 全部非负
    int best = -1, l = 0;
    long long sum = 0;
    for (int r = 0; r < (int)a.size(); ++r) {
        sum += a[r];
        while (sum >= target) {                    // 达标：尝试从左边缩短
            if (best == -1 || r - l + 1 < best) best = r - l + 1;
            sum -= a[l++];
        }
    }
    return best;
}
int shortestReachSafe(const vector<int>& a, long long target) {
    bool nonneg = true;
    for (int x : a) if (x < 0) nonneg = false;
    if (nonneg) return shortestReachWindow(a, target);   // 50% 的数据：O(n)
    return shortestReachBrute(a, target);          // 其余数据：O(n²)，能过 n ≤ 3000 的部分
}
def shortest_reach_brute(a, target):
    n, best = len(a), -1
    for l in range(n):
        s = 0
        for r in range(l, n):
            s += a[r]
            if s >= target:
                if best == -1 or r - l + 1 < best: best = r - l + 1
                break                              # 同一个 l 再往右只会更长
    return best
def shortest_reach_window(a, target):              # 前提：a 全部非负
    best, l = -1, 0
    s = 0
    for r in range(len(a)):
        s += a[r]
        while s >= target:                         # 达标：尝试从左边缩短
            if best == -1 or r - l + 1 < best: best = r - l + 1
            s -= a[l]; l += 1
    return best
def shortest_reach_safe(a, target):
    nonneg = True
    for x in a:
        if x < 0: nonneg = False
    if nonneg: return shortest_reach_window(a, target)   # 50% 的数据：O(n)
    return shortest_reach_brute(a, target)         # 其余数据：O(n²)，能过 n ≤ 3000 的部分

练习 7.9-3【综合】多组数据与输出格式

题面：输入第一行是组数 T。每组第一行是 n 和 k，第二行是 n 个整数（n=0 时第二行为空行）。对每组输出一行：存在 i < j 使 a[i] + a[j] = k 输出 YES，否则输出 NO。1 ≤ T ≤ 10⁴，所有组的 n 之和不超过 2×10⁵，|a[i]| ≤ 10⁹，|k| ≤ 2×10⁹。写暴力 hasPairKBrute、哈希版 hasPairK 和 solvePairsText。

样例 1：输入 "3\n4 8\n1 5 3 4\n2 6\n3 3\n0 5\n\n"，输出 "YES\nYES\nNO\n"。样例 2：输入 "1\n1 8\n4\n"，输出 "NO\n"。

提示

多组数据按 n 的总和估复杂度：哈希版总共 O(2×10⁵)；暴力每组 O(n²)，单组 n 可达 2×10⁵，只能拿小数据的分。哈希版先查后存：先看 k − a[j] 是否在前面出现过，再把 a[j] 放进集合，所以样例 2 的 4 不会和自己配对，样例 1 第二组的两个 3 能配对。输出格式逐项核对：每组一行，YES/NO 大写，每行以换行结尾。istringstream 按空白读数，n=0 那组的空行会被自动跳过。a[i] + a[j] 可达 2×10⁹，k − a[j] 可达 3×10⁹，都用 long long。

参考答案
bool hasPairKBrute(const vector<long long>& a, long long k) {
    for (int i = 0; i < (int)a.size(); ++i)
        for (int j = i + 1; j < (int)a.size(); ++j)
            if (a[i] + a[j] == k) return true;
    return false;
}
bool hasPairK(const vector<long long>& a, long long k) {
    unordered_set<long long> seen;                 // 当前位置之前出现过的值
    for (long long x : a) {
        if (seen.count(k - x)) return true;        // 先查：只和前面的数配对
        seen.insert(x);                            // 后存
    }
    return false;
}
string solvePairsText(const string& input) {
    istringstream in(input);
    int T;
    in >> T;
    string out;
    while (T--) {
        int n;
        long long k;
        in >> n >> k;
        vector<long long> a(n);
        for (auto& x : a) in >> x;                 // n=0 时一个数都不读，空行被 >> 自动跳过
        out += hasPairK(a, k) ? "YES\n" : "NO\n";
    }
    return out;
}
def has_pair_k_brute(a, k):
    for i in range(len(a)):
        for j in range(i + 1, len(a)):
            if a[i] + a[j] == k: return True
    return False
def has_pair_k(a, k):
    seen = set()                                   # 当前位置之前出现过的值
    for x in a:
        if k - x in seen: return True              # 先查：只和前面的数配对
        seen.add(x)                                # 后存
    return False
def solve_pairs_text(text):
    data = text.split()                            # 按空白切开，空行自然消失
    pos = 0
    T = int(data[pos]); pos += 1
    out = []
    for _ in range(T):
        n, k = int(data[pos]), int(data[pos + 1]); pos += 2
        a = [int(x) for x in data[pos:pos + n]]; pos += n
        out.append("YES\n" if has_pair_k(a, k) else "NO\n")
    return "".join(out)

  • 一上来就写代码，写到一半发现思路不对；先说清楚思路、得到面试官认可再写，返工最少。
  • 只测题目样例就提交；至少再加一组最小边界、一组最大值。
  • 笔试时调试输出忘了删，并且写到了 cout，所有测试点都会判错。

7.10 解题模板：拿到一道新题，按七步填一张表 必读

下面逐项说明每一格该怎样填。

① 输入输出（7.1）。 先确定数据的"形状"：一维数组、字符串、链表、二叉树、图、网格、区间列表，还是一串操作。形状本身就缩小了范围，例如输入是区间列表，十有八九要先排序。输出也要看清：只要一个数（最大值、个数），通常是动态规划、贪心或一次扫描；要求列出全部方案，几乎一定是回溯；只问"能不能"，有时可以二分。题目要求"原地修改"或"O(1) 额外空间"，就排除了另开数组的做法。

② 数据范围（7.2）。 时间限制和数据范围一起决定"最多能做多少步"：C++ 每秒大约 10⁸ 次简单运算，Python 大约 10⁷ 次。据此得到常用的对照：

≤ 10O(n!)全排列枚举
≤ 20O(2ⁿ)子集枚举、回溯、状态压缩

数值的范围决定类型：两个不超过 10⁹ 的数相加就可能超过 int 的上限（约 2.1×10⁹），求和、相乘时用 long long。数值范围很小（例如只有 0～1000）时，可以直接用数组下标计数，代替哈希表或排序（17.16 的计数排序）。

内存限制决定能开多大的数组。常见的 256 MB 大约能放 6.7×10⁷ 个 int（每个 4 字节），long long 减半。所以 5000×5000 的 int 二维表约占 95 MB，可以开；10⁴×10⁴ 就要约 381 MB，超出限制，这时要观察第 i 行只依赖第 i−1 行，只保留两行（"滚动数组"，11.7），空间降到约 80 KB。递归也占空间：递归深度达到 10⁵ 时，有的平台会栈溢出，需要改成循环（4.8）。

③ 限制清单（7.1、7.7）。 这一格最容易被跳过，却最常决定方法对不对。逐条问自己，答案从题面、数据范围和样例里找：

  • 有没有负数？ 有负数时，"窗口越长、和越大"不再成立，滑动窗口失效，要改用前缀和（下面的例题）。
  • 有没有重复？ 重复元素会让"去重""第一个或最后一个位置"成为要处理的问题，排列组合题要做同层去重（11.2）。
  • 是否有序？ 有序就可以二分或用对撞双指针；无序但顺序不重要时，可以先排序。
  • 可能为空、只有 1 个元素、全部相同吗？ 这些是最常见的出错输入，写完代码要专门测。
  • 答案有多个时返回哪个？要不要取模？下标从 0 还是从 1 起？

样例是这一格的重要线索：样例里出现了负数、重复值或 0，说明测试数据一定会有；样例的输出格式（空格分隔还是换行、要不要排序）也要照抄。反过来，样例通常很小，不会暴露溢出和超时，这两件事要靠第 ② 格自己算。

④ 一句话抽象。 把题目的故事去掉，写成"在 X 上求 Y"。例如"统计连续若干天销售额恰好为 k 的段数"抽象成"在整数数组上，求和为 k 的连续子数组个数"。抽象之后，题目往往就和一道见过的题对上了。

完整走一遍：和为 k 的子数组

题目（LeetCode 560）：给整数数组 nums 和整数 k，统计和恰好为 k 的连续子数组的个数。数据范围：1 ≤ n ≤ 2×10⁴，−1000 ≤ nums[i] ≤ 1000，−10⁷ ≤ k ≤ 10⁷。

步骤填写的内容
① 输入输出输入一维整数数组和 k；输出一个个数；不需要修改数组
② 数据范围n ≤ 2×10⁴，O(n²) 约 4×10⁸ 次，偏慢，最好 O(n) 或 O(n log n)；前缀和最大约 2×10⁴×1000 = 2×10⁷，int 够用；个数最多约 n²/2 = 2×10⁸，int 也够
③ 限制清单有负数；有重复的值；n ≥ 1，不会为空
④ 抽象在整数数组上，求和为 k 的连续子数组个数
⑤ 信号 → 候选"连续子数组"让人先想到滑动窗口；但有负数，滑动窗口不成立，改用前缀和加哈希表
⑥ 暴力解枚举左右端点，边扩展边累加，O(n²)；优化：子数组 [i, j] 的和 = pre[j+1] − pre[i]，找"和为 k"就是对每个 pre[j+1] 查之前有几个 pre[i] 等于 pre[j+1] − k，用哈希表计数，O(n)
⑦ 变量与检查cnt[s] 表示"目前为止前缀和为 s 出现过几次"，初始 cnt[0] = 1（空前缀）；边界：k = 0、全是 0、只有一个元素

第 ③ 格的"有负数"为什么能推翻滑动窗口？滑动窗口的做法是"和太大就收缩左端"，它依赖"窗口变长，和只会变大"。用 nums = [1, −1, 1]、k = 1 试一下：和为 1 的子数组有 [1]（第一个）、[1, −1, 1]、[1]（最后一个）共 3 个。滑动窗口在右端到第三个元素时，窗口 [1, −1, 1] 的和是 1，计数一次，就移向下一个右端，漏掉了同样以它结尾、和也为 1 的 [1]，只数出 2 个。原因正是负数让"缩短窗口"也可能不改变和。前缀和加哈希表的做法不依赖单调性，得到 3。代码见 9.3 的例题 560。

要点

  • 拿到新题先填七格：输入输出、数据范围、限制清单、一句话抽象、信号与候选、暴力解、变量与检查，填完再写代码。
  • 时间限制配合 n 决定复杂度上限（C++ 约每秒 10⁸ 次）；数值范围决定 int 还是 long long；内存限制决定能开多大的数组（256 MB 约 6.7×10⁷ 个 int）。
  • 样例里出现的负数、重复、0 一定会出现在测试数据中；样例不会暴露溢出和超时，要自己算。
  • 信号表只给候选，要用限制清单验证：连续子数组有负数时，滑动窗口失效，改用前缀和。

A. n ≤ 10⁵，复杂度应控制在 O(n log n) 或 O(n) 左右

B. 信号是'连续子数组、最短'，又有负数，所以普通的滑动窗口可以直接用

C. 前缀和可能超出 int，应该用 long long

D. 限制清单里的'有负数'只影响溢出，不影响选择哪种方法

查看答案与每个选项的解析

A · 正确：O(n²) 约 10¹⁰ 次，远超每秒约 10⁸ 次的上限。

B · 错误：有负数时窗口变长和不一定变大，'和够了就收缩左端'不再正确；这题的正确做法是前缀和加单调队列（LeetCode 862）。

C · 正确：题目没有给出元素的绝对值上限时，10⁵ 个大数相加可能超过 int，按 ② 先算再定类型；拿不准就用 long long。

D · 错误：负数直接决定滑动窗口能不能用，是选方法的关键条件。

多选 · 理解检查 6　内存限制 256 MB。下列哪些数组可以直接开？

A. int dp[5000][5000]

B. int dp[10000][10000]

C. vector<int> a(10000000)

D. vector<long long> a(50000000)

查看答案与每个选项的解析

A · 正确：2500 万个 int，约 95 MB。

B · 错误：1 亿个 int，约 381 MB，超过 256 MB；第 i 行只依赖第 i−1 行时，改成两行的滚动数组。

C · 正确：10⁷ 个 int 约 38 MB。

D · 错误：5×10⁷ 个 long long 约 381 MB，超过限制。

易错点：

  • 跳过第 ③ 格直接按信号表选方法，最常见的后果就是在有负数的数组上用了滑动窗口。
  • 只用样例测试：样例规模小，测不出溢出和超时，第 ② 格要自己算一遍最大数据的规模和数值。

小结： 拿到新题按七步填表：输入输出、数据范围（时间、数值、内存）、限制清单（负数、重复、有序、空、取模）、一句话抽象、信号对应的候选方法、暴力解与优化、变量含义与边界检查；信号表给出候选，限制清单决定候选是否成立。
