33.1 先用循环：2 个数、3 个数的全排列

为什么从循环开始

面对一道不会的题，最稳的起点是"先用已经会的工具做一个最小的版本"。你已经会 for 循环，那就先把 n=2、n=3 的排列用循环写出来。写的过程中会碰到一堵墙，这堵墙正好告诉我们：递归在这里是必需品，而不是炫技。

排列是什么

把 n 个互不相同的数排成一排，每个数恰好用一次，得到的一个序列叫这 n 个数的一个排列（permutation）。"全排列"就是把所有排列都列出来。1,2,3 的全排列有 6 个：123、132、213、231、312、321。

换个说法：排列就是"往 n 个空位里依次填数，每个数只能填一次"。第 0 个空位填什么、第 1 个空位填什么……每个空位都要做一次选择。

2 个数：两重循环

两个空位，就用两层循环：外层变量 i 决定第 0 位放 a[i]，内层变量 j 决定第 1 位放 a[j]。两个位置不能放同一个元素，所以加一个判断 j != i。

vector<int> a = {1, 2};
for (int i = 0; i < 2; ++i)            // 第 0 位放 a[i]
    for (int j = 0; j < 2; ++j)        // 第 1 位放 a[j]
        if (j != i) cout << a[i] << a[j] << "\n";   // 输出 12 和 21

这里判断的是下标相同，而不是数值相同。用下标判断的好处是：以后数组里出现重复数值时，逻辑依然清楚（33.7 会专门讲重复）。

3 个数：三重循环

三个空位，就三层循环。第三层的 k 要同时避开 i 和 j。

vector<vector<int>> permute3Loops(const vector<int>& a) {
    vector<vector<int>> ans;
    for (int i = 0; i < 3; ++i)                       // 第 0 位用 a[i]
        for (int j = 0; j < 3; ++j) {                 // 第 1 位用 a[j]
            if (j == i) continue;                     // 和第 0 位撞了，跳过
            for (int k = 0; k < 3; ++k) {             // 第 2 位用 a[k]
                if (k == i || k == j) continue;       // 和前两位撞了，跳过
                ans.push_back({a[i], a[j], a[k]});
            }
        }
    return ans;
}

逐行读：

行作用为什么这样写
vector<vector<int>> ans;存所有排列的"数组的数组"每个排列本身是一个 vector<int>，很多个排列放在一起就是二维 vector
for (int i ...)枚举第 0 位用哪个下标3 个元素都可能放在第 0 位
if (j == i) continue;第 1 位和第 0 位用了同一个元素，跳过continue 直接进入下一个 j，第三层根本不会执行
if (k == i || k == j) continue;第 2 位要避开前两位位置越靠后，要避开的越多
ans.push_back({a[i], a[j], a[k]});三个位置都填好，存一份{...} 现场构造一个 vector<int> 放进 ans

撞上那堵墙：n 一变就写不下去

现在把题目换成 1~6。照这个办法要写 6 层 for，第 6 层要和前 5 个下标逐一比较。更麻烦的是笔试题常写"第一行输入 n"：n 是运行时才读进来的，而 for 的层数在写代码的那一刻就固定了。你写了 6 层，输入 7 就错；没有任何一种写法能"写出 n 层 for"。

仔细看三层循环，会发现每一层做的事几乎一模一样：

  1. 对每个候选元素试一遍；
  2. 如果它已经被前面的位置用了，跳过；
  3. 否则把它放到"当前位置"，然后进入下一层去决定下一个位置。

唯一的区别是"当前位置是第几位"。既然每层都一样，就把"一层"写成一个函数 dfs(pos)，它里面只有一层 for；"进入下一层"就是调用 dfs(pos + 1)；当 pos == n，说明所有位置都填好了，记录答案。函数调用自己多少次由 n 决定，层数就跟着 n 变了。递归就是层数可变的循环，这是本章最重要的一句话。

左边每多一个位置就要多写一层 for；右边只写一层 for，靠函数调用自己来叠出任意多层

另一个改进：三重循环用 k == i || k == j 判断"撞没撞"，层数一多，要比较的就越来越多。我们准备一个布尔数组 used，used[i] == true 表示 a[i] 已经被前面某个位置用了，查一次就知道，不用挨个比较。33.3 的代码就是"一层 for + used + 调用自己"。

考场结论

  • 位置数固定且很小（2~3 个）时，多重 for 可以直接写，最不容易错。
  • 位置数由输入决定，或者大于 3，就用递归：一层函数负责一个位置。
  • 判断"已用"用下标，借助 used 数组一次查完。

练一练：三位数

题面： 用 1~m 中的数字组成三位数，要求三个数位上的数字互不相同。按从小到大的顺序输出所有这样的三位数。m=4 时有几个？最小和最大分别是多少？

思路提示： 三个位置固定，三重 for 就够。候选直接是数字 1..m；记录时把三个数字拼成整数 x*100 + y*10 + z。

vector<int> threeDigitNumbers(int m) {
    vector<int> out;
    for (int x = 1; x <= m; ++x)
        for (int y = 1; y <= m; ++y) {
            if (y == x) continue;
            for (int z = 1; z <= m; ++z) {
                if (z == x || z == y) continue;
                out.push_back(x * 100 + y * 10 + z);
            }
        }
    return out;
}

答案：m=4 时共 24 个，最小 123，最大 432。计数方法：百位 4 种，十位剩 3 种，个位剩 2 种，4×3×2 = 24。

和例题相比改了哪一处： 候选从"数组下标"换成"数字本身"，并且 m 个候选里只选 3 个（不是全部用完）；记录的东西从 vector 换成了拼好的整数。

易错点：

  • 第三层漏写 k == i，只写了 if (k == j) continue;。对 {1,2,3} 会输出 12 个结果：121 123 131 132 212 213 231 232 312 313 321 323。原因是第 2 位只避开了第 1 位，没避开第 0 位，于是 121、131 这种首尾相同的也混进来了。改法：每一层都要避开前面所有位置。
  • 把 continue 写成 break：break 会结束整层循环，后面的候选一个都试不到，结果会少。

速记： 位置少就多重 for；位置数随输入变化就用递归，一层函数管一个位置，used 记录谁被用了。

33.2 把排列画成搜索树

为什么要画树

递归代码只有十来行，但它执行起来会进进出出很多次，光看代码很难想象。把"每一步做了什么选择"画成一棵树，递归的执行过程就变成了"在树上走路"，这样哪一步在哪一层、下一步去哪里，一眼就能看出来。

生活类比：填空格

想象有 3 个空格 □□□，手上有卡片 1、2、3。第 1 格有 3 种填法；不管第 1 格填了什么，第 2 格只剩 2 张卡片；第 3 格只剩 1 张。这就像走路遇到岔路口：第一个路口分 3 条路，每条路上第二个路口分 2 条，第三个路口只剩 1 条。

它是什么：搜索树的四个名词

  • 根（root）：最上面的节点，表示"一个位置都还没填"，记作 [ ]。
  • 层（level）：根在第 0 层。走到第 d 层，表示已经填好了 d 个位置。树的每一层对应决定一个位置。
  • 孩子：从一个节点往下的每条边，表示"当前位置填某个还没用过的数"。
  • 叶子（leaf）：没有孩子的节点，所有位置都填满了。从根到某个叶子的路径，就是一个排列。

下面是 1,2,3 的完整排列树。每个节点写的是走到这里时已经填好的部分（也就是后面代码里的 path）。

数一数：第 1 层 3 个节点，第 2 层 3×2 = 6 个，第 3 层（叶子）3×2×1 = 6 个。叶子数就是排列数。

这个"每一步的选法相乘"的规则叫乘法原理：一件事分成几步完成，每一步的选法数与前面怎么选无关，总方法数就是各步选法数的乘积。n 个数的排列：第 0 位 n 种，第 1 位 n−1 种……最后一位 1 种，总数 n×(n−1)×…×1，记作 n!（读作"n 的阶乘"）。1..6 的排列有 6! = 720 个。

1..6 的排列树：下标 d 是层号（已经填好的位置数），第 d 层有 6×5×…×(6−d+1) 个节点

完整走一遍：程序怎样走这棵树

程序里并没有真的建出这棵树，它是"想象出来的"。递归执行的顺序，正好是在这棵树上做深度优先搜索（depth-first search，DFS）：能往下走就一直往下走，走到叶子就记录；走不动了就退回最近一个还有别的路的岔路口，换下一条路。"退回去"这个动作叫回溯（backtracking），这也是回溯法名字的来源。[3]

下图黄色是"当前路径"（边也加粗），绿色是"已经走完的部分"，叶子上的 #1、#2…… 是记录的先后顺序。

规律与考场结论

  • 树有 n+1 层（第 0 层到第 n 层），第 d 层每个节点有 n−d 个孩子。
  • 叶子数 = n!；前 k 层走完时的节点数是 n×(n−1)×…×(n−k+1)，记作 A(n,k)，表示"从 n 个里取 k 个排成一排"的方法数。
  • 递归的调用栈里，在任何时刻都恰好放着"根到当前节点"这条路径上的各层。
  • DFS 先走最左边的子树，所以叶子从左到右就是输出顺序：123、132、213、231、312、321。

单选 · 理解检查 1　对 1,2,3,4 画排列树（根在第 0 层）。第 2 层有几个节点？叶子一共有几个？

A. 12 个；24 个

B. 8 个；24 个

C. 12 个；16 个

D. 6 个；12 个

查看答案与每个选项的解析

A · 正确：第 2 层 = 前两个位置已填：4×3 = 12；叶子 = 4! = 24。

B · 错误：第 2 层的每个节点都来自第 1 层的某个节点，第 1 层 4 个节点、每个有 3 个孩子，是 4×3 而不是 4×2。

C · 错误：16 = 2⁴ 是子集的个数；排列的叶子数是 4! = 24。

D · 错误：这是把 4 个数当成 3 个数来算了。

练一练：只取 2 个排成一排

题面： 从 1,2,3,4 中取 2 个不同的数排成一排（例如 12 和 21 算两种）。画出对应的搜索树，叶子有几个？

思路提示： 只决定 2 个位置，所以树只有第 0、1、2 层，第 2 层就是叶子。

答案：4×3 = 12 个，也就是 A(4,2) = 12。33.6 的 arrangeK({1,2,3,4}, 2) 会真的把这 12 个生成出来，practice 文件里有断言。

和例题相比改了哪一处： 树在第 2 层就停，叶子不再是"所有数都用完"，而是"选够 2 个"。

易错点：

  • 树是帮助思考的图，代码里不需要建 TreeNode。递归调用一次，就相当于从当前节点走到一个孩子。
  • 叶子数是 n!，但递归函数被调用的次数等于整棵树的节点数（1..6 时是 1957 次），比叶子数多。估算时间时两者是同一个数量级。

速记： 一层 = 一个位置，一条根到叶子的路径 = 一个排列；叶子数 n!；递归按"先走到底、再退回岔路口"的顺序走这棵树。

33.3 写法一：path + used（最推荐背熟的写法）

为什么是它

这种写法和 33.2 的树一一对应：path 就是"根到当前节点的路径"，used 记录路径上用过哪些元素，for 循环就是"当前节点的每个孩子"。它能直接改成带条件、带重复、只取 k 个等各种变形，是面试里最值得背熟的模板。

变量表

变量含义谁共用
nums输入的数，只读所有层共用，按 const& 传
path已经填好的前几个位置（树上从根到当前节点的路径）所有层共用同一个，按引用传
used[i]nums[i] 是否已经在 path 里所有层共用，按引用传
ans已经找到的完整排列（每个都是复制出来的）所有层共用，按引用传
i本层正在试第几个元素每层各有一个，存在自己的栈帧里

path.size() 恰好等于"当前在第几层"：path 为空在第 0 层，path 有 2 个数就在第 2 层。所以函数不需要额外的 pos 参数。

代码

void dfsPermute(const vector<int>& nums, vector<int>& path,
                vector<bool>& used, vector<vector<int>>& ans) {
    if (path.size() == nums.size()) {          // ① 每个位置都填好了
        ans.push_back(path);                   // ② 复制一份存进答案
        return;                                // ③ 回到上一层
    }
    for (int i = 0; i < (int)nums.size(); ++i) {   // ④ 这一位依次试每个数
        if (used[i]) continue;                 // ⑤ 已经在 path 里，跳过
        used[i] = true;                        // ⑥ 标记：nums[i] 用掉了
        path.push_back(nums[i]);               // ⑦ 填进当前位置
        dfsPermute(nums, path, used, ans);     // ⑧ 去填下一个位置
        path.pop_back();                       // ⑨ 撤销⑦：把 nums[i] 拿出来
        used[i] = false;                       // ⑩ 撤销⑥：nums[i] 又能用了
    }
}
vector<vector<int>> permute(const vector<int>& nums) {
    vector<vector<int>> ans;
    vector<int> path;
    vector<bool> used(nums.size(), false);
    dfsPermute(nums, path, used, ans);
    return ans;
}

为什么必须有撤销的两行

撤销的目的是：兄弟节点要从同一个父状态出发。树上 [1] 的两个孩子 [1,2] 和 [1,3]，都应该在 path=[1]、used=[T,F,F] 的基础上各自加一个数。如果试完 2 不把它拿出来，再试 3 时 path 里还留着 2。

我们分别删掉一行，看看实际输出（practice 文件里有这两个错误版本和断言）：

删掉 ⑨ path.pop_back();，输出只有 1 个：

123

原因：记录 123 后回到第 2 层，3 留在 path 里；回到第 1 层，2 也留着；第 1 层接着选 3，path 变成 [1,2,3,3]，长度 4。从此 path 只会越来越长，再也不会等于 3，① 永远不成立。程序结束时 path 里堆了 15 个数：1,2,3,3,2,2,1,3,3,1,3,1,2,2,1。

删掉 ⑩ used[i] = false;，输出也只有 1 个：123。原因：记录 123 后 used 变成 [T,T,T] 且再也不会变回 false；回到第 1 层想试 3、回到第 0 层想试 2，都被 ⑤ 跳过了。

规律：做选择的两行和撤销的两行一一配对，顺序相反，像穿衣服和脱衣服：先穿的后脱。谁在这一层做了选择，谁就在这一层调用返回之后撤销。

复杂度

叶子有 n! 个，每个叶子复制一次长度为 n 的 path，时间 O(n·n!)；递归最深 n 层，path 和 used 各占 O(n) 额外空间（不算答案本身）。n=6 时只有 720×6 次复制，非常快。

Python 对照

def permute(nums):
    ans, path, used = [], [], [False] * len(nums)
    def dfs():
        if len(path) == len(nums):
            ans.append(path[:]); return      # path[:] 复制一份；直接 append(path) 会存进同一个对象
        for i in range(len(nums)):
            if used[i]: continue
            used[i] = True; path.append(nums[i])
            dfs()
            path.pop(); used[i] = False
    dfs(); return ans

C++ 的 push_back(path) 自动复制；Python 列表是引用，要写 path[:] 才是复制。

练一练 1：相邻两位的差不等于 1

题面： 输出 1..n 的所有排列中，任意相邻两位的差的绝对值都不等于 1 的那些。例如 n=4 时，2413 符合（|2−4|=2，|4−1|=3，|1−3|=2），1324 不符合（|3−2|=1）。n=4、5、6 时各有几个？

思路提示： 在"选"的那一刻就检查：新放的数和 path 最后一个数的差是 1，就不放。这样整棵子树都不用走了，这叫剪枝（pruning，提前剪掉不可能成功的分支）。

void dfsNoAdjacent(int n, vector<int>& path, vector<bool>& used, vector<vector<int>>& ans) {
    if ((int)path.size() == n) { ans.push_back(path); return; }
    for (int v = 1; v <= n; ++v) {
        if (used[v]) continue;
        if (!path.empty() && abs(path.back() - v) == 1) continue;   // 新增的一行：和前一位差 1 就不放
        used[v] = true;
        path.push_back(v);
        dfsNoAdjacent(n, path, used, ans);
        path.pop_back();
        used[v] = false;
    }
}
vector<vector<int>> permuteNoAdjacent(int n) {
    vector<vector<int>> ans;
    vector<int> path;
    vector<bool> used(n + 1, false);
    dfsNoAdjacent(n, path, used, ans);
    return ans;
}

答案：n=4 有 2 个（2413、3142），n=5 有 14 个，n=6 有 90 个。

和例题相比改了哪一处： ① 直接枚举数值 v=1..n，所以 used 开 n+1 个，用 used[v]；② 多了一行剪枝条件。其余 8 行与模板完全相同。

练一练 2：能被 7 整除的六位数

题面： 用 1~6 这 6 个数字各一次组成六位数（共 720 个）。其中能被 7 整除的有几个？能被 11 整除的呢？

思路提示： 先用 permute 生成全部排列，再把每个排列拼成整数（拼法见 33.4），检查余数。

int countDivisible(int m) {
    vector<vector<int>> all = permute({1, 2, 3, 4, 5, 6});
    int cnt = 0;
    for (const vector<int>& p : all) {
        long long num = 0;
        for (int d : p) num = num * 10 + d;
        if (num % m == 0) ++cnt;
    }
    return cnt;
}

答案：能被 7 整除的有 90 个；能被 11 整除的有 0 个。0 个并非程序出错：一个数能被 11 整除，当且仅当"奇数位数字和 − 偶数位数字和"是 11 的倍数。六个数字总和 21 是奇数，两组和的差也一定是奇数，只可能是 ±11；这要求一组和为 16、另一组为 5，而三个不同数字的和最小是 1+2+3 = 6 > 5，做不到。枚举给出答案，推理解释答案，两者对得上，你就放心了。

和例题相比改了哪一处： 模板一行没改，只在拿到 ans 之后多做一步"过滤"。生成全部再过滤，是 n 较小时最省脑子的做法。

易错点：

  • 撤销写在 for 循环外面（循环结束才 pop 一次）：同一层的第二个兄弟会带着第一个兄弟的选择出发，结果缺失。撤销要紧跟在递归调用的下一行。
  • 用数值当下标时（used[v]，v 从 1 到 n），used 要开 n+1 个；开 n 个时 used[n] 越界。
  • ans.push_back(path) 存的是副本，所以记录后撤销 path 不会影响 ans。

速记： 出口在前，循环在后；跳过已用，做选择（标记+放入），递归，撤销（拿出+取消标记）；选择与撤销成对、顺序相反。

为什么单独讲

题目说"存成一个数组"，具体可能是三种东西：二维数组（每个排列是一行）、整数数组（123456 这样的数）、字符串数组（"123456"）。ACM 模式还要求按行打印。这一节把四种形式都写出来，并说清结果为什么恰好按从小到大的顺序排列。

形式三：拼成字符串

    string s;
    for (int d : p) s += char('0' + d);      // 数字 3 → 字符 '3'
    return s;
}

toText({1,2,3,4,6,5}) 得到 "123465"。

形式四：ACM 模式按行输出

笔试常见的格式是"输入一个 n，按字典序每行输出一个排列，数字之间用空格隔开"。

void printPermutationsACM(int n, ostream& out) {
    vector<int> nums;
    for (int v = 1; v <= n; ++v) nums.push_back(v);
    for (const vector<int>& p : permute(nums)) {
        for (int i = 0; i < n; ++i) out << p[i] << (i + 1 < n ? " " : "\n");
    }
}
int main() {
    int n;
    cin >> n;
    printPermutationsACM(n, cout);   // 输入 3，输出 6 行：1 2 3 / 1 3 2 / … / 3 2 1
}

参数写成 ostream& out 是为了方便测试（practice 里传入字符串流检查输出）；做题时直接传 cout。(i + 1 < n ? " " : "\n") 让数字之间是空格、行末是换行，行末不留多余空格。

结果为什么是字典序

字典序（lexicographic order）就是查字典的顺序：两个序列从左往右比，第一个不同的位置上谁小，谁就排在前面。123465 和 123546 前三位相同，第 4 位 4 < 5，所以 123465 在前。

模板输出恰好是字典序，原因有两个，缺一不可：

  1. 输入 nums 是升序的 1,2,3,…；
  2. 每一层的 for 循环 i 从小到大试。

于是第 0 层先试 1：所有以 1 开头的排列都在以 2 开头的之前产生。进入以 1 开头的那一组，第 1 层又从剩下的最小数开始……每一层都"小的先来"，整体就是字典序。

如果输入是 {3,1,2}，第一个输出就是 312，顺序乱了。所以题目要求字典序时，先 sort 再枚举。

考场结论

  • 二维数组：vector<vector<int>>，模板直接返回。
  • 整数：num = num * 10 + d，用 long long。
  • 字符串：s += char('0' + d)，或者直接让 path 本身就是 string。
  • 字典序 = 输入升序 + 每层 i 从小到大。

练一练：字符串的全部排列

题面： 给一个由不同大写字母组成的字符串，例如 "CAB"，按字典序输出它的所有排列。

思路提示： 把元素类型从 int 换成 char，path 直接用 string（string 也有 push_back、pop_back）；先 sort，输出就是字典序。

void dfsString(const string& s, string& path, vector<bool>& used, vector<string>& ans) {
    if (path.size() == s.size()) { ans.push_back(path); return; }
    for (int i = 0; i < (int)s.size(); ++i) {
        if (used[i]) continue;
        used[i] = true;
        path.push_back(s[i]);
        dfsString(s, path, used, ans);
        path.pop_back();
        used[i] = false;
    }
}
vector<string> permuteString(string s) {
    sort(s.begin(), s.end());                  // 先排好序，输出才是字典序
    vector<string> ans;
    string path;
    vector<bool> used(s.size(), false);
    dfsString(s, path, used, ans);
    return ans;
}

答案：permuteString("CAB") = {ABC, ACB, BAC, BCA, CAB, CBA}；"ABCD" 有 24 个。

和例题相比改了哪一处： 只换了类型（int → char，vector<int> → string），以及入口多一个 sort。递归骨架一行没变。

易错点：

  • 10 位及以上的数用 int 存会溢出，统一用 long long。
  • char('0' + d) 只适用于 0~9 的一位数字；元素是 10 以上的数时，用 to_string(x) 拼接。
  • 要字典序却忘了 sort，只有输入恰好有序时结果才对。

速记： 二维 vector 直接存，整数 num*10+d 用 long long，字符串 '0'+d；输入升序 + i 从小到大 = 字典序。

33.5 写法二：std::next_permutation

为什么需要它

C++ 标准库已经提供了"求下一个排列"的函数 next_permutation。用它写全排列只要 5 行，不用写递归，还天然处理重复元素。笔试时间紧，这是最快的写法。但面试官常追问"它是怎么实现的"，所以这一节把原理也讲透，并亲手实现一遍。[4]

它是什么

next_permutation(first, last) 把区间 [first, last) 里的元素原地改成字典序中的下一个排列：

  • 如果存在下一个排列：改成它，返回 true；
  • 如果当前已经是最大的排列（整体从大到小，例如 654321）：把它改回最小的排列（123456），返回 false。

它在头文件 <algorithm> 里。区间写法和 sort 一样：a.begin() 到 a.end()，左闭右开。

用法：sort + do-while

vector<vector<int>> permuteByNext(vector<int> a) {
    sort(a.begin(), a.end());                       // 从最小的排列出发
    vector<vector<int>> ans;
    do {
        ans.push_back(a);                           // 先记录当前这个
    } while (next_permutation(a.begin(), a.end())); // 再变成下一个；没有下一个就停
    return ans;
}

逐行读：

行作用为什么这样写
vector<int> a（按值传）函数里拿到一份副本next_permutation 会修改数组，按值传就不会改坏调用者的数据
sort(...)变成升序，也就是字典序最小的排列next_permutation 只往"更大"的方向走，起点必须是最小的，才能走遍全部
do { ... }先执行一次循环体最小的那个排列也要记录，所以"先记录、后判断"
while (next_permutation(...))变成下一个，返回 true 就继续到了最大的排列，返回 false，循环结束

为什么用 do-while？ 普通 while 是"先判断再执行"。写成 while (next_permutation(...)) ans.push_back(a);，第一次判断时数组已经被改成了第二个排列，最小的 123456 永远没被记录。practice 里用 while 版数 1..6 的排列，只数到 719 个。

忘了 sort 会怎样？ 从 {3,1,2} 出发，只会得到 312、321 两个：321 是最大的排列，下一步就返回 false。

原理：像数字递增一样找"下一个"

把排列当作一个数：123465 的"下一个排列"就是"用同样的数字能组成的、比它大的数里最小的那个"。想让一个数变大一点点，应该改尽量靠右的位置（改高位变化太大）。

看 123465 的末尾 6、5：它们从左到右是降序的，降序已经是这两个数字能排出的最大情况，只动它们无法变大。于是往左找到第一个"还能变大"的位置 4。

像数字递增一样：右边已经到顶时，向左找第一个还能变大的位置

完整算法四步：

  1. 找 i：从右往左，找第一个满足 a[i] < a[i+1] 的位置 i。i 右边的部分（后缀）一定是降序的。找不到 i（整个数组降序），说明已是最大排列，整体反转成升序，返回 false。
  2. 找 j：从右往左，找第一个满足 a[j] > a[i] 的位置 j。因为后缀是降序，从右往左第一个比 a[i] 大的，就是后缀里"比 a[i] 大的数中最小的那个"，这样 i 位置只增大一点点。
  3. 交换 a[i] 和 a[j]。交换后后缀仍然是降序的（a[j] 换成了 a[i]，它比左边的大、比右边的小或相等）。
  4. 反转 i+1 到末尾，降序变升序。i 位置已经变大了，后面要尽量小，升序就是最小。

自己实现一遍

bool myNextPermutation(vector<int>& a) {
    int n = a.size();
    int i = n - 2;
    while (i >= 0 && a[i] >= a[i + 1]) --i;    // 第 1 步：从右往左找第一个"小于右邻居"的位置
    if (i < 0) {                               // 整个数组从左到右不增：已是最大排列
        reverse(a.begin(), a.end());           // 变回最小排列
        return false;
    }
    int j = n - 1;
    while (a[j] <= a[i]) --j;                  // 第 2 步：从右往左找第一个比 a[i] 大的
    swap(a[i], a[j]);                          // 第 3 步：交换
    reverse(a.begin() + i + 1, a.end());       // 第 4 步：把 i 右边反转成升序
    return true;
}

逐行读：

行作用细节
int i = n - 2;从倒数第二个开始要和右邻居 a[i+1] 比较，i 最大只能是 n−2
a[i] >= a[i + 1] 时 --i跳过降序部分用 >= 而不是 >：相等也不能变大，这样重复元素也正确
if (i < 0)没找到返回 false 前先反转，保证和标准库行为一致
while (a[j] <= a[i]) --j;找第一个严格大于 a[i] 的一定找得到（至少 a[i+1] > a[i]），所以无需判断 j ≥ 0
reverse(a.begin() + i + 1, a.end())后缀反转a.begin() + i + 1 是指向下标 i+1 的迭代器

practice 中把 myNextPermutation 和 std::next_permutation 从 123456 开始同步走了 721 步（包括最后返回 false 回到起点那一步），每一步的数组和返回值都一致；对带重复的 {1,1,2,2,3} 也逐步对比了。时间复杂度：一次调用最坏 O(n)，生成全部排列共 O(n·n!)。

prev_permutation：往小的方向走

prev_permutation 是反方向：改成字典序中的上一个排列；已是最小（升序）时变成最大并返回 false。要从大到小输出全部排列，先降序排序，再 do { } while (prev_permutation(...))。例如 {1,2,3,5,4,6} 的上一个是 {1,2,3,4,6,5}。[5]

}

33.6 写法三：交换法

为什么还要学一种

交换法不需要 path 和 used：数组本身就是 path。它的代码最短，经常出现在老教材和别人的题解里，你需要能看懂；它还有一个好处：只排前 m 位时可以直接停，适合"从 n 个里取 m 个排成一排"。

它是什么

用一句话描述状态：下标 0..k−1 的位置已经定好了；第 k 位还没定，候选是 a[k..n−1] 中的每一个。

想让 a[i] 坐到第 k 位，就把它和 a[k] 交换；然后递归去定第 k+1 位；回来后再交换一次，把数组恢复原样，好让下一个候选上场。

void swapDfs(vector<int>& a, int k, vector<vector<int>>& ans) {
    if (k == (int)a.size()) { ans.push_back(a); return; }   // 前 k 位都定好了
    for (int i = k; i < (int)a.size(); ++i) {
        swap(a[k], a[i]);          // 让 a[i] 来坐第 k 个位置
        swapDfs(a, k + 1, ans);    // 定第 k+1 位
        swap(a[k], a[i]);          // 换回来，恢复原样
    }
}
vector<vector<int>> permuteSwap(vector<int> a) {
    vector<vector<int>> ans;
    swapDfs(a, 0, ans);
    return ans;
}

逐行读：

行作用为什么
if (k == n)所有位置都定了，记录整个数组此时 a 本身就是一个排列
for (int i = k; ...)候选是 a[k..n−1]i 从 k 开始：i=k 表示"原来坐这里的数继续坐"，这也是一种选择
第一个 swap把 a[i] 换到第 k 位前 k 位不动，所以已定的部分不会被破坏
swapDfs(a, k + 1, ans)定下一位和 path+used 写法里的 ⑧ 一样
第二个 swap交换回来这一行就是交换法的"撤销"

void arrangeDfs(vector<int>& a, int k, int m, vector<vector<int>>& ans) {
    if (k == m) { ans.push_back(vector<int>(a.begin(), a.begin() + m)); return; }   // 改动：到第 m 位就停

        arrangeDfs(a, k + 1, m, ans);
        swap(a[k], a[i]);

}

}

33.7 有重复元素：1,1,2 的排列只有 3 个

为什么需要它

把 1,1,2 排成一排，看得见的不同结果只有 112、121、211 三个。直接套 33.3 的模板会输出 6 个：

112 121 112 121 211 211

因为模板按下标区分元素，它眼里是两个不同的 1。题目通常要求"不同的排列"，所以要把重复的去掉。

它是什么：重复出在哪里

给两个 1 起名 1a、1b（下标 0、1）。重复的根源是：在同一层（同一个位置）上，先试了 1a，又试了 1b。这两次填进去的数值一样，下面的子树也一模一样，生成的排列必然重复。

所以规则是：在同一层，相同的值只试第一次。实现分两步：

  1. 先 sort，让相同的值挨在一起；
  2. 在循环里加一行：
if (i > 0 && nums[i] == nums[i - 1] && !used[i - 1]) continue;

这一行的三个条件：

  • i > 0：保证 nums[i-1] 存在；
  • nums[i] == nums[i-1]：和左边的值相同（排过序，相同的值都相邻）；
  • !used[i-1]：左边那个相同的数现在没在 path 里。它为什么没在？因为它刚刚在这一层被试过、又被撤销了。所以现在再试 nums[i]，就是"同一层重复试相同的值"，跳过。

反过来，如果 used[i-1] 为 true，说明 nums[i−1] 在 path 上，是上面某一层放进去的；现在把 nums[i] 放在当前位置，是"不同位置放相同的数"，这正是 112 这种合法排列需要的，所以允许。

效果相当于规定：相同的几个数，必须按 1a、1b 的先后顺序被使用。

排好序的 nums = [1a,1b,2]。✕ 的两条边：同一层里 1a 刚试过又撤销（used[0]=false），1b 再来就重复了；[1a] 下面的 1b ✓ 是下一层，1a 还在 path 上（used[0]=true），可以放

代码

void dfsUnique(const vector<int>& nums, vector<int>& path,
               vector<bool>& used, vector<vector<int>>& ans) {
    if (path.size() == nums.size()) { ans.push_back(path); return; }
    for (int i = 0; i < (int)nums.size(); ++i) {
        if (used[i]) continue;
        if (i > 0 && nums[i] == nums[i - 1] && !used[i - 1]) continue;   // 同层遇到相同值的第二个：跳过
        used[i] = true;
        path.push_back(nums[i]);
        dfsUnique(nums, path, used, ans);
        path.pop_back();
        used[i] = false;
    }
}
vector<vector<int>> permuteUnique(vector<int> nums) {
    sort(nums.begin(), nums.end());            // 相同的值必须挨在一起
    vector<vector<int>> ans;
    vector<int> path;
    vector<bool> used(nums.size(), false);
    dfsUnique(nums, path, used, ans);
    return ans;
}

有重复时的个数

33.8 子集：每个元素选或不选

为什么需要它

"从这些物品里挑一部分""每道菜点或不点""每个开关开或关"——这类问题的答案是一个子集：从 n 个元素里挑出一些，可以一个都不挑，也可以全挑，顺序无所谓。{1,3} 和 {3,1} 是同一个子集。

它是什么：一棵二叉树

排列的每一层问"这个位置放谁"；子集的每一层问"这个元素要不要"。第 d 层只决定 a[d] 一个元素，答案只有两种：选、不选。所以子集的搜索树每个节点恰好 2 个孩子，n 个元素有 n 层决定，叶子数是 2×2×…×2 = 2ⁿ。

这和第 32 章"生成所有 01 串"是同一件事：把"选"记成 1、"不选"记成 0，每个子集就对应一个长度为 n 的 01 串。{1,3} 对应 101。

下图左孩子是"选"，右孩子是"不选"；节点里的"定 k？"表示这一层要决定元素 k。叶子从左到右就是输出顺序。

写法一：递归，选或不选

void dfsSubset(const vector<int>& a, int idx, vector<int>& path, vector<vector<int>>& ans) {
    if (idx == (int)a.size()) {          // 每个元素都决定过了
        ans.push_back(path);
        return;
    }
    path.push_back(a[idx]);              // 选 a[idx]
    dfsSubset(a, idx + 1, path, ans);
    path.pop_back();                     // 撤销
    dfsSubset(a, idx + 1, path, ans);    // 不选 a[idx]
}
vector<vector<int>> subsetsChoose(const vector<int>& a) {
    vector<vector<int>> ans;
    vector<int> path;
    dfsSubset(a, 0, path, ans);
    return ans;
}

写法二：二进制枚举（位掩码）

既然子集和 01 串一一对应，而 0 到 2ⁿ−1 的每个整数写成 n 位二进制恰好是所有 01 串，那就用一个循环把整数 mask（掩码）从 0 数到 2ⁿ−1，每个 mask 对应一个子集。[6]

vector<vector<int>> subsetsMask(const vector<int>& a) {
    int n = a.size();
    vector<vector<int>> ans;
    for (int mask = 0; mask < (1 << n); ++mask) {   // 0 .. 2^n - 1，每个数对应一个子集
        vector<int> cur;
        for (int j = 0; j < n; ++j)
            if (mask >> j & 1) cur.push_back(a[j]); // 第 j 位是 1：选 a[j]
        ans.push_back(cur);
    }
    return ans;
}

逐个符号读：

  • 1 << n：1 左移 n 位，等于 2ⁿ。n=3 时是 8。
  • mask >> j：mask 右移 j 位，原来的第 j 位（从右往左数，最右是第 0 位）挪到了最右边。
  • & 1：和 1 做按位与，只保留最右边一位，结果是 0 或 1。
  • 运算顺序：>> 的优先级高于 &，所以 mask >> j & 1 就是 (mask >> j) & 1。不确定时加括号最稳妥。[7]

题面： 给一个由字母和数字组成的字符串，把其中每个字母都可以变成小写或大写，数字保持不变，输出所有可能的字符串。例如 "a1b" → a1b、a1B、A1b、A1B；"3z4" → 3z4、3Z4。"ab12cd" 有几种？

思路提示： 这还是"每个位置二选一"，只是选项从"选 / 不选"变成"小写 / 大写"；数字位置只有一条路。

void dfsCase(string& s, int idx, vector<string>& ans) {
    if (idx == (int)s.size()) { ans.push_back(s); return; }
    char c = s[idx];
    if (isalpha((unsigned char)c)) {
        s[idx] = (char)tolower((unsigned char)c);   // 分支 1：小写
        dfsCase(s, idx + 1, ans);
        s[idx] = (char)toupper((unsigned char)c);   // 分支 2：大写
        dfsCase(s, idx + 1, ans);
        s[idx] = c;                                 // 恢复原字符
    } else {
        dfsCase(s, idx + 1, ans);                   // 数字只有一条路
    }
}
vector<string> letterCaseVariants(string s) {
    vector<string> ans;
    dfsCase(s, 0, ans);
    return ans;
}

答案："ab12cd" 有 4 个字母，2⁴ = 16 种；"2024" 没有字母，只有 1 种。

和例题相比改了哪一处： 不再用 path，直接在字符串 s 上原地改（和交换法一样，"原地改 + 改回来"）；只有字母位置分两叉。isalpha、tolower、toupper 在 <cctype> 里，参数先转成 unsigned char 是为了防止负数编码出错。

易错点：

  • 写成 if (mask & 1 << j == 1)：== 的优先级高于 &，实际算的是 mask & ((1 << j) == 1)，只有 j=0 时才可能为真，结果错得离谱。写成 mask >> j & 1 或加括号 (mask & (1 << j)) != 0。
  • 1 << n 在 n ≥ 31 时超出 int 范围；子集枚举本来也只适合 n ≤ 20 左右。
  • 递归写法的出口要看 idx 是否到 n，而不是 path 长度。

速记： 子集 = 每个元素选或不选 = 01 串，共 2ⁿ 个；递归先选后撤销再不选；位掩码 for mask < (1<<n)，mask >> j & 1 看第 j 个选没选。

33.9 组合 C(n,k)：用 start 防止重复

为什么需要它

"从 5 个人里选 3 个组队""从 1..9 里选 3 个数凑成 15"，要的是组合：从 n 个里选 k 个，不管顺序。{1,2} 和 {2,1} 是同一个组合。如果用排列的模板（每层从全部未用元素里选），{1,2} 和 {2,1} 都会出现，每个组合被重复 k! 次。

它是什么：规定从小到大选

去重的办法很简单：规定组合里的数必须从小到大选。{1,2} 只能以"先 1 后 2"的方式被生成，{2,1} 这种顺序根本不允许出现，重复自然消失。

实现上给递归加一个参数 start：下一个数最小可以是几。选了 i 之后，下一层的 start 就是 i+1，只能往后选。

计数：排列 A(n,k) 里，每个组合被它的 k! 种顺序各数了一次，所以 C(n,k) = A(n,k) / k! = n! / (k!·(n−k)!)。C(4,2) = 12/2 = 6。

combine(4,2)：每个孩子都比父亲最后选的数大，所以 {2,1} 这种倒序根本不会出现；[4] 后面已经没有数可选，剪枝让它连试都不试

代码

void dfsCombine(int n, int k, int start, vector<int>& path, vector<vector<int>>& ans) {
    if ((int)path.size() == k) {                 // 已经选够 k 个
        ans.push_back(path);
        return;
    }
    int need = k - (int)path.size();             // 还差几个
    for (int i = start; i <= n - need + 1; ++i) { // 剪枝：i 及其后面至少要剩 need 个数
        path.push_back(i);                       // 选 i
        dfsCombine(n, k, i + 1, path, ans);      // 下一个只能从 i+1 开始
        path.pop_back();                         // 撤销
    }
}
vector<vector<int>> combine(int n, int k) {
    vector<vector<int>> ans;
    vector<int> path;
    dfsCombine(n, k, 1, path, ans);
    return ans;
}

逐行读：

行作用为什么
start本层候选的最小值保证选出的数严格递增，从而不重复

剪枝为什么有效

以 n=4、k=2 为例，第 0 层 need=2，上界 4−2+1 = 3，所以 i 只试 1、2、3。如果试 i=4，后面没有数可选，path 永远凑不够 2 个，这条路注定白走。剪掉它，递归调用从 11 次降到 10 次。差别看着小，但在 n=20、k=18 时，不剪枝要调用 1,048,555 次，剪枝后只要 1,330 次（practice 里有统计函数和断言）。

题面： 从 1..n 中选 k 个不同的数，使它们的和等于 S，输出所有选法（组合内从小到大）。n=9、k=3、S=15 时有哪些？

思路提示： 在组合模板上多带一个参数 sum（当前和）。因为 i 从小到大，一旦 sum + i > S，后面的 i 更大，全部可以停止（break）。

void dfsSumK(int n, int k, int S, int start, int sum, vector<int>& path, vector<vector<int>>& ans) {
    if ((int)path.size() == k) {
        if (sum == S) ans.push_back(path);
        return;
    }
    for (int i = start; i <= n; ++i) {
        if (sum + i > S) break;                      // 升序：后面更大，一起剪掉
        path.push_back(i);
        dfsSumK(n, k, S, i + 1, sum + i, path, ans);
        path.pop_back();
    }
}
vector<vector<int>> combineSum(int n, int k, int S) {
    vector<vector<int>> ans;
    vector<int> path;
    dfsSumK(n, k, S, 1, 0, path, ans);
    return ans;
}

答案：共 8 组：159、168、249、258、267、348、357、456。

和例题相比改了哪一处： ① 多了参数 sum，递归时传 sum + i（按值传，返回后自动恢复，不用手动撤销）；② 出口多了 sum == S 的判断；③ 剪枝从"数量够不够"换成"和会不会超"。

易错点：

  • 递归写成 dfsCombine(n, k, start + 1, ...)：下一层的起点只比本层起点大 1，而不是比刚选的数大 1。combine(4,2) 会输出 12 个：12 13 14 22 23 24 32 33 34 42 43 44，出现了 22 这样的重复数和 32 这样的倒序。
  • 剪枝上界写成 n - need，少了 +1，会把合法的最后一个起点剪掉，结果变少。
  • 组合不需要 used 数组；混用 used 和 start 不会错，但多余。

速记： 组合 = 不管顺序 = 规定递增；start 表示下一个最小可选值，递归传 i+1；剪枝 i ≤ n−(k−path.size())+1；C(n,k) = n!/(k!(n−k)!)。

long long nCk(int n, int k) {

vector<int> kthPermutation(int n, long long k) {      // k 从 1 开始
    vector<int> left;                                 // 还没用的数，保持升序
    for (int v = 1; v <= n; ++v) left.push_back(v);
    k -= 1;                                           // 改成从 0 开始：前面跳过 k 个
    vector<int> ans;
    for (int pos = 0; pos < n; ++pos) {
        long long block = factorial(n - 1 - pos);     // 这一位每换一个数，后面有 block 个排列
        int idx = k / block;                          // 要跳过几整块
        ans.push_back(left[idx]);
        left.erase(left.begin() + idx);
        k %= block;                                   // 块内还要跳过几个
    }
    return ans;
}

其中 factorial(m) 就是 1×2×…×m（practice 里有实现）。逐行读： left 存还能用的数且保持升序，left[idx] 就是"第 idx 小的可用数"；k / block 是要整块跳过的块数；k %= block 是块内的剩余偏移；erase 把用掉的数删除，后面的自动前移。

n=6、k=100 时：99/120 = 0 → 1；99/24 = 4 → 剩余 {2,3,4,5,6} 的第 4 个是 6；3/6 = 0 → 2；3/2 = 1 → {3,4,5} 中的 4；1/1 = 1 → {3,5} 中的 5；最后是 3。结果 162453，和 33.5 用 next_permutation 走 99 步的结果一样。practice 中对 1..6 的全部 720 个 k 都与 permute 的结果逐一核对过。

复杂度对比： 生成全部再取第 k 个是 O(n·n!)；next_permutation 走 k−1 步是 O(k·n)；逐位确定是 O(n²)（n 次 erase）。n=20、k=10¹⁸ 时只有逐位确定能用；20! = 2,432,902,008,176,640,000 仍在 long long 范围内。

反过来：一个排列是第几个

逐位确定的逆运算叫康托展开（Cantor expansion）：对每一位，数一数它右边有几个比它小的数（这些数放在这一位时，排列更小），乘上后面位数的阶乘，加起来再加 1。[9]

long long permutationRank(const vector<int>& p) {    // 返回 p 是第几个（从 1 开始）
    int n = p.size();
    long long rank = 0;
    for (int i = 0; i < n; ++i) {
        int smaller = 0;                              // 右边比 p[i] 小的个数
        for (int j = i + 1; j < n; ++j)
            if (p[j] < p[i]) ++smaller;
        rank += smaller * factorial(n - 1 - i);
    }
    return rank + 1;
}

2314：2 右边比它小的有 1 个，1×3! = 6；3 右边比它小的有 1 个（1），1×2! = 2；1 右边没有更小的；4 是最后一位。合计 8，加 1 得第 9 个，和上面对上了。

int countNotAdjacent() {        // 6 人排队（编号 0..5），0 号和 1 号不相邻
    vector<int> a = {0, 1, 2, 3, 4, 5};
    int cnt = 0;
    do {
        int p0 = find(a.begin(), a.end(), 0) - a.begin();
        int p1 = find(a.begin(), a.end(), 1) - a.begin();
        if (abs(p0 - p1) != 1) ++cnt;
    } while (next_permutation(a.begin(), a.end()));
    return cnt;
}

find(a.begin(), a.end(), 0) 返回指向值 0 的迭代器，减去 a.begin() 得到下标，也就是甲站在第几个位置。结果 480。
