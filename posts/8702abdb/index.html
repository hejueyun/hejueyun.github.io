6.9 图的 DFS（递归与显式栈）和 BFS

有了邻接表和 visited，就能回答图上最常见的三类问题：从起点能到达哪些点、图由几块组成、从起点到每个点最少走几步。前两类问题 DFS 和 BFS 都可以解决，第三类必须用 BFS。

递归 DFS：进入时先标记

void graphDfs(const vector<vector<int>>& adj, int u, vector<bool>& visited, vector<int>& order) {
    visited[u] = true;                       // 进门先做标记
    order.push_back(u);
    for (int v : adj[u]) {
        if (!visited[v]) graphDfs(adj, v, visited, order);
    }
}
def graph_dfs(adj, u, visited, order):      # 点很多时递归会超过 Python 默认约 1000 层：sys.setrecursionlimit 或改用显式栈
    visited[u] = True                       # 进门先做标记
    order.append(u)
    for v in adj[u]:
        if not visited[v]: graph_dfs(adj, v, visited, order)

逐行说明：第 2 行一进入就标记，这样以后无论从哪条边绕回 u，都会被第 5 行的检查挡住；第 4 行依次查看 u 的每个邻居；第 5 行只进入没有访问过的点。与树的前序遍历相比，树用空指针作为出口，图用 visited 作为出口。

显式栈 DFS

递归 DFS 依靠系统的调用栈记住返回后还要查看哪些邻居。也可以自己用 stack 记录，效果相同，还能避免递归太深导致的栈溢出。[1]

vector<int> graphDfsStack(const vector<vector<int>>& adj, int start) {
    vector<bool> visited(adj.size(), false);
    vector<int> order;
    stack<int> st;
    st.push(start);
    while (!st.empty()) {
        int u = st.top();
        st.pop();
        if (visited[u]) continue;            // 同一个点可能被压过两次，第二次跳过
        visited[u] = true;
        order.push_back(u);
        for (int i = (int)adj[u].size() - 1; i >= 0; --i) {   // 倒着压，顺着出
            int v = adj[u][i];
            if (!visited[v]) st.push(v);
        }
    }
    return order;
}
def graph_dfs_stack(adj, start):
    visited = [False] * len(adj)
    order = []
    st = []                                 # Python 用 list 当栈：append 压栈，pop() 弹出栈顶
    st.append(start)
    while st:
        u = st.pop()                        # pop() 返回并删掉栈顶，对应 top() + pop()
        if visited[u]: continue             # 同一个点可能被压过两次，第二次跳过
        visited[u] = True
        order.append(u)
        for i in range(len(adj[u]) - 1, -1, -1):   # 倒着压，顺着出
            v = adj[u][i]
            if not visited[v]: st.append(v)
    return order

BFS：按距离逐圈向外扩展

图的 BFS 与树的层序遍历结构相同，只多了 visited。这里用一个 dist 数组同时充当 visited：dist[v] == -1 表示还没有到达，否则就是从起点到 v 的最少边数。

vector<int> bfsDist(const vector<vector<int>>& adj, int start) {
    vector<int> dist(adj.size(), -1);        // -1 表示还没到过，同时充当 visited
    queue<int> q;
    dist[start] = 0;
    q.push(start);
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        for (int v : adj[u]) {
            if (dist[v] == -1) {             // 第一次见到 v
                dist[v] = dist[u] + 1;
                q.push(v);
            }
        }
    }
    return dist;
}
from collections import deque

def bfs_dist(adj, start):
    dist = [-1] * len(adj)                  # -1 表示还没到过，同时充当 visited
    q = deque()
    dist[start] = 0
    q.append(start)
    while q:
        u = q.popleft()
        for v in adj[u]:
            if dist[v] == -1:               # 第一次见到 v
                dist[v] = dist[u] + 1
                q.append(v)
    return dist

逐行说明：第 4–5 行起点的距离为 0，入队；第 10 行只处理第一次见到的点；第 11 行它的距离等于把它带进来的那个点的距离加 1；第 12 行入队。在入队时就写入 dist（即标记），而不是在出队时才标记，否则同一个点可能被几个邻居重复入队：例如 4 同时是 2 和 3 的邻居，入队时已经标记，3 再看到 4 时就会跳过。

BFS 为什么能求无权图的最少步数

队列中的点按距离排列：先是距离 0 的起点，然后是所有距离为 1 的点，再是所有距离为 2 的点……因为距离为 d 的点只会把距离为 d+1 的点放到队尾。所以一个点第一次被发现时，一定是从最近的那一层走过来的，此时写入的 dist 就是最少步数，以后不会再改变。

DFS 做不到这一点：它沿一条路一直走下去，第一次到达某个点时所走的路线不一定最短。看一个由 6 个点组成的环：

6 个点连成一圈。DFS 从 1 出发顺着 2→3→4→5→6 一路走（粗线），到 6 时已走了 5 步；BFS 按层扩展，6 和 2 都在第 1 层

从 1 出发，DFS 沿 2→3→4→5→6 走，到达 6 时已经走了 5 步，而 6 实际上与 1 直接相连，最少只需 1 步。bfsDist(ring, 1) 给出 dist[6] = 1、dist[5] = 2、dist[4] = 3。注意 BFS 的前提是每条边的代价相同（都算 1 步）；边的权重不同时要用 Dijkstra 算法（第 10 章）。

要点

  1. 图的递归 DFS：进入时标记，只走向没有访问过的邻居。
  2. 显式栈 DFS 与递归 DFS 等价；弹出时检查是否已访问，倒序压入邻居可以使访问顺序与递归版本一致。
  3. BFS 在入队时标记，dist[v] = dist[u] + 1。
  4. 无权图（每步代价相同）中求最少步数用 BFS；DFS 第一次到达时的路线不一定最短。
  5. 两种搜索都使每个点只处理一次、每条边只检查常数次，时间 O(n + m)。

练一练 2：图有几个连通块

题面：无向图（点为 1..n）由几块互不连通的部分组成？

提示：外层循环扫描每个点；遇到没有访问过的点，就发现了新的一块，从它出发做一次 DFS，把这一块全部标记。

int countComponents(const vector<vector<int>>& adj) {
    int n = (int)adj.size() - 1;
    vector<bool> visited(n + 1, false);
    int comps = 0;
    for (int u = 1; u <= n; ++u) {
        if (!visited[u]) {
            vector<int> order;
            graphDfs(adj, u, visited, order);
            comps++;
        }
    }
    return comps;
}
def count_components(adj):
    n = len(adj) - 1
    visited = [False] * (n + 1)
    comps = 0
    for u in range(1, n + 1):
        if not visited[u]:
            order = []
            graph_dfs(adj, u, visited, order)
            comps += 1
    return comps

本节的图有 2 块；4 个点只有一条边 (1,2) 时有 3 块。与例题的区别： visited 在多次 DFS 之间共享，外层循环负责寻找下一块的起点。6.10 统计网格中的连通块用的是同样的思路。

练习 6.9-1【基础】第 k 天新收到消息的人数

题面：一条消息从用户 s 发出，每天每个已收到消息的人都会转给自己的所有好友。第 0 天只有 s 知道。写 int countAtDistance(const vector<vector<int>>& adj, int s, int k)，返回恰好在第 k 天第一次收到消息的人数。n ≤ 10⁵。

样例：图 G，s = 1：k = 0 → 1；k = 1 → 2（2、5）；k = 2 → 2（3、4）；k = 3 → 0。s = 6，k = 1 → 1。

提示

"第几天第一次收到"就是"离 s 的最少边数"，题目换了说法，模型仍是 bfsDist。BFS 结束后数一数 dist 等于 k 的点，或者在出队时顺手数。没收到消息的点 dist 保持 −1，不会被算进去。

参考答案
int countAtDistance(const vector<vector<int>>& adj, int s, int k) {
    vector<int> dist(adj.size(), -1);
    queue<int> q;
    dist[s] = 0;
    q.push(s);
    int cnt = 0;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        if (dist[u] == k) cnt++;                 // 出队时顺手数：距离恰好为 k
        for (int v : adj[u]) {
            if (dist[v] == -1) { dist[v] = dist[u] + 1; q.push(v); }
        }
    }
    return cnt;
}
def count_at_distance(adj, s, k):
    dist = [-1] * len(adj)
    q = deque()
    dist[s] = 0
    q.append(s)
    cnt = 0
    while q:
        u = q.popleft()
        if dist[u] == k: cnt += 1                # 出队时顺手数：距离恰好为 k
        for v in adj[u]:
            if dist[v] == -1: dist[v] = dist[u] + 1; q.append(v)
    return cnt

练习 6.9-2【变形】每个小区离最近的消防站有多远

题面：n 个小区由无向道路相连，其中若干个小区设有消防站（列表 sources，可能为空、可能重复）。写 vector<int> multiSourceDist(const vector<vector<int>>& adj, const vector<int>& sources)，返回每个小区到最近消防站的最少道路数，到不了的记 −1；下标 0 不用，也是 −1。n ≤ 10⁵。

样例：一条链 1–2–3–4–5–6–7。sources = {1, 7} → {-1, 0, 1, 2, 3, 2, 1, 0}；sources = {4} → {-1, 3, 2, 1, 0, 1, 2, 3}；sources = {} → 全是 −1。

提示

笨办法是对每个消防站各跑一次 BFS 再取最小，k 个站就是 k 倍时间。改动只有初始化：把所有消防站一开始都放进队列、距离都设为 0，然后照常 BFS。可以想成有一个"超级起点"连着所有消防站，它到每个站的距离都是 0，队列里仍然是按距离从小到大排好的。重复的站点用 dist 是否为 −1 挡住，避免入队两次。

参考答案
vector<int> multiSourceDist(const vector<vector<int>>& adj, const vector<int>& sources) {
    vector<int> dist(adj.size(), -1);
    queue<int> q;
    for (int s : sources) {
        if (dist[s] == -1) { dist[s] = 0; q.push(s); }   // 所有起点一开始都入队，距离 0
    }
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        for (int v : adj[u]) {
            if (dist[v] == -1) { dist[v] = dist[u] + 1; q.push(v); }
        }
    }
    return dist;
}
def multi_source_dist(adj, sources):
    dist = [-1] * len(adj)
    q = deque()
    for s in sources:
        if dist[s] == -1: dist[s] = 0; q.append(s)      # 所有起点一开始都入队，距离 0
    while q:
        u = q.popleft()
        for v in adj[u]:
            if dist[v] == -1: dist[v] = dist[u] + 1; q.append(v)
    return dist

练习 6.9-3【变形】网页链接：从一个页面出发能点到哪些页面

题面：n 个网页，有向边 (u, v) 表示 u 上有一个指向 v 的链接。写 vector<int> reachableSorted(const vector<vector<int>>& adj, int s)，返回从 s 出发顺着链接能到达的所有页面（含 s），按编号从小到大。要求不用递归（页面数到 10⁵，链接可能连成很长的链）。

样例：n = 5，有向边 (1,2) (2,3) (3,1) (3,4) (5,4)。从 1 → {1, 2, 3, 4}；从 4 → {4}；从 5 → {4, 5}。

提示

用 graphDfsStack 的骨架：弹出时检查 visited。改动有两处：① 图是有向的，邻接表只记 u → v（buildDirected）；② 题目只要集合不要顺序，所以邻居正着压也行，最后排序。有向图里 1 能到 4 不代表 4 能回到 1，样例 2 就是这种情况。

参考答案
vector<int> reachableSorted(const vector<vector<int>>& adj, int s) {
    vector<bool> visited(adj.size(), false);
    vector<int> res;
    stack<int> st;
    st.push(s);
    while (!st.empty()) {
        int u = st.top();
        st.pop();
        if (visited[u]) continue;                // 同一个点可能被压过两次
        visited[u] = true;
        res.push_back(u);
        for (int v : adj[u])
            if (!visited[v]) st.push(v);         // 只要集合不要顺序：正着压也行
    }
    sort(res.begin(), res.end());
    return res;
}
def reachable_sorted(adj, s):
    visited = [False] * len(adj)
    res = []
    st = [s]
    while st:
        u = st.pop()
        if visited[u]: continue                  # 同一个点可能被压过两次
        visited[u] = True
        res.append(u)
        for v in adj[u]:
            if not visited[v]: st.append(v)      # 只要集合不要顺序：正着压也行

    return res

练习 6.9-4【综合】换乘最少的路线，把站点列出来

题面：地铁网络是无向图，每条边是一段区间。写 vector<int> shortestPathNodes(const vector<vector<int>>& adj, int s, int t)，返回一条从 s 到 t、经过区间数最少的路线（依次列出站点，含两端）；到不了返回空；s == t 返回 {s}。最短路线不止一条时，返回本题 BFS 自然得到的那条。n ≤ 10⁵。

样例：图 G。s = 1，t = 4 → {1, 5, 4}；s = 2，t = 5 → {2, 1, 5}；s = 1，t = 6 → {}；s = 3，t = 3 → {3}。

提示

BFS 求最少步数，再加一个 parent 数组（6.10 的 mazePath 在网格上用的是同一招）：每个点第一次被发现时记下"是谁把它带进来的"（parent[v] = u）。BFS 结束后从 t 顺着 parent 倒退到 s（s 的 parent 是 −1，循环在这里停），再反转。边界：先判断 t 是否被访问过，没访问过就返回空，不能从 t 往回走。样例 1 的 1→2→3→4 要经过 3 段区间，比 1→5→4 多一段，不是最短。practice 的对拍检查四件事：起点终点正确、相邻两站之间真的有边、区间数等于暴力算出的最短距离、到不了时返回空。

参考答案
vector<int> shortestPathNodes(const vector<vector<int>>& adj, int s, int t) {
    vector<int> parent(adj.size(), -1);
    vector<bool> seen(adj.size(), false);
    queue<int> q;
    seen[s] = true;
    q.push(s);
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        for (int v : adj[u]) {
            if (!seen[v]) { seen[v] = true; parent[v] = u; q.push(v); }   // 记下"v 是从 u 来的"
        }
    }
    vector<int> path;
    if (!seen[t]) return path;                   // 到不了：空路线
    for (int v = t; v != -1; v = parent[v]) path.push_back(v);   // 从终点倒退回起点
    reverse(path.begin(), path.end());
    return path;
}
def shortest_path_nodes(adj, s, t):
    parent = [-1] * len(adj)
    seen = [False] * len(adj)
    q = deque()
    seen[s] = True
    q.append(s)
    while q:
        u = q.popleft()
        for v in adj[u]:
            if not seen[v]: seen[v] = True; parent[v] = u; q.append(v)   # 记下"v 是从 u 来的"
    path = []
    if not seen[t]: return path                  # 到不了：空路线
    v = t
    while v != -1:                               # 从终点倒退回起点
        path.append(v)
        v = parent[v]
    path.reverse()
    return path

练习 6.9-5【综合】管道网络里有没有环

题面：无向图（点 1..n，保证没有自环和重复边，可能不连通）。写 bool hasCycleUndirected(const vector<vector<int>>& adj)，判断图中是否存在环。n ≤ 10⁵。

样例：图 G → true（1-2-3-4-5-1）；n = 4，边 (1,2) (1,3) (3,4) → false；n = 5，边 (1,2) (3,4) (4,5) (5,3) → true（环在不含 1 的那一块里）；n = 3，没有边 → false。

提示

DFS 时，如果走到一个已经访问过的邻居，说明有另一条路也能到它，就有环。但无向图里每条边存了两次，从 u 走到 v 后，v 的邻居里一定有 u，这条"回头边"不算环。所以给 DFS 多传一个参数 parent（从哪个点走过来的），遇到 parent 跳过。另一个陷阱是只从 1 号点出发：环可能在别的连通块里，要像 countComponents 那样外层扫描每个点。practice 用一条性质对拍：无自环、无重复边的无向图无环（是森林），当且仅当边数 = 点数 − 连通块数。相近题型：LeetCode 261。

参考答案
bool cycleDfs(const vector<vector<int>>& adj, int u, int parent, vector<bool>& visited) {
    visited[u] = true;
    for (int v : adj[u]) {
        if (v == parent) continue;               // 刚走过来的那条边，不算绕回
        if (visited[v]) return true;             // 从另一条路碰到访问过的点：有环
        if (cycleDfs(adj, v, u, visited)) return true;
    }
    return false;
}
bool hasCycleUndirected(const vector<vector<int>>& adj) {
    int n = (int)adj.size() - 1;
    vector<bool> visited(n + 1, false);
    for (int u = 1; u <= n; ++u)
        if (!visited[u] && cycleDfs(adj, u, 0, visited)) return true;   // 每个连通块都要查；0 表示没有父亲
    return false;
}
def cycle_dfs(adj, u, parent, visited):
    visited[u] = True
    for v in adj[u]:
        if v == parent: continue                 # 刚走过来的那条边，不算绕回
        if visited[v]: return True               # 从另一条路碰到访问过的点：有环
        if cycle_dfs(adj, v, u, visited): return True
    return False
def has_cycle_undirected(adj):
    n = len(adj) - 1
    visited = [False] * (n + 1)
    for u in range(1, n + 1):
        if not visited[u] and cycle_dfs(adj, u, 0, visited): return True   # 每个连通块都要查；0 表示没有父亲
    return False

易错点

  • BFS 出队时才标记，同一个点会被多次入队，结果虽可能仍对，但效率变差，网格题会超时或内存超限。
  • 显式栈 DFS 在入栈时标记、出栈时不检查，访问顺序会和递归版不同；两者都能走遍连通块，但输出顺序题会答错。
  • 用 BFS 求最短路却给边加了不同权重：BFS 只适用于每步代价相同的情况。

小结： DFS 在进入一个点时标记，沿一条路一直走到底；BFS 在入队时标记，一圈一圈向外扩展，最先到达的就是最近的。

6.10 网格也是图：方向数组、越界判断、BFS 与 DFS

int mazeShortest(const vector<string>& g) {
    int R = (int)g.size(), C = (int)g[0].size();
    int sr = 0, sc = 0, er = 0, ec = 0;
    for (int r = 0; r < R; ++r)
        for (int c = 0; c < C; ++c) {
            if (g[r][c] == 'S') { sr = r; sc = c; }
            if (g[r][c] == 'E') { er = r; ec = c; }
        }
    vector<vector<int>> dist(R, vector<int>(C, -1));
    queue<pair<int, int>> q;
    dist[sr][sc] = 0;
    q.push({sr, sc});
    while (!q.empty()) {
        auto [r, c] = q.front();
        q.pop();
        if (r == er && c == ec) return dist[r][c];   // 第一次取出终点就是最少步数
        for (int k = 0; k < 4; ++k) {
            int nr = r + DR[k], nc = c + DC[k];
            if (nr < 0 || nr >= R || nc < 0 || nc >= C) continue;   // 出界
            if (g[nr][nc] == '#') continue;                          // 墙
            if (dist[nr][nc] != -1) continue;                        // 来过
            dist[nr][nc] = dist[r][c] + 1;
            q.push({nr, nc});
        }
    }
    return -1;                                       // 走不到
}

输出路径：记录每个格子从哪里来

只求最少步数时，dist 就够了；要输出路径，就让每个格子记录自己是从哪个格子走过来的（from 数组）。BFS 结束后，从 E 开始沿 from 一路倒退到 S，再把得到的序列反转。

从 E 顺着 from 记录倒着走回 S，再反转：(0,0)→(1,0)→(1,1)→(2,1)→(2,2)→(2,3)→(2,4)→(3,4)→(4,4)，共 8 步

vector<pair<int, int>> mazePath(const vector<string>& g) {
    int R = (int)g.size(), C = (int)g[0].size();
    int sr = 0, sc = 0, er = 0, ec = 0;
    for (int r = 0; r < R; ++r)
        for (int c = 0; c < C; ++c) {
            if (g[r][c] == 'S') { sr = r; sc = c; }
            if (g[r][c] == 'E') { er = r; ec = c; }
        }
    vector<vector<pair<int, int>>> from(R, vector<pair<int, int>>(C, {-1, -1}));
    vector<vector<bool>> seen(R, vector<bool>(C, false));
    queue<pair<int, int>> q;
    seen[sr][sc] = true;
    q.push({sr, sc});
    while (!q.empty()) {
        auto [r, c] = q.front();
        q.pop();
        for (int k = 0; k < 4; ++k) {
            int nr = r + DR[k], nc = c + DC[k];
            if (nr < 0 || nr >= R || nc < 0 || nc >= C) continue;
            if (g[nr][nc] == '#' || seen[nr][nc]) continue;
            seen[nr][nc] = true;
            from[nr][nc] = {r, c};                   // 记下"我是从 (r,c) 走来的"
            q.push({nr, nc});
        }
    }
    vector<pair<int, int>> path;
    if (!seen[er][ec]) return path;                  // 走不到：空路径
    for (pair<int, int> p = {er, ec}; p.first != -1; p = from[p.first][p.second])
        path.push_back(p);                           // 从终点倒着走回起点
    reverse(path.begin(), path.end());
    return path;
}

void floodFill(vector<string>& g, int r, int c) {
    int R = (int)g.size(), C = (int)g[0].size();
    if (r < 0 || r >= R || c < 0 || c >= C) return;  // 出界
    if (g[r][c] != '1') return;                      // 水或已经淹过
    g[r][c] = '0';                                   // 淹掉 = 标记 visited
    for (int k = 0; k < 4; ++k) floodFill(g, r + DR[k], c + DC[k]);
}
int countBlocks(vector<string> g) {                  // 按值传：不改调用者的网格

                floodFill(g, r, c);                  // 把它整块淹掉
            }

要点

  1. 网格题中格子是节点，相邻格子之间有边；邻居用 DR/DC 方向数组计算。
  2. 每个邻居要通过三项检查，出界检查放在最前面。
  3. 求最少步数用 BFS 加 dist；需要输出路径时再加 from，最后从终点倒退并反转。
  4. 统计连通块时，外层扫描，每块做一次 DFS；修改格子本身可以代替 visited。

提示

"同时从多个起点向外扩、问最少几步"→ 多源 BFS（6.9 练习 2 的网格版）：所有 'F' 一开始都入队、时间设为 0。BFS 中每烧着一格草就记一次 burned，并更新最大时间 last。结束后比较 burned 和草的总数：相等返回 last，否则说明有草烧不到。边界：没有草时 last 保持 0、burned == grass == 0，返回 0。相近题型：LeetCode 994。

int burnAllMinutes(const vector<string>& g) {
    int R = (int)g.size(), C = (int)g[0].size();
    vector<vector<int>> t(R, vector<int>(C, -1));     // t：这一格在第几分钟烧着，-1 表示还没烧
    queue<pair<int, int>> q;
    int grass = 0;
    for (int r = 0; r < R; ++r)
        for (int c = 0; c < C; ++c) {
            if (g[r][c] == 'F') { t[r][c] = 0; q.push({r, c}); }   // 所有火源同时入队
            if (g[r][c] == '.') grass++;
        }
    int last = 0, burned = 0;
    while (!q.empty()) {
        auto [r, c] = q.front();
        q.pop();
        for (int k = 0; k < 4; ++k) {
            int nr = r + DR[k], nc = c + DC[k];
            if (nr < 0 || nr >= R || nc < 0 || nc >= C) continue;
            if (g[nr][nc] != '.' || t[nr][nc] != -1) continue;    // 只烧还没烧过的草
            t[nr][nc] = t[r][c] + 1;
            last = max(last, t[nr][nc]);
            burned++;
            q.push({nr, nc});
        }
    }
    return burned == grass ? last : -1;               // 还有草没烧到：-1
}

提示

只记"在哪个格子"不够了：同一格，拆过墙和没拆过墙，以后能走的路不一样。把图的节点扩成 (r, c, b)，b 表示已经拆了几面墙（0 或 1），dist 也开成三维 dist[r][c][b]。走向邻居时，邻居是墙就 b + 1，超过 1 就不能走；其他和 mazeShortest 一样，第一次取出终点（不管 b 是几）就是答案。这就是"状态 BFS"：节点 = 位置 + 额外信息。practice 的暴力解是：不拆墙跑一次普通 BFS，再把每面墙分别拆掉各跑一次，取最小值。相近题型：LeetCode 1293。

参考答案
int shortestWithOneBreak(const vector<string>& g) {
    int R = (int)g.size(), C = (int)g[0].size();
    int sr = 0, sc = 0, er = 0, ec = 0;
    for (int r = 0; r < R; ++r)
        for (int c = 0; c < C; ++c) {
            if (g[r][c] == 'S') { sr = r; sc = c; }
            if (g[r][c] == 'E') { er = r; ec = c; }
        }
    // dist[r][c][b]：走到 (r,c)、已经拆了 b 面墙时的最少步数
    vector<vector<vector<int>>> dist(R, vector<vector<int>>(C, vector<int>(2, -1)));
    queue<array<int, 3>> q;
    dist[sr][sc][0] = 0;
    q.push({sr, sc, 0});
    while (!q.empty()) {
        auto [r, c, b] = q.front();
        q.pop();
        if (r == er && c == ec) return dist[r][c][b];      // 第一次取出终点就是最少步数
        for (int k = 0; k < 4; ++k) {
            int nr = r + DR[k], nc = c + DC[k];
            if (nr < 0 || nr >= R || nc < 0 || nc >= C) continue;
            int nb = b + (g[nr][nc] == '#' ? 1 : 0);        // 走进墙就要用掉一次拆墙机会
            if (nb > 1) continue;                            // 已经拆过一次，不能再拆
            if (dist[nr][nc][nb] != -1) continue;            // 这个状态来过
            dist[nr][nc][nb] = dist[r][c][b] + 1;
            q.push({nr, nc, nb});
        }
    }
    return -1;
}
def shortest_with_one_break(g):
    R, C = len(g), len(g[0])
    sr = sc = er = ec = 0
    for r in range(R):
        for c in range(C):
            if g[r][c] == 'S': sr, sc = r, c
            if g[r][c] == 'E': er, ec = r, c
    # dist[r][c][b]：走到 (r,c)、已经拆了 b 面墙时的最少步数
    dist = [[[-1, -1] for _ in range(C)] for _ in range(R)]
    q = deque()
    dist[sr][sc][0] = 0
    q.append((sr, sc, 0))
    while q:
        r, c, b = q.popleft()
        if r == er and c == ec: return dist[r][c][b]       # 第一次取出终点就是最少步数
        for k in range(4):
            nr, nc = r + DR[k], c + DC[k]
            if nr < 0 or nr >= R or nc < 0 or nc >= C: continue
            nb = b + (1 if g[nr][nc] == '#' else 0)         # 走进墙就要用掉一次拆墙机会
            if nb > 1: continue                              # 已经拆过一次，不能再拆
            if dist[nr][nc][nb] != -1: continue              # 这个状态来过
            dist[nr][nc][nb] = dist[r][c][b] + 1
            q.append((nr, nc, nb))
    return -1

易错点

  • 先读 g[nr][nc] 再判断出界，边缘格子会越界访问。
  • 网格 DFS 先递归再标记，两个相邻陆地互相调用，直到栈溢出。
  • 行列搞反：g[r][c] 的 r 是行（第几个字符串），c 是列（字符串里第几个字符），R = g.size()，C = g[0].size()。

小结： 网格也是一种图：用 DR/DC 数组计算邻居，并检查是否出界、是否是墙、是否已访问；求最短步数用 BFS，数连通块和面积用 DFS。

6.11 选择 DFS 还是 BFS

确定一道题需要搜索之后，下一个问题是选择哪一种搜索。选错了不一定写不出来，但可能得到错误的答案（例如用 DFS 求最少步数），或者代码长出一倍。应当根据题目要求的答案来选择：

先看题目要的答案是什么，再选搜索方式

题目要的答案选择原因
所有方案、所有路径、路径本身的内容DFS + path 回溯DFS 一次只走一条路，path 天然记录这条路
最少步数、最近的目标、第几层（每步代价相同）BFS + dist按层扩展，第一次到达即最短
能不能到、有几块、每块多大两者都行只关心"走遍"，顺序无所谓；DFS 递归写起来最短

练一练：用 DFS 判断迷宫能否到达终点

题面：只问 S 能否到达 E，不问步数，用 DFS 写。

bool reachDfs(const vector<string>& g, int r, int c, vector<vector<bool>>& seen) {
    int R = (int)g.size(), C = (int)g[0].size();
    if (r < 0 || r >= R || c < 0 || c >= C) return false;
    if (g[r][c] == '#' || seen[r][c]) return false;
    if (g[r][c] == 'E') return true;
    seen[r][c] = true;
    for (int k = 0; k < 4; ++k)
        if (reachDfs(g, r + DR[k], c + DC[k], seen)) return true;
    return false;
}
bool mazeReachableDfs(const vector<string>& g) {
    vector<vector<bool>> seen(g.size(), vector<bool>(g[0].size(), false));
    for (int r = 0; r < (int)g.size(); ++r)
        for (int c = 0; c < (int)g[0].size(); ++c)
            if (g[r][c] == 'S') return reachDfs(g, r, c, seen);
    return false;
}
def reach_dfs(g, r, c, seen):
    R, C = len(g), len(g[0])
    if r < 0 or r >= R or c < 0 or c >= C: return False
    if g[r][c] == '#' or seen[r][c]: return False
    if g[r][c] == 'E': return True
    seen[r][c] = True
    for k in range(4):
        if reach_dfs(g, r + DR[k], c + DC[k], seen): return True
    return False
def maze_reachable_dfs(g):
    seen = [[False] * len(g[0]) for _ in range(len(g))]
    for r in range(len(g)):
        for c in range(len(g[0])):
            if g[r][c] == 'S': return reach_dfs(g, r, c, seen)
    return False

逐行说明：函数的含义是从 (r, c) 出发能否到达 E；出界、是墙、已访问时都返回 false；当前格子就是 E 时返回 true；否则标记当前格子后尝试四个方向，任何一个方向能到达就立即返回 true。6.10 的迷宫返回 true，被墙围住的迷宫返回 false。与例题的区别： 容器从队列换成了递归，答案从 int 类型的步数换成了 bool；它能判断是否可达，但第一次找到的路径不一定最短。

练习 6.11-1【基础】数轴上的快递员：最少几步

题面：快递员在数轴上的整数点 a，要到点 b（0 ≤ a, b ≤ 10⁵）。每一步可以从 x 走到 x − 1、x + 1 或 2x，不能走到负数。写 int minStepsLine(int a, int b)，返回最少步数。

样例：(3, 11) → 3（3→6→12→11）；(2, 9) → 3（2→4→8→9）；(10, 3) → 7（只能一步步往回走）；(6, 6) → 0；(0, 1) → 1。

提示

题目没有给图，但"每一步代价相同、问最少步数"就是 BFS 的信号。把每个整数点当节点，三种走法就是从 x 出发的三条边，邻居现算，和网格题用方向数组现算邻居一样。要给数轴设一个上界，否则 2x 会无限往外扩：超过 2 × max(a, b) 之后再回来一定不划算，所以上界取 2 × max(a, b) + 2 就够了（practice 用更大的上界做了对拍）。dist 数组同时充当 visited。

参考答案
int minStepsLine(int a, int b) {
    int LIMIT = 2 * max(a, b) + 2;                 // 数轴的上界：再往外走一定不划算
    vector<int> dist(LIMIT + 1, -1);
    queue<int> q;
    dist[a] = 0;
    q.push(a);
    while (!q.empty()) {
        int x = q.front();
        q.pop();
        if (x == b) return dist[x];
        int nxt[3] = {x - 1, x + 1, x * 2};        // 三种走法 = 三条边，邻居现算
        for (int y : nxt) {
            if (y < 0 || y > LIMIT || dist[y] != -1) continue;   // 出界或来过
            dist[y] = dist[x] + 1;
            q.push(y);
        }
    }
    return -1;
}
def min_steps_line(a, b):
    LIMIT = 2 * max(a, b) + 2                      # 数轴的上界：再往外走一定不划算
    dist = [-1] * (LIMIT + 1)
    q = deque()
    dist[a] = 0
    q.append(a)
    while q:
        x = q.popleft()
        if x == b: return dist[x]
        for y in (x - 1, x + 1, x * 2):            # 三种走法 = 三条边，邻居现算
            if y < 0 or y > LIMIT or dist[y] != -1: continue     # 出界或来过
            dist[y] = dist[x] + 1
            q.append(y)
    return -1

练习 6.11-2【变形】迷宫里一共有几条不同的路线

题面：小迷宫（R × C ≤ 16），S 起点、E 终点、'#' 墙、'.' 空地。一条路线从 S 出发，每步上下左右走一格，同一条路线里每个格子最多经过一次，最后到达 E。写 int countSimplePaths(const vector<string>& g)，返回不同路线的条数。

样例：{"S.", ".E"} → 2；{"S..", "...", "..E"} → 12；{"S#E"} → 0；{"SE"} → 1。

提示

要"所有路线"，选 DFS。和本节练一练 reachDfs 的区别在于标记的含义：reachDfs 里 seen 表示"这个格子来过"，永远不清除，因为只问能不能到；这里标记表示"这个格子在当前这条路线上"，离开时必须撤销（和 6.7 的 path.pop_back() 一样），否则别的路线就不能再经过它。到达 E 就计数并返回。路线数随网格大小指数增长，所以只能用在很小的网格上。

参考答案
void pathsDfs(const vector<string>& g, int r, int c, vector<vector<bool>>& onPath, int& cnt) {
    int R = (int)g.size(), C = (int)g[0].size();
    if (r < 0 || r >= R || c < 0 || c >= C) return;
    if (g[r][c] == '#' || onPath[r][c]) return;
    if (g[r][c] == 'E') { cnt++; return; }       // 到终点：找到一条完整路线
    onPath[r][c] = true;                         // 做选择：这格在当前路线上
    for (int k = 0; k < 4; ++k) pathsDfs(g, r + DR[k], c + DC[k], onPath, cnt);
    onPath[r][c] = false;                        // 撤销：别的路线还可以经过这格
}
int countSimplePaths(const vector<string>& g) {
    vector<vector<bool>> onPath(g.size(), vector<bool>(g[0].size(), false));
    int cnt = 0;
    for (int r = 0; r < (int)g.size(); ++r)
        for (int c = 0; c < (int)g[0].size(); ++c)
            if (g[r][c] == 'S') pathsDfs(g, r, c, onPath, cnt);
    return cnt;
}
def paths_dfs(g, r, c, on_path, cnt):            # cnt = [0]，对应 int&
    R, C = len(g), len(g[0])
    if r < 0 or r >= R or c < 0 or c >= C: return
    if g[r][c] == '#' or on_path[r][c]: return
    if g[r][c] == 'E': cnt[0] += 1; return       # 到终点：找到一条完整路线
    on_path[r][c] = True                         # 做选择：这格在当前路线上
    for k in range(4): paths_dfs(g, r + DR[k], c + DC[k], on_path, cnt)
    on_path[r][c] = False                        # 撤销：别的路线还可以经过这格
def count_simple_paths(g):
    on_path = [[False] * len(g[0]) for _ in range(len(g))]
    cnt = [0]
    for r in range(len(g)):
        for c in range(len(g[0])):
            if g[r][c] == 'S': paths_dfs(g, r, c, on_path, cnt)
    return cnt[0]

练习 6.11-3【综合】两个小组能不能分开：二分图判定

题面：n 个人（编号 1..n），边 (u, v) 表示 u 和 v 互相讨厌、不能分在同一组。问能否把所有人分成两组，使每条边的两头都在不同组。写 bool isBipartite(const vector<vector<int>>& adj)。图无自环、无重复边，可能不连通。n ≤ 10⁵。

样例：n = 4，边 (1,2) (2,3) (3,4) (4,1) → true（{1,3} 和 {2,4}）；n = 3，边 (1,2) (2,3) (3,1) → false；n = 5，边 (1,2) (3,4) (4,5) (5,3) → false（三角形在不含 1 的那一块）；n = 3，没有边 → true。

提示

用两种颜色给点染色：起点染 0，它的邻居必须染 1，邻居的邻居染 0……一旦发现一条边两头颜色相同，就分不开。这属于"走遍整张图"，DFS、BFS 都行，这里用 BFS。color 数组同时充当 visited：−1 表示还没染。和 6.9 判环一样，要在外层扫描每个点，每个没染色的点开启一次新的 BFS，否则会漏掉其他连通块。practice 对 n ≤ 8 的随机图枚举全部 2ⁿ 种分组做暴力对拍。相近题型：LeetCode 785。

参考答案
bool isBipartite(const vector<vector<int>>& adj) {
    int n = (int)adj.size() - 1;
    vector<int> color(n + 1, -1);                // -1 没染色，0 / 1 两种颜色；同时充当 visited
    for (int s = 1; s <= n; ++s) {
        if (color[s] != -1) continue;            // 每个连通块单独起一次 BFS
        color[s] = 0;
        queue<int> q;
        q.push(s);
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            for (int v : adj[u]) {
                if (color[v] == -1) { color[v] = 1 - color[u]; q.push(v); }   // 邻居染相反的颜色
                else if (color[v] == color[u]) return false;                  // 一条边两头同色：分不开
            }
        }
    }
    return true;
}
def is_bipartite(adj):
    n = len(adj) - 1
    color = [-1] * (n + 1)                       # -1 没染色，0 / 1 两种颜色；同时充当 visited
    for s in range(1, n + 1):
        if color[s] != -1: continue              # 每个连通块单独起一次 BFS
        color[s] = 0
        q = deque()
        q.append(s)
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1: color[v] = 1 - color[u]; q.append(v)   # 邻居染相反的颜色
                elif color[v] == color[u]: return False                   # 一条边两头同色：分不开
    return True

易错点

  • 用 DFS 求最少步数，然后在所有路径里取最小：结果对，但要枚举所有路径，网格稍大就超时。
  • 用 BFS 输出所有路径：BFS 每个点只访问一次，天然只保留一条路。
  • 以为 BFS 一定比 DFS 快：走遍整张图时两者都是 O(n + m)，差别只在顺序。

小结： 需要路径或具体方案时用 DFS；需要最少步数时用 BFS；只问能否到达或有几块时，两者都可以。
