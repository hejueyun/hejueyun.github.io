2.8 map、set、multiset：有序容器的全部配套函数 选读

// 示例：map 的 []、insert、count，multiset 的两种 erase，set 的 lower_bound、prev、rbegin。
// 没有参数、没有返回值；先按键打印 m 的每一项，再打印各个变量的值。
void demoMapSet() {
    map<string, int> m;                   // m[名字] = 数值，按键有序
    m["b"] = 2;                           // 插入或覆盖
    m.insert({"a", 1});                   // a 不存在：插入
    m.insert({"a", 100});                 // a 已存在：insert 不覆盖
    int z = m["z"];                       // 读一个不存在的键：插入 z→0
    bool hasY = m.count("y");             // hasY = 键 "y" 是否存在：0，count 不插入
    multiset<int> ms{5, 1, 5, 3, 5};      // 允许重复的有序集合
    ms.erase(ms.find(5));                 // 只删一个 5
    int fives = ms.count(5);              // fives = 剩下的 5 的个数：2
    ms.erase(5);                          // 删掉所有 5
    set<int> st{10, 20, 30};              // st = 有序集合
    auto it = st.lower_bound(15);         // it = 第一个 >= 15 的元素：指向 20
    int before = *prev(it);               // before = it 的前一个元素：10
    int largest = *st.rbegin();           // largest = 最大元素：30
    for (auto& [k, v] : m) cout << k << v << " ";   // k = 键，v = 值；按键从小到大遍历
    cout << z << " " << hasY << " " << fives << " " << ms.size() << " " << *it << " " << before << " " << largest << "\n";
}

练习 2.8-4【函数】分数线查等级 选做

题面：cut 是一张 map，键是分数线，值是这条线对应的等级，例如 {{0, "F"}, {60, "D"}, {70, "C"}, {80, "B"}, {90, "A"}} 表示 0 分起是 F、60 分起是 D、70 分起是 C……分数 s 大于或等于某条分数线，就算达到了这条线。返回 s 达到的分数线中最高的那条对应的等级，也就是最后一个"分数线 ≤ s"的等级；s 比最低的分数线还低时返回 "?"。

样例 1：s = 85，答案 "B"。85 达到了 0、60、70、80 四条线，其中最高的是 80，对应 B。

样例 2：s = 60，答案 "D"。60 正好等于分数线 60，也算达到。

样例 3：s = 100，答案 "A"。五条线都达到了，最高的 90 对应 A。

样例 4：s = -1，答案 "?"。比最低的分数线 0 还低。

提示

"最后一个 ≤ s"＝upper_bound(s) 的前一个。如果 upper_bound(s) 已经是 begin()，说明没有 ≤ s 的键。

参考答案
// cut[分数线] = 等级（只读），s = 分数。返回最后一个"分数线 <= s"对应的等级；s 比最低分数线还低时返回 "?"。
string gradeOf(const map<int, string>& cut, int s) {
    auto it = cut.upper_bound(s);        // 第一个分数线 > s 的项
    if (it == cut.begin()) return "?";   // 所有分数线都 > s：比最低分数线还低
    return prev(it)->second;             // 前一个就是最后一个 <= s 的分数线，取它的等级
}
# cut[分数线] = 等级，s = 分数。返回最后一个"分数线 <= s"对应的等级；s 比最低分数线还低时返回 "?"。
def grade_of(cut, s):
    keys = sorted(cut)                   # keys = 升序的分数线；dict 不保证按键有序，先取出有序的键
    i = bisect.bisect_right(keys, s)     # i = 插入位置，keys[:i] 都 <= s
    if i == 0:                           # 没有 <= s 的分数线
        return "?"
    return cut[keys[i - 1]]              # 最后一个 <= s 的分数线对应的等级

vector<string> uniqueByLenThenDict(const vector<string>& words) {
    // cmp(a, b)：a 应排在 b 前面时返回 true
    auto cmp = [](const string& a, const string& b) {
        return a.size() != b.size() ? a.size() < b.size() : a < b;   // 先比长度，长度相同再比内容

struct PairHash {
    size_t operator()(const pair<int, int>& p) const {   // unordered_map 对每个键调用它得到哈希值
        // first 放高 32 位、second 放低 32 位拼成一个 64 位数，再用标准库对整数的哈希
        return hash<unsigned long long>()(((unsigned long long)(unsigned)p.first << 32) | (unsigned)p.second);

};
unordered_map<pair<int, int>, int, PairHash> seen;   // seen[(r, c)] = 整数值；第三个模板参数传入自定义哈希

返回语句把两个 int 拼成一个 64 位整数，再借用标准库对整数的哈希：first 转成 64 位后左移 32 位，占据高 32 位；second 占据低 32 位，两者用 | 合在一起。左移之前必须先转成 64 位的 unsigned long long，32 位的数左移 32 位是未定义行为。

每个 int 都先转成 32 位的 unsigned，是为了让负数也能正确拼接。例如 second = −1：直接转成 64 位，得到的 64 位全是 1，| 之后会把 first 所在的高 32 位全部盖掉；先转成 unsigned，得到 4294967295，只占低 32 位。

// 给 pair<int, int> 用的哈希函数对象：本身不存数据，调用 PairHash()(p) 返回键 p 的哈希值（size_t）。
struct PairHash {
    size_t operator()(const pair<int, int>& p) const {   // 对每个键算哈希值
        // first 放高 32 位、second 放低 32 位拼成 64 位数，再交给标准库对整数的哈希
        return hash<unsigned long long>()(((unsigned long long)(unsigned)p.first << 32) | (unsigned)p.second);
    }
};
// edges = 无向边 (u, v) 的列表（只读），(u, v) 和 (v, u) 算同一条边。返回同一条边出现的最多次数；没有边时返回 0。
int maxEdgeMultiplicity(const vector<pair<int, int>>& edges) {
    unordered_map<pair<int, int>, int, PairHash> cnt;   // cnt[(小端点, 大端点)] = 这条边出现的次数；PairHash 见上
    int best = 0;                                        // 没有边时答案是 0
    // 小端点放前面统一方向，(u,v) 和 (v,u) 成为同一个键；++ 后的次数和 best 比较
    for (auto [u, v] : edges) best = max(best, ++cnt[{min(u, v), max(u, v)}]);   // u、v = 边的两个端点
    return best;                                         // 出现最多的边的次数
}
# edges = 无向边 (u, v) 的列表，(u, v) 和 (v, u) 算同一条边。返回同一条边出现的最多次数；没有边时返回 0。
def max_edge_multiplicity(edges):
    cnt = Counter((min(u, v), max(u, v)) for u, v in edges)   # 小端点放前面统一方向，再计数
    return max(cnt.values(), default=0)                      # 没有边时返回 0

练习 2.9-5【函数】第一个只出现一次的字符 必做

题面：返回字符串 s 中第一个只出现一次的字符的下标（下标从 0 开始）；没有只出现一次的字符时返回 −1。

样例 1："leetcode"，答案 0。下标 0 的 l 在整个串里只出现一次。

样例 2："loveleetcode"，答案 2。l 和 o 都出现了两次，下标 2 的 v 是第一个只出现一次的字符。

样例 3："aabb"，答案 −1。a 和 b 都出现两次。

提示

两遍扫描：第一遍计数，第二遍按原顺序找第一个计数为 1 的字符。"第一个"由原字符串的顺序决定，与哈希表的遍历顺序无关。

参考答案
// s = 任意字符串（只读）。返回第一个只出现一次的字符的下标；不存在时返回 -1。
int firstUniqueIndex(const string& s) {
    unordered_map<char, int> cnt;                    // cnt[字符] = 出现次数
    for (char c : s) ++cnt[c];                       // 第一遍：计数，c = s 的每个字符
    for (int i = 0; i < (int)s.size(); ++i)          // 第二遍：按原顺序找，i = 当前下标
        if (cnt[s[i]] == 1) return i;                // 第一个只出现一次的字符
    return -1;                                       // 不存在
}
# s = 任意字符串。返回第一个只出现一次的字符的下标；不存在时返回 -1。
def first_unique_index(s):
    cnt = Counter(s)                     # 第一遍：计数，cnt[字符] = 出现次数
    for i, c in enumerate(s):            # 第二遍：按原顺序找，i = 下标，c = 字符
        if cnt[c] == 1:                  # 第一个只出现一次的字符
            return i
    return -1                            # 不存在

易错点

  • 题目要求"按某种顺序输出"时，直接遍历 unordered_map 的结果顺序不确定；先拷出来 sort，或者改用 map。
  • 用 if (m[x]) 判断存在会插入 x；在遍历这个表的循环里这样写还会让迭代器失效。
  • pair、vector 作键时 unordered 容器编译报错；编码成 long long、写自定义哈希，或者改用有序的 map/set。

小结： unordered_map 的接口与 map 相同，但无序，操作平均 O(1)；查询用 count 或 find；需要有序输出时先排序；用 pair 作键时，编码成 r * 大数 + c 或改用 map。

为什么比较器要"反着写"。 比较器在 sort 和 priority_queue 中的含义相同：cmp(a, b) 为 true 表示"a 小于 b"。两者的区别在于怎样用这个"小于"：sort 把小的排在前面，堆却把最大的元素放在堆顶、最先弹出。所以同一个比较器下，sort 排在最后的元素，正是最先出堆的元素（详细对照见 1.10）。

例如三个任务的 cost 是 3、1、9，比较器写 return a.cost > b.cost;。按这个比较器，cost 越大越"小"：sort 排出来是 9、3、1；把它们放进用这个比较器的堆，出堆顺序正好倒过来，是 1、3、9，cost 小的先出。

所以写堆的 lambda 时，把 cmp(a, b) 为 true 读成 "a 比 b 更晚出堆"。想要 cost 小的先出，就让 cost 大的更晚出，写 return a.cost > b.cost;。

什么时候写 push，什么时候写 push_back

  • set、map 和它们的 unordered 版本没有头尾，元素放在哪里由值决定，所以用 insert、erase；map 也可以直接写 m[k] = v。

题面：每个任务是 {名字, 花费}。用 priority_queue 决定处理顺序：花费小的先处理，花费相同时名字字典序小的先处理；返回按处理顺序排列的名字。下面的代码却先处理了花费最大的任务。

题面：返回 v 中最小的 k 个数，按从小到大排列（0 ≤ k ≤ n）。要求用一个元素个数不超过 k 的大根堆（堆顶是堆中最大值的堆）。

提示

堆里保存"目前最小的 k 个"，堆顶是其中最大的。新数入堆后如果超过 k 个，弹出堆顶。最后依次弹出得到降序，再反转。

// v = 整数数组（只读），k = 要取的个数（0 <= k <= n）。返回 v 中最小的 k 个数，升序排列。
vector<int> smallestK(const vector<int>& v, int k) {
    priority_queue<int> pq;              // 大根堆，存目前最小的 k 个，堆顶是其中最大的
    for (int x : v) {                    // x = 当前要考虑的数
        pq.push(x);                      // 先放进去
        if ((int)pq.size() > k) pq.pop();   // 超过 k 个就弹出最大的
    }
    vector<int> out;                     // out = 结果数组
    while (!pq.empty()) { out.push_back(pq.top()); pq.pop(); }   // 依次弹出得到降序
    reverse(out.begin(), out.end());     // 反转成升序
    return out;                          // 最小的 k 个数，升序
}

    for x in v:                              # x = 当前要考虑的数
        heapq.heappush(h, -x)                # 放进去
        if len(h) > k:                       # 超过 k 个
            heapq.heappop(h)                 # 弹出最大的（相反数最小）
    out = []                                 # out = 结果列表
    while h:                                 # 堆不空就继续弹
        out.append(-heapq.heappop(h))        # 依次弹出得到降序，取负还原
    out.reverse()                            # 反转成升序
    return out                               # 最小的 k 个数，升序

练习 2.10-5【函数】合并 k 个有序数组 选做

题面：给若干个数组，每个都已从小到大排好（有的可以是空数组）。把它们的全部元素合并成一个从小到大的数组。

样例 1：{{1, 4, 7}, {2, 5}, {}, {0, 9}}，答案 {0, 1, 2, 4, 5, 7, 9}。全部元素是 1、4、7、2、5、0、9，从小到大排列。

样例 2：{{1, 3}, {1}}，答案 {1, 1, 3}。两个数组里的 1 都保留。

提示

小根堆里放 {值, 第几个数组, 数组内下标} 三元组。弹出最小的，再把同一数组的下一个元素放进去。tuple 自带字典序比较，所以 greater<T> 直接可用。

参考答案
// arrs = 若干个升序数组（只读，可能有空数组）。返回把它们合并成的一个升序数组；全为空时返回空数组。
vector<int> mergeSortedArrays(const vector<vector<int>>& arrs) {
    using T = tuple<int, int, int>;                  // {值, 第几个数组, 数组内下标}
    priority_queue<T, vector<T>, greater<T>> pq;     // 小根堆，tuple 按值优先比较
    for (int i = 0; i < (int)arrs.size(); ++i)       // 每个非空数组先放进第一个元素
        if (!arrs[i].empty()) pq.emplace(arrs[i][0], i, 0);
    vector<int> out;                                 // 合并结果
    while (!pq.empty()) {                            // 还有没取出的元素
        auto [val, i, j] = pq.top();                 // 当前所有候选里最小的：值 val，来自第 i 个数组的下标 j
        pq.pop();
        out.push_back(val);                          // 放进结果
        if (j + 1 < (int)arrs[i].size()) pq.emplace(arrs[i][j + 1], i, j + 1);   // 同一数组还有下一个就补进堆
    }
    return out;                                      // 合并后的升序数组
}

def merge_sorted_arrays(arrs):
    h = [(a[0], i, 0) for i, a in enumerate(arrs) if a]   # (值, 第几个数组, 数组内下标)，跳过空数组
    heapq.heapify(h)                     # 建小根堆

    while h:                             # 还有没取出的元素

        out.append(val)                  # 放进结果

            heapq.heappush(h, (arrs[i][j + 1], i, j + 1))
    return out                           # 合并后的升序列表

练习 2.10-6【函数】滑动窗口最大值（单调 deque） 选做

题面：给数组 v 和整数 k（1 ≤ k ≤ n）。v 中连续的 k 个元素叫一个"窗口"。窗口先盖住最左边的 k 个元素，然后每次向右滑动一格，直到盖住最右边的 k 个元素，共有 n − k + 1 个窗口。按从左到右的顺序返回每个窗口中的最大值。

样例 1：{1, 3, -1, -3, 5, 3, 6, 7}，k = 3，答案 {3, 3, 5, 5, 6, 7}。六个窗口依次是 {1, 3, −1}、{3, −1, −3}、{−1, −3, 5}、{−3, 5, 3}、{5, 3, 6}、{3, 6, 7}，各自的最大值是 3、3、5、5、6、7。

样例 2：{2, 2, 2}，k = 2，答案 {2, 2}。两个窗口都是 {2, 2}。

提示

deque 里存下标，对应的值从队头到队尾递减。新元素进来前，从队尾弹掉所有不大于它的；队头下标滑出窗口时从队头弹出。窗口形成后队头就是最大值。

参考答案
// v = 整数数组（只读），k = 窗口长度（1 <= k <= n）。返回每个长度为 k 的连续窗口的最大值，按窗口从左到右排列。
vector<int> windowMaxDeque(const vector<int>& v, int k) {
    deque<int> dq;                                   // 存下标，对应的值递减
    vector<int> out;                                 // 每个窗口的最大值
    for (int i = 0; i < (int)v.size(); ++i) {        // i 是新进入窗口的下标
        while (!dq.empty() && v[dq.back()] <= v[i]) dq.pop_back();   // 队尾不大于 v[i] 的不可能再当最大值
        dq.push_back(i);                             // 新下标从队尾进入
        if (dq.front() <= i - k) dq.pop_front();     // 窗口是 [i-k+1, i]，队头下标 <= i-k 已滑出
        if (i >= k - 1) out.push_back(v[dq.front()]);   // 窗口凑满 k 个后，队头就是最大值
    }
    return out;                                      // 共 n-k+1 个最大值
}
# v = 整数列表，k = 窗口长度（1 <= k <= n）。返回每个长度为 k 的连续窗口的最大值，按窗口从左到右排列。
def window_max_deque(v, k):
    dq = deque()                         # 存下标，对应的值递减
    out = []                             # 每个窗口的最大值
    for i in range(len(v)):              # i 是新进入窗口的下标
        while dq and v[dq[-1]] <= v[i]:  # 队尾不大于 v[i] 的不可能再当最大值
            dq.pop()
        dq.append(i)                     # 新下标从队尾进入
        if dq[0] <= i - k:               # 窗口是 [i-k+1, i]，队头下标 <= i-k 已滑出
            dq.popleft()
        if i >= k - 1:                   # 窗口凑满 k 个后，队头就是最大值
            out.append(v[dq[0]])
    return out                           # 共 n-k+1 个最大值

多选 · 理解检查 4　想让 priority_queue 里 dist 最小的元素先出堆，下面哪些写法正确？

A. priority_queue<pair<int,int>, vector<pair<int,int>>, greater<pair<int,int>>>，元素放 {dist, node}

B. priority_queue<pair<int,int>>，元素放 {-dist, node}

C. lambda 比较器写 return a.dist < b.dist;

D. lambda 比较器写 return a.dist > b.dist;

查看答案与每个选项的解析

A · 正确：greater 得到小根堆，pair 先比 first，即 dist。

B · 正确：大根堆里 -dist 最大的就是 dist 最小的，取出后再取负。

C · 错误：这样 dist 大的被认为优先级高，得到的是 dist 最大先出。

D · 正确：cmp(a,b) 为 true 表示 a 更晚出堆：dist 大的更晚出，于是小的先出。

易错点

  • pop() 不返回值：int x = pq.pop(); 编译失败，先 top() 再 pop()。
  • 比较器方向：priority_queue 的 cmp 与 sort 的 cmp 写法相同，效果相反——sort 里 a < b 得到升序，堆里 a < b 得到大根堆。
  • 适配器不能遍历、没有 clear()；需要遍历就改用 deque 或 vector。

小结： 栈的 top、队列的 front 读取元素，pop 不返回值；堆默认是大根堆，加 greater 是小根堆；自定义比较器返回 true 表示 a 更晚出堆，所以想让小的先出就写 >。

易错点

  • end() 和 rend() 都不指向元素，解引用是未定义行为；find 的结果先和 end() 比较再用。
  • 遍历中删除：用 it = c.erase(it) 接住下一个位置；for 的第三段留空。
  • vector 的 push_back 可能扩容，让之前拿到的所有迭代器、引用、指针失效；map/set/list 插入不会。

小结： next 和 prev 返回新的迭代器，advance 原地修改迭代器；distance 计算两个迭代器之间的距离；遍历中删除元素要写 it = erase(it)，不删除时才 ++it；vector 扩容后，原来的迭代器全部失效。
