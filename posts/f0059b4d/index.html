7.5 层序遍历：用队列逐层向外扩展 必读

有些题目关心节点在第几层，例如每层的最大值、第 k 层有几个节点、离根最近的叶子。DFS 一直向下走到底，不同层的节点交错着被访问；这类题目需要另一种顺序：先把第 1 层全部处理完，再处理第 2 层。

队列使先发现的节点先处理

BFS（Breadth-First Search，广度优先搜索）使用一个队列：处理一个节点时，把它的孩子排到队尾。同一层的节点都是由上一层的节点按顺序放入的，所以它们在队列中相邻，并且排在下一层的节点之前。

每一轮循环固定做四件事：读取队首（front），删除队首（pop），处理这个节点，把它的孩子入队（push）。

// 层序遍历（BFS）：root 是树根（TreeNode*，可以是 nullptr）；返回按层、每层从左到右的节点值；空树返回空数组
vector<int> bfsOrder(TreeNode* root) {
    vector<int> out;                   // 按出队顺序记下的值
    if (root == nullptr) return out;   // 空树：返回空数组，也避免把 nullptr 入队
    queue<TreeNode*> q;                // 等着处理的节点
    q.push(root);                      // 从根开始
    while (!q.empty()) {               // 队列里还有没处理的节点
        TreeNode* cur = q.front();     // 1. 看队首
        q.pop();                       // 2. 删掉队首
        out.push_back(cur->val);       // 3. 处理它
        if (cur->left) q.push(cur->left);     // 4. 孩子排到队尾
        if (cur->right) q.push(cur->right);
    }
    return out;                        // 一层一层、每层从左到右
}
from collections import deque

# 层序遍历（BFS）：root 是树根（TreeNode，可以是 None）；返回按层、每层从左到右的节点值；空树返回空列表
def bfs_order(root):
    out = []                            # 按出队顺序记下的值
    if root is None: return out         # 空树：返回空列表，也避免把 None 入队
    q = deque()                         # 等着处理的节点
    q.append(root)                      # 从根开始
    while q:                            # 队列里还有没处理的节点
        cur = q.popleft()               # 1+2. 看队首并删掉：popleft() 会把它返回
        out.append(cur.val)             # 3. 处理它
        if cur.left: q.append(cur.left)     # 4. 孩子排到队尾
        if cur.right: q.append(cur.right)
    return out                          # 一层一层、每层从左到右

逐行说明：第 4 行处理空树，否则第 6 行会把 nullptr 入队，第 10 行的 cur->val 就会崩溃；第 8–9 行先 front 再 pop，因为 pop() 不返回被删除的元素；第 11–12 行的 if (cur->left) 等价于 if (cur->left != nullptr)，只让真实节点入队。

按层分组：每轮开始时记下 sz

要输出 [[1],[2,3],[4,5,6]] 这样的分层结果，就要知道每一层有几个节点。方法是：每轮开始时，队列中恰好是完整的一层；先把 q.size() 存入 sz，然后只出队 sz 个节点。这 sz 个节点放入的孩子都排在它们之后，属于下一层。

// 按层分组：root 是树根（TreeNode*，可以是 nullptr）；返回二维数组，第 d 个元素是第 d+1 层从左到右的值；
// 空树返回空数组
vector<vector<int>> levelGroups(TreeNode* root) {
    vector<vector<int>> res;           // res[d] = 第 d+1 层的值
    if (root == nullptr) return res;   // 空树：没有任何层
    queue<TreeNode*> q;                // q = 等着处理的节点；每轮开始时恰好是完整的一层
    q.push(root);                      // 第 1 层只有根
    while (!q.empty()) {               // 每一轮处理完整的一层
        int sz = (int)q.size();        // sz = 这一层有几个节点，先记下来
        vector<int> level;             // level = 这一层的值
        for (int i = 0; i < sz; ++i) { // i = 本层第几个出队；只出队 sz 个：正好是这一层
            TreeNode* cur = q.front(); // cur = 本次出队的节点
            q.pop();
            level.push_back(cur->val); // 记下它的值
            if (cur->left) q.push(cur->left);     // 孩子属于下一层，排在这一层后面
            if (cur->right) q.push(cur->right);
        }
        res.push_back(level);          // 这一层收齐了
    }
    return res;                        // 例如 [[1],[2,3],[4,5,6]]
}
# 按层分组：root 是树根（TreeNode，可以是 None）；返回列表，第 d 个元素是第 d+1 层从左到右的值；
# 空树返回空列表
def level_groups(root):
    res = []                            # res[d] = 第 d+1 层的值
    if root is None: return res         # 空树：没有任何层
    q = deque()                         # q = 等着处理的节点；每轮开始时恰好是完整的一层
    q.append(root)                      # 第 1 层只有根
    while q:                            # 每一轮处理完整的一层
        sz = len(q)                     # sz = 这一层有几个节点，先记下来
        level = []                      # level = 这一层的值
        for i in range(sz):             # 写成 range(len(q)) 也对：range 在开头就算好了次数
            cur = q.popleft()           # cur = 本次出队的节点
            level.append(cur.val)       # 记下它的值
            if cur.left: q.append(cur.left)     # 孩子属于下一层，排在这一层后面
            if cur.right: q.append(cur.right)
        res.append(level)               # 这一层收齐了
    return res                          # 例如 [[1],[2,3],[4,5,6]]

为什么要先把 sz 存起来？ 如果写成 for (int i = 0; i < (int)q.size(); ++i)，循环中一边出队一边入队，q.size() 在不断变化。第 2 轮开始时队列是 [2,3]：i=0 时出队 2、入队 4，size 仍为 2；i=1 时出队 3、入队 5 和 6，size 变成 3，条件 2 < 3 成立，于是第 3 层的 4 也被算进了第 2 层。实际输出会变成 [[1],[2,3,4],[5,6]]。

要点

  1. BFS 使用队列，DFS 使用栈（递归时使用的是系统的调用栈）。
  2. 队列先进先出，所以节点按层出队，每层内部从左到右。
  3. 按层分组时，每轮先记下 sz = q.size()，再出队 sz 个节点。
  4. 每个节点入队、出队各一次，时间 O(n)；队列中最多同时存放一层，空间等于最宽一层的节点数。

练一练 1：第 k 层有几个节点 必做

题面：写 int countLevelK(TreeNode* root, int k)。根在第 1 层，根的孩子在第 2 层，依此类推。返回第 k 层上一共有几个节点；树没有第 k 层时（包括空树）返回 0。

样例 1：树 [1, 2, 3, 4, null, 5, 6]（1 的孩子是 2、3；2 只有左孩子 4；3 的孩子是 5、6），k = 3，返回 3。第 3 层是 4、5、6。同一棵树 k = 1 返回 1，k = 2 返回 2。

样例 2：同一棵树，k = 4，返回 0。树只有 3 层，第 4 层上没有节点。

提示

每轮开始时的 sz 就是这一层的节点数，数到第 k 轮时直接返回 sz。

参考答案
// 第 k 层的节点数：root 是树根（可以是 nullptr），k 是层号（根在第 1 层）；树没有第 k 层或 k < 1 时返回 0
int countLevelK(TreeNode* root, int k) {
    if (root == nullptr || k < 1) return 0;   // 空树或 k 不合法：0 个
    queue<TreeNode*> q;                // q = 等着处理的节点；每轮开始时恰好是完整的一层
    q.push(root);                      // 第 1 层只有根
    int depth = 1;                     // 队列里此刻是第几层；一开始是第 1 层
    while (!q.empty()) {               // 每一轮处理一层
        int sz = (int)q.size();        // 这一层的节点数
        if (depth == k) return sz;     // 队列里正好是第 k 层
        for (int i = 0; i < sz; ++i) { // 把这一层全部出队，换成下一层
            TreeNode* cur = q.front(); // cur = 本次出队的节点
            q.pop();
            if (cur->left) q.push(cur->left);     // 孩子进下一层
            if (cur->right) q.push(cur->right);
        }
        ++depth;                       // 队列里换成了下一层
    }
    return 0;                          // 树没有这么多层
}

def count_level_k(root, k):
    if root is None or k < 1: return 0  # 空树或 k 不合法：0 个
    q = deque()                         # q = 等着处理的节点；每轮开始时恰好是完整的一层

    depth = 1                           # 队列里此刻是第几层；一开始是第 1 层

        sz = len(q)                     # 这一层的节点数
        if depth == k: return sz        # 队列里正好是第 k 层
        for i in range(sz):             # 把这一层全部出队，换成下一层

            if cur.right: q.append(cur.right)
        depth += 1                      # 队列里换成了下一层

样例 2：树 [1, 2, 3, 4, null, 6]，返回 false。第 3 层 4 之后是一个空位，空位后面又出现了 6，中间有洞。

样例 3：树 [1, null, 2]，返回 false。1 的左边空着，右边却有 2。

样例 4：树 [1, 2]，返回 true。2 紧挨着 1 坐，后面全是空位。

样例 5：空树 []，返回 true。

提示

和 toLevelArray 一样，空孩子也入队，这样队列的出队顺序就是"含空位的层序"。用一个 bool 记"是否已经见过空位"：见到空位就置 true；之后只要再出队一个真实节点，就说明中间有洞，返回 false。边界：空树时队列里只有一个 nullptr，循环结束返回 true。练习文件 practice/ch34_drill.cpp 用另一种思路对拍：给节点按 1、2、3… 的堆编号（左孩子 2i，右孩子 2i+1），完全二叉树当且仅当最大编号等于节点数。相近题型：LeetCode 958。

// 完全二叉树判定：root 是树根（可以是 nullptr）；按层序看，所有真实节点都排在第一个空位之前就返回 true；
// 空树返回 true
bool isCompleteTree(TreeNode* root) {
    queue<TreeNode*> q;                 // 含空位的层序：空指针也排队
    q.push(root);                       // 空树时入队的是 nullptr，下面会直接得到 true
    bool seenNull = false;              // 是否已经见过空位
    while (!q.empty()) {                // 按层序逐个位置检查
        TreeNode* cur = q.front();      // cur = 本次出队的位置（可能是空指针）
        q.pop();
        if (cur == nullptr) { seenNull = true; continue; }   // 遇到空位：记下来，它没有孩子
        if (seenNull) return false;     // 空位后面又出现真实节点：中间有洞
        q.push(cur->left);              // 和 toLevelArray 一样，空孩子也入队
        q.push(cur->right);
    }
    return true;                        // 所有真实节点都在第一个空位之前
}

    while q:                            # 按层序逐个位置检查
        cur = q.popleft()               # cur = 本次出队的位置（可能是 None）
        if cur is None: seen_null = True; continue   # 遇到空位：记下来，它没有孩子
        if seen_null: return False      # 空位后面又出现真实节点：中间有洞
        q.append(cur.left)              # 和 toLevelArray 一样，空孩子也入队
        q.append(cur.right)
    return True                         # 所有真实节点都在第一个空位之前

易错点

  • 用 q.size() 直接当 for 的循环条件，层与层会混在一起。
  • 以为 q.pop() 会返回队首；要先 front() 读出来再 pop()。
  • 把 nullptr 入队后又直接访问 ->val：要么入队前判空，要么出队后判空，二选一。

小结： BFS 使用队列：取出队首、弹出、处理、把孩子入队；需要分层时，在每一轮开始时记下当前队列的长度 sz。

7.6 树上递归的两种写法：遍历型与分解型 必读

面试中的树题形式多样：节点个数、高度、叶子数、节点值之和、最大值、是否存在某个值……它们都可以用同一个思路写出来，而且只有两种写法。掌握这两种写法，遇到新题时就知道从哪里入手。

两种写法

下面都以"数一棵树有几个节点"为例，树是：根 5 的左孩子是 3、右孩子是 8，3 又有两个孩子 1 和 4，一共 5 个节点。

  • 遍历型：在函数外面准备一个计数器 cnt = 0，函数从根出发把每个节点走一遍，每到一个节点就 cnt++。函数本身不返回任何东西（返回类型是 void），答案全在 cnt 里：依次经过 5、3、1、4、8，cnt 从 0 加到 5。
  • 分解型：不用外部变量，答案通过返回值一层层交上来。countNodes(node) 返回的是"node 和它下面所有节点加起来有几个"。node 不必亲自去数下面的每个节点，只要拿到左孩子和右孩子各自交上来的数，相加后再加上自己这 1 个。在这棵树上：1 和 4 下面没有节点，各返回 1；3 收到 1 和 1，返回 1 + 1 + 1 = 3；8 返回 1；根 5 收到 3 和 1，返回 3 + 1 + 1 = 5。这和公司统计人数一样：经理不必认识每个员工，只问两位直属下属"你那边连你在内有几个人"，把两个数加起来再加上自己，报给上级。

写分解型之前，先用一句话确定函数的含义，然后回答三个问题：

  1. 函数的含义：f(node) 返回什么？这个含义必须对以任意节点为根的子树都成立。
  2. 空树返回什么？这是递归的出口。
  3. 已知 f(node->left) 和 f(node->right)，怎样计算 f(node)？

// 分解型：node 是子树的根（TreeNode*，可以是 nullptr），返回这棵子树的节点个数；空树返回 0
int countNodes(TreeNode* node) {             // 返回以 node 为根的子树有几个节点
    if (node == nullptr) return 0;           // 空树：0 个
    return countNodes(node->left) + countNodes(node->right) + 1;   // 相信左右子树的个数，再加上自己
}

// 遍历型求高度：node 是当前节点（可以是 nullptr），depth 是它所在的层号（根在第 1 层），
// best 是见过的最大层号（引用，所有层共用）；没有返回值，结论留在 best 里
void heightWalk(TreeNode* node, int depth, int& best) {   // best：见过的最大层号，所有层共用
    if (node == nullptr) return;                  // 空节点不占层
    best = max(best, depth);                      // depth：node 在第几层
    heightWalk(node->left, depth + 1, best);      // 孩子在下一层
    heightWalk(node->right, depth + 1, best);
}
// 返回树 root 的高度（层数）；空树返回 0
int heightByWalk(TreeNode* root) { int best = 0; heightWalk(root, 1, best); return best; }   // 空树 best 保持 0
# 遍历型求高度：node 是当前节点（可以是 None），depth 是它所在的层号（根在第 1 层），
# best[0] 是见过的最大层号（所有层共用）；没有返回值，结论留在 best[0] 里
def height_walk(node, depth, best):              # depth 是 int，重新赋值影响不到调用者，相当于按值传
    if node is None: return                       # 空节点不占层
    best[0] = max(best[0], depth)                 # best = [0] 是只有一个元素的 list，所有层改同一个对象，对应 int&
    height_walk(node.left, depth + 1, best)       # 孩子在下一层
    height_walk(node.right, depth + 1, best)
# 返回树 root 的高度（层数）；空树返回 0
def height_by_walk(root): best = [0]; height_walk(root, 1, best); return best[0]   # 空树返回 0

逐行说明：depth 按值传递，每层有自己的副本，从父节点得到 depth，向孩子传 depth + 1，回到父节点时父节点的 depth 没有被改动；best 按引用传递（int&），所有层修改的是同一个变量，这就是外部变量。入口函数中根在第 1 层，所以传入 1；空树时 best 保持为 0。

// 树高：返回子树有几层；空树返回 0
int height(TreeNode* node) {                      // 返回子树有几层
    if (node == nullptr) return 0;                // 空树 0 层
    return max(height(node->left), height(node->right)) + 1;   // 较高的那边再加上自己这一层
}
// 叶子数：返回子树里两个孩子都为空的节点个数；空树返回 0
int countLeaves(TreeNode* node) {                 // 返回子树里叶子的个数
    if (node == nullptr) return 0;                // 空树没有叶子
    if (node->left == nullptr && node->right == nullptr) return 1;   // 自己就是叶子
    return countLeaves(node->left) + countLeaves(node->right);       // 不是叶子：左右的叶子相加
}
// 求和：返回子树所有节点值之和；空树返回 0
long long sumTree(TreeNode* node) {               // 返回子树所有值之和
    if (node == nullptr) return 0;                // 空树的和是 0
    return sumTree(node->left) + sumTree(node->right) + node->val;   // 左和 + 右和 + 自己
}
// 最大值：返回子树里的最大值；空树返回 INT_MIN（int 能表示的最小值）
int maxVal(TreeNode* node) {                      // 返回子树里的最大值
    if (node == nullptr) return INT_MIN;          // 空树不影响 max
    return max({node->val, maxVal(node->left), maxVal(node->right)});   // 自己和左右最大值中取最大
}
// 查找：子树里有值等于 target 的节点返回 true，否则（包括空树）返回 false
bool contains(TreeNode* node, int target) {       // 子树里有没有 target
    if (node == nullptr) return false;            // 空树里什么都没有
    if (node->val == target) return true;         // 自己就是
    return contains(node->left, target) || contains(node->right, target);   // 左边找到就不再找右边
}

    if node is None: return 0                     # 空树 0 层
    return max(height(node.left), height(node.right)) + 1   # 较高的那边再加上自己这一层
# 叶子数：返回子树里两个孩子都为空的节点个数；空树返回 0
def count_leaves(node):                           # 返回子树里叶子的个数
    if node is None: return 0                     # 空树没有叶子
    if node.left is None and node.right is None: return 1   # 自己就是叶子
    return count_leaves(node.left) + count_leaves(node.right)   # 不是叶子：左右的叶子相加
# 求和：返回子树所有节点值之和；空树返回 0
def sum_tree(node):                               # 返回子树所有值之和
    if node is None: return 0                     # 空树的和是 0
    return sum_tree(node.left) + sum_tree(node.right) + node.val   # 左和 + 右和 + 自己
# 最大值：返回子树里的最大值；空树返回负无穷
def max_val(node):                                # 返回子树里的最大值
    if node is None: return float('-inf')         # Python 没有 INT_MIN，用负无穷：空树不影响 max
    return max(node.val, max_val(node.left), max_val(node.right))   # 自己和左右最大值中取最大

def contains(node, target):                       # 子树里有没有 target

// 以下五组遍历型函数：xxxWalk(node, …) 从 node 出发走遍整棵子树，把结果累积到引用参数里，没有返回值；
// 紧跟的入口函数负责给引用参数设初值、调用一次 Walk，再返回结果。node / root 可以是 nullptr
// 计数：每到一个节点 cnt 加 1
void countWalk(TreeNode* node, int& cnt) {        // cnt：所有层共用的计数器
    if (node == nullptr) return;                  // 空节点不计数
    cnt++;                                        // 每到一个节点就数一个
    countWalk(node->left, cnt);                   // 走左子树
    countWalk(node->right, cnt);                  // 走右子树
}
// 返回树的节点个数
int countNodesWalk(TreeNode* root) { int cnt = 0; countWalk(root, cnt); return cnt; }   // 从 0 开始数

// 数叶子：遇到两个孩子都为空的节点 cnt 加 1
void leavesWalk(TreeNode* node, int& cnt) {       // cnt：所有层共用的叶子计数器
    if (node == nullptr) return;                  // 空节点：什么也不做
    if (node->left == nullptr && node->right == nullptr) cnt++;   // 是叶子才数
    leavesWalk(node->left, cnt);
    leavesWalk(node->right, cnt);
}

void sumWalk(TreeNode* node, long long& s) {      // s：所有层共用的累加器
    if (node == nullptr) return;                  // 空节点：什么也不加
    s += node->val;                               // 到达节点就加上它的值
    sumWalk(node->left, s);
    sumWalk(node->right, s);
}

// 最大值：用每个节点的值更新 best
void maxWalk(TreeNode* node, int& best) {         // best：目前见过的最大值
    if (node == nullptr) return;                  // 空节点：不影响最大值
    best = max(best, node->val);                  // 用当前节点更新最大值
    maxWalk(node->left, best);
    maxWalk(node->right, best);
}

    if (node->val == target) found = true;         // 找到了
    containsWalk(node->left, target, found);
    containsWalk(node->right, target, found);
}
// 树里有值等于 target 的节点返回 true，否则返回 false

def sum_walk(node, s):              # s = [0]：所有层共用的累加器
    if node is None: return         # 空节点：什么也不加
    s[0] += node.val                # 到达节点就加上它的值
    sum_walk(node.left, s)
    sum_walk(node.right, s)
# 返回树所有节点值之和
def sum_tree_walk(root): s = [0]; sum_walk(root, s); return s[0]   # 和从 0 开始

# 最大值：用每个节点的值更新 best[0]
def max_walk(node, best):           # best[0]：目前见过的最大值
    if node is None: return         # 空节点：不影响最大值
    best[0] = max(best[0], node.val)   # 用当前节点更新最大值
    max_walk(node.left, best)
    max_walk(node.right, best)
# 返回树里的最大值；空树返回负无穷
def max_val_walk(root): best = [float('-inf')]; max_walk(root, best); return best[0]   # 初值负无穷

# 查找：遇到值等于 target 的节点就把 found[0] 设为 True，之后不再往下走
def contains_walk(node, target, found):          # found[0]：是否已经找到
    if node is None or found[0]: return          # 找到后就不再往下走
    if node.val == target: found[0] = True       # 找到了
    contains_walk(node.left, target, found)
    contains_walk(node.right, target, found)
# 树里有值等于 target 的节点返回 True，否则返回 False
def contains_by_walk(root, target): found = [False]; contains_walk(root, target, found); return found[0]

对 7.2 的树 [5,3,8,1,4]，两种写法的结果完全相同：节点数 5、高度 3、叶子数 3、和 21、最大值 8、包含 4 而不包含 7。对于全是负数的树 [-5,-9,-2]，最大值是 −2，这说明 maxVal 的出口必须返回 INT_MIN：如果返回 0，结果会错成 0。

如何选择

  • 题目要求的量能由左右子树的同一个量得出（个数、高度、和、是否平衡）时，优先使用分解型，代码最短，也没有需要重置的外部变量。
  • 节点需要从上方传下来的信息（深度、路径、到根的和），或者答案是在遍历过程中顺便统计的量时，使用遍历型，信息通过参数向下传递。
  • 很多中等难度的题目两者混用：函数把子树的答案返回给父节点使用，同时在外部变量中更新全局答案，第 11 章的直径、最大路径和就是这样。

long long sumEven(TreeNode* node) {               // 分解型：返回子树里偶数值之和

void dwsWalk(TreeNode* node, int depth, long long& s) {   // depth：node 在第几层；s：奖金累加器

练习 7.6-4【综合】每个部门都"不偏科"吗：平衡二叉树 选做

题面：一棵树是平衡的，当且仅当树中 每一个 节点的左子树和右子树的高度相差都不超过 1（高度是子树一共有几层，空子树的高度为 0）。写 bool isBalancedTree(TreeNode* root)，平衡返回 true，否则返回 false，要求时间 O(n)。空树是平衡的。节点数不超过 10⁵。

样例 1：树 [6, 2, 8, null, null, 7, 9]（6 的孩子是 2、8；2 没有孩子；8 的孩子是 7、9），返回 true。根的左子树 {2} 高 1，右子树 {8, 7, 9} 高 2，相差 1；其余节点的左右两边高度都相同。

样例 2：树 [1, 2, null, 3]（1 只有左孩子 2，2 只有左孩子 3），返回 false。根的左子树由 2、3 组成，高 2；右子树为空，高 0；相差 2。

样例 3：树 [1, 2, 3, 4, null, null, 5, 6, null, null, 7]，返回 false。这棵树的根下面是两条链：左边 2、4、6（每个都是上一个的左孩子），右边 3、5、7（每个都是上一个的右孩子）。根的左右子树都高 3，根本身没问题；但节点 2 的左子树（4 和 6）高 2、右子树为空高 0，相差 2。

样例 4：空树 []，返回 true。

提示

分解型求高度，再加一个"坏了"的信号：函数 balancedHeight(node) 在子树平衡时返回高度，不平衡时返回 −1。设 L、R 分别是左、右子树调用 balancedHeight 的返回值，合并时依次检查：L 是 −1 直接返回 −1；R 是 −1 直接返回 −1；L 与 R 相差大于 1 返回 −1；都没有问题才返回 max(L, R) + 1。只检查根的左右高度是常见错误，样例 3 就是反例。在每个节点上都调用一次 height 也能做对，但是 O(n²)；练习文件 practice/ch34_drill.cpp 里正是用这个慢版本对拍。相近题型：LeetCode 110。

参考答案
// node 是子树的根（TreeNode*，可以是 nullptr）；子树平衡（每个节点左右高度差不超过 1）时返回它的高度，
// 不平衡时返回 -1；空树平衡，返回 0
int balancedHeight(TreeNode* node) {          // 平衡时返回高度，不平衡时返回 -1
    if (node == nullptr) return 0;            // 空树平衡，高度 0
    int L = balancedHeight(node->left);       // L = 左子树的高度（或 -1）
    if (L == -1) return -1;                   // 左子树里已经有不平衡的节点
    int R = balancedHeight(node->right);      // R = 右子树的高度（或 -1）
    if (R == -1) return -1;                   // 右子树里已经有不平衡的节点
    if (abs(L - R) > 1) return -1;            // 自己这里不平衡
    return max(L, R) + 1;                     // 平衡时返回真实高度
}
// 整棵树平衡返回 true，否则 false；空树返回 true

    if L == -1: return -1                     # 左子树里已经有不平衡的节点
    R = balanced_height(node.right)           # R = 右子树的高度（或 -1）
    if R == -1: return -1                     # 右子树里已经有不平衡的节点
    if abs(L - R) > 1: return -1              # 自己这里不平衡
    return max(L, R) + 1                      # 平衡时返回真实高度
# 整棵树平衡返回 True，否则 False；空树返回 True
def is_balanced_tree(root): return balanced_height(root) != -1   # 没收到 -1 就是平衡

练习 7.6-5【综合】有几个部门的预算正好等于 target 选做

题面：每个节点代表一个人，节点值是他自己的预算（可正可负）。一个"部门"是以某个节点为根的整棵子树，即这个节点连同它下面的所有节点；部门预算是这棵子树中所有值之和。树中每个节点都对应一个部门。写 int countSubtreeSum(TreeNode* root, long long target)，返回部门预算恰好等于 target 的部门个数；空树返回 0。节点数不超过 10⁵。

样例 1：树 [5, 3, 8, 1, 4]，target = 8，返回 2。5 个部门的预算：以 1 为根是 1，以 4 为根是 4，以 3 为根是 3 + 1 + 4 = 8，以 8 为根是 8，以 5 为根是 21。等于 8 的有 2 个。

样例 2：树 [0, 1, -1]，target = 0，返回 1。以 1 为根是 1，以 −1 为根是 −1，整棵树是 0 + 1 − 1 = 0，只有整棵树符合。

样例 3：树 [0, 0, 0]，target = 0，返回 3。三个部门的预算都是 0。

样例 4：空树，target = 0，返回 0。

提示

这是本节"怎样选"里说的混用：函数 subSumWalk(node) 的返回值是"子树之和"（分解型，交给父亲用），同时在函数里顺手检查"这个和是否等于 target"，命中就让引用参数 cnt 加 1（遍历型记全局答案）。每个节点只算一次子树和，总共 O(n)。如果对每个节点再单独调用一次 sumTree，就是 O(n²)，练习文件 practice/ch34_drill.cpp 里用它对拍。值可以为负，所以不能"和已经超过 target 就剪枝"。

参考答案
// 混用两种写法：node 是子树的根（可以是 nullptr），target 是要找的预算；返回这棵子树所有值之和（分解型），
// 同时每遇到一棵和等于 target 的子树就让 cnt 加 1（cnt 是引用，所有层共用）
long long subSumWalk(TreeNode* node, long long target, int& cnt) {   // 返回子树之和；cnt 记命中的部门数
    if (node == nullptr) return 0;            // 空子树的和是 0
    // s = 这棵子树的和 = 左子树之和 + 右子树之和 + 自己
    long long s = subSumWalk(node->left, target, cnt) + subSumWalk(node->right, target, cnt) + node->val;
    if (s == target) cnt++;                   // 返回值交给父亲，外部变量记全局答案
    return s;                                 // 这棵子树的和，交给父亲继续加
}
// 返回树 root 中"子树之和恰好等于 target"的子树个数；空树返回 0
int countSubtreeSum(TreeNode* root, long long target) { int cnt = 0; subSumWalk(root, target, cnt); return cnt; }
# 混用两种写法：node 是子树的根（可以是 None），target 是要找的预算；返回这棵子树所有值之和（分解型），
# 同时每遇到一棵和等于 target 的子树就让 cnt[0] 加 1（所有层共用）
def sub_sum_walk(node, target, cnt):          # cnt = [0]，对应 int&
    if node is None: return 0                 # 空子树的和是 0
    # s = 这棵子树的和
    s = sub_sum_walk(node.left, target, cnt) + sub_sum_walk(node.right, target, cnt) + node.val   # 左 + 右 + 自己
    if s == target: cnt[0] += 1               # 返回值交给父亲，外部变量记全局答案
    return s                                  # 这棵子树的和，交给父亲继续加
# 返回树 root 中"子树之和恰好等于 target"的子树个数；空树返回 0
def count_subtree_sum(root, target): cnt = [0]; sub_sum_walk(root, target, cnt); return cnt[0]

易错点

  • 遍历型的外部变量写成全局变量，在同一个程序里测第二棵树时忘了清零，答案会叠加。用"入口函数里初始化 + 引用参数"可以避免。
  • 分解型没先写函数含义，合并时就会犹豫"要不要加 1""叶子算不算"。先用一句话写出含义，再写代码。
  • 最大值的出口返回 0，遇到全负数的树就错。

小结： 遍历型写法走遍整棵树，用外部变量记录结果，信息通过参数向下传递；分解型写法先确定函数的含义和空树的返回值，再用左右子树的答案得出自己的答案。
