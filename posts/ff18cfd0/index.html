听懂讲解和自己写出来之间常有一道坎：要定义几个变量，循环的边界写 < 还是 <=，答案在什么时候更新。这一章用一组经典题，演示怎样跨过这道坎：

  • 写代码之前，先用一句话说清每个变量表示什么，以及每一轮循环开始时有什么条件一定成立；循环体就照着这句话来写。
  • 读别人的代码时，分清一个名字是类型还是变量，一个操作得到的是一个值还是一个位置。
  • 用这个方法写出二分查找、回溯、链表和矩阵题里最容易写错的那几行。

听懂思路之后写不出代码，问题通常不在思路本身，而在把思路翻译成代码的这一步：不知道需要几个变量、每个变量表示什么、循环每一步该怎样更新。本章每一节用一道具体的题，演示这一步怎样完成。容器和语法的系统讲解在第 1 章，各类题型的成套练习在第 9 至 11 章。

8.1 从思路到代码：以"移动零"为例 必读

题目：把数组里的 0 全部移到末尾，非零元素保持原来的相对顺序，要求原地修改。例如 [0,1,0,3,12] 应变成 [1,3,12,0,0]。

不限制空间时，可以开一个新数组，先依次抄入非零元素，再补 0。题目要求原地，这块额外空间就省不掉了，只能在同一个数组上一边读、一边写。于是需要两个下标：read 从左到右逐个读取元素，write 指向下一个非零元素应当放入的位置。读到非零元素时，把它和 nums[write] 交换，再把 write 加 1；读到 0 时只让 read 前进。

这样交换会不会弄乱数据？先看两个下标的关系：write 只在读到非零元素时加 1，read 每轮都加 1，所以始终有 write ≤ read，交换只涉及已经读过的位置。再看两者之间夹着什么：[write, read) 是读过、却没有写入非零元素的位置，里面只能是 0。因此每次交换，被换到后面去的都是一个 0；非零元素则按读到的先后依次落在 write 处，相对顺序不变。read 走完数组时，[0, write) 是全部非零元素且顺序不变，[write, n) 全是 0，正是题目要的结果。

上面的推理依赖一个条件：每轮循环开始时，[0, write) 是已经处理过的全部非零元素、顺序与原数组一致，[write, read) 全是 0。循环开始前两个区间都为空，条件成立；每处理一个元素，它仍然成立。像这样在每一轮开始时都成立的条件叫循环不变式（invariant）。它有两个用处：写循环体时，每一步操作都是为了让它继续成立；循环结束时，把它和结束条件 read == n 合在一起，就能推出答案正确。后面的二分查找、回溯、链表操作，都用这种方式说明"为什么这样写是对的"。

动手前的五个问题

把上面的分析拆开，就是写任何循环或递归之前都可以先回答的五个问题。五个答案写清楚以后，代码的每一行都有出处；哪一个答不出来，就说明思路卡在哪里。

问题移动零的答案
输入输出：拿到什么、交出什么，能否修改原数据，复杂度要求是什么原地修改 nums；O(n) 时间、O(1) 额外空间
变量含义：每个变量记录哪一部分信息read 是正在检查的下标；write 是下一个非零元素的落点
不变式：每轮循环开始时什么一定成立[0,write) 是已整理好的非零元素且顺序不变，[write,read) 全是 0
一步：处理一个元素时变量怎样变，为什么不变式仍成立读到非零就与 nums[write] 交换并让 write 加 1；读到 0 只移动 read
结束：何时停，停下时不变式推出什么read == n 时，非零元素全在前，0 全在后

五个答案对应到哪几行代码

左边是五个问题的回答，右边是对应的代码行；不变式③本身不写成代码，它决定了④为什么这样写

代码

因为要原地修改，参数写成引用 vector<int>&，函数里的改动会直接作用在调用者的数组上。

void moveZeroes(vector<int>& nums) {
    int write = 0;                                         // [0,write) 是已整理好的非零
    for (int read = 0; read < (int)nums.size(); ++read) {  // read 走到 n 就结束
        if (nums[read] != 0) {                             // 遇到非零：换到 write 处
            swap(nums[write], nums[read]);
            ++write;
        }
    }
}
def move_zeroes(nums):                     # nums 是列表对象的引用：原地修改，调用者看得到（对应 vector<int>&）
    write = 0                                          # [0,write) 是已整理好的非零
    for read in range(len(nums)):                      # read 走到 n 就结束；range(n) 不含 n
        if nums[read] != 0:                            # 遇到非零：换到 write 处
            nums[write], nums[read] = nums[read], nums[write]   # 元组赋值完成交换，对应 swap
            write += 1

要点

写循环或递归之前先回答上面五个问题，其中不变式最关键：循环体里每一个操作，都应当能说出它如何让不变式继续成立。

方法名只给出方向，具体写法由这五个答案决定。不同方法也可以组合：回溯枚举时，如果同一个状态被反复计算，给它加上缓存就成了记忆化搜索；动态规划的表里如果额外记下每个状态从哪里转移而来，就能还原出具体方案。选用哪种方法，取决于状态能否用几个变量完整描述、重复的子问题能否合并，以及题目要输出全部方案还是只要一个数。

单选 · 理解检查 1　对 [4,0,5,0,0,6] 执行 moveZeroes。当 read=2 这一轮刚处理完时，数组和 write 分别是什么？

A. [4,5,0,0,0,6]，write=2

B. [4,0,5,0,0,6]，write=1

C. [4,5,6,0,0,0]，write=3

D. [4,5,0,0,0,6]，write=3

查看答案与每个选项的解析

A · 正确：read=0 时 4 换到自身，write=1；read=1 是 0；read=2 时 5 与 nums[1] 的 0 交换，write=2。

B · 错误：这是 read=1 处理完的状态，read=2 时 5 已经被换到下标 1。

C · 错误：这是全部处理完的结果，6 要到 read=5 才被换过来。

D · 错误：到 read=2 为止只见过两个非零（4 和 5），write 等于非零个数 2。

练习 8.1-1【基础】已取消订单挪到末尾

题面：订单数组 orders（n ≤ 10⁵），值为 -1 的是已取消订单，其余是非负的订单号。原地把所有 -1 挪到末尾，有效订单保持原来的相对顺序，返回有效订单的个数。

样例：[5,-1,3,-1,8] 返回 3，数组变为 [5,3,8,-1,-1]；[-1,-1] 返回 0，数组不变。

提示

和 283 移动零的五个问题回答相同，只把"是 0"换成"是 -1"。write 仍是"下一个有效订单的落点"，不变式仍是 [0,write) 为有效订单且保序、[write,read) 全是 -1。返回值不需要另外计数：循环结束时 [0,write) 恰好是全部有效订单，write 就是它们的个数。

参考答案
int moveCanceledToEnd(vector<int>& orders) {
    int write = 0;                                          // [0,write)：有效订单，保持原顺序
    for (int read = 0; read < (int)orders.size(); ++read) { // [write,read)：全是 -1
        if (orders[read] != -1) {
            swap(orders[write], orders[read]);
            ++write;
        }
    }
    return write;                                           // 有效订单的个数
}
def move_canceled_to_end(orders):
    write = 0                                   # [0,write)：有效订单，保持原顺序
    for read in range(len(orders)):             # [write,read)：全是 -1
        if orders[read] != -1:
            orders[write], orders[read] = orders[read], orders[write]
            write += 1
    return write                                # 有效订单的个数

练习 8.1-2【变形】把 0 挪到最前面

题面：整数数组 nums（n ≤ 10⁵），原地把所有 0 放到最前面，非零元素放在后面并保持原来的相对顺序。

样例：[1,0,2,0,3] 变为 [0,0,1,2,3]；[0,4,0,0,5,6] 变为 [0,0,0,4,5,6]。

提示

非零元素要保序并落在右段。从左往右扫时，第一个非零该落在哪个下标取决于它后面还有几个非零，扫到它时还不知道；从右往左扫，最后一个非零的落点固定是 n-1。所以只改扫描方向，其余照搬：write 是"下一个非零从右边数的落点"，初值 n-1；不变式镜像过来，(write,n-1] 是已整理好的非零且保序，(read,write] 全是 0。read 遇到非零就与 nums[write] 交换，write 减一。

参考答案
void moveZeroesToFront(vector<int>& nums) {
    int write = (int)nums.size() - 1;               // (write,n-1]：已整理好的非零，保持原顺序
    for (int read = write; read >= 0; --read) {     // (read,write]：全是 0
        if (nums[read] != 0) {
            swap(nums[write], nums[read]);
            --write;
        }
    }
}
def move_zeroes_to_front(nums):
    write = len(nums) - 1                       # (write,n-1]：已整理好的非零，保持原顺序
    for read in range(write, -1, -1):           # (read,write]：全是 0；read 取 n-1..0
        if nums[read] != 0:
            nums[write], nums[read] = nums[read], nums[write]
            write -= 1

练习 8.1-3【综合】按基准值分成三段

题面：整数数组 a（n ≤ 10⁵，可含负数和重复值）和基准值 pivot。原地重排成三段：小于 pivot 的在前，等于的在中间，大于的在后，各段内部顺序不限。只扫描一趟，额外空间 O(1)。（相近题型：LeetCode 75）

样例：a=[2,0,2,1,1,0], pivot=1 变为 [0,0,1,1,2,2]；a=[3,1,2], pivot=5 不变（全部小于 pivot）。

提示

三段结果加一个未检查区，不变式要四个区间：[0,lt) 小于 pivot、[lt,i) 等于、[i,gt) 未检查、[gt,n) 大于。gt 取开区间端点，和 8.4 的半开写法一致，初值是 n。a[i] 小于 pivot 时与 a[lt] 交换：换过来的元素来自 [lt,i)，已确认等于 pivot（lt 等于 i 时就是它自己），所以 lt 和 i 都前进。a[i] 大于 pivot 时先 --gt 再与 a[gt] 交换：换过来的元素来自未检查区，所以 i 不动，下一轮再判断它。未检查区为空时结束，循环条件是 i < gt。

参考答案
void threeWaySplit(vector<int>& a, int pivot) {
    int lt = 0, i = 0, gt = (int)a.size();     // [0,lt) < pivot；[lt,i) == pivot；[i,gt) 未检查；[gt,n) > pivot
    while (i < gt) {
        if (a[i] < pivot) {
            swap(a[lt], a[i]);                 // 换过来的 a[i] 来自 [lt,i)，等于 pivot，已检查过
            ++lt; ++i;
        } else if (a[i] > pivot) {
            --gt;
            swap(a[i], a[gt]);                 // 换过来的 a[i] 来自未检查区，i 不动，下一轮再看它
        } else {
            ++i;
        }
    }
}
def three_way_split(a, pivot):
    lt, i, gt = 0, 0, len(a)       # [0,lt) < pivot；[lt,i) == pivot；[i,gt) 未检查；[gt,n) > pivot
    while i < gt:
        if a[i] < pivot:
            a[lt], a[i] = a[i], a[lt]      # 换过来的 a[i] 来自 [lt,i)，等于 pivot，已检查过
            lt += 1; i += 1
        elif a[i] > pivot:
            gt -= 1
            a[i], a[gt] = a[gt], a[i]      # 换过来的 a[i] 来自未检查区，i 不动，下一轮再看它
        else:
            i += 1

易错点：

  • 把 write 写成"最后一个非零的位置"，初值就会变成 −1，后面每处都要加减 1。让变量指向"下一个空位"，区间写成左闭右开，边界最少。
  • 题目要求保持非零的相对顺序。从两端向中间交换的写法会打乱顺序，只适合不要求顺序的题。

小结： 写代码之前，先回答输入输出、变量含义、不变式、每一步做什么、何时结束这五个问题；不变式说明了每一步为什么这样写；方法的名称只是思考的起点。

8.2 计数排序：类型与对象、容器与元素、循环次数 选读

计数排序先统计每个数出现了几次，再按从小到大的顺序把每个数写回相应的次数。例如 [3,1,3,2] 统计得到 1 出现 1 次、2 出现 1 次、3 出现 2 次，写回得到 [1,2,3,3]。把这个思路写成 C++ 时，常见错误集中在三处：把类型名当成对象名使用，把整个容器当成其中一个元素使用，以及循环多执行或少执行一次。

三个容易出错的地方

类型与对象。 map<int,int> 是一个类型，它规定了映射的形式：键和值都是 int，并按键从小到大排列。语句 map<int,int> freq; 按这个类型创建出一个名为 freq 的对象。读写数据要通过对象名，例如 ++freq[x]；写成 map[x] 是对类型名取下标，无法通过编译。

容器与元素。 arr 表示整个数组。在 for (int value : arr) 中，value 依次取数组里的每一个元素。统计时要计数的是当前这个元素，所以写 ++freq[value]。

循环次数。 一个值要写回 times 次时，用变量 c 表示已经写了几次：c 从 0 开始，每写一次加 1，等于 times 时停止，即 for (int c = 0; c < times; ++c)，循环体恰好执行 times 次。若写成从 times 递减到 0 且包含 0，循环体会执行 times + 1 次。

遍历 map 时，每个元素是一个键值对，类型为 pair<const int, int>。结构化绑定 auto [value, times] = kv 把这个键值对拆成两个变量：value 是数值，times 是它出现的次数。结构化绑定要求被拆的对象由若干部分组成，例如 pair、结构体或数组；对单个 int 使用会编译失败。

四个名字分别是什么

高亮的是循环里每轮变化的单个值；方框标题写出了每个名字的类型

代码

代码中，freq 记录每个数值出现的次数，并按数值从小到大排列；pos 是下一个要写入的位置。

void histogramSort(vector<int>& nums) {
    map<int, int> freq;                          // 键：数值；值：出现次数
    for (int value : nums) ++freq[value];        // value 是一个 int，不是整个数组
    int pos = 0;                                 // 下一个要写的位置
    for (const auto& [value, times] : freq) {    // 拆开的是 freq 里的一对
        for (int c = 0; c < times; ++c) {        // 已写 c 次，写满 times 次停
            nums[pos] = value;
            ++pos;
        }
    }
}
def histogram_sort(nums):
    freq = {}                                    # 键：数值；值：出现次数。dict 按插入顺序而不是按键排序
    for value in nums:                           # value 是一个 int，不是整个列表
        freq[value] = freq.get(value, 0) + 1     # dict 的 [] 读不存在的键会抛 KeyError，不会像 map 那样插入 0
    pos = 0                                      # 下一个要写的位置
    for value, times in sorted(freq.items()):    # 拆开的是一对 (键, 值)；sorted 按键排序，对应 map 的有序遍历
        for c in range(times):                   # 已写 c 次，写满 times 次停：c 取 0..times-1
            nums[pos] = value
            pos += 1

设共有 n 个数，其中有 u 个不同的值。每次 map 操作需要 O(log u) 时间，统计阶段共 O(n log u)；写回阶段每个数写一次，共 O(n)；freq 占用 O(u) 额外空间。教材中的计数排序用长度等于值域 R 的数组计数，时间为 O(n + R)。用 map 代替数组，适合值域很大而不同值较少的情况。

要点

写每一行代码时，先确认其中每个名字是什么：类型、对象、单个元素，还是键值对。表示"重复 times 次"的循环统一写成 for (int c = 0; c < times; ++c)。检查循环边界时代入最小输入 times = 1：正确的写法执行 1 次，从 times 数到 0 的写法执行 2 次，错误立刻暴露。

练习 8.2-1【基础】得票最多的候选人

题面：选票数组 votes（n ≤ 10⁵），每个元素是一张票上的候选人编号（0 ≤ 编号 ≤ 10⁹）。返回得票最多的编号；平票时返回其中最小的编号；没有选票返回 -1。

样例：[3,1,3,1,2] 返回 1（1 号和 3 号各 2 票，取小编号）；[] 返回 -1。

提示

编号可达 10⁹，开不出下标就是编号的数组，所以用 map<int,int> 计数。三问各落在一行：freq 是对象，计数写 ++freq[cid]；第一个循环里的 cid 是一张票上的一个 int；第二个循环里的 [cid, cnt] 是从 freq 拆出的一对。平票规则由两点共同保证：map 按键升序遍历，小编号先出现；更新条件用严格的 >，后出现的同票编号替换不了它。把 > 改成 >=，返回的就是平票中最大的编号。

参考答案
int topCandidate(const vector<int>& votes) {
    map<int, int> freq;                              // 键：候选人编号；值：票数
    for (int cid : votes) ++freq[cid];               // cid 是一张票上的编号
    int best = -1, bestCnt = 0;                      // 目前票数最多的编号和它的票数
    for (const auto& [cid, cnt] : freq) {            // 按编号升序拆出每一对
        if (cnt > bestCnt) {                         // 严格大于：平票时保留先遇到的小编号
            best = cid;
            bestCnt = cnt;
        }
    }
    return best;
}
def top_candidate(votes):
    freq = {}                                   # 键：候选人编号；值：票数
    for cid in votes:                           # cid 是一张票上的编号
        freq[cid] = freq.get(cid, 0) + 1
    best, best_cnt = -1, 0                      # 目前票数最多的编号和它的票数
    for cid, cnt in sorted(freq.items()):       # sorted 按编号升序，对应 map 的遍历顺序
        if cnt > best_cnt:                      # 严格大于：平票时保留先遇到的小编号
            best = cid
            best_cnt = cnt
    return best

练习 8.2-2【变形】成绩降序：下标就是分数

题面：分数数组 scores（n ≤ 10⁵，每个分数是 0 到 100 的整数），返回按分数从高到低排好的新数组，时间 O(n + 101)。

样例：[60,100,60,0] 返回 [100,60,60,0]；[] 返回 []。

提示

值域只有 101 个值，用 vector<int> cnt(101) 代替 map，下标就是分数，即本节提到的经典计数排序。和 histogramSort 相比改了两处：容器从 map 换成数组；写回从升序改为降序，外层写 for (int s = 100; s >= 0; --s)。这里含 0 的 >= 0 是对的，因为 s 是一个分数，0 分必须取到；内层的 c 是"已写次数"，要跑 cnt[s] 次，所以仍写 c < cnt[s]。两个循环的边界由各自变量的含义决定。

参考答案
vector<int> sortScoresDesc(const vector<int>& scores) {
    vector<int> cnt(101, 0);                         // cnt[s]：分数 s 出现的次数，下标就是分数
    for (int s : scores) ++cnt[s];
    vector<int> out;
    for (int s = 100; s >= 0; --s) {                 // s 是一个分数，0 也是合法分数，所以写 >= 0
        for (int c = 0; c < cnt[s]; ++c) out.push_back(s);   // 写 cnt[s] 次
    }
    return out;
}
def sort_scores_desc(scores):
    cnt = [0] * 101                             # cnt[s]：分数 s 出现的次数，下标就是分数
    for s in scores:
        cnt[s] += 1
    out = []
    for s in range(100, -1, -1):                # s 取 100..0；range 右端不含，所以写 -1
        for c in range(cnt[s]):                 # 写 cnt[s] 次
            out.append(s)
    return out

练习 8.2-3【综合】按出现次数排序

题面：整数数组 nums（n ≤ 10⁵，可含负数），返回新数组：出现次数多的值排在前面，次数相同时值小的在前，同一个值的所有副本连续排列。（相近题型：LeetCode 1636）

样例：[4,1,4,2,2,4] 返回 [4,4,4,2,2,1]；[-1,3,3,-1,5] 返回 [-1,-1,3,3,5]。

提示

统计用 map，写回用 c < times 的次数循环，这两步和 histogramSort 相同。多出的一步是按次数排序：map 只按键排序，所以先把它的键值对复制进 vector<pair<int,int>>，再给 sort 一个比较函数。比较函数里 p.first 是值、p.second 是次数：先比次数，大的在前；次数相同再比值，小的在前。两条 return 都用严格的 > 和 <，两个元素相等时返回 false，这是 sort 对比较函数的要求。Python 版用 key=(-次数, 值) 表达同一个顺序。

参考答案
vector<int> sortByFrequency(const vector<int>& nums) {
    map<int, int> freq;                                       // 值 -> 次数
    for (int x : nums) ++freq[x];
    vector<pair<int, int>> items(freq.begin(), freq.end());   // 复制成 (值, 次数) 数组，才能按次数排序
    sort(items.begin(), items.end(), [](const pair<int, int>& p, const pair<int, int>& q) {
        if (p.second != q.second) return p.second > q.second; // 次数多的在前
        return p.first < q.first;                             // 次数相同，值小的在前
    });
    vector<int> out;
    for (const auto& [value, times] : items) {
        for (int c = 0; c < times; ++c) out.push_back(value);
    }
    return out;
}
def sort_by_frequency(nums):
    freq = {}                                                   # 值 -> 次数
    for x in nums:
        freq[x] = freq.get(x, 0) + 1
    items = sorted(freq.items(), key=lambda p: (-p[1], p[0]))   # 次数多的在前；次数相同，值小的在前
    out = []
    for value, times in items:
        for c in range(times):
            out.append(value)
    return out

易错点：

  • for(int i=val, i>=0; i--) 中间用了逗号，for 的三部分要用分号隔开，这一行本身就编译不过。
  • freq[x] 在键不存在时会插入一个 0。计数时正好利用这一点；只想查询时用 count 或 find（见 1.7 哈希表）。

小结： 读代码时先弄清它是类型还是对象、是一个值还是一个容器、循环执行几次；按次数循环时写成 c=0; c<times。

8.4 二分查找：lo 和 hi 圈出的是"还没排除的区间" 必读

二分查找每轮检查中点，排除一半区间，所以 n 个元素只需检查约 log₂n 次。它的代码只有几行，出错几乎都在边界：区间端点该写 mid + 1 还是 mid，循环条件该写 < 还是 <=。这些细节都由一件事决定：lo 和 hi 表示什么。先把这一点规定清楚，每一行代码都能推出来。

区间的含义决定每一行代码

我们固定一个最常用的问题：在升序数组 a 里找第一个 a[i] >= target 的下标；如果没有，返回 n。这就是 C++ 的 lower_bound。[3]

取半开区间 [lo, hi) 表示"还没有判断过的下标"，并约定每轮循环开始时满足：[0, lo) 中的值都小于 target，因此答案在它们右边；[hi, n) 中的值都大于等于 target，因此答案是 hi 或在它左边。

每一步看中点，把它连同一侧并入左段或右段；未分类区间为空时，lo==hi 就是第一个 ≥ target 的位置

由这个约定可以推出每一行代码。

开始时所有下标都还没判断，所以 lo = 0, hi = n。每轮取中点 mid：若 a[mid] < target，mid 及其左边的值都小于 target，可以一起排除，令 lo = mid + 1；若 a[mid] >= target，mid 本身可能就是答案，不能排除，令 hi = mid。两种情况都保持了上面的约定，而且区间每轮至少缩小 1。当 lo == hi 时没有未判断的下标，循环条件因此写成 lo < hi；此时 [hi, n) 都大于等于 target、[0, lo) 都小于 target，所以 lo 就是第一个大于等于 target 的位置。

74 题：把矩阵当成一维数组

74 题的矩阵每行升序，并且每行第一个数大于上一行最后一个数。按行读出来就是一个全局升序的一维序列，长度 rows*cols。一维下标 k 对应的行、列是：row = k / cols，col = k % cols。

cols=4：k=6 → row=6/4=1，col=6%4=2，即值 16

在这个矩阵里找 16：[0,12) 时 mid=6，值 16 ≥ 16，hi=6；[0,6) 时 mid=3，值 7 < 16，lo=4；[4,6) 时 mid=5，值 11 < 16，lo=6；区间为空，lo=6，对应 (1,2)，值正好是 16，找到。

bool searchMatrix(const vector<vector<int>>& a, int target) {
    if (a.empty() || a[0].empty()) return false;
    int rows = a.size(), cols = a[0].size();
    int lo = 0, hi = rows * cols;                  // 虚拟一维数组上的 [lo,hi)
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        int v = a[mid / cols][mid % cols];         // 一维下标 → 行、列
        if (v < target) lo = mid + 1;
        else hi = mid;
    }
    return lo < rows * cols && a[lo / cols][lo % cols] == target;
}
def search_matrix(a, target):
    if not a or not a[0]: return False
    rows, cols = len(a), len(a[0])
    lo, hi = 0, rows * cols                        # 虚拟一维数组上的 [lo,hi)

        else: hi = mid

int countInRange(const vector<int>& ts, int from, int to) {

题面：把一个元素互不相同的升序数组从某处切开、前后两段交换位置，得到 a（1 ≤ n ≤ 10⁵）；也可能没有切开。用 O(log n) 时间返回最小值。（相近题型：LeetCode 153）

提示

用末元素 last 当分界：左段每个数都 > last，右段（从最小值开始）每个数都 ≤ last。于是"a[i] ≤ last"在数组上前假后真，最小值是第一个使它为真的位置，三段划分照搬：[0,lo) 都 > last，[hi,n) 都 ≤ last。a[mid] > last 时 lo = mid + 1，否则 hi = mid。没有切开时所有数都 ≤ last，lo 停在 0。这个分界依赖元素互不相同：[1,1,0,1] 里左段的 1 也 ≤ last，二分返回 a[0]=1，答案却是 0。

int rotatedMin(const vector<int>& a) {
    int last = a.back();                     // 右段（含最小值）都 <= last，左段都 > last

练习 8.4-5【综合】最小运力

题面：n 件包裹（1 ≤ n ≤ 5×10⁴，重量 1 到 500）必须按给定顺序装车，每天装连续的若干件，当天总重不超过运力 cap。求在 days 天内运完的最小 cap。（相近题型：LeetCode 1011）

提示

二分的对象从数组下标换成答案 cap。判定函数 canShip 按顺序贪心装车，当天装不下就换一天，最后看天数是否 ≤ days。cap 越大，用的天数越少，所以 canShip 在 cap 上前假后真，答案是第一个为真的 cap，套用 lowerBound 的三段划分：[0,lo) 都不可行，[hi,∞) 都可行。初值由题意推出：cap 小于最重的一件一定不行，lo 取最大重量；cap 等于总重时一天就能运完，hi 取总重。样例里 cap=5 要 4 天（[3,2]、[2]、[4,1]、[4]），cap=6 要 3 天，答案 6。总重最大 2.5×10⁷，int 装得下，代码用 long long 是为了重量上限放大后不用改。

bool canShip(const vector<int>& w, long long cap, int days) {
    int used = 1;                                // 已经开始的天数
    long long load = 0;                          // 当天已装的重量
    for (int x : w) {
        if (x > cap) return false;               // 单件就超过运力
        if (load + x > cap) {                    // 装不下：换到新的一天
            ++used;
            load = 0;
        }
        load += x;
    }
    return used <= days;
}
long long minShipCapacity(const vector<int>& w, int days) {
    long long lo = 0, hi = 0;                    // [0,lo) 都不可行；[hi,∞) 都可行
    for (int x : w) {
        lo = max(lo, (long long)x);              // 小于最重的一件一定不行
        hi += x;                                 // 等于总重时一天就能运完
    }
    while (lo < hi) {
        long long mid = lo + (hi - lo) / 2;
        if (canShip(w, mid, days)) hi = mid;     // 可行：mid 可能就是最小的
        else lo = mid + 1;                       // 不可行：更小的运力也不行
    }
    return lo;
}

8.5 回溯的调用栈：一帧一帧看 return 回到哪里 必读

回溯代码通常只有十几行，难点在于：递归调用返回之后，程序从哪一行继续执行，哪些变量还保持原来的值。函数每被调用一次，系统就为这次调用分配一块独立的存储，叫栈帧（stack frame），用来存放这次调用的参数和局部变量；调用结束时这块存储被释放，控制回到调用者的下一条语句。用栈帧来追踪回溯，上面的问题就都有确定的答案。

哪些变量各层独立，哪些变量各层共享

以 46 题全排列为例：给定互不相同的数，输出全部排列。第 k 层递归决定排列的第 k 个位置放哪个还没用过的数。

path 是当前已经选好的前缀，used[i] 记录下标 i 的数是否已放入 path，ans 收集已完成的排列。这三个变量以引用方式传递，所有层操作的是同一份数据。循环变量 i 则是局部变量，存在各自的栈帧里：子调用返回后，父层的 i 仍是调用前的值，程序从递归调用的下一行接着执行。正因为 path 和 used 被所有层共享，子调用返回后必须把本层所做的修改撤销，否则下一次循环会看到被子调用改过的状态。

void backtrackPermute(const vector<int>& nums, vector<int>& path,
                      vector<bool>& used, vector<vector<int>>& ans) {
    if (path.size() == nums.size()) { ans.push_back(path); return; }  // 复制一份完整排列
    for (int i = 0; i < (int)nums.size(); ++i) {   // i 属于本层自己的帧
        if (used[i]) continue;
        used[i] = true;  path.push_back(nums[i]);  // 做选择
        backtrackPermute(nums, path, used, ans);   // 进入下一层；返回后从下一行继续
        path.pop_back(); used[i] = false;          // 撤销本层的选择
    }
}
vector<vector<int>> permute(const vector<int>& nums) {
    vector<vector<int>> ans;
    vector<int> path;
    vector<bool> used(nums.size(), false);
    backtrackPermute(nums, path, used, ans);
    return ans;
}
def backtrack_permute(nums, path, used, ans):
    if len(path) == len(nums): ans.append(path[:]); return  # 必须 path[:] 复制；append(path) 存的是同一个列表，撤销后会变空
    for i in range(len(nums)):                     # i 属于本层自己的帧
        if used[i]: continue
        used[i] = True; path.append(nums[i])       # 做选择
        backtrack_permute(nums, path, used, ans)   # 进入下一层；返回后从下一行继续
        path.pop(); used[i] = False                # 撤销本层的选择

    used = [False] * len(nums)
    backtrack_permute(nums, path, used, ans)
    return ans

[1,2,3] 的排列树

树中每个节点是某次调用开始时的 path，边上的数是这一层选择的元素。递归总是先进入第一个可选的分支，所以节点按"先走最左边的子树"的顺序被访问，叶子从左到右就是输出的顺序。

高亮的是正在记录第④个排列时的当前路径：栈里有 [] → [2] → [2,3] → [2,3,1] 四帧；绿色是已经走完的子树

任一时刻，调用栈中的帧恰好对应树上从根到当前节点的路径，因此栈的最大深度是 n + 1。叶子共有 n! 个，每到达一个叶子要复制一次长度为 n 的 path，总时间为 O(n·n!)。

要点

return 只结束当前这一层调用，父层从递归调用的下一行继续执行，父层的 i 保持调用前的值。ans.push_back(path) 存入的是 path 的副本，之后撤销 path 不影响已经记录的答案。撤销的目的是让同一层的各个分支都从同一个状态出发，所以在哪一层做的修改，就在那一层的递归调用返回后撤销。

path 也可以按值传递：每层得到自己的副本，就不必显式 pop_back，代价是每层多一次复制。可见是否写撤销只是实现上的选择，回溯本身的过程不变：选择一个分支，递归到底，返回后换下一个分支。

练习 8.5-3【综合】第 k 个排列，找到就停

题面：互不相同的整数数组 nums（1 ≤ n ≤ 8），按本节 permute 的生成顺序返回第 k 个排列（k 从 1 数）；k < 1 或 k > n! 时返回空数组。找到后立即停止，不再生成后面的排列。（相近题型：LeetCode 60）

样例：nums=[1,2,3], k=4 返回 [2,3,1]；k=7 返回 []；nums=[3,1,2], k=2 返回 [3,2,1]（顺序按下标，不按数值）。

提示

两处改动都和栈帧有关。计数器要被所有帧共享，所以按引用传 int& k，每完成一个排列减一，减到 0 的那一帧就是答案；按值传的话每帧各减各的副本，计数会错。return 只回一层，要让整棵递归停下，函数改为返回 bool：子调用返回 true 时，父帧立即 return true，跳过撤销，也不进入下一轮 i，path 就停在第 k 个排列上；如果找到后照常撤销，path 会被逐层清空。Python 的 int 不可变，用长度为 1 的列表让各层共享同一个计数。

参考答案
bool dfsKth(const vector<int>& nums, int& k, vector<int>& path, vector<bool>& used) {
    if (path.size() == nums.size()) return --k == 0;   // 又完成一个排列；k 减到 0 就是要找的那个
    for (int i = 0; i < (int)nums.size(); ++i) {
        if (used[i]) continue;
        used[i] = true;  path.push_back(nums[i]);
        if (dfsKth(nums, k, path, used)) return true;  // 找到了：不撤销，把 true 一层层传回去
        path.pop_back(); used[i] = false;
    }
    return false;
}
vector<int> kthPermutation(const vector<int>& nums, int k) {

易错点：

  • 撤销写在 for 循环外面，会让同一层的下一个兄弟带着上一个选择出发，结果出现重复或缺失。撤销要紧跟在递归调用的下一行，与"做选择"成对出现。
  • ans.push_back(path) 之后忘了 return，程序会继续进入 for 循环；对排列题来说所有元素都已用过，循环什么也不做，但对其他题可能多加元素。终止条件后统一写 return。

小结： 每次调用都有一个栈帧，各层的 i 分别保存；return 只返回上一层；在哪一层做了选择，就在哪一层撤销；记录答案时存一份副本。

8.6 排列、子集、组合、切分：同一套回溯写法改哪几处 必读

排列、子集、组合、切分都用回溯求解，代码结构几乎相同，区别在于递归函数带哪些参数：排列需要 used 数组，子集需要起始下标 start，组合总和还要多一个剩余目标 remain，切分中的 start 则表示字符串里尚未切分部分的起点。这些参数由题目的三个性质决定。

题目的三个性质决定递归参数

第一，顺序不同是否算不同的答案。排列中 [1,2] 和 [2,1] 是两个答案，所以每层要从所有未用过的元素中选，用 used 记录哪些已用；子集和组合中二者是同一个答案，为了只生成一次，规定下标递增，每层只从 start 往后选。

第二，同一个元素能否重复使用。39 题组合总和允许重复选同一个数，所以选了下标 i 之后递归时仍传 i；不允许重复时传 i + 1。

第三，是否要求覆盖全部输入。131 题要把整个字符串切成回文段，下一段只能从第一个尚未切分的位置 start 开始，start == n 时才得到一个完整的切法。

void backtrackCombination(const vector<int>& cand, int start, int remain,

        if (cand[i] > remain) break;               // 已升序：后面更大，一起剪掉

}

                        vector<string>& path, vector<vector<string>>& ans) {

def is_pal(s, l, r):

22 题中条件 r < l 保证每个前缀里右括号都不多于左括号，这比"最后左右括号数相等"更强，正是合法括号串的定义。51 题每层固定放一行，所以同一行自然只有一个皇后；冲突只需检查列、主对角线（同一条上 row − col 相同）和副对角线（同一条上 row + col 相同）三个集合。

单选 · 理解检查 7　用本节 subsets 代码对 [1,2,3] 求子集，ans 中第 5 个是？

A. [1,3]

B. [2]

C. [1,2,3]

D. [3]

查看答案与每个选项的解析

A · 正确：记录顺序是 []、[1]、[1,2]、[1,2,3]、[1,3]、[2]、[2,3]、[3]。

B · 错误：[2] 是第 6 个：以 1 开头的整棵子树先全部走完。

C · 错误：这是第 4 个，深度优先先走到最深。

D · 错误：[3] 最后记录。

多选 · 理解检查 8　关于这些回溯模型，哪些说法正确？

A. 子集用 start 递增，可避免把同一集合按不同顺序重复输出

B. 组合总和允许重复选当前正数时，递归传 i 而不是 i+1

C. 生成有效括号只要最终左右总数相等就够

D. 回文切分中，下一段可以从任意未选位置开始

查看答案与每个选项的解析

A · 正确：强制所选下标递增，[2,1] 不会出现。

B · 正确：下一层仍可选同一项，remain 减少保证终止。

C · 错误：每个前缀都要满足右数 ≤ 左数，例如 ")(" 总数相等却不合法。

D · 错误：必须从第一个未覆盖字符 start 开始，才能保证连续、完整、不重叠。

练习 8.6-1【基础】从 n 人中选 k 人

题面：编号 1 到 n 的志愿者（n ≤ 20）中选 k 人组成小组，组内不分先后。按字典序列出所有小组。（相近题型：LeetCode 77）

样例：n=4, k=2 返回 [[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]；n=3, k=0 返回 [[]]。

提示

组内不分先后，用 start 规定编号递增，和 subsets 是同一个模板。改动在记录时机：subsets 每个节点都记录，这里只在 path 长度等于 k 时记录并返回。候选直接是编号 x，从 start 取到 n，递归传 x+1。剩下的编号不够凑满 k 个时（n − x + 1 < k − path.size()）可以提前 break，结果不变，只是少走必然失败的分支。

参考答案
void backtrackChoose(int n, int k, int start, vector<int>& path, vector<vector<int>>& ans) {
    if ((int)path.size() == k) { ans.push_back(path); return; }  // 选够 k 个才记录
    for (int x = start; x <= n; ++x) {
        path.push_back(x);
        backtrackChoose(n, k, x + 1, path, ans);                  // 下一个编号必须比 x 大
        path.pop_back();
    }
}
vector<vector<int>> chooseK(int n, int k) {
    vector<vector<int>> ans;
    vector<int> path;
    backtrackChoose(n, k, 1, path, ans);
    return ans;
}
def backtrack_choose(n, k, start, path, ans):
    if len(path) == k: ans.append(path[:]); return   # 选够 k 个才记录
    for x in range(start, n + 1):
        path.append(x)
        backtrack_choose(n, k, x + 1, path, ans)     # 下一个编号必须比 x 大
        path.pop()

def choose_k(n, k):
    ans = []
    path = []
    backtrack_choose(n, k, 1, path, ans)
    return ans

练习 8.6-2【变形】含重复值的子集

题面：整数数组 a（n ≤ 10，可含重复值），返回所有不同的子集，每个子集内部升序，按本节 subsets 的生成顺序输出。（相近题型：LeetCode 90）

样例：[2,1,2] 返回 [[],[1],[1,2],[1,2,2],[2],[2,2]]；[3,3,3] 返回 [[],[3],[3,3],[3,3,3]]。

提示

直接套 subsets 会出重复：排序后的 [1,2,2] 里，选下标 1 的 2 和选下标 2 的 2 都得到 [1,2]。重复只发生在同一层：同一个父节点下，第二个相同的值开出的子树和第一个完全一样。所以先排序让相同值相邻，再在 for 循环里跳过 i > start && a[i] == a[i-1]。条件写 i > start 而不是 i > 0：i 等于 start 时 a[i] 是本层第一个候选，它和 a[i-1] 相同说明 a[i-1] 已在上一层被选进 path，这是不同层的选择，[2,2] 就靠它生成。

参考答案
void backtrackSubsetsDup(const vector<int>& a, int start, vector<int>& path,
                         vector<vector<int>>& ans) {
    ans.push_back(path);
    for (int i = start; i < (int)a.size(); ++i) {
        if (i > start && a[i] == a[i - 1]) continue;   // 同一层里，相同的值只试第一个
        path.push_back(a[i]);
        backtrackSubsetsDup(a, i + 1, path, ans);
        path.pop_back();
    }
}
vector<vector<int>> subsetsWithDup(vector<int> a) {
    sort(a.begin(), a.end());                          // 排序让相同的值挨在一起
    vector<vector<int>> ans;
    vector<int> path;
    backtrackSubsetsDup(a, 0, path, ans);
    return ans;
}
def backtrack_subsets_dup(a, start, path, ans):
    ans.append(path[:])
    for i in range(start, len(a)):
        if i > start and a[i] == a[i - 1]: continue  # 同一层里，相同的值只试第一个
        path.append(a[i])
        backtrack_subsets_dup(a, i + 1, path, ans)
        path.pop()

def subsets_with_dup(a):
    a = sorted(a)                                    # 排序让相同的值挨在一起；不改调用者的列表
    ans = []
    path = []
    backtrack_subsets_dup(a, 0, path, ans)
    return ans

练习 8.6-3【变形】每件只用一次的凑数

题面：正整数候选数组 cand（n ≤ 30，可含重复值）和 target，选出若干件使和等于 target，每件最多用一次，相同的组合只输出一次。每个组合内部升序，组合之间按字典序输出。（相近题型：LeetCode 40）

样例：cand=[10,1,2,7,6,1,5], target=8 返回 [[1,1,6],[1,2,5],[1,7],[2,6]]；cand=[2,2,2], target=4 返回 [[2,2]]。

提示

在 combinationSum 上改两处。每件只能用一次，递归传 i+1 而不是 i。候选有重复值，同一层跳过 i > start && cand[i] == cand[i-1]，理由同练习 8.6-2：第一个 [1,1,6] 由两个 1 分别在第一、二层被选出，属于不同层，不会被跳过。剪枝 cand[i] > remain 时 break 照旧保留，它依赖排序后的升序。

参考答案
void backtrackSumOnce(const vector<int>& cand, int start, int remain,
                      vector<int>& path, vector<vector<int>>& ans) {
    if (remain == 0) { ans.push_back(path); return; }
    for (int i = start; i < (int)cand.size(); ++i) {
        if (cand[i] > remain) break;                   // 已升序：后面更大，一起剪掉
        if (i > start && cand[i] == cand[i - 1]) continue;  // 同一层相同的值只试第一个
        path.push_back(cand[i]);
        backtrackSumOnce(cand, i + 1, remain - cand[i], path, ans);  // 传 i+1：每件只用一次
        path.pop_back();
    }
}
vector<vector<int>> combinationSumOnce(vector<int> cand, int target) {
    sort(cand.begin(), cand.end());
    vector<vector<int>> ans;
    vector<int> path;
    backtrackSumOnce(cand, 0, target, path, ans);
    return ans;
}
def backtrack_sum_once(cand, start, remain, path, ans):
    if remain == 0: ans.append(path[:]); return
    for i in range(start, len(cand)):
        if cand[i] > remain: break                   # 已升序：后面更大，一起剪掉
        if i > start and cand[i] == cand[i - 1]: continue   # 同一层相同的值只试第一个
        path.append(cand[i])
        backtrack_sum_once(cand, i + 1, remain - cand[i], path, ans)   # 传 i+1：每件只用一次
        path.pop()

def combination_sum_once(cand, target):
    cand = sorted(cand)
    ans = []
    path = []
    backtrack_sum_once(cand, 0, target, path, ans)
    return ans

练习 8.6-4【变形】复原 IP 地址

题面：只含数字的字符串 s（长度 ≤ 20），插入 3 个点切成 4 段，每段是 0 到 255 的整数且没有前导零（"0" 合法，"01" 不合法）。返回所有合法地址，顺序与 131 切分模板的枚举顺序一致（前面的段先取短的）。（相近题型：LeetCode 93）

样例："25525511135" 返回 ["255.255.11.135","255.255.111.35"]；"0000" 返回 ["0.0.0.0"]。

提示

变量含义与 131 回文切分相同：s[0,start) 已经切好，下一段必须从 start 开始，枚举结尾 end。改动有三处。一段是否合法从"是回文"换成 validSegment：长度 1 到 3、无前导零、值 ≤ 255；长度不超过 3，所以 stoi 不会溢出。段数固定为 4，parts 满 4 段就返回，其中只有 start == n 的才记录；不满 4 段而 start == n 时，for 循环一次也不执行，自然返回。end 最多比 start 大 2，每层最多 3 个分支，整棵树不超过 3⁴ = 81 个叶子；长度超过 12 的串一个答案也没有。

参考答案
bool validSegment(const string& s, int l, int r) {    // s[l..r] 能否作为一段
    int len = r - l + 1;
    if (len > 3 || (len > 1 && s[l] == '0')) return false;   // 超过 3 位，或有前导零
    return stoi(s.substr(l, len)) <= 255;
}
void backtrackIp(const string& s, int start, vector<string>& parts, vector<string>& ans) {
    if ((int)parts.size() == 4) {                     // 已经切出 4 段
        if (start == (int)s.size())                   // 并且正好用完整串，才是一个答案
            ans.push_back(parts[0] + "." + parts[1] + "." + parts[2] + "." + parts[3]);
        return;
    }
    for (int end = start; end < (int)s.size() && end < start + 3; ++end) {
        if (!validSegment(s, start, end)) continue;
        parts.push_back(s.substr(start, end - start + 1));
        backtrackIp(s, end + 1, parts, ans);
        parts.pop_back();
    }
}
vector<string> restoreIp(const string& s) {
    vector<string> ans;
    vector<string> parts;
    backtrackIp(s, 0, parts, ans);
    return ans;
}
def valid_segment(s, l, r):                          # s[l..r] 能否作为一段
    length = r - l + 1
    if length > 3 or (length > 1 and s[l] == '0'): return False   # 超过 3 位，或有前导零
    return int(s[l:r + 1]) <= 255

def backtrack_ip(s, start, parts, ans):
    if len(parts) == 4:                              # 已经切出 4 段
        if start == len(s):                          # 并且正好用完整串，才是一个答案
            ans.append(".".join(parts))
        return
    for end in range(start, min(len(s), start + 3)):
        if not valid_segment(s, start, end): continue
        parts.append(s[start:end + 1])
        backtrack_ip(s, end + 1, parts, ans)
        parts.pop()

def restore_ip(s):
    ans = []
    parts = []
    backtrack_ip(s, 0, parts, ans)
    return ans

练习 8.6-5【综合】按词典切分句子

题面：小写字符串 s（1 ≤ 长度 ≤ 20）和单词表 words。把 s 切成若干段，每段都是表中的单词，返回所有切法，每种切法把各段用一个空格连接；顺序与 131 切分模板一致（前面的段先取短的）；没有切法返回空列表。（相近题型：LeetCode 140）

样例：s="icecreamcone"，words=["ice","cream","icecream","cone","am","creamcone"] 返回 ["ice cream cone","ice creamcone","icecream cone"]；s="dogs", words=["dog"] 返回 []。

提示

切分模板不变，一段是否合法从"是回文"换成"在词典里"。词表先放进 unordered_set，每次判断平均 O(段长)。start == n 时 path 至少有一段（s 非空），所以从 path[0] 开始拼接不会越界；空串在入口单独处理。词表里的 "am" 只出现在 "cream" 内部，而切分必须从 start 连续往后，s[0..5]="icecre" 不在词典里，以 "am" 为一段的分支从来不会出现。只问"能不能切"时可以用 DP（LeetCode 139）；要列出所有切法时，输出本身可能是指数级：s 全是 a、词表为 {"a","aa"} 时切法个数是斐波那契数。

参考答案
void backtrackSentence(const string& s, int start, const unordered_set<string>& dict,
                       vector<string>& path, vector<string>& ans) {
    if (start == (int)s.size()) {                    // 整串切完：各段用空格连起来
        string line = path[0];
        for (int i = 1; i < (int)path.size(); ++i) line += " " + path[i];
        ans.push_back(line);
        return;
    }
    for (int end = start; end < (int)s.size(); ++end) {
        string word = s.substr(start, end - start + 1);
        if (!dict.count(word)) continue;             // 只有词典里的词能作为一段
        path.push_back(word);
        backtrackSentence(s, end + 1, dict, path, ans);
        path.pop_back();
    }
}
vector<string> splitSentences(const string& s, const vector<string>& words) {
    unordered_set<string> dict(words.begin(), words.end());
    vector<string> ans;
    vector<string> path;
    if (!s.empty()) backtrackSentence(s, 0, dict, path, ans);
    return ans;
}
def backtrack_sentence(s, start, dictionary, path, ans):
    if start == len(s):                              # 整串切完：各段用空格连起来
        ans.append(" ".join(path))
        return
    for end in range(start, len(s)):
        word = s[start:end + 1]
        if word not in dictionary: continue          # 只有词典里的词能作为一段
        path.append(word)
        backtrack_sentence(s, end + 1, dictionary, path, ans)
        path.pop()

def split_sentences(s, words):
    dictionary = set(words)                          # 对应 unordered_set；不用 dict 作变量名，它是内置类型
    ans = []
    path = []
    if s: backtrack_sentence(s, 0, dictionary, path, ans)
    return ans

易错点：

  • 组合总和的终止依赖"候选都是正数"。允许 0 或负数并可无限复用时，remain 可能永远减不到 0，同样的递归不会停。
  • 子集在函数入口记录；如果改成"到叶子才记录"，只会得到长度为 n 的那一个。

小结： 顺序不同算作新答案时用 used 数组，不算新答案时用 start 参数；元素可以重复使用时递归传 i，不能重复使用时传 i+1；要求完整覆盖时，从 start 一直切到 n。

    2、在博客根目录（注意不是yilia根目录）执行以下命令：
    npm i hexo-generator-json-content --save

    3、在根目录_config.yml里添加配置：

      jsonContent:
    meta: false
    pages: false
    posts:
      title: true
      date: true
      path: true
      text: false
      raw: false
      content: false
      slug: false
      updated: false
      comments: false
      link: false
      permalink: false
      excerpt: false
      categories: false
      tags: true
