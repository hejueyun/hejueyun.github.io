21.1 五句状态契约：用"移动零"从思路走到代码

为什么需要它

"用双指针""用回溯"是方法的名字。名字告诉我们大方向，代码却需要更细的信息：有几个变量、每个变量装着什么、循环一步改了哪些东西、什么时候停。从方法名到代码之间缺的这一层，我们叫它状态契约：用五句话把"程序在任何时刻知道什么"说清楚。五句话写完，代码几乎是逐句照抄出来的。

五句话分别回答什么

句问题写出来的形式
① 输入输出拿到什么、交出什么？能改原数据吗？复杂度要求？"原地修改 nums，O(n) 时间、O(1) 额外空间"
② 变量含义每个变量一句话：它保存哪一部分事实？"write：下一个非零该放的位置"
③ 不变式每轮循环开始时，什么事实一定成立？"[0,write) 是已整理好的非零，顺序与原来一致"
④ 一步转移处理一个元素后，哪些变量怎样变？为什么③仍成立？"遇到非零就换到 write 处，write+1"
⑤ 结束与返回何时停？停下时③推出了什么答案？"read 走到 n 时，非零全在前面，0 全在后面"

不变式（invariant）是这五句里最关键的一句：它是一句在每轮循环开始时都成立的话。循环开始前它成立，每一步之后它仍成立，循环结束时把它和"结束条件"合在一起，就得到答案。后面讲二分、回溯、链表，用的都是这个思路。

看图：五句话对应到哪几行代码

左边是五句契约，右边是对应的代码行；不变式③本身不写成代码，它决定了④为什么这样写

完整走一遍：283 移动零

题目：把数组里的 0 全部移到末尾，非零元素保持原来的相对顺序，要求原地操作。输入 [0,1,0,3,12]，输出 [1,3,12,0,0]。

我们按五句话来写。① 原地修改，所以参数是 vector<int>&。② 需要两个下标：read 从左到右检查每个元素，write 指向"下一个非零应该放的位置"。③ 不变式：[0,write) 是已经整理好的非零（顺序不变），[write,read) 全是 0。④ 看到 nums[read] 不是 0，就和 nums[write] 交换，write 加一；看到 0 就只让 read 前进。⑤ read 走到 n 时，[0,write) 是全部非零、[write,n) 全是 0，这就是答案。

代码

变量表：nums 是要原地整理的数组；read 是正在检查的下标；write 是下一个非零的落点。

void moveZeroes(vector<int>& nums) {
    int write = 0;                                         // [0,write) 是已整理好的非零
    for (int read = 0; read < (int)nums.size(); ++read) {  // read 走到 n 就结束
        if (nums[read] != 0) {                             // 遇到非零：换到 write 处
            swap(nums[write], nums[read]);
            ++write;
        }
    }
}
def move_zeroes(nums):                     # nums 是列表对象的引用：原地修改，调用者看得到（对应 vector<int>&）
    write = 0                                          # [0,write) 是已整理好的非零
    for read in range(len(nums)):                      # read 走到 n 就结束；range(n) 不含 n
        if nums[read] != 0:                            # 遇到非零：换到 write 处
            nums[write], nums[read] = nums[read], nums[write]   # 元组赋值完成交换，对应 swap
            write += 1

为什么交换不会打乱非零的顺序？因为 [write,read) 里全是 0，被换到后面去的永远是一个 0；非零元素按 read 遇到的先后依次落在 write，先遇到的落在前面。

规律与考场结论

  • 写代码前先写五句话：输入输出、变量含义、不变式、一步转移、结束条件。写不出某一句，就说明卡在这一句，回头只补这一句。
  • 不变式回答"这一步为什么这样写"。④ 的每个操作都要能说出"它让 ③ 继续成立"。
  • 方法名只是起点。回溯、DP、贪心可以组合使用：先回溯枚举，发现重复状态再加缓存，就是记忆化搜索；DP 也能记录前驱、还原具体方案。选哪种，看"状态能否完整描述、重复子问题能否合并、要输出多少东西"。
  • 有一种常见想法是"让插入排序的 j 指向当前空位"，这正是在写第②句：给变量一个更清楚的含义，代码自然更顺。

单选 · 理解检查 1　对 [4,0,5,0,0,6] 执行 moveZeroes。当 read=2 这一轮刚处理完时，数组和 write 分别是什么？

A. [4,5,0,0,0,6]，write=2

B. [4,0,5,0,0,6]，write=1

C. [4,5,6,0,0,0]，write=3

D. [4,5,0,0,0,6]，write=3

查看答案与每个选项的解析

A · 正确：read=0 时 4 换到自身，write=1；read=1 是 0；read=2 时 5 与 nums[1] 的 0 交换，write=2。

B · 错误：这是 read=1 处理完的状态，read=2 时 5 已经被换到下标 1。

C · 错误：这是全部处理完的结果，6 要到 read=5 才被换过来。

D · 错误：到 read=2 为止只见过两个非零（4 和 5），write 等于非零个数 2。

易错点：

  • 把 write 写成"最后一个非零的位置"，初值就会变成 −1，后面每处都要加减 1。让变量指向"下一个空位"，区间写成左闭右开，边界最少。
  • 题目要求保持非零的相对顺序。从两端向中间交换的写法会打乱顺序，只适合不要求顺序的题。

速记： 写代码前先写五句话；不变式说明每一步为什么这样写；方法名只是起点。

21.2 容器、值与循环：把 countSort 片段逐个落地

为什么需要它

这段片段说明思路已经有了，卡在三个翻译问题上：这个名字是类型还是对象？手里拿的是一个值还是整个容器？这个循环到底跑几次？我们把这三问固定下来，每写一行就问一遍。

三问逐个回答

  1. 类型还是对象。map<int,int> 是类型，相当于"一种盒子的规格"；count 是按这个规格造出来的那个盒子。要往盒子里放东西，用的是对象名：count[x]++。map[...] 是在对类型名做下标，编译器会报错。
  2. 一个值还是整个容器。arr 是整个数组；for (int value : arr) 里的 value 才是"当前这一个数"。计数时用的是当前这个数：++freq[value]。
  3. 循环跑几次。要写 times 次，最稳的写法是"已写 c 次，c 到 times 就停"：for (int c = 0; c < times; ++c)。原片段从 times 数到 0 并且包含 0，会多跑一次。

结构化绑定 auto [a, b] = x 的意思是"把 x 拆成两部分"，只有 x 本身由两部分组成时才能用，例如 map 里的一对 <键, 值>、pair。int 只有一个部分，没法拆。

代码

变量表：freq 是"数值 → 出现次数"的有序表；value 是当前一个数；times 是这个数要写几次；pos 是下一个要写的位置；c 是当前数已写的次数。

void histogramSort(vector<int>& nums) {
    map<int, int> freq;                          // 键：数值；值：出现次数
    for (int value : nums) ++freq[value];        // value 是一个 int，不是整个数组
    int pos = 0;                                 // 下一个要写的位置
    for (const auto& [value, times] : freq) {    // 拆开的是 freq 里的一对
        for (int c = 0; c < times; ++c) {        // 已写 c 次，写满 times 次停
            nums[pos] = value;
            ++pos;
        }
    }
}
def histogram_sort(nums):
    freq = {}                                    # 键：数值；值：出现次数。dict 按插入顺序而不是按键排序
    for value in nums:                           # value 是一个 int，不是整个列表
        freq[value] = freq.get(value, 0) + 1     # dict 的 [] 读不存在的键会抛 KeyError，不会像 map 那样插入 0
    pos = 0                                      # 下一个要写的位置
    for value, times in sorted(freq.items()):    # 拆开的是一对 (键, 值)；sorted 按键排序，对应 map 的有序遍历
        for c in range(times):                   # 已写 c 次，写满 times 次停：c 取 0..times-1
            nums[pos] = value
            pos += 1

复杂度：n 个数、u 个不同的值。统计每次 map 操作 O(log u)，共 O(n log u)；写回 O(n)；额外空间 O(u)。教材里的经典计数排序用一个长度为值域 R 的数组计数，复杂度 O(n+R)；这里用 map，适合值域很大、不同值较少的情况。

规律与考场结论

  • 每用一个名字前说出它的类型：类型名、对象、单个元素、键值对。
  • 次数循环统一写成 for (int c = 0; c < times; ++c)，跑 times 次。
  • 用最小例子测边界：times = 1 时，写对的循环跑 1 次，包含 0 的倒数循环跑 2 次，一眼就能看出来。

单选 · 理解检查 2　times=2 时，循环 for (int c = times; c >= 0; --c) 的循环体执行几次？

A. 3 次

B. 2 次

C. 1 次

D. 0 次

查看答案与每个选项的解析

A · 正确：c 依次取 2、1、0，三个值都满足 c>=0。

B · 错误：包含 0 的倒数会多出 c=0 这一次；要跑 2 次应写 c=0; c<times。

C · 错误：c=2 和 c=1 也都满足条件。

D · 错误：初值 c=2 满足 c>=0，循环会进入。

易错点：

  • for(int i=val, i>=0; i--) 中间用了逗号，for 的三部分要用分号隔开，这一行本身就编译不过。
  • freq[x] 在键不存在时会插入一个 0。计数时正好利用这一点；只想查询时用 count 或 find（见 22.7 哈希表）。

速记： 先问"类型还是对象、一个值还是容器、循环跑几次"；次数循环写 c=0; c<times。

21.3 C++ 五个语义关口：读代码时怎样翻译

为什么需要它

完整走一遍：读懂 LRU 的 DLinkedNode

146 LRU 缓存的官方题解里有这样一个类型。我们按五关逐行翻译：

struct DLinkedNode {
    int key, value;
    DLinkedNode* prev;
    DLinkedNode* next;
    DLinkedNode() : key(0), value(0), prev(nullptr), next(nullptr) {}
    DLinkedNode(int k, int v) : key(k), value(v), prev(nullptr), next(nullptr) {}
};
行关口翻译
int key, value;① 类型两个整数成员；存 key 是为了淘汰节点时能回到哈希表里删掉对应项
DLinkedNode* prev; …next;① 类型两个地址：前一个节点、后一个节点。成员是指针，节点之间才能互相指向
DLinkedNode() : …④ 构造无参构造：四个成员都设为 0 或空。题解用它造头、尾两个哨兵节点
DLinkedNode(int k, int v) : …④ 构造带参构造：设好 key、value，两个指针先为空，之后由插入函数连上
new DLinkedNode(k, v)③ 共享在堆上造一个节点，返回它的地址；哈希表和链表存的都是这个地址，指向同一个节点

无参构造造出两个哨兵，带参构造造出数据节点；哈希表里存的是节点地址，所以能 O(1) 找到它再从链表中摘下

初始化列表是构造函数冒号后面那一串 成员(初值)，它在构造函数体 {} 执行之前给成员赋初值。成员按在类里声明的顺序初始化，列表里写的先后不影响这个顺序。[1]

21.4 二分查找：lo 和 hi 圈出的是"还没排除的区间"

为什么需要它

二分的代码只有几行，难在每一行的 +1、-1、< 还是 <=。背模板容易混；把 lo、hi 的含义写成一句不变式，每一行就都能推出来。

它是什么：三段划分

我们固定一个最常用的问题：在升序数组 a 里找第一个 a[i] >= target 的下标；如果没有，返回 n。这就是 C++ 的 lower_bound。[3]

采用半开区间 [lo, hi)。不变式：

  • [0, lo) 里的值都 < target（已排除，答案在它右边）；
  • [hi, n) 里的值都 >= target（答案在它左边或就是 hi）；
  • [lo, hi) 还没分类。

每一步看中点，把它连同一侧并入左段或右段；未分类区间为空时，lo==hi 就是第一个 ≥ target 的位置

由不变式直接推出每一行：

  • 开始时什么都没分类：lo = 0, hi = n。
  • a[mid] < target：mid 属于左段，连同 mid 一起排除，lo = mid + 1。
  • a[mid] >= target：mid 属于右段，它可能就是答案，保留它，hi = mid。
  • lo == hi 时未分类区间为空，循环条件写 lo < hi，返回 lo。

int lowerBound(const vector<int>& a, int target) {
    int lo = 0, hi = (int)a.size();          // [lo,hi) 是还没分类的区间
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] < target) lo = mid + 1;   // mid 属于"小于"区，连同它一起排除
        else hi = mid;                       // mid 可能就是答案，留在区间右端
    }
    return lo;                               // 第一个 >= target 的下标，没有则为 n
}

def upper_bound(a, target):
    lo, hi = 0, len(a)
    while lo < hi:
        mid = lo + (hi - lo) // 2
        if a[mid] <= target: lo = mid + 1    # 只把 < 改成 <=
        else: hi = mid
    return lo                                # 第一个 > target 的下标；同 bisect.bisect_right

74 题的矩阵每行升序，并且每行第一个数大于上一行最后一个数。按行读出来就是一个全局升序的一维序列，长度 rows*cols。一维下标 k 对应的行、列是：row = k / cols，col = k % cols。

cols=4：k=6 → row=6/4=1，col=6%4=2，即值 16

在这个矩阵里找 16：[0,12) 时 mid=6，值 16 ≥ 16，hi=6；[0,6) 时 mid=3，值 7 < 16，lo=4；[4,6) 时 mid=5，值 11 < 16，lo=6；区间为空，lo=6，对应 (1,2)，值正好是 16，找到。

bool searchMatrix(const vector<vector<int>>& a, int target) {
    if (a.empty() || a[0].empty()) return false;
    int rows = a.size(), cols = a[0].size();
    int lo = 0, hi = rows * cols;                  // 虚拟一维数组上的 [lo,hi)
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        int v = a[mid / cols][mid % cols];         // 一维下标 → 行、列
        if (v < target) lo = mid + 1;
        else hi = mid;
    }
    return lo < rows * cols && a[lo / cols][lo % cols] == target;
}
def search_matrix(a, target):
    if not a or not a[0]: return False
    rows, cols = len(a), len(a[0])
    lo, hi = 0, rows * cols                        # 虚拟一维数组上的 [lo,hi)

        if v < target: lo = mid + 1
        else: hi = mid
    return lo < rows * cols and a[lo // cols][lo % cols] == target

21.5 回溯的调用栈：一帧一帧看 return 回到哪里

为什么需要它

回溯代码通常只有十几行，难点在"递归调用返回之后，程序从哪一行继续、哪些变量还是原来的值"。把每一次函数调用画成一个栈帧（stack frame，一次调用自己的那份局部变量），这个问题就有了答案。

它是什么：局部的 i，共享的 path

46 全排列：给定互不相同的数，输出所有排列。每一层递归决定"下一个位置放哪个还没用过的数"。

  • path：当前已经选好的前缀，所有层共用一份（按引用传）。
  • used[i]：下标 i 是否已在 path 里，所有层共用。
  • ans：已完成排列的副本集合。
  • i：每一层自己的循环变量，存在各自的栈帧里。子调用返回后，父帧的 i 还是调用前的值，从调用语句的下一行接着执行。
void backtrackPermute(const vector<int>& nums, vector<int>& path,
                      vector<bool>& used, vector<vector<int>>& ans) {
    if (path.size() == nums.size()) { ans.push_back(path); return; }  // 复制一份完整排列
    for (int i = 0; i < (int)nums.size(); ++i) {   // i 属于本层自己的帧
        if (used[i]) continue;
        used[i] = true;  path.push_back(nums[i]);  // 做选择
        backtrackPermute(nums, path, used, ans);   // 进入下一层；返回后从下一行继续
        path.pop_back(); used[i] = false;          // 撤销本层的选择
    }
}
vector<vector<int>> permute(const vector<int>& nums) {
    vector<vector<int>> ans;
    vector<int> path;
    vector<bool> used(nums.size(), false);
    backtrackPermute(nums, path, used, ans);
    return ans;
}
def backtrack_permute(nums, path, used, ans):
    if len(path) == len(nums): ans.append(path[:]); return  # 必须 path[:] 复制；append(path) 存的是同一个列表，撤销后会变空
    for i in range(len(nums)):                     # i 属于本层自己的帧
        if used[i]: continue
        used[i] = True; path.append(nums[i])       # 做选择
        backtrack_permute(nums, path, used, ans)   # 进入下一层；返回后从下一行继续
        path.pop(); used[i] = False                # 撤销本层的选择


def permute(nums):
    ans = []
    path = []                                      # 列表按对象引用传：各层共享同一个 path/used/ans（对应 C++ 的 &）
    used = [False] * len(nums)
    backtrack_permute(nums, path, used, ans)
    return ans

  • path 也可以按值传：每层拿到自己的副本，就无需显式 pop_back，代价是每层复制一次。所以"有没有 pop"只是实现方式，回溯的本质是"试一个选择、走到底、退回来试下一个"。

21.6 排列、子集、组合、切分：改的是状态契约

为什么需要它

这几道题都用回溯，代码长得很像，但入口参数各不相同：排列用 used，子集用 start，组合总和多一个 remain，切分的 start 含义又不一样。把模板里的变量随手换掉往往出错；先回答三个问题，参数自然就定了。

三个问题决定参数

  1. 顺序不同算不算新答案？ 算（排列）→ 每层从所有未用元素里选，用 used；不算（子集、组合）→ 规定下标递增，每层只从 start 往后选。
  2. 同一个元素能否重复用？ 能（39 组合总和）→ 递归传 i；不能 → 递归传 i+1。
  3. 是否要求完整覆盖？ 要（131 切分必须把整串切完）→ 下一段必须从第一个未覆盖的位置 start 开始，start == n 时记录。

void backtrackCombination(const vector<int>& cand, int start, int remain,

    for (int i = start; i < (int)cand.size(); ++i) {
        if (cand[i] > remain) break;               // 已升序：后面更大，一起剪掉

             vector<vector<bool>>& used, int r, int c, int k) {

    if (r < 0 || r >= m || c < 0 || c >= n) return false;       // 出界

vector<int> spiralOrder(const vector<vector<int>>& a) {
    vector<int> out;
    if (a.empty() || a[0].empty()) return out;
    int top = 0, bottom = (int)a.size() - 1, left = 0, right = (int)a[0].size() - 1;
    while (top <= bottom && left <= right) {
        for (int c = left; c <= right; ++c) out.push_back(a[top][c]);    // 上边，向右
        ++top;
        for (int r = top; r <= bottom; ++r) out.push_back(a[r][right]);  // 右边，向下
        --right;
        if (top <= bottom) {                                             // 还剩行，才有下边
            for (int c = right; c >= left; --c) out.push_back(a[bottom][c]);
            --bottom;
        }
        if (left <= right) {                                             // 还剩列，才有左边
            for (int r = bottom; r >= top; --r) out.push_back(a[r][left]);
            ++left;
        }
    }
    return out;
}
def spiral_order(a):
    out = []
    if not a or not a[0]: return out
    top, bottom, left, right = 0, len(a) - 1, 0, len(a[0]) - 1
    while top <= bottom and left <= right:            # range 右端不含，所以闭区间 [x,y] 写 range(x, y+1)
        for c in range(left, right + 1): out.append(a[top][c])     # 上边，向右
        top += 1
        for r in range(top, bottom + 1): out.append(a[r][right])   # 右边，向下
        right -= 1
        if top <= bottom:                                          # 还剩行，才有下边
            for c in range(right, left - 1, -1): out.append(a[bottom][c])
            bottom -= 1
        if left <= right:                                          # 还剩列，才有左边
            for r in range(bottom, top - 1, -1): out.append(a[r][left])
            left += 1
    return out

    if (a.empty() || a[0].empty()) return false;
    int r = 0, c = (int)a[0].size() - 1;      // 从右上角出发
    while (r < (int)a.size() && c >= 0) {

        if (a[r][c] > target) --c;            // 这一列往下更大：整列排除
        else ++r;                             // 这一行往左更小：整行排除
    }
    return false;
}
def search_matrix_ii(a, target):
    if not a or not a[0]: return False
    r, c = 0, len(a[0]) - 1                # 从右上角出发
    while r < len(a) and c >= 0:
        if a[r][c] == target: return True
        if a[r][c] > target: c -= 1        # 这一列往下更大：整列排除
        else: r += 1                       # 这一行往左更小：整行排除
    return False

21.10 先写一个对的基线，再优化真正重复的工作

为什么需要它

一上来就找最优解，容易卡在"想不到"上，一行也写不出来。更稳的路线是：先写一个复杂度高但一定正确的基线（baseline），确认它在题目规模下够不够；不够时，指出它在哪一步重复劳动，只优化那一步。基线还能当对拍：随机生成小数据，比较优化版和基线的输出。

题目：数一数有多少个连续子数组的和等于 k。数组可能含负数。

  1. O(n³)：枚举左端 l、右端 r，再用一层循环求 nums[l..r] 的和。
  2. O(n²)：固定 l 后，r 每右移一格，和只多了 nums[r]，在上一个和上累加即可。省掉的是"重复求和"。

优化版（O(n)），变量表：prefix 是到当前位置为止的前缀和；seen 记录此前每个前缀和出现的次数。

int subarraySum(const vector<int>& nums, int k) {
    unordered_map<int, int> seen{{0, 1}};     // 前缀和 → 出现次数；空前缀的和是 0
    int prefix = 0, count = 0;
    for (int x : nums) {
        prefix += x;                          // prefix = nums[0..i] 的和
        auto it = seen.find(prefix - k);      // 先查：之前有几个前缀等于 prefix-k
        if (it != seen.end()) count += it->second;
        ++seen[prefix];                       // 再记录当前前缀
    }
    return count;
}
def subarray_sum(nums, k):
    seen = {0: 1}                             # 前缀和 → 出现次数；空前缀的和是 0
    prefix, count = 0, 0
    for x in nums:
        prefix += x                           # prefix = nums[0..i] 的和；Python 整数不会溢出
        if prefix - k in seen:                # 先查：之前有几个前缀等于 prefix-k
            count += seen[prefix - k]
        seen[prefix] = seen.get(prefix, 0) + 1   # 再记录当前前缀
    return count

seen{{0,1}} 代表"空前缀出现过一次"，这样从下标 0 开始的子数组也能被数到。先查再记：k=0 时，如果先把当前前缀放进表，就会把"长度为 0 的空区间"也数进去。

  • 卡住时先判断卡在哪一级、哪一句契约，然后只补那一处，避免把整篇题解再读三遍。
  • 二分题至少测四个点：空数组、目标是首元素、目标是末元素、目标不存在。

单选 · 理解检查 14　做完 35 搜索插入位置后，下面哪组测试最能检查 lowerBound 的边界？

A. []查1；[1,3,5]查0、查1、查5、查6

B. [1,3,5]查3，跑十遍

C. 随机生成 100 个长度 1000 的数组，只看是否崩溃

D. 只测 target 存在的情况

查看答案与每个选项的解析

A · 正确：覆盖空数组、比所有数小、等于首元素、等于末元素、比所有数大，期望分别为 0、0、0、2、3。

B · 错误：重复同一个中间例子，碰不到任何边界。

C · 错误：没有对照期望值，答案错了也发现不了；随机测试要配合基线对拍。

D · 错误：35 的重点是不存在时返回插入位置，必须测。

易错点：

  • 读过讲解的题标成"已掌握"，复习时会跳过真正没练过的题。没有独立提交记录的题，状态写"看懂"。
  • 随机测试只看"有没有崩溃"不够，要和基线或标准库（如 std::lower_bound）的结果逐个比较。

速记： 四级验收：看懂、手跑、独立写、测边界；卡在哪级回哪节。
