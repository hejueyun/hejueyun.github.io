11.1 树的表示与建树 必读

LeetCode 的树题只给出函数签名，传进来的树已经建好。自己练习和写测试时，需要先把题目中的 [1,2,3,4,5,null,6] 这样的数组变成一棵真正的树。本节先介绍树节点的表示，再写一个建树函数，后面各节的测试都使用它。

TreeNode：一个值和两个指针

// 二叉树节点：一个对象表示树里的一个节点。val = 节点的值，left / right = 指向左、右孩子的指针。
struct TreeNode {
    int val;              // val = 节点存的值
    TreeNode* left;       // left = 左孩子，没有就是 nullptr
    TreeNode* right;      // right = 右孩子，没有就是 nullptr
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}   // 构造：TreeNode(x) 新建值为 x 的节点，一开始没有孩子
};
# 二叉树节点：一个对象表示树里的一个节点。val = 节点的值，left / right = 左、右孩子。
class TreeNode:
    def __init__(self, x):    # 构造：TreeNode(x) 新建值为 x 的节点
        self.val = x          # val = 节点存的值
        self.left = None      # left = 左孩子。Python 没有指针：left/right 存对象引用，没有孩子时是 None（对应 nullptr）
        self.right = None     # right = 右孩子；新节点一开始没有孩子

每个节点存一个值 val，再用 left、right 两个指针指向左右孩子；没有孩子时指针为 nullptr。指针和 -> 的用法见 1.11。

每个节点 = 一个值 + 两根指针；没有孩子时指针是 nullptr

LeetCode 的层序数组格式

题目中的 [1,2,3,4,5,null,6] 是按层从左到右列出的节点，null 表示这个位置没有节点。需要注意：只有实际存在的节点才在数组后面占两个位置存放它的两个孩子，空节点的孩子不再写出。因此，堆中“下标 i 的孩子是 2i+1 和 2i+2”的关系（16.9）只对完全二叉树成立；对一般的树，要用队列把数组元素和父节点对应起来。

[1,2,3,4,5,null,6]：按层从左到右；null 占位表示"这里没有节点"

用队列建树

函数 buildTree 输入层序数组 a，返回根指针；数组为空或首元素为 null 时返回 nullptr。C++ 的数组里不能直接写 null，所以用常量 NIL = INT_MIN 代表它。代码里还有三个变量：

  • q：队列，按层序存放已经建好、但还没有连上孩子的节点。
  • i：下一个要读取的数组下标。
  • cur：这一轮从队首取出、要给它连孩子的节点。

建根时用掉 a[0]，把根放入 q，令 i = 1。此后队首节点总是 a[i] 和 a[i+1] 的父节点。每一轮做三件事：

  1. 弹出队首 cur。
  2. 用 a[i] 建它的左孩子，用 a[i+1] 建右孩子；值为 null 的不建。新建的孩子放进队尾。
  3. i 增加 2。

数组读完时结束；数组末尾省略不写的 null 自然被当作空节点。

const int NIL = INT_MIN;   // NIL = 层序数组里的 null（取 int 的最小值，正常的节点值不会用到它）
// 用 LeetCode 层序数组建二叉树。a 是按层从左到右列出的节点值，NIL 表示该位置没有节点，
// 例如 {1, 2, 3, 4, 5, NIL, 6}。返回根指针；a 为空或 a[0] 是 NIL 时返回 nullptr。
TreeNode* buildTree(const vector<int>& a) {
    if (a.empty() || a[0] == NIL) return nullptr;   // 空数组或根是 null：空树
    TreeNode* root = new TreeNode(a[0]);             // root = 整棵树的根，值是 a[0]
    queue<TreeNode*> q;              // q = 已建好、还没连孩子的节点，按层序排队等着"认领孩子"
    q.push(root);
    size_t i = 1;                    // i = 下一个要读的数组下标
    while (!q.empty() && i < a.size()) {             // 还有等孩子的节点，数组也没读完
        TreeNode* cur = q.front(); q.pop();          // cur = 这一轮要连孩子的节点；队首就是 a[i]、a[i+1] 的父节点
        if (a[i] != NIL) { cur->left = new TreeNode(a[i]); q.push(cur->left); }   // a[i] 是左孩子
        ++i;                                                                      // i 移到右孩子的值
        // a[i+1] 是右孩子；数组可能在左孩子处就结束，先查越界
        if (i < a.size() && a[i] != NIL) { cur->right = new TreeNode(a[i]); q.push(cur->right); }
        ++i;                                                                      // i 移到下一个节点的左孩子
    }
    return root;                     // 末尾省略的 null 自然当作空节点
}
# 用 LeetCode 层序数组建二叉树。a 是按层从左到右列出的节点值，None 表示该位置没有节点，
# 例如 [1, 2, 3, 4, 5, None, 6]。返回根；a 为空或 a[0] 是 None 时返回 None。
def build_tree(a):
    # Python 列表可以混放 None：层序数组里的 null 直接写 None，不需要 NIL = INT_MIN
    if not a or a[0] is None: return None            # 空数组或根是 null：空树
    root = TreeNode(a[0])                            # root = 整棵树的根，值是 a[0]
    q = deque()                      # q = 已建好、还没连孩子的节点，排队等着"认领孩子"；popleft() 是 O(1)
    q.append(root)
    i = 1                            # i = 下一个要读的数组下标
    while q and i < len(a):          # 还有等孩子的节点，数组也没读完
        cur = q.popleft()            # cur = 这一轮要连孩子的节点；队首就是 a[i]、a[i+1] 的父节点
        if a[i] is not None:         # a[i] 是左孩子
            cur.left = TreeNode(a[i])
            q.append(cur.left)
        i += 1                       # i 移到右孩子的值
        if i < len(a) and a[i] is not None:   # a[i+1] 是右孩子；数组可能在左孩子处就结束，先查越界
            cur.right = TreeNode(a[i])
            q.append(cur.right)
        i += 1                                # i 移到下一个节点的左孩子
    return root                      # 末尾省略的 null 自然当作空节点

每个数组元素只读一次，时间 O(n)；队列中最多存放一层的节点，空间 O(n)。

写树的递归前要回答的三个问题

大多数树题都是对每个节点做同样的计算，写递归函数前先回答三个问题：

  1. 空节点返回什么？ 这是递归的出口。例如求深度时，空树的深度是 0；判断对称时，两个空节点算作对称。
  2. 当前节点怎样由左右子树的结果得出自己的结果？ 假设左右子树的结果已经由递归调用正确算出，只需写出当前节点这一层的计算式。
  3. 答案是函数的返回值，还是需要另设变量记录？ 如果父节点需要的量正是题目要求的答案（如深度），直接返回即可；如果答案是父节点用不上的量，例如经过某个节点转折的路径（直径），就需要另设一个变量，在递归过程中更新，见 11.5。

maxDepth：空节点返回 0；每个节点返回 1 + max(左, 右)；根的返回值 3 就是答案

上图是 104 题“二叉树的最大深度”的三个问题：空节点返回 0；当前节点返回 1 + max(左子树深度, 右子树深度)；答案就是根节点的返回值。图中每条边上的数字是子节点返回给父节点的值。

多选 · 理解检查 1　用本节的 buildTree 读入 [1,null,2,null,3]，得到的树有几层？

A. 3 层，是一条往右下斜的链 1→2→3

B. 2 层：1 的右孩子是 2，2 的左孩子是 3

C. 按堆下标 2i+1、2i+2 读，3 在下标 4，是 2 的左孩子

D. 递归的三个问题里，求层数时空节点返回 0

查看答案与每个选项的解析

A · 正确：队列读法：1 的左为 null、右为 2；2 的左为 null、右为 3。每层一个节点，共 3 层。

B · 错误：2 的左孩子位置是 a[3]=null，右孩子才是 a[4]=3。

C · 错误：堆下标规则只适用于完全二叉树；这里的 null 节点不再给孩子留位置。

D · 正确：空树 0 层，这是 maxDepth 的递归出口。

练习 11.1-1【基础】组织架构图里有几位一线员工 必做

题面：公司的组织架构画成一棵二叉树：每个节点是一个人，他的孩子是他的直属下属，每人最多有两个直属下属。树按本节的层序数组给出。没有任何下属的人叫"一线员工"，在树里就是叶子，即左右孩子都为空的节点。返回一线员工的人数；空树返回 0。数据范围：节点数 0 ≤ n ≤ 10^4。

样例 1：root = [1, 2, 3, 4, 5, null, 6]，答案 3。1 的孩子是 2 和 3，2 的孩子是 4 和 5，3 只有右孩子 6；4、5、6 都没有孩子，是叶子，共 3 个。

样例 2：root = []，答案 0。空树里一个人也没有。

样例 3：root = [7]，答案 1。只有 7 一个人，他没有下属，所以根本身就是叶子。

提示

递归的三个问题：空树返回 0；左右孩子都为空的节点是叶子，返回 1；其余节点返回"左子树叶子数 + 右子树叶子数"。和 maxDepth 相比，合并公式从 1 + max 换成了加法，另外多了一个"叶子"出口。

参考答案
// 数出以 root 为根的树里有几片叶子（左右孩子都为空的节点）；空树返回 0。
// TreeNode 是 11.1 的二叉树节点：val = 值，left / right = 左、右孩子指针。
int countLeaves(TreeNode* root) {
    if (root == nullptr) return 0;                                   // 问 1：空树没有叶子
    if (root->left == nullptr && root->right == nullptr) return 1;   // 两个孩子都空：自己就是 1 片叶子
    return countLeaves(root->left) + countLeaves(root->right);       // 问 2：左右相加
}

    if root is None: return 0                                        # 问 1：空树没有叶子
    if root.left is None and root.right is None: return 1            # 两个孩子都空：自己就是 1 片叶子
    return count_leaves(root.left) + count_leaves(root.right)        # 问 2：左右相加

练习 11.1-2【变形】把树写回层序数组（建树的逆操作） 选做

题面：这是建树的反过程：给出一棵二叉树的根，写出它的 LeetCode 层序数组。写法是从根开始一层一层地写，每层从左到右：每遇到一个存在的节点，就写下它的值，并在数组后面依次给它的左孩子、右孩子各留一个位置；孩子不存在的位置写 null（C++ 里写 NIL）；null 位置不再给孩子留位置。最后删掉数组末尾连续的 null。空树返回空数组。数据范围：节点数 ≤ 10^4。写好以后，对任何末尾不是 null 的层序数组 a，toLevelArray(buildTree(a)) 都应该原样得到 a。

样例 1：根 1 只有右孩子 2，2 只有左孩子 3，答案 [1, null, 2, 3]。先写根 1；1 的左孩子不存在，写 null，右孩子写 2；接着写 2 的左孩子 3 和右孩子 null，再写 3 的两个空孩子 null、null；删掉末尾的三个 null，得到 [1, null, 2, 3]。

样例 2：空树，答案 []。

样例 3：buildTree([1, 2, 3, 4, 5, null, 6]) 建出的树，答案 [1, 2, 3, 4, 5, null, 6]，和建树用的数组相同。

提示

还是"队列里放等着交代孩子的节点"，只是方向和 buildTree 相反：出队一个，如果它是空的，就写一个 null，然后 continue，空节点不再把孩子入队；如果非空，就写它的值，再把左右孩子入队，空孩子也要入队，因为它要在数组里占一个 null 位置。最后从数组尾部把 null 弹掉。

参考答案
// 建树的逆操作：把以 root 为根的树写成 LeetCode 层序数组，空位置写 NIL（11.1 定义的 null 标记），
// 末尾的 NIL 全部删掉。空树返回空数组。TreeNode 是 11.1 的二叉树节点（val、left、right）。
vector<int> toLevelArray(TreeNode* root) {
    vector<int> out;                                            // out = 层序数组，null 用 NIL 表示
    queue<TreeNode*> q;                                         // q = 等着写进数组的位置，按层序排队（可能是空指针）
    q.push(root);                                               // 空树时第一个就是 nullptr
    while (!q.empty()) {                                        // 还有位置没写
        TreeNode* cur = q.front(); q.pop();                     // cur = 这一轮要写进数组的位置
        if (cur == nullptr) { out.push_back(NIL); continue; }   // 空位置：记 null，不再给孩子留位
        out.push_back(cur->val);                                // 非空：写它的值
        q.push(cur->left);                                      // 空孩子也入队，它要占一个 null
        q.push(cur->right);
    }
    while (!out.empty() && out.back() == NIL) out.pop_back();   // 删掉末尾的 null
    return out;                                                 // 空树返回 []
}

def to_level_array(root):

    q = deque([root])                                           # q = 等着写进数组的位置，按层序排队；空树时就是 [None]
    while q:                                                    # 还有位置没写
        cur = q.popleft()                                       # cur = 这一轮要写进数组的位置
        if cur is None:                                         # 空位置：记 None，不再给孩子留位
            out.append(None)
            continue
        out.append(cur.val)                                     # 非空：写它的值
        q.append(cur.left)                                      # 空孩子也入队，它要占一个 None
        q.append(cur.right)
    while out and out[-1] is None: out.pop()                    # 删掉末尾的 None
    return out                                                  # 空树返回 []

练习 11.1-3【综合】老系统的"堆下标格式"转成 LeetCode 格式 选做

题面：一个老系统用另一种格式存二叉树，叫"堆下标格式"：根放在下标 0；下标 i 的节点，左孩子放在下标 2i+1，右孩子放在下标 2i+2；没有节点的位置写 null。和 LeetCode 格式不同的是，空位置下面的孩子位置也照样占着（这些位置保证都是 null）。给出这样的数组 h，把它转换成 LeetCode 层序数组（末尾不留 null）。h 为空或根是 null 时，树是空的，返回空数组。数据范围：h 的长度 ≤ 4095。

样例 1：h = [1, null, 2, null, null, 3]，答案 [1, null, 2, 3]。下标 0 是根 1，它的孩子在下标 1、2，分别是 null 和 2；下标 1 是空位，它下面的下标 3、4 也是 null；2 在下标 2，左孩子在下标 2×2+1 = 5，是 3。所以这棵树是：1 只有右孩子 2，2 只有左孩子 3，写成 LeetCode 格式就是 [1, null, 2, 3]。

样例 2：h = [5, 4, null, 3]，答案 [5, 4, null, 3]。5 的孩子是下标 1 的 4 和下标 2 的 null；4 的左孩子在下标 3，是 3。LeetCode 格式依次写 5、4、null，再给 4 的两个孩子留位置，写 3，末尾的 null 删去，结果恰好和 h 相同。

样例 3：h = [null, null, null]，答案 []。根是 null，整棵树为空。

提示

两步拼起来：先按堆下标递归建树，下标越界或者是 null 就返回空，否则左孩子取 2i+1，右孩子取 2i+2；再用 11.1-2 的 toLevelArray 写回去。容易错的边界有两个：根是 null 时整棵树为空；数组长度不一定是 2^k − 1，所以越界要当作空。中间建的树只是临时用，转换完要 freeTree。

参考答案
// 按堆下标建子树：h 是“堆下标格式”的数组（下标 i 的孩子在 2i+1、2i+2，NIL 表示空位置），
// 返回以 h[i] 为根的子树；i 越界或 h[i] 是 NIL 时返回 nullptr。NIL、TreeNode 见 11.1。
TreeNode* heapToTree(const vector<int>& h, size_t i) {          // 用堆下标 i 处的值建子树
    if (i >= h.size() || h[i] == NIL) return nullptr;          // 越界或空位置
    TreeNode* node = new TreeNode(h[i]);                       // node = 当前子树的根，值是 h[i]
    node->left = heapToTree(h, 2 * i + 1);                      // 堆下标：左孩子在 2i+1
    node->right = heapToTree(h, 2 * i + 2);                     // 右孩子在 2i+2
    return node;
}
// 把堆下标格式的数组 h 转成 LeetCode 层序数组并返回。toLevelArray 是练习 11.1-2 的函数；
// freeTree(root) 释放整棵树（练习文件里的辅助函数）。
vector<int> heapToLevelArray(const vector<int>& h) {
    TreeNode* root = heapToTree(h, 0);                          // root = 临时树的根：先建临时树；根是 null 时得到空树
    vector<int> out = toLevelArray(root);                       // out = 结果：再写回 LeetCode 格式
    freeTree(root);                                             // 临时树用完就释放
    return out;
}
# 按堆下标建子树：h 是“堆下标格式”的列表（下标 i 的孩子在 2i+1、2i+2，None 表示空位置），
# 返回以 h[i] 为根的子树；i 越界或 h[i] 是 None 时返回 None。
def heap_to_tree(h, i):                                        # 用堆下标 i 处的值建子树
    if i >= len(h) or h[i] is None: return None                # 越界或空位置
    node = TreeNode(h[i])                                      # node = 当前子树的根，值是 h[i]
    node.left = heap_to_tree(h, 2 * i + 1)                     # 堆下标：左孩子在 2i+1
    node.right = heap_to_tree(h, 2 * i + 2)                    # 右孩子在 2i+2
    return node

# 把堆下标格式的列表 h 转成 LeetCode 层序列表并返回。to_level_array 是练习 11.1-2 的函数。
def heap_to_level_array(h):
    root = heap_to_tree(h, 0)                                   # root = 临时树的根：先建临时树；根是 null 时得到空树
    return to_level_array(root)                                 # Python 自动回收，不用 freeTree

易错点

  • 层序数组只给"存在的节点"留孩子位置。把 [1,null,2,3] 按"下标 i 的孩子在 2i+1"去读，会把 3 放错层；用队列读就对了：3 是 2 的左孩子。
  • 访问 a[i+1] 前要先判断 i + 1 < a.size()，数组在左孩子处结束的情况很常见。
  • 递归的第 1 个问题最容易漏：先写 if (root == nullptr) return ...;，再写其余逻辑。

小结： 建树时用队列，队首节点依次认领数组中接下来的两个元素作为孩子；写树的递归前先回答三个问题：空节点返回什么、怎样由左右子树得出当前结果、答案放在哪里。

11.2 深度优先遍历：前序、中序、后序的递归与迭代写法 选读

当题目要求按某种顺序输出所有节点，或者要求不使用递归时，就要用到本节的遍历方法。二叉搜索树的题目（11.7）大多依赖中序遍历。

前序、中序、后序的区别在于何时访问根节点：前序是根、左、右，中序是左、根、右，后序是左、右、根（定义见 16.3）。递归写法中，三者的差别只是“访问”这一行代码放在两次递归调用之前、之间还是之后。迭代写法用一个显式的栈来完成递归时调用栈所做的事情：记住处理完当前子树后还要回到哪个节点。

本节所有遍历都用这棵树：[1,2,3,4,5,null,6]

递归写法

下面三个函数分别按前序、中序、后序，把以 node 为根的树的节点值依次追加到 out 的末尾。调用前 out 通常是空的，调用后 out 就是对应的遍历序列。

// 三种递归遍历：node 是当前子树的根（可以为空），按对应顺序把节点值追加到 out 末尾（out 会被修改）。
// TreeNode 是 11.1 的二叉树节点：val = 值，left / right = 左、右孩子指针。前序：根、左、右。
void preorderDfs(TreeNode* node, vector<int>& out) {
    if (node == nullptr) return;     // 空树：什么也不追加
    out.push_back(node->val);        // 根
    preorderDfs(node->left, out);    // 左
    preorderDfs(node->right, out);   // 右
}
// 中序：左、根、右。
void inorderDfs(TreeNode* node, vector<int>& out) {
    if (node == nullptr) return;     // 空树直接返回
    inorderDfs(node->left, out);     // 左
    out.push_back(node->val);        // 根：夹在中间
    inorderDfs(node->right, out);    // 右
}
// 后序：左、右、根。
void postorderDfs(TreeNode* node, vector<int>& out) {
    if (node == nullptr) return;     // 空树直接返回
    postorderDfs(node->left, out);   // 左
    postorderDfs(node->right, out);  // 右
    out.push_back(node->val);        // 根：最后才访问
}
# 三种递归遍历：node 是当前子树的根（可以为 None），按对应顺序把节点值追加到 out 末尾。前序：根、左、右。
def preorder_dfs(node, out):         # out 对应 vector<int>&：传进来的是同一个列表，append 调用者能看到
    if node is None: return          # 空树：什么也不追加
    out.append(node.val)             # 根
    preorder_dfs(node.left, out)     # 左
    preorder_dfs(node.right, out)    # 右

# 中序：左、根、右。
def inorder_dfs(node, out):
    if node is None: return          # 空树直接返回
    inorder_dfs(node.left, out)      # 左
    out.append(node.val)             # 根：夹在中间
    inorder_dfs(node.right, out)     # 右

# 后序：左、右、根。
def postorder_dfs(node, out):
    if node is None: return          # 空树直接返回
    postorder_dfs(node.left, out)    # 左
    postorder_dfs(node.right, out)   # 右
    out.append(node.val)             # 根：最后才访问

前序遍历的迭代写法

栈 st 中存放已经发现、但还没有访问的子树的根，并且栈顶总是前序序列中的下一个节点。开始时把根压入栈。每一步弹出栈顶并输出，然后先压入右孩子，再压入左孩子：栈是后进先出的，后压入的左孩子会先弹出，所以整棵左子树会在右子树之前处理完，顺序正好是根、左、右。栈为空时，所有节点都已输出；空树直接返回空数组。

// 前序遍历的迭代写法：返回以 root 为根的树的前序序列；空树返回空数组。
// TreeNode 是 11.1 的二叉树节点：val = 值，left / right = 左、右孩子指针。
vector<int> preorderIter(TreeNode* root) {
    vector<int> out;                               // out = 前序序列
    if (root == nullptr) return out;               // 空树返回空数组
    stack<TreeNode*> st;                           // st = 已发现、还没访问的子树根；栈顶是下一个要输出的
    st.push(root);
    while (!st.empty()) {                          // 栈空 = 全部输出完
        TreeNode* node = st.top(); st.pop();       // node = 这次要访问的节点
        out.push_back(node->val);                  // 出栈即访问
        if (node->right) st.push(node->right);     // 先压右
        if (node->left) st.push(node->left);       // 后压左，左先出栈
    }
    return out;
}

def preorder_iter(root):
    out = []                                       # out = 前序序列
    if root is None: return out                    # 空树返回空数组
    st = []                                        # st = 已发现、还没访问的子树根；Python 用 list 当栈：append 压栈，pop() 弹出栈顶
    st.append(root)
    while st:                                      # 栈空 = 全部输出完
        node = st.pop()                            # node = 这次要访问的节点
        out.append(node.val)                       # 出栈即访问
        if node.right: st.append(node.right)       # 先压右
        if node.left: st.append(node.left)         # 后压左，左先出栈
    return out

中序遍历的迭代写法

中序遍历要在左子树全部处理完之后才访问根，所以第一次遇到一个节点时还不能输出它，只能先压入栈中，等它的左子树处理完再输出。

cur 是下一棵要处理的子树的根，栈中保存的是左子树正在处理、自身尚未输出的祖先节点。每一轮先从 cur 出发沿左孩子一直向下走，把经过的节点依次压栈；走到空时，栈顶节点的左子树已经处理完，于是弹出并输出它，再令 cur 指向它的右孩子，对右子树重复同样的过程。当 cur 为空且栈也为空时，遍历结束。

// 中序遍历的迭代写法：返回以 root 为根的树的中序序列；空树返回空数组。
// TreeNode 是 11.1 的二叉树节点：val = 值，left / right = 左、右孩子指针。
vector<int> inorderIter(TreeNode* root) {
    vector<int> out;                               // out = 中序序列
    stack<TreeNode*> st;                           // st = 左子树正在处理、自己还没输出的祖先
    TreeNode* cur = root;                          // cur = 下一棵要处理的子树的根（空表示这棵子树为空）
    while (cur != nullptr || !st.empty()) {        // cur 和栈都空才结束
        while (cur != nullptr) {                   // 沿左链一路压栈
            st.push(cur);
            cur = cur->left;
        }
        cur = st.top(); st.pop();                  // 左边已走完，弹出访问
        out.push_back(cur->val);                   // 访问 cur
        cur = cur->right;                          // 转向右子树
    }
    return out;
}
# 中序遍历的迭代写法：返回以 root 为根的树的中序序列；空树返回 []。
def inorder_iter(root):
    out = []                                       # out = 中序序列
    st = []                                        # st = 左子树正在处理、自己还没输出的祖先
    cur = root                                     # cur = 下一棵要处理的子树的根（None 表示这棵子树为空）
    while cur is not None or st:                   # cur 和栈都空才结束
        while cur is not None:                     # 沿左链一路压栈
            st.append(cur)
            cur = cur.left
        cur = st.pop()                             # 左边已走完，弹出访问
        out.append(cur.val)                        # 访问 cur
        cur = cur.right                            # 转向右子树
    return out

// TreeNode 是 11.1 的二叉树节点：val = 值，left / right = 左、右孩子指针。
vector<int> postorderIter(TreeNode* root) {
    vector<int> out;                               // out = 先存“根 右 左”序列，最后反转成后序
    if (root == nullptr) return out;               // 空树返回空数组
    stack<TreeNode*> st;                           // st = 已发现、还没访问的子树根
    st.push(root);
    while (!st.empty()) {                          // 和前序迭代一样，只是左右压栈顺序对调
        TreeNode* node = st.top(); st.pop();       // node = 这次要访问的节点
        out.push_back(node->val);                  // 得到"根 右 左"
        if (node->left) st.push(node->left);       // 先压左
        if (node->right) st.push(node->right);     // 后压右，右先出栈
    }
    reverse(out.begin(), out.end());               // 反转成"左 右 根"
    return out;                                    // 后序序列
}

def postorder_iter(root):

        if node.left: st.append(node.left)         # 先压左
        if node.right: st.append(node.right)       # 后压右，右先出栈
    out.reverse()                                  # 原地反转成"左 右 根"（out[::-1] 会另建一个新列表）
    return out                                     # 后序序列

// 后序遍历的迭代写法（prev 法）：不反转，直接按“左 右 根”输出。返回后序序列；空树返回空数组。
// TreeNode 是 11.1 的二叉树节点：val = 值，left / right = 左、右孩子指针。
vector<int> postorderIterPrev(TreeNode* root) {
    vector<int> out;                               // out = 后序序列
    stack<TreeNode*> st;                           // st = 还没输出的祖先
    TreeNode* cur = root;                          // cur = 下一棵要处理的子树的根
    TreeNode* prev = nullptr;                      // prev = 上一个输出的节点
    while (cur != nullptr || !st.empty()) {        // cur 和栈都空才结束
        while (cur != nullptr) { st.push(cur); cur = cur->left; }   // 沿左链一路压栈
        TreeNode* top = st.top();                  // top = 栈顶节点：只看，先不弹出
        // 右孩子存在、且不是刚输出的那个 → 右子树还没处理
        if (top->right != nullptr && top->right != prev) {
            cur = top->right;                      // 右子树还没处理：先去右边
        } else {
            st.pop();                              // 左右都处理完：输出根
            out.push_back(top->val);
            prev = top;                            // 记住刚输出的是谁；cur 保持空，下一轮直接看栈顶
        }
    }
    return out;
}

114 二叉树展开为链表

题面：给一棵二叉树的根 root，把这棵树 原地 展开成一条"链表"。原地的意思是不新建节点，只修改已有节点的 left、right 指针。展开后的节点仍是 11.1 的 TreeNode：每个节点的 left 都为空，right 指向链表里的下一个节点，最后一个节点的 right 为空；节点在链表中的先后顺序就是原树的前序（根、左、右）顺序。函数没有返回值，结果就是修改后的这棵树。树中节点数在 0 到 2000 之间，节点值在 −100 到 100 之间。进阶要求：只用 O(1) 的额外空间。[3]

样例 1：root = [1, 2, 5, 3, 4, null, 6]，展开后写成层序数组是 [1, null, 2, null, 3, null, 4, null, 5, null, 6]。原树先是根 1，再是左子树（根 2，孩子 3、4），最后是右子树（根 5，右孩子 6），前序为 1、2、3、4、5、6。把这 6 个节点用 right 依次串起来、left 全部置空，就是答案；层序数组里每个值后面的 null 就是这个节点空着的左孩子。

样例 2：root = []，答案 []。空树没有节点，什么也不用改。

样例 3：root = [0]，答案 [0]。只有一个节点，它的两个指针本来就是空的，已经是一条长度为 1 的链。

思路。 题目要的顺序正是前序，本节刚写过前序遍历。所以先用它直接拼出一个解法，再把它改成只用 O(1) 额外空间的写法。

第一步：先存下前序，再重新连接。 把 preorderDfs 里追加 node->val 的那一行改成追加节点指针 node，就能按前序得到全部节点。样例 1 得到的数组依次是节点 1、2、3、4、5、6。然后从头到尾走一遍：第 k 个节点的 left 置空，right 指向第 k+1 个节点，最后一个节点的 right 置空。必须先把节点全部存好再改指针：如果一边遍历一边改 right，还没走到的右子树就找不到了。

这一步用到两个变量：

  • nodes：按前序存放的节点指针，nodes[k] 是前序第 k 个节点（从 0 数）。
  • k：正在重新连接的节点在 nodes 中的下标。
// 114 解法一的辅助函数：和 preorderDfs 写法相同，只是按前序把节点指针（而不是值）追加到 nodes 末尾。
// node 是当前子树的根（可以为空，空树什么也不追加）；nodes 会被修改；无返回值。TreeNode 见 11.1。
void collectPreorder(TreeNode* node, vector<TreeNode*>& nodes) {
    if (node == nullptr) return;          // 空树：什么也不追加
    nodes.push_back(node);                // 根：存节点本身，后面要改它的指针
    collectPreorder(node->left, nodes);   // 左
    collectPreorder(node->right, nodes);  // 右
}
// 114 二叉树展开为链表，解法一：先按前序把节点存进数组，再依次重新连接。root 是树根（可以为空，空树不做任何事）。
// 原地修改，不新建节点：每个节点的 left 置空，right 指向前序的下一个节点；无返回值。时间 O(n)，额外空间 O(n)。
void flattenByList(TreeNode* root) {
    vector<TreeNode*> nodes;                       // nodes[k] = 前序第 k 个节点
    collectPreorder(root, nodes);                  // 先存完，再改指针
    for (int k = 0; k < (int)nodes.size(); ++k) {  // k = 正在连接的节点下标
        nodes[k]->left = nullptr;                  // 链表里不用左指针
        nodes[k]->right = (k + 1 < (int)nodes.size()) ? nodes[k + 1] : nullptr;   // 指向前序下一个；最后一个指向空
    }
}

# 原地修改，不新建节点：每个节点的 left 置空，right 指向前序的下一个节点；无返回值。时间 O(n)，额外空间 O(n)。
def flatten_by_list(root):

这个解法正确，时间 O(n)。但数组 nodes 存了全部 n 个节点，额外空间是 O(n)，不满足进阶要求。

第二步：不存数组，直接在树上搬动子树。 还看样例 1 的根 1。它的前序是 1，接着是左子树的前序 2、3、4，最后是右子树的前序 5、6。展开以后，1 的 right 应该指向 2；右子树的开头 5 应该紧跟在左子树前序的最后一个节点 4 后面。而 4 正是从左孩子 2 出发、沿 right 一直走到头的节点。所以对节点 1 做三件事：

  1. 从 1 的左孩子 2 出发，沿 right 一直走，走到没有右孩子的节点 4。
  2. 把 1 原来的右子树（以 5 为根）挂到 4 的 right 上。
  3. 把 1 的左子树搬到右边：1 的 right 改为 2，left 置空。

搬完以后，从 1 开始按前序读这棵树，仍然是 1、2、3、4、5、6。原因是：前序遍历左子树时，沿 right 走到底的那个节点（这里是 4）连同它下面的节点是最后走到的，走完它们整棵左子树就走完了，所以挂在它 right 上的右子树正好排在整棵左子树后面。每这样搬一次，前序顺序不变，而当前节点不再有左孩子。

接着沿 right 走到下一个节点，做同样的事；遇到没有左孩子的节点就直接往右走。走出链尾时，每个节点都没有左孩子，整棵树就成了一条按前序排列的链。

代码中的变量：

  • cur：正在处理的节点。从根开始，每轮沿 right 前进一步；它前面的节点都已排成链，left 都为空。
  • rightmost：从 cur 的左孩子出发、沿 right 走到头的节点，cur 的右子树要挂在它下面。

步骤：

  1. 令 cur = root。
  2. 若 cur 为空，结束。否则，若 cur 有左孩子：从 cur->left 出发沿 right 走到头得到 rightmost，令 rightmost->right = cur->right，再令 cur->right = cur->left、cur->left = nullptr。
  3. 令 cur = cur->right，回到第 2 步。

        cur = cur->right;                          // 处理链上的下一个节点

# 对每个有左孩子的节点：把它的右子树挂到左子树沿 right 走到头的节点下面，再把左子树整个搬到右边。
def flatten(root):
    cur = root                                     # cur = 正在处理的节点；它前面的节点都已排成链
    while cur is not None:                         # 沿 right 走出链尾就结束
        if cur.left is not None:                   # 有左子树才需要搬
            rightmost = cur.left                   # rightmost = 从左孩子出发沿 right 走到头的节点
            while rightmost.right is not None:
                rightmost = rightmost.right
            rightmost.right = cur.right            # 先把右子树挂到它后面
            cur.right = cur.left                   # 再把左子树搬到右边
            cur.left = None                        # 左指针置空
        cur = cur.right                            # 处理链上的下一个节点

每个节点恰好当一次 cur。找 rightmost 时走过的节点，搬完后都落在 cur 往右的链上，以后不会再出现在任何节点的左子树里，所以每个节点最多被这样走过一次。时间 O(n)，额外空间只有两个指针，是 O(1)。

易错点

  • 先挂右子树，再搬左子树。如果先写 cur->right = cur->left，原来的右子树就没有指针指向它，丢失了。
  • 搬完要把 cur->left 置空。漏掉这一句，左孩子会同时被 left 和 right 指着，结果不是链表。
  • rightmost 要从 cur->left 出发往右走。从 cur 自己出发，走到的是右子树沿 right 的尽头，挂错了位置。
  • 解法一必须先收集完全部节点再改指针，边遍历边改会丢掉还没访问的右子树。

// 按前序列出家谱树里每个人和他是第几代：返回 (值, 代数) 的数组，根是第 1 代；空树返回空数组。
// TreeNode 是 11.1 的二叉树节点：val = 值，left / right = 左、右孩子指针。
vector<pair<int, int>> preorderWithDepth(TreeNode* root) {
    vector<pair<int, int>> out;                        // out = 按前序记录的 (值, 第几代)
    if (root == nullptr) return out;                   // 空树：没有人
    stack<pair<TreeNode*, int>> st;                    // st = 栈，存 (节点, 代数)
    st.push({root, 1});                                // 根是第 1 代
    while (!st.empty()) {                              // 栈空 = 全部访问完
        auto [node, d] = st.top(); st.pop();           // node = 这次要访问的节点，d = 它是第几代
        out.push_back({node->val, d});                 // 弹出即访问
        if (node->right) st.push({node->right, d + 1});   // 先压右；孩子比自己多一代
        if (node->left) st.push({node->left, d + 1});     // 后压左，左先出栈
    }
    return out;
}

练习 11.2-2【变形】排行榜从高到低：反向中序 选做

题面：成绩存在一棵二叉搜索树（BST）里。BST 是这样一种二叉树：每个节点左子树里的值都比它小，右子树里的值都比它大；这里的值互不相同。用显式栈（不用递归）从大到小输出前 k 个成绩；k 超过节点数时，把所有成绩从大到小全部输出；k = 0 时输出空数组。数据范围：节点数 ≤ 10^5，0 ≤ k ≤ 10^5。

样例 1：root = [5, 3, 8, 2, 4, null, 9]，k = 3，答案 [9, 8, 5]。树里的成绩是 2、3、4、5、8、9，最大的三个从大到小是 9、8、5。

样例 2：同一棵树，k = 0，答案 []。一个也不要。

样例 3：root = [2, 1]，k = 5，答案 [2, 1]。树里只有 2 个成绩，k 比节点数大，就全部输出。

提示

中序"左根右"在 BST 上是升序，把左右对调成"右根左"就是降序。所以只改中序迭代的一处：沿左链压栈改成沿右链压栈，弹出后转向左子树。另一处小变化是外层循环多一个条件 out.size() < k，拿够了立刻停，不必走完整棵树。

// 在二叉搜索树 root 里按从大到小取前 k 个值（反向中序：右、根、左）。节点不足 k 个时返回全部。
// TreeNode 是 11.1 的二叉树节点：val = 值，left / right = 左、右孩子指针。
vector<int> topKDescending(TreeNode* root, int k) {
    vector<int> out;                                                 // out = 已取出的值，从大到小

        cur = st.top(); st.pop();                                    // 栈顶是剩下的最大值
        out.push_back(cur->val);
        cur = cur->left;                                             // 转向左子树
    }
    return out;                                                      // 不足 k 个就是全部节点
}

练习 11.2-3【综合】部门子树和：不用递归的后序 选做

题面：每个节点存一个整数，可能为负。一个节点的"子树"是它自己加上它下面的全部节点，"子树和"是子树里所有节点值的和。按后序（先左子树，再右子树，最后根）的顺序，返回每个节点的子树和；空树返回空数组。数据范围：节点数 ≤ 10^5，|val| ≤ 10^9；树可能是一条长链，必须用显式栈。

样例 1：root = [1, 2, 3, null, 4]，答案 [4, 6, 3, 10]。1 的孩子是 2 和 3，2 只有右孩子 4。后序依次是 4、2、3、1：4 的子树只有自己，和为 4；2 的子树是 2 和 4，和为 6；3 的和为 3；1 的子树是整棵树，和为 1 + 2 + 3 + 4 = 10。

样例 2：root = [-5]，答案 [-5]。只有一个节点，它的子树和就是它自己的值。

样例 3：root = []，答案 []。

提示

用本节 postorderIterPrev 的 prev 指针写法：一个节点出栈时，它的左右子树都已经处理完，左右孩子的子树和都已经算好。用哈希表 sum[节点] 存已经算好的子树和，出栈时把自己的值加上左右孩子的子树和，空孩子按 0 算。两个坑：反转法（根右左再反转）做不到"孩子先算好"，因为它访问根的时候孩子还没算；10^5 个 10^9 相加会超过 int，所以和要用 long long。

参考答案
// 不用递归，按后序算出每个节点的子树和（自己加上所有后代的值），按后序顺序返回；空树返回空数组。
// TreeNode 是 11.1 的二叉树节点：val = 值，left / right = 左、右孩子指针。
vector<long long> subtreeSumsPost(TreeNode* root) {
    vector<long long> out;                             // out = 按后序排列的子树和
    unordered_map<TreeNode*, long long> sum;           // sum[node] = 已经出栈的节点 node 的子树和
    stack<TreeNode*> st;                               // st = 还没输出的祖先
    TreeNode* cur = root;                              // cur = 下一棵要处理的子树的根
    TreeNode* prev = nullptr;                          // prev = 上一个出栈的节点
    while (cur != nullptr || !st.empty()) {
        while (cur != nullptr) { st.push(cur); cur = cur->left; }   // 沿左链压栈
        TreeNode* top = st.top();                                   // top = 栈顶节点，先不弹出
        if (top->right != nullptr && top->right != prev) {          // 右孩子存在、且不是刚出栈的那个
            cur = top->right;                          // 右子树还没处理
        } else {
            st.pop();                                  // 左右孩子都已算好
            long long s = top->val;                    // s = top 的子树和，先放自己的值；long long：大量 10^9 相加会超 int
            if (top->left) s += sum[top->left];        // 加左子树和（空孩子按 0）
            if (top->right) s += sum[top->right];      // 加右子树和
            sum[top] = s;                              // 存起来，给父节点用
            out.push_back(s);
            prev = top;                                // 记住刚出栈的是谁
        }
    }
    return out;
}
# 不用递归，按后序算出每个节点的子树和（自己加上所有后代的值），按后序顺序返回；空树返回 []。
def subtree_sums_post(root):
    out = []                                           # out = 按后序排列的子树和
    total = {}                                         # total[node] = 已经出栈的节点 node 的子树和；节点对象可以直接当键
    st = []                                            # st = 还没输出的祖先
    cur = root                                         # cur = 下一棵要处理的子树的根
    prev = None                                        # prev = 上一个出栈的节点
    while cur is not None or st:
        while cur is not None:                         # 沿左链压栈
            st.append(cur)
            cur = cur.left
        top = st[-1]                                   # top = 栈顶节点，先不弹出
        if top.right is not None and top.right is not prev:  # 右孩子存在、且不是刚出栈的那个
            cur = top.right                            # 右子树还没处理
        else:
            st.pop()                                   # 左右孩子都已算好
            s = top.val                                # s = top 的子树和，先放自己的值
            if top.left: s += total[top.left]          # 加左子树和（空孩子按 0）
            if top.right: s += total[top.right]        # 加右子树和
            total[top] = s                             # 存起来，给父节点用
            out.append(s)
            prev = top                                 # 记住刚出栈的是谁
    return out

易错点

  • 前序迭代压栈顺序写反（先左后右）会得到"根右左"。记法：想让谁先出来，就后压谁。
  • 中序迭代的外层循环条件是 cur != nullptr || !st.empty()，两者缺一都会提前结束：刚转向右子树时栈可能已空，而 cur 还有一整棵树。
  • 后序用"反转"时，压栈顺序要和前序相反（先左后右）；用 prev 写法时，判断条件是 top->right != prev，漏掉它会在右子树里来回绕。

小结： 前序迭代弹出即输出，先压右孩子再压左孩子；中序迭代先把左侧路径全部压栈，弹出时输出并转向右孩子；后序迭代按先左后右的顺序压栈得到根、右、左，再整体反转。

102 二叉树的层序遍历

题面：给一棵二叉树，按层返回节点值：结果的第 1 行是根所在的第 1 层，第 2 行是根的孩子所在的第 2 层，依此类推；每一行里的值按从左到右的顺序排列。空树返回空数组。

// 102 层序遍历：按层返回节点值，res[k] = 第 k 层（根是第 0 层）从左到右的值；空树返回空数组。
// TreeNode 是 11.1 的二叉树节点：val = 值，left / right = 左、右孩子指针。
vector<vector<int>> levelOrder(TreeNode* root) {
    vector<vector<int>> res;                       // res[k] = 第 k 层从左到右的值
    if (root == nullptr) return res;               // 空树返回空数组
    queue<TreeNode*> q;                            // 每轮开始时恰好是同一层的全部节点
    q.push(root);
    while (!q.empty()) {                           // 还有下一层
        int sz = (int)q.size();                    // sz = 这一层的节点数，先固定下来
        vector<int> level;                         // level = 这一层从左到右的值
        for (int i = 0; i < sz; ++i) {             // i = 本层第几个；只出队本层的 sz 个
            TreeNode* node = q.front(); q.pop();   // node = 本层当前出队的节点
            level.push_back(node->val);
            if (node->left) q.push(node->left);    // 下一层的节点排在后面
            if (node->right) q.push(node->right);
        }
        res.push_back(level);                      // 本层收集完
    }
    return res;
}
# 102 层序遍历：按层返回节点值，res[k] = 第 k 层（根是第 0 层）从左到右的值；空树返回 []。
def level_order(root):
    res = []                             # res[k] = 第 k 层从左到右的值
    if root is None: return res          # 空树返回空数组
    q = deque()                          # q = 待处理的节点；每轮开始时恰好是同一层的全部节点
    q.append(root)
    while q:                             # 还有下一层
        sz = len(q)                      # sz = 这一层的节点数，先固定下来
        level = []                       # level = 这一层从左到右的值
        for _ in range(sz):              # _ = 本层第几个（用不到）；range(len(q)) 也行：range 在进入循环时就固定了本层长度
            node = q.popleft()           # node = 本层当前出队的节点；popleft 是 O(1)；list.pop(0) 是 O(n)
            level.append(node.val)
            if node.left: q.append(node.left)      # 下一层的节点排在后面
            if node.right: q.append(node.right)
        res.append(level)                # 本层收集完
    return res

时间 O(n)。队列中最多同时存放一整层：根为第 1 层时，第 i 层最多有 2^(i−1) 个节点，所以空间是 O(树的最大宽度)。

Python 中的队列要用 collections.deque，它的 popleft() 是 O(1)；如果用 list.pop(0)，每次都要把后面的所有元素前移一位，是 O(n)。[4]

// 105 的切片写法：每层都把数组切成小数组再递归，和上面的图一一对应。
// preorder、inorder 是同一棵树（值互不相同）的前序、中序序列，返回根；数组为空返回 nullptr。
TreeNode* buildTreeSlice(const vector<int>& preorder, const vector<int>& inorder) {
    if (preorder.empty()) return nullptr;                  // 空数组 = 空子树
    TreeNode* root = new TreeNode(preorder[0]);            // 前序第一个是根
    int leftSize = find(inorder.begin(), inorder.end(), preorder[0]) - inorder.begin();   // 根在中序里的下标 = 左子树节点数
    vector<int> preL(preorder.begin() + 1, preorder.begin() + 1 + leftSize);   // 前序：根后面紧跟的 leftSize 个是左子树
    vector<int> preR(preorder.begin() + 1 + leftSize, preorder.end());         // 再往后是右子树
    vector<int> inL(inorder.begin(), inorder.begin() + leftSize);              // 中序：根左边是左子树
    vector<int> inR(inorder.begin() + leftSize + 1, inorder.end());            // 根右边是右子树
    root->left = buildTreeSlice(preL, inL);                // 左右两对小数组各自递归
    root->right = buildTreeSlice(preR, inR);
    return root;
}

def build_tree_slice(preorder, inorder):

    left_size = inorder.index(preorder[0])                 # 根在中序里的下标 = 左子树节点数

在样例 1 上：第一层 leftSize = 1，切出左边的一对 [9]、[9] 和右边的一对 [20, 15, 7]、[15, 20, 7]，正是图里的第一步。

这个写法是对的，但每一层都要复制出新数组，在中序里找根也要从头扫。树退化成一条链时，每层都要复制和扫描约 n 个元素，总共 O(n²)。

不复制：下标写法。 切出来的每一对小数组，其实都是原数组里连续的一段。所以不必真的复制，只要记住"这一段在原数组里从哪到哪"就行。两种写法一一对应：

代码用下标来表示"当前这棵子树"。递归函数 buildPreIn 里，前序序列叫 pre，各个名字的含义如下：

  • pl、pr：当前子树在前序序列中占的下标区间 [pl, pr]，两端都含。
  • il：当前子树在中序序列中开始的下标。同一棵子树在两个序列中长度相同，所以中序只需记起点。
  • pos：事先建好的哈希表，pos[v] 是值 v 在中序序列中的下标。
  • k：根在中序序列中的下标，即 pos[pre[pl]]。
  • leftSize：左子树的节点数，等于 k − il，也就是中序中根左边那一段的长度。

先用样例 1 算第一层。整棵树在前序中占 [0, 4]，在中序中从 0 开始。根是 pre[0] = 3，查得 k = pos[3] = 1，leftSize = 1 − 0 = 1，左子树只有 1 个节点。前序中紧跟在根后面的 1 个元素，即下标 1 的 9，是左子树；其余的下标 2 到 4，即 20、15、7，是右子树。中序中，左子树从下标 0 开始，右子树从根的下一个位置 k + 1 = 2 开始。

一般地，左子树在前序中是 [pl+1, pl+leftSize]、在中序中从 il 开始；右子树在前序中是 [pl+leftSize+1, pr]、在中序中从 k+1 开始。区间为空（pl > pr）时返回 nullptr。这一做法要求节点值互不相同，否则无法唯一确定根在中序中的位置。

// pos[v] = 值 v 在中序里的下标。返回当前子树的根；区间为空返回 nullptr。TreeNode 见 11.1。
TreeNode* buildPreIn(const vector<int>& pre, int pl, int pr, int il, unordered_map<int, int>& pos) {
    if (pl > pr) return nullptr;                   // 空区间 = 空子树
    TreeNode* root = new TreeNode(pre[pl]);        // root = 当前子树的根：前序第一个就是根
    int k = pos[pre[pl]];                          // k = 根在中序里的下标
    int leftSize = k - il;                         // leftSize = 左子树节点数（中序里根左边那一段的长度）
    // 左子树：前序 [pl+1, pl+leftSize]，中序从 il 开始
    root->left = buildPreIn(pre, pl + 1, pl + leftSize, il, pos);
    // 右子树：前序 [pl+leftSize+1, pr]，中序从 k+1 开始
    root->right = buildPreIn(pre, pl + leftSize + 1, pr, k + 1, pos);
    return root;
}
// 105 从前序与中序遍历序列构造二叉树：preorder、inorder 是同一棵树（值互不相同）的前序、中序序列，返回根。
TreeNode* buildTreePreIn(const vector<int>& preorder, const vector<int>& inorder) {
    unordered_map<int, int> pos;                   // pos[v] = 值 v 在中序里的下标（要求值互不相同）
    for (int i = 0; i < (int)inorder.size(); ++i) pos[inorder[i]] = i;  // i = 中序下标：先把每个值的位置存好
    return buildPreIn(preorder, 0, (int)preorder.size() - 1, 0, pos);   // 整棵树：前序全区间，中序从 0 开始
}
# 105 的递归部分：当前子树的前序是 pre[pl..pr]（闭区间），它的中序从下标 il 开始；
# pos[v] = 值 v 在中序里的下标。返回当前子树的根；区间为空返回 None。
def build_pre_in(pre, pl, pr, il, pos):
    if pl > pr: return None                        # 空区间 = 空子树
    root = TreeNode(pre[pl])                       # root = 当前子树的根：前序第一个就是根
    k = pos[pre[pl]]                               # k = 根在中序里的下标
    left_size = k - il                             # left_size = 左子树节点数（中序里根左边那一段的长度）
    root.left = build_pre_in(pre, pl + 1, pl + left_size, il, pos)          # 左：前序 [pl+1, pl+left_size]
    root.right = build_pre_in(pre, pl + left_size + 1, pr, k + 1, pos)      # 右：中序从 k+1 开始
    return root

# 105 从前序与中序遍历序列构造二叉树：preorder、inorder 是同一棵树（值互不相同）的前序、中序序列，返回根。
def build_tree_pre_in(preorder, inorder):
    pos = {}                                       # pos[v] = 值 v 在中序里的下标（要求值互不相同）
    for i in range(len(inorder)): pos[inorder[i]] = i  # i = 中序下标：先把每个值的位置存好
    return build_pre_in(preorder, 0, len(preorder) - 1, 0, pos)   # 整棵树：前序全区间，中序从 0 开始

练习 11.3-1【基础】每层楼最高的人 必做

题面：一栋楼的住户按二叉树排列：根在第 1 层，根的孩子在第 2 层，依此类推，第 d 层的节点就是第 d 层楼的住户，节点值是身高。树按 11.1 的层序数组给出（按层从左到右列出节点，null 表示该位置没有节点）。身高可能为负，这样可以检查最大值的初始值写得对不对。从上到下返回每层住户身高的最大值；空树返回空数组。数据范围：节点数 ≤ 10^4。

样例 1：root = [1, 3, 2, 5, 3, null, 9]，答案 [1, 3, 9]。第 1 层只有 1；第 2 层是 3、2，最大 3；第 3 层是 3 的孩子 5、3 和 2 的右孩子 9，最大 9。

样例 2：root = [-7, -8, -9]，答案 [-7, -8]。第 1 层只有 -7；第 2 层是 -8 和 -9，较大的是 -8。

样例 3：root = []，答案 []。

提示

这就是 levelOrder：先记下 sz = q.size()，再出队 sz 个，这 sz 个就是同一层。和例题相比只改一处：不再把这一层存成数组，而是维护一个最大值。初始值用本层第一个节点的值；写成 0 的话，全是负数时会出错。

// 返回每一层的最大值，out[k] = 第 k 层（根是第 0 层）的最大节点值；空树返回空数组。
// TreeNode 是 11.1 的二叉树节点：val = 值，left / right = 左、右孩子指针。
vector<int> largestPerLevel(TreeNode* root) {
    vector<int> out;                                   // out = 每层一个最大值
    if (root == nullptr) return out;                   // 空树返回空数组
    queue<TreeNode*> q;                                // q = 待处理的节点，每轮开始时恰好是同一层的全部节点
    q.push(root);
    while (!q.empty()) {                               // 还有下一层
        int sz = q.size();                             // sz = 这一层的节点数，先记下来
        int best = q.front()->val;                     // best = 本层目前的最大值；用本层第一个值初始化，负数也对
        for (int i = 0; i < sz; ++i) {                 // i = 本层第几个；只出队本层的 sz 个
            TreeNode* cur = q.front(); q.pop();        // cur = 本层当前出队的节点
            best = max(best, cur->val);                // 更新本层最大值
            if (cur->left) q.push(cur->left);          // 孩子属于下一层
            if (cur->right) q.push(cur->right);
        }
        out.push_back(best);
    }
    return out;
}

练习 11.3-2【综合】哪一层最宽 选做

题面：把二叉树放进一棵同样层数的满二叉树（每一层都排满节点的二叉树）里，每个节点占它所在位置的那一格。某一层的"宽度"是这一层最左边的非空节点到最右边的非空节点一共占几格：两端都算，夹在中间的空位也算。返回所有层宽度的最大值；空树返回 0。数据范围：节点数 ≤ 3000，树可能非常深；保证答案不超过 2^31 − 1。

样例 1：root = [1, 3, 2, 5, 3, null, 9]，答案 4。第 3 层有 4 格，从左到右是 5、3、空、9，最左的 5 到最右的 9 共 4 格；第 1、2 层的宽度是 1 和 2。

样例 2：root = [1, 3, 2, 5, null, null, 9, 6, null, 7]，答案 7。这棵树里 3 只有左孩子 5，2 只有右孩子 9，5 只有左孩子 6，9 只有左孩子 7。第 4 层共 8 格：6 在第 1 格，7 在第 7 格，从第 1 格到第 7 格是 7 格。第 3 层的 5 和 9 在第 1、4 格，宽度只有 4。

样例 3：root = [1]，答案 1。

样例 4：root = []，答案 0。

提示

按层 BFS，队列里存 (节点, 编号)：左孩子编号 2i，右孩子 2i+1，宽度 = 本层最后一个编号 − 第一个编号 + 1。坑在溢出：一条 3000 层的链，编号会到 2^3000。解决办法是每层先把编号减去本层第一个编号，改成相对编号，再算孩子的编号。题目保证答案在 int 范围内，相对编号就不会越界。C++ 里编号用 unsigned long long。

参考答案
// 返回最宽那一层的宽度：一层的宽度 = 最右节点和最左节点之间的位置数（中间的空位也算）；空树返回 0。
// 给节点按满二叉树编号：根是 0，编号 id 的左孩子是 2id、右孩子是 2id+1。TreeNode 见 11.1。
int widestLevel(TreeNode* root) {
    if (root == nullptr) return 0;                     // 空树宽度 0
    unsigned long long best = 0;                       // best = 目前最宽的层宽
    queue<pair<TreeNode*, unsigned long long>> q;      // q = 待处理的 (节点, 编号)
    q.push({root, 0});                                 // 根编号 0
    while (!q.empty()) {                               // 逐层处理
        int sz = q.size();                             // sz = 这一层的节点数
        unsigned long long first = q.front().second;   // first = 本层第一个节点的编号
        unsigned long long last = 0;                   // last = 本层最后一个节点的相对编号
        for (int i = 0; i < sz; ++i) {                 // i = 本层第几个
            auto [node, id] = q.front(); q.pop();      // node = 当前节点，id = 它的编号
            id -= first;                               // 相对编号：防止一层层累积溢出
            last = id;                                 // 本层按从左到右出队，最后一次赋值就是最右
            if (node->left) q.push({node->left, 2 * id});          // 左孩子编号 2id
            if (node->right) q.push({node->right, 2 * id + 1});    // 右孩子编号 2id+1
        }
        best = max(best, last + 1);                    // 宽度 = 最后 - 第一 + 1，第一个已是 0
    }
    return (int)best;
}
# 返回最宽那一层的宽度：一层的宽度 = 最右节点和最左节点之间的位置数（中间的空位也算）；空树返回 0。
# 给节点按满二叉树编号：根是 0，编号 idx 的左孩子是 2idx、右孩子是 2idx+1。
def widest_level(root):
    if root is None: return 0                          # 空树宽度 0
    best = 0                                           # best = 目前最宽的层宽
    q = deque([(root, 0)])                             # q = 待处理的 (节点, 编号)；根编号 0
    while q:                                           # 逐层处理
        sz = len(q)                                    # sz = 这一层的节点数
        first = q[0][1]                                # first = 本层第一个节点的编号
        last = 0                                       # last = 本层最后一个节点的相对编号
        for _ in range(sz):
            node, idx = q.popleft()                    # node = 当前节点，idx = 它的编号
            idx -= first                               # 相对编号；Python 整数不溢出，但数字小了更快
            last = idx                                 # 最后一次赋值就是最右
            if node.left: q.append((node.left, 2 * idx))          # 左孩子编号 2idx
            if node.right: q.append((node.right, 2 * idx + 1))    # 右孩子编号 2idx+1
        best = max(best, last + 1)                     # 宽度 = 最后 - 第一 + 1，第一个已是 0
    return best

易错点

  • 层序遍历内层循环要写 for (int i = 0; i < sz; ++i)，把 q.size() 直接写进循环条件会边弹边变，层就分乱了。
  • 105 切前序时按左子树的节点数切，下标是 pl + leftSize；用中序下标 k 直接去切前序是最常见的错误。
  • 只有前序和后序时一般还原不出唯一的树（16.4 的反例），必须有中序。

小结： 层序遍历先记下 sz 再出队 sz 个节点；由前序和中序重建树时，前序确定根，中序划分左右子树，再按左子树的大小切分前序。
