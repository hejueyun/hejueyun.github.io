10.1 树的表示与建树 必读

LeetCode 的树题只给出函数签名，传进来的树已经建好。自己练习和写测试时，需要先把题目中的 [1,2,3,4,5,null,6] 这样的数组变成一棵真正的树。本节先介绍树节点的表示，再写一个建树函数，后面各节的测试都使用它。

TreeNode：一个值和两个指针

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};
class TreeNode:
    def __init__(self, x):
        self.val = x
        self.left = None      # Python 没有指针：left/right 存对象引用，没有孩子时是 None（对应 nullptr）
        self.right = None

每个节点存一个值 val，再用 left、right 两个指针指向左右孩子；没有孩子时指针为 nullptr。指针和 -> 的用法见 1.11。

每个节点 = 一个值 + 两根指针；没有孩子时指针是 nullptr

LeetCode 的层序数组格式

题目中的 [1,2,3,4,5,null,6] 是按层从左到右列出的节点，null 表示这个位置没有节点。需要注意：只有实际存在的节点才在数组后面占两个位置存放它的两个孩子，空节点的孩子不再写出。因此，堆中“下标 i 的孩子是 2i+1 和 2i+2”的关系（15.9）只对完全二叉树成立；对一般的树，要用队列把数组元素和父节点对应起来。

[1,2,3,4,5,null,6]：按层从左到右；null 占位表示"这里没有节点"

用队列建树

函数输入层序数组 a（C++ 中用 NIL = INT_MIN 表示 null），返回根指针；数组为空或首元素为 null 时返回 nullptr。先用 a[0] 建根并放入队列 q，i 是下一个要读取的下标。队列中按层序存放已经建好、但还没有连上孩子的节点，并且始终满足：队首节点就是 a[i] 和 a[i+1] 的父节点。每一步弹出队首 cur，用 a[i] 建它的左孩子、a[i+1] 建右孩子（值为 null 则不建），新建的孩子放进队尾，i 增加 2。数组读完时结束；数组末尾省略不写的 null 自然被当作空节点。

const int NIL = INT_MIN;   // 层序数组里的 null
TreeNode* buildTree(const vector<int>& a) {
    if (a.empty() || a[0] == NIL) return nullptr;
    TreeNode* root = new TreeNode(a[0]);
    queue<TreeNode*> q;              // 排队等着"认领孩子"的节点
    q.push(root);
    size_t i = 1;                    // 下一个要读的数组下标
    while (!q.empty() && i < a.size()) {
        TreeNode* cur = q.front(); q.pop();
        if (a[i] != NIL) { cur->left = new TreeNode(a[i]); q.push(cur->left); }
        ++i;
        if (i < a.size() && a[i] != NIL) { cur->right = new TreeNode(a[i]); q.push(cur->right); }
        ++i;
    }
    return root;
}
def build_tree(a):
    # Python 列表可以混放 None：层序数组里的 null 直接写 None，不需要 NIL = INT_MIN
    if not a or a[0] is None: return None
    root = TreeNode(a[0])
    q = deque()                      # 排队等着"认领孩子"的节点；popleft() 是 O(1)
    q.append(root)
    i = 1                            # 下一个要读的数组下标
    while q and i < len(a):
        cur = q.popleft()
        if a[i] is not None:
            cur.left = TreeNode(a[i])
            q.append(cur.left)
        i += 1
        if i < len(a) and a[i] is not None:
            cur.right = TreeNode(a[i])
            q.append(cur.right)
        i += 1
    return root

每个数组元素只读一次，时间 O(n)；队列中最多存放一层的节点，空间 O(n)。

写树的递归前要回答的三个问题

大多数树题都是对每个节点做同样的计算，写递归函数前先回答三个问题：

  1. 空节点返回什么？ 这是递归的出口。例如求深度时，空树的深度是 0；判断对称时，两个空节点算作对称。
  2. 当前节点怎样由左右子树的结果得出自己的结果？ 假设左右子树的结果已经由递归调用正确算出，只需写出当前节点这一层的计算式。
  3. 答案是函数的返回值，还是需要另设变量记录？ 如果父节点需要的量正是题目要求的答案（如深度），直接返回即可；如果答案是父节点用不上的量，例如经过某个节点转折的路径（直径），就需要另设一个变量，在递归过程中更新，见 10.5。

maxDepth：空节点返回 0；每个节点返回 1 + max(左, 右)；根的返回值 3 就是答案

上图是 104 题“二叉树的最大深度”的三个问题：空节点返回 0；当前节点返回 1 + max(左子树深度, 右子树深度)；答案就是根节点的返回值。图中每条边上的数字是子节点返回给父节点的值。

多选 · 理解检查 1　用本节的 buildTree 读入 [1,null,2,null,3]，得到的树有几层？

A. 3 层，是一条往右下斜的链 1→2→3

B. 2 层：1 的右孩子是 2，2 的左孩子是 3

C. 按堆下标 2i+1、2i+2 读，3 在下标 4，是 2 的左孩子

D. 递归的三个问题里，求层数时空节点返回 0

查看答案与每个选项的解析

A · 正确：队列读法：1 的左为 null、右为 2；2 的左为 null、右为 3。每层一个节点，共 3 层。

B · 错误：2 的左孩子位置是 a[3]=null，右孩子才是 a[4]=3。

C · 错误：堆下标规则只适用于完全二叉树；这里的 null 节点不再给孩子留位置。

D · 正确：空树 0 层，这是 maxDepth 的递归出口。

练习 10.1-1【基础】组织架构图里有几位一线员工

题面：公司的组织架构是一棵二叉树，每位经理最多带两个直属下属，按 LeetCode 层序数组给出。没有下属的人叫"一线员工"，也就是叶子。返回叶子的个数。节点数 0 ≤ n ≤ 10^4。

样例：[1,2,3,4,5,null,6] → 3（4、5、6 三片叶子）；[] → 0；[7] → 1。

提示

递归的三个问题：空树返回 0；左右孩子都为空的节点是叶子，返回 1；其余节点返回"左子树叶子数 + 右子树叶子数"。和 maxDepth 相比，合并公式从 1 + max 换成了加法，另外多了一个"叶子"出口。

参考答案
int countLeaves(TreeNode* root) {
    if (root == nullptr) return 0;                                   // 问 1：空树没有叶子
    if (root->left == nullptr && root->right == nullptr) return 1;   // 叶子
    return countLeaves(root->left) + countLeaves(root->right);       // 问 2：左右相加
}
def count_leaves(root):
    if root is None: return 0                                        # 问 1：空树没有叶子
    if root.left is None and root.right is None: return 1            # 叶子
    return count_leaves(root.left) + count_leaves(root.right)        # 问 2：左右相加

练习 10.1-2【变形】把树写回层序数组（建树的逆操作）

题面：给定一棵树的根，输出它的 LeetCode 层序数组：按层从左到右写，空位置写 null（C++ 用 NIL），只有存在的节点才为孩子留位置，数组末尾多余的 null 要删掉。节点数 ≤ 10^4。写好以后，toLevelArray(buildTree(a)) 应该原样还给你 a（a 末尾没有 null 时）。

样例：根 1 只有右孩子 2，2 只有左孩子 3 → [1,null,2,3]；空树 → []；buildTree([1,2,3,4,5,null,6]) → [1,2,3,4,5,null,6]。

提示

还是"队列里放等着交代孩子的节点"，只是方向和 buildTree 相反：出队一个，如果它是空的，就写一个 null，然后 continue，空节点不再把孩子入队；如果非空，就写它的值，再把左右孩子入队，空孩子也要入队，因为它要在数组里占一个 null 位置。最后从数组尾部把 null 弹掉。

参考答案
vector<int> toLevelArray(TreeNode* root) {
    vector<int> out;
    queue<TreeNode*> q;
    q.push(root);
    while (!q.empty()) {
        TreeNode* cur = q.front(); q.pop();
        if (cur == nullptr) { out.push_back(NIL); continue; }   // 空位置：记 null，不再给孩子留位
        out.push_back(cur->val);
        q.push(cur->left);                                      // 空孩子也入队，它要占一个 null
        q.push(cur->right);
    }
    while (!out.empty() && out.back() == NIL) out.pop_back();   // 删掉末尾的 null
    return out;
}
def to_level_array(root):
    out = []
    q = deque([root])
    while q:
        cur = q.popleft()
        if cur is None:                                         # 空位置：记 None，不再给孩子留位
            out.append(None)
            continue
        out.append(cur.val)
        q.append(cur.left)                                      # 空孩子也入队，它要占一个 None
        q.append(cur.right)
    while out and out[-1] is None: out.pop()                    # 删掉末尾的 None
    return out

练习 10.1-3【综合】老系统的"堆下标格式"转成 LeetCode 格式

题面：老系统用堆下标存树：下标 i 的两个孩子在 2i+1 和 2i+2，空位置写 null，而且空节点下面的位置也照样占位（保证都是 null）。给出这样的数组 h（长度 ≤ 4095），把它转换成 LeetCode 层序数组。

样例：[1,null,2,null,null,3] → [1,null,2,3]（3 在下标 5 = 2×2+1，是 2 的左孩子）；[5,4,null,3] → [5,4,null,3]；[null,null,null] → []。

提示

两步拼起来：先按堆下标递归建树，下标越界或者是 null 就返回空，否则左孩子取 2i+1，右孩子取 2i+2；再用 10.1-2 的 toLevelArray 写回去。容易错的边界有两个：根是 null 时整棵树为空；数组长度不一定是 2^k − 1，所以越界要当作空。中间建的树只是临时用，转换完要 freeTree。

参考答案
TreeNode* heapToTree(const vector<int>& h, size_t i) {
    if (i >= h.size() || h[i] == NIL) return nullptr;          // 越界或空位置
    TreeNode* node = new TreeNode(h[i]);
    node->left = heapToTree(h, 2 * i + 1);
    node->right = heapToTree(h, 2 * i + 2);
    return node;
}
vector<int> heapToLevelArray(const vector<int>& h) {
    TreeNode* root = heapToTree(h, 0);
    vector<int> out = toLevelArray(root);
    freeTree(root);                                             // 临时树用完就释放
    return out;
}
def heap_to_tree(h, i):
    if i >= len(h) or h[i] is None: return None                # 越界或空位置
    node = TreeNode(h[i])
    node.left = heap_to_tree(h, 2 * i + 1)
    node.right = heap_to_tree(h, 2 * i + 2)
    return node

def heap_to_level_array(h):
    root = heap_to_tree(h, 0)
    return to_level_array(root)                                 # Python 自动回收，不用 freeTree

易错点

  • 层序数组只给"存在的节点"留孩子位置。把 [1,null,2,3] 按"下标 i 的孩子在 2i+1"去读，会把 3 放错层；用队列读就对了：3 是 2 的左孩子。
  • 访问 a[i+1] 前要先判断 i + 1 < a.size()，数组在左孩子处结束的情况很常见。
  • 递归的第 1 个问题最容易漏：先写 if (root == nullptr) return ...;，再写其余逻辑。

小结： 建树时用队列，队首节点依次认领数组中接下来的两个元素作为孩子；写树的递归前先回答三个问题：空节点返回什么、怎样由左右子树得出当前结果、答案放在哪里。

10.2 深度优先遍历：前序、中序、后序的递归与迭代写法 选读

当题目要求按某种顺序输出所有节点，或者要求不使用递归时，就要用到本节的遍历方法。二叉搜索树的题目（10.7）大多依赖中序遍历。

前序、中序、后序的区别在于何时访问根节点：前序是根、左、右，中序是左、根、右，后序是左、右、根（定义见 15.3）。递归写法中，三者的差别只是“访问”这一行代码放在两次递归调用之前、之间还是之后。迭代写法用一个显式的栈来完成递归时调用栈所做的事情：记住处理完当前子树后还要回到哪个节点。

本节所有遍历都用这棵树：[1,2,3,4,5,null,6]

前序遍历的迭代写法

栈 st 中存放已经发现、但还没有访问的子树的根，并且栈顶总是前序序列中的下一个节点。开始时把根压入栈。每一步弹出栈顶并输出，然后先压入右孩子，再压入左孩子：栈是后进先出的，后压入的左孩子会先弹出，所以整棵左子树会在右子树之前处理完，顺序正好是根、左、右。栈为空时，所有节点都已输出；空树直接返回空数组。

中序遍历的迭代写法

中序遍历要在左子树全部处理完之后才访问根，所以第一次遇到一个节点时还不能输出它，只能先压入栈中，等它的左子树处理完再输出。

cur 是下一棵要处理的子树的根，栈中保存的是左子树正在处理、自身尚未输出的祖先节点。每一轮先从 cur 出发沿左孩子一直向下走，把经过的节点依次压栈；走到空时，栈顶节点的左子树已经处理完，于是弹出并输出它，再令 cur 指向它的右孩子，对右子树重复同样的过程。当 cur 为空且栈也为空时，遍历结束。

    vector<int> out;
    stack<TreeNode*> st;

            cur = cur->left;

        out.push_back(cur->val);
        cur = cur->right;                          // 转向右子树

    st = []
    st.append(root)

        out.append(node.val)                       # 得到"根 右 左"

这种写法要先存下全部结果再反转。如果题目要求在遍历过程中按后序处理每个节点（例如逐个释放节点），可以用 prev 记录上一个输出的节点：若栈顶节点的右子树存在且尚未输出，就先转去处理右子树；否则输出栈顶节点。

vector<int> postorderIterPrev(TreeNode* root) {
    vector<int> out;
    stack<TreeNode*> st;
    TreeNode* cur = root;
    TreeNode* prev = nullptr;                      // 上一个输出的节点
    while (cur != nullptr || !st.empty()) {
        while (cur != nullptr) { st.push(cur); cur = cur->left; }
        TreeNode* top = st.top();
        if (top->right != nullptr && top->right != prev) {
            cur = top->right;                      // 右子树还没处理：先去右边
        } else {
            st.pop();                              // 左右都处理完：输出根
            out.push_back(top->val);
            prev = top;
        }
    }
    return out;
}
def postorder_iter_prev(root):
    out = []

三种迭代写法中，每个节点各进栈、出栈一次，时间 O(n)；栈中的节点不超过一条从根到叶子的路径附近的节点数，空间 O(h)，h 是树的高度。

练习 10.2-3【综合】部门子树和：不用递归的后序

题面：每个节点存一个整数（可能为负，|val| ≤ 10^9）。一个节点的"子树和"是它的子树里所有值的和。按后序（左右根）的顺序返回每个节点的子树和。节点数 ≤ 10^5，树可能是一条长链，必须用显式栈。

样例：[1,2,3,null,4] → [4,6,3,10]（后序是 4、2、3、1，子树和分别是 4、2+4、3、1+6+3）；[-5] → [-5]；[] → []。

提示

用本节 postorderIterPrev 的 prev 指针写法：一个节点出栈时，它的左右子树都已经处理完，左右孩子的子树和都已经算好。用哈希表 sum[节点] 存已经算好的子树和，出栈时把自己的值加上左右孩子的子树和，空孩子按 0 算。两个坑：反转法（根右左再反转）做不到"孩子先算好"，因为它访问根的时候孩子还没算；10^5 个 10^9 相加会超过 int，所以和要用 long long。

参考答案
vector<long long> subtreeSumsPost(TreeNode* root) {
    vector<long long> out;
    unordered_map<TreeNode*, long long> sum;           // 已经出栈的节点的子树和
    stack<TreeNode*> st;
    TreeNode* cur = root;
    TreeNode* prev = nullptr;
    while (cur != nullptr || !st.empty()) {
        while (cur != nullptr) { st.push(cur); cur = cur->left; }
        TreeNode* top = st.top();
        if (top->right != nullptr && top->right != prev) {
            cur = top->right;                          // 右子树还没处理
        } else {
            st.pop();                                  // 左右孩子都已算好
            long long s = top->val;
            if (top->left) s += sum[top->left];
            if (top->right) s += sum[top->right];
            sum[top] = s;
            out.push_back(s);
            prev = top;
        }
    }
    return out;
}
def subtree_sums_post(root):

        else:

易错点

  • 前序迭代压栈顺序写反（先左后右）会得到"根右左"。记法：想让谁先出来，就后压谁。
  • 中序迭代的外层循环条件是 cur != nullptr || !st.empty()，两者缺一都会提前结束：刚转向右子树时栈可能已空，而 cur 还有一整棵树。
  • 后序用"反转"时，压栈顺序要和前序相反（先左后右）；用 prev 写法时，判断条件是 top->right != prev，漏掉它会在右子树里来回绕。

小结： 前序迭代弹出即输出，先压右孩子再压左孩子；中序迭代先把左侧路径全部压栈，弹出时输出并转向右孩子；后序迭代按先左后右的顺序压栈得到根、右、左，再整体反转。

10.3 层序遍历与由遍历序列重建二叉树 必读

题目中出现“按层”“每一层”“最右侧的节点”“最小深度”“之字形”等说法时，用队列做广度优先搜索（BFS）；题目给出两种遍历序列、要求还原二叉树时，用递归不断划分序列的区间。

队列先进先出，先发现的节点先处理，所以节点按层的顺序出队。若要把结果按层分开，关键是在处理每一层之前记下当前队列的长度 sz：这一时刻队列中恰好是这一层的全部节点；接下来出队的 sz 个节点压入的孩子都属于下一层，并且都排在它们之后。

vector<vector<int>> levelOrder(TreeNode* root) {
    vector<vector<int>> res;
    if (root == nullptr) return res;
    queue<TreeNode*> q;
    q.push(root);
    while (!q.empty()) {
        int sz = (int)q.size();                    // 这一层的节点数，先固定下来
        vector<int> level;
        for (int i = 0; i < sz; ++i) {
            TreeNode* node = q.front(); q.pop();
            level.push_back(node->val);
            if (node->left) q.push(node->left);    // 下一层的节点排在后面
            if (node->right) q.push(node->right);
        }
        res.push_back(level);
    }
    return res;
}
def level_order(root):
    res = []
    if root is None: return res
    q = deque()
    q.append(root)
    while q:
        sz = len(q)                      # 这一层的节点数，先固定下来
        level = []
        for _ in range(sz):              # range(len(q)) 也行：range 在进入循环时就固定了本层长度
            node = q.popleft()           # popleft 是 O(1)；list.pop(0) 是 O(n)
            level.append(node.val)
            if node.left: q.append(node.left)      # 下一层的节点排在后面
            if node.right: q.append(node.right)
        res.append(level)
    return res

时间 O(n)。队列中最多同时存放一整层：根为第 1 层时，第 i 层最多有 2^(i−1) 个节点，所以空间是 O(树的最大宽度)。

Python 中的队列要用 collections.deque，它的 popleft() 是 O(1)；如果用 list.pop(0)，每次都要把后面的所有元素前移一位，是 O(n)。[3]

105 从前序与中序遍历序列构造二叉树

前序序列的第一个元素是根。在中序序列中找到根的位置，它左边的元素属于左子树，右边的属于右子树。由此知道左子树有几个节点，就能在前序序列中划出左子树和右子树对应的两段，再分别对两段递归。

设当前子树在前序序列中占区间 [pl, pr]，在中序序列中从下标 il 开始，两段描述的是同一棵子树。根是 pre[pl]；用哈希表 pos 查出它在中序中的下标 k，左子树的节点数是 leftSize = k − il。于是左子树在前序中是 [pl+1, pl+leftSize]、在中序中从 il 开始；右子树在前序中是 [pl+leftSize+1, pr]、在中序中从 k+1 开始。区间为空（pl > pr）时返回 nullptr。这一做法要求节点值互不相同，否则无法唯一确定根在中序中的位置。

TreeNode* buildPreIn(const vector<int>& pre, int pl, int pr, int il, unordered_map<int, int>& pos) {
    if (pl > pr) return nullptr;                   // 空区间 = 空子树
    TreeNode* root = new TreeNode(pre[pl]);        // 前序第一个就是根
    int k = pos[pre[pl]];                          // 根在中序里的下标
    int leftSize = k - il;                         // 左子树节点数
    root->left = buildPreIn(pre, pl + 1, pl + leftSize, il, pos);
    root->right = buildPreIn(pre, pl + leftSize + 1, pr, k + 1, pos);
    return root;
}
TreeNode* buildTreePreIn(const vector<int>& preorder, const vector<int>& inorder) {
    unordered_map<int, int> pos;                   // 值 -> 中序下标
    for (int i = 0; i < (int)inorder.size(); ++i) pos[inorder[i]] = i;
    return buildPreIn(preorder, 0, (int)preorder.size() - 1, 0, pos);
}
def build_pre_in(pre, pl, pr, il, pos):
    if pl > pr: return None                        # 空区间 = 空子树
    root = TreeNode(pre[pl])                       # 前序第一个就是根
    k = pos[pre[pl]]                               # 根在中序里的下标

    root.left = build_pre_in(pre, pl + 1, pl + left_size, il, pos)
    root.right = build_pre_in(pre, pl + left_size + 1, pr, k + 1, pos)

def build_tree_pre_in(preorder, inorder):

    return build_pre_in(preorder, 0, len(preorder) - 1, 0, pos)

每个节点只创建一次，用哈希表查中序位置是 O(1)，总时间 O(n)；哈希表占 O(n) 空间，递归栈占 O(h)。

练习 10.3-3【综合】哪一层最宽

题面：把树放进一棵"满二叉树"的格子里，某一层的宽度 = 这一层最右边的非空节点和最左边的非空节点之间的格子数（两端都算，中间的空位也算）。返回所有层里最大的宽度。节点数 ≤ 3000，树可能非常深；保证答案不超过 2^31 − 1。

样例：[1,3,2,5,3,null,9] → 4（第 3 层的 5、3、空、9 占 4 格）；[1,3,2,5,null,null,9,6,null,7] → 7；[1] → 1；[] → 0。

提示

按层 BFS，队列里存 (节点, 编号)：左孩子编号 2i，右孩子 2i+1，宽度 = 本层最后一个编号 − 第一个编号 + 1。坑在溢出：一条 3000 层的链，编号会到 2^3000。解决办法是每层先把编号减去本层第一个编号，改成相对编号，再算孩子的编号。题目保证答案在 int 范围内，相对编号就不会越界。C++ 里编号用 unsigned long long。

参考答案
int widestLevel(TreeNode* root) {
    if (root == nullptr) return 0;
    unsigned long long best = 0;
    queue<pair<TreeNode*, unsigned long long>> q;      // (节点, 编号)
    q.push({root, 0});
    while (!q.empty()) {
        int sz = q.size();
        unsigned long long first = q.front().second;   // 本层第一个编号
        unsigned long long last = 0;
        for (int i = 0; i < sz; ++i) {
            auto [node, id] = q.front(); q.pop();
            id -= first;                               // 相对编号：防止一层层累积溢出
            last = id;
            if (node->left) q.push({node->left, 2 * id});
            if (node->right) q.push({node->right, 2 * id + 1});
        }
        best = max(best, last + 1);
    }
    return (int)best;
}
def widest_level(root):
    if root is None: return 0
    best = 0
    q = deque([(root, 0)])                             # (节点, 编号)
    while q:
        sz = len(q)
        first = q[0][1]                                # 本层第一个编号
        last = 0
        for _ in range(sz):
            node, idx = q.popleft()
            idx -= first                               # 相对编号；Python 整数不溢出，但数字小了更快
            last = idx
            if node.left: q.append((node.left, 2 * idx))
            if node.right: q.append((node.right, 2 * idx + 1))
        best = max(best, last + 1)
    return best

易错点

  • 层序遍历内层循环要写 for (int i = 0; i < sz; ++i)，把 q.size() 直接写进循环条件会边弹边变，层就分乱了。
  • 105 切前序时按左子树的节点数切，下标是 pl + leftSize；用中序下标 k 直接去切前序是最常见的错误。
  • 只有前序和后序时一般还原不出唯一的树（15.4 的反例），必须有中序。

小结： 层序遍历先记下 sz 再出队 sz 个节点；由前序和中序重建树时，前序确定根，中序划分左右子树，再按左子树的大小切分前序。

问整棵树的某个性质（深度、是否对称、是否平衡），或者要求对每个节点做同样的修改，这类题按 10.1 的三个问题直接写递归，答案就是根节点的返回值。

    if (root == nullptr) return nullptr;
    swap(root->left, root->right);                 // 前序位置交换
    invertTree(root->left);
    invertTree(root->right);
    return root;
}
def invert_tree(root):
    if root is None: return None
    root.left, root.right = root.right, root.left  # 前序位置交换；Python 用元组赋值代替 swap
    invert_tree(root.left)
    invert_tree(root.right)
    return root

TreeNode* invertTreeBfs(TreeNode* root) {
    queue<TreeNode*> q;
    if (root) q.push(root);
    while (!q.empty()) {
        TreeNode* node = q.front(); q.pop();
        swap(node->left, node->right);
        if (node->left) q.push(node->left);
        if (node->right) q.push(node->right);
    }
    return root;
}
def invert_tree_bfs(root):
    q = deque()
    if root: q.append(root)
    while q:
        node = q.popleft()
        node.left, node.right = node.right, node.left
        if node.left: q.append(node.left)
        if node.right: q.append(node.right)
    return root

两种写法都是时间 O(n)；递归写法用 O(h) 的栈空间，层序写法用 O(最大宽度) 的队列空间。

101 对称二叉树

一棵树对称，是指它的左子树和右子树互为镜像。判断两棵树 a、b 是否互为镜像时，要比较的是外侧对外侧、内侧对内侧：a->left 对应 b->right，a->right 对应 b->left。因此递归函数需要同时接收两个节点。

isMirror(a, b) 判断以 a、b 为根的两棵树是否互为镜像。两个都为空时返回 true；只有一个为空时返回 false；否则要求两个节点的值相等，并且外侧的一对 (a->left, b->right) 和内侧的一对 (a->right, b->left) 也分别互为镜像。整棵树对称当且仅当 isMirror(root->left, root->right) 成立。

bool isMirror(TreeNode* a, TreeNode* b) {
    if (a == nullptr && b == nullptr) return true;     // 两边都空：对称
    if (a == nullptr || b == nullptr) return false;    // 只有一边空：不对称
    return a->val == b->val
        && isMirror(a->left, b->right)                 // 外侧对外侧

10.5 树的递归（二）：返回值与全局答案分开 选读

题目问任意两个节点之间的路径，例如直径、最大路径和。这样的路径可以在某个节点处转折，同时经过它的左子树和右子树。

一条在节点 x 处转折的路径无法再延伸到 x 的父节点：父节点只能接上一条从 x 一直向下的路径。所以每个节点要计算两个量：

  • 全局答案（在当前节点更新）：以当前节点为转折点、把左右两侧向下的路径连起来得到的结果，用它更新全局变量 best。

    if (node == nullptr) return 0;
    int L = depthForDiameter(node->left, best);    // 左边往下最多几个节点

    best = max(best, L + R);                       // 以 node 为拐点的路径，边数 = L + R
    return 1 + max(L, R);                          // 交给父节点：只能带一边
}

    depthForDiameter(root, best);
    return best;
}

样例：[5,4,5,1,1,null,5] → 2（右边的 5—5—5）；[1,4,5,4,4,null,5] → 2（4—4—4，在左边的 4 处拐弯）；[] → 0。

提示

这是直径的变形，多了一个条件：孩子的颜色和自己相同，才能接上那条腿。返回值是从当前节点往下、全部同色的最长一条腿（边数）。孩子颜色相同时，这条腿 = 孩子的腿 + 1；颜色不同时为 0。全局答案 = 左腿 + 右腿。最容易错的地方：孩子颜色不同时也必须递归下去，因为孩子的子树内部可能藏着更长的同色路径。

参考答案
int sameColorLeg(TreeNode* node, int& best) {
    if (node == nullptr) return 0;
    int L = sameColorLeg(node->left, best);            // 先递归：孩子子树内部的答案也要结算
    int R = sameColorLeg(node->right, best);
    int legL = (node->left && node->left->val == node->val) ? L + 1 : 0;    // 同色才能接上
    int legR = (node->right && node->right->val == node->val) ? R + 1 : 0;
    best = max(best, legL + legR);                     // 在 node 拐弯
    return max(legL, legR);                            // 交给父节点：只带一条腿
}
int longestSameColorPath(TreeNode* root) {
    int best = 0;
    sameColorLeg(root, best);
    return best;
}
def same_color_leg(node, best):
    if node is None: return 0
    L = same_color_leg(node.left, best)                # 先递归：孩子子树内部的答案也要结算
    R = same_color_leg(node.right, best)
    leg_l = L + 1 if node.left and node.left.val == node.val else 0     # 同色才能接上
    leg_r = R + 1 if node.right and node.right.val == node.val else 0
    best[0] = max(best[0], leg_l + leg_r)              # 在 node 拐弯
    return max(leg_l, leg_r)                           # 交给父节点：只带一条腿

def longest_same_color_path(root):
    best = [0]
    same_color_leg(root, best)
    return best[0]

练习 10.5-4【变形】节日值班：上下级不能同时被选

题面：公司的汇报关系是一棵二叉树，节点值是员工愿意值班的积极度（≥ 0）。要选一批人值班，直接上下级（父子）不能同时被选。求被选的人积极度之和的最大值。节点数 ≤ 10^4。

样例：[3,2,3,null,3,null,1] → 7（选 3、3、1）；[3,4,5,1,3,null,1] → 9（选 4、5）；[] → 0。

提示

父节点只拿一个数不够用：它要知道"孩子被选时"和"孩子没被选时"各自的最好结果。所以返回值改成一对：(选自己时子树的最大值, 不选自己时子树的最大值)。选自己，孩子都不能选：val + 左.不选 + 右.不选；不选自己，每个孩子随意：max(左两项) + max(右两项)。这就是"树形 DP"，第 11 章会再遇到。

参考答案
pair<long long, long long> pickOrSkip(TreeNode* node) {   // first：选 node；second：不选 node
    if (node == nullptr) return {0, 0};
    auto [lp, ls] = pickOrSkip(node->left);
    auto [rp, rs] = pickOrSkip(node->right);
    long long pick = node->val + ls + rs;              // 选自己：孩子都不能选
    long long skip = max(lp, ls) + max(rp, rs);        // 不选自己：孩子随意
    return {pick, skip};
}
long long maxDutyValue(TreeNode* root) {
    auto [p, s] = pickOrSkip(root);
    return max(p, s);
}
def pick_or_skip(node):                                # 返回 (选 node, 不选 node)
    if node is None: return (0, 0)
    lp, ls = pick_or_skip(node.left)
    rp, rs = pick_or_skip(node.right)
    pick = node.val + ls + rs                          # 选自己：孩子都不能选
    skip = max(lp, ls) + max(rp, rs)                   # 不选自己：孩子随意
    return (pick, skip)

def max_duty_value(root):
    p, s = pick_or_skip(root)
    return max(p, s)

练习 10.5-5【综合】两片叶子之间的最大路径和

题面：节点值可正可负（|val| ≤ 10^4，节点数 ≤ 10^4）。叶子是没有孩子的节点。找一条两端都是叶子（两片不同的叶子）的路径，使路径上的值之和最大，返回这个和。叶子少于两片时，C++ 返回 LLONG_MIN，Python 返回 None。

样例：[-10,9,20,null,null,15,7] → 42（15→20→7）；[1,-5,-6] → -10（只有一条叶到叶路径）；[1,2] → 没有答案（根有一个孩子，不算叶子）；[] → 没有答案。

提示

和 124 比，有两处变化。① 腿必须一直走到叶子，所以不能像 124 那样把负的腿截成 0。返回值定义为"从当前节点往下走到某片叶子的最大和"，只对非空节点调用：叶子返回自己；只有一个孩子时，只能沿那个孩子走下去。② 只有左右孩子都存在时，才能在这里拐弯，结算 best = 左腿 + 右腿 + 自己。一个孩子为空时就拐弯，路径的一端会落在空位置上，不是叶子。

参考答案
long long leafLeg(TreeNode* node, long long& best) {   // node 非空：往下走到叶子的最大和
    if (node->left == nullptr && node->right == nullptr) return node->val;
    if (node->left == nullptr) return node->val + leafLeg(node->right, best);   // 只能走右
    if (node->right == nullptr) return node->val + leafLeg(node->left, best);   // 只能走左
    long long L = leafLeg(node->left, best);
    long long R = leafLeg(node->right, best);
    best = max(best, L + R + node->val);               // 两边都有叶子，才能在这里拐弯
    return node->val + max(L, R);                      // 负的腿也得带着，不能截成 0
}
long long maxLeafToLeaf(TreeNode* root) {
    long long best = LLONG_MIN;                        // 留着 LLONG_MIN 表示"没有答案"
    if (root != nullptr) leafLeg(root, best);
    return best;
}
def leaf_leg(node, best):                              # node 非空：往下走到叶子的最大和
    if node.left is None and node.right is None: return node.val
    if node.left is None: return node.val + leaf_leg(node.right, best)    # 只能走右
    if node.right is None: return node.val + leaf_leg(node.left, best)    # 只能走左
    L = leaf_leg(node.left, best)
    R = leaf_leg(node.right, best)
    if best[0] is None or L + R + node.val > best[0]:  # 两边都有叶子，才能在这里拐弯
        best[0] = L + R + node.val
    return node.val + max(L, R)                        # 负的腿也得带着，不能截成 0

def max_leaf_to_leaf(root):
    best = [None]                                      # None 表示"没有答案"
    if root is not None: leaf_leg(root, best)
    return best[0]

易错点

  • 返回值写成 L + R（把拐弯路径交给父节点）会让父节点接上一条分叉的"路径"，结果偏大。返回值只能带一条腿。
  • 直径最长路径未必经过根。例如 [1,2,null,3,4,5,null,null,6] 的直径是 5−3−2−4−6，共 4 条边，根 1 不在上面；所以每个节点都要结算，而不是只在根结算一次。
  • 124 的 best 初值要用 INT_MIN：全是负数的树（如 [-3]）答案是 −3，初值写 0 会错。

小结： 返回给父节点的值只包含一侧向下的路径；全局答案在当前节点更新，等于左侧加右侧再加当前节点。
