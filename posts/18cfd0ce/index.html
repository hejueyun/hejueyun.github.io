14.1 线性表：同一组数据的两种存法 必读

银行系统里"今天的交易流水"、学生名单、待处理的请求，都是"一个接一个排好的数据"。我们关心两件事：按位置取第 k 个快不快，在中间插一个、删一个麻不麻烦。这两件事的答案取决于数据在内存里怎么放。

线性表是 n 个同类型元素的有限序列 (a₁, a₂, …, aₙ)：除第一个元素外，每个元素有唯一的前驱；除最后一个外，每个元素有唯一的后继。线性表是逻辑结构，描述"谁挨着谁"；落到内存上有两种存储结构：

  • 顺序表：用一段连续的存储单元依次存放元素，逻辑上相邻的元素物理上也相邻。第 i 个元素的地址 = 首地址 + (i−1)×每个元素的字节数，所以按位置访问是 O(1)，称为随机存取。
  • 链表：每个元素放在一个结点里，结点 = 数据域 + 指针域，指针域存下一个结点的地址。结点可以散落在内存各处，运行时按需创建，逻辑顺序靠指针串起来。找第 i 个元素要从头沿指针走 i 步，称为顺序存取。

上：元素紧挨着，地址可直接算；下：每个结点多存一个地址，顺着 next 才能找到下一个

完整走一遍：两种结构做同一件事。 表中有 4 个 int（每个 4 字节），顺序表首地址 1000。

操作顺序表链表
取第 3 个元素直接算地址 1000+2×4=1008，O(1)从头走 2 步，O(n)
在第 2 个位置插入把 a₂、a₃、a₄ 各后移一格，O(n)已知 a₁ 结点时改 2 个指针，O(1)
删除第 2 个元素把 a₃、a₄ 各前移一格，O(n)已知 a₁ 结点时改 1 个指针，O(1)
空间一次分配，可能有空闲槽位每个结点多一个指针

存储密度衡量"结点里有多少是真数据"：存储密度 = 数据域字节数 ÷ 整个结点字节数。设数据 8 字节、指针 8 字节（忽略对齐填充）：顺序表每个槽位只放数据，密度为 1；单链表结点 8/(8+8)=50%；双链表结点有两个指针，8/(8+8+8)≈33.3%。动态数组还有一个相关指标"容量利用率"：容量 8、存了 5 个，利用率 5/8=62.5%，它描述预留槽位的使用情况，与结点存储密度是两个口径。

缓存局部性。 CPU 读内存时，一次把一整块连续的数据（一个"缓存行"，常见为 64 字节）搬进高速缓存。访问一个元素后，紧挨着它的元素很可能已经在缓存里，下一次访问就很快，这种"访问位置相互靠近、可以沾光"的性质叫缓存局部性（准确说是空间局部性）。顺序表元素连续，遍历时天然享受这一点；链表结点分散，每走一步都可能要重新从内存取数。所以即使复杂度都是 O(n)，顺序遍历数组在实际机器上往往更快。

要点：

  1. 顺序表：随机存取，按位置访问 O(1)；插入、删除要移动元素，平均 O(n)；存储密度高。
  2. 链表：顺序存取，按位置访问 O(n)；已知前驱结点时插入、删除 O(1)，不移动元素；每个结点有指针开销。
  3. 标准答案句："频繁按序号访问、很少插删，选顺序表；频繁插删、表长变化大，选链表。"
  4. 存储密度 = 数据域 / 结点总大小；顺序表为 1，链表小于 1。

练习 14.1-1【基础】存储密度

题面：数据域 4 字节，指针 8 字节，忽略对齐填充。分别求顺序表、单链表、双链表的存储密度。若数据域改为 16 字节的结构体，单链表的存储密度是多少？

提示

存储密度 = 数据域字节数 ÷ 整个结点的字节数。双链表的结点有两个指针。

参考答案

顺序表只存数据，存储密度为 1。单链表为 4/(4+8) = 1/3 ≈ 0.33。双链表为 4/(4+8+8) = 1/5 = 0.2。数据域为 16 字节时，单链表为 16/(16+8) = 2/3 ≈ 0.67。数据域越大，指针开销所占的比例越小。

练习 14.1-2【基础】顺序表的地址

题面：顺序表首地址为 2000，每个元素 6 字节，位序从 1 起。(1) 第 15 个元素的地址是多少？(2) 某元素的地址为 2120，它是第几个元素？

提示

第 i 个元素前面有 i−1 个元素。

参考答案

(1) 2000 + (15−1)×6 = 2084。(2) (2120−2000)/6 = 20，它前面有 20 个元素，所以是第 21 个。

练习 14.1-3【综合】同一组操作的代价

题面：表长 n=100。比较顺序表与带头结点的单链表完成下列操作的代价：(1) 取第 50 个元素；(2) 在第 1 个位置插入；(3) 删除第 100 个元素。顺序表数"移动元素的个数"，单链表数"从头结点出发沿 next 走的步数"。

提示

单链表删除一个结点，要先找到它的前驱。

参考答案
操作顺序表单链表
取第 50 个直接算地址，移动 0 个走 50 步
在第 1 个位置插入后移 100 个前驱就是头结点，走 0 步，改 2 个指针
删除第 100 个移动 0 个先走 99 步找到前驱，再改 1 个指针

单链表删除表尾元素也要 O(n)，因为必须先找到前驱；顺序表删除表尾元素是 O(1)。哪种结构更快，取决于操作发生在表的哪个位置。

易错点：

  • "随机存取"指按序号直接算地址，说的是顺序表；链表即使已知头指针，找第 i 个仍要走 i 步。
  • 链表的"插入 O(1)"前提是已经拿到前驱结点；先查找位置再插入，总代价仍是 O(n)。

小结： 顺序表占用连续空间，支持随机存取，插入和删除需要移动元素；链表的结点分散存放，只能顺序存取，插入和删除只需修改指针；存储密度等于数据所占空间除以整个结点所占空间。

14.2 顺序表：插入和删除要搬动多少个元素 必读

顺序表的"插入 O(n)"从哪来？选择题常问"平均移动多少个元素"，答案 n/2 和 (n−1)/2 要能当场推出来，而不是死背。

顺序表用数组 data[0..MaxSize-1] 存元素，另用 length 记录当前长度。位序 i（从 1 起）的元素放在 data[i-1]。

  • 插入到位序 i（合法范围 1 ≤ i ≤ length+1）：把位序 i..length 的元素整体后移一格，腾出 data[i-1]，写入新值，length+1。
  • 删除位序 i（合法范围 1 ≤ i ≤ length）：取出 data[i-1]，把位序 i+1..length 的元素整体前移一格，length−1。

搬动方向有讲究：插入时从最后一个元素开始往后搬，删除时从被删位置的下一个开始往前搬，这样每次写入的位置都已经"空出来"或"不再需要"。

在位序 2 插入 8：[7,9,4,6] → [7,8,9,4,6]

共移动 3 个 = length − i + 1 = 4 − 2 + 1

平均移动次数的推导。 设表长为 n，每个位置等可能。

  • 插入到位序 i，要移动 n−i+1 个元素。i 有 n+1 种取法，每种概率 1/(n+1)。总移动数 = n + (n−1) + … + 1 + 0 = n(n+1)/2，平均 = n(n+1)/2 ÷ (n+1) = n/2。
  • 删除位序 i，要移动 n−i 个元素。i 有 n 种取法，每种概率 1/n。总移动数 = (n−1) + … + 0 = n(n−1)/2，平均 = (n−1)/2。
  • 按值查找成功时，第 i 个元素要比较 i 次，平均 (1+2+…+n)/n = (n+1)/2。

以 n=10 核对：插入总移动 10+9+…+0=55，除以 11 得 5=10/2；删除总移动 9+8+…+0=45，除以 10 得 4.5=(10−1)/2。

代码。 变量表：a 是底层数组（容量即 a.size()）；len 是当前长度；i 是 1 起的位序；返回值是移动的元素个数，非法时返回 −1。

int listInsert(vector<int>& a, int& len, int i, int x) {
    if (i < 1 || i > len + 1 || len == (int)a.size()) return -1;
    for (int j = len; j >= i; --j) a[j] = a[j - 1];   // from the tail backwards: a[len-1] moves first
    a[i - 1] = x;
    ++len;
    return len - i;                                   // = old length - i + 1 elements moved
}
int listDelete(vector<int>& a, int& len, int i, int& out) {
    if (i < 1 || i > len) return -1;
    out = a[i - 1];
    for (int j = i; j < len; ++j) a[j - 1] = a[j];    // from the front forwards
    --len;
    return len - i + 1;                               // = old length - i
}
def list_insert(a, length, i, x):    # a 是开好容量的 list，如 [7, 9, 4, 6, None, None]，容量即 len(a)
    # Python 没有 int& 引用：新长度通过返回值带回，调用写 moved, length = list_insert(a, length, 2, 8)
    # 日常写 Python 直接 a.insert(i - 1, x)：list 满了自动扩容，但后面的元素照样要搬，仍是 O(n)
    if i < 1 or i > length + 1 or length == len(a): return -1, length
    for j in range(length, i - 1, -1): a[j] = a[j - 1]   # j = length..i: from the tail backwards
    a[i - 1] = x
    length += 1
    return length - i, length                         # = old length - i + 1 elements moved

def list_delete(a, length, i):       # C++ 的 int& out 也改成返回值：(moved, length, out)
    if i < 1 or i > length: return -1, length, None
    out = a[i - 1]
    for j in range(i, length): a[j - 1] = a[j]        # j = i..length-1: from the front forwards
    length -= 1
    return length - i + 1, length, out               # = old length - i

14.3 单链表：头插、尾插、插入与删除 必读

链表题是 LeetCode 的高频区，笔试也常考"下面哪组语句能正确完成插入"。这些题的本质只有一件事：改指针的先后顺序。

单链表的结点含 data 和 next。我们通常在第一个数据结点前放一个头结点：它的数据域不存元素，next 指向第一个数据结点。头指针 L 指向头结点。

  • 带头结点：空表时 L->next == NULL。在第 1 个位置插入、删除第 1 个元素，与在中间操作写法相同（前驱就是头结点）。
  • 不带头结点：空表时 L == NULL。在第 1 个位置操作时没有前驱，要单独改头指针 L 本身。

头结点让"第一个元素"也拥有前驱，从而消除特殊情况；LeetCode 里的 dummy 结点就是同一个技巧（见 1.11）。

在 p 之后插入新结点 s，两条语句：

  1. s->next = p->next;：先让新结点接住 p 后面的整条链；
  2. p->next = s;：再让 p 指向新结点。

建表：头插法与尾插法。 头插法把每个新结点插在头结点之后（就是上面的"在 p 之后插入"，p 固定为头结点），所以读入顺序与链表顺序相反，常用于链表逆置。尾插法额外维护尾指针 r，每次接在 r 后面再让 r 后移，顺序不变。

代码。 变量表：p 是前驱结点；s 是新结点；q 是被删结点；out 带回被删的值；L 是头结点；r 是尾指针。

struct LNode { int data; LNode* next; };
void insertAfter(LNode* p, int x) {        // insert x right after node p
    LNode* s = new LNode{x, nullptr};
    s->next = p->next;                     // (1) new node grabs the rest of the list first
    p->next = s;                           // (2) then p points to the new node
}
bool deleteAfter(LNode* p, int& out) {     // delete the node right after p
    LNode* q = p->next;
    if (q == nullptr) return false;
    out = q->data;
    p->next = q->next;                     // bypass q
    delete q;
    return true;
}
LNode* buildHeadInsert(const vector<int>& v) {   // each new node goes right after the head node: order reverses
    LNode* L = new LNode{0, nullptr};
    for (int x : v) insertAfter(L, x);
    return L;
}
LNode* buildTailInsert(const vector<int>& v) {   // keep a tail pointer r: order preserved
    LNode* L = new LNode{0, nullptr};
    LNode* r = L;
    for (int x : v) { r->next = new LNode{x, nullptr}; r = r->next; }
    return L;
}
class LNode:                               # 对应 struct LNode；Python 没有指针，None 对应 nullptr
    def __init__(self, data, next=None):
        self.data = data
        self.next = next

def insert_after(p, x):                    # insert x right after node p
    s = LNode(x)                           # p、s 都是对象引用，作用相当于 C++ 的指针
    s.next = p.next                        # (1) new node grabs the rest of the list first
    p.next = s                             # (2) then p points to the new node

def delete_after(p):                       # delete the node right after p；返回 (是否成功, 被删的值)
    q = p.next
    if q is None: return False, None
    out = q.data
    p.next = q.next                        # bypass q
    return True, out                       # 不写 delete q：q 不再被引用后由垃圾回收释放

def build_head_insert(v):                  # each new node goes right after the head node: order reverses
    L = LNode(0)
    for x in v: insert_after(L, x)
    return L

def build_tail_insert(v):                  # keep a tail pointer r: order preserved
    L = LNode(0)
    r = L
    for x in v: r.next = LNode(x); r = r.next
    return L

手工模拟：buildTailInsert({1,2,3}) 得到链表 1、2、3；对第一个数据结点调用 insertAfter(…, 9) 后得到 1、9、2、3；再对同一个结点调用 deleteAfter，删除 9 并返回 9。

要点：

  1. 在 p 后插 s：s->next=p->next; p->next=s;，顺序固定，先连后断。
  2. 删 p 的后继：q=p->next; p->next=q->next; free(q);。
  3. 头插法得到逆序，尾插法保持原序；两种建表都是 O(n)。
  4. 带头结点的好处：第一个位置的插删与其他位置统一；空表与非空表的处理统一。
  5. 只给出结点 p 要删除 p 本身时，可以把后继的值复制到 p，再删后继，O(1)；p 是尾结点时这招失效，只能从头找前驱。

14.4 双链表、循环链表与静态链表 选读

单链表只能往后走：已知结点 q，想删除它却得从头找前驱。双链表给每个结点加一个 prior 指针，前驱一步可达；循环链表让表尾连回表头，从任何结点出发都能走遍全表；静态链表在不支持指针的环境里（早期 Fortran、某些嵌入式场景）用数组下标模拟指针。

双链表的结点有 prior、data、next 三个域。** 在 p 之后插入 s** 要改 4 个指针：

  1. s->next = p->next;：s 的后继设为 p 原来的后继（记作 B）；
  2. p->next->prior = s;：B 的前驱改为 s；
  3. s->prior = p;：s 的前驱设为 p；
  4. p->next = s;：p 的后继改为 s。

关键的约束只有一条：修改 p->next 的第 4 句必须放在第 1、2 句之后，因为第 1、2 句都要通过 p->next 找到 B；第 4 句一旦执行，p->next 就变成了 s，B 的地址只能通过 s->next 得到。前三句之间的顺序可以调换（例如把第 3 句放在最前面）。

struct DNode { int data; DNode* prior; DNode* next; };
void dInsertAfter(DNode* p, int x) {
    DNode* s = new DNode{x, nullptr, nullptr};
    s->next = p->next;                     // (1)
    if (p->next) p->next->prior = s;       // (2) must run before (4): it still reaches the old successor via p->next
    s->prior = p;                          // (3)
    p->next = s;                           // (4)
}
void dDeleteAfter(DNode* p) {
    DNode* q = p->next;
    p->next = q->next;                     // (1)
    if (q->next) q->next->prior = p;       // (2)
    delete q;
}
class DNode:
    def __init__(self, data, prior=None, next=None):
        self.data = data
        self.prior = prior
        self.next = next

def d_insert_after(p, x):
    s = DNode(x)
    s.next = p.next                        # (1)
    if p.next is not None: p.next.prior = s   # (2) must run before (4): it still reaches the old successor via p.next
    s.prior = p                            # (3)
    p.next = s                             # (4)

def d_delete_after(p):
    q = p.next
    p.next = q.next                        # (1)
    if q.next is not None: q.next.prior = p   # (2)；不写 delete q，q 由垃圾回收释放

循环链表：表尾结点的 next 指回头结点。判空条件变成 L->next == L，遍历的终止条件是"回到头结点"而不是"遇到 NULL"。若只设尾指针 r，那么 r->next 就是头结点，表头、表尾都能 O(1) 找到，适合频繁在两端操作的场景。循环双链表则让头结点的 prior 指向表尾，空表时头结点的 prior、next 都指向自己。

循环单链表：a₃ 的 next 回到头结点（下方弧线）；只设尾指针 r 时，r->next 即头结点

静态链表用一个结构体数组模拟链表：每个元素存 data 和 next，这里的 next 是下一个元素的数组下标（游标），-1 表示表尾。下标 0 充当头结点。插入、删除只改游标，不移动元素；但容量固定，也失去了随机存取能力。

要点：

  1. 双链表在 p 后插入 4 句，p->next = s 放最后；删除 2 句加释放。
  2. 双链表已知结点 q 时删除 q 是 O(1)（前驱一步可达）；按序号查找仍是 O(n)。
  3. 循环单链表判空 L->next == L；只设尾指针时头尾都 O(1)。
  4. 静态链表用游标代替指针，插删改游标不移元素，容量固定，只能顺序存取。

14.5 栈：顺序栈、链栈、共享栈与出栈序列 必读

浏览器的"后退"、编辑器的"撤销"、函数调用的返回，都遵循"最后放进去的最先拿出来"。栈就是只允许在一端（栈顶）插入和删除的线性表，特性是后进先出（LIFO）。

顺序栈用数组 data[0..MaxSize-1] 加栈顶下标 top 实现。408 约定：top 指向栈顶元素，初始 top = -1。

链栈用单链表实现，栈顶就是表头，进栈、出栈都是头插、头删，O(1)，没有"栈满"问题。

共享栈让两个栈共用一个数组，栈底分别在数组两端，向中间生长：0 号栈 top0 初始 −1，1 号栈 top1 初始 MaxSize。0 号进栈 data[++top0]=x，1 号进栈 data[--top1]=x。栈满条件：top1 - top0 == 1（两个栈顶相邻）。好处是两个栈此消彼长，只有总量用满时才溢出，空间利用率更高。

快速判断规则：输出序列中某元素 x 之后，比 x 小的元素必须按递减顺序出现。等价说法是序列中不存在下标 i<j<k 使得 p_j < p_k < p_i（即"大、小、中"的模式）。3,1,2 中 3 后面的 1、2 是递增的，非法；3,2,5,4,1 中 3 后面比 3 小的是 2、1，递减，5 后面比 5 小的是 4、1，递减，合法。

合法序列个数是卡特兰数：n 个不同元素依次进栈，合法出栈序列共有

C_n = C(2n, n) / (n+1)

个。n=3 时 C(6,3)/4 = 20/4 = 5，即 123、132、213、231、321（缺的是 312）；n=4 时 C(8,4)/5 = 70/5 = 14；n=5 时 C(10,5)/6 = 252/6 = 42。直观理解：把一次进栈记作"("，一次出栈记作")"，合法操作序列就是 n 对括号的合法配对，个数正是卡特兰数。

bool isValidPopSeq(const vector<int>& out) {
    stack<int> st;
    int next = 1, n = (int)out.size();                       // next = smallest value not yet pushed
    for (int x : out) {
        while (next <= n && (st.empty() || st.top() != x)) st.push(next++);   // push until x is on top
        if (st.empty() || st.top() != x) return false;       // x is buried under another value
        st.pop();
    }
    return true;
}
def is_valid_pop_seq(out):
    st = []                                  # list 当栈：append 压栈，pop() 弹栈，st[-1] 是栈顶
    nxt, n = 1, len(out)                     # nxt = smallest value not yet pushed（next 是内置函数名，改叫 nxt）
    for x in out:
        while nxt <= n and (not st or st[-1] != x):   # push until x is on top
            st.append(nxt); nxt += 1                  # Python 没有 next++，拆成两句
        if not st or st[-1] != x: return False        # x is buried under another value
        st.pop()
    return True

要点：

  1. 顺序栈 top=-1 为空，data[++top]=x 进栈，x=data[top--] 出栈，top+1 为元素个数。
  2. 共享栈满：top1 - top0 == 1。
  3. 判断出栈序列：模拟入栈直到目标到栈顶；或检查"x 之后比 x 小的数递减"。
  4. n 个元素的合法出栈序列数 = C(2n,n)/(n+1)，n=3,4,5 时分别为 5、14、42。

三种写法。 运算符写在两个操作数中间叫中缀（a+b），写在后面叫后缀（a b +，也叫逆波兰式），写在前面叫前缀（+ a b）。后缀表达式的优点是：运算顺序完全由书写顺序决定，不需要括号，也不需要比较优先级。

  1. 遇到操作数：直接输出。
  2. 遇到 (：直接压栈。

string toPostfix(const string& in) {
    string out; stack<char> ops;
    for (char c : in) {
        if (isalnum((unsigned char)c)) out += c;                   // operand: output directly
        else if (c == '(') ops.push(c);                            // '(' : always push
        else if (c == ')') {                                       // ')' : pop until '('
            while (ops.top() != '(') { out += ops.top(); ops.pop(); }
            ops.pop();                                             // discard '('
        } else {                                                   // operator: pop all with priority >= c
            while (!ops.empty() && prio(ops.top()) >= prio(c)) { out += ops.top(); ops.pop(); }
            ops.push(c);
        }
    }
    while (!ops.empty()) { out += ops.top(); ops.pop(); }
    return out;
}
int evalPostfix(const string& post) {
    stack<int> st;
    for (char c : post) {
        if (isdigit((unsigned char)c)) { st.push(c - '0'); continue; }
        int b = st.top(); st.pop();                                // first pop = RIGHT operand
        int a = st.top(); st.pop();                                // second pop = LEFT operand
        st.push(c == '+' ? a + b : c == '-' ? a - b : c == '*' ? a * b : a / b);
    }
    return st.top();
}

        if c.isalnum(): out += c                               # operand: output directly
        elif c == '(': ops.append(c)                           # '(' : always push
        elif c == ')':                                         # ')' : pop until '('
            while ops[-1] != '(': out += ops.pop()             # list.pop() 取出并删除栈顶，相当于 top() + pop()
            ops.pop()                                          # discard '('
        else:                                                  # operator: pop all with priority >= c
            while ops and prio(ops[-1]) >= prio(c): out += ops.pop()
            ops.append(c)
    while ops: out += ops.pop()
    return out

def eval_postfix(post):
    st = []
    for c in post:
        if c.isdigit(): st.append(int(c)); continue           # int('7') == 7，对应 c - '0'
        b = st.pop()                                           # first pop = RIGHT operand
        a = st.pop()                                           # second pop = LEFT operand
        # C++ 的 a / b 向零截断；Python 的 // 向下取整，负数时不同（-7 // 2 == -4），所以写 int(a / b)
        st.append(a + b if c == '+' else a - b if c == '-' else a * b if c == '*' else int(a / b))
    return st[-1]

prio('(') 为 0，而普通运算符的优先级都 ≥1，因此第 4 条规则的循环遇到 ( 自然停下，与"( 像墙"的描述一致。手工模拟：toPostfix("6+8*(5-3)/4") 得 "6853-*4/+"，evalPostfix 得 10。

递归与调用栈

函数调用时，系统在调用栈上压入一个栈帧，保存参数、局部变量和返回地址；函数返回时弹出栈帧，回到调用处继续执行。递归调用层层压栈，到达递归出口后再层层弹出，因此递归深度就是栈的最大深度。递归太深（例如忘了写出口）会耗尽栈空间，导致栈溢出。任何递归程序都可以改写成"自己维护一个栈"的非递归程序，第 15 章的树的非递归遍历就是这样做的。

14.7 队列：循环队列、双端队列与受限序列 必读

银行叫号、打印任务、BFS 遍历都要求"先来先服务"。队列只允许在队尾插入（入队）、在队头删除（出队），特性是先进先出（FIFO）。

顺序队列的"假溢出"。 用数组存队列，front 指队头元素，rear 指队尾元素的下一个位置。出队让 front 后移，入队让 rear 后移；两个指针都只往后走，rear 走到数组末尾后，即使前面已经空出很多位置，也无法再入队。这种"有空位却判满"的现象叫假溢出。

循环队列把数组首尾相接看成一个环：指针前进一格写成 (p + 1) % M（M 是数组长度），走到末尾后自动回到 0。

M=6 的循环队列：队中依次是 E(4)、F(5)、G(0)，front 指队头 E，rear 指 G 的下一个位置 1；长度 (1−4+6)%6=3

判空与判满的三种方案。 循环队列中，队空时 front == rear；如果把 M 个位置全部装满，rear 绕一圈追上 front，也是 front == rear。空和满无法区分，于是有三种解决方案：

方案队空队满长度最多存几个
牺牲一个单元（408 默认）front == rear(rear + 1) % M == front(rear − front + M) % MM − 1
增设 size 成员size == 0size == MsizeM
增设 tag 标志front == rear && tag == 0front == rear && tag == 1由 tag 和取模差共同确定M

第三种方案中，每次入队时置 tag = 1，每次出队时置 tag = 0。理由是：只有入队才可能使队列变满，只有出队才可能使队列变空，所以 front 与 rear 重合时，看最后一次操作是入队还是出队，就能判断队列是满还是空。

第一种方案的长度公式也可以这样理解：rear ≥ front 时，长度就是 rear − front；rear < front 时说明发生了回绕，长度是 rear − front + M。加上 M 再取模，就把两种情况合并成了一个式子。

struct CircQueue {
    vector<int> a; int M, front = 0, rear = 0;
    explicit CircQueue(int m) : a(m), M(m) {}
    bool empty() const { return front == rear; }
    bool full() const { return (rear + 1) % M == front; }
    int size() const { return (rear - front + M) % M; }
    bool push(int x) { if (full()) return false; a[rear] = x; rear = (rear + 1) % M; return true; }
    bool pop(int& x) { if (empty()) return false; x = a[front]; front = (front + 1) % M; return true; }
};
struct TagQueue {
    vector<int> a; int M, front = 0, rear = 0, tag = 0;
    explicit TagQueue(int m) : a(m), M(m) {}
    bool empty() const { return front == rear && tag == 0; }
    bool full() const { return front == rear && tag == 1; }
    bool push(int x) { if (full()) return false; a[rear] = x; rear = (rear + 1) % M; tag = 1; return true; }
    bool pop(int& x) { if (empty()) return false; x = a[front]; front = (front + 1) % M; tag = 0; return true; }
};
class CircQueue:                                     # 牺牲一格；front 指队头元素，rear 指下一个空位
    def __init__(self, m):
        self.a = [0] * m; self.M = m; self.front = 0; self.rear = 0   # 预先开好 m 格，不靠 list 扩容
    def empty(self): return self.front == self.rear
    def full(self): return (self.rear + 1) % self.M == self.front
    def size(self): return (self.rear - self.front + self.M) % self.M
    # + M 是为 C++ 写的：C++ 中负数 % M 得负数；Python 的 % 结果总与 M 同号，去掉 + M 也对
    def push(self, x):
        if self.full(): return False
        self.a[self.rear] = x; self.rear = (self.rear + 1) % self.M; return True
    def pop(self):                                   # C++ 的 int& x 改成返回 (是否成功, 取出的值)
        if self.empty(): return False, None
        x = self.a[self.front]; self.front = (self.front + 1) % self.M; return True, x

class TagQueue:                                      # tag 记录最后一次操作：1 入队，0 出队；M 格全可用
    def __init__(self, m):
        self.a = [0] * m; self.M = m; self.front = 0; self.rear = 0; self.tag = 0
    def empty(self): return self.front == self.rear and self.tag == 0
    def full(self): return self.front == self.rear and self.tag == 1
    def push(self, x):
        if self.full(): return False
        self.a[self.rear] = x; self.rear = (self.rear + 1) % self.M; self.tag = 1; return True
    def pop(self):
        if self.empty(): return False, None
        x = self.a[self.front]; self.front = (self.front + 1) % self.M; self.tag = 0; return True, x

双端队列与受限序列

双端队列（deque） 允许两端都能入队和出队。再加限制得到两种变体：

  • 输入受限的双端队列：只允许一端插入，两端都可删除。
  • 输出受限的双端队列：两端都可插入，只允许一端删除。

双端队列与两种受限形式

判断受限序列的思路与出栈序列相同：先找第一个输出的元素，想清楚它出队时队列里其余元素必然的排列，再看下一个要输出的元素是否在可出队的那一端。设输入顺序为 1、2、3、4：

  • 输出受限能否得到 4,1,3,2？要先输出 4，1、2、3 必须都已入队，并且出队端（设为右端）读出的顺序是 1、3、2，即队列自左向右应为 2、3、1。但 1、2、3 依次从两端插入时，最后插入的 3 一定在两端之一，排不成 2、3、1 这种 3 在中间的样子。所以得不到。
  • 输入受限能否得到 4,2,1,3？只能从一端插入，1、2、3、4 入队后队列自左向右必为 1、2、3、4（设从右端插入）。4 从右端出队后剩 1、2、3，下一个要 2，但 2 在中间，两端都拿不到。所以得不到。

14.8 数组地址计算：行优先、列优先与下标起点 选读

二维数组在内存中仍是一维排开的，编译器要把 a[i][j] 换成一个地址。笔试常给出首地址、元素大小、某个元素的地址，让你求另一个元素的地址或反推行列数。

把 m 行 n 列的数组摊平有两种方式：

  • 行优先：先存第 0 行全部元素，再存第 1 行……C、C++、Java、Python（NumPy 默认）都是行优先 [3]。
  • 列优先：先存第 0 列，再存第 1 列……Fortran、MATLAB 采用列优先。

核心方法只有一句：地址 = 首地址 + (a[i][j] 前面元素的个数) × 每个元素的字节数 L。行优先时，a[i][j] 前面有完整的 i 行（每行 n 个）再加本行的 j 个，共 i×n + j 个。

3×4 数组，求 a12：行优先时它前面有第 0 行的 4 个加第 1 行的 2 个（绿色），共 6 个

同一个 a12：列优先时前面有 2 整列（每列 m=3 个）加本列 1 个，共 7 个

下标从 0 起与从 1 起的公式对照（m 行 n 列，元素大小 L）：

存储方式下标从 0 起，首元素 a[0][0]下标从 1 起，首元素 a[1][1]
行优先LOC = base + (i×n + j)×LLOC = base + [(i−1)×n + (j−1)]×L
列优先LOC = base + (j×m + i)×LLOC = base + [(j−1)×m + (i−1)]×L

一般形式：数组 A[l₁..h₁][l₂..h₂]，行优先 LOC = base + [(i−l₁)×(h₂−l₂+1) + (j−l₂)]×L。其中 h₂−l₂+1 是每行元素个数。下标从 0 起、从 1 起都是它的特例。

示例：

  1. 3×4 数组，下标从 0 起，L=4，base=1000，行优先求 a[1][2]：(1×4+2)×4 = 24，地址 1024。列优先：(2×3+1)×4 = 28，地址 1028。
  2. 旧版算例：3×4 数组，L=2，base=200，行优先 a[2][1] 是偏移 2×4+1 = 9 的元素，地址 200 + 9×2 = 218。
  3. A[1..5][1..6]（5 行 6 列），L=2，a[1][1] 地址 200。行优先求 a[3][4]：前面有 2 整行 12 个，加本行 3 个，共 15 个，地址 200+15×2 = 230。列优先：前面有 3 整列 15 个，加本列 2 个，共 17 个，地址 200+17×2 = 234。
long long addrRow1(long long base, int i, int j, int n, int L) { return base + ((long long)(i - 1) * n + (j - 1)) * L; }
long long addrCol1(long long base, int i, int j, int m, int L) { return base + ((long long)(j - 1) * m + (i - 1)) * L; }
def addr_row1(base, i, j, n, L): return base + ((i - 1) * n + (j - 1)) * L   # Python int 不溢出，不需要 long long
def addr_col1(base, i, j, m, L): return base + ((j - 1) * m + (i - 1)) * L

要点：

  1. 先数"前面有几个元素"，再乘 L，再加首地址。
  2. 行优先乘的是列数 n（每行长度），列优先乘的是行数 m（每列长度）。
  3. 下标从 1 起时，行号、列号各减 1 再代入。
  4. 反推题：用已知元素的地址列方程解出 n（或 m）。

14.9 特殊矩阵的压缩存储：对称、三角、三对角 选读

一个 1000 阶对称矩阵有一百万个元素，其中一半是另一半的镜像；三对角矩阵只有对角线附近三条带上有非零值。把重复或固定为 0 的部分省掉，就能把空间压到一半甚至 3n 级别。考题的核心是：矩阵元素 a[i][j] 存到一维数组 B 的第几个位置 k。

统一方法：k = 按存储顺序，a[i][j] 前面存了多少个元素。下面默认 408 写法：矩阵下标 i、j 从 1 起，一维数组 B 下标 k 从 0 起，按行优先存。

对称矩阵

满足 a[i][j] = a[j][i] 的 n 阶方阵。只存下三角（含对角线，即 i ≥ j 的部分），共 1+2+…+n = n(n+1)/2 个。

a[i][j]（i ≥ j）前面有第 1 到第 i−1 行的下三角部分，共 1+2+…+(i−1) = i(i−1)/2 个，再加本行的 j−1 个：

  • i ≥ j 时：k = i(i−1)/2 + j − 1
  • i < j 时（上三角元素）：利用对称性交换 i、j，k = j(j−1)/2 + i − 1

4 阶对称矩阵只存下三角 10 个元素；灰色上三角不存，用对称位置代替。a32：前 2 行 1+2=3 个，加本行 1 个，k=4

一维数组 B[0..9]：第 i 行的下三角部分有 i 个元素

求上三角元素 a23 时，它等于 a32，所以 k 同样是 4。

三角矩阵

下三角矩阵：上三角部分（i < j）全是同一个常数 c（常见为 0）。存储方式与对称矩阵相同，只是上三角元素统一指向最后多存的一个单元：

  • i ≥ j：k = i(i−1)/2 + j − 1
  • i < j：k = n(n+1)/2（存常数 c 的位置）

上三角矩阵：下三角部分（i > j）全是常数 c。按行存上三角时，第 1 行有 n 个，第 2 行有 n−1 个……第 i 行之前共有 n + (n−1) + … + (n−i+2) = (i−1)(2n−i+2)/2 个，本行 a[i][i] 到 a[i][j−1] 又有 j−i 个：

  • i ≤ j：k = (i−1)(2n−i+2)/2 + (j − i)
  • i > j：k = n(n+1)/2

例：n=4 的上三角矩阵求 a23：前 1 行有 4 个，本行 a22 在它前面 1 个，k = 1×(8−2+2)/2 + 1 = 5。

三对角矩阵

只有主对角线和它上下各一条对角线（|i − j| ≤ 1）上有非零元素，其余全为 0。第 1 行和第 n 行各有 2 个，中间每行 3 个，共 3n − 2 个。

a[i][j]（|i−j| ≤ 1）前面：第 1 行 2 个，第 2 到 i−1 行各 3 个，共 2 + 3(i−2) = 3i − 4 个；本行的第一个非零元素是 a[i][i−1]，a[i][j] 在本行排第 j−i+2 个，前面有 j − i + 1 个。合计：

  • k = (3i − 4) + (j − i + 1) = 2i + j − 3

反过来，已知 k 求行列：i = ⌊(k+1)/3⌋ + 1，j = k − 2i + 3。

5 阶三对角矩阵存 3×5−2 = 13 个元素。a34：k = 2×3 + 4 − 3 = 7

14.10 稀疏矩阵：三元组、CSR 与十字链表 了解

了解即可：十字链表等，主要是 408 考点。点击展开

推荐系统的"用户 × 商品"评分矩阵、银行的"账户 × 交易类型"统计表，绝大多数位置是 0。非零元素很少而且分布没有规律的矩阵叫稀疏矩阵。它无法套用上一节的公式，只能把每个非零元素的位置一起记下来。

三元组表（COO）：每个非零元素存一个三元组 (行, 列, 值)，按行优先排序，另外记录矩阵的行数、列数和非零元个数 nnz [4]。

CSR（压缩稀疏行） 在三元组的基础上把"行号"压缩成行区间 [5]：

  • values：按行优先排列的非零值；
  • cols：每个非零值的列号；
  • rowptr：长度为行数 + 1，第 i 行的非零元在 values 中占区间 [rowptr[i], rowptr[i+1])。

以下面的 3×4 矩阵为例（本节行列下标从 0 起）：

3×4 稀疏矩阵 A：4 个非零元，其余 8 个为 0

  • 三元组：(0,2,7)、(1,0,2)、(2,1,5)、(2,3,9)
  • CSR：values=[7,2,5,9]，cols=[2,0,1,3]，rowptr=[0,1,2,4]

rowptr=[0,1,2,4] 把 values 切成三段；括号里是 cols 中的列号

读第 2 行：区间 [rowptr[2], rowptr[3]) = [2, 4)，对应 values[2]=5（列 1）和 values[3]=9（列 3）。若某一行全是 0，它的两个相邻 rowptr 值相等，区间为空。CSC（压缩稀疏列）把行列角色交换，适合按列访问。

struct CSR { vector<int> values, cols, rowptr; };
CSR toCSR(const vector<vector<int>>& A) {
    CSR c; c.rowptr.push_back(0);
    for (const auto& row : A) {
        for (int j = 0; j < (int)row.size(); ++j)
            if (row[j] != 0) { c.values.push_back(row[j]); c.cols.push_back(j); }
        c.rowptr.push_back((int)c.values.size());   // row i occupies [rowptr[i], rowptr[i+1])
    }
    return c;
}
class CSR:
    def __init__(self):
        self.values, self.cols, self.rowptr = [], [], []

def to_csr(A):
    c = CSR(); c.rowptr.append(0)
    for row in A:

空间算例。 m×n 稠密矩阵每个值 v 字节，共 mnv 字节。三元组每个非零元还要存两个坐标（各 b 字节），约 nnz×(v+2b) 字节。取 v=8、b=4，三元组每项 16 字节，是稠密存储每项的 2 倍，所以要 nnz < mn/2 才更省空间。

三元组转置。 把每个三元组的行列交换，(0,2,7)、(1,0,2)、(2,1,5)、(2,3,9) 变成 (2,0,7)、(0,1,2)、(1,2,5)、(3,2,9)，矩阵尺寸变为 4×3。若要求结果仍按行优先排序，需重排成 (0,1,2)、(1,2,5)、(2,0,7)、(3,2,9)。快速转置先统计原矩阵每列的非零元个数，做前缀和得到转置后每行的起始位置，再把元素逐个放到位，时间 O(列数 + nnz)。

十字链表：每个非零元是一个结点 (row, col, value, right, down)，同一行的结点用 right 串成一条链，同一列的结点用 down 串成一条链，每个结点同时属于一条行链和一条列链。插入、删除非零元只改指针，适合非零元位置经常变化的矩阵。

十字链表：实线为行链（right），虚线为列链（down）

要点：

  1. 稀疏矩阵压缩后失去随机存取特性，要按行号、列号查找。
  2. 三元组表存 (行, 列, 值)，CSR 把行号压缩为 rowptr（长度 = 行数 + 1）。
  3. 十字链表便于插入、删除非零元，代价是每个结点两个指针。
  4. 压缩是否省空间取决于 nnz 与坐标开销，需要具体算。

14.11 串与朴素模式匹配 选读

在日志里搜一个交易号、在文章里查一个关键词，都是"在主串 S 中找模式串 P 第一次出现的位置"，这就是模式匹配。

串的基本概念。 串是由零个或多个字符组成的有限序列，是一种元素限定为字符的线性表。

  • 子串：串中任意个连续字符组成的子序列；主串是包含它的串。
  • 空串：长度为 0 的串；空格串：由空格组成，长度不为 0。
  • 存储：定长顺序存储（字符数组，可能截断）、堆分配存储（动态申请，C++ string 属于此类 [6]）、块链存储（链表每个结点存多个字符）。C 语言的字符串以 '\0' 结尾，长度靠扫描得到；C++ string、Java、Python 的字符串对象另外记录长度。

朴素匹配（BF 算法）：让 P 依次对齐 S 的每个起点 s=0,1,…,n−m，逐字符比较；全部相同就找到，遇到不同就把 P 右移一位，从 P 的开头重新比。

int naiveSearch(const string& t, const string& p, int& cmp) {
    int n = t.size(), m = p.size(); cmp = 0;
    for (int s = 0; s + m <= n; ++s) {
        int k = 0;
        while (k < m) { ++cmp; if (t[s + k] != p[k]) break; ++k; }
        if (k == m) return s;
    }
    return -1;
}
def naive_search(t, p):                    # C++ 的 int& cmp 改成返回值：返回 (位置, cmp)
    n, m = len(t), len(p); cmp = 0
    for s in range(n - m + 1):             # s + m <= n，即 s = 0..n-m
        k = 0
        while k < m:
            cmp += 1
            if t[s + k] != p[k]: break
            k += 1
        if k == m: return s, cmp
    return -1, cmp

复杂度。 最坏情况每个起点都比到模式串最后一位才失配，例如 S = aaaaaaab、P = aab：起点 0 到 4 各比较 3 次，起点 5 比较 3 次成功，共 18 次。一般地最坏比较 (n−m+1)×m 次，即 O(nm)。最好情况第一个起点就匹配成功，比较 m 次。

要点：

  1. 朴素匹配失配时，主串指针回退到本次起点的下一位，模式串指针回到开头。
  2. 最坏时间 O(nm)，常见最坏输入是主串和模式串大多是同一字符。
  3. 408 写法中主串指针 i、模式指针 j 都从 1 起，失配时 i = i − j + 2; j = 1;。

14.12 KMP：next 数组怎么造、失配后怎么跳 选读

朴素匹配在 s=0 时已经知道主串前 5 个字符是 ababa，失配后却把这些信息全扔了。KMP 算法利用模式串自身的结构：失配时主串指针 i 不回退，只把模式串向右滑动到一个合适位置继续比较，总时间 O(n+m)。[7]

核心概念：最长相等前后缀。 一个串的真前缀是除了它自身以外、从开头取的子串；真后缀同理从结尾取。例如 ababa 的真前缀有 a、ab、aba、abab，真后缀有 a、ba、aba、baba。两者中相同且最长的是 aba，长度 3。

为什么它有用？在 s=0 时我们已匹配了 ababa，失配位置是第 6 个字符。已匹配部分的后缀 aba 与模式串的前缀 aba 相同，所以可以直接让模式串的前缀 aba 对齐主串里这段 aba，从模式串的第 4 个字符继续比较。主串指针停在原地。

第 0 行主串，第 1 行失配时的模式串（下标 5 处 b≠c），第 2 行右移后的模式串。已匹配的 ababa 中后缀 aba 与前缀 aba 相同，右移后这三位无需再比，直接比较下标 5 处的 b 与 P[3]=b

pi 数组（前缀函数，下标从 0 起）

定义：pi[i] = P[0..i] 的最长相等真前后缀的长度。失配时，若已匹配 j 个字符，就令 j = pi[j−1]，继续用当前主串字符与 P[j] 比较。

构造 pi 数组本身就是"模式串自己和自己匹配"：用 k 表示当前已匹配的前缀长度，若 P[i] == P[k]，前后缀同时延长一位，k+1；若不相等，k 退回到 pi[k−1]，尝试更短的相等前后缀，直到相等或 k=0。

vector<int> buildPi(const string& p) {
    int m = p.size();
    vector<int> pi(m, 0);
    for (int i = 1, k = 0; i < m; ++i) {
        while (k > 0 && p[i] != p[k]) k = pi[k - 1];   // fall back to a shorter border
        if (p[i] == p[k]) ++k;
        pi[i] = k;
    }
    return pi;
}
vector<int> kmpSearch(const string& t, const string& p) {   // all match positions (0-based)
    vector<int> pi = buildPi(p), res;
    for (int i = 0, j = 0; i < (int)t.size(); ++i) {         // j = number of pattern chars matched
        while (j > 0 && t[i] != p[j]) j = pi[j - 1];          // text pointer i never moves back
        if (t[i] == p[j]) ++j;
        if (j == (int)p.size()) { res.push_back(i - j + 1); j = pi[j - 1]; }
    }
    return res;
}
def build_pi(p):
    m = len(p)
    pi = [0] * m
    k = 0                                             # C++ 把 k 写在 for 的初始化里，Python 放到循环前
    for i in range(1, m):
        while k > 0 and p[i] != p[k]: k = pi[k - 1]   # fall back to a shorter border
        if p[i] == p[k]: k += 1
        pi[i] = k
    return pi

def kmp_search(t, p):                                 # all match positions (0-based)
    pi, res = build_pi(p), []
    j = 0                                             # j = number of pattern chars matched
    for i in range(len(t)):
        while j > 0 and t[i] != p[j]: j = pi[j - 1]   # text pointer i never moves back
        if t[i] == p[j]: j += 1
        if j == len(p): res.append(i - j + 1); j = pi[j - 1]
    return res

复杂度：i 共前进 n 次；j 每次 +1 最多 n 次，每次回退至少 −1，回退总次数不超过增加总次数，所以匹配 O(n)，构造 O(m)，合计 O(n+m)。

vector<int> getNext(const string& p) {
    int n = p.size(); vector<int> nx(n + 1, 0);
    int i = 1, j = 0;                                         // p[i-1] is the 1-based character P[i]
    while (i < n) {
        if (j == 0 || p[i - 1] == p[j - 1]) { ++i; ++j; nx[i] = j; }
        else j = nx[j];
    }
    return nx;
}
int indexKMP(const string& s, const string& p, const vector<int>& nx) {   // 1-based result, 0 = not found
    int i = 1, j = 1, n = s.size(), m = p.size();
    while (i <= n && j <= m) {
        if (j == 0 || s[i - 1] == p[j - 1]) { ++i; ++j; }

def get_next(p):
    n = len(p); nx = [0] * (n + 1)
    i, j = 1, 0                                       # p[i-1] is the 1-based character P[i]
    while i < n:
        # j == 0 必须写在 or 前面：否则 p[j - 1] 成了 p[-1]，Python 负下标取末字符，不报错而是悄悄算错

nextval：跳过注定失败的比较

看 P = aaaab，next = [0,1,2,3,4]。设主串当前字符是 b，在 j=4 处失配（P[4]=a≠b），按 next 依次跳到 j=3、2、1，每次比较的 P[j] 都是 a，注定又失配，最后才到 0。原因是 P[j] 与 P[next[j]] 相同：既然 P[j] 已经和主串字符不等，换一个相同的字符来比，结果必然相同。

nextval 的规则：nextval[1] = 0；对 j ≥ 2，若 P[j] == P[next[j]]，则 nextval[j] = nextval[next[j]]；否则 nextval[j] = next[j]。从左往右算，每项只依赖前面已算好的值。

vector<int> getNextval(const string& p) {
    int n = p.size(); vector<int> nx = getNext(p), nv(n + 1, 0);
    for (int j = 2; j <= n; ++j)                             // nv[1] = 0
        nv[j] = (p[j - 1] == p[nx[j] - 1]) ? nv[nx[j]] : nx[j];
    return nv;
}
def get_nextval(p):
    n = len(p); nx = get_next(p); nv = [0] * (n + 1)
    for j in range(2, n + 1):                         # nv[1] = 0
        nv[j] = nv[nx[j]] if p[j - 1] == p[nx[j] - 1] else nx[j]
    return nv

要点：

  1. KMP 失配时主串指针不回退，模式串指针 j 跳到 next[j]（408）或 pi[j−1]（0 起）。时间 O(n+m)。
  2. next[1]=0，next[j] = P[1..j−1] 的最长相等前后缀长度 + 1；next[j] = pi[j−2] + 1。
  3. nextval：P[j] 与 P[next[j]] 相同就继承 nextval[next[j]]，否则取 next[j]。
  4. KMP 的优势在模式串有较多部分匹配时才明显；随机文本上朴素匹配也接近 O(n)。

练习 14.12-3【综合】KMP 的比较次数

题面：S = aabaabaaf，P = aabaaf。用 next 数组做 KMP 匹配，写出失配后 j 的变化，共比较几次？朴素匹配要比较几次？

提示

先求 P 的 next 数组。失配时 i 不动，j 跳到 next[j]。

参考答案

P 的 next = [0, 1, 2, 1, 2, 3]。

S[1..5] 与 P[1..5] 逐个相等，比较 5 次；第 6 次比较 S[6]=b 与 P[6]=f，失配，j = next[6] = 3，i 不动；第 7 次比较 S[6]=b 与 P[3]=b，相等；之后 S[7..9] 与 P[4..6] 逐个相等，再比较 3 次。共比较 10 次，在主串第 4 个字符处匹配成功。

朴素匹配：起点 1 比较 6 次后失配；起点 2 比较 2 次（a=a，b≠a）；起点 3 比较 1 次；起点 4 比较 6 次成功。共 15 次。

练习 14.12-4【变形】求 pi 数组

题面：求 P = aabaaab 的前缀函数 pi（下标从 0 起）。

提示

用 k 表示当前相等前后缀的长度：P[i] == P[k] 时 k 加 1；不等时 k 退到 pi[k−1] 再比。

参考答案
i0123456
P[i]aabaaab
pi[i]0101223

i=5 时 k 从 2 开始：P[5]=a 与 P[2]=b 不等，k 退到 pi[1]=1；P[5]=a 与 P[1]=a 相等，k=2。i=6 时 P[6]=b 与 P[2]=b 相等，k=3。

易错点：

  • 有的教材 next 从 0 起且 next[0] = −1，数值等于 408 的 next 每项减 1；还有的直接用 pi。做题先看题目给的第一项是 0 还是 −1。
  • 求最长相等前后缀时，前缀和后缀都要是真的：ababa 的答案是 3（aba），整个串不算。

小结： KMP 根据最长相等前后缀决定失配后的跳转位置；next 数组等于前缀函数右移一位再加 1，并且 next[1]=0；求 nextval 时，若跳转位置的字符与当前字符相同，就继承它的 nextval 值。
