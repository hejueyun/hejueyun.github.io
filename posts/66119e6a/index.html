22.1 一个 C++ 程序长什么样

我们先看一个最小的完整程序：读入两个整数，输出它们的和。

#include <iostream>          // 引入"输入输出"功能
using namespace std;         // 之后可以直接写 cin、cout，不用写 std::cin

int main() {                 // 程序从 main 开始执行
    int a, b;                // 声明两个整数变量
    cin >> a >> b;           // 从标准输入读两个数
    cout << a + b << "\n";   // 把结果写到标准输出
    return 0;                // 0 表示正常结束
}

每一行都有固定作用：#include 引入库，using namespace std; 省掉 std:: 前缀，main 是入口，cin >> 读、cout << 写。刷题时最省事的写法是 #include <bits/stdc++.h>（GCC 提供的"一次引入全部标准库"），平台一般都支持；本资料的测试代码逐个写出头文件，让你知道每个容器来自哪里。

写完代码到运行，要经过编译。 C++ 是编译型语言：编译器（如 g++）先把源代码翻译成机器码，再运行。语法错误在编译阶段就会被拦下（"编译错误"）；数组越界、空指针这类问题要到运行时才出现（"运行时错误"）。

两种做题模式

笔试平台的题目有两种形式，区别在于"谁负责读输入"。

左：只写函数；右：输入输出全部自己处理

  • 核心代码模式：题目给出函数签名，例如 int maxProfit(vector<int>& prices)，你只写函数体，用 return 交出答案。LeetCode 全部是这种。
  • ACM 模式：你写完整的程序，自己从标准输入读数据、按格式打印结果。牛客和很多银行、互联网公司的笔试采用这种模式，读输入的写法见 22.12。

速记： #include 引库，main 是入口；核心代码模式写函数并 return，ACM 模式写 main 并自己读写。

22.2 变量与类型：先选对能装下答案的类型

变量就是"有名字、有类型的一块存储"。类型决定这块存储能放什么、放多大。刷题最常用的类型如下：

类型存什么范围（常见平台）典型用途
int整数，4 字节约 −2.1×10⁹ ～ 2.1×10⁹（INT_MAX=2147483647）下标、计数、一般数值
long long整数，8 字节约 ±9.2×10¹⁸大数相加相乘、求和、取模运算
double小数（浮点）约 15–16 位有效数字平均值、几何
char一个字符，本质是小整数'a' 的编码是 97字符串处理
booltrue / false—标记、visited 数组

溢出：结果超过类型范围

int 最大约 21 亿。两个 10 万相乘是 100 亿，放不进 int。有符号整数溢出在 C++ 中是未定义行为，结果不可信。解决方法是在计算发生前就转成 long long：

long long big = 1LL * 100000 * 100000;   // 1LL 让整个乘法按 long long 计算，得到 10000000000

写成 long long big = 100000 * 100000; 不行：右边两个 int 先相乘（已经溢出），之后才转换成 long long，转换来得太晚。

怎样判断要不要 long long？ 看题目给的数据范围：n 个数、每个最大 10⁹，求和最大可到 n×10⁹，只要 n≥3 就超过 int；两个 10⁵ 级别的数相乘超过 10⁹ 时也要用 long long。

整数除法和取余

两个整数相除，结果仍是整数，小数部分向零截断（直接丢掉）；取余 % 的符号跟被除数一致。[1]

表达式结果原因
7 / 233.5 向零截断
-7 / 2−3−3.5 向零截断（不是 −4）
-7 % 2−1满足 (−7/2)×2 + (−7%2) = −7
7.0 / 23.5有一边是 double，就按小数除

这条规则有两个实际用处：判断奇偶要写 x % 2 != 0（负奇数的余数是 −1，写 x % 2 == 1 会漏掉负数）；求平均值要先转 double，写成 sum / 2.0。

二分查找里的 mid 为什么写成 lo + (hi − lo) / 2

lo 和 hi 都接近 21 亿时，lo + hi 会超出 int。改写成 lo + (hi - lo) / 2：先算距离（不会溢出），再加回起点，数学上与 (lo+hi)/2 相同。

先算差再加回起点，中间结果始终在 int 范围内

字符就是小整数

char 存的是字符编码。小写字母编码连续，所以 c - 'a' 得到 0～25，正好当数组下标：

'c' - 'a'          // 2
char('a' + 3)      // 'd'

这个技巧把"统计 26 个字母出现次数"变成"一个长度 26 的数组计数"，22.6 会用到。

多选 · 理解检查 1　int 范围约 ±2.1×10⁹。下列哪些写法能正确得到 10⁵×10⁵ = 10¹⁰？

A. long long r = 1LL * 100000 * 100000;

B. long long r = 100000 * 100000;

C. long long r = (long long)100000 * 100000;

D. int r = 100000LL * 100000;

查看答案与每个选项的解析

A · 正确：1LL 是 long long，乘法从第一步起就按 long long 计算。

B · 错误：右边先按 int 相乘、先溢出，之后才赋值给 long long。

C · 正确：先把第一个数转成 long long，乘法按 long long 计算。

D · 错误：计算正确，但结果放回 int 时装不下。

单选 · 理解检查 2　C++ 中 -7 / 2 和 -7 % 2 分别是多少？

A. -3 和 -1

B. -4 和 1

C. -3.5 和 0

D. -3 和 1

查看答案与每个选项的解析

A · 正确：整数除法向零截断，余数符号与被除数相同。

B · 错误：这是向下取整的规则（Python 的 // 和 % 就是这样），C++ 不是。

C · 错误：两个 int 相除结果仍是整数。

D · 错误：(-3)×2 + 1 = -5 ≠ -7，余数应为 -1。

速记： 看数据范围选 int 还是 long long，乘法前先转型；整数除法向零截断；c-'a' 把字母变下标。

22.3 条件与循环：用"循环变量的含义"控制边界

if / else 做选择，for / while 做重复。刷题中大部分 bug 出在循环边界上：多走一步越界，少走一步漏掉元素。

vector<int> a = {4, 7, 1, 9};
int best = a[0];                         // 当前见过的最大值
for (int i = 1; i < (int)a.size(); ++i) {
    if (a[i] > best) best = a[i];
}
// best == 9

写循环前先用一句话说出循环变量的含义："i 是下一个要看的下标，[0, i) 已经看过，best 是 [0, i) 的最大值"。有了这句话，边界就能推出来：

  • 开始时只看过 a[0]，所以 i = 1、best = a[0]；
  • 所有下标都要看到，最后一个下标是 size()-1，所以条件是 i < size()；
  • 循环结束时 i == size()，[0, size()) 全部看过，best 就是答案。

逐步执行：求最大值

1 / 5

第1步 · 开始：只看过下标 0，best=4

best = 4
2 / 5

第2步 · i=1：7 > 4，更新 best

best = 7
3 / 5

第3步 · i=2：1 不大于 7，不变

best = 7
4 / 5

第4步 · i=3：9 > 7，更新 best

best = 9
5 / 5

第5步 · i=4 = size()，条件不成立，循环结束

[0,4) 全部看过，答案 best = 9

范围 for 是更短的写法，适合"每个元素都看一遍、不需要下标"的场合：

for (int x : a) sum += x;              // x 是每个元素的副本
for (int& x : a) x *= 2;               // 加 & 后 x 就是元素本身，可以修改

while 适合"不知道要循环几次，只知道何时停"的场合，例如链表遍历 while (p != nullptr)、二分查找 while (lo < hi)。

速记： 写循环先说清"变量代表什么、哪些已处理"，边界由这句话推出；只读用 for (int x : a)，要改用 for (int& x : a)。

22.4 函数与参数传递：值、引用、const 引用

函数把一段逻辑打包，起个名字，以后反复调用。参数有三种常见写法，区别在于函数里拿到的是副本还是原对象。[2]

void addOneByValue(int x) { x += 1; }     // 拿到副本
void addOneByRef(int& x)  { x += 1; }     // 拿到原变量本身（引用 = 别名）

int a = 5;
addOneByValue(a);   // a 仍是 5
addOneByRef(a);     // a 变成 6

按值：改副本，不影响 a；按引用：x 和 a 是同一个变量

为什么 LeetCode 的函数签名常写 vector<int>& nums？

  1. 省时间：按值传递会把整个数组复制一遍，n=10⁵ 时每次调用都复制 10⁵ 个数；引用不复制。
  2. 允许原地修改：像"移动零""旋转数组"要求直接改输入数组，必须用引用。

只读又不想复制时，写 const vector<int>& nums：引用避免复制，const 保证函数里不会误改。

long long sumOf(const vector<int>& v) {   // 只读，不复制
    long long s = 0;
    for (int x : v) s += x;
    return s;
}
void swapByRef(int& a, int& b) { int t = a; a = b; b = t; }   // 交换必须用引用
写法拿到什么能改调用者吗复制开销典型场合
int x副本不能小类型可忽略int、char 等小参数
vector<int>& v原对象能无需要原地修改
const vector<int>& v原对象（只读）不能无大对象只读

易错点： 递归时把 vector<int> path 按值传，每层都复制一份，速度慢但逻辑仍对；按引用传更快，但"做选择后要撤销"（见 21.5 回溯）。

速记： 小类型按值，大对象只读用 const 引用，要改原数据用引用。

22.5 vector：会自动变长的数组

vector<T> 是刷题用得最多的容器：元素连续存放，可以用下标 O(1) 访问，在尾部添加、删除元素均摊 O(1)。

vector<int> v;               // 空数组
v.push_back(3);              // [3]
v.push_back(1);              // [3,1]
v.push_back(4);              // [3,1,4]
v.pop_back();                // [3,1]   删掉最后一个
v.size();                    // 2
v.back();                    // 1       最后一个元素
v[0];                        // 3
vector<int> zeros(5, 0);     // [0,0,0,0,0]  5 个 0

合法下标是 0 ~ size()-1；size() 本身是越界位置

二维 vector：矩阵、DP 表、网格

m 行 n 列、全部初始化为 0：

vector<vector<int>> grid(m, vector<int>(n, 0));
grid[i][j] = 7;              // 第 i 行第 j 列
grid.size();                 // 行数 m
grid[0].size();              // 列数 n

读法：外层 vector 有 m 个元素，每个元素都是一个"长度为 n、全 0 的 vector<int>"。

grid(3, vector<int>(4, 0)) 后执行 grid[2][3] = 7

最容易错的一点：size() 是无符号数

size() 返回无符号整数（size_t），不会是负数。空数组的 size() 是 0，size() - 1 不等于 −1，而是绕回成一个极大的正数。于是下面的循环在空数组上会越界：

for (int i = 0; i <= v.size() - 1; ++i)    // v 为空时，v.size()-1 是一个巨大的数

统一写成 i < (int)v.size()：先转成 int 再比较，空数组时条件直接不成立。

操作作用复杂度
push_back(x) / pop_back()尾部加 / 删均摊 O(1)
v[i]访问第 i 个O(1)，不检查越界
size() / empty()元素个数 / 是否为空O(1)
insert(v.begin()+i, x) / erase(v.begin()+i)中间插 / 删O(n)，后面元素整体移动
clear()清空O(n)
sort(v.begin(), v.end())升序排序O(n log n)
reverse(v.begin(), v.end())反转O(n)

v.begin() 和 v.end() 是迭代器，可以理解为"指向第一个元素"和"指向最后一个元素之后"的位置标记；标准库算法都接收这样一个左闭右开区间 [begin, end)。

多选 · 理解检查 3　vector<vector<int>> g(3, vector<int>(4, 0)); 之后，哪些正确？

A. g.size() 是 3，g[0].size() 是 4

B. g[3][0] 是合法访问

C. g[2][3] 是最后一行最后一列

D. g 中共有 12 个 int

查看答案与每个选项的解析

A · 正确：外层 3 个元素（行），每行长度 4（列）。

B · 错误：行下标只能是 0、1、2。

C · 正确：行 0~2、列 0~3。

D · 正确：3×4=12。

速记： 合法下标 0～size()−1；二维写 vector<vector<int>> g(m, vector<int>(n))；循环条件写 i < (int)v.size()。

22.6 string：字符组成的 vector

string 的用法和 vector<char> 很像，另外多了拼接、截取、查找等字符串专用操作。[3]

string s = "hello";
s += " world";            // 拼接："hello world"
s.size();                 // 11
s[0];                     // 'h'
s.substr(6, 5);           // 从下标 6 开始取 5 个字符："world"
s.substr(6);              // 从下标 6 取到末尾："world"
s.find("wor");            // 6；找不到时返回 string::npos
to_string(42);            // "42"
stoi("-17");              // -17

substr 的第二个参数是长度，不是结束下标

易错点： substr(pos, len) 的第二个参数是长度。要取下标 [l, r] 的子串，写 s.substr(l, r - l + 1)。

用长度 26 的数组统计字母

很多字符串题（字母异位词、最小覆盖子串）都要统计每个字母出现了几次。题目说明"只含小写字母"时，用数组比哈希表更简单也更快：

vector<int> letterCount(const string& s) {
    vector<int> cnt(26, 0);           // cnt[0] 是 'a' 的次数 … cnt[25] 是 'z'
    for (char c : s) cnt[c - 'a']++;
    return cnt;
}

字符减 'a' 得到下标，计数数组就是一张字母→次数的表

两个字符串是否互为字母异位词，只要比较 letterCount(s) == letterCount(t)：vector 可以直接用 == 逐元素比较。

速记： substr(起点, 长度)；find 找不到返回 npos；只含小写字母时用 cnt[c-'a'] 计数。

22.7 unordered_map 与 unordered_set：O(1) 查"见没见过"

哈希表回答两类问题：某个键是否出现过（set），某个键对应什么值（map）。查找、插入平均 O(1)。[4]

经典例子：两数之和

题目：数组中找两个数，和等于 target，返回它们的下标。

暴力做法是两层循环，O(n²)。换个角度：扫描到 nums[i] 时，我们需要的另一个数是 target - nums[i]；只要能 O(1) 回答"它之前出现过吗、在哪个下标"，一次扫描就够了。这正是哈希表的用途。

变量表：seen 是"之前出现过的值 → 它的下标"；i 是当前下标；need 是当前数需要配对的值。

vector<int> twoSum(const vector<int>& nums, int target) {
    unordered_map<int, int> seen;            // 值 -> 下标（只存 i 之前的元素）
    for (int i = 0; i < (int)nums.size(); ++i) {
        int need = target - nums[i];
        auto it = seen.find(need);
        if (it != seen.end()) return {it->second, i};
        seen[nums[i]] = i;                   // 先查后存：不会把自己和自己配对
    }
    return {};
}

twoSum([2,7,11,15], 9)

1 / 2

第1步 · i=0，nums[0]=2，需要 7。表是空的，没找到；存入 2→0

seen = {2:0}
2 / 2

第2步 · i=1，nums[1]=7，需要 2。表里有 2，下标 0

找到！返回 [0, 1]

为什么要"先查后存"？考虑 nums=[3,3], target=6：i=0 时表是空的，存入 3→0；i=1 时查到 3→0，返回 [0,1]，正确。若先存后查，i=0 时就会查到自己，错误地返回 [0,0]。

常用操作

unordered_map<string, int> freq;
for (string w : {"a", "b", "a"}) freq[w]++;   // 计数：键不存在时自动从 0 开始
freq.count("a");                // 1：存在（map 里 count 只会是 0 或 1）
freq.find("z") == freq.end();   // true：不存在
for (auto& [key, val] : freq) { /* 遍历每个键值对，顺序不固定 */ }

unordered_set<int> seen = {1, 2, 3};
seen.insert(4);  seen.erase(1);  seen.count(2);   // 插入、删除、查询

[] 会插入新键。 freq["z"] 在键不存在时，会插入 "z"→0 再返回 0。所以只想查询、不想改表时，用 count 或 find。计数场景正是利用了这个特点：freq[w]++ 对新键从 0 开始加。

想做什么写法
计数cnt[x]++
判断存在m.count(x) 或 m.find(x) != m.end()
取值（确定存在）m[x] 或 m.at(x)
删除m.erase(x)
遍历for (auto& [k, v] : m)，顺序不固定

多选 · 理解检查 4　unordered_map<int,int> m; 执行 int x = m[5]; 之后，哪些正确？

A. x 是 0

B. m.size() 变成 1

C. m.count(5) 是 0

D. 只查询时用 find 或 count 可以避免插入

查看答案与每个选项的解析

A · 正确：键 5 不存在时，[] 插入值初始化的 0 并返回它。

B · 正确：[] 把键 5 插进了表。

C · 错误：5 已经被插入，count 返回 1。

D · 正确：这两个操作不会修改表。

速记： 哈希表回答"见过没有、对应什么"；先查后存；[] 会插入，查询用 count/find。

22.8 map 与 set：自动保持有序

map 和 set 的接口和哈希版本几乎一样，区别是内部按键排序（红黑树实现，见 03 章），所以：

  • 遍历时按键从小到大；
  • 能回答"第一个不小于 x 的键是谁"（lower_bound）；
  • 查找、插入、删除是 O(log n)，比哈希表的平均 O(1) 慢一些。
map<int, string> m = {{3, "c"}, {1, "a"}, {2, "b"}};
for (const auto& [key, val] : m) cout << val;   // 输出 abc：按键 1,2,3 的顺序
set<int> st = {10, 20, 30};
*st.lower_bound(15);   // 20：第一个 >= 15 的元素
*st.lower_bound(20);   // 20
st.upper_bound(30) == st.end();   // true：没有 > 30 的元素

lower_bound：第一个 ≥ x；upper_bound：第一个 > x

选哪个？ 只需要"存在吗 / 计数"用 unordered_*；需要有序遍历、找前驱后继、维护一个动态有序集合时用 map/set。有重复元素的有序集合用 multiset。

速记： map/set 有序、O(log n)、能 lower_bound；unordered 无序、平均 O(1)。

22.9 stack、queue、deque、priority_queue

这四个容器各自只开放特定的进出口，因此能表达不同的处理顺序。

四种受限容器：用哪个，取决于下一个该处理谁

容器下一个取出的是典型题型
stack最后放进去的括号匹配、单调栈、DFS 的显式栈
queue最早放进去的BFS、层序遍历
deque两头都可以滑动窗口最大值（单调队列）
priority_queue当前最大（或最小）的Top K、合并 K 个有序链表、Dijkstra

注意 pop() 不返回值。 要先用 top() / front() 读出来，再 pop() 删掉。

栈：括号匹配

规则：遇到左括号就压栈；遇到右括号，栈顶必须是与之配对的左括号，然后弹出。扫描结束时栈必须为空。

bool isValid(const string& s) {
    stack<char> st;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') { st.push(c); continue; }
        if (st.empty()) return false;          // 右括号多了
        char open = st.top(); st.pop();
        if ((c == ')' && open != '(') || (c == ']' && open != '[') || (c == '}' && open != '{')) return false;
    }
    return st.empty();                         // 左括号多了也不合法
}

isValid("([]{})")

1 / 5

第1步 · 读 '('：左括号，压栈

2 / 5

第2步 · 读 '['：左括号，压栈

3 / 5

第3步 · 读 ']'：栈顶 '[' 配对，弹出

4 / 5

第4步 · 读 '{'：压栈

5 / 5

第5步 · 读 '}'：配对，弹出；读 ')'：配对，弹出

扫描结束且栈空 → 合法

优先队列：默认是大根堆

priority_queue<int> maxHeap;                                   // top() 是最大值
priority_queue<int, vector<int>, greater<int>> minHeap;        // top() 是最小值

记忆方法：模板里写 greater<int>，得到的却是小根堆。原因是比较器表示"谁的优先级更低、应该往下沉"：greater 让大的数下沉，小的浮到堆顶。不必背原理，记住"默认大根堆，加 greater 变小根堆"就够了。

Top K 问题：找最大的 k 个数。维护一个大小为 k 的小根堆，堆顶是"目前入选的 k 个数里最小的那个"。新数进来后，若堆超过 k 个，就弹出堆顶（最小的）。最后堆里剩下的就是最大的 k 个。时间 O(n log k)。

vector<int> topK(const vector<int>& nums, int k) {
    priority_queue<int, vector<int>, greater<int>> heap;   // 小根堆
    for (int x : nums) {
        heap.push(x);
        if ((int)heap.size() > k) heap.pop();               // 弹出最小的
    }
    vector<int> out;
    while (!heap.empty()) { out.push_back(heap.top()); heap.pop(); }
    reverse(out.begin(), out.end());                        // 从大到小
    return out;
}
// topK({3,1,4,1,5,9,2,6}, 3) == {9, 6, 5}

多选 · 理解检查 5　求数组中最大的 k 个数，用 priority_queue 维护大小为 k 的堆。哪些正确？

A. 应使用小根堆 priority_queue<int, vector<int>, greater<int>>

B. pop() 会返回被删除的元素

C. 时间复杂度 O(n log k)

D. priority_queue<int> 默认 top() 是最小值

查看答案与每个选项的解析

A · 正确：堆顶是入选者中最小的，超过 k 个时弹出它。

B · 错误：pop() 返回 void，需先用 top() 读取。

C · 正确：n 次 push/pop，每次堆大小不超过 k+1。

D · 错误：默认是大根堆，top() 是最大值。

速记： 栈后进先出，队列先进先出，deque 两头进出；优先队列默认大根堆，greater 变小根堆；pop() 不返回值。

22.10 pair、auto、排序与 lambda

pair 和结构化绑定

pair<A, B> 把两个值绑成一个，用 .first、.second 访问。排序时先比 first，相同再比 second。

vector<pair<int,int>> ps = {{2,1}, {1,5}, {2,0}};
sort(ps.begin(), ps.end());          // {1,5}, {2,0}, {2,1}
auto [a, b] = ps[0];                 // 结构化绑定：a=1, b=5

auto 让编译器自己推断类型，刷题时可以少写很长的类型名，例如 auto it = m.find(x);。

自定义排序：lambda 比较器

sort(begin, end, cmp) 的第三个参数是一个"比较函数"：cmp(a, b) 返回 true，表示 a 应该排在 b 前面。最方便的写法是 lambda（就地写的匿名函数）：

struct Student { string name; int score; };
void sortStudents(vector<Student>& v) {
    sort(v.begin(), v.end(), [](const Student& a, const Student& b) {
        if (a.score != b.score) return a.score > b.score;   // 分数高的在前
        return a.name < b.name;                             // 分数相同按名字
    });
}
// {Bob,90}, {Amy,95}, {Cat,90}  →  Amy(95), Bob(90), Cat(90)

lambda 的结构是 [捕获](参数) { 函数体 }。[] 里可以写 &，表示可以使用外部变量，例如按另一个数组的值排序下标：

vector<int> idx = {0, 1, 2};
vector<int> val = {30, 10, 20};
sort(idx.begin(), idx.end(), [&](int i, int j) { return val[i] < val[j]; });   // idx = {1, 2, 0}

易错点： 比较器必须是"严格小于"的含义。写成 return a.score >= b.score; 在两个元素相等时也返回 true，违反 sort 的要求，可能导致崩溃或错误结果。

其他常用算法

函数作用返回
sort(b, e) / sort(b, e, greater<int>())升序 / 降序—
reverse(b, e)反转—
*max_element(b, e)最大值迭代器，解引用得到值
lower_bound(b, e, x) - b有序数组中第一个 ≥ x 的下标迭代器，减 begin 得下标
upper_bound(b, e, x) - b第一个 > x 的下标同上
accumulate(b, e, 0LL)求和（<numeric>）初值类型决定结果类型
max(a, b) / min(a, b) / swap(a, b)两数取大取小 / 交换—

lower_bound 的原理和手写版本见 21.4。

速记： cmp(a,b) 为 true 表示 a 在前，只能是严格比较；lambda 写成 [&](参数){...}；lower_bound - begin 得下标。

22.11 struct、指针与链表 / 二叉树节点

链表和树的题目会给出节点类型。先把这段定义读懂：

struct ListNode {
    int val;                 // 节点里存的值
    ListNode* next;          // 指向下一个节点的指针
    ListNode(int x) : val(x), next(nullptr) {}   // 构造函数
};
  • struct 把几个变量打包成一种新类型；
  • ListNode* 是"指向 ListNode 的指针"，保存另一个节点的地址；
  • nullptr 是空指针，表示"不指向任何节点"，链表的结尾就是 next == nullptr；
  • ListNode(int x) : val(x), next(nullptr) {} 是构造函数，冒号后面是初始化列表，创建节点时把 val 设为 x、next 设为空。
ListNode* a = new ListNode(1);   // 在堆上新建一个节点，a 保存它的地址
a->val;                          // 1。指针访问成员用 ->，等价于 (*a).val
a->next = new ListNode(2);       // 接上第二个节点

每个节点 = 值 + 指向下一节点的指针；最后一个节点的 next 是 nullptr（∅）

用虚拟头节点建链表

ListNode* buildList(const vector<int>& v) {
    ListNode dummy(0);                // 虚拟头：不是真实数据，只为了统一"接在尾巴后面"
    ListNode* tail = &dummy;          // tail 永远指向当前最后一个节点
    for (int x : v) {
        tail->next = new ListNode(x);
        tail = tail->next;
    }
    return dummy.next;                // 真正的头是 dummy 的下一个
}

没有 dummy 时，第一个节点要单独处理（"头指针是空吗"）；有了 dummy，每个节点都是"接在 tail 后面"，代码只有一种情况。这个技巧在删除节点、合并链表时还会反复出现（见 21.8）。

二叉树节点和递归

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};
int treeDepth(TreeNode* root) {
    if (root == nullptr) return 0;                                  // 空树深度 0
    return 1 + max(treeDepth(root->left), treeDepth(root->right));  // 自己这一层 + 更深的子树
}

上图这棵树：treeDepth(4) = 1，treeDepth(2) = 1 + max(1, 0) = 2，treeDepth(3) = 1，treeDepth(1) = 1 + max(2, 1) = 3。树的递归套路（"空节点返回什么、当前节点如何用左右子树的结果"）会在刷题模式章系统展开。

易错点： 访问 p->next 或 root->left 之前，必须确认 p、root 不是 nullptr，否则运行时崩溃（空指针解引用）。

速记： 指针存地址，-> 访问成员，nullptr 表示空；dummy 头让"接在后面"只有一种写法。

22.12 ACM 模式：按题目格式读输入

ACM 模式下，题目会描述输入格式。先把格式翻译成"要读几次、每次读什么类型"，再选对应写法。下面四种格式覆盖了绝大多数笔试题。为了能测试，示例函数接收 istream& in，实际做题时把 in 换成 cin 即可。[5]

加速：数据量大时，在 main 开头加两行，让 cin/cout 不再与 C 风格的 scanf/printf 同步，读写速度会快很多（加了之后不要再混用 scanf/printf）：

ios::sync_with_stdio(false);
cin.tie(nullptr);

格式 A：先给个数 n，再给 n 个数

3
10 20 30

long long readCountThenNumbers(istream& in) {
    int n; in >> n;
    long long s = 0;
    for (int i = 0; i < n; ++i) { int x; in >> x; s += x; }
    return s;
}

>> 会自动跳过空格和换行，所以数字在一行还是多行都能读。

格式 B：不告诉个数，读到输入结束

1 2
3
4 5

long long readUntilEof(istream& in) {
    long long s = 0; int x;
    while (in >> x) s += x;      // 读取成功返回 true；读到结尾失败返回 false，循环结束
    return s;
}

格式 C：多行，每行个数不定，要按行处理

1 2 3

10 -4
7

>> 跳过换行，分不出"哪些数属于同一行"。这时先用 getline 读一整行，再用 stringstream 把这一行当作新的输入流逐个拆数：

vector<long long> readLineSums(istream& in) {
    vector<long long> out; string line;
    while (getline(in, line)) {
        if (line.empty()) continue;          // 跳过空行
        stringstream ss(line);
        long long s = 0; int x;
        while (ss >> x) s += x;
        out.push_back(s);
    }
    return out;                              // {6, 6, 7}
}

格式 D：先读数字，再读一整行文字

2
hello world

cin >> n 读走数字 2 后，换行符还留在输入里。紧接着的 getline 会读到这一行剩下的部分，也就是一个空字符串。所以要先多调用一次 getline，把数字所在行的剩余部分（换行）吃掉：

pair<int, string> readNumberThenLine(istream& in) {
    int n; in >> n;
    string rest; getline(in, rest);   // 吃掉数字后面的换行
    string text; getline(in, text);   // 这才是 "hello world"
    return {n, text};
}

cin>> 读完 2 停在换行前；此时 getline 只会读到空行

输出

cout << ans << "\n";                         // 用 "\n" 换行，比 endl 快（endl 每次都刷新缓冲）
for (int i = 0; i < n; ++i) cout << a[i] << (i + 1 < n ? " " : "\n");   // 空格分隔，行末不留空格
cout << fixed << setprecision(2) << 3.14159; // 保留两位小数：3.14（需要 <iomanip>）

多选 · 理解检查 6　输入第一行是整数 n，第二行是一句含空格的英文句子。哪种读法能正确得到整句？

A. cin >> n; getline(cin, s);

B. cin >> n; getline(cin, rest); getline(cin, s);

C. cin >> n >> s;

D. cin >> n; cin.ignore(); getline(cin, s);

查看答案与每个选项的解析

A · 错误：getline 读到的是 n 所在行剩下的换行，s 为空。

B · 正确：第一次 getline 吃掉换行，第二次读到整句。

C · 错误：>> 遇到空格就停，只能读到第一个单词。

D · 正确：ignore() 跳过一个字符（这里是换行），效果同上；前提是数字后紧跟换行、没有多余空格。

速记： 知道个数就 for 循环读；不知道个数就 while (cin >> x)；要按行就 getline + stringstream；>> 后接 getline 先吃掉换行。

A. BFS 层序遍历用 queue
