2.1 条件概率：把分母换成已知发生的那部分

做风控时最常见的问题是"已知客户用了 APP，他同时用网页的可能性有多大"。这里多了一个已知条件，问题的参照人群就变了。条件概率就是用来描述"在已知某件事发生的前提下，另一件事发生的概率"。

直观解释。 事件 A 的概率 P(A) 是"A 占全体的比例"。条件概率 P(B|A) 读作"已知 A 时 B 的概率"，它把全体缩小成 A 这一部分，再看其中有多少也属于 B。精确定义是：

P(B|A) = P(A∩B) / P(A)，要求 P(A) > 0。

这里 A∩B 表示"A 和 B 同时发生"，A∪B 表示"A 或 B 至少一个发生"。两者的关系是加法公式 P(A∪B) = P(A) + P(B) − P(A∩B)：两块面积相加时，重叠部分被算了两次，要减掉一次。

我们用一个具体人群走一遍。100 名客户中，40 人用 APP（事件 A），30 人用网页（事件 B），10 人两者都用。下面这张图把四类人排成一行，上方的括号就是 Venn 图里的两个圆：A 覆盖前两格，B 覆盖中间两格，重叠的那一格就是 A∩B。

把 Venn 图摊平：两个括号重叠的格子是 A∩B

  • P(A∩B) = 10/100 = 0.1，分母是全体 100 人。
  • P(B|A) = 10/40 = 0.25，分母换成用 APP 的 40 人。
  • P(A|B) = 10/30 ≈ 0.333，分母换成用网页的 30 人。
  • P(A∪B) = 0.4 + 0.3 − 0.1 = 0.6，所以都不用的是 40 人。

三个数的分子都是 10，差别全在分母。读题时先问一句"现在的参照群体是谁"，分母就定下来了。

独立与互斥

独立的意思是"知道 B 发生，不改变 A 的概率"，即 P(A|B) = P(A)，等价写法 P(A∩B) = P(A)P(B)。互斥的意思是"A 和 B 不会同时发生"，即 A∩B 为空，P(A∩B) = 0。用掷一次骰子来看：

两个括号没有公共格子：A、B 互斥

A = 偶数（绿色与高亮格：2、4、6），B = {1,2}；交集只有 2：P(A∩B)=1/6，恰好等于 P(A)P(B)=1/2×1/3

第二张图里，A 是偶数，P(A) = 1/2；B 是点数不超过 2，P(B) = 1/3；同时满足的只有点数 2，P(A∩B) = 1/6 = P(A)P(B)，所以 A、B 独立。直观上，知道"点数不超过 2"之后，偶数仍占一半（{1,2} 里的 2），概率没变。

回到客户例子：P(A)P(B) = 0.4 × 0.3 = 0.12，而 P(A∩B) = 0.1，两者不等，所以"用 APP"和"用网页"不独立。

至少一次用反面算。 独立重复 n 次、每次成功概率 p，至少成功一次的概率是 1 − (1−p)ⁿ。两次抛公平硬币至少一次正面 = 1 − (1/2)² = 3/4；每次成功率 0.2，做 3 次至少成功一次 = 1 − 0.8³ = 0.488。

要点：

  1. 条件概率先换分母：P(B|A) 的分母是 P(A)。
  2. 互斥看交集为空，独立看 P(A∩B) = P(A)P(B)，一个讲"能否同时发生"，一个讲"会不会互相影响概率"。
  3. 两个概率都大于 0 的事件，如果互斥，就一定不独立：知道 A 发生，B 的概率立刻变成 0。
  4. 至少一次 = 1 − 一次都没有。

单选 · 理解检查 1　100 名客户中 40 人用 APP，30 人用网页，10 人两者都用。已知某客户用网页，他也用 APP 的概率是多少？

A. 1/3

B. 1/4

C. 1/10

D. 0.12

查看答案与每个选项的解析

A · 正确：分母换成用网页的 30 人，分子是两者都用的 10 人，10/30。

B · 错误：这是 P(网页|APP)=10/40，条件方向反了。

C · 错误：这是 P(A∩B)=10/100，分母仍是全体。

D · 错误：这是 P(A)P(B)，只有独立时才等于 P(A∩B)，而且问的是条件概率。

易错点：

  • 互斥和独立是两回事。正概率的两个互斥事件反而强烈相关。
  • 两次抛硬币至少一个正面，写成 1/2 + 1/2 = 1 会把"两次都正"算两遍；用反面 1 − 1/4。

小结： 条件概率就是换一个分母；互斥是不能同时发生，独立是一个事件不改变另一个事件的概率；求“至少发生一次”的概率，用 1 减去全部不发生的概率。

2.2 全概率公式与贝叶斯：警报响了，真有问题的概率是多少

反欺诈系统报警了，这笔交易真是欺诈的概率有多大？很多人会脱口而出"系统检出率 90%，所以 90%"。这把"有问题时报警的概率"和"报警时有问题的概率"弄反了。贝叶斯公式就是把条件方向倒过来的工具。

两个公式。 设 A 是"有问题"，B 是"报警"。

  • 全概率公式：报警可能来自"有问题"和"正常"两条路，把两条路的概率加起来，P(B) = P(B|A)P(A) + P(B|非A)P(非A)。
  • 贝叶斯公式：P(A|B) = P(B|A)P(A) / P(B)。

公式里的几个名字：P(A) 叫先验（看到报警前对"有问题"的估计，也叫基率）；P(B|A) 叫似然（有问题时出现这个证据的概率，这里就是检出率、灵敏度）；P(B|非A) 是误报率；P(A|B) 叫后验（看到报警后更新的概率）。

我们用 1000 个对象画一棵概率树。第一层按"是否有问题"分，第二层按"是否报警"分；每条路径的人数 = 上一层人数 × 这一层的条件概率。

贝叶斯手算：报警后真有问题的概率

1 / 4

第1步 · 写出先验：1000 个对象里 10 个有问题

P(有问题) = 10/1000 = 0.01
P(正常)   = 990/1000 = 0.99
2 / 4

第2步 · 沿树的两条报警路径算人数

有问题且报警：10 × 0.9 = 9
正常且报警：990 × 0.1 = 99
3 / 4

第3步 · 全概率公式：把所有报警加起来

报警总数 = 9 + 99 = 108
P(报警) = 0.9×0.01 + 0.1×0.99 = 0.108
4 / 4

第4步 · 贝叶斯公式：只看报警的那 108 个

P(有问题|报警) = 9 / 108 = 1/12 ≈ 8.33%
检出率 90% 是 P(报警|有问题)，方向相反

为什么后验这么低？因为正常对象有 990 个，误报率 10% 就贡献了 99 次报警，远多于真问题的 9 次。基率越低，误报在报警中的占比越大。

再算一个全概率的例子。 某行两个外包团队录入单据：A 团队承担 60%，差错率 2%；B 团队承担 40%，差错率 5%。随机抽一张单据有差错的概率 P(差错) = 0.6×0.02 + 0.4×0.05 = 0.012 + 0.020 = 0.032。抽到一张差错单，它来自 A 的概率 = 0.012 / 0.032 = 0.375。A 承担的量多，但差错率低，所以差错单只有 37.5% 来自 A。

复检会怎样？ 后验可以当作下一轮的先验。某检测先验 1%、灵敏度 95%、误报率 5%，第一次阳性后后验 = 0.0095 / 0.059 ≈ 16.1%；独立复检再次阳性，把 16.1% 当先验再算一次，后验升到约 78.5%。这就是"多个独立证据逐步累积"的意思。

和 AI 的联系。 朴素贝叶斯分类器用的正是贝叶斯公式：P(类别|特征) ∝ P(类别) × ∏ P(特征ᵢ|类别)。"朴素"指在给定类别时假设各特征条件独立，于是似然可以连乘。某个条件概率估计成 0 会让整个乘积为 0，常用拉普拉斯平滑把计数加 1。[1] 完整算例见第 4 章。

要点：

  1. P(A|B) 和 P(B|A) 方向不同、分母不同；贝叶斯公式就是把条件方向倒过来。
  2. 后验 = 似然 × 先验 / 证据；分母 P(B) 用全概率公式展开。
  3. 基率低时，即使检出率高，报警中误报也可能占多数。
  4. 画概率树：每层乘条件概率，同一结果的路径相加。

单选 · 理解检查 2　某检测先验 1%、灵敏度 95%、误报率 5%。一次阳性后，真阳性的概率最接近？

A. 约 16.1%

B. 95%

C. 约 1%

D. 约 50%

查看答案与每个选项的解析

A · 正确：0.95×0.01=0.0095，0.05×0.99=0.0495，0.0095/(0.0095+0.0495)=0.0095/0.059≈0.161。

B · 错误：95% 是 P(阳性|有病)，题目问的是 P(有病|阳性)。

C · 错误：1% 是看到阳性之前的先验，阳性证据会把它往上推。

D · 错误：需要按全概率算出 P(阳性)=0.059 作分母，结果约 16%。

多选 · 理解检查 3　本节 1000 对象、真问题 10、检出 9、误报 99。哪些说法正确？

A. 检出率 90%

B. 报警为真问题的比例 90%

C. 报警为真问题的比例约 8.33%

D. 不看基率也能由灵敏度直接算出后验

查看答案与每个选项的解析

A · 正确：9/10。

B · 错误：应为 9/108，方向和分母都不同。

C · 正确：所有报警 9+99=108，其中真问题 9。

D · 错误：还需要先验比例和正常群体的误报率。

易错点：

  • 似然 P(B|A) 是"给定 A 时证据的概率"，它对 A 求和不必等于 1；后验 P(A|B) 才是关于 A 的概率分布。
  • 朴素贝叶斯的条件独立假设是建模简化，真实特征之间往往相关，但分类效果常常仍然可用。

小结： 用概率树解贝叶斯问题：沿路径把条件概率相乘，再把各路径的结果相加；后验概率等于似然乘以先验，再除以全概率。

2.3 期望、方差、协方差与相关系数：描述一个数和两个数的关系

评估一款理财产品，我们想知道两件事：平均能赚多少，波动有多大。前者是期望，后者是方差。再进一步，两只产品是否同涨同跌，要看协方差和相关系数。

随机变量是"把随机结果映射成数"的规则，例如掷骰子的点数 X。

  • 期望 E[X] = Σ x·P(X=x)，即按概率加权的长期平均。公平骰子 E[X] = (1+2+…+6)/6 = 3.5。期望可以取到单次实验不会出现的值，骰子没有 3.5 点。
  • 方差 Var(X) = E[(X − E[X])²] = E[X²] − (E[X])²，衡量离均值有多远。骰子 E[X²] = 91/6，Var = 91/6 − 3.5² = 35/12 ≈ 2.917。
  • 标准差 σ = √Var，单位和原数据一致，骰子 σ ≈ 1.708。

总体方差与样本方差。 对数据 [1, 2, 3]，均值 2，偏差平方和 = 1 + 0 + 1 = 2。除以 n = 3 得 2/3，这是"把这三个数当成全体"的总体方差；除以 n − 1 = 2 得 1，这是用样本估计总体方差时常用的无偏样本方差。题目问哪一种，就用哪个分母。

协方差与相关系数。 协方差 Cov(X, Y) = E[(X − E[X])(Y − E[Y])]：两者同时高于均值或同时低于均值，乘积为正，协方差为正。相关系数 r = Cov(X, Y) / (σ_X σ_Y)，把协方差缩放到 [−1, 1]，去掉了单位的影响，也叫皮尔逊相关系数。

我们用 5 组数据算一遍，x 是营销次数，y 是成交笔数。

先减均值（x̄=3，ȳ=4），再逐行相乘；最后一行是三列的合计

  • 协方差（除 n）= 6/5 = 1.2；除 n − 1 则为 1.5。
  • Var(x) = 10/5 = 2，Var(y) = 6/5 = 1.2。
  • r = 6 / √(10 × 6) = 6/√60 ≈ 0.775，正相关且较强。算 r 时分子分母用同一个分母，n 或 n − 1 会约掉。

几条运算规律：

规律条件
E[aX + b] = aE[X] + b总成立
E[X + Y] = E[X] + E[Y]总成立，无需独立
Var(aX + b) = a²Var(X)总成立，加常数不改波动
Var(X + Y) = Var(X) + Var(Y) + 2Cov(X, Y)总成立
Var(X + Y) = Var(X) + Var(Y)当 Cov(X, Y) = 0，例如独立时

用上表的数据核对：x + y = [3, 6, 8, 8, 10]，总体方差 5.6 = 2 + 1.2 + 2×1.2。

要点：

  1. 期望是加权平均，线性可加，无需独立。
  2. 方差加常数不变，乘 a 变成 a² 倍。
  3. 相关系数在 [−1, 1]，只衡量线性关系；独立 ⇒ 不相关（矩存在时），反过来一般不成立。
  4. 样本方差除 n − 1 是无偏估计，总体方差除 n。

单选 · 理解检查 4　x=[1,2,3,4,5]，y=[2,4,5,4,5]。按除以 n 计算，Cov(x,y) 和相关系数 r 分别约是多少？

A. 1.2 和 0.775

B. 1.5 和 0.775

C. 6 和 1

D. 1.2 和 1.2

查看答案与每个选项的解析

A · 正确：偏差乘积和 6，6/5=1.2；r=6/√(10×6)≈0.775。

B · 错误：1.5 是除以 n−1 的样本协方差，题目要求除以 n；r 两种分母都一样。

C · 错误：6 是乘积之和，还没除样本数；r=1 要求点全部落在一条上升直线上。

D · 错误：r 还要除以两个标准差的乘积 √(2×1.2)≈1.549。

易错点：

  • 不相关只说明没有线性关系。X 在 {−1, 0, 1} 上等可能、Y = X²，Cov = 0，但 Y 完全由 X 决定。
  • 相关不意味着因果：冰淇淋销量和溺水人数正相关，背后是气温。

小结： 期望是加权平均，可以直接相加；方差衡量偏差平方的平均；相关系数 r 等于协方差除以两个标准差的乘积。

2.4 六个常见分布：伯努利、二项、泊松、均匀、正态、指数

建模时第一步常是"这个量大概服从什么分布"：一次是否违约、一天来多少笔投诉、客户等待多久……不同问题对应不同分布，选对分布，期望和方差就有现成公式。

离散分布取有限或可数个值，用概率质量函数 P(X = k)；连续分布取一段区间里的任意值，用概率密度 f(x)，区间上密度曲线下的面积才是概率。

分布描述什么概率公式期望方差
伯努利 B(1, p)一次 0/1 试验P(1)=p，P(0)=1−ppp(1−p)
二项 B(n, p)n 次独立同概率试验的成功次数C(n,k) pᵏ (1−p)ⁿ⁻ᵏnpnp(1−p)
泊松 P(λ)单位时间内稀有事件的次数e^(−λ) λᵏ / k!λλ

逐个算一遍：

  • 二项：某类贷款违约率 0.2，抽 5 笔，恰好 2 笔违约的概率 = C(5,2)×0.2²×0.8³ = 10×0.04×0.512 = 0.2048。至少 1 笔违约 = 1 − 0.8⁵ ≈ 0.672。期望 np = 1 笔，方差 np(1−p) = 0.8。
  • 泊松：某网点每小时平均 2 次投诉，λ = 2。一小时没有投诉的概率 = e^(−2) ≈ 0.1353；恰好 2 次 = e^(−2)×2²/2! ≈ 0.2707；至少 2 次 = 1 − 0.1353 − 0.2707 ≈ 0.594。
  • 均匀：U(0, 10) 的均值 5，方差 100/12 ≈ 8.33。
  • 指数：客服平均每 2 分钟接起一通电话，λ = 0.5/分钟。等待超过 2 分钟的概率 = e^(−0.5×2) = e^(−1) ≈ 0.368。指数分布有无记忆性：已经等了 3 分钟，再多等 2 分钟以上的概率仍是 e^(−1)，P(T>5 | T>3) = P(T>2)。

要点：

  1. 固定次数数成功用二项，固定时间数次数用泊松，等多久用指数。
  2. 泊松的期望和方差相等，都是 λ。
  3. 指数分布是唯一具有无记忆性的连续分布，几何分布是离散版。
  4. 连续分布在单个点上的概率为 0，概率看面积。

2.5 标准正态分布：从钟形曲线到双侧概率（银行选择题专项）

银行笔试中的正态分布题几乎都是同一种形式：给出 Φ 表中的一个值，要求计算右尾、双侧或中间部分的概率。只要会画图、会利用对称性，这类题十几秒就能做完。

正态分布是连续概率分布，均值 μ 决定中心位置，标准差 σ 决定胖瘦。** 标准正态**记为 Z ~ N(0, 1)：均值 0、方差 1、标准差 1。密度曲线左右对称，最高点在 0 处，高度 1/√(2π) ≈ 0.399。曲线下的面积才是概率，某一个精确点的概率为 0。

密度函数 φ(z) = (1/√(2π))·e^(−z²/2)。累积分布函数 Φ(z) = P(Z ≤ z)，是从最左端到 z 的面积。题目一般直接给 Φ 的数值，无需积分。

两条虚线之外是左右两个尾部，各 0.0668；之间的中央面积 0.8664

由对称性得到的四个公式：

  • Φ(0) = 0.5
  • Φ(−a) = 1 − Φ(a)
  • P(−a ≤ Z ≤ a) = 2Φ(a) − 1
  • P(|Z| > a) = 2[1 − Φ(a)]

把数字代进去。 题目给出 Φ(1.5) = 0.9332。

三块面积加起来等于 1；双侧尾部 = 0.0668×2 = 0.1336

  • 右侧超过 1.5：1 − 0.9332 = 0.0668。
  • 左侧小于 −1.5：由对称，也是 0.0668。
  • 双侧极端 |Z| > 1.5：0.0668 × 2 = 0.1336。
  • 中央 −1.5 到 1.5：1 − 0.1336 = 0.8664。

一般正态怎样变成标准正态。 若 X ~ N(μ, σ²)，令 Z = (X − μ)/σ，这一步叫标准化，Z 表示"离均值几个标准差"。例：某测评分数 X ~ N(100, 15²)。

2.6 大数定律与中心极限定理：平均值为什么越来越稳

银行估计一类客户的平均交易额，统计所有人成本太高，只能抽样。抽多少才靠得住？抽出来的平均值又会在真值附近怎样波动？大数定律回答第一个问题，中心极限定理回答第二个。

大数定律：独立重复同一个试验，样本平均值随着样本量 n 增大，越来越接近期望。抛公平硬币，正面频率会趋近 0.5。

下面第一张图是一次模拟：抛 5000 次固定序列的硬币，在不同次数时记录正面频率。前 10 次只有 2 次正面（频率 0.2），波动很大；到几千次时稳定在 0.5 附近。

一次模拟：n 越大，频率越贴近 0.5

一次模拟可能碰巧好看，我们再看精确概率。下图是"抛 n 次，正面频率偏离 0.5 超过 0.1"的概率，用二项分布精确计算：n = 10 时高达 0.344，n = 100 时降到 0.035，n = 500 时已小于十万分之一。

大数定律的含义：大偏差的概率随 n 增大趋于 0（n=500 时小于 0.00001，显示为 0）

中心极限定理（CLT）：单个数据原本是什么分布都可以（只要方差有限），n 个独立同分布数据的平均值，在 n 较大时近似服从正态分布：

X̄ 近似 ~ N(μ, σ²/n)

其中 σ/√n 叫标准误，是样本均值的标准差。n 变成 4 倍，标准误减半。

下图用骰子演示。单个骰子是平的（均匀分布）；2 个骰子的平均值呈三角形；4 个骰子的平均值已经接近钟形，而且更集中在 3.5 附近。纵轴是"概率 ÷ 相邻取值间距"，这样不同 n 的曲线可以放在一起比较形状。

平均的个数越多，分布越像钟形、越窄（精确计算，非模拟）

完整算一遍。 某行单笔交易金额均值 200 元、标准差 60 元，分布明显右偏（少数大额）。随机抽 36 笔，平均金额超过 220 元的概率是多少？

  1. 标准误 = 60/√36 = 10 元。
  2. 由 CLT，X̄ 近似 ~ N(200, 10²)。
  3. z = (220 − 200)/10 = 2。
  4. P(X̄ > 220) ≈ 1 − Φ(2) ≈ 0.0228。

原始数据偏态，但 36 笔的平均值已经可以按正态处理，这正是 CLT 的威力。

要点：

  1. 大数定律：样本均值收敛到期望（讲"会不会接近"）。
  2. 中心极限定理：样本均值的分布趋近正态，标准误 σ/√n（讲"以什么形状接近"）。
  3. 样本量翻 4 倍，误差减半。
  4. 置信区间、z 检验、A/B 测试都建立在 CLT 上。

2.7 点估计与最大似然：哪个参数最能解释看到的数据

抛一枚可能不均匀的硬币 10 次，出现 7 次正面。正面概率 p 估计为多少？大家会说 0.7。最大似然估计（MLE）给这个直觉一个通用的方法，逻辑回归、神经网络的交叉熵损失都由它推出。

点估计是用一个数去估计未知参数，例如用样本均值 x̄ 估计总体均值 μ。评价估计量常看两点：无偏（多次抽样的平均正好等于真值）和方差小。样本方差除 n − 1 就是为了无偏。

似然函数 L(θ) 是"把参数 θ 当变量，数据固定时，观察到这组数据的概率"。** 最大似然估计**就是找让 L(θ) 最大的 θ。连乘不好求导，通常取对数，最大化对数似然 ℓ(θ) = ln L(θ)。

10 次中 7 次正面：p=0.7 让这组数据出现的概率最大

最大似然手算：10 次 7 正

1 / 4

第1步 · 写出似然：每次独立，概率连乘

L(p) = p⁷ (1−p)³
p=0.5 时 L=0.000977；p=0.7 时 L=0.002224
2 / 4

第2步 · 取对数，把连乘变连加

ℓ(p) = 7 ln p + 3 ln(1−p)
3 / 4

第3步 · 求导并令其为 0

dℓ/dp = 7/p − 3/(1−p) = 0
7(1−p) = 3p
4 / 4

第4步 · 解出估计值

p̂ = 7/10 = 0.7
正好是样本中正面的比例

推广。 数据来自正态分布时，均值的 MLE 是样本均值；方差的 MLE 是除以 n 的那一个（对 [4, 6, 8] 得 8/3），它略有偏差，样本方差除 n − 1 得 4。在机器学习里：

  • 线性回归假设误差服从正态，最大似然等价于最小化平方误差（MSE）。
  • 逻辑回归和神经网络分类，最大似然等价于最小化交叉熵（2.17 节）。
  • 训练时常写"最小化负对数似然"（NLL），就是 MLE 换个符号。

要点：

  1. MLE：选择让已观察数据出现概率最大的参数。
  2. 步骤：写似然 → 取对数 → 求导令 0 → 解方程。
  3. 伯努利的 MLE 是样本比例，正态均值的 MLE 是样本均值。
  4. 正态方差的 MLE 除以 n，有偏；无偏的样本方差除以 n − 1。

2.8 置信区间：给估计值配一个误差范围

上一节得到一个估计值，但单个数字没说"多准"。抽 36 笔交易得到平均 200 元，真实均值可能是 195，也可能是 210。置信区间用一个范围来表达不确定性。[2]

定义。 95% 置信区间是按某个规则从样本算出的区间；如果反复抽样、每次都按同样规则造区间，大约 95% 的区间会盖住真实参数。真实参数是固定的，随机的是区间。

总体标准差已知时，均值的置信区间：

x̄ ± z × σ/√n

95% 用 z = 1.96，90% 用 1.645，99% 用 2.576。σ 未知时用样本标准差 s 代替，临界值改查 t 分布（自由度 n − 1），n 较大时 t 值接近 z 值。

示例： n = 36，x̄ = 200，σ = 60。

  1. 标准误 = 60/√36 = 10。
  2. 误差边界 = 1.96 × 10 = 19.6。
  3. 95% 置信区间 = [200 − 19.6, 200 + 19.6] = [180.4, 219.6]。

区间中心是样本均值，半宽是 1.96 个标准误

区间宽度由什么决定？ 宽度 = 2 × z × σ/√n。

改变结果
置信水平从 95% 降到 90%（z 从 1.96 到 1.645）区间变窄：[183.55, 216.45]
置信水平升到 99%（z = 2.576）半宽 25.76，区间变宽
样本量从 36 增到 144标准误 5，宽度从 39.2 减半到 3.6
数据波动 σ 变大区间变宽

更高的置信水平要付出"更宽"的代价；想要又窄又可靠，只能加样本。

要点：

  1. 区间 = 估计值 ± 临界值 × 标准误。
  2. 置信水平越高越宽，样本越多越窄（宽度 ∝ 1/√n）。
  3. 标准解释：按此方法反复构造的区间，约 95% 覆盖真值。
  4. σ 未知、样本小用 t 分布。

  • 第二类错误（取伪）：H0 本来是假的，却被保留，概率 β。
  • 功效 = 1 − β：真有差异时检出来的概率。

算一次功效。 上例中拒绝域是 x̄ > 219.6 或 x̄ < 180.4。若真实均值是 230，x̄ ~ N(230, 10²)，落入拒绝域的概率 ≈ 1 − Φ(−1.04) ≈ 0.851，所以 β ≈ 0.149。样本量越大、真实差异越大，功效越高。

多重比较。 同时做 20 个独立检验，每个 α = 0.05，即使全部 H0 为真，至少一个显著的概率 = 1 − 0.95²⁰ ≈ 0.64。只挑显著的那个报告，就是"p-hacking"，需要预先约定分析或做多重比较校正。

标准答案：

  1. p 值是在原假设成立的条件下，观察到当前或更极端结果的概率。
  2. 第一类错误是弃真，概率为 α；第二类错误是取伪，概率为 β；功效为 1 − β。
  3. 样本量固定时，α 越小，β 越大，两者此消彼长；加大样本量可同时降低。
  4. 统计显著还要看效应量与业务意义：大样本可以让很小的差异也显著。

2.10 卡方检验：用列联表判断两个类别变量是否有关

思路。 先假设两个变量独立（H0），算出"如果独立，每个格子应该有多少人"，即期望频数；再看实际观察频数和期望差多少。差得越多，越不像独立。

  • 期望频数 E = 行合计 × 列合计 / 总数。
  • 卡方统计量 χ² = Σ (O − E)² / E，O 是观察频数，对所有格子求和。
  • 自由度 df = (行数 − 1) × (列数 − 1)。
  • χ² 大于临界值（df = 1、α = 0.05 时为 3.841）就拒绝独立。

2.11 向量与矩阵：点积、余弦相似度与维度规则

一条客户记录 [年龄, 收入, 交易次数] 就是一个向量；1000 条记录摞起来就是 1000 × 3 的矩阵。模型的每一层都在做矩阵乘法，大模型检索靠向量的余弦相似度找相近文本。线性代数是 AI 的"数据接口"。[5]

基本对象。 标量是一个数；向量是一列数；矩阵是 m 行 n 列的数表，记作 m × n；张量是更多轴的数组，例如一批图片是 批量 × 通道 × 高 × 宽。

点积：对应位置相乘再相加，a·b = Σ aᵢbᵢ。[1, 2]·[3, 4] = 1×3 + 2×4 = 11。几何上 a·b = ‖a‖‖b‖cos θ，其中 ‖a‖ = √(a·a) 是向量长度（L2 范数），‖[3, 4]‖ = 5。

余弦相似度 cos θ = a·b / (‖a‖‖b‖)，只看方向，取值 [−1, 1]。1 表示方向相同，0 表示正交（毫不相关），−1 表示方向相反。

我们拿一个检索例子走一遍。查询 q = [1, 1, 0]，三篇文档 d1 = [2, 2, 0]、d2 = [1, 0, 1]、d3 = [0, 0, 3]。

文档点积 q·d‖d‖余弦欧氏距离
d1 = [2,2,0]42√21.0√2 ≈ 1.414
d2 = [1,0,1]1√20.5√2 ≈ 1.414
d3 = [0,0,3]030√11 ≈ 3.317

d1 和 d2 离 q 的欧氏距离一样，但 d1 与 q 方向完全相同（只是"更长"），余弦为 1。文本嵌入里长度常受文本长短影响，所以检索常用余弦，第 6 章的向量检索会用到。

矩阵乘法维度规则。 A 是 m × n，B 是 n × p，AB 才有定义，结果是 m × p："内维相同，外维保留"。结果第 i 行第 j 列 = A 的第 i 行与 B 的第 j 列的点积。

一个全连接层就是一次矩阵乘法：(32×784)(784×128) → 32×128；参数量 784×128+128=100480

小例子手算：X = [[1, 2], [3, 4]]（2 × 2），W = [[5], [6]]（2 × 1），XW = [[1×5 + 2×6], [3×5 + 4×6]] = [[17], [39]]（2 × 1）。每一行样本与权重做一次点积，得到一个预测分数。

其他规则： 矩阵乘法一般不可交换，AB ≠ BA，有时一个有定义另一个没有；转置交换行列，(AB)ᵀ = BᵀAᵀ，顺序反转；单位矩阵 I 像乘法里的 1，AI = A。

要点：

  1. (m × n)(n × p) = m × p，内维相等才能乘。
  2. 点积 = 对应相乘再相加；余弦 = 点积 ÷ 两个长度。
  3. 余弦只看方向，欧氏距离同时受长度影响。
  4. AB ≠ BA，(AB)ᵀ = BᵀAᵀ。

2.12 秩、逆与特征值：矩阵把空间怎样变形

PCA 要找"数据变化最大的方向"，LoRA 要用"低秩矩阵"压缩参数，这两件事都需要先看懂矩阵对空间做了什么。把矩阵看成一个变换：它把每个向量映射成另一个向量。秩、逆、特征值分别回答"压扁了没有""能否还原""哪些方向只伸缩不转弯"。

秩是矩阵中线性无关的列（或行）的最大个数，即"独立信息方向的个数"。两列 [1, 2, 3] 和 [2, 4, 6] 中第二列是第一列的 2 倍，只有一个独立方向，秩为 1。

逆矩阵 A⁻¹ 满足 AA⁻¹ = I，能把变换还原回去。只有方阵且满秩（行列式 ≠ 0）才有逆。2 × 2 矩阵 [[a, b], [c, d]] 的逆 = (1/(ad − bc)) × [[d, −b], [−c, a]]。

  • A = [[2, 1], [1, 1]]：行列式 2×1 − 1×1 = 1，逆 = [[1, −1], [−1, 2]]，验证 AA⁻¹ = I。
  • [[1, 2], [2, 4]]：行列式 1×4 − 2×2 = 0，秩 1，没有逆：它把整个平面压到一条直线上，信息丢了，还原不回来。

特征值与特征向量。 若非零向量 v 满足 Av = λv，v 就是 A 的特征向量，λ 是对应的特征值。几何意义：A 作用在 v 上，v 方向不变（λ < 0 时反向），只是长度伸缩 λ 倍。

我们看 S = [[2, 1], [1, 2]]：

  • v = (1, 1)：Sv = (3, 3) = 3v，方向不变，拉长 3 倍，λ₁ = 3。
  • w = (1, −1)：Sw = (1, −1) = 1·w，方向不变，长度不变，λ₂ = 1。
  • u = (1, 0)：Su = (2, 1)，方向变了，u 不属于特征向量。

特征向量经过变换只伸缩不转弯；普通向量会被转向

怎样求特征值。 解特征方程 det(A − λI) = 0。对 S：(2 − λ)² − 1 = 0，λ = 3 或 1。两个检查：特征值之和 = 迹（对角线之和）2 + 2 = 4；特征值之积 = 行列式 4 − 1 = 3。

对称矩阵的好性质。 协方差矩阵这类实对称矩阵，特征值都是实数，不同特征值的特征向量互相正交。PCA 正是利用了这一点。

要点：

  1. 秩 = 独立方向个数；满秩方阵才可逆，行列式为 0 就没有逆。
  2. Av = λv：特征向量方向不变，特征值是伸缩倍数。
  3. 特征值之和 = 迹，之积 = 行列式。
  4. 实对称矩阵的特征值为实数，特征向量正交。

2.13 PCA 与 SVD：二维数据完整手算

客户有几十个高度相关的特征（月收入、年收入、存款……），我们想用少数几个综合指标概括它们，既便于可视化，也能去掉冗余。主成分分析（PCA）找出数据方差最大的方向，把数据投影上去，用更少的坐标保留大部分变化。[6]

PCA 的步骤： 先中心化（每个特征减去均值），再计算协方差矩阵，然后求特征值和特征向量，按特征值从大到小选出前 k 个方向，最后把数据投影到这些方向上。特征向量叫作主成分方向，特征值是数据在该方向上的方差。

我们用 4 个二维点完整做一遍：A(1, 1)、B(2, 3)、C(3, 2)、D(4, 4)。协方差用除以 n − 1 的样本版本（与 scikit-learn 一致）。

SVD 的直观理解。 奇异值分解把任意 m × n 矩阵写成 A = UΣVᵀ：U、V 是正交矩阵（只做旋转或翻转），Σ 是对角矩阵，对角线上的奇异值从大到小排列。从几何上看，任何线性变换都可以分解为三步：旋转、沿坐标轴伸缩、再旋转。

SVD：任何矩阵 = 旋转 × 伸缩 × 旋转；奇异值就是伸缩倍数

SVD 与 PCA 的关系。 把上例中心化后的 4 × 2 数据矩阵记为 X，XᵀX = 3C = [[5, 4], [4, 5]]，特征值 9 和 1，所以 X 的奇异值是 3 和 1，满足 奇异值² / (n − 1) = 特征值（9/3 = 3）。实际软件常直接对 X 做 SVD 来算 PCA，数值更稳定。

低秩近似。 只保留最大的 k 个奇异值，得到最好的秩 k 近似（平方误差意义下）。上例保留奇异值 3，保留了 9/(9+1) = 90% 的平方和。一个 1000 × 1000 矩阵用秩 10 近似，只需存 1000×10 + 10 + 10×1000 = 20010 个数，原来是 100 万个。LoRA 微调就是用两个细长矩阵的乘积表示权重的低秩更新（第 5 章）。

要点：

  1. PCA 是无监督降维：中心化 → 协方差 → 特征分解 → 投影。
  2. 主成分方向是协方差矩阵的特征向量，方差等于特征值，各主成分互相正交。
  3. 解释方差比 = λᵢ / Σλ，用来决定保留几个主成分。
  4. SVD：A = UΣVᵀ，旋转-伸缩-旋转；截断 SVD 给出最优低秩近似。

易错点：

  • PCA 的主成分是原特征的线性组合，这和"从原表里挑几列"的特征选择是两种做法。
  • PCA 不看标签，方差最大的方向未必最利于分类；特征量纲差别大时要先标准化，否则大数值特征主导结果。
  • 在测试集上重新拟合 PCA 会造成数据泄漏，应只在训练集上拟合（第 1 章）。

小结： PCA 依次进行中心化、计算协方差矩阵、特征分解和投影；特征值等于数据在对应方向上的方差；SVD 把线性变换分解为旋转、伸缩、再旋转。

2.14 导数、偏导、梯度与链式法则：计算图上的反向传播

模型训练的核心问题是"每个参数往哪边调、调多少，损失才会下降"。导数给出单个参数的变化率，梯度把所有参数的变化率排成一个向量，链式法则让我们在多层模型里逐层把它算出来。[7]

导数 f′(x) 描述 x 附近改变一点点时 f 改变多少：f(x + Δx) ≈ f(x) + f′(x)Δx。f(w) = w² 在 w = 3 处导数为 6：w 增加 0.01，f 约增加 0.06。

偏导：多个变量时，固定其他变量，只对一个求导，记作 ∂f/∂x。f(x, y) = x² + 3y²，∂f/∂x = 2x，∂f/∂y = 6y。

梯度 ∇f 是所有偏导排成的向量，指向函数增长最快的方向，长度是增长率。上例在 (1, 1) 处 ∇f = (2, 6)。所以沿 −∇f 走，下降最快，这就是梯度下降。

链式法则。 若 y = f(g(x))，则 dy/dx = f′(g(x)) · g′(x)：外层导数乘内层导数。多层嵌套就一路乘下去。神经网络把计算写成一张计算图，前向算出每个节点的值，反向从损失出发，把局部导数逐个相乘，这就是反向传播。

  3. 反向传播 = 在计算图上从损失往回应用链式法则。
  4. sigmoid′ = σ(1 − σ) ≤ 0.25；softmax 加交叉熵对 logits 的梯度是 p − y。

2.15 梯度下降与凸性：沿最陡的下坡走

上一节算出了梯度，下一步是用它更新参数。梯度下降是几乎所有模型训练的基础，学习率选得好坏决定能否收敛。凸性则告诉我们，什么情况下找到的最低点就是全局最低点。[8]

梯度下降：反复执行 θ ← θ − η∇L(θ)。η 是学习率（步长）。每一步沿负梯度方向走一小步。

示例： 最小化 f(w) = (w − 3)²，导数 2(w − 3)，最优点 w* = 3。从 w = 0 出发：

  • η = 0.1：w₁ = 0 − 0.1×2×(0 − 3) = 0.6，w₂ = 0.6 − 0.1×2×(0.6 − 3) = 1.08，之后 1.464、1.771……稳步逼近 3。
  • 规律：每一步 w − 3 乘以 (1 − 2η)。η = 0.1 时乘 0.8，误差每步缩到 80%。
  • η = 0.9 时乘 −0.8：w 在 3 的两侧来回跳（5.4、1.08、4.536……），振荡着收敛。
  • η = 1.1 时乘 −1.2：6.6、−1.32、8.184、−3.221……越跳越远，发散。

小学习率平稳逼近；大学习率在最优点两侧振荡；η=1.1 会发散（未画出）

三种批量方式。 每步用全部样本算梯度叫批量梯度下降（稳定但慢）；每步只用一个样本叫随机梯度下降 SGD（快但抖）；每步用一小批（如 32、64 个）叫小批量梯度下降，是深度学习的默认做法。Momentum、Adam 等优化器在此基础上加入动量和自适应步长。

凸函数。 函数图像上任取两点连一条弦，弦总在函数图像的上方（或重合），这个函数就是凸函数。精确写法：f(θa + (1−θ)b) ≤ θf(a) + (1−θ)f(b)，对所有 θ ∈ [0, 1] 成立。一元函数只要二阶导数处处 ≥ 0 就是凸的。

例：f(t) = (t − 3)²，取 a = 0、b = 4 的中点 2，f(2) = 1，而两端平均 (9 + 1)/2 = 5，1 ≤ 5。

凸函数只有一个谷；非凸函数有两个谷，梯度下降落进哪个取决于起点

在非凸函数 t⁴ − 2t² 上，从 t = 0.25 出发做梯度下降会落到 +1，从 −0.25 出发会落到 −1。凸函数没有这个烦恼：凸函数的局部最小值就是全局最小值。线性回归的 MSE、逻辑回归的交叉熵对参数是凸的；神经网络的损失是非凸的，但实践中小批量 SGD 仍能找到效果很好的解。[9]

要点：

  1. 更新规则 θ ← θ − η∇L；学习率过大振荡或发散，过小收敛慢。
  2. 凸函数：弦在图像上方，二阶导 ≥ 0；局部最优即全局最优。
  3. 线性回归、逻辑回归的损失是凸的，神经网络是非凸的。
  4. 小批量梯度下降兼顾速度和稳定，是深度学习默认方式。

2.16 拉格朗日乘子：带约束的最优化

很多问题是"在某个限制下找最优"：预算固定时收益最大，向量长度为 1 时方差最大（PCA），间隔约束下最大化间隔（SVM）。拉格朗日乘子法把约束和目标合到一个式子里处理。

直观图景。 要在约束曲线 g(x, y) = c 上找 f 的最小值。沿着约束线走，f 的值会变化；在最优点，再沿约束线挪一点点，f 也降不下去了。这时 f 的等高线恰好与约束线相切，两者的法向量平行，也就是：

∇f = λ∇g

λ 就是拉格朗日乘子。把它和约束一起写成拉格朗日函数 𝓛(x, y, λ) = f(x, y) − λ(g(x, y) − c)，令所有偏导为 0 即可。

示例： 在 x + y = 2 上找 f = x² + y² 的最小值（直线上离原点最近的点）。

  1. ∇f = (2x, 2y)，∇g = (1, 1)。
  2. 令 ∇f = λ∇g：2x = λ，2y = λ，所以 x = y。
  3. 代入约束 x + y = 2，得 x = y = 1，λ = 2，最小值 f = 2。

我们也可以换一种看法检验：把约束代入，y = 2 − x，f 变成一元函数 x² + (2 − x)²，画出来就是一条抛物线，最低点在 x = 1。

只在约束线上看，f 在 x=1 处最小；拉格朗日条件 ∇f=λ∇g 给出同一个点

再看 PCA。 PCA 要在 ‖u‖ = 1 的条件下最大化投影方差 uᵀCu。写出拉格朗日函数 uᵀCu − λ(uᵀu − 1)，对 u 求导令其为 0，得到 Cu = λu，恰好是特征方程。所以主成分就是协方差矩阵的特征向量，投影方差就是特征值。在 2.13 的数据上，u = (1, 1)/√2 给出 uᵀCu = 3，单位圆上其他方向都在 3 以下。

不等式约束。 约束是 g ≤ c 时，推广为 KKT 条件：最优点要么在边界上（约束起作用，λ > 0），要么在内部（约束没起作用，λ = 0）。SVM 的对偶问题和"支持向量"就来自这里：只有落在间隔边界上的样本 λ > 0（第 3 章）。

要点：

  1. 拉格朗日乘子法：在最优点 ∇f = λ∇g，目标的等高线与约束相切。
  2. 构造 𝓛 = f − λ(g − c)，对所有变量和 λ 求偏导令其为 0。
  3. PCA 的特征方程 Cu = λu 可由拉格朗日乘子法推出。
  4. 不等式约束用 KKT 条件，SVM 的支持向量对应 λ > 0 的样本。

2.17 熵、交叉熵与 KL 散度：用信息衡量不确定和差异

分类模型输出"欺诈概率 0.7"，我们要一个数来衡量"这个预测离真实答案有多远"；大模型对齐时，又要衡量"新模型的输出分布偏离原模型多少"。信息论提供了三把尺子：熵、交叉熵、KL 散度。[10]

信息量与熵。 一个概率为 p 的事件发生时，带来的信息量是 −log p：越意外，信息越多。** 熵** H(P) = −Σ pᵢ log pᵢ 是信息量的期望，衡量分布的不确定性。以 2 为底时单位是 bit，以 e 为底时单位是 nat。

  • 必然事件 [1, 0]：H = 0，没有不确定性。
  • 公平硬币 [0.5, 0.5]：H = 1 bit，二分类中最大。
  • 四个等可能结果：H = 2 bit。
  • [0.9, 0.1]：H ≈ 0.469 bit，比较确定。

二分类熵：越接近一半一半越不确定，越接近 0 或 1 越确定

交叉熵 H(P, Q) = −Σ pᵢ log qᵢ：真实分布是 P，却用预测分布 Q 去编码时的平均信息量。分类中 P 是 one-hot 标签，交叉熵就简化为 −log(真实类别的预测概率)。

  • 三分类真实是第 1 类，预测 [0.7, 0.2, 0.1]：损失 = −ln 0.7 ≈ 0.357 nat。
  • 预测 [0.2, 0.7, 0.1]（把概率给错了类）：损失 = −ln 0.2 ≈ 1.609 nat。

预测越自信地错，损失越大。深度学习框架默认用自然对数，单位是 nat。

KL 散度 KL(P‖Q) = Σ pᵢ log(pᵢ/qᵢ)，衡量"用 Q 近似 P 时多付出的信息量"。它满足 KL ≥ 0，当且仅当 P = Q 时为 0。三者的关系是：

H(P, Q) = H(P) + KL(P‖Q)

真实分布 P 固定时，H(P) 是常数，所以最小化交叉熵等价于最小化 KL 散度。

KL 不对称：数值演示。 取 P = [0.5, 0.5]，Q = [0.9, 0.1]，用自然对数：

同一对分布，交换顺序后 KL 从 0.511 变成 0.368

表中四项分别是：0.5·ln(0.5/0.9) = −0.294，0.5·ln(0.5/0.1) = 0.805；0.9·ln(0.9/0.5) = 0.529，0.1·ln(0.1/0.5) = −0.161。核对：H(P) = ln 2 ≈ 0.693，H(P, Q) = −0.5 ln 0.9 − 0.5 ln 0.1 ≈ 1.204，相减正好是 0.511。

为什么不对称？KL(P‖Q) 用 P 加权：P 在第 2 类有 0.5 的概率，而 Q 只给 0.1，这一项惩罚很重（0.805）。反过来 KL(Q‖P) 用 Q 加权，第 2 类权重只有 0.1，惩罚就轻了。所以 KL 散度是"有方向的差异"，也叫相对熵，它违反了距离要求的对称性。RLHF 里的 KL 惩罚写作 KL(π_新‖π_参考)，方向是固定的（第 7 章）。

要点：

  1. 熵衡量不确定性，均匀分布最大，确定分布为 0。
  2. 交叉熵 = 熵 + KL；分类损失 = −log(真实类别的预测概率)。
  3. KL ≥ 0，P = Q 时为 0；KL(P‖Q) ≠ KL(Q‖P)，因此 KL 散度算不上距离。
  4. 最小化交叉熵等价于最大似然，也等价于最小化 KL(数据‖模型)。

2.18 互信息与信息增益：特征能消除多少不确定性

决策树每次分裂要选一个特征："有无逾期记录"和"是否有房"哪个对预测违约更有用？信息增益回答"知道这个特征后，对标签的不确定性减少了多少"。它和互信息是同一个量。[11]

条件熵 H(Y|X) 是知道 X 后 Y 剩余的不确定性，计算方法是按 X 的每个取值分组，算各组 Y 的熵，再按组的人数比例加权平均。

信息增益 IG(Y, X) = H(Y) − H(Y|X)，即父节点熵减去加权子节点熵。** 互信息** I(X; Y) = H(Y) − H(Y|X) = H(X) − H(X|Y)，对称，衡量两个变量共享多少信息；在决策树里，信息增益就是特征与标签的互信息。

示例： 10 名客户中 4 人违约、6 人正常。按"有无逾期记录"分组：

  1. 父节点熵：H = −0.4 log₂0.4 − 0.6 log₂0.6 ≈ 0.971 bit。
  2. 有逾期组：p = 3/4，H = −0.75 log₂0.75 − 0.25 log₂0.25 ≈ 0.811。
  3. 无逾期组：p = 1/6，H ≈ 0.650。
  4. 加权子熵：0.4 × 0.811 + 0.6 × 0.650 ≈ 0.7145。
  5. 信息增益：0.971 − 0.7145 ≈ 0.256 bit。

用互信息公式 I = Σ p(x, y) log₂[p(x, y) / (p(x)p(y))] 对联合概率表 [[0.3, 0.1], [0.1, 0.5]] 计算，得到同样的 0.256，验证了两者相等。

极端情况。 父节点 2 正 2 负（H = 1），若某特征把它分成"2 个全正"和"2 个全负"，子熵都是 0，信息增益 = 1 bit，达到最大。若特征与标签独立，分组后每组比例和父节点一样，信息增益为 0。

基尼不纯度。 CART 决策树用 Gini = 1 − Σpᵢ²。上例父节点 Gini = 1 − 0.4² − 0.6² = 0.48；2 正 2 负时 Gini = 0.5，熵 = 1。两种指标的数值尺度不同，各自只在同类之间比较。

要点：

  1. 信息增益 = 父熵 − 加权子熵，选增益最大的特征分裂（ID3）。
  2. 信息增益就是特征和标签的互信息，互信息对称且 ≥ 0，独立时为 0。
  3. 信息增益偏好取值多的特征，C4.5 用信息增益率修正，CART 用基尼指数（第 3 章）。
  4. 互信息能捕捉非线性关系，比相关系数更一般，可用于特征选择（第 4 章）。

多选 · 理解检查 19　4 样本 2 正 2 负，熵以 2 为底。若分裂成全正的 2 个和全负的 2 个，哪些正确？

A. 父熵 1 bit，子熵都为 0

B. 信息增益 1 bit

C. 父节点 Gini 也是 1

D. 选特征只看某一个子节点很纯就够

查看答案与每个选项的解析

A · 正确：均匀二分类熵为 1，纯类别熵为 0。

B · 正确：1 − (2/4×0 + 2/4×0) = 1。

C · 错误：1 − 0.5² − 0.5² = 0.5。

D · 错误：要按各子节点的样本比例加权，一个只含 1 人的纯节点贡献很小。

易错点：

  • 加权子熵的权重是各组人数占比，直接把两组熵平均会算错。
  • 像"客户编号"这种每人一个值的特征，信息增益最大但毫无泛化能力，这正是需要信息增益率的原因。

小结： 信息增益等于父结点的熵减去子结点熵的加权平均，也等于特征与标签之间的互信息；信息增益越大，说明这个特征越能消除标签的不确定性。
