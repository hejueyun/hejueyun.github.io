2.6 numeric 与数值：求和、前缀和、gcd、极值常量、溢出与取模 选读

练习 2.6-4【改错】面积溢出

题面：area(100000, 100000) 应为 10000000000，下面的函数返回了一个错误的数（这是有符号溢出，属于未定义行为）。

long long area(int w, int h) {
    return w * h;
}
提示

返回类型是 long long，但 w * h 两边都是 int，乘法在 int 里完成，已经溢出了；结果再转成 long long 也救不回来。让其中一个操作数先变成 long long。

参考答案
long long area(int w, int h) {
    return 1LL * w * h;
}
def area(w, h):
    return w * h                         # Python 整数是任意精度，不会溢出

练习 2.6-5【函数】非负取模

题面：返回 a 除以 m 的非负余数（m > 0，a 可以是负数）。

样例：modPos(-7, 3) → 2；modPos(10, 4) → 2；modPos(-6, 3) → 0。

提示

先 a % m 得到 (−m, m) 之间的数，加 m 变成 (0, 2m)，再 % m。

参考答案
int modPos(long long a, int m) {
    return (int)((a % m + m) % m);
}
def mod_pos(a, m):
    return a % m                         # Python 的 % 结果和除数同号，m > 0 时天然非负

练习 2.6-6【函数】一组数的最小公倍数

题面：v 中都是 1～40 的正整数，返回它们的最小公倍数（保证结果在 long long 范围内）。

样例：{4, 6} → 12；1..10 → 2520；1..20 → 232792560。

提示

逐个合并：l = lcm(l, x)。手写时先除后乘 l / gcd(l, x) * x，避免 l * x 先溢出。gcd 的两个参数类型要一致，所以把 x 转成 long long。

参考答案
long long lcmAll(const vector<int>& v) {
    long long l = 1;
    for (int x : v) l = l / gcd(l, (long long)x) * x;
    return l;
}
def lcm_all(v):
    l = 1
    for x in v:
        l = l // math.gcd(l, x) * x      # Python 3.9+ 也可以直接 math.lcm(*v)
    return l

练习 2.6-7【一行】是不是 2 的幂

题面：n 是 int，判断它是否为 2 的幂（1、2、4、8……）。函数体只写一行。

样例：16 → true；12 → false；0 → false；−8 → false。

参考答案
bool isPowerOfTwo(int n) {
    return n > 0 && __builtin_popcount(n) == 1;
}

练习 2.6-8【函数】前缀和回答区间和

题面：对每个询问 (l, r)（0 ≤ l ≤ r < n），返回 v[l] + … + v[r]。

样例：v = {2, -1, 3, 4}，询问 (0, 1)、(1, 3)、(2, 2) → {1, 6, 3}。

提示

建 pre，长度 n+1，pre[0] = 0，pre[i+1] = v[0] + … + v[i]；区间和 = pre[r + 1] - pre[l]。partial_sum 的输出起点写 pre.begin() + 1。

参考答案
vector<long long> rangeSums(const vector<int>& v, const vector<pair<int, int>>& qs) {
    vector<long long> pre(v.size() + 1, 0);
    partial_sum(v.begin(), v.end(), pre.begin() + 1);   // 累加器类型跟 v 的元素走（int）：总和可能超过 int 时先把 v 转成 long long
    vector<long long> out;
    for (auto [l, r] : qs) out.push_back(pre[r + 1] - pre[l]);
    return out;
}
def range_sums(v, qs):
    pre = list(itertools.accumulate(v, initial=0))   # initial=0 让 pre[0] = 0（Python 3.8+）
    return [pre[r + 1] - pre[l] for l, r in qs]

易错点

  • accumulate 的结果类型由初值决定：求 long long 和写 0LL，求小数和写 0.0。
  • (long long)(a * b) 太晚，乘法已经在 int 里溢出；写 1LL * a * b。
  • 负数取模结果为负，做数组下标或哈希桶号前要用 ((a % m) + m) % m 调整。

小结： accumulate 的初值决定结果类型（0LL、0.0）；乘法之前先乘 1LL；/ 向零截断，% 的符号与被除数相同，需要非负余数时写 (a % m + m) % m；gcd 和 lcm 在 <numeric> 中。

易错点

  • 题目要求"按某种顺序输出"时，直接遍历 unordered_map 的结果顺序不确定；先拷出来 sort，或者改用 map。
  • 用 if (m[x]) 判断存在会插入 x；在遍历这个表的循环里这样写还会让迭代器失效。

vector<int> mergeSortedArrays(const vector<vector<int>>& arrs) {
    using T = tuple<int, int, int>;                  // {值, 第几个数组, 数组内下标}
    priority_queue<T, vector<T>, greater<T>> pq;
    for (int i = 0; i < (int)arrs.size(); ++i)
        if (!arrs[i].empty()) pq.emplace(arrs[i][0], i, 0);
    vector<int> out;
    while (!pq.empty()) {
        auto [val, i, j] = pq.top();
        pq.pop();
        out.push_back(val);
        if (j + 1 < (int)arrs[i].size()) pq.emplace(arrs[i][j + 1], i, j + 1);
    }
    return out;
}
def merge_sorted_arrays(arrs):
    h = [(a[0], i, 0) for i, a in enumerate(arrs) if a]
    heapq.heapify(h)
    out = []
    while h:
        val, i, j = heapq.heappop(h)
        out.append(val)
        if j + 1 < len(arrs[i]):
            heapq.heappush(h, (arrs[i][j + 1], i, j + 1))
    return out

    for (int i = 0; i < (int)v.size(); ++i) {
        while (!dq.empty() && v[dq.back()] <= v[i]) dq.pop_back();
        dq.push_back(i);
        if (dq.front() <= i - k) dq.pop_front();
        if (i >= k - 1) out.push_back(v[dq.front()]);
    }
    return out;
}
def window_max_deque(v, k):
    dq = deque()
    out = []
    for i in range(len(v)):
        while dq and v[dq[-1]] <= v[i]:
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()
        if i >= k - 1:
            out.append(v[dq[0]])
    return out

多选 · 理解检查 2　想让 priority_queue 里 dist 最小的元素先出堆，下面哪些写法正确？

A. priority_queue<pair<int,int>, vector<pair<int,int>>, greater<pair<int,int>>>，元素放 {dist, node}

B. priority_queue<pair<int,int>>，元素放 {-dist, node}

C. lambda 比较器写 return a.dist < b.dist;

D. lambda 比较器写 return a.dist > b.dist;

查看答案与每个选项的解析

A · 正确：greater 得到小根堆，pair 先比 first，即 dist。

B · 正确：大根堆里 -dist 最大的就是 dist 最小的，取出后再取负。

C · 错误：这样 dist 大的被认为优先级高，得到的是 dist 最大先出。

D · 正确：cmp(a,b) 为 true 表示 a 更晚出堆：dist 大的更晚出，于是小的先出。

易错点

  • pop() 不返回值：int x = pq.pop(); 编译失败，先 top() 再 pop()。
  • 比较器方向：priority_queue 的 cmp 与 sort 的 cmp 写法相同，效果相反——sort 里 a < b 得到升序，堆里 a < b 得到大根堆。
  • 适配器不能遍历、没有 clear()；需要遍历就改用 deque 或 vector。

小结： 栈的 top、队列的 front 读取元素，pop 不返回值；堆默认是大根堆，加 greater 是小根堆；自定义比较器返回 true 表示 a 更晚出堆，所以想让小的先出就写 >。
