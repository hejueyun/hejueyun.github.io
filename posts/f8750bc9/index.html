25.1 读写指针：在原数组上"挑出要留的"

模式识别。 题目说"原地修改数组""不要使用额外的数组空间""返回新长度""保持相对顺序"，并且要做的是"删掉一些元素"或"把某类元素挪到一边"。典型题：283 移动零、27 移除元素、26 删除有序数组中的重复项。

核心思想。 用两个下标扫同一个数组：read 逐个读原数据，write 指向下一个要写入的位置。不变式只有一句：

[0, write) 是已经确定保留的元素，并且保持原来的先后顺序；read 是下一个要检查的元素。

因为每保留一个元素 write 才加 1，而 read 每轮都加 1，所以 write ≤ read 始终成立。写入 a[write] 只会覆盖已经读过的位置，没读过的数据不会被破坏。

三段：已保留 | 可以被覆盖的废位 | 还没看的；read 永远不落后于 write

通用模板。 把"保留谁"抽成一个判断函数 keep，其余代码对所有这类题都一样：

变量含义
write下一个保留元素要写入的位置，也等于已保留的个数
read正在检查的元素下标
keep(x)返回 true 表示 x 要留下
template <class Keep>
int keepIf(vector<int>& a, Keep keep) {
    int write = 0;                                  // [0, write)：已经保留下来的元素，保持原顺序
    for (int read = 0; read < (int)a.size(); ++read) {
        if (keep(a[read])) a[write++] = a[read];    // 要保留：写到 write 处，write 右移一格
    }
    return write;                                   // 保留下来的个数
}

例题 283 移动零

把所有 0 移到末尾，非零元素保持原顺序，原地完成。[1]

状态契约

  1. 输入输出：vector<int>& nums，原地修改，无返回值；要求 O(1) 额外空间。
  2. 变量：write 是已排好的非零元素个数；read 是正在看的元素。
  3. 不变式：nums[0..write) 是 nums[0..read) 中所有非零元素，按原顺序排列。
  4. 一步：nums[read] 非零就写到 write 处并 write++；是 0 就跳过。非零元素一个都没丢，因为每个非零元素都在被读到的那一轮写下了。
  5. 结束：read 走到 n 时，前 write 格就是全部非零元素；把 [write, n) 补 0。read 每轮加 1，循环必然结束。

void moveZeroes(vector<int>& nums) {
    int write = keepIf(nums, [](int x) { return x != 0; });     // 非零元素按原顺序挤到前面
    for (int i = write; i < (int)nums.size(); ++i) nums[i] = 0;  // 剩下的位置补 0
}

复杂度：时间 O(n)，每个元素读一次、最多写两次；额外空间 O(1)。

例题 27 移除元素

删除所有等于 val 的元素，返回剩余个数 k，前 k 个位置放剩余元素（后面的内容不检查）。[2] 契约与 283 相同，只把"非零"换成"不等于 val"，并且最后返回 write 而不必补零。

int removeElement(vector<int>& nums, int val) {
    int write = 0;                                  // [0, write)：不等于 val 的元素
    for (int read = 0; read < (int)nums.size(); ++read) {
        if (nums[read] != val) nums[write++] = nums[read];
    }
    return write;                                   // 新长度
}

时间 O(n)，空间 O(1)。

规律与考场结论。

  • "原地 + 保序 + 删/挪"就用读写指针；保留条件写进一个 if，其余代码一模一样。
  • 返回值是 write，它同时是"新长度"和"下一个写入位置"。
  • 26 题（有序数组去重）的保留条件是"write == 0 或 nums[read] != nums[write-1]"，即与已保留的最后一个元素不同。

单选 · 理解检查 1　对 nums=[0,1,2,2,3,0,4,2] 执行 removeElement(nums, 2)。返回值和前几个元素是什么？

A. 返回 5，前 5 个是 [0,1,3,0,4]

B. 返回 5，前 5 个是 [0,0,1,3,4]

C. 返回 3

D. 返回 8，因为数组长度没变

查看答案与每个选项的解析

A · 正确：去掉三个 2 后剩 5 个元素，读写指针保持原顺序。

B · 错误：读写指针不排序，保留的是原来的先后顺序。

C · 错误：3 是被删掉的个数，函数返回的是剩下的个数 write。

D · 错误：数组物理长度没变，但题目要的是有效长度 k。

易错点和变式。

  • 283 若用"遇到非零就和 nums[write] 交换"，结果同样正确，还省掉了补零循环；两种写法任选其一，契约相同。
  • 循环条件写 read < (int)nums.size()，空数组时直接跳过（22.5 讲过 size() 无符号的问题）。
  • 80 题"每个数最多留两个"：保留条件改成 write < 2 || nums[read] != nums[write-2]，模板不变。

速记： [0,write) 是保留区，read 只管往前读；保留就 a[write++]=a[read]，最后返回 write。

25.2 哈希表：把"再扫一遍"变成"查一下"

模式识别。 题目要你"找一个和某值配对的元素""统计出现次数""判断是否出现过""把同类的东西分到一组"，而暴力做法是两层循环、第二层在"找某个值"。典型题：1 两数之和、49 字母异位词分组、128 最长连续序列、217 存在重复元素。

核心思想。 哈希表用平均 O(1) 回答"某个键在不在、对应什么值"（原理见 04 章，C++ 用法见 22.7）。用法有两类：查找（键是值，存下标或存在性）和分组/计数（键是"签名"，值是一组元素或次数）。不变式：

扫描到第 i 个元素时，表里恰好记录了前 i 个元素的信息（先查后存）。

分组题的关键是设计签名：所有"应该算同一类"的东西必须得到同一个键，不同类的必须得到不同的键。

哈希的核心：把"应该算同一类"的东西映射到同一个键，再用键找桶

通用模板（先查后存）。

变量含义
seen已经扫过的元素（或它们的信息）
x当前元素；先拿它去表里查，再把它放进表
bool containsDuplicate(const vector<int>& nums) {
    unordered_set<int> seen;                 // 已经扫过的值
    for (int x : nums) {
        if (seen.count(x)) return true;      // 先查：x 之前出现过
        seen.insert(x);                      // 后存：把 x 记下来，留给后面的元素查
    }
    return false;
}

例题 1 两数之和

找出和为 target 的两个数的下标，同一个元素不能用两次，题目保证恰有一个答案。[3] 22.7 已经讲过这题和"先查后存"；这里补上完整契约和一个"答案不在开头"的例子。

状态契约

  1. 输入输出：数组和 target，返回两个下标；要求优于 O(n²)。
  2. 变量：seen 是"值 → 下标"，只存 i 之前的元素；i 是当前下标。
  3. 不变式：进入第 i 轮时，seen 恰好包含 nums[0..i)。
  4. 一步：查 target - nums[i]，找到就返回；找不到就存入 nums[i] → i。若答案是 (j, i) 且 j < i，那么第 i 轮时 j 已在表里，一定能查到。
  5. 结束：找到即返回；i 每轮加 1。

第1步 · i=0，nums[i]=3，需要 3：表里没有；存入 3→0

2 / 3

第2步 · i=1，nums[i]=2，需要 4：表里没有；存入 2→1

3 / 3

vector<int> twoSum(const vector<int>& nums, int target) {
    unordered_map<int, int> seen;            // 值 -> 下标，只存 i 之前的元素
    for (int i = 0; i < (int)nums.size(); ++i) {
        auto it = seen.find(target - nums[i]);
        if (it != seen.end()) return {it->second, i};
        seen[nums[i]] = i;                   // 先查后存：自己不会和自己配对
    }
    return {};
}

def two_sum(nums, target):
    seen = {}                         # 值 -> 下标，只含当前位置之前的元素
    for i, x in enumerate(nums):
        if target - x in seen:
            return [seen[target - x], i]
        seen[x] = i                   # 先查后存
    return []

时间期望 O(n)，空间 O(n)。重复值 [3,3] 也正确：第 0 轮表为空，存入 3→0；第 1 轮查到 3→0，返回 [0,1]。

例题 49 字母异位词分组

把由相同字母重新排列得到的单词分到一组。[4]

状态契约

  1. 输入输出：字符串数组，返回分组（组的顺序任意）。
  2. 变量：groups 是"签名 → 这组单词"；key 是当前单词排序后的字符串。
  3. 不变式：处理完前 i 个单词后，每个单词都在自己签名对应的组里。
  4. 一步：算签名、追加到对应组。两个词互为异位词 ⇔ 字母排序后相同，所以分组既不多也不少。
  5. 结束：所有单词处理完，把每组取出。

vector<vector<string>> groupAnagrams(const vector<string>& strs) {
    unordered_map<string, vector<string>> groups;   // 签名 -> 这一组的单词
    for (const string& s : strs) {
        string key = s;
        sort(key.begin(), key.end());               // 字母排序后的串就是签名
        groups[key].push_back(s);
    }
    vector<vector<string>> ans;
    for (auto& [key, words] : groups) ans.push_back(words);
    return ans;
}

复杂度：n 个词、最长 k，排序签名 O(n·k log k)。只含小写字母时，也可以用"26 个计数拼成的字符串"作签名，做到 O(n·k)。

例题 128 最长连续序列

无序数组中，找数值连续（如 1,2,3,4）的最长元素序列的长度，要求 O(n)。[5]

状态契约

  1. 输入输出：整数数组，返回长度；排序是 O(n log n)，题目要 O(n)。
  2. 变量：st 是去重后的集合；x 是候选起点；y 是从 x 往上数到的最后一个数；best 是目前最长长度。
  3. 不变式：best 是所有已经处理过的"起点"出发能数到的最长长度。
  4. 一步：若 x-1 在集合里，x 是某段的中间，跳过；否则 x 是一段的起点，从 x 一直数到 y。每一段恰好有一个起点，所以每段都被数到，且只数一次。
  5. 结束：遍历完集合，返回 best。

int longestConsecutive(const vector<int>& nums) {
    unordered_set<int> st(nums.begin(), nums.end());   // 去重，并支持 O(1) 查询
    int best = 0;
    for (int x : st) {
        if (st.count(x - 1)) continue;   // x-1 存在：x 只是某段的中间，留给起点去数
        int y = x;
        while (st.count(y + 1)) ++y;     // 从起点 x 一直向上数
        best = max(best, y - x + 1);
    }
    return best;
}

def longest_consecutive(nums):
    st = set(nums)
    best = 0
    for x in st:
        if x - 1 in st:               # 不是起点，跳过
            continue
        y = x
        while y + 1 in st:
            y += 1
        best = max(best, y - x + 1)
    return best

复杂度：每个数最多被"向上数"经过一次（只有起点才开始数），总时间期望 O(n)，空间 O(n)。

多选 · 理解检查 2　对 nums=[9,1,4,7,3,-1,0,5,8,-1,6] 运行 longestConsecutive。哪些说法正确？

A. 答案是 7（3,4,5,6,7,8,9）

B. 只有 -1 和 3 会作为起点去向上数

C. 重复的 -1 会让 -1..1 这一段被数两次

D. 答案是 3（-1,0,1）

查看答案与每个选项的解析

A · 正确：集合是 {-1,0,1,3,4,5,6,7,8,9}，最长连续段是 3..9，共 7 个。

B · 正确：-2 和 2 都不在集合里；其余每个数的前一个数都在集合里。

C · 错误：先转成 unordered_set 去重，遍历集合时 -1 只出现一次。

D · 错误：那只是较短的一段；3..9 更长。

易错点和变式。

  • 128 题要遍历集合而不是原数组：原数组里起点重复出现时（例如 10 万个相同的起点），会把同一段重复数很多次，退化成 O(n²)。
  • unordered_map 的 [] 会插入新键（22.7），只查询时用 find / count。
  • 用户笔记里提到"用数组代替哈希表还要先清零"：值域小且非负时（如 26 个字母、0..1000），数组计数更快；值域大或有负数时用哈希表。

25.3 前缀和与差分：区间和变成两数之差

模式识别。 题目问"连续子数组的和""和为 K 的子数组个数""区间和查询很多次"，或者"对很多个区间统一加一个数，最后问结果"。数组里有负数时，滑动窗口失效（25.6 解释原因），前缀和仍然可用。典型题：560 和为 K 的子数组、238 除自身以外数组的乘积（前后缀思想）、303 区域和检索、1094/1109 区间加。

核心思想。 定义 P[k] = a[0] + … + a[k-1]，P[0] = 0（空前缀）。于是：

闭区间 a[l..r] 的和 = P[r+1] − P[l]。

求区间和就变成"两个前缀和相减"。差分是它的逆运算：d[i] = a[i] − a[i-1]，对 d 求前缀和就还原 a；一次区间加只改 d 的两个位置。

P[k] 是前 k 个数的和，夹在格子之间；a[1..2] 的和 = P[3] − P[1] = 6 − 3 = 3

vector<long long> buildPrefix(const vector<int>& a) {
    vector<long long> P(a.size() + 1, 0);    // P[k] = a[0] + ... + a[k-1]，P[0] = 0 是空前缀

int subarraySum(const vector<int>& nums, int k) {
    unordered_map<long long, int> freq;   // 前缀和的值 -> 出现次数（只含当前位置之前的前缀）
    freq[0] = 1;                          // 空前缀 P[0] = 0
    long long pre = 0;                    // 到当前位置为止的前缀和
    int count = 0;
    for (int x : nums) {
        pre += x;
        auto it = freq.find(pre - k);     // 之前有几个前缀等于 pre - k，就有几段和为 k
        if (it != freq.end()) count += it->second;
        freq[pre]++;                      // 先查后存
    }
    return count;
}

def subarray_sum(nums, k):
    freq = Counter({0: 1})            # 前缀和 -> 次数；空前缀为 0
    pre = count = 0
    for x in nums:
        pre += x
        count += freq[pre - k]        # Counter 查不到时返回 0，不会插入新键
        freq[pre] += 1
    return count

vector<int> productExceptSelf(const vector<int>& nums) {
    int n = nums.size();
    vector<int> ans(n, 1);
    for (int i = 1; i < n; ++i) ans[i] = ans[i - 1] * nums[i - 1];   // 第一遍：ans[i] = 左侧乘积
    int right = 1;                                                   // nums[i+1..n-1] 的乘积
    for (int i = n - 1; i >= 0; --i) {
        ans[i] *= right;                                             // 左侧乘积 × 右侧乘积
        right *= nums[i];
    }
    return ans;
}

vector<long long> rangeAdd(int n, const vector<vector<int>>& updates) {   // 每个更新是 {l, r, v}
    vector<long long> diff(n + 1, 0);       // 多开一格：r = n-1 时 diff[r+1] 不越界
    for (const auto& u : updates) {
        diff[u[0]] += u[2];                 // 从 l 开始都加 v
        diff[u[1] + 1] -= u[2];             // 从 r+1 开始抵消
    }
    vector<long long> a(n);
    long long run = 0;
    for (int i = 0; i < n; ++i) { run += diff[i]; a[i] = run; }   // 差分的前缀和就是原数组
    return a;
}

复杂度：m 次更新 O(m)，还原 O(n)，合计 O(n+m)。

25.4 对撞双指针：每一步排除一整行

模式识别。 数组有序（或可以先排序），要找满足条件的一对数；或者答案由"左右两端"共同决定，例如容器、接雨水。典型题：167 有序两数之和、11 盛最多水的容器、15 三数之和、16 最接近的三数之和、42 接雨水。

核心思想。 l 从左、r 从右向中间走。把所有 (i, j) 组合看成一张表，每次比较后，能断定"l 和右边所有剩余的配对都没用"或"r 和左边所有剩余的配对都没用"，于是排除一整行或一整列：

答案若存在，一定在 [l, r] 之间；每次移动只丢掉"已证明不可能更优"的那一端。

以有序两数之和为例：a[l] + a[r] < target 时，a[l] 和最大的 a[r] 配都不够，和更小的配更不够，所以 l 出局。

vector<int> twoSumSorted(const vector<int>& a, int target) {   // a 升序
    int l = 0, r = (int)a.size() - 1;
    while (l < r) {
        int s = a[l] + a[r];
        if (s == target) return {l, r};
        if (s < target) ++l;      // 和太小：a[l] 配最大的 a[r] 都不够，a[l] 出局
        else --r;                 // 和太大：a[r] 配最小的 a[l] 都超了，a[r] 出局
    }
    return {};
}

int maxArea(const vector<int>& h) {
    int l = 0, r = (int)h.size() - 1, best = 0;
    while (l < r) {
        best = max(best, (r - l) * min(h[l], h[r]));
        if (h[l] < h[r]) ++l;     // 左边矮：左板配任何更近的右板都不会更大，左板出局
        else --r;
    }
    return best;
}

vector<vector<int>> threeSum(vector<int> nums) {     // 按值传入：排序不影响调用者
    sort(nums.begin(), nums.end());
    int n = nums.size();
    vector<vector<int>> ans;
    for (int i = 0; i < n - 2; ++i) {
        if (nums[i] > 0) break;                              // 最小的都大于 0，凑不出 0
        if (i > 0 && nums[i] == nums[i - 1]) continue;       // 第 1 层去重：同一个首项只做一次
        int l = i + 1, r = n - 1;
        while (l < r) {
            int s = nums[i] + nums[l] + nums[r];
            if (s < 0) ++l;
            else if (s > 0) --r;
            else {
                ans.push_back({nums[i], nums[l], nums[r]});
                while (l < r && nums[l] == nums[l + 1]) ++l;  // 第 2 层去重：跳过相同的左值
                while (l < r && nums[r] == nums[r - 1]) --r;  // 第 3 层去重：跳过相同的右值
                ++l; --r;
            }
        }
    }
    return ans;
}

def three_sum(nums):
    nums = sorted(nums)
    n, ans = len(nums), []
    for i in range(n - 2):
        if nums[i] > 0:
            break
        if i > 0 and nums[i] == nums[i - 1]:
            continue                  # 首项去重
        l, r = i + 1, n - 1
        while l < r:
            s = nums[i] + nums[l] + nums[r]
            if s < 0:
                l += 1
            elif s > 0:
                r -= 1
            else:
                ans.append([nums[i], nums[l], nums[r]])
                while l < r and nums[l] == nums[l + 1]:
                    l += 1            # 左值去重
                while l < r and nums[r] == nums[r - 1]:
                    r -= 1            # 右值去重
                l += 1
                r -= 1
    return ans

变式 16 最接近的三数之和

返回与 target 最接近的三数之和（题设只有一个答案）。[10] 框架同 15，只把"等于 0"换成"比较 |s − target|"：先更新答案，再按 s 与 target 的大小移动指针，相等时直接返回。

int threeSumClosest(vector<int> nums, int target) {   // 题设 n >= 3
    sort(nums.begin(), nums.end());
    int n = nums.size(), best = nums[0] + nums[1] + nums[2];
    for (int i = 0; i < n - 2; ++i) {
        int l = i + 1, r = n - 1;
        while (l < r) {
            int s = nums[i] + nums[l] + nums[r];
            if (abs(s - target) < abs(best - target)) best = s;   // 先更新答案
            if (s < target) ++l;
            else if (s > target) --r;
            else return s;                                      // 差为 0，已经最近
        }
    }
    return best;
}

int trap(const vector<int>& h) {
    int l = 0, r = (int)h.size() - 1;
    int leftMax = 0, rightMax = 0, water = 0;   // h[0..l-1] 的最高、h[r+1..n-1] 的最高
    while (l < r) {
        if (h[l] < h[r]) {                      // 右边有更高的墙：l 格水位只由 leftMax 决定
            leftMax = max(leftMax, h[l]);
            water += leftMax - h[l];
            ++l;
        } else {                                // 左边有不矮的墙：r 格水位只由 rightMax 决定
            rightMax = max(rightMax, h[r]);
            water += rightMax - h[r];
            --r;
        }
    }
    return water;
}

def trap(h):

模式识别。 单链表题要"判断有没有环""找环的入口""找中点""找倒数第 k 个"，并且要求 O(1) 额外空间（不能把节点存进哈希表）。典型题：141 环形链表、142 环形链表 II、876 链表的中间结点、19 删除倒数第 N 个节点（见 25.11）、287 寻找重复数。

核心思想。 两个指针从头出发，fast 每次两步、slow 每次一步：

任意时刻 fast 走过的步数是 slow 的 2 倍。

无环时 fast 先到尾；有环时两者都会进环，fast 每步追近 1 格，必然追上。

入口推导。 设头到入口 a 步，环长 c，相遇点在入口后 b 步。相遇时 slow 走了 a+b，fast 走了 a+b+kc（多绕 k 圈）。由 2(a+b) = a+b+kc 得 a = kc − b = (k−1)c + (c−b)。所以：一个指针从头走 a 步到入口，另一个从相遇点走同样 a 步，也正好到入口（先绕 k−1 整圈，再走 c−b）。两者同速出发，第一次相遇处就是入口。

        fast = fast->next->next;

ListNode* detectCycle(ListNode* head) {
    ListNode *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) {               // 第一次相遇
            ListNode* p = head;           // 一个从头出发，一个从相遇点出发，都走一步
            while (p != slow) { p = p->next; slow = slow->next; }
            return p;                     // 再次相遇的地方就是入环点
        }
    }
    return nullptr;
}

25.6 滑动窗口：扩右、缩左、更新答案

模式识别。 题目问"最长 / 最短的连续子数组或子串"，满足某个关于窗口内元素的条件（无重复、包含某些字符、和不超过 S），并且条件有单调性：窗口变大只会更难满足（或更容易满足）。典型题：3 无重复字符的最长子串、76 最小覆盖子串、438 找到字符串中所有字母异位词、209 长度最小的子数组。

核心思想。 窗口是 [left, right]，两个指针都只向右走：

每次循环结束时，[left, right] 是以 right 结尾的、满足条件的最长窗口（求最短时：left 已缩到再缩就不满足）。

单调性保证 left 只进不退：如果 [left, right] 已经不满足，那么以更大的 right 结尾、起点在 left 或更左的窗口也不满足，left 左边的位置可以永久丢掉。

left 左边是永久扔掉的；right 右边是还没看的；两个指针都只向右走

通用模板（可变窗口，求最长）：扩右 → 不满足就缩左 → 更新答案。 下面以"非负数组中和不超过 S 的最长子数组"为例：

变量含义
right本轮新加入窗口的下标
left窗口左端；[0, left) 已永久移出
sum窗口内的统计量（和、计数表等）
best已见过的最优答案
int longestSumAtMost(const vector<int>& nums, long long S) {   // nums 全部非负
    int left = 0, best = 0;
    long long sum = 0;                             // 窗口 [left, right] 内元素和
    for (int right = 0; right < (int)nums.size(); ++right) {
        sum += nums[right];                        // ① 扩右：nums[right] 进窗口
        while (sum > S) sum -= nums[left++];       // ② 不满足就缩左，直到窗口重新合法
        best = max(best, right - left + 1);        // ③ 窗口合法，更新答案
    }
    return best;
}

求最短窗口时第 ② 步反过来：满足就记答案并缩左，直到不满足（见 76）。窗口长度固定为 m 时，右边进一个、左边出一个即可（见 438）。

string minWindow(const string& s, const string& t) {
    if (t.empty()) return "";
    vector<int> need(128, 0);              // need[c] > 0：窗口还欠 c 的个数；< 0：c 有富余
    for (char c : t) need[c]++;
    int missing = t.size();                // 还欠的字符总数（按次数算）
    int left = 0, bestL = 0, bestLen = INT_MAX;
    for (int right = 0; right < (int)s.size(); ++right) {
        if (need[s[right]]-- > 0) missing--;          // ① 扩右：这个字符补上了一个欠缺
        while (missing == 0) {                         // ② 已经覆盖：先记答案，再试着缩左
            if (right - left + 1 < bestLen) { bestLen = right - left + 1; bestL = left; }
            if (++need[s[left++]] > 0) missing++;      // 移出的字符变成欠缺：窗口失效，停止缩
        }
    }
    return bestLen == INT_MAX ? "" : s.substr(bestL, bestLen);
}

def min_window(s, t):
    if not t:
        return ""
    need = Counter(t)                 # >0 表示还欠，<0 表示富余
    missing = len(t)
    left, best_l, best_len = 0, 0, float('inf')
    for right, c in enumerate(s):
        if need[c] > 0:
            missing -= 1
        need[c] -= 1
        while missing == 0:
            if right - left + 1 < best_len:
                best_l, best_len = left, right - left + 1
            need[s[left]] += 1
            if need[s[left]] > 0:
                missing += 1
            left += 1
    return "" if best_len == float('inf') else s[best_l:best_l + best_len]

时间 O(|s|+|t|)，空间 O(字符集)。

    vector<int> ans;
    int n = s.size(), m = p.size();

    while (l >= 0 && r < (int)s.size() && s[l] == s[r]) { --l; ++r; }

string longestPalindrome(const string& s) {
    int start = 0, best = 0;
    for (int i = 0; i < (int)s.size(); ++i) {
        int len = max(expand(s, i, i),          // 奇数长度：中心是字符 i
                      expand(s, i, i + 1));     // 偶数长度：中心是 i 和 i+1 之间的缝
        if (len > best) { best = len; start = i - (len - 1) / 2; }
    }
    return s.substr(start, best);
}

def longest_palindrome(s):
    def expand(l, r):
        while l >= 0 and r < len(s) and s[l] == s[r]:
            l -= 1
            r += 1
        return l + 1, r               # 回文是 s[l+1:r]
    best = (0, 0)
    for i in range(len(s)):
        for a, b in (expand(i, i), expand(i, i + 1)):
            if b - a > best[1] - best[0]:
                best = (a, b)
    return s[best[0]:best[1]]

KMP 的 next 数组：代码怎么构造

02.12 节讲了 KMP 的原理：next[i] 是 p[0..i] 的最长相等真前缀和真后缀的长度（02.12 记作 pi）。匹配失败时，模式串退到 next[j−1]，文本指针不后退。这里专注于构造 next 的代码。

状态契约

  1. 输入输出：模式串 p，返回 next；要求 O(m)。
  2. 变量：i 是正在求 next[i] 的位置；j 是 p[0..i-1] 的最长相等前后缀长度，也是下一个要和 p[i] 比的位置。
  3. 不变式：进入第 i 轮时，p[0..j) 等于 p[i-j..i)，并且 j 是满足这一点的最大值。
  4. 一步：p[i] == p[j] 则前后缀都延长 1；不等则 j 退到 next[j−1]（下一个更短的相等前后缀），再比，直到相等或 j=0。
  5. 结束：i 走到 m。j 每轮最多加 1，每次回退至少减 1，所以回退总次数不超过 m，总 O(m)。

vector<int> buildNext(const string& p) {
    int m = p.size();
    vector<int> next(m, 0);          // next[i]：p[0..i] 的最长相等真前缀、真后缀的长度
    for (int i = 1, j = 0; i < m; ++i) {                 // j：当前已经匹配上的前缀长度
        while (j > 0 && p[i] != p[j]) j = next[j - 1];    // 接不上：退到更短的相等前后缀
        if (p[i] == p[j]) ++j;                            // 接得上：长度加 1
        next[i] = j;
    }
    return next;
}

def build_next(p):
    nxt = [0] * len(p)
    j = 0

        while j > 0 and p[i] != p[j]:
            j = nxt[j - 1]
        if p[i] == p[j]:
            j += 1
        nxt[i] = j
    return nxt

int kmpSearch(const string& text, const string& p) {   // 第一次出现的下标，没有返回 -1

    for (int i = 0, j = 0; i < (int)text.size(); ++i) {    // i 只前进，从不后退
        while (j > 0 && text[i] != p[j]) j = next[j - 1];
        if (text[i] == p[j]) ++j;

}

bool isValid(const string& s) {
    stack<char> st;                          // 存"接下来期待看到的右括号"
    for (char c : s) {
        if (c == '(') st.push(')');
        else if (c == '[') st.push(']');
        else if (c == '{') st.push('}');
        else if (st.empty() || st.top() != c) return false;   // 来了右括号，但不是期待的那个
        else st.pop();
    }
    return st.empty();                       // 还有没闭合的左括号也不合法
}

string decodeString(const string& s) {
    stack<pair<string, int>> st;     // 遇到 '[' 时保存：（括号外已拼好的串，这个括号的倍数）
    string cur;                      // 当前这一层已经拼出的串
    int num = 0;                     // 正在读的倍数，可能有多位
    for (char c : s) {
        if (c >= '0' && c <= '9') num = num * 10 + (c - '0');
        else if (c == '[') { st.push({cur, num}); cur = ""; num = 0; }   // 进入新的一层
        else if (c == ']') {                                             // 回到外层
            auto [outer, k] = st.top(); st.pop();
            string rep;
            for (int i = 0; i < k; ++i) rep += cur;
            cur = outer + rep;
        } else cur += c;
    }
    return cur;
}

def decode_string(s):
    st, cur, num = [], "", 0
    for c in s:
        if c.isdigit():
            num = num * 10 + int(c)
        elif c == '[':
            st.append((cur, num))
            cur, num = "", 0
        elif c == ']':
            outer, k = st.pop()
            cur = outer + cur * k
        else:
            cur += c
    return cur

int evalRPN(const vector<string>& tokens) {
    stack<long long> st;
    for (const string& t : tokens) {
        if (t == "+" || t == "-" || t == "*" || t == "/") {
            long long b = st.top(); st.pop();    // 先弹出的是右操作数
            long long a = st.top(); st.pop();
            if (t == "+") st.push(a + b);
            else if (t == "-") st.push(a - b);
            else if (t == "*") st.push(a * b);
            else st.push(a / b);                 // C++ 整数除法向零截断，正好符合题意

}

int largestRectangleArea(const vector<int>& heights) {
    vector<int> h(heights);
    h.push_back(0);                          // 哨兵：高度 0 会把栈里剩下的柱子全部弹出结算
    stack<int> st;                           // 下标，对应高度从栈底到栈顶严格递增
    int best = 0;
    for (int i = 0; i < (int)h.size(); ++i) {
        while (!st.empty() && h[st.top()] >= h[i]) {
            int height = h[st.top()];
            st.pop();
            int left = st.empty() ? -1 : st.top();       // 左边第一根更矮的柱子
            best = max(best, height * (i - left - 1));   // 右边第一根更矮的是 i
        }
        st.push(i);
    }
    return best;
}

def largest_rectangle_area(heights):
    h = heights + [0]                 # 哨兵
    st, best = [], 0
    for i, x in enumerate(h):
        while st and h[st[-1]] >= x:
            height = h[st.pop()]
            left = st[-1] if st else -1
            best = max(best, height * (i - left - 1))
        st.append(i)
    return best

25.10 单调队列：滑动窗口里的最大值

模式识别。 固定长度 k 的窗口在数组上滑动，每个位置都要窗口内的最大值（或最小值）。暴力每窗 O(k)，总 O(nk)；用堆是 O(n log n)；单调队列做到 O(n)。典型题：239 滑动窗口最大值、1438 绝对差不超过限制的最长连续子数组。

核心思想。 用 deque 存下标，从队头到队尾对应的值严格递减。新元素 x 从队尾进来时，队尾所有 ≤ x 的元素再也当不了最大值（x 比它们大，而且比它们晚离开窗口），直接踢掉。

队列里的下标都在当前窗口内，对应的值从队头到队尾递减；队头就是窗口最大值。

它和单调栈的区别是多了一个出口：队头元素滑出窗口时要从队头弹出。

vector<int> maxSlidingWindow(const vector<int>& nums, int k) {
    deque<int> dq;                  // 下标；对应值从队头到队尾严格递减，且都在窗口内
    vector<int> ans;
    for (int i = 0; i < (int)nums.size(); ++i) {
        while (!dq.empty() && nums[dq.back()] <= nums[i]) dq.pop_back();   // 队尾：踢掉不可能再当最大的
        dq.push_back(i);
        if (dq.front() <= i - k) dq.pop_front();                          // 队头：踢掉滑出窗口的
        if (i >= k - 1) ans.push_back(nums[dq.front()]);                  // 窗口成形后，队头就是最大值
    }
    return ans;
}

def max_sliding_window(nums, k):
    dq, ans = deque(), []             # 下标，值严格递减
    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] <= x:
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()
        if i >= k - 1:
            ans.append(nums[dq[0]])
    return ans

时间 O(n)，空间 O(k)。

ListNode* removeElements(ListNode* head, int val) {
    ListNode dummy(0);                       // 虚拟头：让"删第一个节点"也有前驱
    dummy.next = head;
    ListNode* prev = &dummy;                 // prev 及之前的节点都已确定保留
    while (prev->next) {
        if (prev->next->val == val) prev->next = prev->next->next;   // 跳过要删的节点
        else prev = prev->next;
    }
    return dummy.next;
}

综合：146 LRU 缓存

实现 get(key) 和 put(key, value)，都要平均 O(1)；容量满时淘汰最久未使用的 key。[32]

哈希表：key → 节点地址，O(1) 找到节点；双向链表：越靠 head 越新，tail 前面是最该淘汰的

为什么是哈希 + 双向链表。 哈希表能 O(1) 找到 key，但记不住先后顺序；链表能 O(1) 在任意已知节点处删除和插入（双向链表能直接拿到前驱），但查找要 O(n)。组合起来：哈希表存 key → 节点地址，链表按使用时间排序，head 后面最新，tail 前面最旧。两个哨兵 head、tail 让插入和删除都没有边界特判。

状态契约

  1. 输入输出：容量 cap，一系列 get / put；get 未命中返回 −1。
  2. 变量：pos 是 key → 节点；链表 head ↔ … ↔ tail 按最近使用时间从新到旧排列；cap 是容量。
  3. 不变式：pos 中的 key 与链表中的节点一一对应，个数不超过 cap；越靠近 head 的越近被使用过。
  4. 一步：get 命中时把节点移到 head 后；put 已有 key 时改值并移到 head 后；put 新 key 时，若已满先删 tail.prev 并从哈希表抹掉，再插到 head 后。
  5. 结束：每个操作只做常数次哈希查找和指针修改。

class LRUCache {
    struct Node { int key, val; Node *prev, *next; };
    int cap;
    unordered_map<int, Node*> pos;                       // key -> 链表中的节点
    Node head{0, 0, nullptr, nullptr};                   // 哨兵：head 后面是最近用过的
    Node tail{0, 0, nullptr, nullptr};                   // 哨兵：tail 前面是最久没用的
    void unlink(Node* x) { x->prev->next = x->next; x->next->prev = x->prev; }
    void pushFront(Node* x) {
        x->prev = &head; x->next = head.next;
        head.next->prev = x; head.next = x;
    }
public:
    LRUCache(int capacity) : cap(capacity) { head.next = &tail; tail.prev = &head; }
    ~LRUCache() { for (auto& kv : pos) delete kv.second; }
    int get(int key) {
        auto it = pos.find(key);
        if (it == pos.end()) return -1;
        unlink(it->second); pushFront(it->second);       // 读一次也算"用过"：移到最前
        return it->second->val;
    }
    void put(int key, int value) {
        auto it = pos.find(key);
        if (it != pos.end()) {                           // key 已存在：改值、移到最前，大小不变
            it->second->val = value;
            unlink(it->second); pushFront(it->second);
            return;
        }
        if ((int)pos.size() == cap) {                    // 满了：淘汰 tail 前面那个最旧的
            Node* old = tail.prev;
            unlink(old); pos.erase(old->key); delete old;
        }
        Node* x = new Node{key, value, nullptr, nullptr};
        pushFront(x);
        pos[key] = x;
    }
};

class Node:
    __slots__ = ('key', 'val', 'prev', 'next')

    def __init__(self, key=0, val=0):
        self.key, self.val, self.prev, self.next = key, val, None, None


class LRUCache:
    def __init__(self, capacity):
        self.cap, self.pos = capacity, {}
        self.head, self.tail = Node(), Node()      # 两个哨兵
        self.head.next, self.tail.prev = self.tail, self.head

    def _unlink(self, x):
        x.prev.next, x.next.prev = x.next, x.prev

    def _push_front(self, x):
        x.prev, x.next = self.head, self.head.next
        self.head.next.prev = x
        self.head.next = x

    def get(self, key):
        if key not in self.pos:
            return -1
        x = self.pos[key]
        self._unlink(x)
        self._push_front(x)
        return x.val

    def put(self, key, value):
        if key in self.pos:
            x = self.pos[key]
            x.val = value
            self._unlink(x)
            self._push_front(x)
            return
        if len(self.pos) == self.cap:
            old = self.tail.prev
            self._unlink(old)
            del self.pos[old.key]
        x = Node(key, value)
        self._push_front(x)
        self.pos[key] = x

25.12 区间与排序：先按左端点排好队

模式识别。 输入是一组区间 [l, r]，问合并重叠区间、插入区间、最少删除几个使其不重叠、最少需要几个会议室等。典型题：56 合并区间、57 插入区间、435 无重叠区间、452 用最少数量的箭引爆气球。

核心思想。 先按左端点排序。排好后，和当前合并段重叠的区间一定紧挨着它出现：

按左端点升序扫描时，ans 的最后一段是"目前为止所有区间合并后的最右一段"；下一个区间只可能和这一段重叠。

为什么按左端点？设下一个区间是 [l, r]，ans 中更早的段的右端都小于最后一段的左端，而 l 不小于最后一段的左端，所以 [l, r] 和更早的段都不相交，只需和最后一段比。若按右端点排序，[1,10] 可能排在 [2,3]、[4,5] 之后，前面已经分开的两段会被它重新连起来，需要回头修改。

列号是数轴坐标。第 0–3 行：排序后的 [1,3] [2,6] [8,10] [9,12]；第 4 行：合并结果 [1,6] [8,12]

vector<vector<int>> mergeIntervals(vector<vector<int>> intervals) {
    sort(intervals.begin(), intervals.end());          // 按左端点升序（左端点相同再比右端点）
    vector<vector<int>> ans;
    for (const auto& cur : intervals) {
        if (!ans.empty() && cur[0] <= ans.back()[1])   // 和上一段重叠（端点相等也算）
            ans.back()[1] = max(ans.back()[1], cur[1]);  // 吸收：右端取较大者
        else
            ans.push_back(cur);                        // 不重叠：开新的一段
    }
    return ans;
}

def merge_intervals(intervals):
    ans = []
    for l, r in sorted(intervals):
        if ans and l <= ans[-1][1]:
            ans[-1][1] = max(ans[-1][1], r)
        else:
            ans.append([l, r])
    return ans

速记： 区间题先按左端点排序；重叠条件 l ≤ 上一段右端；右端取 max。
