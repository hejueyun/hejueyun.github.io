9.1 读写指针：在原数组上筛选元素 必读

有一类题要求在数组中删除某些元素，或者把某一类元素集中到一端，同时要求原地修改、保持其余元素的相对顺序，并返回处理后的长度。例如 283 题移动零、27 题移除元素、26 题删除有序数组中的重复项。

因为不能另开数组，读取和写入只能在同一个数组上进行。于是用两个下标扫描同一个数组：read 逐个读取原有元素，write 指向下一个要保留的元素应写入的位置。每轮循环开始时满足下面的不变式：

[0, write) 中是已经确定保留的元素，并且保持原来的先后顺序；read 是下一个要检查的元素。

只有保留一个元素时 write 才加 1，而 read 每轮都加 1，所以始终有 write ≤ read。写入 a[write] 只会覆盖已经读过的位置，尚未读到的数据不会被破坏。

三段：已保留 | 可以被覆盖的废位 | 还没看的；read 永远不落后于 write

这类题的区别只在于保留哪些元素。把这个判断写成函数 keep，其余代码对所有这类题都相同：

变量含义
write下一个保留元素要写入的位置，也等于已保留的个数
read正在检查的元素下标
keep(x)返回 true 表示 x 要留下
template <class Keep>
int keepIf(vector<int>& a, Keep keep) {
    int write = 0;                                  // [0, write)：已经保留下来的元素，保持原顺序
    for (int read = 0; read < (int)a.size(); ++read) {
        if (keep(a[read])) a[write++] = a[read];    // 要保留：写到 write 处，write 右移一格
    }
    return write;                                   // 保留下来的个数
}
def keep_if(a, keep):                 # keep 是任意可调用对象（函数、lambda），对应 C++ 的模板参数 Keep
    write = 0                         # [0, write)：已经保留下来的元素，保持原顺序
    for read in range(len(a)):
        if keep(a[read]):             # 要保留：写到 write 处，write 右移一格
            a[write] = a[read]        # Python 没有 a[write++]，拆成两句
            write += 1
    return write                      # 保留下来的个数

例题 283 移动零

把所有 0 移到末尾，非零元素保持原顺序，原地完成。[4]

本题原地修改 nums，不需要返回值，要求 O(1) 额外空间。write 等于已经排好的非零元素个数，read 是正在检查的下标。不变式是：nums[0..write) 恰好是 nums[0..read) 中的全部非零元素，并保持原顺序。每一步，若 nums[read] 非零，就写到 write 处并让 write 加 1；若为 0 则跳过。每个非零元素都在被读到的那一轮写入，所以不会遗漏。read 每轮加 1，走到 n 时循环结束，此时前 write 个位置就是全部非零元素，再把 [write, n) 补成 0 即可。

void moveZeroes(vector<int>& nums) {
    int write = keepIf(nums, [](int x) { return x != 0; });     // 非零元素按原顺序挤到前面
    for (int i = write; i < (int)nums.size(); ++i) nums[i] = 0;  // 剩下的位置补 0
}
def move_zeroes(nums):
    write = keep_if(nums, lambda x: x != 0)   # 非零元素按原顺序挤到前面；列表传的是引用，原地修改
    for i in range(write, len(nums)):         # 剩下的位置补 0
        nums[i] = 0

每个元素读一次、最多写两次，时间 O(n)，额外空间 O(1)。

例题 27 移除元素

删除所有等于 val 的元素，返回剩余元素的个数 k，前 k 个位置存放剩余元素（之后的内容不作检查）。[5] 做法与 283 题相同，只是保留条件从"非零"换成"不等于 val"；由于不检查后面的内容，最后直接返回 write，不必补 0。

2 / 5

第2步 · read=0：3==3，丢弃，write 不动

3 / 5

第3步 · read=1：2≠3，保留到下标 0，write=1

4 / 5

第4步 · read=2：2≠3，保留到下标 1，write=2

5 / 5

第5步 · read=3：3==3，丢弃，write 不动

int removeElement(vector<int>& nums, int val) {
    int write = 0;                                  // [0, write)：不等于 val 的元素
    for (int read = 0; read < (int)nums.size(); ++read) {
        if (nums[read] != val) nums[write++] = nums[read];
    }
    return write;                                   // 新长度
}
def remove_element(nums, val):
    write = 0                         # [0, write)：不等于 val 的元素
    for read in range(len(nums)):
        if nums[read] != val:
            nums[write] = nums[read]
            write += 1
    return write                      # 新长度；列表物理长度不变，nums[:write] 才是有效部分

时间 O(n)，空间 O(1)。

要求原地修改、保持顺序，并删除或移动部分元素时，就用读写指针：把保留条件写进一个 if，其余代码不变。函数返回 write，它既是新数组的长度，也是下一个写入位置。26 题（有序数组去重）的保留条件是 write == 0 或 nums[read] != nums[write - 1]，即当前元素与已保留的最后一个元素不同。

单选 · 理解检查 1　对 nums=[0,1,2,2,3,0,4,2] 执行 removeElement(nums, 2)。返回值和前几个元素是什么？

A. 返回 5，前 5 个是 [0,1,3,0,4]

B. 返回 5，前 5 个是 [0,0,1,3,4]

C. 返回 3

D. 返回 8，因为数组长度没变

查看答案与每个选项的解析

A · 正确：去掉三个 2 后剩 5 个元素，读写指针保持原顺序。

B · 错误：读写指针不排序，保留的是原来的先后顺序。

C · 错误：3 是被删掉的个数，函数返回的是剩下的个数 write。

D · 错误：数组物理长度没变，但题目要的是有效长度 k。

练习 9.1-1【基础】日志按等级过滤

题面：服务器日志用整数等级表示（0 = DEBUG，…，4 = FATAL）。给定数组 levels（n ≤ 10⁵）和阈值 minLevel，原地只保留等级 ≥ minLevel 的日志，保持原顺序，返回保留个数 k（前 k 格是结果，后面的内容不检查）。

样例：levels=[3,1,4,1,0,2], minLevel=2 → 返回 3，前 3 格为 [3,4,2]；levels=[], minLevel=1 → 返回 0。

提示

读写指针模板原样套用，keep(x) 就是 x >= minLevel。和例题 27 相比只把"不等于 val"换成"不小于阈值"。这题练的是认信号："原地""保持顺序""返回新长度"三个词同时出现，就是读写指针。

参考答案
int keepLevelsAtLeast(vector<int>& levels, int minLevel) {
    int write = 0;                                   // [0, write)：等级够高、已经保留的日志
    for (int read = 0; read < (int)levels.size(); ++read) {
        if (levels[read] >= minLevel) levels[write++] = levels[read];
    }
    return write;
}
def keep_levels_at_least(levels, min_level):
    write = 0                         # [0, write)：等级够高、已经保留的日志
    for read in range(len(levels)):
        if levels[read] >= min_level:
            levels[write] = levels[read]
            write += 1
    return write

练习 9.1-2【变形】有序数组每个值最多留 k 个

题面：升序数组 a（n ≤ 10⁵）和整数 k ≥ 0。原地删去多余的重复，使每个值最多出现 k 次，保持顺序，返回新长度。k = 0 时全部删除。（相近题型：LeetCode 26、80）

样例：a=[1,1,1,2,2,3], k=2 → 返回 5，前 5 格 [1,1,2,2,3]；同一数组 k=1 → 返回 3，前 3 格 [1,2,3]。

提示

模板不变，改的是保留条件。数组有序，同值元素挨在一起，保留区 [0,write) 也有序；所以只要看保留区倒数第 k 个 a[write-k]：它等于 a[read]，说明最后 k 个全是这个值，已经留够了；不等就留下。write < k 时保留区还不满 k 个，直接留。比较对象是 a[write-k]（保留区里的内容），不是 a[read-k]：read-k 位置可能已经被覆盖过。k = 0 要先特判，否则会访问 a[write-0] 这个还没写的位置。

参考答案
int keepAtMostK(vector<int>& a, int k) {
    if (k <= 0) return 0;                            // 一个都不留
    int write = 0;                                   // [0, write)：每个值最多 k 个，保持升序
    for (int read = 0; read < (int)a.size(); ++read) {
        if (write < k || a[read] != a[write - k])    // 保留区末尾 k 个不全是 a[read]，才留下
            a[write++] = a[read];
    }
    return write;
}
def keep_at_most_k(a, k):
    if k <= 0:                        # 一个都不留
        return 0
    write = 0                         # [0, write)：每个值最多 k 个，保持升序
    for read in range(len(a)):
        if write < k or a[read] != a[write - k]:   # 保留区末尾 k 个不全是 a[read]，才留下
            a[write] = a[read]
            write += 1
    return write

练习 9.1-3【综合】原地压缩连续字符

题面：字符数组 s（只含字母，n ≤ 2000），把每一段连续相同的字符改写成"字符 + 次数"：次数为 1 时省略，次数 ≥ 10 时写成多位数字。原地完成，返回新长度。（相近题型：LeetCode 443）

样例："aaabcc" → 返回 5，前 5 格是 "a3bc2"；"a" 后跟 12 个 "b" → 返回 4，前 4 格是 "ab12"；空数组 → 返回 0。

提示

仍是读写指针，只是 read 一次跳过一整段：记下段首 start，让 read 走到下一段开头，段长 len = read - start；再在 write 处写字符，len > 1 时把 len 的各位数字逐个写上。为什么不会覆盖还没读的数据：长 len 的一段压缩后占 1 + (len 的位数) 格，len ≥ 2 时这不超过 len，所以 write 始终不超过 read。边界：len = 10、12 这类多位数要逐位写（to_string）；单个字符不写 "1"；空数组直接返回 0。

参考答案
int compressRuns(vector<char>& s) {
    int n = s.size(), write = 0, read = 0;
    while (read < n) {
        int start = read;                                 // 这一段从 start 开始
        while (read < n && s[read] == s[start]) ++read;   // read 停在下一段的开头
        s[write++] = s[start];
        int len = read - start;
        if (len > 1) {
            for (char d : to_string(len)) s[write++] = d; // 多位数逐位写出
        }
    }
    return write;
}
def compress_runs(s):
    n, write, read = len(s), 0, 0
    while read < n:
        start = read                  # 这一段从 start 开始
        while read < n and s[read] == s[start]:
            read += 1                 # read 停在下一段的开头
        s[write] = s[start]
        write += 1
        length = read - start
        if length > 1:
            for d in str(length):     # 多位数逐位写出，对应 C++ 的 to_string
                s[write] = d
                write += 1
    return write

9.2 哈希表：把再扫描一遍改为查询一次 必读

如果暴力解法是两层循环，而内层循环只是在寻找某个特定的值，就可以用哈希表把内层循环换成一次查询。这类题的要求通常是：找一个与当前元素配对的元素，统计出现次数，判断某个元素是否出现过，或把同类元素分到一组。例如 1 题两数之和、49 题字母异位词分组、128 题最长连续序列、217 题存在重复元素。

哈希表能在平均 O(1) 时间内回答某个键是否存在、对应什么值（原理见第 16 章，C++ 用法见 1.7）。它在这类题中有两种用法：一种是查找，键是元素的值，值是下标或出现与否；另一种是分组或计数，键是能代表一类元素的标识，值是这一组元素或它们的个数。扫描数组时保持下面的不变式：

扫描到第 i 个元素时，表中恰好记录了前 i 个元素的信息。

为了保持这个不变式，对当前元素要先查询、再存入。分组题的关键在于设计作为键的标识：应当归为同一类的元素必须得到同一个键，不同类的元素必须得到不同的键。

哈希的核心：把"应该算同一类"的东西映射到同一个键，再用键找桶

通用写法如下，seen 保存已经扫描过的元素的信息，x 是当前元素：

bool containsDuplicate(const vector<int>& nums) {
    unordered_set<int> seen;                 // 已经扫过的值
    for (int x : nums) {
        if (seen.count(x)) return true;      // 先查：x 之前出现过
        seen.insert(x);                      // 后存：把 x 记下来，留给后面的元素查
    }
    return false;
}
def contains_duplicate(nums):
    seen = set()                      # 已经扫过的值
    for x in nums:
        if x in seen:                 # 先查：x 之前出现过
            return True
        seen.add(x)                   # 后存：把 x 记下来，留给后面的元素查
    return False

vector<int> twoSum(const vector<int>& nums, int target) {
    unordered_map<int, int> seen;            // 值 -> 下标，只存 i 之前的元素
    for (int i = 0; i < (int)nums.size(); ++i) {
        auto it = seen.find(target - nums[i]);
        if (it != seen.end()) return {it->second, i};
        seen[nums[i]] = i;                   // 先查后存：自己不会和自己配对
    }
    return {};
}
def two_sum(nums, target):
    seen = {}                         # 值 -> 下标，只含当前位置之前的元素
    for i, x in enumerate(nums):
        if target - x in seen:
            return [seen[target - x], i]
        seen[x] = i                   # 先查后存
    return []

时间期望 O(n)，空间 O(n)。有重复值时同样正确：对 [3,3]，第 0 轮表为空，存入 3 → 0；第 1 轮查到 3 对应下标 0，返回 [0, 1]。正因为先查询后存入，同一个元素不会与自己配对。

def group_anagrams(strs):
    groups = defaultdict(list)        # 签名 -> 这一组的单词；缺键时自动建空列表，像 C++ 的 groups[key]

    return ans

int longestConsecutive(const vector<int>& nums) {
    unordered_set<int> st(nums.begin(), nums.end());   // 去重，并支持 O(1) 查询
    int best = 0;
    for (int x : st) {
        if (st.count(x - 1)) continue;   // x-1 存在：x 只是某段的中间，留给起点去数
        int y = x;
        while (st.count(y + 1)) ++y;     // 从起点 x 一直向上数
        best = max(best, y - x + 1);
    }
    return best;
}
def longest_consecutive(nums):
    st = set(nums)
    best = 0
    for x in st:
        if x - 1 in st:               # 不是起点，跳过
            continue
        y = x
        while y + 1 in st:
            y += 1
        best = max(best, y - x + 1)
    return best

只有从起点出发时才会向上逐个查询，所以每个数最多被这样经过一次，总时间期望 O(n)，空间 O(n)。

9.3 前缀和与差分：把区间和变成两个数之差 必读

前缀和适用于求连续子数组的和、统计和为某值的子数组个数、多次查询区间和等问题；它的逆运算差分，适用于对许多区间统一加上一个数、最后再求结果的问题。例如 560 题和为 K 的子数组、238 题除自身以外数组的乘积（前后缀的思想）、303 题区域和检索、1094 与 1109 题的区间加。数组中有负数时，滑动窗口不再适用（原因见 9.6），前缀和仍然适用。

定义前缀和 P[k] = a[0] + … + a[k-1]，其中 P[0] = 0 表示空前缀的和。P[r+1] 是前 r + 1 个元素之和，P[l] 是前 l 个元素之和，两者相减恰好剩下 a[l..r]，因此：

闭区间 a[l..r] 的和等于 P[r+1] − P[l]。

预处理出前缀和以后，任意区间和都只需一次减法。差分是前缀和的逆运算：定义 d[i] = a[i] − a[i-1]，对 d 求前缀和就能还原出 a。给区间 [l, r] 中每个数加上 v，只会使 d[l] 增加 v、d[r+1] 减少 v，其余差分不变，所以一次区间加只需修改两个位置。

P[k] 是前 k 个数的和，夹在格子之间；a[1..2] 的和 = P[3] − P[1] = 6 − 3 = 3

通用写法如下，P 的长度为 n + 1，l、r 是闭区间的端点：

vector<long long> buildPrefix(const vector<int>& a) {
    vector<long long> P(a.size() + 1, 0);    // P[k] = a[0] + ... + a[k-1]，P[0] = 0 是空前缀
    for (int i = 0; i < (int)a.size(); ++i) P[i + 1] = P[i] + a[i];
    return P;
}
long long rangeSum(const vector<long long>& P, int l, int r) {   // 闭区间 [l, r] 的和
    return P[r + 1] - P[l];
}
def build_prefix(a):
    P = [0] * (len(a) + 1)            # P[k] = a[0] + ... + a[k-1]，P[0] = 0 是空前缀；Python 整数不溢出，不用 long long
    for i in range(len(a)):
        P[i + 1] = P[i] + a[i]
    return P

def range_sum(P, l, r):               # 闭区间 [l, r] 的和
    return P[r + 1] - P[l]

int subarraySum(const vector<int>& nums, int k) {
    unordered_map<long long, int> freq;   // 前缀和的值 -> 出现次数（只含当前位置之前的前缀）
    freq[0] = 1;                          // 空前缀 P[0] = 0
    long long pre = 0;                    // 到当前位置为止的前缀和
    int count = 0;
    for (int x : nums) {
        pre += x;
        auto it = freq.find(pre - k);     // 之前有几个前缀等于 pre - k，就有几段和为 k
        if (it != freq.end()) count += it->second;
        freq[pre]++;                      // 先查后存
    }
    return count;
}
from collections import Counter

def subarray_sum(nums, k):
    freq = Counter({0: 1})            # 前缀和 -> 次数；空前缀为 0
    pre = count = 0
    for x in nums:
        pre += x
        count += freq[pre - k]        # Counter 查不到时返回 0，不会插入新键
        freq[pre] += 1
    return count

vector<int> productExceptSelf(const vector<int>& nums) {
    int n = nums.size();
    vector<int> ans(n, 1);
    for (int i = 1; i < n; ++i) ans[i] = ans[i - 1] * nums[i - 1];   // 第一遍：ans[i] = 左侧乘积
    int right = 1;                                                   // nums[i+1..n-1] 的乘积
    for (int i = n - 1; i >= 0; --i) {
        ans[i] *= right;                                             // 左侧乘积 × 右侧乘积
        right *= nums[i];
    }
    return ans;
}
def product_except_self(nums):
    n = len(nums)
    ans = [1] * n
    for i in range(1, n):             # 第一遍：ans[i] = 左侧乘积
        ans[i] = ans[i - 1] * nums[i - 1]
    right = 1                         # nums[i+1..n-1] 的乘积
    for i in range(n - 1, -1, -1):    # i 从 n-1 降到 0；range 不含右端，所以终点写 -1
        ans[i] *= right               # 左侧乘积 × 右侧乘积
        right *= nums[i]
    return ans

vector<long long> rangeAdd(int n, const vector<vector<int>>& updates) {   // 每个更新是 {l, r, v}
    vector<long long> diff(n + 1, 0);       // 多开一格：r = n-1 时 diff[r+1] 不越界
    for (const auto& u : updates) {
        diff[u[0]] += u[2];                 // 从 l 开始都加 v
        diff[u[1] + 1] -= u[2];             // 从 r+1 开始抵消
    }
    vector<long long> a(n);
    long long run = 0;
    for (int i = 0; i < n; ++i) { run += diff[i]; a[i] = run; }   // 差分的前缀和就是原数组
    return a;
}
def range_add(n, updates):            # 每个更新是 [l, r, v]
    diff = [0] * (n + 1)              # 多开一格：r = n-1 时 diff[r+1] 不越界
    for l, r, v in updates:
        diff[l] += v                  # 从 l 开始都加 v
        diff[r + 1] -= v              # 从 r+1 开始抵消
    a = [0] * n
    run = 0
    for i in range(n):                # 差分的前缀和就是原数组
        run += diff[i]
        a[i] = run
    return a

long long countDivisibleSubarrays(const vector<int>& a, int K) {

int longestBalanced(const vector<int>& bits) {
    unordered_map<int, int> first;           // 前缀和 -> 最早出现时的前缀长度
    first[0] = 0;                            // 空前缀
    int pre = 0, best = 0;
    for (int i = 0; i < (int)bits.size(); ++i) {
        pre += bits[i] == 1 ? 1 : -1;        // 达标 +1，未达标 -1
        auto it = first.find(pre);
        if (it != first.end()) best = max(best, i + 1 - it->second);   // 两端前缀和相等：中间和为 0
        else first[pre] = i + 1;             // 只记最早的位置，后来的离得近，不会更长
    }
    return best;
}
def longest_balanced(bits):
    first = {0: 0}                    # 前缀和 -> 最早出现时的前缀长度；先放入空前缀
    pre = best = 0
    for i, b in enumerate(bits):
        pre += 1 if b == 1 else -1    # 达标 +1，未达标 -1
        if pre in first:
            best = max(best, i + 1 - first[pre])   # 两端前缀和相等：中间和为 0
        else:
            first[pre] = i + 1        # 只记最早的位置，后来的离得近，不会更长

vector<long long> rectQueries(const vector<vector<int>>& g, const vector<array<int, 4>>& qs) {
    int R = g.size(), C = R ? (int)g[0].size() : 0;
    vector<vector<long long>> S(R + 1, vector<long long>(C + 1, 0));   // S[i][j]：前 i 行、前 j 列之和
    for (int i = 0; i < R; ++i)
        for (int j = 0; j < C; ++j)
            S[i + 1][j + 1] = g[i][j] + S[i][j + 1] + S[i + 1][j] - S[i][j];   // 上 + 左 - 重复的左上
    vector<long long> ans;
    for (const auto& q : qs) {               // q = {r1, c1, r2, c2}，闭区间
        int r1 = q[0], c1 = q[1], r2 = q[2], c2 = q[3];
        ans.push_back(S[r2 + 1][c2 + 1] - S[r1][c2 + 1] - S[r2 + 1][c1] + S[r1][c1]);   // 容斥
    }
    return ans;
}
def rect_queries(g, qs):
    R = len(g)
    C = len(g[0]) if R else 0
    S = [[0] * (C + 1) for _ in range(R + 1)]   # S[i][j]：前 i 行、前 j 列之和
    for i in range(R):
        for j in range(C):
            S[i + 1][j + 1] = g[i][j] + S[i][j + 1] + S[i + 1][j] - S[i][j]   # 上 + 左 - 重复的左上
    ans = []
    for r1, c1, r2, c2 in qs:         # 闭区间
        ans.append(S[r2 + 1][c2 + 1] - S[r1][c2 + 1] - S[r2 + 1][c1] + S[r1][c1])   # 容斥
    return ans

易错点和变式。

  • freq[0] = 1 必须在循环前写好，它代表"从下标 0 开始的子数组"。
  • 先查后存：若先 freq[pre]++ 再查，k=0 时会把"空子数组"也算进去。
  • 前缀和可能超出 int（10⁵ 个 10⁴ 量级的数），用 long long。差分数组开 n+1 格，r = n−1 时 diff[n] 才不越界。

若答案存在，一定在 [l, r] 之内；每次移动只舍弃已经证明不可能更优的那一端。

以有序数组的两数之和为例：若 a[l] + a[r] < target，那么 a[l] 与区间内最大的 a[r] 相加仍然不够，与其他更小的数相加更不够，所以 a[l] 不可能出现在答案中，令 l 加 1。同理，和大于 target 时令 r 减 1。

vector<int> twoSumSorted(const vector<int>& a, int target) {   // a 升序
    int l = 0, r = (int)a.size() - 1;
    while (l < r) {
        int s = a[l] + a[r];
        if (s == target) return {l, r};
        if (s < target) ++l;      // 和太小：a[l] 配最大的 a[r] 都不够，a[l] 出局
        else --r;                 // 和太大：a[r] 配最小的 a[l] 都超了，a[r] 出局
    }
    return {};
}
def two_sum_sorted(a, target):        # a 升序

int maxArea(const vector<int>& h) {
    int l = 0, r = (int)h.size() - 1, best = 0;
    while (l < r) {
        best = max(best, (r - l) * min(h[l], h[r]));
        if (h[l] < h[r]) ++l;     // 左边矮：左板配任何更近的右板都不会更大，左板出局
        else --r;
    }
    return best;
}
def max_area(h):

vector<vector<int>> threeSum(vector<int> nums) {     // 按值传入：排序不影响调用者
    sort(nums.begin(), nums.end());
    int n = nums.size();
    vector<vector<int>> ans;
    for (int i = 0; i < n - 2; ++i) {
        if (nums[i] > 0) break;                              // 最小的都大于 0，凑不出 0
        if (i > 0 && nums[i] == nums[i - 1]) continue;       // 第 1 层去重：同一个首项只做一次
        int l = i + 1, r = n - 1;
        while (l < r) {
            int s = nums[i] + nums[l] + nums[r];
            if (s < 0) ++l;
            else if (s > 0) --r;
            else {
                ans.push_back({nums[i], nums[l], nums[r]});
                while (l < r && nums[l] == nums[l + 1]) ++l;  // 第 2 层去重：跳过相同的左值
                while (l < r && nums[r] == nums[r - 1]) --r;  // 第 3 层去重：跳过相同的右值
                ++l; --r;
            }
        }
    }
    return ans;
}
def three_sum(nums):
    nums = sorted(nums)               # sorted 返回新列表，不影响调用者（对应 C++ 的按值传入）
    n, ans = len(nums), []
    for i in range(n - 2):
        if nums[i] > 0:
            break
        if i > 0 and nums[i] == nums[i - 1]:
            continue                  # 首项去重
        l, r = i + 1, n - 1
        while l < r:
            s = nums[i] + nums[l] + nums[r]
            if s < 0:
                l += 1
            elif s > 0:
                r -= 1
            else:
                ans.append([nums[i], nums[l], nums[r]])
                while l < r and nums[l] == nums[l + 1]:
                    l += 1            # 左值去重
                while l < r and nums[r] == nums[r - 1]:
                    r -= 1            # 右值去重
                l += 1
                r -= 1
    return ans

排序 O(n log n)，外层 n 轮、每轮内层 O(n)，总时间 O(n²)。额外空间取决于排序的实现，结果所占空间另计。

另一种常见写法是用 set 和 frozenset 去重，但它是错误的。frozenset({-1,-1,2}) 会变成 {-1,2}，重复的元素被合并，输出的三元组只剩两个数；如果再加上 n != -nums[i]-n 这样的条件，[-2,1,1] 这类含两个相同数的答案也会被漏掉。上面分层跳过相同值的写法既不需要额外的集合，也不会丢失重复元素。

变式 16 最接近的三数之和

返回与 target 最接近的三数之和，题目保证答案唯一。[13] 框架与 15 题相同，只是把"和等于 0"换成比较 |s − target|：每一步先用当前的和更新答案，再根据 s 与 target 的大小关系移动指针，二者相等时直接返回。

int threeSumClosest(vector<int> nums, int target) {   // 题设 n >= 3
    sort(nums.begin(), nums.end());
    int n = nums.size(), best = nums[0] + nums[1] + nums[2];
    for (int i = 0; i < n - 2; ++i) {
        int l = i + 1, r = n - 1;
        while (l < r) {
            int s = nums[i] + nums[l] + nums[r];
            if (abs(s - target) < abs(best - target)) best = s;   // 先更新答案
            if (s < target) ++l;
            else if (s > target) --r;
            else return s;                                      // 差为 0，已经最近
        }
    }
    return best;
}
def three_sum_closest(nums, target):  # 题设 n >= 3
    nums = sorted(nums)               # 新列表，不影响调用者
    n, best = len(nums), nums[0] + nums[1] + nums[2]
    for i in range(n - 2):
        l, r = i + 1, n - 1
        while l < r:
            s = nums[i] + nums[l] + nums[r]
            if abs(s - target) < abs(best - target):
                best = s              # 先更新答案
            if s < target:
                l += 1
            elif s > target:
                r -= 1
            else:
                return s              # 差为 0，已经最近
    return best

例题 42 接雨水（双指针版）

给定柱子的高度数组，求下雨后能接多少水。[14] 第 i 列上方的水面高度等于它左边最高柱子与右边最高柱子中较低的那个，这一列的水量等于水面高度减去 h[i]。

高度 [4,2,0,3,2,5]：深色是墙，"水"是积水；每列水量 [0, 2, 4, 1, 2, 0]，共 9

int trap(const vector<int>& h) {
    int l = 0, r = (int)h.size() - 1;
    int leftMax = 0, rightMax = 0, water = 0;   // h[0..l-1] 的最高、h[r+1..n-1] 的最高
    while (l < r) {
        if (h[l] < h[r]) {                      // 右边有更高的墙：l 格水位只由 leftMax 决定
            leftMax = max(leftMax, h[l]);
            water += leftMax - h[l];
            ++l;
        } else {                                // 左边有不矮的墙：r 格水位只由 rightMax 决定
            rightMax = max(rightMax, h[r]);
            water += rightMax - h[r];
            --r;
        }
    }
    return water;
}
def trap(h):
    l, r = 0, len(h) - 1
    left_max = right_max = water = 0
    while l < r:
        if h[l] < h[r]:
            left_max = max(left_max, h[l])
            water += left_max - h[l]
            l += 1
        else:
            right_max = max(right_max, h[r])
            water += right_max - h[r]
            r -= 1
    return water

时间 O(n)，空间 O(1)。

提示

"有序 + 找一对"就是对撞指针。把"等于 target"改成"不超过 B 时取最大"：若 a[l]+a[r] ≤ B，a[l] 和 l..r 之间任何其他元素配都不会更大（它们都 ≤ a[r]），所以记下这个和，l 出局；否则 a[r] 和最便宜的配都超预算，r 出局。

int maxPairWithinBudget(const vector<int>& prices, int B) {   // prices 升序
    int l = 0, r = (int)prices.size() - 1, best = -1;
    while (l < r) {
        int s = prices[l] + prices[r];
        if (s <= B) { best = max(best, s); ++l; }   // a[l] 配 a[r] 已是它能配出的最大合法和，l 出局
        else --r;                                   // a[r] 配最便宜的都超预算，r 出局
    }
    return best;
}

提示

只要个数、不要下标，所以可以先排序。对撞时把"找到一对就返回"改成"一次数一批"：若 a[l]+a[r] < T，那么 a[l] 和 a[l+1..r] 里任何一个配都 < T（它们都 ≤ a[r]），一次加上 r−l 对，然后 l 出局；否则 r 出局。和例题相比，改的是"条件成立时做什么"。结果可达 n²/2，用 long long。

练习 9.4-3【综合】最少几条皮划艇

题面：n 名游客体重 w（n ≤ 10⁵，1 ≤ w[i] ≤ L），每条艇最多坐 2 人且总重不超过 L，求最少要几条艇。（相近题型：LeetCode 881）

样例：w=[3,2,2,1], L=3 → 3（[1,2]、[2]、[3]）；w=[3,5,3,4], L=5 → 4；w=[1,2], L=3 → 1。

提示

排序后对撞。最重的人 a[r] 总要上一条艇：最轻的 a[l] 能和他同船就一起走（l 前进），否则他独占一条；两种情况下 r 都出局、艇数 +1。为什么"和最轻的配"不会更差：如果最优方案里 a[r] 和另一个人 x 同船，把 x 换成更轻的 a[l] 依然合法，艇数不变。边界：l == r 时只剩一个人，也要一条艇，所以循环条件是 l <= r，而不是例题里的 l < r。

参考答案
int minBoats(vector<int> w, int L) {
    sort(w.begin(), w.end());
    int l = 0, r = (int)w.size() - 1, boats = 0;
    while (l <= r) {                         // l == r：只剩一个人，也要一条艇
        if (l < r && w[l] + w[r] <= L) ++l;  // 最轻的能和最重的同船
        --r;                                 // 最重的无论如何都坐这条艇走
        ++boats;
    }
    return boats;
}
def min_boats(w, L):
    w = sorted(w)
    l, r, boats = 0, len(w) - 1, 0
    while l <= r:                     # l == r：只剩一个人，也要一条艇
        if l < r and w[l] + w[r] <= L:
            l += 1                    # 最轻的能和最重的同船
        r -= 1                        # 最重的无论如何都坐这条艇走
        boats += 1
    return boats

易错点和变式。

  • 对撞指针依赖"移动一端就能排除一整行"的单调性；无序数组找两数和要先排序（只要值）或用哈希（要下标，见 9.2）。
  • 三数之和 nums[i] + nums[l] + nums[r] 在值域到 10⁹ 时会溢出 int，用 long long；LeetCode 15 的值域是 ±10⁵，int 够用。
  • 对撞指针和快慢指针容易混淆：对撞是两端相向走，快慢是同向不同速（9.5）。

小结： 对撞指针每一步都排除一端的一个元素：盛水容器移动较矮的一侧，接雨水先结算较矮的一侧，三数之和先排序再逐层去重。
