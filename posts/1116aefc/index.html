3.1 Python 程序的骨架：缩进、动态类型和名字绑定

我们从第 1 章那个"读两个数、输出它们的和"的程序开始，看看换成 Python 会变成什么样：

a, b = map(int, input().split())   # 读一行，按空格切开，每段转成 int
print(a + b)                       # 输出并换行

两行就够了：没有 #include，没有 main，没有类型声明，也没有分号。Python 从文件第一行开始往下执行，这一行写什么就做什么。

解释执行。 C++ 要先用 g++ 编译成可执行文件，再运行；Python 由解释器 python3 直接运行 .py 文件。解释器内部也有一步编译：先把源代码翻译成字节码，再由虚拟机一条条执行字节码。所以语法错误（少冒号、缩进不齐）在开始运行前就会报出来，而拼错变量名、下标越界这些问题要等执行到那一行才报错。

上：C++ 先整体编译再运行；下：Python 由解释器边翻译边执行，省掉了显式编译，也因此慢一些

缩进就是代码块

C++ 用 {} 括起一个代码块，Python 用行尾冒号 + 下一行缩进表示代码块，缩进退回去，代码块就结束。下面是第 1 章"求最大值"的 Python 版：

def max_of(nums):
    best = nums[0]              # 当前见过的最大值
    for x in nums[1:]:          # 冒号 + 缩进 = 一个代码块
        if x > best:
            best = x
    return best

同一个代码块里每行的缩进必须完全一样，惯例是 4 个空格。return best 和 for 对齐，说明它在循环外面、循环结束后才执行。把它多缩进一层，它就跑进了循环体，第一轮就返回，这是 Python 新手最常见的逻辑错误。

动态类型：类型属于对象，名字只是标签

C++ 里 int x = 5; 声明了一个装 int 的盒子，x 永远只能装 int。Python 里 x = 5 的意思是：先创建（或找到）一个值为 5 的 int 对象，再把名字 x 贴到这个对象上。类型记录在对象身上，名字本身没有类型，所以同一个名字之后可以改贴到一个字符串上：x = "five"。这就叫动态类型。[1]

C++ 变量是固定类型的存储格；Python 变量是贴在对象上的名字，可以改贴

"名字绑定对象"在列表上最能看出差别。b = a 在 C++ 里会复制整个 vector；在 Python 里只是让 b 也贴到 a 贴着的那个列表上。之后通过 b 修改列表，a 也看得见：

3.2 数字：int 不会溢出，// 和 % 向下取整

刷题里和数字有关的 bug，C++ 主要栽在溢出和负数除法上。Python 的整数规则不同：溢出的问题消失了，负数除法换了一套规则，/ 的结果类型也变了。先把这三件事弄清，再写代码。[2] [3]

int 是任意精度

Python 的 int 位数不设上限，需要多大就用多大的内存，所以没有溢出。100000 * 100000 直接得到 10000000000，2 ** 100（** 是乘方）得到 1267650600228229401496703205376。第 1 章的 1LL * a * b、long long、lo + (hi - lo) / 2 在 Python 里都用不着：二分的中点直接写 mid = (lo + hi) // 2。

代价是速度：大整数运算比 C++ 的固定宽度整数慢。有的题目要求"答案对 10⁹+7 取模"，Python 也照样每步取模，让数字保持小、运算保持快。求 aᵇ mod m 用内置的 pow(a, b, m)，它内部是快速幂。

把 −7 ÷ 2 = −3.5 画在数轴上，两种规则的差别一目了然：

商落在 -4 和 -3 之间：Python 取左边的 -4，C++ 取靠近 0 的 -3；余数随之变成 1 或 -1

余数由商决定，两种语言都满足"商 × 除数 + 余数 = 被除数"：

  • Python：(−4) × 2 + 1 = −7；
  • C++：(−3) × 2 + (−1) = −7。

divmod(-7, 2) 一次返回 (-4, 1)。向下取整有个实用的好处：x % m 在 m > 0 时一定落在 [0, m)。环形数组往回走一步写 (i - 1) % n，i = 0 时直接得到 n−1，C++ 里则要写成 (i - 1 + n) % n。判断奇数写 x % 2 == 1 在 Python 里对负数也成立（−3 % 2 == 1），这和第 1 章 C++ 的结论正好相反。

需要 C++ 那种"向零截断"时，写 int(a / b)（数字不大时可用）或者用整数运算模拟：

def c_div(a, b):
    """模拟 C++ 的整数除法：向零截断。"""
    q = abs(a) // abs(b)
    return q if (a >= 0) == (b >= 0) else -q

c_div(-7, 2) 先算 7 // 2 = 3，两数异号，返回 −3。

/ 一定得到 float

/ 是"真除法"，结果一定是 float：7 / 2 是 3.5，4 / 2 是 2.0 而不是 2。拿 n / 2 当下标会报 TypeError: list indices must be integers，下标要写 n // 2。大整数用 / 还会丢精度：(10**17 + 1) / 1 得到 1e+17，末尾的 1 没了，因为 float 只有约 15–16 位有效数字。[4]

322 零钱兑换就用 inf 表示"凑不出"：

def coin_change(coins, amount):
    """322 零钱兑换：凑出 amount 的最少硬币数，凑不出返回 -1。"""
    INF = float('inf')
    dp = [0] + [INF] * amount          # dp[v]：凑出 v 的最少枚数
    for v in range(1, amount + 1):
        for c in coins:
            if c <= v and dp[v - c] + 1 < dp[v]:
                dp[v] = dp[v - c] + 1
    return dp[amount] if dp[amount] != INF else -1

coin_change([1, 2, 5], 11) 返回 3（5+5+1）；coin_change([2], 3) 中 dp[3] 始终是 inf，返回 −1。inf + 1 仍是 inf，所以 dp[v - c] + 1 不需要特判。

3.3 list：Python 的 vector

list 对应 C++ 的 vector：元素按顺序存放，下标从 0 开始，尾部添加删除很快。区别在于一个 list 里可以放不同类型的元素，而且自带切片、推导式这些很省事的写法。[5]

负下标和切片

Python 允许负下标：a[-1] 是最后一个，a[-2] 是倒数第二个，相当于 a[len(a) - 1]、a[len(a) - 2]。

切片 a[start:stop:step] 取出下标从 start 开始、到 stop 为止（不含 stop）、每次跨 step 的元素，组成一个新列表。三个参数都能省略：start 默认是开头，stop 默认是结尾，step 默认是 1。

切片左闭右开：x[2:5] 取下标 2、3、4；负下标 -k 就是 len-k

切片赋值能原地替换整段内容。189 轮转数组要求修改传进来的列表本身：

def rotate_right(nums, k):
    """189 轮转数组：原地向右轮转 k 步。"""
    n = len(nums)
    k %= n
    if k:
        nums[:] = nums[-k:] + nums[:-k]   # 切片赋值：改的是原列表对象

nums = [1,2,3,4,5,6,7]、k=3：nums[-3:] 是 [5,6,7]，nums[:-3] 是 [1,2,3,4]，拼起来写回 nums[:]，得到 [5,6,7,1,2,3,4]。如果写成 nums = ...，只是让函数里的局部名字改绑到新列表，调用者手里的列表纹丝不动（原因见 3.11）。

列表推导式

3.4 二维列表：每一行必须是独立的对象

DP 表、网格、邻接矩阵都需要二维数组。C++ 写 vector<vector<int>> g(m, vector<int>(n, 0))，会构造出 m 个各自独立的行。Python 有两种"看起来都对"的写法，其中一种藏着一个经典陷阱。[6]

正确写法：

def make_grid(m, n, fill=0):
    return [[fill] * n for _ in range(m)]

列表推导式执行 m 次，[fill] * n 每次都新建一个长度为 n 的列表，所以 m 行各是各的。_ 是"这个循环变量用不到"的惯用名字。

陷阱写法：[[0] * n] * m。* 对列表的含义是"把元素重复 m 次"，而外层列表的元素是对内层列表的引用，重复 m 次得到的是 m 个指向同一个内层列表的引用。

bad = [[0]*3]*2 后执行 bad[0][0] = 7：两个槽位指向同一行，两行一起变成 [7, 0, 0]

good = [[0]*3 for _ in range(2)] 后执行 good[0][0] = 7：只有第 0 行改变

我们完整走一遍：bad = [[0] * 3] * 2，先算 [0] * 3 得到一个列表 L = [0, 0, 0]，再 [L] * 2 得到 [L, L]。执行 bad[0][0] = 7，改的是 L 的第 0 个元素；bad[1] 也是 L，所以打印 bad 得到 [[7, 0, 0], [7, 0, 0]]，bad[0] is bad[1] 为 True。

那为什么 [0] * 3 这一层没有问题？因为它的元素是 int。row[0] = 5 是让槽位 0 改绑到新的 int 对象 5，其他槽位仍绑定 0，互不影响。陷阱只在"重复的元素本身是可变对象（列表、字典、集合）"时出现。

def two_sum(nums, target):
    seen = {}                          # 值 -> 下标（只存 i 之前的元素）
    for i, x in enumerate(nums):
        need = target - x
        if need in seen:
            return [seen[need], i]
        seen[x] = i                    # 先查后存
    return []

什么样的对象能当键：可哈希

dict 和 set 内部是哈希表：先对键调用 hash() 得到一个整数，用它决定放进哪个桶；同一个桶里再用 == 比较确认。所以能当键（或放进 set）的对象必须满足可哈希（hashable）的两个条件：[7] [8]

  1. 有 __hash__ 方法，而且在对象的整个生命周期里哈希值不变；
  2. 有 __eq__ 方法能比较相等，并且相等的对象哈希值必须相同。

可变容器的内容会变，哈希值无法保持不变，所以 list、dict、set 都无法哈希

由这两条可以推出各类型的情况：

最后一行是笔试爱考的点：只重写 __eq__ 会让对象变得无法哈希，因为默认的按身份哈希已经和新的相等规则矛盾了。要两者一起写，并让哈希值由参与比较的字段决定：

class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __eq__(self, other):
        return (self.x, self.y) == (other.x, other.y)

    def __hash__(self):
        return hash((self.x, self.y))  # 相等的对象必须有相同的哈希值

3.7 collections：Counter、defaultdict、deque

用 dict 计数要写 get(k, 0) + 1；用 dict 存放从键到列表的映射，要先判断键是否存在；用 list 当队列时，pop(0) 是 O(n)。collections 模块中的三个类型分别解决这三个问题，几乎每场笔试都用得上。[9]

Counter：计数器

Counter 是专门计数的 dict：传入任何可迭代对象，它统计每个元素出现几次。访问不存在的键返回 0（不报错，也不插入）。

from collections import Counter
c = Counter("banana")      # Counter({'a': 3, 'n': 2, 'b': 1})
c['a'], c['z']             # 3, 0
c.most_common(2)           # [('a', 3), ('n', 2)]：出现最多的 2 个
c.update("ab")             # 继续累加：a 变 4，b 变 2
Counter("aab") - Counter("ab")   # Counter({'a': 1})：减法只保留正数

小题：242 有效的字母异位词。 两个字符串字母相同、次数也相同：

def is_anagram(s, t):
    """242 有效的字母异位词。"""
    return Counter(s) == Counter(t)

defaultdict：键不存在时自动建默认值

defaultdict(list) 访问一个不存在的键时，会自动调用 list() 建一个空列表放进去，再返回它。defaultdict(int) 自动建 0，defaultdict(set) 自动建空集合。

小题：49 字母异位词分组。 把每个单词排序后的字母串当键，原单词追加到对应列表：

def group_anagrams(strs):
    """49 字母异位词分组。"""
    groups = defaultdict(list)          # 键第一次出现时自动建一个空列表
    for w in strs:
        groups[''.join(sorted(w))].append(w)
    return list(groups.values())

输入 ["eat","tea","tan","ate","nat","bat"]：eat、tea、ate 排序后都是 "aet"，tan、nat 是 "ant"，bat 是 "abt"，结果 [["eat","tea","ate"], ["tan","nat"], ["bat"]]。建图的邻接表也用它：graph = defaultdict(list)，然后 graph[u].append(v)。

deque：两端都是 O(1) 的队列

deque（双端队列）对应 C++ 的 deque，左右两端添加、删除都是 O(1)。list 的 pop(0) 要把后面的元素整体前移，是 O(n)；BFS 里每个节点都要出队一次，n 个节点就是 O(n²)，换成 deque 就是 O(n)。[10]

def bfs_dist(graph, start):
    """无权图 BFS：返回 start 到每个可达点的最少边数。"""
    dist = {start: 0}
    q = deque([start])
    while q:
        u = q.popleft()                 # O(1) 从左端取出
        for v in graph[u]:
            if v not in dist:
                dist[v] = dist[u] + 1
                q.append(v)             # 从右端放入
    return dist

def largest_number(nums):
    """179 最大数：需要"两两比较"规则时用 cmp_to_key。"""
    def cmp(a, b):
        if a + b > b + a:
            return -1                   # a 应排在 b 前面
        if a + b < b + a:
            return 1
        return 0
    strs = sorted(map(str, nums), key=cmp_to_key(cmp))
    ans = ''.join(strs)
    return '0' if ans[0] == '0' else ans

比较函数的约定：返回负数表示 a 在前，正数表示 b 在前，0 表示相等。[3, 30, 34, 5, 9] 的结果是 "9534330"：比较 "3" 和 "30" 时，"330" > "303"，所以 3 在 30 前面。

3.9 heapq：只有小根堆的优先队列

需要反复取出当前最小（或最大）的元素时用堆，例如前 K 大、合并 K 个有序链表、Dijkstra。堆的结构以及 push、pop 为什么是 O(log n)，见 1.9 优先队列 的图解和手写实现。C++ 的 priority_queue 默认是大根堆；Python 的 heapq 模块只提供小根堆，而且它不是一个类，而是一组函数，直接操作一个普通的 list：h[0] 是堆顶，下标 i 的孩子在 2i+1 和 2i+2，与 1.9 中的数组存法相同。[13]

元组入堆

堆里的元素可以是元组，比较时按元组规则：先比第一项，相同再比第二项。所以把优先级放在第一项即可：

def top_k_frequent(nums, k):
    """347 前 K 个高频元素：元组 (次数, 值) 入堆，按次数比较。"""
    heap = []
    for val, c in Counter(nums).items():
        heapq.heappush(heap, (c, val))
        if len(heap) > k:
            heapq.heappop(heap)
    return [val for c, val in sorted(heap, reverse=True)]

def merge_k_lists(lists):

Top-K：大小为 k 的小根堆

和第 1 章的思路一样：维护 k 个"目前最大的数"，堆顶是其中最小的，也就是"门槛"。新数比门槛大，就替换掉门槛。heappushpop 把"放入再弹出"合成一步，比分开调用更快：

def top_k_pushpop(nums, k):
    heap = nums[:k]
    heapq.heapify(heap)                 # O(k)
    for x in nums[k:]:
        if x > heap[0]:
            heapq.heappushpop(heap, x)  # 先放 x，再弹最小：一步完成
    return sorted(heap, reverse=True)

3.10 bisect：有序列表上的二分查找

第 8 章我们手写了 lower_bound：在有序数组里找第一个 ≥ x 的位置。Python 的 bisect 模块直接提供了这两个函数，名字不同，含义一致。[14]

Python含义C++ 对应
bisect_left(a, x)第一个 ≥ x 的下标；x 若已存在，插在它们左边lower_bound(...) - begin
bisect_right(a, x)第一个 > x 的下标；x 若已存在，插在它们右边upper_bound(...) - begin
insort(a, x)把 x 插到正确位置，保持有序insert(upper_bound(...), x)

两个函数返回的都是"插入位置"，范围是 0 到 len(a)，返回 len(a) 表示"所有元素都比 x 小"。

left 停在第一个 4 上，right 停在最后一个 4 的后面；x 比所有元素都大时（如 8）返回 len(a)=6

我们手算几个值，a = [1, 2, 4, 4, 4, 7]：

  • bisect_left(a, 4) = 2：下标 2 是第一个 ≥ 4 的位置；
  • bisect_right(a, 4) = 5：下标 5 的 7 是第一个 > 4 的元素；
  • bisect_left(a, 5) = bisect_right(a, 5) = 5：5 不在 a 中，两个函数结果相同；
  • bisect_left(a, 0) = 0，bisect_left(a, 8) = 6 = len(a)。

由此得到两个常用公式：x 的出现次数 = bisect_right(a, x) - bisect_left(a, x)；落在 [lo, hi] 的元素个数 = bisect_right(a, hi) - bisect_left(a, lo)。

五个辅助函数

官方文档给出了一组"在有序列表里找值"的写法，思路都是"先求插入位置，再看左边或右边那个元素"：

def index(a, x):
    """第一个等于 x 的下标；找不到抛 ValueError。"""
    i = bisect_left(a, x)
    if i != len(a) and a[i] == x:
        return i
    raise ValueError(x)

def find_lt(a, x):
    """最右边一个 < x 的值。"""
    i = bisect_left(a, x)
    if i:
        return a[i - 1]
    raise ValueError(x)

def find_le(a, x):
    """最右边一个 <= x 的值。"""
    i = bisect_right(a, x)
    if i:
        return a[i - 1]
    raise ValueError(x)

def find_gt(a, x):
    """最左边一个 > x 的值。"""
    i = bisect_right(a, x)
    if i != len(a):
        return a[i]
    raise ValueError(x)

def find_ge(a, x):
    """最左边一个 >= x 的值。"""
    i = bisect_left(a, x)
    if i != len(a):
        return a[i]
    raise ValueError(x)

记法："小于"类看插入位置的左边一格（i−1），"大于"类看插入位置本身（i）；带等号的 le / gt 用 right，不带等号的 lt / ge 用 left。每个函数都先检查下标是否越界：i 为 0 时左边没有元素，i 为 len(a) 时右边没有元素。

x = 4 时：find_lt=2（下标1），find_ge=4（下标2），find_le=4（下标4），find_gt=7（下标5）

3.11 函数与参数：共享传参、默认参数、nonlocal、记忆化

第 1 章用 int x、int& x、const vector<int>& 区分"拿到副本还是原对象"。Python 只有一种传参方式：把实参对象绑定到形参名字上，常被称为"对象共享传参"（call by sharing）。理解它只需要 3.1 的那张图。[15]

改对象 vs 重新绑定名字

def change(lst):
    lst.append(4)          # 改对象：调用者看得见

def rebind(lst):
    lst = [0]              # 只是让局部名字 lst 指向新对象
    return lst

进入函数时 lst 和 nums 指向同一个列表；append 修改它，调用者看得见；lst = [0] 只是改绑局部名字

所以 change(nums) 之后 nums 变成 [1, 2, 3, 4]；rebind(nums) 之后 nums 不变。int、str 这类内容固定的对象，函数里无论怎么写都只能改绑，所以调用者的值永远不会被函数改掉。C++ 里"在函数里交换两个外部 int"的写法在 Python 里做不到，通常改成返回新值：a, b = f(a, b)。

刷题里的直接后果：题目要求"原地修改数组"时，要写 nums[:] = ... 或逐个赋值 nums[i] = ...，写 nums = ... 只会改绑局部名字，评测拿到的仍是旧数组。

可变默认参数陷阱

默认参数的值在 def 语句执行时只计算一次，之后每次调用共用同一个对象：[16]

def add_bad(x, box=[]):
    box.append(x)
    return box

def add_good(x, box=None):
    if box is None:
        box = []
    box.append(x)
    return box

add_bad(1) 返回 [1]，再调 add_bad(2) 返回 [1, 2]，因为两次用的是函数对象里存着的同一个列表。add_good 用 None 当"没传"的标记，每次调用在函数体里新建列表，两次分别得到 [1] 和 [2]。规则：默认值只用 None、数字、字符串这类内容固定的对象。

嵌套函数和 nonlocal

回溯和 DFS 常在函数里再定义一个 dfs，让它直接用外层的变量。读外层变量没问题；给外层变量赋值时要先声明 nonlocal，否则 Python 会把它当成内层函数自己的新局部变量：

def max_depth(root):
    """嵌套函数 + nonlocal：在 dfs 里更新外层的 best。"""
    best = 0

    def dfs(node, depth):
        nonlocal best
        if node is None:
            return
        best = max(best, depth)
        dfs(node[1], depth + 1)
        dfs(node[2], depth + 1)

    dfs(root, 1)
    return best

（这里用元组 (值, 左, 右) 表示树节点，方便测试。）去掉 nonlocal best 这一行，best = max(best, depth) 会让 best 成为 dfs 的局部变量，等号右边读它时它还没有值，抛 UnboundLocalError。

什么时候不需要 nonlocal？只是修改外层对象、并不给名字赋值时。78 子集里 ans.append(path[:])、path.pop() 都是在改列表对象，ans、path 这两个名字始终绑定原来的列表，所以不用声明。判断标准就一条：内层函数里有没有 外层名字 = ... 或 外层名字 += ...。全局变量对应的关键字是 global。

lambda

lambda 参数: 表达式 是只有一个表达式的匿名函数，最常用在 key= 里。它只能写一个表达式，没有语句、没有 return；逻辑复杂时就写普通的 def。

递归深度与记忆化

CPython 默认的递归深度上限是 1000 层，超过就抛 RecursionError。链表长 10⁴ 的递归、深度可能到 10⁵ 的 DFS 都会触发。可以调高上限：[17]

import sys
sys.setrecursionlimit(10**6)

调高上限只是放宽检查，实际的 C 栈仍可能不够而崩溃。深度真的很大时，把递归改成显式栈（list 的 append/pop）更稳。

记忆化：给递归函数加上 @functools.lru_cache(maxsize=None) 装饰器，相同参数的调用结果会被缓存，第二次直接返回。（Python 3.9 起也可以写 @functools.cache，效果相同。）[12]

@lru_cache(maxsize=None)
def climb(n):
    """70 爬楼梯：记忆化递归。"""
    if n <= 2:
        return n
    return climb(n - 1) + climb(n - 2)

没有缓存时，climb(40) 要调用上亿次；有了缓存，每个 n 只算一次，共 40 个状态，瞬间得到 165580141。缓存以参数为键存进字典，所以参数必须可哈希：传 list 会抛 TypeError，要先转成 tuple。

1 / 4

先递归算 climb(4)
2 / 4

第2步 · climb(4) → climb(3) → climb(2)=2、climb(1)=1，climb(3)=3 存入缓存

climb(4) 还需要 climb(2)：命中缓存
3 / 4

第3步 · climb(4) = 3 + 2 = 5，存入缓存

回到 climb(5)，还需要 climb(3)
4 / 4

第4步 · climb(3) 命中缓存，climb(5) = 5 + 3 = 8

第一行是 n 个点、m 条边，后面 m 行每行一条边。m 达到 10⁵ 量级时，input() 逐行读会明显变慢，常见做法是把 input 换成 sys.stdin.readline：

def solve():
    input = sys.stdin.readline                 # 只在本函数里替换 input
    n, m = map(int, input().split())
    graph = defaultdict(list)
    for _ in range(m):
        u, v = map(int, input().split())
        graph[u].append(v)
        graph[v].append(u)
    dist = [-1] * (n + 1)                      # dist[v]：1 号点到 v 的最少边数
    dist[1] = 0
    q = deque([1])
    while q:
        u = q.popleft()
        for v in graph[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)
    return dist[1:]

readline 读到的字符串带着行尾的 '\n'。split() 会自动忽略它，所以这里没问题；但要把整行当字符串用时，必须先 .strip()，否则 "abc\n" 和 "abc" 比较不相等。上面的输入输出 0 1 1 2 3 -1（6 号点不可达）。

第一行 T 组数据，每组先给 n 再给 n 个数，但数字怎么换行没有规律。按行读会很麻烦；把全部输入读进来、按空白切开，问题就变成"从一个列表里依次取数"：

def solve():
    data = sys.stdin.read().split()   # 所有空白（空格、换行）都当分隔符
    pos = 0
    t = int(data[pos]); pos += 1
    answers = []
    for _ in range(t):
        n = int(data[pos]); pos += 1
        nums = list(map(int, data[pos:pos + n])); pos += n
        answers.append(max(nums) - min(nums))
    return answers

read().split() 抹平了换行；pos 指向下一个未读的 token，每组先读 n，再切出 n 个数

三组的"最大值 − 最小值"分别是 9−1=8、42−42=0、8−(−5)=13。这种写法是 Python 读入最快的方式，数据量大时优先用它。

每行求和，可能有空行。for line in sys.stdin: 会逐行读，读到结束（EOF）自动退出循环：

def solve():
    sums = []
    for line in sys.stdin:              # 逐行读，读到 EOF 自动结束
        line = line.strip()
        if not line:                    # 跳过空行
            continue
        sums.append(sum(map(int, line.split())))
    return sums

输出 6、6、7。如果习惯用 input()，读到结尾时它会抛 EOFError，写成 while True: try: line = input() except EOFError: break。
